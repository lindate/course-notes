P054定积分的应用 · 求面积：上减下、右减左

一句话核心

面积公式只有一句话：上面的函数减下面的函数，从 a 积到 b。要说清的不是公式，而是两件事——「谁减谁」不看大小，看上下（所以曲线跑到 x 轴下方也照样成立）；以及什么时候该改对 y 积分。选错型，一道题会从「一个积分」变成「两个积分」。

从哪里来：面积本来就是定积分的出身

00:00求面积是定积分最经典的应用，也是考试里几乎必考的一道。好消息是它并不陌生——定积分的定义本身就是用面积引入的。

先看最简单的情形：f(x)≥0。这时图像在 x 轴上方，它与 x 轴、直线 x=a、x=b 围成的曲边梯形，面积就是

S=∫abf(x)dx

没毛病。但考卷上几乎不会只给一个函数——真实题目都是两个函数夹着一块。这才需要动脑筋：谁减谁？怎么积？

X 型区域：上减下

00:48设两条曲线 y=f(x) 与 y=g(x) 在 [a,b] 上夹出一块阴影，且 f 在上面、g 在下面。怎么求它的面积？老师给的第一个思路很朴素，也很管用：分两步。

  1. 先求大块。f 与 x 轴之间、从 a 到 b 的面积是 ∫abf(x)dx。
  2. 再求小块。g 与 x 轴之间的面积是 ∫abg(x)dx。
  3. 相减。中间那块阴影正好是大块去掉小块剩下的，所以面积等于两者之差。
S=∫abf(x)dx−∫abg(x)dx=∫ab[f(x)−g(x)]dx

两个积分可以合并成一个，因为积分区间相同。于是得到这一节唯一要背的公式：

S=∫ab[f(x)−g(x)]dx(f在上,g在下)
「谁减谁」不看大小，看上下

学生最常问的一句是：如果 f 和 g 的大小关系在某一段反过来了呢？答案是——那就不是这一段的公式了，说明你该分段。公式里的 f 和 g 指的是「上面的那个」和「下面的那个」，不是「大的那个」和「小的那个」。

这个规定有一个立刻能验证的好处。老师提醒：把 g 取成 0，公式就退化成 ∫abfdx——正是最开始那条最简单的面积公式。也就是说，「f≥0 时面积等于定积分」本来就只是「上减下」的一个特例（下边是 x 轴）。

那如果曲线掉到 x 轴下面呢？这时「下面」不再是 x 轴了。假设上段在上方、下段在下方，记上方那块面积为 S1、下方那块面积为 S2：

  • S1 在上面，f≥0，所以 S1=∫abfdx；
  • 下半部分虽然面积是正的，但它的定积分值是负的（g≤0），所以 S2=−∫abgdx。

两式相加就得到

S=S1+S2=∫abfdx−∫abgdx=∫ab[f−g]dx

形式上完全没变。

所以结论是：不管这两条曲线在 x 轴的上面还是下面，都用上面的函数减下面的函数。「上减下」是一个几何位置的规定，不是一个大小比较——这样规定之后，正负号会自动被处理掉。

两段曲线纠缠怎么办

上面的公式有一个前提：在 [a,b] 上，谁是上面的那个是固定的。但真实题目里，两条曲线常常一会你在上、一会我在上——老师打了个很好玩的比方：就像谈恋爱闹分手，一会分一会不分，纠缠得很。

遇到这种图，最稳妥的写法是用绝对值：

S=∫ab|f(x)−g(x)|dx

因为加了绝对值，结果一定非负，不管谁在上面都不会错。但注意——这个写法只能用来「表达」，不能用来「计算」。带绝对值的积分你算不出来，必须把绝对值符号去掉。去绝对值就得知道每一段上谁在上、谁在下，于是自然要在交点处把区间切开：

S=∫ac[f(x)−g(x)]dx+∫cb[g(x)−f(x)]dx

其中 c 是两条曲线交点的横坐标（也是上下关系发生交换的地方）。所以遇到纠缠的图形，做题的流程是：先求交点 → 用交点把区间分段 → 逐段判断谁上谁下 → 逐段套「上减下」。

判断上下关系的唯一可靠办法是画图

求完交点，务必在草稿纸上画一个简图（哪怕几条直线的小草图）。取一个区间中点的数值代进去比一比大小，比在脑子里推理可靠得多。这一步花三十秒，能省掉一整道题的返工。

Y 型区域：右减左

有时候竖着切不好使，那就横着切。给定一条曲线 x=g(y)，y 从 c 到 d，它和 y 轴夹出的面积是

S=∫cdg(y)dy

为什么是 dy 了？老师的解释非常直观：把 x 轴和 y 轴互换一下，也就是把整个图形「放倒」。放倒之后，原来的 x=g(y) 就变成了我们熟悉的 y=g(x)，原来的积分区间 [c,d] 变成了横向的 [c,d]——于是它和一个普通的 X 型问题一模一样，只是变量名字换了。既然只是换个名字，那就不必真的倒一次，直接按原来的符号写 ∫cdg(y)dy 即可。

两个函数夹着的情况同理，只要把「上减下」翻译成竖直方向的说法：

S=∫cd[f(y)−g(y)]dy(f在右,g在左)

几何语言就是「右减左」：沿着 y 从 c 扫到 d，每个高度上都取右边的函数减去左边的函数。

用 Y 型时最容易忘的一件事

题目给的曲线几乎总是写成 y=⋯(x) 的样子（比如 y=x−4、y=2x）。要用 Y 型，必须先把它化成 x=⋯(y)——把等式里的 x 解出来。

为什么强调这一点？因为同学最常见的错误是：口头上说「用 Y 型、右减左」，然后直接把 y=x−4 当成右边的函数写进去，最后积出来一个带 y 却处处写着 x 的怪物。老师原话说得很直白：「做 Y 型的时候，这个右边的函数和左边的函数，都要写成 x 是 y 的函数。」

举个最小例子：y=x−4 要化成 x=y+4；y2=2x 要化成 x=y22。这两步不做，后面全错。

12:28到底用 X 型还是 Y 型

这是本讲的第二个重点，也是老师说「以后二重积分还要用到」的地方。判断方法只有一条，但非常好用：

选型判据

看这块阴影的边缘，找出那些「平着的」边（水平的或竖直的直线段），它们垂直于哪个轴，就用哪种型。

  • 阴影的边缘垂直于 x 轴（也就是边界里有 x=a、x=b 这样的竖直线）→ 用 X 型，对 x 积分；
  • 阴影的边缘垂直于 y 轴（边界里有 y=c、y=d 这样的水平线）→ 用 Y 型，对 y 积分。

弯曲的那些边不用看，只看直的那几条。

如果两种型都行呢？老师的建议是给一个固定顺序：

  1. 先考虑 X 型。因为它符合我们一贯的习惯（上下限是 x 的范围），写起来顺。做出来了就直接完事。
  2. X 型做不出来再考虑 Y 型。「做不出来」通常有两种：一是要分很多段，二是被积函数压根积不出来。这两种情况下换 Y 型往往一步到位。
  3. 用 Y 型时，先做变量改写。把每条曲线都化成 x=⋯(y)，再去写「右减左」。

老师还强调：这套 X 型 / Y 型的思路不只是为求面积服务的。「二重积分、三重积分、曲线积分、曲面积分都是一个套路」——二重积分化累次积分时，第一步就是判断这是 X 型区域还是 Y 型区域；有的被积函数按 X 型根本积不出来，必须换 Y 型。所以这一节练的不是面积，是「选坐标系」这个基本功。

两道例题

例 114:44求 y=2x、y=x 与 x=1 围成的图形的面积（两种型都做一遍）。

思路：先画图，再看边缘是横是竖

三条边是 y=x、y=2x（都过原点）和 x=1（一条竖直线）。阴影的边缘里有一条垂直于 x 轴的边，所以先用 X 型。

X 型

三角形的横坐标范围是 0≤x≤1。在每一竖线上比较：y=2x 比 y=x 大（当 x>0 时），所以上面是 2x、下面是 x：

S=∫01(2x−x)dx=∫01xdx=[x22]01=12

一步就完事了。

Y 型（为什么这里更麻烦）

如果改用 Y 型，就得把曲线化成 x=⋯(y)：由 y=2x 得 x=y2，由 y=x 得 x=y。麻烦在于右边的那条曲线会换人：

  • 当 0≤y≤1 时，右边是 x=y、左边是 x=y2，所以
    ∫01(y−y2)dy=[y24]01=14
  • 当 1≤y≤2 时，右边换成了竖直线 x=1（它确实是一个 x 关于 y 的函数），左边仍是 x=y2，所以
    ∫12(1−y2)dy=[y−y24]12=14

两段相加：S=14+14=12，和 X 型一致。

这一步容易漏

Y 型必须分成两段，因为 y=1 是「右边曲线换人」的分界点。很多同学只算了 ∫01 那一段就交卷，答案少了正好一半。

另外注意：x=1 这条竖直线在 Y 型里也要当成一个函数用（它确实是 x 关于 y 的函数），不要因为「它不叫 y=⋯」就不知道往哪儿放。

要点：同一块面积，X 型用 1 个积分，Y 型用 2 个积分。这就是「选型」的价值——选对了省一半工作量。

例 224:28求 y=x−4 与 y2=2x 围成的图形的面积。

思路：先画图 → 求交点 → 选型 → 分段

y2=2x 是一条开口向右的抛物线（上下两支：y=±2x），y=x−4 是一条斜直线。老师提醒：求面积、求体积、做二重积分，第一件事永远是画图。

第一步：求交点

把 x=y+4 代入 y2=2x：

y2=2(y+4)⇒y2−2y−8=0⇒(y−4)(y+2)=0

得 y=4 与 y=−2，对应 x=8 与 x=2。所以两个交点是 (2,−2) 和 (8,4)。

第二步：先用 X 型（要分两段）

看 x 的范围 0≤x≤8，但下方的边界在 x=2 处换了人：

  • 0≤x≤2：上面是 y=2x，下面是 y=−2x，所以
    ∫0222xdx=22⋅23[x32]02=22⋅23⋅22=163
  • 2≤x≤8：上面还是 y=2x，但下面换成了直线 y=x−4，所以
    ∫28(2x−(x−4))dx=563−6=383

两段相加：

S=163+383=543=18
第三步：换成 Y 型（一个积分搞定）

这块阴影的上、下边界是水平方向的两条虚线 y=−2 与 y=4——它们垂直于 y 轴，说明 Y 型更合适。把两条曲线都化成 x=⋯(y)：直线是 x=y+4（在右），抛物线是 x=y22（在左）。于是

S=∫−24[(y+4)−y22]dy=[y22+4y−y36]−24

上限代入：8+16−646=24−323=403；下限代入：2−8+86=−6+43=−143。相减：

S=403−(−143)=543=18

两个结果一致，都等于 18。

Y 型这道题最容易全盘错的地方

直接把 y=x−4 当成右边的函数写进去。写成 ∫−24[(x−4)−y22]dy 就全错了——被积函数里还留着 x，连积分都做不下去。

正确做法：先解出 x=y+4，再写 ∫−24[(y+4)−y22]dy。

要点：这道题把本讲的两件事一次讲全了——X 型要分两段、Y 型只用一个积分；而 Y 型省事的代价是必须先把曲线改写成 x=⋯(y)。另外注意交点要用 y 的方程去解（把 x 消掉），这样得到的 y=−2、y=4 恰好就是 Y 型要用的积分限，一步到位。

为什么「Y 型一个积分」通常更受欢迎

把例 1 与例 2 的经验合起来看，规律很清楚：选型选的就是「边界会不会换人」。

用 X 型时，你沿着 x 从左走到右，每遇到一个交点就要问一次「上边还是它吗、下边还是它吗」。k 个交点就意味着可能要分 k+1 段。用 Y 型时，你沿着 y 从下走到上，同样的问题换个方向问一遍。

所以真正的判据不是「哪种型更高级」，而是：换一个方向走，会不会少切几刀。例 2 里，y=x−4 与抛物线正好是一条水平边界的上下两端，横着走一路到底，那就用 Y 型；例 1 里有一条竖直线 x=1，竖着走一路到底，那就用 X 型。

另外，还有一个和分段无关的理由也会逼你换型：被积函数积不出来。有时按 X 型写出来的积分（比如带 e−x2 这样的）根本没有初等原函数，而换成 Y 型之后反而变得很好积。这就是老师说「有的题必须用另一种」的意思——到了二重积分那一章，这种情况会更常见。

记忆入口 · 一眼回忆

一句话

求面积 = 把图形「切」成一堆细条，每条的面积加起来。竖着切是 X 型（上减下），横着切是 Y 型（右减左）。

两个公式

S=∫ab[f(x)−g(x)]dx(X 型：上减下)
S=∫cd[f(y)−g(y)]dy(Y 型：右减左)

一条链

画图 草图必须有→ 求交点 定分段点→ 看边缘 垂直谁用哪种型→ 逐段上减下 定积分

要背的

  • 「谁减谁」不看大小、看上下。认准上面的函数写在前面，曲线在 x 轴下方也照写，符号会自动对。
  • 曲线纠缠（上下来回换）时用 ∫ab|f−g|dx 表达，但计算必须按交点分段去掉绝对值。
  • 用 Y 型前必须把曲线化成 x=⋯(y)——这一步不做，全盘错。
  • 选型顺序：先 X 后 Y；X 型做不出来（段太多、积不出来）就换 Y 型。

两个坑

  1. 忘了分段。例 1 的 Y 型、例 2 的 X 型都必须在交点处切开；少算一段，答案直接少一半。
  2. dx 与 dy 写混。对 y 积分时积分限是 y 的范围、被积函数是 x 关于 y 的表达式，三者必须配套。

一个意识

这一节练的其实不是面积，而是「选坐标系」：二重积分化累次积分时，第一步就是判断 X 型区域还是 Y 型区域；三重积分、曲线曲面积分都是同一套思路。所以一定要把「看边缘、选型、分段」练成条件反射。
