P138【黑板】二重积分{极坐标}

一句话核心

极坐标二重积分的题，九成的错都发生在动笔之前——θ 从哪转到哪、r 的上限写成什么，这两步定不下来，后面的积分再熟也没用。这一页是黑板精讲，重点不是那条公式（公式当然还是 dσ=rdrdθ），而是一套「转角度、画射线」的区域扫描动作：先把常见区域——整圆、扇形、圆环、偏心圆、被直线截出的角形——的极坐标表示练成条件反射，再谈积分。偏心圆与直线题是本节的重头：那里的 r 上限几乎都不是常数。

一、先把三个参数的规矩立好

00:41老师开场就说得很直白：极坐标这部分的课本里「几乎来说我们想用的东西都没有」，而它在「后边解题过程中非常非常重要」——学不懂它，后面的柱坐标、球面坐标，以及一切能用极坐标的积分，全都会塌掉。所以这一节先把地基夯一遍。

三个参数，三条规矩。

  • 极轴。01:14就是从原点出发、朝右的那条射线，其实就是 x 轴的正半轴。注意：极轴只有右半边，没有朝左的部分。这不影响做题，因为我们所有的题目都是从直角坐标系「引出」极坐标的。
  • r。点到原点的距离，所以必定 r≥0。「我们国内的教材都是 r 大于等于零」；国外有些教材允许 r<0，那也能用，但课本不认。
  • θ。从极轴出发、沿逆时针转过的角度，0≤θ≤2π。转满一圈会把平面上所有点扫一遍，严格说取不到 2π；但二重积分要求两个端点都能取到，照写「零到二派」。

04:25转换公式三条，先摆出来：

x=rcosθ,y=rsinθ,x2+y2=r2

老师强调：「好多同学容易记混，记成 x 对应 sin、y 对应 cos，这是不对的。」正确的记法是看直角三角形——对边比斜边是 sin，所以 y 配 sin；邻边比斜边是 cos，所以 x 配 cos。另有一条在直线题里很省事的：yx=tanθ。

03:21为什么课本写 0 到 2π，做题却常常从负角写起

因为「合法」和「好用」是两回事。看两种情形：

  • 09:29一块扇形如果从 0 转到 π4、再从 7π4 转到 2π，严格说要分成两段才能覆盖。改成 −π4 到 π4，一段就写完了。
  • 10:14第四象限里的一块区域，若按规定写就是 3π2 到 2π。「你是不是觉得你自己写的都很别扭啊」——直接写 −π2 到 0 就干净了。

所以取负角不是违规，而是一种「让上下限变好看」的等价写法。代价只有一个：你必须回头确认 r 的表达式在这段角度上不会变成负数（后面第三节会专门检查这一条）。

二、定区域只有一个动作：转角度、画射线

06:08老师把「用极坐标描述一个区域」压缩成两个动作，像做操一样：

  1. 先定 θ。「你拿着一只胳膊，从 x 轴的正半轴开始转，注意是沿着逆时针转」——一直转到再转就扫不到区域为止。「再转的话是不是没有阴影部分了？那你转了个寂寞吗？那就不用转了呗。」
  2. 再定 r。在角度范围内随便画一条射线，看它穿过区域时「离原点最近是多远、最远是多远」。老师建议「你最好多画两条」，两条都对得上才放心。

这里有个容易被忽略的细节：r 的量法始终以原点为起点。图上标的数字若恰好是「到圆心的距离」，那就不能直接搬来当上下限——下一个坑就是这么来的。

图上画着一段圆弧围成的环带，旁边标了 4 和 5 两个数，问 r 的范围。不少同学张口就写 4≤r≤5。老师说：你看一忽悠你就上当了是吧。

为什么不能照抄那两个数字？因为 r 的定义是点到原点的距离，图上标的数字却不一定是从原点量起的。要判断只能自己动手：在角度范围内画两三条射线，把每条射线与区域边界的最近交点、最远交点分别量到原点的距离。图上写的数字只是提示，不是答案。

三、偏心圆与直线：r 的上限几乎都不是常数

14:55这是本节最容易丢分的一类，也是老师花了最长时间拆解的一类。题目是：圆心 (1,0)、半径 1 的圆面，问极坐标表示。

他先演了一遍「对话式」的推导。先看角度：

老师的现场追问

这个角度是从零度开始转，转到 45 度行不行？14:55——不行，「你仔细画一下，转到 45 度是不是转到了这？那这一小点你没转到啊」。那继续转到 90 度呢？89 度？16:0889.9999 度？那不就是 90 度吗。老师说，这其实就是极限的定义：「他无限接近就是相等」。

所以 θ 从 0 到 π2。接下来是 r：

17:05「这样写是一个严重的错误」

r 是不是大于等于 0、小于等于 2？最远的那个点那个距离是不是 2？——不是。老师说：「最远的这个点的距离这么长、这么长、这么长……有没有发现在逐渐地变小？」到 θ=π2 时，射线和圆只在原点相交，最远距离是 0。你写的这个式子对应的是另外一款，你要的其实是这一款。

18:36正确的办法是代入法：把圆的方程 (x−1)2+y2=1 展开成 x2+y2=2x，再代入 x2+y2=r2 与 x=rcosθ，得 r2=2rcosθ，两边约掉一个 r（r≠0 的部分才构成圆），于是

r=2cosθ,0≤r≤2cosθ

验一遍：θ=0 时 cos0=1，上限是 2，正好是图上最远那一点 (2,0)；θ 越来越大，cosθ 越来越小，「θ=π2 的时候这个点离原点的距离是不是 0」——完全吻合。老师一句话点到要害：「所以我们经常用这个代入法来确定它」。

下面四组结果（两个偏心圆 + 两条直线）必须背下来，考试常出：

22:09写完范围以后，为什么还要「怀疑一下自己」

老师把 −π2 到 π2、0≤r≤2cosθ 写完，立刻说：「你应该怀疑一下你自己。」为什么？因为上面那道题只做了第一象限，现在多出个第四象限——θ 取负角时，r=2cosθ 会不会变成负数？

「我一说你是不害怕一下子？」但只要一考虑就没什么事：cosθ 在 −π2 到 π2 上恒为正，所以 r 总是正的。

同样的检查在直线题里也要做。30:57r=1sinθ 配合 π4 到 3π4，老师也追问了一遍：「sinθ 如果是个负的，你这个 r 是不是就是个负的啦？」——从 π4 到 3π4 上 sinθ 恒正，「对呀，没问题」。

于是有了本页最实用的一条自检规则：只要 r 的上限里含 θ，就顺手问一句「它在我这个角度范围里会不会变负」。变负了就说明角度范围写错了。

两类「组合区域」

32:41把上面几块拼起来，就是常考的难度题。

  • 「内圆 + 外直线」。32:41内边界是圆心在原点的单位圆、外边界是直线 x=1、只取第一象限那一块。角度从 0 到 π4；射线上的最近点始终在单位圆上（距离恒为 1，不动），最远点在 x=1 上，所以 1≤r≤1cosθ。老师点评：「这不刚才都讲了吗，这两个单独的是不是都讲了，把它融合了一下。」
  • 「外形 + 内偏心圆」。35:11半径 2 的四分之一圆里，挖掉圆心 (1,0)、半径 1 的圆。角度仍是 0 到 π2；最近点在偏心圆上，r=2cosθ；最远点在半径 2 的圆上，恒为 2。于是 2cosθ≤r≤2。内边界给下限，外边界给上限。

四、面积元素：为什么这里要多一个 r

35:48直角坐标下我们「横着切、竖着切」，每一小块是长方形，面积就是 ΔxΔy，所以 dσ=dxdy。很自然地会想：极坐标下不也一样吗，dσ=drdθ 不就完了？

37:33老师说：「这个地方就不太一样了。」极坐标的切法是先朝外面画射线，然后再画同心圆——一族过原点的射线加一族同心圆。切出来的小块不是长方形，而是一个「小扇形环」。

  1. 扇形面积公式不妨现场推。41:29「这个扇形的面积，其实它有一个固定的公式，但是我都不愿意记。」老师喜欢用比例：整圆面积是 πR2，角度 θ 占整圆 θ2π，面积就占同样的比例，于是 S=12R2θ。
  2. 算大扇形。半径 r+Δr、张角 Δθ，面积是 12Δθ(r+Δr)2。
  3. 算小扇形。半径 r、张角同样是 Δθ，面积是 12Δθr2。
  4. 相减。把 12Δθ 提出来，括号里用完全平方展开：
    Δσ=12Δθ[2rΔr+(Δr)2]=rΔrΔθ+12Δθ(Δr)2
  5. 丢掉高阶项。第二项与主项的比是 Δr2r→0，是高阶无穷小，取极限时消失。
45:43那个「平均数」和「小点点」，说的都是同一件事

推导到第四步时，老师绕了一个弯：他把 rΔrΔθ 里的 r 拆成 r+(r+Δr)2，说「短的这个加长的这个除以 2，是不是求它俩的平均数啊？它俩的平均数是不是那个中点的长度？」47:23然后补一句：切小块时「要切得非常非常小」，那个中点「向这个点是不是也无限接近」——所以在极限下，平均长度就是 r。

绕这一圈的意义在于，它把「哪些项可以扔」讲明白了。12Δθ(Δr)2 相对主项是高阶无穷小，扔得心安理得；那个「平均值」在极限下塌成 r。做题时这套推导一个字都不用写，但你要知道它为什么成立。

48:48于是转换公式登场。老师用他惯用的说法宣布：「数学老师经常会大喊一声——注意我要变形了。」然后一句一句换：x 换成 rcosθ，y 换成 rsinθ，dxdy 换成 rdrdθ：

∬Df(x,y)dσ=∬Df(rcosθ,rsinθ)rdrdθ
书写顺序：极坐标永远是 θ 在前、r 在后

53:21写成累次积分时，先写 θ 的范围、再写 r 的范围，即 ∫αβdθ∫r1(θ)r2(θ)⋯rdr。老师特意确认过：「这俩顺序还颠倒吗？不颠倒，都是 θ 在这、r 在这。」

顺序不是装饰——它决定了「先算哪个积分」。按这个写法，先算内层的 r 积分，再算外层的 θ 积分。下一节的「能不能拆」全靠这个顺序判断。

五、四道例题

例 150:03计算 ∬Dxydσ，其中 D:1≤r≤2、0≤θ≤π2。

思路：范围直接给了，只需换被积函数 + 补那个 r

极坐标的题第一步永远是范围，这题范围是现成的。被积函数 xy=(rcosθ)(rsinθ)，再乘上面积元素里的 r，一共出现三个 r：

∬Dxydσ=∫0π/2dθ∫12(rcosθ)(rsinθ)⋅rdr=∫0π/2sinθcosθdθ⋅∫12r3dr

内层那部分与 θ 无关（上下限都是常数），所以可以把它单独算成一个数再相乘：∫12r3dr=[r44]12=16−14=154。外层凑微分：∫0π/2sinθcosθdθ=[12sin2θ]0π/2=12。相乘：

∬Dxydσ=12×154=158
54:45什么时候能「加神奇小点点」

老师管「把重积分拆成两个定积分相乘」叫「加神奇小点点」。54:45判断标准只有一条：内层积完之后，如果结果是常数（与外侧变量无关），就能拆。这题的内层积出来是 154，一个纯数，所以「它俩之间根本就没有关系」。

反过来，只要内层的上限含有外侧变量，就绝不能拆。下一题正是这种情况——那也是本页最重要的一处对比。

例 258:40计算 ∬Dydσ，其中 D:x2+y2≤y。

思路：先认出这是偏心圆，再老老实实一步步算

x2+y2≤y 是个偏心圆（圆过原点，圆心在 (0,12)）。按前面练过的：θ 从 0 到 π；x2+y2=y 代入得 r2=rsinθ，约掉 r 得 r=sinθ。所以 0≤r≤sinθ。

59:52被积函数 y=rsinθ，配上面积元素里的 r，内层是 r3/2sinθ。注意 sinθ 里也含 θ，它可以提到内层积分号外面：

∬Dydσ=∫0πdθ∫0sinθr3/2sinθdr=∫0πsinθ[25r5/2]0sinθdθ

代入上限得 (sinθ)5/2，与前面那个 sinθ 合起来变成 (sinθ)3：

∬Dydσ=25∫0πsin3θdθ=25×43=815
1:01:02这一题就是「不能加小点点」的样板

老师在这里连问了两遍：「刚才这个地方能加神奇小点点，现在我的问题是这个地方能不能加？不能。为什么不能？它的上限有 sinθ 这个东西，求出来以后是不是 θ 的函数啊？它得带到前面再对 θ 去求。」

所以这题必须先算内层、代回外层，再对 θ 积分，一步都不能提前。积分 ∫0πsin3θdθ 既可用点火公式（2×23=43），也可凑微分 sin3θ=(1−cos2θ)sinθ 硬算，结果一样。

例 31:04:00计算 ∬De−(x2+y2)dσ，其中 D:x2+y2≤a2。

思路：整圆 + 含 x2+y2——极坐标最漂亮的一类

θ 从 0 到 2π，r 从 0 到 a（射线上的最远距离处处是 a，是常数）。被积函数 e−(x2+y2)=e−r2，再乘面积元素里的 r：

∬De−(x2+y2)dσ=∫02πdθ∫0ae−r2rdr=2π⋅[−12e−r2]0a

这里内层上限是常数，照旧可以「加小点点」；而且更省事——被积函数里那个 r 正好拿来凑微分（rdr=12d(r2)）：

∬De−(x2+y2)dσ=π(1−e−a2)
1:07:53顺手挤出一个著名的反常积分

上题的结果可以直接用来算 ∫0+∞e−x2dx。1:07:53老师先说明为什么不能硬算：「e−x2 对 x 直接积是积不出来的。」于是换个思路——把一元积分配成二元积分，再用两块区域去夹。

1:11:30他画了三块区域：D1 是半径 R 的四分之一圆，S 是边长 R 的正方形（第一象限），D2 是半径 2R 的四分之一圆。1:14:26三者一个套一个，被积函数 e−(x2+y2) 又恒正，所以对应的三个积分也一个夹一个：

∬D1e−(x2+y2)dσ≤∬Se−(x2+y2)dσ≤∬D2e−(x2+y2)dσ

两边用极坐标算，分别是 π4(1−e−R2) 与 π4(1−e−2R2)。中间那块用直角坐标算，得 (∫0Re−x2dx)2——定积分与积分变量用什么符号无关，两个因子长得一模一样。

让 R→+∞，两个 e−R2 都趋于 0，两边同时趋于 π4。由夹逼定理中间那块也趋于 π4，开方得 ∫0+∞e−x2dx=π2。1:18:39老师说这个结果「在高数里用得不多，但在概率和工程里用得比较多」，知道就好。

例 41:19:30求球体 x2+y2+z2≤4a2 被圆柱面 x2+y2=2ax 截出的那部分立体的体积。

思路：先靠对称性缩到一块，再让极坐标接手

1:19:30老师说这个图「不好理解」，但套路没变。圆柱面 x2+y2=2ax 不含 z，「它沿着 z 轴上下移动，不就整出来一个烟囱吗」——是一个偏心圆绕着 z 轴竖起来形成的柱面。1:22:41立体被这个柱子切成了好几块：左边一块、下边一块、还有几块。利用对称性，只算其中一块再乘 4——取 x≥0、y≥0 那四分之一。

投影区域 D 就是圆柱面那个圆 x2+y2=2ax 落在第一象限的部分，即 θ 从 0 到 π2、r 从 0 到 2acosθ（偏心圆，老熟人）；曲顶是球面的上半支 z=4a2−x2−y2=4a2−r2。于是体积是个曲顶柱体，用二重积分的定义直接写：

V=4∫0π/2dθ∫02acosθ4a2−r2rdr

1:26:03这里不能加小点点——上限 2acosθ 含 θ。内层凑微分：4a2−r2rdr=−13(4a2−r2)3/2。代入 r=2acosθ 时 4a2−r2=4a2sin2θ（开 32 次方得 8a3sin3θ，在 [0,π2] 上 sinθ≥0，不必加绝对值）；代入 r=0 得 8a3。内层是 8a33(1−sin3θ)，所以

V=32a33∫0π/2(1−sin3θ)dθ=32a33(π2−23)

又用了一次点火公式：∫0π/2sin3θdθ=23。这道题把本页所有工具串了一遍：偏心圆的范围、面积元素里的 r、凑微分、点火公式、对称性——一个都不新，只考基本功。

记忆入口 · 一眼回忆

一句话

极坐标做题 = 转角度、画射线定上下限，再多乘一个 r 积分。难点全在第一句。

核心公式

∬Df(x,y)dσ=∬Df(rcosθ,rsinθ)rdrdθ

一条链

转角度 θ 从哪到哪→ 画射线 找最近、最远→ 怀疑一下 r 会不会变负→ 补一个 r 再积分

要背的区域（偏心圆与直线）

整圆 x2+y2≤a2
0≤θ≤2π，0≤r≤a
(x−1)2+y2≤1
−π2≤θ≤π2，0≤r≤2cosθ
x2+(y−2)2≤4
0≤θ≤π，0≤r≤4sinθ
直线 x=1 截出的角形
0≤r≤1cosθ
直线 y=1 截出的角形
0≤r≤1sinθ

两个坑

  • 偏心圆的 r 上限不是常数。以为「最远就是 2」是本节最贵的错；写成常数就等于换了另一块区域。
  • 「能不能加小点点」看内层。内层积完是常数 → 能拆成两个定积分相乘；内层上限含外侧变量 → 不能拆，必须逐层做（例 2 与例 1 的对比）。
