P005数列的极限：把「越来越接近」变成一句能检查的话

一句话核心

这节课只干一件事：给「n 越大，an 越接近 A」这句大白话装上刻度。办法是——你随便报一个多小的容许误差 ε，我都能指给你看某一项，从它之后所有的项全都待在 A 的 ε 范围里。就靠「存在 N」这一句，用有限管住了无限。

数列：一句话说完

00:37数列就是按正整数编好号排成一列的数：x1,x2,x3,…,xn,…。这里唯一容易踩空的地方是：它必须是无限多项——末尾那个「点点点」不是省略号随便写写，它代表「永远还有下一项」。

课上举的几个例子，看一眼就明白什么叫通项公式：

写出来的样子通项 xn一句话说明
1,2,3,…,n,…n就是正整数本身
12,23,34,…nn+1n 一取定，这一项就定了
2,4,8,…2n翻倍增长
1,1,1,…1常数列也算数列
1,−1,1,−1,…(−1)n+1常数列的「变号版」，它不收敛

式子外面加个大括号 {xn} 就表示整个数列。还有一句话值得记住：数列其实是 n 的函数——n 是自变量（只取正整数），xn 是因变量。后面研究极限，本质就是在看「当自变量 n 越来越大时，函数值往哪走」。

记号小坑

写 n→∞ 就可以了，不用写成 n→+∞。因为 n 本来就是正整数，只能往大走，所以「趋于无穷」在这里默认就是「趋于正无穷」。课上专门提过这一句——写 +∞ 不算错，但没必要。

极限值是「猜」出来的

03:05先看最简单的：

11,12,13,14,…1,0.5,0.333,0.25,0.2,…

越往后越小，越往后越贴着 0。所以我们「猜」它的极限是 0。

05:10到这里要停一下想清楚一件事：「猜」不是敷衍。在正式做题时，极限值通常都是先看出来的——因为你能看出趋势，说明你懂了这个数列。定义真正的作用不是帮你求极限，而是帮你证明你猜的那个数是对的。所以后面所有例题的套路都是同一条：先猜 A，再用定义验证 A 确实是极限。

「无限接近」到底该怎么描述

06:07这是全课最关键的一步。老师没用数学语言，用了两个生活例子，效果反而更好：

视频原话（大意）

比如我媳妇站我旁边，挨得特别近，我说咱俩的距离趋于零。那她就问了：有多近？是 10 厘米吗？我说比 10 厘米还近。那是一厘米吗？我说比一厘米还近——不管你报一个多小的距离，我都比你报的那个更近。

再换个例子：我说我比你有钱。你说你有 1 万块，我说我有 1 万零 1 块。你说你有 10 万，我说我有 11 万。你随便报一个数，我的钱都比你多。

这两句话里藏着同一个结构，也就是我猜出的极限为什么成立：

你任意报一个距离 ε → 我都能找到某一项 → 从那一项往后全部落在里面

注意这里「任意」和「存在」的顺序不能换。是你先报、我后找——顺序一反，意思就完全变了（变成「我先找一个固定的位置，然后要求所有距离都满足」，那当然做不到）。这就是为什么定义里 ε 写在 N 前面。

再看一个从两侧逼近的例子

11:30课上第二个例子是

an=n+(−1)n−1n=1+(−1)n−1n

把它拆开看就很清楚了：前面的 1 是不动的，后面 (−1)n−1n 只干一件事——制造一个正负号。n 是奇数时它是正的，n 是偶数时它是负的，但大小 1n 在往 0 跑。所以整个数列就在 1 的左边一下、右边一下地摆动，而摆幅越来越小。

数列极限的定义

定义 · 数列的极限

设 {xn} 是一个数列，A 是一个常数。如果对任意给定的正数 ε>0，总存在正整数 N，使得当 n>N 时，都有

|xn−A|<ε

则称 A 是数列 {xn} 的极限，也称数列收敛于 A，记作

limn→∞xn=A或xn→A(n→∞)

如果这样的常数 A 不存在，就说数列发散。

15:52定义只有三行，但每个字都在干活。逐句拆开看：

存在常数 A
先要有一个候选值。「存在」的意思就是「能找到」——所以它不会凭空告诉你答案，答案要你自己先猜出来。
任给 ε>0
这是「误差标尺」，你随便报，多小都行。因为是距离，所以一定取正数。
存在正整数 N
这是定义里唯一需要你动手算的东西：你要指出「从第几项开始」。课本上写 N 时可以不写它的具体式子——考试时也允许先空着，等草稿纸上推完了再填。
当 n>N 时
注意是 n>N 而不是 n≥N。这一项往后的所有项都要满足，前面那有限几项不在考核范围内。
|xn−A|<ε
这个绝对值就是「xn 与 A 的距离」。整条定义的落点就在这一个不等式上。
为什么这一句话就能代替「无限接近」

「无限接近」的问题在于它无法检验：你说接近了，那到底算不算？定义给出的检验方式是反过来问——你挑毛病。你报一个 ε，只要能找到违反它的项（也就是落在外面且序号还很大的项），那 A 就不是极限。

于是「收敛于 A」等价于一句话：任何 ε 带的带外，都只剩下有限个项。有限个项再多也是有限的，总有一个最大序号——把它取成 N 就完事了。这就是「有限管住无限」的意思：无穷多项里，只有掉队的那几项被容忍，其余无穷多项必须一直待在带子里。

19:05把绝对值不等式拆开，定义就变成了一个更好用的形式：

A−ε<xn<A+ε

这时它读起来就是：xn 落在开区间 (A−ε,A+ε) 里面。这个区间叫 A 的 ε 邻域，宽度是 2ε。做题时用双边形式往往比绝对值形式更好下手，因为两边可以分别去估计。

怎么用定义证明一个极限

23:15这是本节课最实用的一段。老师反复强调了一件事，很多同学听完还是懵的：「倒着推、正着写」。

  1. 先猜出 A 是多少。看趋势猜，这个不许含糊。
  2. 在草稿纸上倒着推。目标是让 |xn−A|<ε 成立，把这个不等式当成条件去反解出「n 需要多大」。两边一通整理、放缩、化简，最后落到一个形如 n>(ε 的表达式) 的式子。
  3. 把结论填回 N。上面那个表达式（必要时取整再加一，保证它确实是整数）就是 N。这一步是最后一步写上去的。
  4. 卷面上正着写一遍。「任给 ε>0，取 N=…，则当 n>N 时有……」——从 n>N 出发，一路推到 |xn−A|<ε。
为什么要绕这一圈

因为定义里的逻辑顺序是：先给定 ε，再存在 N。所以写出来必须是「任给 ε → 取 N → 当 n>N 时成立」。但你在动手之前根本不知道 N 该取什么，只能先在草稿纸上从结论往回推。推出来了、心里有底了，再按定义要求的顺序抄一遍。

所以卷面上不要写「为了使……成立，需要……」这类倒推过程。阅卷人要看的是「N 取好了，结论成立」，而不是你怎么找到 N 的。老师课上打了个比方：先在答案的位置留个空，往后写，草稿纸上推完了再回来把 N 填上去。

例 122:42证明 limn→∞1n=0。

草稿纸上怎么想

A=0 已经猜好了，所以只需要让 |xn−A|<ε 成立，也就是 |1n−0|<ε。因为 1n 和 ε 都是正的，绝对值可以直接去掉：

1n<ε⟹n>1ε

推到这里就结束了：只要 n 比 1ε 大，不等式就成立。但 N 必须是正整数，而 1ε 不一定是整数——所以取「取整再加一」：N=[1ε]+1，这样保证 N>1ε 一定成立。

卷面上怎么写

任给 ε>0，取 N=[1ε]+1，则当 n>N 时

n>N=[1ε]+1>1ε⟹1n<ε⟹|1n−0|<ε

于是按定义，limn→∞1n=0。证毕。

为什么要「取整加一」而不是直接取 1ε

分两种情况，结论都能落到同一句话上：

  • 1ε 本身是整数（比如 ε=0.001，1ε=1000）：取整还是它自己，加一之后是 1001，显然大于 1000。
  • 1ε 不是整数（比如 ε=112.3，1ε=12.3）：取整得 12，加一得 13，而 13>12.3。

两种情况都保证 N>1ε，所以这个 N 写法是安全的。这一步看着像「技术处理」，其实正是定义严谨性的地方——定义要求 N 是正整数，不是一个实数。

例 231:04证明 limn→∞n+(−1)n−1n=1。

草稿纸上怎么想

这个数列就是前面画图那个。目标：|n+(−1)n−1n−1|<ε。先化简：

n+(−1)n−1n−1=(−1)n−1n

加上绝对值以后，(−1)n−1 这个符号就没用了（绝对值吃掉它）：

|(−1)n−1n|=1n

接下来和例 1 一模一样：1n<ε 就是 n>1ε，所以

N=[1ε]+1
卷面上怎么写

任给 ε>0，取 N=[1ε]+1，则当 n>N 时有 1n<ε，于是

|n+(−1)n−1n−1|=|(−1)n−1n|=1n<ε

故 limn→∞n+(−1)n−1n=1。证毕。

做题时的感受

这道题卷面上写出来会觉得「好像什么都没干」——确实如此。所有需要动脑的部分（把式子化简成 1n、确认 N 取多大）都在草稿纸上。卷面只负责把逻辑顺序摆对，这也是定义类证明题普遍的样子。

例 337:46证明 limn→∞(−1)n(n+1)2=0。

草稿纸上怎么想

先猜：分母 (n+1)2 长得飞快，分子只是个正负号，所以极限是 0。目标是

|(−1)n(n+1)2−0|=1(n+1)2<ε

这里如果直接解得 n>1ε−1，式子太丑。课上用了一步放缩把它变简单：因为分母变大了，倒数就变小，所以

1(n+1)2<1n2

于是只要让 1n2<ε 就够了——这是更强的要求，它成立则原来的不等式必然成立。解 1n2<ε 得 n>1ε，所以取

N=[1ε]+1
卷面上怎么写

任给 ε>0，取 N=[1ε]+1，则当 n>N 时 n>1ε，即 1n2<ε，从而

|(−1)n(n+1)2|=1(n+1)2<1n2<ε

故 limn→∞(−1)n(n+1)2=0。证毕。

放缩的用法与代价

放缩的方向只有一条原则：放缩之后要更好算，而且放得「够狠」（也就是确实比原式大，这样把大的压住了，小的自然就压住了）。这里的代价是 N 变大了——不去放缩时 N 是 1ε−1 取整，放缩后是 1ε 取整，稍微大一点。

但这完全没关系，因为下一节要讲的正是：N 本来就不唯一，只要存在一个就够了，取大一点不算错。

例 446:27设 |q|<1，证明 limn→∞qn−1=0。

草稿纸上怎么想

先猜：q=0.5 时是 12n−1，q=−13 时是 ±13n−1，都在缩向 0，所以极限是 0。目标是

|qn−1|<ε⟹|q|n−1<ε

指数形式的 n 不好直接解出来，所以两边取对数（两边都是正数，取对数合法）：

(n−1)ln|q|<lnε

这一步要看清符号。因为 |q|<1，所以 ln|q|<0；又因为 ε 可以取得很小，不妨设 ε<1，于是 lnε<0。一个负数乘 (n−1) 小于一个负数，两边同除以 ln|q|（负数）时不等号要反向：

n−1>lnεln|q|⟹n>1+lnεln|q|

所以取 N 为右边那个表达式的取整加一即可。

卷面上怎么写

任给 ε>0，不妨设 ε<1，取

N=1+[lnεln|q|]

则当 n>N 时，n−1>lnεln|q|，两边乘 ln|q|（负）反向后得 (n−1)ln|q|<lnε，即 ln|q|n−1<lnε。由于 ln 单调递增，故 |q|n−1<ε，也即 |qn−1−0|<ε。所以 limn→∞qn−1=0。

这一题的两个坑

坑 1：不加「不妨设 ε<1」就直接用 lnε。ε 是任给的正数，取 ε=100 时 lnε>0，符号讨论会全部乱掉。写「不妨设」是合法的——因为我们要对付的本来就是「ε 很小」的困难情形，ε 很大时带子里能装下所有项，反而更容易满足。

坑 2：两边除以 ln|q| 时忘了变号。因为 ln|q|<0，除一个负数不等号必须反向。这一步写错，最后得到的 N 方向就是反的，整个证明不成立。

老师的话

这类用 ε–N 语言做的证明题，在大学高数里「了解即可」——不是考试重点。后面更常用、更省力的手段（极限的四则运算、重要极限、等价无穷小、洛必达）都会陆续学。但是定义本身必须吃透，因为它定义了「收敛」这个词的含义，后面所有关于极限的判断都建立在它上面。

两个容易被忽略的细节

42:10例 3、例 4 里我们写出了 N 的具体表达式，但有一件事必须掰开说：

细节一 · N 不是唯一的

定义说的是「存在」一个 N，没说「只有这一个」。用 ε=0.01 算出来 N 够用，那把 N 换成 100N、10000N 当然更够用——只要项数够靠后，就越没问题。

所以考试时不必纠结「我的 N 和答案不一样是不是错了」。不一样是正常的，尤其是用了放缩之后——放缩会牺牲精确度，换来的是算式干净。

细节二 · 只能往后挪，不能往前挪

如果从第 N 项开始所有项都在带子里，那么从第 N+1 项、第 N+5 项开始当然也在——往后取永远安全。但往前就不行了：从第 N−3 项开始未必满足，因为 N 前面可能正好有落在带外的项。

43:07课上打了个比方：班里同学按身高排成一排，要挑跳高的人。说「1.75 米以上的都来试试」，那么 1.78、1.80 的都可以来；但站在 1.75 前面的 1.65 就不该拉进来。

一句话：往大取可以，往小取不行。所以做题时宁可把 N 取大一点、式子糙一点，也不要冒险取小。

记忆入口 · 一眼回忆

一句话

数列极限 = 误差随便报，某一项之后全都合格。带外只剩有限个，这就是收敛。

∀ε>0,∃N,n>N:|xn−A|<ε

四步走

  1. 猜 A：看趋势看出来的
  2. 草稿纸倒推：|xn−A|<ε 反解出 n> 什么
  3. 取 N= 那个东西取整加一
  4. 卷面正写：任给 ε → 取 N → 当 n>N 时推到成立

定义里的三个字

任给 ε
你先报，多小都行
存在 N
我后找，只需要找到一个
n>N
往后全部算数，前面有限项不管

三条经验

  • N 不唯一，写出来和答案不同不算错
  • N 只能往大取，不能往小取
  • 式子难看就放缩：把分母放大（分式变小）、或换成更简单的上界，把大的压住就够了

四个例题的钥匙

  • 1n→0：N=[1ε]+1，模板题
  • n+(−1)n−1n→1：减完之后绝对值吃掉正负号，回到上一题
  • (−1)n(n+1)2→0：放缩 1(n+1)2<1n2
  • qn−1→0(|q|<1)：两边取对数，记得 ln|q|<0 要变号
