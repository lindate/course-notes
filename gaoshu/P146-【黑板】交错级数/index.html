P146【黑板】交错级数：莱布尼茨的两个前提，一个都不能少

一句话核心

交错级数只有一件武器——莱布尼茨判别法，而它要求两件事同时成立：去掉符号后的 un 单调递减，且 un→0。少任何一条，结论就作废。这一页还要把绝对收敛与条件收敛分清楚：先取绝对值走正项级数的老路，绝对值收敛就叫绝对收敛（必收敛）；绝对值发散、原级数却收敛，才叫条件收敛——(−1)n−11n 就是标准样本。

交错级数：只有一件武器

00:00前面讲的正项级数要求 un≥0；交错级数则是正负号交替出现：1−12+13−14+⋯ 是正负交替，−12+13−14+⋯ 是负正交替，都算。一般写成两类形式：

∑n=1∞(−1)nun或∑n=1∞(−1)n−1un(un>0)
02:08定理 · 莱布尼茨（Leibniz）判别法

若交错级数 ∑(−1)n−1un 同时满足

  • ① 单调递减：un≥un+1（即后一项比前一项小）；
  • ② 趋于零：limn→∞un=0，

则该级数收敛。

02:08先弄清楚 un 到底指哪一部分

老师把这句话讲得特别慢：定理里说「un 递减且趋于 0」，这里的 un 不包含正负号——书上把 (−1)n−1 单独看作一部分，考察的是它后面那坨东西。所以在 (−1)n−11n 里，「那个 un」指的是 1n，不是 −1n。这一点必须先在脑子里立住，否则「是否递减」根本无从谈起。

03:12第二条也很轻松：老师反复强调，递减和趋于 0 这两条是「不需要严格证」的。「n 越来越大，1n 当然越来越小；1n→0 谁都知道」——用眼睛打眼一扫就行，写一句「由莱布尼茨定理可知收敛」即可，不扣步骤分。

04:02黑板上过的两个例子都很干脆：

  • ∑(−1)n−11n：un=1n 递减、趋于 0，两条都满足 ⇒ 收敛。（它没有专门的名字，老师笑称「你可以自己起个名字叫交错调和级数」。）
  • ∑(−1)n+11n2+1：un=1n2+1 递减、趋于 0 ⇒ 收敛。
06:25「交错级数都收敛」是错觉

06:25有同学会有一个错觉：老师举的例子怎么都是收敛的？那就换一个：∑(−1)n−1n。这里的「un」是 n，它既不递减，也不趋于 0——两条前提一条都不满足，莱布尼茨根本用不上。

那它到底是收敛还是发散？07:17老师抛出一个「弱智问题」：「判断它的敛散性需要莱布尼茨吗？」不需要——任何级数判断敛散，第一思路永远是通项是不是趋于零。(−1)n−1n 的通项在正负之间越跳越大，不趋于 0，由收敛的必要条件立刻判发散。这一步连莱布尼茨都不用请出来。

缺了「单调」会怎样：一个必须记住的反例

两条前提是并列的，缺一条都不行。缺「趋于 0」（如 (−1)n−1n）的通项就帮我们判了发散；缺「单调」则更隐蔽——通项确实趋于 0，级数却仍旧发散。定义

un={1n,n为奇数1n2,n为偶数

则 un→0（它是两个趋于 0 的数列拼起来的），但不是单调递减：u2=14<u3=13，中间「抬」了一下。此时

∑n=1∞(−1)n−1un=∑k=0∞12k+1−∑k=1∞1(2k)2

右边第一项是发散的调和级数的一半（11+13+15+⋯ 发散），第二项是收敛的 p 级数。发散减有限 = 发散，所以这个交错级数发散。

这个反例的教训是：看见交错级数不能条件反射地「上莱布尼茨」，必须真的确认 un 一路递减。单调这条前提不是装饰，它决定了奇偶两个子列是否「从两侧往中间挤」——不单调，两个子列就可能在同一个方向上漂。

绝对收敛与条件收敛

08:27交错级数只解决了「正负交替」这一类。真正的任意项级数（各项符号随便来）怎么办？总方针是：先取绝对值，把它变成正项级数，然后套上一节的所有武器。

定义 · 绝对收敛 / 条件收敛
  • 若 ∑|un| 收敛，则称 ∑un 绝对收敛；
  • 若 ∑un 收敛，但 ∑|un| 发散，则称 ∑un 条件收敛。

08:27看两个标准样本，一秒分清：

  • ∑(−1)n1n2：取绝对值就是 ∑1n2，p=2 收敛 ⇒ 原级数绝对收敛。
  • 10:57∑(−1)n1n：本身是交错级数、收敛；可取了绝对值就是调和级数、发散 ⇒ 原级数条件收敛。

定理：绝对收敛必收敛

14:03定理 · 绝对收敛必收敛

若 ∑un 绝对收敛，则 ∑un 一定收敛。

证明（构造式）：令 vn=un+|un|2。因为 un 可正可负，这个式子只有两种结果——un 为负时 vn=0，un 为正时 vn=un。所以 vn≥0，且 vn≤|un|，即 ∑vn 是正项级数、又"比瘦子还瘦"（∑|un| 收敛）⇒ ∑vn 收敛。

再把式子反过来：un=2vn−|un|。右边是「收敛 − 收敛」，由级数的线性性质，∑un 也收敛。

16:03为什么「绝对」两个字里没有「已经知道收敛」这层意思

老师提醒：「绝对收敛」这个名字容易让人误会——它定义的其实是「取绝对值之后收敛」这件事，名字里虽然有「收敛」，但那是结论而不是前提。只是由上面这条定理，一旦绝对收敛，原级数必收敛，所以「绝对收敛」这个身份足够用了。

直觉也很好懂：取了绝对值以后全是正的，正负之间一点也抵消不了，这么「不利」的情况都还能收敛；那不动绝对值、允许正负互相抵消，当然只会更容易收敛。

19:23反方向不成立，而且这是最常错的一步

「∑|un| 发散 ⇒ ∑un 发散」是错的。反例还是 ∑(−1)n1n：取绝对值是调和级数、发散，可原级数收敛（条件收敛）。所以绝对值发散时，绝不能顺手判原级数发散。

19:58不过书上补了一句很有用的例外：如果你是用比值判别法或根值判别法得到 ρ>1，那就不一样了——因为 ρ>1 能推出 |un| 本身不趋于 0，于是 un 也不趋于 0，由必要条件原级数必发散。也就是说：用通项性质（趋于 0 与否）判出来的发散可以「传染」给原级数；用其他理由判出来的发散不可以。

两道例题：一道绝对收敛，一道直接判发散

例 122:01判断 ∑n=1∞sinnαn2 的敛散性类型。

思路：|sin|≤1 直接放缩，一步落到绝对收敛

22:01老师提示：级数里出现 sin、cos 时，可以走等价无穷小的路子，但更常用的是直接把 sin 干掉——因为正弦的绝对值永远不超过 1：

|sinnαn2|≤1n2

右端是 p=2 的 p 级数、收敛；左端是正项、又「比瘦子还瘦」，所以 ∑|sinnαn2| 收敛。即原级数绝对收敛，从而收敛。

顺带一提：这个级数的通项符号由 sinnα 决定，可能一会儿正一会儿负、也可能出现连续几项同号（不是严格的交错级数），莱布尼茨根本套不上——正是「先取绝对值」这条路把它救了下来。

例 224:04判断 ∑n=1∞(−1)nan 的敛散性，其中 an>0。

思路：先取绝对值、用根值，再看通项

24:04这是个交错级数，先把正负号摘掉（取绝对值），剩下的是

an=(12)n(1+1n)n2

通项里有 n 次方、又有 n2 次方，正对上「见到 n 次方就开 n 次根」的规律：

ann=12(1+1n)n→e2≈1.359>1

25:28这里用到了第二重要极限 (1+1n)n→e。ρ=e2>1，说明 ∑an 是发散的，也就是 ∑|un| 不收敛——原级数不是绝对收敛。

但还不能就此收工。这里正好落在前面那条「例外」上：ρ>1 能推出 an 不趋于 0（ann→e2>1 意味着 an 大致以 1.36n 的速度爆炸），于是原级数的通项 (−1)nan 也不趋于 0。由收敛的必要条件，原级数发散。

这一步最容易错

看到是交错级数就抬出莱布尼茨。莱布尼茨要求 un→0，可这里的 an 是往无穷冲的，前提直接不成立。它的正确死法是「通项不趋于 0」，而不是「莱布尼茨判不出收敛」。这也再次说明那条判别顺序：先看通项趋于 0 与否，再看绝对／条件。

记忆入口 · 一眼回忆

一条链

交错 正负交替→ 莱布尼茨 递减 + 趋于 0→ 任意项 先取绝对值→ 绝对／条件 收敛

莱布尼茨的两条前提（缺一不可）

  • ① un≥un+1：后一项不比前一项大；
  • ② un→0。
  • un 是去掉正负号的那部分；两条都用眼睛扫，不必写证明。
  • 缺 ② 的反例：(−1)n−1n（通项不趋于 0，发散）。缺 ① 的反例：奇数项取 1n、偶数项取 1n2（通项趋于 0 却发散）。

绝对 / 条件

  • ∑|un| 收敛 ⇒ 绝对收敛 ⇒ 原级数必收敛。
  • ∑|un| 发散、原级数收敛 ⇒ 条件收敛。样本：∑(−1)n1n。
  • ∑|un| 发散推不出原级数发散；但若 ρ>1（比值/根值），则通项不趋于 0，可以判原级数发散。

三个坑

  • 「交错级数都收敛」——反例 (−1)n−1n。
  • 莱布尼茨只认单调递减 + 趋于 0，递减那条不能省。
  • 先看通项是否趋于 0，再说绝对／条件；顺序颠倒必翻车。
