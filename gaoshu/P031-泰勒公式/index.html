P031泰勒公式：用多项式完整复刻一个函数

一句话核心

等价无穷小是泰勒公式的一次项版本——它只保留 f'(x0)。泰勒做的事情是：把「用一条切线代替曲线」推广到用一条 n 次多项式代替曲线，并且给出误差的确切表达式。它把「近似」从一种手感变成了一种可以估算的运算。

为什么要拿多项式去换别的函数

多项式是最好用的函数：求值只要加减乘，求导求积都不改变形式，计算机算它最省事。而 sinx、ex、ln(1+x) 这些函数，虽然处处光滑，却没法用有限次的加减乘算出来。

所以有一件事一直很诱人：能不能用多项式去顶替它们？在局部范围内，答案是能，而且能顶替到任意好的程度。

在此之前我们已经有了两把粗糙的工具：

等价无穷小
sinx∼x。它说的是「在 x0=0 附近，sinx 可以被 x 顶替」。这其实是用一个一次多项式顶替 sinx。
微分近似
f(x)≈f(x0)+f'(x0)(x−x0)，几何上就是「用切线代替曲线」。这还是一个一次多项式。

两把工具都停在了一次。它们知道函数值和变化率，仅此而已。如果一次多项式不够准，能不能上二次、三次、n 次？这就是泰勒公式要回答的问题。它的思路简单到有点朴素：既然要像，就让它们在 x0 处的各阶导数都一样。

先看清一次情形：切线为什么能代替曲线

设 f 在 x0 处可导，记

T1(x)=f(x0)+f'(x0)(x−x0)

这就是 f 在 x0 处的切线。它在 x0 处与 f 有相同的函数值和相同的导数——两次「对齐」。对齐之后，误差有多大？

limx→x0f(x)−T1(x)x−x0=limx→x0f(x)−f(x0)x−x0−f'(x0)=0

也就是说，误差 f(x)−T1(x) 是比 x−x0 更高阶的无穷小。这正是 无穷小的比较 等价无穷小替换 里那条「等价」判据的另一种说法：f(x)−f(x0)∼f'(x0)(x−x0)。当 f'(x0)=1 时，退化成 f(x)−f(x0)∼x−x0，也就是我们最熟的那批等价无穷小。

只知道「高阶」是不够的

「误差是比 x−x0 高阶的无穷小」这句话，只告诉我们误差趋于 0 更快，没有告诉我们有多快。是 O((x−x0)2)？还是 O((x−x0)5)？

这个差别在实际问题里是决定性的。求极限时，如果两个低阶项刚好抵消，剩下的答案就完全由「高阶到底几阶」决定——这也是加减陷阱的根源。所以我们需要一个能说清阶数的工具，而不是只能说「更高阶」。

把系数定下来：唯一性推导

假设 f 在 x0 附近有 n 阶导数。我们想找一个 n 次多项式

Tn(x)=a0+a1(x−x0)+a2(x−x0)2+⋯+an(x−x0)n

让它尽可能像 f。「尽可能像」需要一个可执行的标准。最自然的标准是：在 x0 处，两者的各阶导数逐一相等。为什么是导数而不是别的？因为逼近的忠实程度是由局部形状刻画的，而局部形状就是由各阶导数刻画的——函数值管位置，一阶导管倾斜，二阶导管弯曲，三阶导管弯曲的变化……对齐得越多，贴得越近。

要求 Tn(k)(x0)=f(k)(x0) → k=0,1,…,n 共 n+1 个方程 → 解出 n+1 个系数
  1. 代入 x=x0。除首项外全部为 0，得
    Tn(x0)=a0⟹a0=f(x0)
  2. 求一次导再代入。只有一次项以上存活，且 a1 的系数是 1：
    Tn'(x0)=a1⟹a1=f'(x0)
  3. 求二次导再代入。此时 a2(x−x0)2 的两阶导数是 2a2，而更高次项仍含 (x−x0) 的因子，取 x0 后归零：
    Tn''(x0)=2a2⟹a2=f''(x0)2
  4. 找规律。ak(x−x0)k 求 k 阶导后是常数 k!ak；更高次项在 x0 处为 0；更低次项已经变成 0。所以
    Tn(k)(x0)=k!ak⟹ak=f(k)(x0)k!

推导到这一步，系数被完全锁死了：没有第二种选择。因为每一个 ak 都是被单独解出来的，彼此不干扰。这就是所谓的唯一性——「n 次多项式里最像 f 的那一个」有且只有一个。

代回去，得到泰勒多项式：

定义 · 泰勒多项式

设 f 在 x0 处有 n 阶导数，则

Tn(x)=∑k=0nf(k)(x0)k!(x−x0)k

各项的含义很清楚：k=0 项是函数值，k=1 项是线性主部，k=2 项是曲率修正，依此类推。系数 f(k)(x0)k! 中，k! 是求 k 阶导时反复掉下来的因子。

k! 是从哪冒出来的

把 (x−x0)k 连续求 k 次导：指数每次掉一个到前面，k 次之后变成 k(k−1)(k−2)⋯1=k!。所以 k!ak 就是 Tn 在 x0 处的 k 阶导数。

反过来看：为了抵消 k!，系数里必须除以 k!。它出现的理由只有这一个，不是硬性的规定。

差多少：余项

Tn 只是「很像」，不是「等于」。差额

Rn(x)=f(x)−Tn(x)

叫余项。泰勒公式的完整形态必须带上它，否则等式根本不成立。而余项之所以能写得那么具体，是因为它其实是中值定理的产物（微分中值定理）。

定理 · 泰勒中值定理（拉格朗日余项）

设 f 在包含 x0 的某个开区间内具有 n+1 阶导数，则对该区间内任意 x，在 x0 与 x 之间至少存在一点 ξ，使得

f(x)=∑k=0nf(k)(x0)k!(x−x0)k+f(n+1)(ξ)(n+1)!(x−x0)n+1

最后一个分式就是 Rn(x)。注意它的形状与公式里的一般项完全一致，只是把 f(n+1) 在 x0 处取值换成了在某点 ξ 处取值——这一点正是中值定理留下的印记。

为什么它会是一个「中值定理」

把结论改写成

f(x)−Tn(x)(x−x0)n+1=f(n+1)(ξ)(n+1)!

形状立刻就熟悉了：这是「某个函数在区间上的平均变化率等于某点导数」的标准长相。事实上，只要对辅助函数反复使用柯西中值定理，就能把 ξ 抓出来。所以它和罗尔、拉格朗日、柯西是同一族——结论都是存在性的，都不告诉你 ξ 在哪。

由此立刻得到一条极有用的结论：如果 f(n+1) 在区间上有界，设 |f(n+1)|≤M，那么

|Rn(x)|≤M(n+1)!|x−x0|n+1

这就是误差估计：误差被一个 |x−x0|n+1 量级的量压住。x 离 x0 越近、n 取得越大，误差越小。

两种余项怎么选

余项形式写法前提与用途
佩亚诺（Peano） Rn(x)=o((x−x0)n) 只要求 f 在 x0 处有 n 阶导数。定性地说明「误差是更高阶的」，专用于求极限。
拉格朗日（Lagrange） Rn(x)=f(n+1)(ξ)(n+1)!(x−x0)n+1 要求区间上有 n+1 阶导数。定量地给出误差大小，专用于误差估计与不等式证明。

写 o 的好处是干净，代价是它只说"高阶"不说"几阶"。所以在求极限时，正确的读法是：o((x−x0)n) 代表所有阶数大于 n 的项的总和，它自己不能在加减法里被直接扔掉——相减时低阶项会抵消，这些被扔掉的项就会被抬上来变成主角。

麦克劳林公式与常用展开

取 x0=0 就是最常用的情形，习惯上叫麦克劳林公式。下面这张表是求极限的主力装备，务必熟到能反射性写出前三项。

怎么记

ex 最规整：分母是阶乘，符号全正。sin 与 cos 的系数也是阶乘，但sin 只留奇次项、cos 只留偶次项，符号交替——它们是同一个级数被拆成两半。ln(1+x) 的分母是普通的 k（不是阶乘），符号交替，这是它比 ex 更容易记错的地方。

还有一个省事的看法：tanx 与 arctanx 的三次项符号相反（+13 与 −13），因为 tan 在 x>0 时长得比 x 快，而 arctan 长得比 x 慢。

阶数越高，贴得越远

把 sinx 和它的几个泰勒多项式叠在一起画，就能看出「对齐导数」到底换来了什么。

这也解释了为什么一次近似（等价无穷小）只能用于局部：它只有能力对齐两个量（函数值、一阶导），信息量太少，一离开原点就露馅。要覆盖更宽的范围，只能靠更多项。

余项有多大：误差也是「几阶」的事

看 T3 的误差。把 |sinx−T3(x)| 单独画出来，再叠上 x55!，两条线几乎重合。

这里有一个非常值得记住的规律：用 Tn 逼近 f，误差的大小由下一个被丢掉的项决定，量级是 |x−x0|n+1。这既是误差估计的依据，也是下一节「主部法」的根据。

泰勒能做的三件事

一、求极限：主部法

这是泰勒在考试里的主战场。要点只有一句：把每一项都展开到「出现的第一个不抵消的阶」为止，然后只留那一阶。低阶项会相消，高阶项是余项，真正决定答案的是那个「第一个活下来的阶」——也就是主部。

理论依据正是佩亚诺余项：o((x−x0)n) 在除以 (x−x0)n 后趋于 0，所以它在最终结果里的贡献为零。换句话说，只要阶数展够了，写 o 的那些项就可以放心忽略。

「展够」的标准是什么

准则是：展开到分子、分母出现同阶的主部为止。操作上更简单的判断法是逐步试探——先展到一次，看是否相消；消了就往上升一阶，直到某一阶不再相消。那个阶就是答案的量级。

展不够会算错（真主部被你当成 o 扔了），展过头不会算错（多出来的都是 o，最后照样归零）。所以宁可多展一项。

二、判阶

想知道一个无穷小是几阶的，展开就能直接读出来：tanx−sinx 的展开式里最低次是 x32，所以它是 3 阶；x−sinx 最低次是 x36，也是 3 阶；1−cosx 最低次是 x22，是 2 阶。这比反复通分、凑公式快得多。

三、近似计算与误差估计

用拉格朗日余项把误差压在一个可控范围内，就可以大胆地用多项式算函数值。例如要算 e0.1，取 T3：

e0.1≈1+0.1+0.122+0.136=1.105166…

而真实值 e0.1=1.1051709…。误差约 5×10−6，可以用余项事先估出来：|R3|≤M4!(0.1)4，其中 M 是 ex 在 [0,0.1] 上的最大值，即 e0.1<1.11，于是 |R3|≤1.1124×10−4≈4.6×10−6——估得很准。

例题

例 1重做那个陷阱题：limx→0tanx−sinxx3
解

在 无穷小的比较 等价无穷小替换 里我们用「提公因子」绕过它，现在可以直接展开。两项都展到三次项（一次项会相消，所以要展过它）：

tanx=x+x33+o(x3),sinx=x−x36+o(x3)

相减，一次项 x 果然抵消，剩下三次项：

tanx−sinx=(13+16)x3+o(x3)=x32+o(x3)

所以

limx→0tanx−sinxx3=limx→0x32+o(x3)x3=12

要点：两条路通向同一个答案。提公因子用的是「把差化成乘」的技巧，泰勒用的是「把信息直接取出来」。泰勒是通法，技巧只是它的特例。但要注意：tanx 的展开式不在必背五式里，考场上更稳的做法仍是用 tanx(1−cosx) 推。

例 2阶数要展够：limx→0ln(1+x)−xx2
解

只展到一次项会得到 ln(1+x)−x=o(x)，代进去变成 o(x)x2，算不出来——这正说明一次不够。展到二次项：

ln(1+x)=x−x22+o(x2)

于是 ln(1+x)−x=−x22+o(x2)，主部是 −x22，与分母 x2 同阶：

limx→0ln(1+x)−xx2=−12

要点：分子是一次项相消的结构，所以必须展到二次。这一步的判断不需要灵感，只要记住「消了就往上升一阶」。

例 3连续相消：limx→01−cosx−x22x4
解

分母是四阶，所以要一直展到四次项：

cosx=1−x22+x424+o(x4)

代入分子，常数项与二次项全被减掉，只剩四次项：

1−cosx−x22=−x424+o(x4)
limx→01−cosx−x22x4=−124

要点：这道题里 cosx 的展开被消掉两次（先是常数项 1，后是二次项），所以必须展到第三项才见主部。分母的阶数就是最直接的提示——分母几阶，分子至少展到几阶。

例 4证明不等式：对一切 x>0，ex>1+x+x22
解

带拉格朗日余项展开到二次项（此时余项是三次的）：

ex=1+x+x22+eξ6x3,ξ∈(0,x)

因为 x>0，所以 x3>0；又 eξ>0（指数恒正）。两个正数相乘为正，于是

ex−(1+x+x22)=eξ6x3>0

得证。

要点：这类题靠的是最后一项的符号。用佩亚诺余项 o(x2) 是证不出来的——符号不明。要证明不等式，必须换成拉格朗日余项，因为它给出了具体的表达式和可以判断的符号。

易错清单

一 · 展不够就下结论

把 ln(1+x) 只展到 x，然后说 ln(1+x)−x=0，是把真正的二阶主部当成余项扔掉了。判据：如果算出来的结果是 0 或 ∞，而分母是一个确定的幂，几乎一定是阶数没展够。

二 · 把余项 o 直接删掉

o(x3) 不是「可以忽略的小量」，而是「所有三阶以上项的总和」。在乘除结构里它确实可以省（最终归结为 o(x3)x3→0）；但在加减结构里，低阶项一相消，它就会升格成主角。删之前先看结构。

三 · 在 x0≠0 处硬套麦克劳林公式

所有常用展开都是 x0=0 的版本。求 x→1 或 x→∞ 的极限时，先作代换把过程搬到 0：x→1 令 t=x−1，x→∞ 令 t=1x。代换之后连「几阶」的定义也一起搬过去了，不能只搬一半。

四 · 忘了 k! 里的阶乘

sinx 的系数是 13!=16，不是 13；ln(1+x) 的系数才是 13（因为它不是阶乘型）。混用这两个模式，结果会差出六倍。
