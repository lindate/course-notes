P142【黑板】第二型曲线积分：方向、代入、三类题

一句话核心

第二型曲线积分（对坐标）比第一型多一件东西——方向，也因此少了一件东西——那个根号。所以它的算法反而更短：参数化 → 代入并求微分 → 定限由「起点对谁、终点对谁」决定。定限可以大在下、小在上，这是它与第一型最大的分野。黑板课上的题目只有三类：只对 dx 积、只对 dy 积、两样都有。

做功这件事，逼出了「方向」

00:01这一讲的名字叫对坐标的曲线积分，也叫第二型曲线积分。它有一个很具体的物理出身：01:25一个质点在变力作用下沿曲线从 A 运动到 B，问这个力一共做了多少功。功是最老实的物理量，也是最容易暴露方向问题的量。

01:25先回忆最简单的情形：力和位移同向，功就等于力的大小乘距离。但一般情况下，力 ⃗F=(M,N) 与位移方向不同，那就要用点乘：

W=⃗F⋅AB⃗=(M,N)⋅(a,b)=Ma+Nb

03:52现实里更麻烦的是，力本身还在变。在曲线上的每一点，力的大小和方向都不同，所以它是一个向量函数 ⃗F=(P(x,y),Q(x,y))。处理办法仍然是老一套：把曲线切成很多小段，在每一小段上取一点 (ξi,ηi)，用这一点的力代表整小段上的力，再和这一小段对应的位移作点乘，求和、取极限。写出来就是

∫LP(x,y)dx+Q(x,y)dy=limλ→0∑i=1n[P(ξi,ηi)Δxi+Q(ξi,ηi)Δyi]

注意这里的 Δxi、Δyi 是位移在两条坐标轴上的分量，是可以带负号的——往左走，Δx 就是负的。第一型里的 Δsi 永远为正，而这里出现了可正可负的量，方向就自然而然地进了积分。

03:52为什么第二型必须讲方向，第一型不能讲

接着用上一页那两个比方，一句话就分清了：

铁链子——不管从这头量还是那头量，它都是同一根链子，质量不变，这是第一型，所以不讲方向。

上山下山——从山底爬到山顶消耗的能量，和从山顶走回山底消耗的能量，完全是两个数。这是第二型，所以必须讲方向。

反映到公式上，就是一条保命的性质：∫L−Pdx+Qdy=−∫LPdx+Qdy。把曲线掉个头，整个积分值加一个负号。这条性质在第一型里根本不存在，因为那里连「掉头」这个概念都没有。

题目只有三类，别自己吓自己

09:00老师把这一块要考的题目一次说透：一共只有三种。

题型长相要做什么
只对 x 积∫LP(x,y)dx只把 x 用参数表示、求出 dx，y 只在被积函数里出现
只对 y 积∫LQ(x,y)dy同理，只求 dy
两样都有∫LPdx+Qdy两项分别代、分别求微分，最后一起定限

11:13第三种写法一开始会让人别扭：以前的积分都是一个积分号配一个微分，这里只有一个积分号却挂着 dx 和 dy 两个微分。其实它是个简写：

∫LPdx+Qdy=∫LPdx+∫LQdy

两个积分号省成了一个，仅此而已。做题时不必关心这个形式，按项处理就行。空间曲线也一样，只是名字换成 Γ、多一项 Rdz：∫ΓPdx+Qdy+Rdz。

方向铁律：参数的上下限由起点和终点决定

18:10设曲线 L 的参数方程是 x=x(t)、y=y(t)。第一型要求 t 必须从小取到大，第二型没有这个规矩：

18:10参数化的定限规则

若曲线 L 指定的方向是「起点 A 到终点 B」，那么 t 的下限取起点的对应值，上限取终点的对应值。谁大谁小完全不管。

19:37同一个圆弧，两种方向，两个答案

看单位圆在第一象限的那段弧。用高中那组参数方程 x=cosθ、y=sinθ：

  • 若题目说方向是「从 (1,0) 逆时针走到 (0,1)」，起点对应 θ=0，终点对应 θ=π2，所以积分区间是 θ:0→π2。
  • 若题目说方向是「从 (0,1) 顺时针走到 (1,0)」，同一个起点终点换了个称呼，θ 就变成 π2→0。

两句话说的是同一段弧，但一个上限大、一个上限小，算出来的值差一个负号——这恰好就是反向变号的性质在起作用。19:37所以第二型的定限不是「取范围」，而是「按走向写」：起点对谁，谁就在下面。

这也解释了为什么第二型的算法里没有绝对值问题：第一型必须把 |dt| 写成 dt，才不得不规定小在下；第二型里 dx=x'(t)dt 本身就是带符号的，符号正是方向，谁也不必去管。

算法：一代、二求微分、三对应定限

21:32公式只有一条，而且比第一型还短——因为没有那个根号：

∫LPdx+Qdy=∫αβ[P(x(t),y(t))x'(t)+Q(x(t),y(t))y'(t)]dt

（这里 α、β 分别是起点与终点对应的参数值，α 可以比 β 大。）三步走：

  1. 一代。把被积函数里的 x、y 都换成 t 的表达式。
  2. 二求微分。dx=x'(t)dt，dy=y'(t)dt。这一步会把两个 dt 一起带出来，最后统一收在积分号末尾。
  3. 三对应定限。下限写起点的参数、上限写终点的参数。
21:32最常走的一条捷径：y=y(x) 就自己当参数

如果曲线给的是 y=y(x)、x 从 x0 变到 X，那就把 x 本身当参数，x'=1，dx 直接就是 dx，一步都不用换。这时公式退化成

∫LPdx+Qdy=∫x0X[P(x,y(x))+Q(x,y(x))y'(x)]dx

绝大多数题目都可以走这条路——只要 y 好写成 x 的函数。反过来 x=x(y) 就换成对 y 积分，判断标准和第一型的「两种变形」完全一样：哪个写法简单就用哪个。

例题

例 123:01计算 ∫Ly2dx，其中 L 是直线 y=2x 上从 (0,0) 到 (1,2) 的一段。

思路：题目只有 dx，那就只跟 x 较劲；y 只是被积函数里的配角

这条直线写成 y=2x，干脆把 x 当参数：x 就是 x，y=2x。23:01方向是从 (0,0) 到 (1,2)，所以 x 从 0 到 1。

一代：y2=(2x)2=4x2。二求微分：这里被积的是 dx，所以这一项不需要管 dy，直接留一个 dx。三定限：0→1。于是

∫Ly2dx=∫014x2dx=43

顺手把同一个曲线上的另一道题做了练手：∫L(x+y)dy。这次被积的是 dy，y=2x 给出 dy=2dx，被积函数 x+y=3x，所以

∫L(x+y)dy=∫013x⋅2dx=3

要点：这两小道只差一个字母，做法却完全不同——题目给 dx 就只求 dx，给 dy 就只求 dy，千万不要「顺手把两个都算上」。21:32这也正是「给什么做什么」这句口头禅的具体含义。

例 232:21计算 ∫Lxydx，其中 L 是抛物线 x=y2 上从 (1,−1) 到 (1,1) 的一段。

思路：曲线是 x 关于 y 的式子，那就把 y 当参数走一遍

这道题给的是 x=y2，把 y 看作参数最省事：x=y2，而 y 就是 y。方向从 (1,−1) 到 (1,1)，所以 y 从 −1 到 1（这里下限比上限小，纯属巧合）。

一代：xy=y2⋅y=y3。二求微分：x=y2，所以 dx=2ydy。于是

∫Lxydx=∫−11y3⋅2ydy=∫−112y4dy=45

最后一步用到了偶函数对称性：2y4 是偶函数，积分区间 [−1,1] 关于原点对称，所以等于 2∫012y4dy=45。

方向反了，上下限就得跟着反

如果题目写的是「从 (1,1) 到 (1,−1)」，那么 y 就是从 1 到 −1，同一个被积函数、同一个参数化，结果会成为 −45。很多同学看到 y2 就条件反射地写成从 0 到 1 或者从 −1 到 1，这是在拿第一型的习惯套第二型。第二型必须回头看题目给的方向。

另外注意：若换成 x 当参数就会很别扭——y=±x 在 x=1 处要分段，还得分别对应两个方向。32:21「哪个变量好表示就用哪个当参数」是选参数化的唯一标准。

例 336:22计算 ∫Ly2dx，其中 L 是半径为 a 的上半圆周，方向从 (a,0) 到 (−a,0)；再问：若 L 是从 (a,0) 到 (−a,0) 的 x 轴上的直线段，结果是多少？

思路：两个小题问的是同一个被积函数在不同路径上的值——这是后面「路径无关」的伏笔

第一小问：上半圆用参数方程 x=acosθ、y=asinθ。起点 (a,0) 对应 θ=0，终点 (−a,0) 对应 θ=π，方向是逆时针，所以 θ 从 0 到 π。此时

y2=a2sin2θ,dx=−asinθdθ
∫Ly2dx=∫0πa2sin2θ(−asinθ)dθ=−a3∫0πsin3θdθ=−43a3

（∫0πsin3θdθ=43 是一条常用结果。）答案是负的，这一点值得停一下想想：沿着上半圆从右往左走，x 一直在减小，dx 大体上是负的，被积函数 y2 又恒非负，所以积分值当然为负——第二型的结果出现负号是正常的，它不是错误信号，而是方向的印记。

第二小问：这次 L 就是 x 轴上的一段，y≡0。把 y=0 代进被积函数，y2=0，被积函数整个变成零：∫Ly2dx=0。

要点：36:22同一个被积函数 y2，一条路径给出 −43a3，另一条给出 0。这说明第二型曲线积分一般与路径有关——换条路走，结果就变了。下一道题会看到反面：三种不同的走法居然给出同一个数。

例 442:06计算 ∫L2xydx+x2dy，其中 L 分别是：① 抛物线 y=x2 上从 (0,0) 到 (1,1)；② 抛物线 x=y2 上从 (0,0) 到 (1,1)；③ 折线 O(0,0)→A(1,0)→B(1,1)。

思路：三条路各算一遍，看结果是不是一样

路径 ①：把 x 当参数，y=x2，dy=2xdx，x 从 0 到 1：

∫L=∫01[2x⋅x2+x2⋅2x]dx=∫014x3dx=1

路径 ②：这次换 y 当参数，x=y2，dx=2ydy，y 从 0 到 1：

∫L=∫01[2y2⋅y⋅2y+y4]dy=∫015y4dy=1

路径 ③：折线要拆成两段。OA 上 y=0，所以 dy=0、x 项也带上 y=0，整段贡献为 0。AB 上 x=1，所以 dx=0，dy 前面的系数是 x2=1，即 ∫011dy=1。两段相加还是 1。

要点：三条完全不同的路径——一条抛物线、另一条抛物线、一条折线——竟然都等于 1。42:06这不是巧合：注意到 2xydx+x2dy=d(x2y)，被积表达式恰好是某个函数的全微分，所以积分只认起点和终点。这条线索下一页会变成一个大定理。

例 553:44计算 ∫Γx3dx+3zy2dy−x2ydz，其中 Γ 是从 A(3,2,1) 到 B(0,0,0) 的直线段。

思路：空间直线先写成点向式，再化成参数方程——这是第八章的老手艺

直线的方向向量取 BA⃗=(3,2,1)（取 AB⃗ 也行，方向向量朝哪边无所谓）。以 B(0,0,0) 为定点写点向式：

x−03=y−02=z−01

把这个公共比值设为 t，就得到参数方程 x=3t、y=2t、z=t。53:44接下来是最容易错的一步：t 从几到几？从 A 走到 B，z 从 1 变到 0，所以 t 从 1 变到 0——谁要是大笔一挥写成 0 到 1，这道题就整道错了。

三段分别处理：x3=27t3，dx=3dt；3zy2=3⋅t⋅4t2=12t3，dy=2dt；x2y=18t3，dz=dt。把 dt 统一收在末尾（56:54老师原话就是「把这个 dt 整个提出去」）：

27t3⋅3+12t3⋅2−18t3=(81+24−18)t3=87t3
∫Γ=∫1087t3dt=−874

要点：三维的公式和二维没有任何区别，只是多了一项。56:54整个第二型曲线积分，说到底只有一条核心技能——把曲线写成参数方程。剩下的都是代入和求微分。

记忆入口 · 一眼回忆

一句话

第二型曲线积分 = 「按坐标方向累加做功」。数学上只有一条公式：参数化、代进去、求微分、按走向定限。

核心公式

∫LPdx+Qdy=∫αβ[Px'(t)+Qy'(t)]dt

一条链

物理 变力沿曲线做功→ 方向 反向变号 ∫L−=−∫L→ 参数化 一代二求微分→ 定限 起点→终点

要背的

  • 三类题：∫Pdx、∫Qdy、∫Pdx+Qdy——给什么做什么。
  • ∫LPdx+Qdy 只是两个积分号省成了一个。
  • 定限由起点、终点决定，可大可小；与第一型的「必须小到大」正相反。
  • y=y(x) 时把 x 自己当参数，dx 不用换；x=x(y) 同理。
  • 空间直线用点向式化参数方程，方向向量取哪边都行，t 的范围跟着走向定。

两个坑

  • 按第一型的习惯把上下限排成小到大。第二型里这会直接把答案的符号搞反。
  • 把结果里的负号当成算错了。沿 x 减小方向走，dx 为负，积分本来就该是负的（例 3）。
