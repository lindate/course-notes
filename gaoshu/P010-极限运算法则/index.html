P010极限运算法则

一句话核心

极限有两个层次的工具：一是无穷小自己的算术（和、积、被有界量乘，仍然是无穷小）；二是极限的四则运算——但第二条有个铁门槛：只有两个极限都存在，才能把极限「分进去」先算。再加上一套专治 x→∞ 多项式商的「抓大头」，做题的骨架就齐了。

先说无穷小自己的算术

00:00这节课一开头，老师就把无穷小单独拎出来讲了一组「自己的运算法则」。它们之所以重要，是因为后面做题时你会反复、无意识地用到——最好让它们变成肌肉记忆。

结论条件一句话理解
有限个无穷小的和仍是无穷小有限个加几个趋于 0 的量，还是趋于 0
有限个无穷小的积仍是无穷小有限个乘几个趋于 0 的量，还是趋于 0
有界函数与无穷小的乘积仍是无穷小一个有界、一个趋于 0「有限振幅」压不住「无限变小」
常数与无穷小的乘积仍是无穷小k 是常数k⋅α→0

00:59四条里最要命的是一个字：「有限个」。老师反复强调，对有限个成立的直觉，搬到无限个身上经常翻车。

反例01:16当 N→∞ 时，1N 是无穷小；取 N 个 1N 相加，结果是多少？

思路：把「每个都趋于 0」和「加起来」分开看

每一项 1N 确实趋于 0（无穷多个无穷小）。但一共有 N 项，于是

1N+1N+⋯+1NN 项=N⋅1N=1

和不是 0，而是恒等于 1！所以「无穷多个无穷小的和」不一定是无穷小。乘法同理，老师课上说那个例子「挺复杂，网上能搜到」，结论先记住：有限个行，无限个不一定行。

为什么第二条「有界×无穷小」这么好用

03:08先看例子：求 limx→0xsin1x。单独看，sin1x 在 x→0 时根本没有极限——它在 −1 和 1 之间疯狂震荡，谁也压不住它。但别忘了它永远在 [−1,1] 之间，是有界的；而 x 趋于 0，是无穷小。一个有界、一个趋于 0，乘积就被「夹」向 0。

图形上更直观：y=xsin1x 被夹在 y=x 和 y=−x 两条线之间，而两条线都逼近 x 轴——中间的曲线想乱晃也晃不出这个越来越窄的「喇叭口」。

极限的四则运算法则

07:47现在进入本课核心。设 limf(x)=A、limg(x)=B（注意：两个极限必须存在），则

定理 · 函数极限的四则运算

在 limf(x) 与 limg(x) 都存在的条件下：

lim[f(x)±g(x)]=limf(x)±limg(x)=A±B
lim[f(x)⋅g(x)]=limf(x)⋅limg(x)=A⋅B
limf(x)g(x)=limf(x)limg(x)=AB(要求 B≠0)

09:17第一条和第三条里那个分母 B≠0 的要求很好理解——B 在分母上，当然不能为零。真正容易被忽略的是老师反复敲黑板的那句话：「右边这种写法，相当于把极限『分进去』先算；前提是左边两个极限都得存在。」

为什么「分进去」必须先验极限存在

10:58把极限分进去做，本质是断言「先算各自的极限、再四则组合」与「先组合、再求极限」等价。这个等价，只有在两个极限都存在时才成立。老师给了一个让人恍然大悟的反例：

limx→0(1x−1x)=limx→00=0

这个答案明明是 0。可如果不管三七二十一先把极限「分进去」：

limx→01x−limx→01x=∞−∞

1x 在 x→0 时趋于无穷大，而无穷大属于「极限不存在」。于是右边变成了「不存在 − 不存在」，什么也不是。结论很清楚：你分开之后发现极限不存在，并不代表原来的极限不存在，而是说明你「根本不该这么拆」。

常数和「无关变量」都能提

14:53法则里还有一条常被低估：常数因子可以提到极限外面，即 limkf(x)=klimf(x)。更妙的是——凡是和求极限的那个变量无关的字母，也能提。比如对 x 求极限时，limx→1(N+1)1x2 里的 N+1 与 x 无关，可以提；再比如对 N 求极限时，limN→∞sinxN2 里的 sinx 与 N 无关，也能提。判断标准一句话：看你是「对谁」求极限，和它没关系的就提出来。

17:29把四则运算套到幂上也很自然：若 limf(x) 存在，则 lim[f(x)]n=[limf(x)]n（前提是那个极限存在，并且整数幂）。这是「乘积法则」连用好几次的推论。

数列极限也有四则运算

19:30函数和数列本质是一家，所以数列极限也有完全平行的四则运算法则：若 limn→∞xn=A、limn→∞yn=B 且两者都存在，则加减、相乘、相除（B≠0 且 yn≠0）同样成立。这部分老师课上说过「做题时用到数列极限四则运算的题太少了，瞅一眼就行」——但原理和上面一模一样，同样要求两个极限先存在。

保号性的一个提醒

21:30法则第九条是保号性的推论：若在某个变化过程中始终 f(x)≥g(x)，那么 limf(x)≥limg(x)。老师特意考了大家一个问题：如果始终 f(x)>g(x)，能不能推出极限严格大于？答案是不能，只能推出 limf≥limg，因为极限可能相等。一句话：「严格大于」在取极限后会塌成「大于等于」。

例题：直接代入与 0/0 型

22:37下面进入做题。一类最简单的题，是「把 x 直接往里代」——前提当然是代入后分母不是 0、且函数在该点连续（多项式、有理函数在其有定义处都连续，这点后面会专门讲）。

例 122:37求 limx→1(2x−1) 与 limx→2x3−1x2−5x+3。

第一个直接代：x→1 时 2x−1→1。第二个也是直接代分子分母：

limx→2x3−1x2−5x+3=8−14−10+3=7−3=−73

23:47分子分母代入后都是「非零常数」，所以结果直接出来。这种题严格写要分拆成「lim 分子 / lim 分母」，但因为它太简单，后面做题一般就直接写了。

例 225:46求 limx→3x−3x2−9。

思路：分子分母都趋于 0，不能直接代，必须因式分解

直接代的话分子 3−3=0、分母 9−9=0，变成 00 型——而这个型我们说过「不知道结果」。所以先变形：

limx→3x−3x2−9=limx→3x−3(x+3)(x−3)

27:07关键一步：x→3 但 x≠3，所以 x−3 趋于 0 却永远不是 0，放在分母上可以约掉。约掉后

limx→31x+3=16
这里的易错点

约掉 x−3 的合法性来自「x≠3」。很多人心里发虚，怕「除以零」。记住：求极限时 x 是无限接近 3 而不等于 3，所以 x−3 是个非零无穷小，约掉完全合法。

例 326:48求 limx→12x−3x2−5x+4。

分子代 x=1 得 2−3=−1；分母代 x=1 得 1−5+4=0。分子是有限非零、分母趋于 0，整体是一个无穷大量。老师课上说：无穷大量属于「极限不存在」的情况。

对照例 2 和例 3：同样是分母趋于 0，例 2 分子也趋于 0、能约掉，于是极限是有限数；例 3 分子不趋于 0，于是极限是无穷（不存在）。分母趋于 0 时，必须同时看分子是不是也趋于 0。

抓大头：x→∞ 时的多项式商

29:29这是本课最实用的一招，专治 x→∞ 时分子分母都是多项式的极限。核心思想一句话：当 x 巨大时，最高次项「碾压」一切低次项，所以只留最高次项比一比就行。老师管它叫「抓大头」。

抓大头公式

设分子分母都是多项式，最高次分别为 m、n，最高次项系数分别为 a0、b0（a0,b0≠0），则

limx→∞a0xm+⋯b0xn+⋯={a0b0,m=n0,m<n∞,m>n

即：同次看系数比；分母次数高则趋于 0；分子次数高则趋于 ∞。把分子分母同除以 x 的最高次，低次项全变成 1x 的幂，趋于 0，只剩最高次项。

例 429:29求 limx→∞3x3+4x2+27x3+5x2−3x 与 limx→∞3x2−2x−12x3−x2+5。

第一题分子分母同除以 x3：

limx→∞3+4x+2x37+5x−3x2=37

第二题同除以 x3（注意分母是三次、分子是二次，即 m<n）：

limx→∞3x−2x2−1x32−1x+5x3=02=0

31:20第三题是第二题的「倒过来」：分子三次、分母二次，即 m>n，极限是 ∞。老师特地提醒：因为第二题趋于 0（无穷小），它的倒数自然趋于 ∞，所以可以「偷个懒」直接判断。

抓大头最容易踩的坑

35:05老师专门举了一个错题：有人看到 limx→1x2+2x+13x2−5，发现分子分母都是 x2 同次，就套公式得出「系数比 13」。这是错的！抓大头公式只适用于 x→∞；当 x→1 时，直接把 1 代进去算就行：

limx→1x2+2x+13x2−5=1+2+13−5=44=−1

36:14一句话：x 趋于常数时，别套抓大头；只有当 x 趋于无穷大时，大头才「大得起来」。

再遇「有界 × 无穷小」与复合函数极限

39:22把前面的性质用起来。先看一个经典：

例 5求 limx→∞sinxx。

这不是第一重要极限（第一重要极限是 x→0）。把它改写成 1x⋅sinx：当 x→∞ 时 1x→0 是无穷小，而 sinx 永远在 [−1,1] 之间、是有界的。于是「有界 × 无穷小 = 无穷小」，极限为 0。

limx→∞sinxx=limx→∞1x⋅sinx=0

40:39最后一块是复合函数的极限。例子：limx→0esinx。直觉上 x→0 时 sinx→0，所以 esinx→e0=1。严格写法应当把求极限「写到上面」：

limx→0esinx=elimx→0sinx=e0=1

42:09老师提醒：直接写「x→0 不就是 sin0 嘛，所以 e0=1」在意思上没错，但不够严谨；规范写法是把外层指数上的求极限显式写出来，体现「内函数的极限存在、外函数连续，所以极限可以推进去」。这部分其实已经用到了后面要讲的复合函数连续性，这里先理解「能直接用」即可。

为什么这一节是「做题骨架」

四则运算 + 抓大头 + 有界×无穷小 + 复合函数极限，这四块覆盖了高数里至少一半极限题的「第一步」。它们共同的前提意识是：先看清能不能直接算、要不要变形、极限是否真的存在。把这些养成习惯，后面遇到 00 才不至于乱套公式。

记忆入口 · 一眼回忆

一句话

无穷小自己会加减乘；极限四则运算的铁门槛是「两个极限都存在」才拆；x→∞ 多项式商抓大头。

铁门槛

lim(f±g)、lim(fg)、lim(f/g) 成立的前提：limf 与 limg 都存在。拆开发现不存在，说明你不该拆。

抓大头三分支

m=n
同次 → 最高次项系数比 a0/b0
m<n
分母高 → 0
m>n
分子高 → ∞

只适用 x→∞；x→ 常数不能套。

两个反例（务必背住）

  • 无限个无穷小之和不一定无穷小：N 个 1N 相加 ≡1。
  • limx→0(1x−1x)=0，但拆成 ∞−∞ 不存在 → 反证「先存在才可拆」。
