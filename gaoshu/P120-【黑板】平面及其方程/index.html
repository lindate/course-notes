P120【黑板】平面及其方程

一句话核心

平面这一节只有一个主角——法向量 ⃗n=(A,B,C)。所有题型都可以压缩成一句话：找一个点、找一个法向量，代进点法式，最后化成一般式。找法向量的三条路要背下来：直接给、用两条边向量叉乘、用「垂直于已知平面」这句话把它读出来。本页交付一张公式速查卡（点法式 / 一般式 / 截距式 / 夹角 / 距离）、六道从实录来的例题，以及三个最容易丢分的细节：点法式不是最终答案、夹角公式分子要加绝对值、距离公式里的 D 是移项之后那个常数。新授课见 曲面方程 平面方程 直线方程。

一、从「曲面」说起：为什么是 F(x,y,z)=0

老师讲平面之前先花了两分钟交代曲面与曲线，看起来像闲笔，其实是在解释为什么方程要写成那样。他先抛出疑问：

课堂原话（大意）

曲面我们在后边讲的时候一般是这样说：z 是 x、y 的一个二元函数，x、y 你随便取，z 的取值就是一个这样弯弯曲曲的面。我们书上是说如果 F(x,y,z)=0——哎，老师，你直接用 z=f(x,y) 我觉得挺清楚的，为什么要整的这么复杂呢？

他给的答案很实在：

曲面与曲线

如果能把 z 写成 x、y 的二元函数，说明这个曲面有显式表达式。但曲面有时候 z 写不出来——它是个隐函数关系，所以只能写成三元方程 F(x,y,z)=0。

曲线则用两个方程联立表示：两个曲面相交，公共部分就是一条曲线。

老师的解释是这个曲面它有的时候 z 呀不能写成显示表达式，也就是说它可能是一个隐函数的关系——z 也是 x 的函数，但是这种显示表达式写不出来，所以我们就写成关于 x、y、z 的一个方程的形式。

这段话对后面有什么用？两点：

  • 平面是曲面的一种，只是它恰好能写成显式（比如 z=−2x−3y+1）。所以本页所有结论都落在「三元一次方程」这个最特殊的情形里。
  • 曲线 = 两个曲面相交这一句，是下一讲 【黑板】直线及其方程 里「直线 = 两个平面联立」的出处。老师当时就把这一步埋下了：用一个曲面和另外的一个曲面相交，他俩联立就是相交或者都满足，那么两个面相交就是一条曲线。

二、点法式：一个点 + 一个法向量

这里是全讲第一个「必须背下来」的式子，但它的推导只有一句话：法向量与平面上的任意向量都垂直。

定义 · 法向量

与平面垂直的非零向量叫这个平面的法向量，通常记作 ⃗n=(A,B,C)。

法向量不唯一——这句话后面天天要用

老师说这一句的时候专门停了一下，因为「法向量」有一件事和直线的方向向量完全不同：它不唯一。他当场拿书比划：

有些同学就有点问题了：老师啊，这个平面的法向量，你说呢，只要和它垂直就行哈？那咱随便说——那这个也和它垂直，这个也和它垂直，那我如果朝下的话，那不也和它垂直吗？那这些不都是它的法向量啊？答案是：对呀，法向量不唯一啊。法向量和平面垂直就叫法向量。

为什么要特意说这个？因为它给了做题两条极大的自由：

  • 方向朝哪都行。算出来是 (14,9,−1) 还是 (−14,−9,1)，描述的是同一张平面。所以后面例 6 里，叉乘结果取相反数完全不影响答案。
  • 模长多大都行。老师用一道题解释得更清楚：假如叉乘算出来是 (5,10,10)，那这个法向量是不是就取做 (5,10,10) 啊？倒没问题。但是你想，如果 5 都提出去的话，是不是就是个 (1,2,2) 啊？因为它这么长的一个向量和它垂直，我把这个向量取短一点是不是也是法向量啊？但是你如果写成 (1,2,2) 的话，你后边的解题过程是不是会简单很多啊。

所以「算出法向量之后，先约公因子」是一条能省下大量计算的实战习惯。不过老师也补了一句边界：这个地方给大家解释一下，这个不能再化简了，所以我们取的这个 ⃗n 就等于它。——约不动就照抄，别硬凑。

推导本身很短。设平面上一个已知点 P0(x0,y0,z0)，法向量是 ⃗n=(A,B,C)，在平面上任取另一点 P(x,y,z)，连成向量：

P0P⃗=(x−x0,y−y0,z−z0)

因为 ⃗n 垂直于平面、P0P⃗ 躺在平面里，所以两者垂直。「垂直」这两个字立刻翻译成数量积为零（【黑板】数量积与向量积 的核心结论）：

A(x−x0)+B(y−y0)+C(z−z0)=0

老师说：这个推导我就懒得看，我们做题的时候点法式是非常容易做的。所以重点在用。

为什么「一个点 + 一个法向量」恰好锁死一张平面

关键在于「垂直于平面」这个条件对平面上每一个点都成立。所以把 P 取成平面上任意一点，写出来的等式都一样。反过来，如果一个点 P 满足上面这个方程，那 P0P⃗⊥⃗n，它就只能落在「过 P0 且垂直于 ⃗n 的那张面」上——而这样的面只有一张。

所以「点」管位置、「法向量」管姿态，两样齐了平面就唯一。这也解释了那些看着很怪的题为什么能做：

  • 「过一点且平行于已知平面」——法向量照抄已知平面的，姿态已经给了。
  • 「过一点且垂直于已知直线」——直线是法线，方向向量就是 ⃗n，姿态也给了。
  • 「过两点且垂直于已知平面」——两个条件凑一个 ⃗n，这就是本页例 6。

一句话：题目里所有关于「平行、垂直、夹角」的要求，本质上都是在告诉你法向量是什么。做题的第一步永远是问自己：这个题想把 ⃗n 怎么给我？

例 1求过点 (2,−3,0) 且以 ⃗n=(1,−2,3) 为法向量的平面方程。

思路：点有了、法向量有了，直接套点法式，然后再整理成一般式

老师讲这个式子时的动作是整得明明白白的：点法式是这么找——你这个法向量不是 (A,B,C) 吗？这个点是减 x0、减 y0、减 z0，是在这个地方。所以你的法向量 (1,−2,3)，那就是 1、−2、3；点就是 x 减 2、y 加 3、再减零，是等于零。

1⋅(x−2)−2⋅(y+3)+3⋅(z−0)=0

展开合并：

x−2y+3z−8=0

验算一下：把点 (2,−3,0) 代进去，2+6+0−8=0 ✓，点在平面上；而 x、y、z 的系数 (1,−2,3) 正是题目给的法向量 ✓。

这一步最容易错：写到点法式就当答完了

老师专门强调：但是有个问题，求平面的方程你光写到点法式这一步是不行的，这个会给你扣分。我们要给它写成 x−2y+3z−8=0，这个啊是一般式。点法式是过程，一般式才是答案。

顺带一个符号细节：y−y0=y−(−3)=y+3。那个负号是本题唯一的坑——写成 y−3 得到的常数项就是 +2 而不是 −8，整题崩。

另外注意「A、B、C 是法向量」这句话是双向的：从一般式读法向量时，直接抄三个系数就行，不用计算。

三、三点定平面：法向量从哪里来

题目换成「过三个点」时，点和法向量里的「点」立刻有了（三个随便挑一个），唯一的缺口是法向量。老师的办法是把 【黑板】数量积与向量积 那把叉乘用上：

找法向量的第二条路

要找一个与平面垂直的向量，只需要找出平面上两条不共线的方向，再取它们的向量积：

⃗n=AB⃗×AC⃗

理由：⃗n 垂直于平面，就必然垂直于平面内的每一条向量；而「同时垂直于两条不平行向量」的那个向量，正是它们的向量积。

例 2求过 M1(2,−1,4)、M2(−1,3,−2)、M3(0,2,3) 三点的平面方程。

思路：点现成，法向量用两条边向量叉乘——三步走完

先纠正一个不自觉的误解：三点不一定能确定一个平面。老师说：三个点啊确定一个平面，这个倒好理解是吧？这三点确定一个平面没问题吧——其实有点问题：三个点不一定能确定一个平面。为什么？如果这三个点在一条线上的话，能确定多少个平面啊？无数个。所以这三个点其实是不共线才能确定一个平面。题目既然这么出，就默认三点不共线。

还有一个书写提醒，顺手记下：大家一定要注意，因为这个点的坐标和向量的坐标是一样的，所以这个点 M1、M2 在后边千万不要写等号哈，你要写等号就成了这个向量了，那点就是点。

第一步，造两条边向量。取 M1 当公共起点（一律「终点减起点」）：

M1M2⃗=(−3,4,−6),M1M3⃗=(−2,3,−1)

第二步，叉乘求法向量。老师说这一步就是要求和这两个向量垂直的向量，我们是不是想起来了向量积呀：

⃗n=M1M2⃗×M1M3⃗=(14,9,−1)

逐项核对：第一项 |4−63−1|=−4+18=14；第二项 |−3−6−2−1|=3−12=−9，取负得 9；第三项 |−34−23|=−9+8=−1。

第三步，选一点写点法式。老师讲了个很实用的小习惯：三个点可以随便取，但是你稍微看一下这三个点——如果我来选的话，我会选择用这个点，因为我觉得 (0,2,3) 比较简单啊。第一它是不是有一个零？这俩是不是都有个负号啊？难免会做错。于是用 M3：

14(x−0)+9(y−2)−(z−3)=0
14x+9y−z−15=0

把三个点都代回去验一验（这一步不能省，它是唯一能当场挡住加减号错误的手段）：M1：28−9−4−15=0 ✓；M2：−14+27+2−15=0 ✓；M3：18−3−15=0 ✓。

三个易错处

一、叉乘时中间项忘了取负。写成 (14,−9,−1) 就全错了（【黑板】数量积与向量积 反复强调过这一处）。

二、选了带负号的点。选点本身不影响答案，但 (0,2,3) 这种「有一个零」的点在减法时出错率最低——这是老师在课上明确给出的经验。

三、验算被省略。三个点代回去只要有一个不等于零，就是前面算错了。老师在这道题上还吐槽过课本的答案与他的不同：书上用的和我不是一个数啊，不是一个点哈——这不影响对错，因为法向量与点都可以换。

「四个未知数三个方程」为什么照样能写出平面

老师把另一条路也讲了：设一般式 Ax+By+Cz+D=0，三个点各代一次，得到三个方程。

{2A−B+4C+D=0−A+3B−2C+D=02B+3C+D=0

念完他就替学生把疑虑说出来了：这里一定会有人犯嘀咕——这是几个未知数啊？ABCD 四个未知数，几个方程？三个方程，你解不出来。当然按照高中我们觉得不能解出来，因为大家学了线代，只是你还没有学到方程组那章。他这个是个齐次线性方程组，它是有无穷多个解的。

那无穷多解怎么办？老师的办法很朴素：你把 A 等于多少 D、B 等于多少 D、C 等于多少 D 给它解出来，然后把它带进去以后是不是都有这个 D 呀？你把 D 再给它约了。他最后也承认这条路麻烦：这个过程啊是比较麻烦的。

为什么「解不唯一」是应该的？因为同一条方程乘上任何非零常数还是同一张平面。14x+9y−z−15=0 与 −28x−18y+2z+30=0 描述的是同一张面。所以 A、B、C、D 本来就该有「整体倍数」这一自由度——解不唯一是正常的，无解才是出错了。

四、一般式：缺哪一项，贴着哪根轴

把点法式展开合并，就得到一般式：

Ax+By+Cz+D=0(A,B,C不全为零)

为什么要求「不全为零」？因为 A=B=C=0 时方程退化成 D=0，什么都没剩下，也就描不出任何图形了。

书写上两条约定俗成的规则（课本没写，但考试认）

第一条：能约就约。比方说最后你这个平面写成这个样子 5x+5y+5z−10=0——这不也是个一般式吗？但是 5、5、10 这个咱得稍微给他处理一下，给他变成 x+y+z−2=0。

第二条：把 x 的系数变成正的。如果你变成了 −x−y−z=0，就这个 x 这个系数啊，我们一般给它变成一个正的；这方面如果是个负的，你就两边同时乘以负号、乘以 −1 不就行了吗？

不过要注意：「x 的系数必须化成 1」是错的。老师说得很随意：这个无所谓，方是三就是三，你不用变成一。要正的，不要「一」。这两条要求的真正作用是「让阅卷人一眼对得上标准答案」——因为同一张平面的方程不唯一，考卷必须约定一个最简形式。

一般式最有信息量的地方是缺项：哪一项缺了，图形的形状立刻跟着变。判断依据只有一句：法向量垂直于谁，平面就平行于谁。

系数情况方程变成法向量图形是什么
D=0 Ax+By+Cz=0 (A,B,C) 过原点的平面（把 (0,0,0) 代进去当然成立）
A=0 By+Cz+D=0 (0,B,C) 法向量垂直于 x 轴，所以平面平行于 x 轴（或含 x 轴）
A=B=0 Cz+D=0，即 z=−DC (0,0,C) 平面平行于 xOy 面（一张水平面）
A=D=0 By+Cz=0 (0,B,C) 既过原点又平行 x 轴，即通过 x 轴

老师是用最直观的例子讲这一段的。先看 y+z=1：大家对立体的图总是很头疼，就是没有这个 x 了。这样咱举一个具体的例子吧，咱说 y+z=1——先不考虑三维的图，先考虑二维的平面的图：那我问你 y+z=1 是表示一个什么东西？直线嘛，x+y=1 你总该知道是什么东西吧，直线。

然后是他最漂亮的一句翻译：它这里没有 x，那就证明 x 怎么着啊？随便取啊——你不能说 x 等于零，没有 x 那就 x 随便取。x 随便取，是不是都是 y+z=1 呀？所以是把这条直线平行于 x 轴平行移动，得到了一个平面。

再看 z=1：这个啊我给你举个例子就更好理解了，我说 z 加一等于零是个什么东西？其实就是 z 等于 1。x、y 呢？随便取；z 都等于 1，所以就是 z 啊沿着 1 的这个点平着切一刀呗。

一句话记住这一整节

方程里缺哪个变量，图形就沿着哪根轴无限延伸。缺 x 就平行于 x 轴，缺 x 和 y 就平行于整个 xOy 面，一个都不缺就是一个「斜」的平面。这条经验在下一节讲柱面时就是全部内容。

反过来也要小心：老师说这一块也没什么特殊的，你如果死记书这么个东西吧，你也记不住，所以每次碰到这样的东西呢，我都得先推、现画现推。不要背表格，要会当场推。

例 3求经过 x 轴和点 A(4,−3,−1) 的平面方程。

思路：法向量要同时垂直于两条已知方向——x 轴方向与 OA⃗

老师先声明不用课本那条路：书上那个方法我不准备讲了，因为书上那个方法如果给我做题的时候我也想不起来，我们就按照正常的去做。

第一步，找两条方向。平面过 x 轴，就一定过原点，所以取 O(0,0,0) 当点。两条躺在这个平面里的方向是：

  • x 轴的方向向量。老师说这里有一个特别温暖的词——就是基本单位向量 ⃗i=(1,0,0)，他自己在第 117 讲里把 ⃗i 形容成「一个很温暖的词」。
  • 从原点指向已知点的向量 OA⃗=(4,−3,−1)。

第二步，叉乘。两条方向都垂直于法向量，所以法向量是它们的向量积：

⃗n=⃗i×OA⃗=(0⋅(−1)−0⋅(−3),0⋅4−1⋅(−1),1⋅(−3)−0⋅4)=(0,1,−3)

逐项核对：第一项是 0⋅(−1)−0⋅(−3)=0；第二项 |104−1| 取负得 1（老师现场口算时说的就是要去掉这一行、去掉这一列，其实是个一要变负号，就是一个一）；第三项 |104−3|=−3。

第三步，选点。老师特意反问了一句：法向量有了，点我再问你一遍，你决定一定要用这个点吗？你会不会觉得 (0,0,0) 比较简单？当然是啊，x 轴上不是有零点吗，(0,0,0) 多简单。于是

0⋅(x−0)+1⋅(y−0)−3⋅(z−0)=0
y−3z=0

这个答案既过原点（D=0），又平行于 x 轴（x 的系数为 0）——正好对上表格里「A=D=0」那一行，等于顺手自检了一遍。

这种题的条件怎么读成向量

题目里凡是出现「过某根坐标轴」「平行于某根坐标轴」「垂直于某个坐标面」，都要立刻翻译成方向向量：x 轴用 ⃗i=(1,0,0)，y 轴用 ⃗j=(0,1,0)，z 轴用 ⃗k=(0,0,1)。含 x 轴的平面只有两个自由度，所以「过 x 轴 + 过一个点」正好够用——这也是为什么这类题总是恰好可解。

五、截距式：三个截距都给了才用它

第三种写法描述的是「平面与三根坐标轴的交点都已知」这种情形：若平面在 x 轴、y 轴、z 轴上的截距分别是 a、b、c，则

xa+yb+zc=1
截距式的三个条件，缺一不可

一、a、b、c 三个数都不能为零。老师说得很直接：在书上公式的旁边你可以记一下：A 不等于零、B 也不等于零、C 也不等于零，要求 ABC 都不等于零。为什么不能为零？因为三个数都在分母上。而「截距为零」的意思就是平面过原点——过原点的平面用不了截距式，但它当然有方程（比如例 3 的 y−3z=0）。

二、右边等于 1，不是 0。老师说：并且在右边啊是等于一，右边不是等于零，这就叫截距式方程。这是它和一般式唯一的形式差别，也是最容易记错的地方。

三、截距可以是负数。老师自问自答：我想问一下啊，这个 ABC 可不可以取负的？可以，可以，不能取零；可以取正的，可以取负的，没问题。

另外提醒一句：截距式也不是最终答案。老师说：但是我们在做题的最终的结果一般是还是要写成一般式方程。

例 4已知平面在 x 轴、y 轴、z 轴上的截距分别是 1、2、3，求它的方程。

思路：三个截距直接摆成分母，再化成一般式
x1+y2+z3=1

老师接着就把它化成一般式：但是我们在做题的最终的结果一般还是要写成一般式方程。写到这一步其实是不行的，我们要继续写——两边同时都乘以 6 呗。

6x+3y+2z−6=0

验算：x 轴上取 (1,0,0) 代入得 6−6=0 ✓；y 轴上 (0,2,0) 得 6−6=0 ✓；z 轴上 (0,0,3) 得 6−6=0 ✓。三个截距都对上了。

什么时候该想到截距式

题目里只要出现「与三根坐标轴的交点分别是什么」这种描述，就该立刻反映到截距式——它是三种写法里唯一「以交点信息为输入」的。反过来说，截距式能处理的问题面最窄：点法式不挑条件，一般式最通用，截距式的约束最多。

六、两平面的夹角与位置关系

两个平面之间的夹角，直观上可以像课本那样「在交线上取一点，各作一条垂线」，但那样做太麻烦。真正的定义是用两个法向量的夹角，因为法向量是现成的。

定义 · 两平面的夹角

两个平面的夹角，用它们法向量的夹角来定义，并且规定 θ∈[0,π2]。于是

cosθ=|⃗n1⋅⃗n2||⃗n1||⃗n2|

老师先画图指出了那个「微妙之处」，他是用四边形内角和来说明的：因为这个角啊和这个角是互补、加起来是 180，因为这俩角呢都是直角——这个四边形四个角加起来是一个 360 度，这俩相加是 180，那么这个角和这个角相加是不是也是 180 呀？那么它和它互补，就是这个角度就等于这个角度了。这样的话我们就把两个平面的夹角转换成两个向量的夹角。

为什么分子必须加绝对值

老师先说明了「两个平面的夹角」这个量本身的脾气：咱想一想，如果这两个平面长这个样子，它两个的夹角呢是一个锐角；如果这个平面是这个样子的，他两个的夹角是不是就是一个钝角了？博士平面是无限延伸的——这里是个钝角，这里是不是个锐角啊？所以两个平面的夹角是大于等于零、小于等于 90 度。

也就是说：平面是无限延伸的，「那个钝角」不过是同一个锐角在另一个方向上的补角，所以约定只取锐角。

可是法向量就麻烦了——平面本身没有方向，法向量却有方向。同一张平面，法向量可以朝上取、也可以朝下取；换一下方向，⃗n1⋅⃗n2 立刻变号。可两个平面的夹角是客观的，不该因为我们「挑了个朝下的法向量」就变成钝角。

加绝对值，就是把这种人为选择的影响抹掉：|⃗n1⋅⃗n2| 与两个法向量各自怎么取方向无关。顺带还解决了一件事——cosθ≥0，所以 θ 自动落在 [0,π2]，正好符合「夹角取锐角」的约定。

老师说这个公式课本上写得不够显眼：这个地方大家应该在课本上补一下，特别是分子上的那个绝对值。

位置关系的判定也全部落在法向量上，而且判断顺序本身就是解题步骤：

位置关系向量条件怎么一眼看出
垂直 ⃗n1⋅⃗n2=0 算一次数量积，等于零就垂直
平行（不重合） ⃗n1∥⃗n2，即系数成比例，但常数项不成同一比例 x、y、z 的系数成比例
重合 ⃗n1∥⃗n2，且四个系数全部成同一比例 整条方程是另一条的倍数

老师把「垂直」和「平行」两条都用一句话说透了：两个平面如果是垂直，那么它的法向量和它的法向量就是垂直——法向量垂直咱不是用的点乘吗，所以就是它两个做点乘等于零；如果两个平面是平行，它的法向量和它的法向量那不也是平行吗，那就直接用法向量平行呗，就对应的分量成比例。

例 538:07求两平面 x−y+2z−6=0 与 2x+y+z−5=0 的夹角。

思路：先从一般式读出两个法向量，再套夹角公式

老师说这一步那就甭客气了，就直接上法向量呗。系数直接读：⃗n1=(1,−1,2)，⃗n2=(2,1,1)。

⃗n1⋅⃗n2=1⋅2+(−1)⋅1+2⋅1=2−1+2=3
|⃗n1|=1+1+4=6,|⃗n2|=4+1+1=6
cosθ=36⋅6=36=12⟹θ=π3

老师对书写格式很宽容：如果书上那个公式你不愿意写，你就写个 cosθ 就行。但绝对值一个都不能漏——不过本题算出来是正的，所以漏了也对；真正危险的是两个法向量各自反向的情形，那时漏绝对值就会得到 2π3 这种超范围的答案。

例 6求过点 M1(1,1,1)、M2(0,1,−1) 且垂直于平面 x+y+z=0 的平面方程。

思路：三个条件一起凑一个法向量——「过两点」给一条方向，「垂直于已知平面」把已知法向量拉进来当第二条方向

老师先说了一句让空间想象困难的同学放心的话：这一章的题目大家在做题的时候其实是不需要画图的，这一章我们书上几乎没有图，大家做题其实是不需要画图的。只是有的时候画图呢，大家这个思路比较容易确定。

第一步，把条件翻译成方向。

  • 「过两点」给出了所求平面上的一条方向：M1M2⃗=(−1,0,−2)。
  • 「垂直于 x+y+z=0」这句话的含义是：已知平面的法向量 ⃗n0=(1,1,1) 平行于所求平面，所以 ⃗n0 也是所求平面上的一条方向。

两条方向都垂直于所求的法向量，所以叉乘：

⃗n=M1M2⃗×⃗n0=|⃗i⃗j⃗k−10−2111|=(2,−1,−1)

逐项核对：第一项 |0−211|=0+2=2；第二项 |−1−211|=−1+2=1，取负得 −1；第三项 |−1011|=−1。

第二步，选点写点法式。老师说那我一点我喜欢用这个 (1,1,1) 呀，(1,1,1) 比较好一些：

2(x−1)−(y−1)−(z−1)=0
2x−y−z=0

验算：M1(1,1,1) 代入得 2−1−1=0 ✓；M2(0,1,−1) 代入得 0−1+1=0 ✓；与 x+y+z=0 垂直：(2,−1,−1)⋅(1,1,1)=2−1−1=0 ✓。三个条件全都满足，这才叫做完。

这一步最容易错

把「垂直于已知平面」读成了「与已知平面平行」。两者的意思是刚好相反的：所求平面垂直于已知平面 ⟺ 所求平面的法向量垂直于已知的法向量。而「已知平面的法向量平行于所求平面」这句话之所以成立，正是因为两个平面垂直——一个平面的法向量垂直于另一个平面，就必然躺在它的平行方向上。这一步的翻译最容易绕晕，画个草图或者用两支笔比划一下最保险。

老师说这道题他走的是「正常思路」：这个答案跟书上的答案肯定是一样的，但是我们正常的思路是按照我这个思路来。

七、点到平面的距离

这是平面部分最后一个公式，也是最好用的一个。点 P0(x0,y0,z0) 到平面 Ax+By+Cz+D=0 的距离是

d=|Ax0+By0+Cz0+D|A2+B2+C2

老师对它的态度是「别推，直接背」：这个公式你必须记住，这个公式你如果要现场推，那就麻烦了。

代入左边为什么会不等于零

老师说这个疑问每年都有：那有个问题啊，他带到左边去不就是零了吗？是不是等于零啊？那算出来不都是零了吗？是不是啊？

答案很简单：Ax+By+Cz+D=0 是「平面上的点」才满足的条件；拿一个平面外的点代进去，左边算出来的就是一个非零的数——那个数的大小恰恰反映了这个点「离平面有多远」。

接下来是他自己接住的那个反问：那他如果带进去等于零的话，那他不就是平面上的点了吗？如果他真要是平面上的点，带进去它等于零，这个分子等于零，说明它的距离等于零。那我问一下哈，平面上的一个点到这个平面的距离是不是等于零啊？是啊，它在平面上当然等于零啊。所以这个公式我发现一个问题，就是这个点不管在平面外头还是在平面里头，这个公式都成立吧？——对的，统一成立。

分母 A2+B2+C2 是把法向量的长度除掉，起的是「归一化」的作用：换了法向量的长短，分子分母一起变，比值不变。这正好呼应了本页开头那条性质——法向量不唯一，但距离必须是唯一的。

分子的绝对值同样不能少：点在平面「另一侧」时算出来是负数，而距离只能是正的。

出题人爱设的那个障碍

老师说得很直白：这个公式在用的时候，第一点——这个平面右边必须等于零。如果他给的平面比方说他等于一，那好办，挪过去不就行了嘛。右边必须等于零。

公式里的 D 是「移到左边之后」的那个常数项。曲面方程 平面方程 直线方程 里老师演示过这个坑：题目给的是 x+y+z=10，如果偷懒直接把右边的 10 当成 D=10 代进去，算出来的结果会差整整四倍。所以每次用这个公式之前，先花两秒钟把方程整理成「右边是 0」的标准形状。

顺手验证一下「公式对平面上的点也成立」：例 6 的平面 2x−y−z=0 上，点 M1(1,1,1) 代入左边得 2−1−1=0，按公式 d=04+1+1=0 ✓；而点 M1 确实就在这张平面上，距离为 0，完全对上。

八、易错清单

一 · 停在点法式就交卷

老师两次强调过：求平面的方程你光写到点法式这一步是不行的，这个会给你扣分。答案一律化成一般式 Ax+By+Cz+D=0，并且按惯例约掉公因子、把 x 的系数变成正的（但不必化成 1）。

二 · 两平面夹角公式漏掉绝对值

cosθ=|⃗n1⋅⃗n2||⃗n1||⃗n2|，两平面的夹角只能取锐角（0≤θ≤π2）。漏掉绝对值在「两个法向量恰好好反向」时会得到超出范围的角。对照记：只有「两个向量的夹角」不加绝对值（可以取钝角），两个平面的夹角要加。

三 · 距离公式里的 D 用错了

必须先化成「右边等于 0」再代。题目给 x+y+z=10 时，D=−10 而不是 10。

四 · 把叉乘的中间项忘了取负

例 2 与例 6 都要叉乘，而「中间项取负」是 【黑板】数量积与向量积 反复强调的失分点。叉乘算完顺手验一下：⃗n 与两条方向向量的数量积都应该等于零。

五 · 三点定平面没检查共线

严格的说法是「不共线的三点确定唯一平面」。题目既然这么出就默认不共线，但如果叉乘算出来是零向量，就说明你取的两条边向量共线了（或者三点共线），要换一组边。

六 · 截距式的三个截距里出现了零

有一个截距是零（即平面过原点）就用不了截距式，改用点法式或一般式。「不能用某种写法」不等于「平面不存在」——换一种形式就是了。

记忆入口 · 一眼回忆

一句话

平面的唯一主角是法向量：找点、找 ⃗n、套点法式、化成一般式。题目里所有「平行 / 垂直 / 夹角」的要求，都是在告诉你 ⃗n 是什么。

一条链

法向量 ⃗n=(A,B,C)→ 点法式 A(x−x0)+B(y−y0)+C(z−z0)=0→ 一般式 Ax+By+Cz+D=0→ 夹角与位置关系（都看 ⃗n）

法向量从哪里来（三条路）

  1. 直接给：题目说「以 ⃗n=(1,−2,3) 为法向量」。
  2. 叉乘：过三点的题，取两条边向量做叉乘（例 2）；过某根坐标轴的题，拿该轴的 ⃗i／⃗j／⃗k 去叉乘（例 3）。
  3. 从「平行 / 垂直」这句话读出来：平行于已知平面 ⟹ 法向量照抄；垂直于已知平面 ⟹ 它的法向量是我的一条方向（例 6）。

公式速查

要什么写法条件
点法式A(x−x0)+B(y−y0)+C(z−z0)=0点 + 法向量，不挑条件
一般式Ax+By+Cz+D=0A,B,C 不全为零；最终答案用这个
截距式xa+yb+zc=1abc≠0，右边等于 1

点到平面距离d=|Ax0+By0+Cz0+D|A2+B2+C2右边必须先等于零

要背的两句位置关系

  • 两平面垂直 ⟺ ⃗n1⋅⃗n2=0。
  • 两平面平行（不重合）⟺ 系数成比例、常数项不成同一比例；四个系数全部成比例就是重合。

四个坑

  1. 点法式不是最终答案，要化成一般式（并约公因子、把 x 的系数变正）。
  2. 两平面夹角公式分子要加绝对值。
  3. 距离公式里的 D 是「移项之后」的常数。
  4. 叉乘的中间项要取负；算完用「与两条方向向量的点乘为零」验一下。
