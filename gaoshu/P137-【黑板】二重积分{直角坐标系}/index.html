P137【黑板】二重积分·直角坐标：选型、换序与题型手册

一句话核心

直角坐标是二重积分真正用来计算的方法，老师说得很重：「前面讲的定义跟性质你一个字都没听懂都不要紧，但这个地方你必须听懂，要不然你二重积分就真的一个字都不会了。」整件事只有两条动作线：把区域画出来、写成不等式（定限），以及落成两次定积分再算。据此分出四种题型：基本款、要分段、必须换序、次序选得好省一半力气。三个判据决定你选 X 型还是 Y 型——尽量只写一个积分、边界垂直于哪个轴、被积函数积不积得出来；而「先积后头那个」与「代入时替换的是刚积完的那个变量」是绝不能错的两条纪律。

从「切土豆」到累次积分：笔该怎么放

01:48老师先带大家回到定积分的求体积老办法——当时「画了一个类似于土豆的东西」：平行切面切出一片横截面，面积记 A(x)，那么

V=∫abA(x)dx

02:48现在的处境是：横截面的形状也说不清。他把这一片「推到黑板上」看——因为 x 已经被切面固定住，x 就是常数，曲面 z=f(x,y) 退化成只含 y 的一元函数；这一片是曲边梯形，上边界 y=φ2(x)、下边界 y=φ1(x)，于是

V=∫ab[∫φ1(x)φ2(x)f(x,y)dy]dx

05:53这就是累次积分的来历。07:03但老师说这套立体推导「你不要记」——真正要记的是操作层面的两句话：

  • X 型：09:01把笔垂直于 x 轴，从区域最左端走到最右端。x 的范围是常数区间 a≤x≤b；09:01「在走的过程中，上面的函数放上边、下边的函数放下边」，被积函数照抄，最后跟一个 dy。
  • Y 型：22:44把笔垂直于 y 轴，从最下端走到最上端。y 的范围是常数区间 c≤y≤d，25:00「右边的函数放上边、左边的函数放下边」。
25:00写 Y 型时最容易漏的一步

直接把题目给的 y=f(x) 抄进去。题目给的曲线几乎总是写成 y 关于 x 的样子（比如 y=x），可 Y 型要的是x 关于 y 的函数。25:00老师反复叮：「按 Y 型去做题，左右的这两个函数 x 必须改成 y 的函数」——y=x 要改成 x=y，y=x−1 要改成 x=y+1，y=x2 要改成 x=±y。

自检办法：Y 型的内层上下限里必须出现 y。如果里面还是 x 的式子，一定写错了。

三个规定动作，一步都不能错

动作怎么做错了会怎样
① 先算哪一层09:01先算右边那一层（内层），再把它作为被积函数积外层整道题作废
② 代入时替换谁27:01第一次是对 y 积的，上下限就替换 y；第二次再替换 x表达式变成「x 里含着 x」之类的怪东西
③ 外层上下限外层只能是常数到常数；函数到函数只能出现在内层区域定限写反
11:43「这个 b−a 的用法，在这里不成立」

一看见 ∫abdx 就顺手算成 b−a，然后拿它去乘内层结果。11:43老师说这是必须避免的错：11:43「有些同学先做前头——老师啊，∫abdx 我会啊，这个就是 b−a 呀，这玩意定积分谁不会啊。这是不对的。」

原因在于：内层积完还是一个含 x 的式子，它必须待在 ∫ab⋯dx 的被积函数位置上，而「∫abdx=b−a」这条性质成立的前提是被积函数与 x 无关。11:43「因为这个形式其实是 ∫ab[一个含 x 的东西]dx」，绝不能拆成两半。

09:01唯一的例外在下面「两个可以偷懒的情形」里——只有当内层的被积函数和上下限都与外层变量无关时，才能先算外层。

选型：三个判据，按优先级用

1:16:13老师把经验总结成三条，按优先级排：

  1. 边界垂直于哪个轴，就按哪种型。1:16:40两条竖边是典型的 X 型，两条横边是典型的 Y 型；没有明显特征的（比如 y=x2 与 y=x 围成的那种）1:17:07「两者均可，那就优先选择 X 型」——1:17:40「没有哪个同学先傻乎乎地先是 Y 型再是 X 型」。
  2. 尽量只写一个积分。同一道题 X 型一个积分、Y 型两个积分时，选前者——1:17:53「尽量选择一个积分，因为俩积分你得积两次，相对来说比较麻烦」。
  3. 被积函数积不积得出来。1:18:05「有可能按某种积分次序做不出来，那你就得换另一种。」这一条优先级最高，因为另外两条只是「省事」，这一条是「能不能做」。

题型一：基本款（两种型各走一遍）

例 112:43计算 ∬D(x2+y2)dxdy，其中 D 由 y=0、y=1−x、x=0 围成。

思路：读区域 → 落成累次积分 → 从右往左算

12:43「拿出一支笔来，按 X 型是把你的笔垂直于 x 轴，从左边嘚嘚嘚走到右边。」x 从 0 到 1；走的过程中，12:43「下面的函数比较简单，是个什么函数呀？y=0；上面的函数是这条直线，就是 y=1−x」。于是

∬D(x2+y2)dxdy=∫01dx∫01−x(x2+y2)dy

14:06「先做后边那一部分」——对 y 求积分时 x 是常数，所以 x2 关于 y 的原函数是 x2y，y2 的原函数是 13y3：

∫01−x(x2+y2)dy=x2(1−x)+(1−x)33

再对 x 从 0 积到 1，两项分别算：∫01(x2−x3)dx=13−14=112，13∫01(1−x)3dx=13⋅14=112，相加得

∬D(x2+y2)dxdy=16
16:23这一步最容易错

先把外层 ∫01dx 算成 1。这里的 ∫01dx∫01−x(x2+y2)dy 是累次积分，不是「1 乘内层」——因为内层积出来带着 x（本题里带着 x2(1−x) 和 (1−x)3），它必须留在 ∫01⋯dx 的被积函数位置上。

例 217:54计算 ∬Dxydxdy，其中 D 由 y=x、y=1、x=2 围成。

先按 X 型算一遍

17:54x 从 1 走到 2；17:54「上面的函数就是 y=x，下面的函数是不是 y=1」。于是

∬Dxydxdy=∫12dx∫1xxydy=∫12x[y22]1xdx=∫12x3−x2dx
=12[x44−x22]12=12[(4−2)−(14−12)]=12(2+14)=98
再按 Y 型重做一遍：这是一次免费的验算

30:48「我再用 Y 型再做一遍。」y 从 1 走到 2；30:48左右两条边界分别是竖直线 x=2 和直线 y=x——后者要改写成 x=y：

∬Dxydxdy=∫12dy∫y2xydx=12∫12y(4−y2)dy=12[2y2−y44]12=98

两次答案一致。32:43老师说这正是做积分的一个好处：32:43「换一种积分次序啊，你得到了同一个答案」——它相当于对自己的计算做了一次独立复核。考试时若时间允许，换序重算一遍是最划算的检查手段。

题型二：要分段（第一次遇到写两个积分）

例 333:54计算 ∬Dx2dxdy，其中 D 由 x+y=2 与 y=x 围成。

思路：先按习惯试 X 型——一个积分就够；再看 Y 型贵在哪里

两条直线交于 (1,1)，D 是顶点为 (0,0)、(1,1)、(0,2) 的三角形。按 X 型，x 从 0 到 1，35:00下边界 y=x、上边界 y=2−x：

∬Dx2dxdy=∫01dx∫x2−xx2dy

35:00这里有个漂亮的观察——被积函数 x2 里没有 y，对 y 积分时它是常数，可以直接提出来；剩下的 ∫x2−xdy 积出来就是「上限减下限」：

∫01x2(2−2x)dx=2(13−14)=16

35:51老师顺手对比了 Y 型的代价：「Y 呢从 0 到 1……走到这儿你得停一下子了，为什么呢？它左边的函数一直都没有变化，但是右边原来是这个函数、现在右边是不是这个函数啊？右边的函数变化了，那你是不是就得写俩积分了。」——0≤y≤1 时 x 从 0 到 y，1≤y≤2 时 x 从 0 到 2−y，两段相加。

35:51这就是选型的价值

同一道题、同一个答案 16，X 型写一个积分、Y 型写两个。35:51「这是我们第一次碰到写成累次积分以后得写俩积分——这种题目算是比较正常的题目。」所以拿到题先别动笔，先在图上比划一遍：沿哪个方向扫，边界不换人？

题型三：必须换序（不换就积不出来）

例 41:04:50计算 ∬De−y2dxdy，其中 D 由 y=x、y=1、x=0 围成。

先按 X 型写出来，立刻卡住

区域是三角形：0≤x≤1，x≤y≤1，于是按 X 型是 ∫01dx∫x1e−y2dy。1:05:00问题出在内层：1:05:00「你是做不出来的，这个 e 的负 y 方对 y 是积不出来的，你到这一步就卡住了，这个题就拉倒了。」这不是技巧不够，而是这条路本身走不通。

换成 Y 型：内外一调，立刻通了

按 Y 型：0≤y≤1，左边界 x=0、右边界由 y=x 改写为 x=y：

∬De−y2dxdy=∫01dy∫0ye−y2dx

关键在这里：内层是对 x 积分，而 e−y2 里根本没有 x，所以它整个是常数，可以提出来；剩下 ∫0ydx=y：

=∫01e−y2⋅ydy=12∫01e−y2d(y2)=[−12e−y2]01=12(1−e−1)
为什么同一个函数，换个次序就能积了

因为积分的难度不只取决于被积函数，还取决于对谁积。e−y2 对 y 积是死路，但作为「关于 x 的常函数」时它只是一个常数因子，提出来就完事；剩下那个 ∫0ydx=y 把它救活了——最后要算的变成 ∫e−y2ydy，而 y 恰好是 y2 的导数（差一个常数），凑微分立刻成功。

「必须换序」的本质不是换算法，而是换一个「谁当常数、谁当变量」的身份。

例 51:11:02计算 ∫01dx∫x21x3sin(y3)dy。

思路：题里已经替你选好次序了，恰恰说明这个次序不行

1:11:02老师说得很幽默也很准：「考试的时候累次积分只要现成的给你，一般都没憋什么好屁——他肯定求不出来。他如果能求出来，不会这么好直接给你。」确实，sin(y3) 对 y 积分是死路。

1:11:54所以第一步是由上下限把区域读出来：0≤x≤1，x2≤y≤1，这是抛物线 y=x2 与直线 y=1 夹出的区域。换成 Y 型：0≤y≤1，左边界 x=0、右边界 x2=y 即 x=y（取正根，因为 x≥0）：

∫01dx∫x21x3sin(y3)dy=∫01dy∫0yx3sin(y3)dx

内层对 x 积分时 sin(y3) 是常数：∫0yx3dx=[14x4]0y=14y2。于是

=14∫01y2sin(y3)dy=112∫01sin(y3)d(y3)=[−112cos(y3)]01=1−cos112

要点：这两道「必须换序」的题，套路完全一样——内层的原函数求不出来时，就画图、换个方向扫，让那个讨厌的函数退化成常数因子提出来。

题型四：次序选得好，省掉一个大坑

例 642:38计算 ∬Dy1+x2−y2dxdy，其中 D 由 y=x、y=1、x=−1 围成。

先试 Y 型：内层对 x 积要带着根号里的 x2，很麻烦

按 Y 型是 −1≤y≤1、x 从 −1 到 y，内层 ∫y1+x2−y2dx 里根号带着 x2，得用第二换元，非常难走。

改用 X 型：y 恰好可以凑进微分

按 X 型：−1≤x≤1，下边界 y=x、上边界 y=1：

∬Dy1+x2−y2dxdy=∫−11dx∫x1y1+x2−y2dy

内层对 y 积分时 x 是常数，于是 1+x2 也是常数。把根号里的整体记作 u=1+x2−y2，则 du=−2ydy，所以 ydy=−12du：

∫y1+x2−y2dy=−12⋅23(1+x2−y2)3/2=−13(1+x2−y2)3/2

代入 y=1 与 y=x（替换的是 y）：y=1 时括号里是 x2，y=x 时括号里是 1，于是内层等于 −13[(x2)3/2−1]。

47:05「这里有一个严重的错误」——(x²)^{3/2} 不等于 x³

把 (x2)3/2 直接写成 x3。看着好像只是「2 和 32 的分母约掉」，其实完全错了——47:05「为什么呢？因为他先平方了，这里必须加绝对值，很容易漏」。

  • (x2)3/2 里先是 x2，它非负，再开 32 次方仍然非负；
  • 而 x3 在 x<0 时是负的。

正确的是 x2=|x|，进而 (x2)3/2=|x|3。所以内层是 13(1−|x|3)。

收尾：用偶函数性质砍一半计算量

于是原积分变成 13∫−11(1−|x|3)dx。积分区间关于原点对称，被积函数 1−|x|3 是偶函数，所以「偶函数积两倍」：

13×2∫01(1−x3)dx=23(1−14)=12

要点：选型不只看区域形状，42:38更要看被积函数更愿意对谁积。这题按 Y 型也能算出 12，但要多绕一次第二换元；按 X 型则 ydy 正好凑微分。

50:38顺带一个「Y 型更省」的对照

课本另一题：∬Dxydσ，D 由 y2=x 与 y=x−2 围成。交点联立解出 (4,2) 与 (1,−1)。50:38按 X 型要沿 x=1 分成两段（0≤x≤1 时下界 y=−x，1≤x≤4 时下界换成直线 y=x−2）；按 Y 型则 −1≤y≤2 一路畅通，左边界 x=y2、右边界 x=y+2，一个积分搞定，算得 458。53:24「所以呢，大家在选择的时候优先选择一个积分。」

两个可以「偷懒」的情形

情形一：长方形区域 + 可分离的被积函数。57:37设 D:a≤x≤b、c≤y≤d 是长方形，且 f(x,y)=f1(x)f2(y)，则

∬Df1(x)f2(y)dxdy=(∫abf1(x)dx)(∫cdf2(y)dy)

道理不难：按 X 型先对 y 积分时，f1(x) 与 y 无关，可以提出来；∫cdf2(y)dy 上下限都是常数、不含 x，所以它是一个数，再提到外层，就成了两个定积分相乘。1:00:06老师说这里必须盯住「有没有乘号」：∫abdx∫cdf1f2dy 是累次积分（必须先算右边），而 (∫abf1dx)(∫cdf2dy) 是两个定积分相乘，意思完全不同。1:00:36他还给那个乘号起了个名字——「画上宋老师的神奇小点点」。

情形二：内层与外层变量无关时，可以先算外层。1:01:07这是前一条纪律的唯一例外。判断标准是两条同时满足：内层的被积函数与外层变量无关，并且内层的上下限也与外层变量无关。1:02:05老师当场示范：∫12dx∫13y2dy 里，内层 ∫13y2dy=263 是一个与 x 无关的常数，而 ∫12dx=1，所以可以先算外层再乘起来。

为什么这个例外很容易被误用

因为「先算外层」在绝大多数情形下是错的，所以只能靠两条严格的条件把它圈起来。1:03:16老师说他特意留到现在才讲：「那老师你怎么之前不讲啊？我傻呀，我之前讲我们同学就全乱套了——因为正常的就是先求后头的再求前头的。我们同学都是先求前头，∫cddy 求出来了一般的都是错的。」

唯一的合法时机：内层的上下限与被积函数都与外层变量无关。按这个标准回头看例 1 和例 3，内层积出来都带着 x，所以那里绝不能先算外层。

综合题：两个圆柱面相交

例 71:22:51求两个圆柱面 x2+y2=R2 与 x2+z2=R2 相交所围立体的体积。

思路：先靠对称性把体积缩到第一卦限，再定出投影区域与「上表面」

1:22:51这个立体是个「交叉管」，不太好想象——老师说「你去那个厕所找两个看看，他那个两个水管」，一根竖着一根横着。它由 8 块完全相同的部分拼成，只算第一卦限那一块再乘 8。

1:26:19第一卦限里的投影区域 D 是四分之一圆：x≥0、y≥0、x2+y2≤R2。上表面取自圆柱面 x2+z2=R2，即 z=R2−x2——注意这里 z 只与 x 有关，不含 y，这正是本题的机关。按 X 型写：0≤x≤R，0≤y≤R2−x2，

V=8∬DR2−x2dxdy=8∫0Rdx∫0R2−x2R2−x2dy

被积函数不含 y，对 y 积分时它是常数，提出来；剩下 ∫0R2−x2dy 积出来「上限减下限」，正好也是 R2−x2。两个根号相乘把根号消掉：

=8∫0R(R2−x2)dx=8[R2x−13x3]0R=8⋅23R3=163R3
这道题真正值得记的是一个套路

它的投影区域是圆，按道理后面用极坐标会更舒服（老师也承认「和圆有关的我们一般用极坐标」），这里只是还没讲极坐标，所以硬做了一遍。要带走的是那句话：被积函数与内层变量无关时，内层积分退化成「一段长度」，可以直接提出去。下一讲换到极坐标，同一道题会短很多。

带绝对值的题：先分区域，再写累次积分

1:29:17课本还有一类题：∬D|y−x2|dxdy，D:0≤x≤1、0≤y≤1。区域是正方形，但被积函数带绝对值，1:29:17「有个问题，就是这个 y−x2 什么时候大于零、什么时候小于零」。判据是把它写成 y 与 x2 比大小，于是曲线 y=x2 把正方形分成两块：

  • D1（y≥x2，即曲线上方）：此时 y−x2≥0，所以 |y−x2|=y−x2。按 X 型是 0≤x≤1、x2≤y≤1。
  • D2（y≤x2，即曲线下方）：此时 y−x2≤0，所以 |y−x2|=x2−y。按 X 型是 0≤x≤1、0≤y≤x2。

用区域可加性把原积分拆成两块之和即可。1:30:12老师另外提了一个判断内层该对谁积的小窍门：被积函数里出现 x2 又套在根号里时，对 x 积会很难（根号内还在变），而对 y 积时 x2 是常数，显然更省事。于是两块都按 X 型写：

∬D1y−x2dxdy=∫01dx∫x21y−x2dy,∬D2x2−ydxdy=∫01dx∫0x2x2−ydy

这类题的两个动作：先按「绝对值里的式子变号的曲线」把区域切开，再对每一块单独写累次积分。两道内层都是「整体换元」型：把 y−x2（或 x2−y）看成整体，原函数是 23(⋅)3/2。

记忆入口 · 一眼回忆

两种型

X 型：∬Dfdσ=∫abdx∫φ1(x)φ2(x)fdy
Y 型：∬Dfdσ=∫cddy∫ψ1(y)ψ2(y)fdx

口诀

  • X 型：笔竖着放，从左划到右 —— 上边界做上限，下边界做下限
  • Y 型：笔横着放，从下划到上 —— 右边界做上限，左边界做下限
  • 写 Y 型之前，务必把 y=f(x) 改写成 x=g(y)

三个规定动作

  1. 先算右边那一层，另一个变量当常数
  2. 上下限代进去时，替换的是刚才积分那个变量
  3. 外层上下限必须是常数到常数；绝不先算 ∫abdx=b−a

选型三判据

  • ① 边界垂直于哪个轴 → 就按那种型（没有特征时先试 X 型）
  • ② 尽量只写一个积分（边界会不会中途换人）
  • ③ 被积函数积不出来 → 赶紧换序

两个坑

  • (x2)3/2=|x|3，不是 x3
  • ∫abdx∫cdf1f2dy（累次积分）与 (∫abf1dx)(∫cdf2dy)（两个积分相乘）差一个乘号
