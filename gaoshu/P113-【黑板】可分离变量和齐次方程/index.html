P113【黑板】可分离变量和齐次方程

一句话核心

本页只处理两类一阶方程，是微分方程专题复习的第一站。可分离变量的套路是「分离 → 两边积分 → 写通解」，它没有任何公式，只有三个必须养成的动作；齐次方程的套路是三板斧，砍完自动变成可分离变量。两个最真实的失分点是：分离时除以过谁，就要回头问一句「它等于零算不算解」，以及换元之后必须把 u 换回 yx。完整新授见 可分离变量的微分方程、齐次方程。

一、知识速查：一阶方程先认形，再动手

这一章的方法特别多：可分离变量、齐次方程、一阶线性、伯努利、可降阶的高阶方程……每一种长相不同、解法也不同。所以老师反复强调的第一个动作不是「怎么解」，而是「认清楚它属于哪一类」。认对了，后面全是机械劳动；认错了，算到一半就会发现怎么挪都挪不动。

本页只管两类——它们是一阶方程里最早学会、也是考得最勤的两种。先看下面这张表，把「看到什么 → 认成什么 → 走哪一套」一次性记住。

看到的形式认成哪一类走哪一套
x 与 y 只在相乘、相除的位置上碰面（x+3、y2+6 这种「括号里只有一种变量」的不算掺和） 可分离变量 移项：x 与 dx 归一边、y 与 dy 归一边 → 两边同时求不定积分
右边能整理成整体 yx 的函数（看不出来就先上下同除 x 的最高次幂） 齐次方程 三板斧换元，把它化成可分离变量，再走上一行

老师说判断顺序就一条：遇到任何一个一阶方程，先试可分离变量——它是最简单的一种模式。分得开就赢了，分不开再往齐次上想。17:54拿几个「随手写出来的」方程练一练这个判断：

y'=exsiny
右边是「只含 x 的块」乘以「只含 y 的块」，在乘法位置上，能分离。移项得 dysiny=exdx。
xy'=…（右边是 x 乘 y 的组合）
相乘的关系，能分离。
(x+y)dx=sinydy
x 与 y 在加法里黏住了，怎么除都分不开，不能分离。
dydx=x2−y2xy
分不开，但上下同除 x2 就露出 yx，是一道齐次方程。
为什么「有加法」不等于「不可分离」

很多同学一看到 x(y+1)dx+(x+1)ydy=0 就摇头，理由是「有加法」。判断错了。真正的判据不是有没有加法，而是x 与 y 有没有待在同一个加减式里。

看那个方程的两项：第一项 x(y+1) 的括号里只有 y，第二项 (x+1)y 的括号里只有 x。两个变量其实早就被乘法分开了，只是外面包了一层括号。而 x+y 不一样，它是一个真正的加法式，x 和 y 在这个式子里成为一体的东西，你除谁都拆不开。

老师把这把尺子总结成一句原话：x 跟 y 啊，它在加减法里头不掺和；在相乘跟相除，x、y 可以掺和。记这句就够了。

二、可分离变量：分离 → 积分 → 通解

先看最原始的那个例子，它把整件事说得清清楚楚。方程是 dydx=2x。把 dx 拿过去，就得到 dy=2xdx；两边同时求不定积分：

∫dy=∫2xdx⟹y=x2+C

到这里方法就没了。老师对这个套路有一个很朴素的描述：把含有 y 的部分放一边，含有 x 的部分放一边，然后两边同时求不定积分……思想非常的简单。

为什么 dydx 允许被「拆开」

这是全章最容易含糊的一处。老师把它讲得很清楚：记号 dydx 本身是「一体」的，它表示「y 对 x 求导」，不是「dy 除以 dx」。所以从「导数的定义」这个角度看，它不能拆。

但微分的公式给了另一条路：dy=y'dx。这条公式里，dy 与 dx 是可以分家的两个微分。解微分方程时把 dx 乘过去，用到的正是这一条，而不是把导数当成商。

老师还举了第三个场景做对比：讲参数方程求导时，dydx=dy/dtdx/dt，那里也是把 dydx 看成能分开的。三个地方，同一件事：什么时候能拆、什么时候不能拆，取决于你引用的是哪一条公式。做微分方程的分离，引用的是微分公式。

例 1求 dydx=2xy 的通解。

思路：把 y 的因子整块挪到左边，x 的因子留在右边

两边同乘 dx、再除以 y：

1ydy=2xdx

两边同时求不定积分。左边界是 ln|y|，右边 2x 的原函数是 x2：

ln|y|=x2+C

07:31这里有一个必须强调的细节：绝对值不能随手写掉。1y 的原函数是 ln|y| 而不是 lny，因为 y 完全可以取负值，题目里没给任何理由保证它为正。老师说：这个绝对值在我们微分方程这个地方非常重要，什么时候能去什么时候不能去，仔细地听我讲去是有理由的。

第二步：两边取 e，把对数消掉

两边取 e 的幂。eln|y|=|y|，右边用指数律拆开：

|y|=ex2+C=eC⋅ex2

去掉绝对值要补一个正负号，于是 y=±eCex2。±eC 里 C 任意、符号任意，合起来仍然是一个任意常数——老师在这里统一把它记成一个 C：

y=Cex2

注意编号上的小动作：写到这里时，前面那个 C 已经被吞掉了，所以有些教材会把最初的那个常数写成 C1，最后一步再把它改回 C。老师说这是倒过来把刚才那个 C 改成了 C1，考场上不必纠结，先把常数叫 C，最后统一收拾。

核一下：这是一阶方程，通解里正好一个任意常数，对上了。验算也很快：y=Cex2 有 y'=2xCex2=2xy ✓。

分离之后必须补的一步：你除以过谁

刚才第二步除以了 y。除法天然带一条隐含前提：分母不能等于零。也就是说，整段推导默认了 y≠0，而方程 dydx=2xy 在 y≡0（恒等于零的常函数）时到底成不成立，刚才那道题里根本没验证过。

验证很简单：y≡0 时 y'=0，右边 2xy=2x⋅0=0，两边都是 0，成立。所以 y≡0 也是方程的一个解。

那它丢了没有？看通解 y=Cex2：把 C 取成 0，得到的正是 y=0。所以这道题里没丢——常数 C 把它救回来了。老师当时的讲法就是这样的：y 等于零的话，那我们假设这个 C 取零不就完了吗？

但这只是运气好。下一节的反例说明：同样是除以含 y 的因子，换个方程，常数就救不回来了。所以「回头查漏」这一步不能省，也不能靠感觉，要真去算。

反例：C 救不回来的那一半

把例 1 的方程动一个字母：dydx=xy2。分离时除以的是 y2：

1y2dy=xdx⟹−1y=x22+C

解得 y=−1x2/2+C。现在是关键的一问：y≡0 还是不是解？把它代回去：y'=0，右边 xy2=x⋅0=0，还是成立，它仍然是解。

但它能不能被某个 C 表示？不能——无论 C 取什么实数，−1x2/2+C 都不恒等于 0（分母永远是有限数）。也就是说，y≡0 这条解真的丢在除法里了，必须在答案后面补一句。

这就是「除以 g(y) 会漏掉 g(y)=0 的常数解」的真实代价。对照一下两个方程：例 1 除以 y，漏掉的 y≡0 恰好是 C=0；本题除以 y2，漏掉的 y≡0 落在一个「C 够不到」的位置上。差别不在难度，而在你有没有回头看一眼。

例 2解 dMdt=−λM，并求满足 t=0 时 M=M0 的特解。

思路：变量换成了 M 和 t，动作完全不变

这道题的物理背景（衰变）老师说他也不讲，因为我也不太懂——我们只看它是个微分方程。这里自变量是 t、未知函数是 M，与 x、y 没有任何区别。分离：

1MdM=−λdt

λ 是常数，不用管它。两边积分，−λ 的原函数是 −λt：

ln|M|=−λt+C

13:55这里书上写的是 ln|M|=−λt+lnC，多了个对数。老师专门解释了这件事的来历：老师，这书上怎么加的 lnC 呢？我就想不明白了，那求完不定积分都加 C，什么时候说让加个 lnC 呢？答案是——这是倒着写出来的。如果按正常人类的思路加 C，两边取 e 会有：

M=e−λt+C=eC⋅e−λt

那个 eC 是个常数，而我们本来就想把它记成一个常数 C1。既然 C1=eC，反过来就是 C=lnC1。所以教材提前把常数写成 lnC，这样下一步取 e 时对数直接消掉，一步到位。

另外，M 是质量一类的实际量、恒为正，所以这个绝对值有理由去掉（要去得说得出理由）。于是

M=Ce−λt
第三步：代初始条件

t=0 时 M=M0，而 e0=1，所以 M0=C⋅1，即 C=M0：

M=M0e−λt

这就是那条著名的指数衰减公式。它的全部来路就是「分离 + 两边积分 + 代初值」三步，没有任何额外技巧——这也是可分离变量在应用里出场率极高的原因。

这道题的两个易错点

一、绝对值没有理由就去掉。本题可以去掉，理由是 M 代表实际量、恒正。如果换成一道 y 可能取负值的题，去掉绝对值就是错的。

二、常数写成 lnC 却忘了它表示不出 0。lnC 覆盖所有正数而不覆盖零，这一步本质上放弃了一个常数解。本题里 C=0 意味着 M≡0（没有任何物质），它显然也是一个解，要不要写上去看题目要求。

解不出来就写隐式，别硬凑

老师在这一段特意提了两个「书上没写、但大家一定会遇到」的问题。第一个是解的形式：我们习惯显函数 y=f(x)，但微分方程常常给不出显式。比如解到 ex+y=y+12x+C，想把 y 单独解出来非常麻烦，有的根本解不出。

他的态度很干脆：隐函数也可以，你不用都写成显函数。保留 F(x,y)=C 这种把 x、y 混在一起的形式就是完整答案。本页例 3 的答案 y=Cey/x 就是这样——y 在指数上也在等号左边，永远解不出来，但这已经是最好的写法。

三、齐次方程：认形 + 三板斧 + 回代

第二类方程的特征只有一条：yx 作为一个整体出现。标准形式是

dydx=φ(yx)

老师原话是：关键点就是说在他这个表达式的部分，y 比 x 啊它是整体出现的。比如 dydx=1+yx，右边只有一个「y 比 x」的整块；再比如 dydx=x2−y2xy，看上去不像，但只要分子分母同时除以 x2：

dydx=1−(yx)2yx

整块立刻现形。21:41那怎么提前猜出它是齐次方程？老师给的提示是看次数：因为 yx 整体出现，就是说有 y 出现就有 x 出现，所以 x 是几次方 y 就是几次方，所以它的次数其实是有规律的。分子分母的每一项次数相同，这就是最实用的线索。

三板斧（每个题都必须写出来）
  1. 第一斧：设 u=yx。
  2. 第二斧：写出 y=xu。
  3. 第三斧：换掉导数。因为 y=xu 是「x 乘 u」，而 u 也是 x 的函数，所以按乘积求导：
    dydx=u+xdudx

代进去就得到 xdudx=φ(u)−u，也就是 duφ(u)−u=dxx——一个标准的可分离变量方程。

老师说得很实在：记住这三板斧就这三步，每一个题目都得写这三步，并且这三步你要写到解题的步骤上去。至于课本上后面的内容，后边我们书上所有的话一个字都不要看，没用，每个题都不一样——因为带进去之后是什么样子完全由题目决定，公式背不下来也不需要背。

例 3求 (xy−x2)dydx=y2 的通解。

思路：先试可分离，分不开再上齐次

这道题老师先替我们排除了可分离变量：y2 挪不到 x 那边去，xy−x2 也提不出只有一种变量的因子，分不开。于是转向齐次。

第一步：整理成 dydx=⋯，再上下同除 x2
dydx=y2xy−x2=(yx)2yx−1

分子除以 x2 得 (yx)2；分母 xy−x2 除以 x2 得 yx−1。现在右边只剩 yx 这一块了，是「很清晰的齐次方程」。

第二步：三板斧，一个都不能少

设 u=yx，则 y=xu，dydx=u+xdudx。代入：

u+xdudx=u2u−1

把 u 挪到右边通分：

xdudx=u2u−1−u=u2−u2+uu−1=uu−1
第三步：分离并积分

把 u−1u 挪到左边、dx 挪到右边，再把左边的分式拆成两项：

(1−1u)du=1xdx

两边积分：1 的原函数是 u，1u 的原函数是 ln|u|，1x 的原函数是 ln|x|：

u−ln|u|=ln|x|+C1

把 −ln|u| 挪到右边，两个对数合成一个乘积：

u=ln|u|+ln|x|+C1=ln|ux|+C1
31:01第四步：回代 u=yx

注意 ux=yx⋅x=y，所以 ln|ux|=ln|y|，得到

yx=ln|y|+C1

两边取 e、去绝对值补正负号、把 ±e−C1 收成一个常数：

y=Ceyx

这是一个隐式解——y 既在左边又在指数上，解不出来，也不需要解出来。

31:55这一步是本节的第一号失分点

算完 u 就交卷。如果停在 yx=ln|y|+C1 之前、或者停在 u=ln|ux|+C1 这一行，答案里就留着 u。而 u 是我们自己引进的辅助字母，题目里从来没有它。老师原话：你求出来以后一定要记住一个事，就是 u 等于 y 比 x，你一定要回代。

第二号：把 u 当成常数。第三斧里 dydx=u+xdudx 的后半截不能丢。理由是 u=yx 而 y 是 x 的函数，所以 u 也是 x 的函数。丢掉这半截会得到 dydx=u，方程当场死掉。

两个「同名不同义」的提醒

第一，本页的「齐次方程」和后面要学的「一阶线性齐次方程」不是一回事。本页的「齐次」指的是右边只依赖 yx 这个比值；一阶线性里的「齐次」指的是方程右端的自由项为零（形如 y'+P(x)y=0）。两个词长得像，含义毫无关系，看题目给的形式来分辨。

第二，看到 x2−y2 这种「有减号」的式子不要急着否掉齐次。有没有减法不影响判断，能不能让右边只剩 yx 才算数。

四、易错清单

一 · 分离后忘了回头查漏解

动作：凡是分离时用除法除掉了含变量的因子，就把它令成零，单独代回原方程检验一遍。检验通过还不算完，还要再问一句「它能不能被某个 C 值表示」。能表示（如例 1 的 y≡0 对应 C=0）就不必单写；不能表示（如 dydx=xy2 的 y≡0）必须在答案后补一句。

二 · 正负号和绝对值的处理全线混乱

∫1ydy=ln|y|+C 这个绝对值不能凭习惯去掉。要去掉必须给出理由（比如某量恒正）。去绝对值必然带出一个 ±，而这个 ± 与该处的常数可以合并成一个任意常数——把它当成「又一个 C 要被吞掉」处理，不要让 ± 一路飘到最后。

三 · 换元之后不回代 / 把 u 当常数

齐次方程只有三板斧，没有第四斧，但回代是隐含在「写出答案」里的第一步。交卷前扫一眼答案里有没有 u，就能拦住这一类错误。

四 · 把变量留在分母上

写成 y=Cx 这类形状会把「x=0 也是解」这件事在写法上抹掉（可分离变量的微分方程 里讲过这件事）。能整理成整式就整理成整式；整理不出来再保留分式。

记忆入口 · 一眼回忆

一句话

两类一阶方程，出口只有一个：把 x 和 dx 归一边、y 和 dy 归另一边，两边积分。可分离变量直接走；齐次方程先用三板斧化过来。

认形口诀

  • 变量只在乘除里碰面 → 可分离变量（先试这一条）。
  • 变量在同一个加减式里黏住（如 x+y）→ 不是可分离变量。
  • 右边只剩 yx 一整块 → 齐次方程；看不出来就上下同除 x 的最高次幂。

两条链

可分离 分离变量→ 两边积分 常数加一边→ 化简常数 收成一个 C→ 查漏 除以过谁？
齐次 逼出 y/x→ 三板斧 u=yx、y=xu、换导数→ 可分离 分离积分→ 回代 u=yx

要背的

  • dydx=2xy 的通解 y=Cex2；其中 C=0 给出被除掉的解 y≡0。
  • dMdt=−λM 配 M(0)=M0，特解 M=M0e−λt。
  • (xy−x2)dydx=y2 的通解 y=Ceyx——隐式解，解不出 y 也算完成。
  • dydx=u+xdudx（第三斧，乘积求导）。

三个坑

  1. 漏常数解。除以 g(y) 就可能丢掉 g(y)=0 的解；丢掉之后先看 C 能不能救回来，救不回就补写。
  2. 忘了回代。答案里留着 u，等于没做完。
  3. 把 u 当常数。第三斧的后半截丢了，方程立刻失真。
