P114【黑板】可降阶的高阶微分方程

一句话核心

高阶方程一般很难，但有一批「残缺」的高阶方程可以从容降阶。判断依据只有一条——方程里缺了谁：右边只有 x，就两边直接积分；缺 y，就令 u=y(n−1)；缺 x，就令 p=y' 并把 p 看成 y 的函数。后两类最爱混，判别提示是看方程里到底缺 x 还是缺 y；三类的出口都是一阶方程，工具全是前面那两套。完整推导见 可降阶的高阶微分方程。

一、知识速查：「方程缺什么，就设什么」

可降阶的高阶方程，是微分方程里最「有章法」的一块。二阶、三阶、四阶方程一般都不好惹，但有一批方程只是长得残缺：它们缺了某一样东西，于是可以用一个换元把阶数降下去，降到一阶就回到前面学过的老路。

判据不需要灵感，只需要一眼：看方程里缺了谁。三种情形各缺一样东西，配三种不同的处理手法。先把总表摆出来，这就是本页的全部骨架。

类型方程里缺什么（怎么认）设什么降成什么
一 y(n)=f(x)：右边只有 x，y、y'、…、y(n−1) 一个都没露面 不用换元 两边直接积分，一直积到 y 为止，共积 n 次
二 只有 y(n)、y(n−1) 与 x，缺 y 以及它的低阶导数 u=y(n−1)，则 u'=y(n) 关于 u 的一阶方程
三 y''=f(y,y')：右边有 y 与 y'，缺 x（自变量不露面） p=y'，并把 p 看成 y 的函数 关于 p 与 y 的一阶方程，x 彻底消失

老师把这套判断压成了一句口诀，本页就靠它立住：

口诀

方程缺什么，就设什么。

  • 右边只剩 x → 什么都不缺，两边积分。
  • 缺 y → 令 u=y(n−1)（把「低一阶的那个导数」整体打包）。
  • 缺 x → 令 p=y'，并且把 p 看成 y 的函数，而不是 x 的函数。

注意口诀说的是「设什么」而不是「怎么解」。解完之后的出口永远是一阶方程，所以真正要熟练的还是可分离变量与一阶线性那两套。

为什么「缺什么就设什么」是合理的

换个角度看这三种情形：降阶的本质是「把不熟悉的对象换成熟悉的」。我们对二阶方程不熟，对一阶方程熟；那就想办法把方程里最高的那个东西，换成它的下一阶。

类型一的方程里最高的就是 y(n)，而它已经和 y 没有任何直接关系（右边只有 x），所以积一次分就降一阶，没有任何阻碍。

类型二里最高的两项 y(n) 与 y(n−1) 只差一阶，把它们整体记成 u 与 u'，方程立刻变成只含 u'、u、x 的一阶方程。

类型三最麻烦：最高的两项是 y'' 与 y'，也差一阶，看起来可以照搬。但右边出现了 y 本身，而 y 与 y' 之间没有「求一次导」的关系。所以只能换一条思路：把 y' 记成 p，并把 p 的「身份」从「x 的函数」改成「y 的函数」。这一步是对的，因为 y 是 x 的函数这件事没有变，只是我们选择了不同的观察方向。

二、类型一：y(n)=f(x)，一路积分到底

先说一个容易看岔的地方：y(n) 的括号里写的是阶数，不是幂次。y(4) 是「y 的四阶导数」，不是「y 的四次方」。老师特意强调过这一点：不是 y 的 n 次方，是 y 的 n 阶导数。

类型一的解法没有技巧：两边同时求不定积分，n 阶降成 n−1 阶；再积一次，降到 n−2 阶……一直降到 y 为止。老师对这一类的评价是：两边不停地求不定积分不就完了吗？

例 1求 y'''=x 的通解。

思路：积三次，每次冒出一个常数，最后统一编号

第一次积分：x 的原函数是 x22：

y''=x22+C

第二次积分：x22 的原函数是 x36，常数 C 的原函数是 Cx：

y'=x36+Cx+C1

第三次积分：x36 的原函数是 x424，Cx 的原函数是 C2x2，C1 的原函数是 C1x：

y=x424+C2x2+C1x+C2

到这里已经是对的。但老师又做了一步「好看化」：常数本身是任意的，所以 C2 这类系数完全可以吸收进常数里：

y=x424+C1x2+C2x+C3

收尾动作有两个：把系数并进常数、把编号理顺。然后数一遍个数——三阶方程，通解里必须有三个任意常数，这里 C1、C2、C3 正好三个。老师说：微分方程是几阶的，就得有几个任意的常数。

数常数这件事不只是形式要求：如果数出来只有两个，说明你漏了一次积分，或者中途把两个常数并成了一个。它是这类题最省事的自检手段。

例 204:08求 y'''=e2x−cosx 的通解。

思路：和例 1 一样，只是被积函数换成了指数与三角

第一次积分。e2x 要与内层的 2 相配，所以要补一个 12；cosx 的原函数是 sinx，前面带着减号：

y''=12e2x−sinx+C1

第二次积分。e2x 再补一个 12，于是系数变成 14；−sinx 的原函数是 cosx，负负得正：

y'=14e2x+cosx+C1x+C2

第三次积分。e2x 的系数变成 18，cosx 的原函数是 sinx：

y=18e2x+sinx+C12x2+C2x+C3

把系数并进常数，得到

y=18e2x+sinx+C1x2+C2x+C3

04:41这类题真正容易错的地方只有一个：12 每积一次就要再乘一次。e2x 积三次，系数从 12 到 14 再到 18，漏一次分母就会错一倍。老师说这一步如果拿不准，就在草稿纸上老老实实写一遍 ∫e2xdx，不要跳。

三、类型二：y''=f(x,y')，缺 y 就令 u=y'

类型二的长相很好认：方程里有 y''、有 y'、也有 x，唯独没有 y。老师说它的特点是有 y'' 有 y' 但是没有 y，有 x。处理办法顺理成章：既然最碍事的是「最高的那一阶」，而它只比另一个导数高一阶，就把低一阶的那个整体设成一个新字母：

p=y'⟹y''=p'

代进去之后，方程里只剩 p'、p 和 x——这是一个关于 p 的一阶微分方程：p'=f(x,p)。它可能是可分离变量的，也可能是一阶线性的，也可能恰好是齐次方程，看题目给的样子决定；不管哪一种，前面都学过。

例 309:23求 (1+x2)y''=2xy' 满足 y'(0)=3、y(0)=1 的特解。

思路：方程里有 y''、y'、x，没有 y——类型二，令 p=y'

设 p=y'，则 y''=p'，代入得

(1+x2)p'=2xp
第一步：解这个关于 p 的一阶方程

10:22把 p 与 x 各自归边。p'=dpdx，把 dx 乘过去、把 1+x2 除过来：

1pdp=2x1+x2dx

两边积分。左边是 ln|p|；右边的分子 2x 恰好是分母 1+x2 的导数，正是「分母求导型」，所以也积成对数：

ln|p|=ln(1+x2)+C

因为 1+x2 恒为正，这个对数不需要绝对值。两边取 e、去绝对值补正负号，把 ±eC 收成一个常数：

p=C1(1+x2)
12:52第二步：p 完了不能停，还要回到 y

老师在这里特别提醒：p 完事了，你千万别着急就停了，p 完事了还得整 y 呢。因为 p 就是 y'，所以现在手里拿的是

y'=C1(1+x2)

先代第一个初始条件 y'(0)=3：把 x=0 代进去，1+0=1，所以 C1=3。于是

y'=3(1+x2)

再积一次就得到 y：3 的原函数是 3x，3x2 的原函数是 x3：

y=x3+3x+C2

再代第二个初始条件 y(0)=1：把 x=0 代进去只剩 C2，所以 C2=1。特解是

y=x3+3x+1

核一下：y'=3x2+3=3(1+x2) ✓，y''=6x，代回原方程左边 (1+x2)⋅6x=6x(1+x2)，右边 2x⋅3(1+x2)=6x(1+x2) ✓；两个初值也都对上。

这道题的两个坎

一、解出 p 就交卷。答案里留着 p——p 是我们引进的临时变量，题目问的是 y。老师说这一步的关键就是把这个 Y 再求出来呗，无非也就是再求一次不定积分。

二、把两个初始条件搞错了顺序。y'(0)=3 是给 y' 用的，必须用在「p=C1(1+x2)」这一步；y(0)=1 是给 y 用的，必须等 y 求出来之后再用。拿 y(0)=1 去定 C1，或者拿 y'(0)=3 去定 C2，都是把条件用错了地方。

四、类型三：y''=f(y,y')，缺 x 就令 p=y'（并把 p 看作 y 的函数）

第三种类型长这样：y''=f(y,y')。它的特征同样是一句话——x 没有出现。老师说它没有 x，是 y''、y' 和 y。这句话容易让人发懵：方程里明明没有 x，可 y 是 x 的函数啊？关键在「直接出现」三个字——y 里当然藏着 x，但方程把 y 与 y' 当成两个普通的量摆在一起，x 这个字母从头到尾没有露面。

处理手法还是把一阶导数设成新变量：p=y'，于是 y''=p'。想法和类型二一样，都是「对二阶不熟、对一阶熟」。但这里有一处天差地别的不同：p 要看成 y 的函数。

y'' 为什么要写成 pdpdy

设 p=y' 之后，y'' 就是 p 对 x 的导数，也就是 dpdx。麻烦在于：题目右边只有 y 和 p，没有 x；如果左边留在 dpdx 这个形式上，方程里就同时出现了 y、p、x 三个量，还是解不动。

出路是把求导的「对象」从 x 换成 y。用链式法则：

dpdx=dpdy⋅dydx

而已知 dydx=p，所以

y''=pdpdy

代进原方程，y''=f(y,y') 变成 pdpdy=f(y,p)——这是一个只含 p、y 与 dpdy 的方程，x 彻底消失了，它就是一个「以 y 为自变量、以 p 为未知函数」的一阶微分方程。

老师说这一步「不是特别好理解」，所以他课上专门把它推导了一遍。记住这个动机比记住公式重要：我们不是「规定」p 是 y 的函数，而是为了把 x 赶出方程，才主动换了观察角度。

例 4求 yy''−(y')2=0 的通解。

思路：有 y、有 y'、有 y''，独独没有 x——类型三

20:41先说一个书写上的小提醒：(y')2 里的那一撇后面必须套上小括号。老师专门提过这件事：手写时若不套括号，y'2 很容易被看成一堆数字，和 12 几乎分不出来。这个习惯要从现在养成。

令 p=y'，并把 p 看成 y 的函数，则 y''=pdpdy。代入：

y⋅pdpdy=p2

两边同时约掉一个 p（这一步默认 p≠0，稍后回头查），方程立刻瘦下来：

ydpdy=p
第一步：分离变量，解出 p 与 y 的关系

这已经是标准的可分离变量了：

dpp=dyy

两边积分，1p 与 1y 都给出对数：

ln|p|=ln|y|+C1

两边取 e、去绝对值补正负号，把 ±eC1 收成一个常数：

p=C1y

老师说这一步心里要有数：因为它是二阶方程，最终是不是两个常数？你一个 C 肯定搞不定。所以从一开始就把这个常数写成 C1，为后面那个常数留位置。

第二步：回代 p=y'，再分离一次

把 p 换回 dydx：

dydx=C1y⟹dyy=C1dx

两边积分，左边是 ln|y|，右边是 C1x：

ln|y|=C1x+C2

取 e、收常数，得到

y=CeC1x

核一下常数：二阶方程，通解里两个任意常数（C 与 C1），对上了。

被约掉的那两处，这次运气好

这道题做了两次除法：约掉 p（默认 p≠0），分离时又除以 y（默认 y≠0）。按 【黑板】可分离变量和齐次方程 的规矩，要回头检查 p=0 与 y=0 对应的解在不在通解里。

p=y'=0 意味着 y≡C（常函数）；y≡0 是它的特例。代回原方程：y⋅0−0=0 ✓，成立。而通解 y=CeC1x 里取 C1=0 正好给出 y=C，取 C=0 给出 y≡0——两个都被常数吸收了，所以不必另写。

但老师的态度是「别赌运气」：你会频繁地把某一项放到分母上，只要放到分母，你就把它等于零这种情况给排除掉了。回看一眼的成本极低，而漏掉一条解是要扣分的。

五、后两类最爱混：判别提示

这三类里，类型一基本不会认错，真正容易混的是后两类的「设什么」——它们都要引进一个新字母，但那个新字母的身份完全不同。老师也给了「考试预报」：第三种和第二种出现的可能性就比较小一些，第一种——两边直接求积分的这种——可能还会出现。不过这不妨碍我们把两者分清。

对比项类型二（缺 y）类型三（缺 x）
怎么认方程里出现 x，但没有 y方程里出现 y，但没有 x
设什么u=y(n−1)（二阶时就是 p=y'）p=y'
新变量是谁的函数u 仍然是 x 的函数p 要看 y 的函数（关键区别）
导数怎么换y(n)=u'，直接对 x 求导y''=pdpdy，用链式法则换自变量
降成什么关于 u 与 x 的一阶方程关于 p 与 y 的一阶方程
解完之后回代 u，再按类型一积到底回代 p=y'，再分离变量积一次
判别提示：不要看「设什么」，先看「缺什么」

很多同学的错法是这样的：看到二阶方程要换元，凭记忆写下「令 p=y'」，然后顺手把 y'' 写成 dpdx——结果方程里突然冒出 x，再也化不动了。

避免它的办法不是背两类公式，而是养成一个固定的扫描动作：拿到方程先从头到尾扫一遍，只问一个问题——这个方程里有没有 x？

  • 有 x、没有 y → 类型二，设 u=y'，u 是 x 的函数，y''=dudx。
  • 没有 x、有 y → 类型三，设 p=y'，p 是 y 的函数，y''=pdpdy。

用一句话记：缺 y 的时候，大家还在「对 x 求导」的世界里，照旧即可；缺 x 的时候，必须换个世界，把自变量临时改成 y。这就是为什么后一类的公式里会出现 dpdy 这种长相古怪的东西。

六、易错清单

一 · 把 y(n) 看成 n 次方

y(3) 是「y 的三阶导数」，不是 y 的三次方。括号里是阶数，这是全章通用的记号，认错会导致整道题的性质判断全错。

二 · 降阶完不回代

类型二尤其容易：解出 u（或 p）就停手，答案里留着这个辅助变量。老师的原话是解完以后别忘了回代。类型二还要继续按类型一积到 y；类型三还要再分离一次积分。

三 · 类型三把 p 当成 x 的函数

那样 y'' 会写成 dpdx，方程里 x 重新出现，整道题白忙。判别动作是前面那句口诀：先看方程缺 x 还是缺 y。

四 · 忘了被除数与约分干掉的那些解

约掉 p、把 y 放到分母上，都会排除掉某些情形（典型的是 y≡0 这类常函数解）。求完之后回看一眼：那些被排除的情形代回原方程成不成立？成立就补写。在例 4 里它们恰好被常数吸收了，但这不是普遍规律——【黑板】可分离变量和齐次方程 里给出了一个救不回来的反例。

五 · 逐次积分时把常数个数数错

类型一积 n 次就该有 n 个任意常数。数出来不够，说明漏了一次积分；数出来多余，说明把同一个常数重复计数了。交卷前数一遍，是这类题最廉价的保险。

记忆入口 · 一眼回忆

一句话

可降阶的高阶方程 = 看方程缺了谁，就换谁。三类都汇入一阶方程，然后照 可分离变量的微分方程、一阶线性微分方程 的方法做。

三类对照（照这张卡片认类型）

y(n)=f(x)
右边只有 x。两边直接积分，积 n 次，得 n 个常数
只有 y(n)、y(n−1)、x
缺 y。令 u=y(n−1)，u 是 x 的函数，化成关于 u 的一阶方程
y''=f(y,y')
缺 x。令 p=y'，p 是 y 的函数，y''=pdpdy

一条链（类型三）

认出 有 y、y'，没有 x→ 换元 p=y'，y''=pdpdy→ 解出 p=φ(y)→ 分离 dyφ(y)=dx→ 再积一次 得 y

要背的

  • y'''=x 的通解 y=x424+C1x2+C2x+C3（三阶三个常数）。
  • y'''=e2x−cosx 的通解 y=18e2x+sinx+C1x2+C2x+C3（e2x 每积一次多一个 12）。
  • (1+x2)y''=2xy' 配 y'(0)=3、y(0)=1，特解 y=x3+3x+1。
  • yy''−(y')2=0 的通解 y=CeC1x。
  • y''=pdpdy（类型三的命门，来自链式法则）。

三个坑

  1. 缺 x 却把 p 当成 x 的函数。方程里会重新冒出 x，白忙。
  2. 降阶完不回代。答案里留着 u 或 p，等于没做完。
  3. 忘了被约掉的解。约了 p、除了 y，就回看一眼 p=0、y=0 对应的函数是不是也是解。
