开篇：计算不麻烦，定义和性质烦

00:00定积分这一章，真要算积分，牛顿—莱布尼兹公式一代就完事。但考试前面那些定义和性质，以及"哪些结论能直接用、哪些有隐藏条件"，才是容易栽跟头的地方。本页是复习精讲课，结构跟新授课不同：先速查定义，再列性质表，最后用题型和易错清单把考点压实。新授课的完整推导请看 定积分的定义 定积分的性质。

一、定义速查：四步 + 一个关键

00:48定积分最经典的引子是曲边梯形面积：曲线 y=f(x) 与 x 轴在 [a,b] 上围成的图形不规则，没法直接算，于是采用"近似"思想——把整体切成许多竖条，每个竖条近似成矩形，再求和取极限。

定积分的定义（四步）

分割：在 [a,b] 任意插入分点 a=x0&lt;x1&lt;⋯&lt;xn=b（任意切，不要求等分），记 Δxi=xi−xi−1。

近似：在每个小区间 [xi−1,xi] 上任取一点 ξi，以 f(ξi) 为高作小矩形，面积 f(ξi)Δxi。

求和：Sn=∑i=1nf(ξi)Δxi（黎曼和）。

取极限：令 λ=max{Δx1,…,Δxn}，若 λ→0 时极限存在且与分法、ξi 取法无关，则称该极限为 ∫abf(x)dx。

04:25为什么是 λ→0，不能只写 n→∞

只让小区间个数 n→∞，只能保证"切得多"，却保证不了每一块都小——完全可能出现某一个小区间特别长、其余特别短的情况，那块上的近似误差就会爆炸，极限可能不存在或不唯一。而 λ→0 要求最长那一段趋于 0，既保证切得极多、又保证每块都极细，两个效果同时达到。所以定义里取极限的变量是 λ（最大区间长度），不是 n。老师原话的潜台词就是：你切了一万刀，只要有一刀切得跟脸一样大，近似就废了。

09:48"与分法、取法无关"是什么意思

定义里强调：无论你怎么切（等分或不等分）、无论每个 ξi 取左端点、右端点还是中点，只要 λ→0 极限都一样。这说明定积分是区间与函数共同决定的客观量，不依赖于你"怎么逼近"。但注意：做题时为了求极限，我们通常主动取等分、取右端点，因为定义只要求存在性，具体算可以挑最方便的分法。这就像"无论用什么方法量，桌子的长度都不变；但你量的时候当然选最顺手的尺子"。

三个必须记住的注意点

是一个数
15:10一旦上限、下限、被积函数都确定，∫abf(x)dx 就是一个确定的实数，不是函数。
与积分变量符号无关
16:52∫abf(x)dx=∫abf(t)dt，换成 t、u 都一样；积分变量只在积分内部有效，积完就消失。
上下限大小未必
13:17下限是"写在下面的"、上限是"写在上面的"，谁大谁小不一定；交换上下限要加负号（见性质二）。
21:39几何意义：符号随函数值正负翻转

若 f(x)≥0，定积分就是曲边梯形面积；若 f(x)≤0，每一块 f(ξi)Δxi 都是负的，所以定积分是面积的相反数；若一段在上、一段在下，则 ∫abf=S1−S2（S1 上为面积、S2 下为面积的绝对值）。一句话：积分带符号，面积是正的，别把二者画等号。题目问"面积"和问"定积分"是两个不同的量，必须先判断函数是否变号，变号时面积要分段取绝对值加起来。

二、性质速查表

33:45下面这些性质，考试直接调用。凡写"在区间 [a,b] 上"的性质，默认 a&lt;b；一旦上下限大小反过来，结论可能翻面（详见易错清单）。

性质内容陷阱
零区间∫aaf(x)dx=0线段面积为 0
交换变号∫abf=−∫baf上下限互换加负号
线性∫(mf+pg)=m∫f+p∫g相乘 ∫fg 不能拆；相除也不能拆
区间可加∫ab=∫ac+∫cbc 可在线段内外任意位置
保号f≥0⇒∫abf≥0必须 a&lt;b
比较f≤g⇒∫abf≤∫abg必须 a&lt;b
绝对值|∫abf|≤∫ab|f|先取绝对值更大
估值m(b−a)≤∫abf≤M(b−a)m,M 为最小、最大值
中值定理∫abf=f(ξ)(b−a)要求 f 连续，ξ∈[a,b]
积分中值定理

39:38若 f 在 [a,b] 上连续，则至少存在一点 ξ∈[a,b]，使

∫abf(x)dx=f(ξ)(b−a)

几何上：f(ξ) 是曲线在 [a,b] 上的平均高度，以它为高的矩形面积等于原曲边梯形面积。

39:38中值定理怎么证：靠介值定理

把估值不等式 m(b−a)≤∫abf≤M(b−a) 三边同除以 b−a>0，得 m≤1b−a∫abf≤M。记中间这个常数为 c，则 c 介于最小值 m 与最大值 M 之间。因 f 在 [a,b] 连续，由介值定理，必存在 ξ∈[a,b] 使 f(ξ)=c，即 ∫abf=f(ξ)(b−a)。可见"连续"这条不是凑数，正是为了启用介值定理——若 f 不连续，中间值未必能取到，定理就垮了。

20:00可积条件：连续就够了，有界只是必要

什么函数才能定积分？老师原话说"可积条件要求比较松"。准确地说：充分条件——若 f 在 [a,b] 上连续，则必可积；更弱一点，若 f 有界且只有有限个间断点，也可积。必要条件——若 f 可积，则 f 必有界（所以"有界"是可积的必要条件，但不是充分条件）。经典反例是狄利克雷函数：在有理点取 1、无理点取 0，处处有界却处处不连续，黎曼不可积。记住三角色：连续 ⇒ 可积（最常用）；有界+有限间断 ⇒ 可积（也够用）；仅有界 ⇏ 可积（别想当然）。

44:02区间可加性：c 在 [a,b] 外也成立

性质"∫ab=∫ac+∫cb"里的 c 不要求落在 a,b 之间。若 c 在右侧（b&lt;c）：由 ∫bc=−∫cb 与 ∫ac=∫ab+∫bc，移项得 ∫ab=∫ac−∫bc=∫ac+∫cb，公式照样成立。同理 c 在左侧也成立。所以无论 c 在线段内还是延长线上，区间可加性都成立，它本质是"交换变号"和"线段拼接"的组合。做题时若想把积分拆成两段而中间点不好放，放心放外面即可。

三、题型套路

题型 1：用定义算积分（极少但必会）

例 125:57用定积分的定义计算 ∫01x2dx。

思路：主动取等分、取右端点

按定义，n 等分 [0,1]：Δxi=1n，取右端点 ξi=in。则

∫01x2dx=limn→∞∑i=1n(in)2⋅1n=limn→∞1n3∑i=1ni2

用求和公式 ∑i=1ni2=n(n+1)(2n+1)6，抓大头（分子分母同为 n3）：

limn→∞n(n+1)(2n+1)6n3=26=13

所以 ∫01x2dx=13。（这里 n 等分使得 λ=1n→0 等价于 n→∞，所以可以直接取极限。）

这步最容易错

求和公式记错或抓大头抓错。∑i2 是 n(n+1)(2n+1)6，不是 n2(n+1)24（那是 ∑i3）。抓大头时分子最高次项系数 2、分母 6，结果 13。这类题考的就是"求和公式 + 同次幂系数比"，公式记混就全错。

题型 2：用性质比较大小

例 248:14比较 ∫01xdx 与 ∫01x2dx 的大小。

思路：用比较性质（保号性的推论）

在 [0,1] 上，显然 x≥x2≥0，且 x−x2 不恒为 0。由比较性质（此处 0&lt;1，满足 a&lt;b）：

∫01xdx≥∫01x2dx≥0

代入已知值即 12≥13。结论的"为什么"正是：被积函数大，则定积分大（在 a&lt;b 的前提下）。

别漏掉 a&lt;b

只写"f≥g 所以积分大"就完事。若区间写成 ∫10（上限小于下限），交换变号后不等号会反向。比较性质成立的前提是明确 a&lt;b。

题型 3：估值

例 339:38估计 ∫02x2dx 的范围。

思路：用估值定理

在 [0,2] 上，f(x)=x2 的最小值 m=0（在 x=0），最大值 M=4（在 x=2）。由估值定理：

0⋅(2−0)≤∫02x2dx≤4⋅(2−0),即0≤∫02x2dx≤8

实际值 83≈2.67，确实落在区间内。估值不求精确值，只给"夹逼"范围，常用于证明不等式。

四、易错清单

错 1 · 把 ∫ab 与 ∫aa 弄混

33:45∫aaf(x)dx 是零区间，规定等于 0（线段面积为 0）。有人把 ∫ab 也直觉成"从 a 到 b 反正都是一段"而忽略上下限；记住：只有上下限相同才为 0，一般 ∫ab 与区间长度 b−a 有关，不是 0。另外 ∫ab 与积分变量符号无关，∫abf(x)dx=∫abf(t)dt。

错 2 · 乱用保号 / 中值定理，忘记 a&lt;b

52:41课本写"若 f≥0 则 ∫abf≥0"是默认 a&lt;b 为前提的。如果实际是 ∫10（上限小于下限），交换变号后结论变成 ≤0。同样，比较性质、估值、中值定理都暗含"[a,b] 是正常区间"。凡用这些性质，先确认谁上谁下。老师专门挖的坑：说"ex≥−x2 所以 ∫abex≥∫ab(−x2)"——若 a,b 大小不确定，这句话是错的。

错 3 · 以为下限必须比上限小

14:33定积分的记号里，写在下面的是下限、上面的是上限，谁大谁小没有规定。∫01x2dx 与 ∫10x2dx 都合法，后者等于前者相反数。不要看到上限小于下限就当成写错了。

错 4 · 几何意义符号搞反

21:39当 f(x)≤0 时，定积分是图形面积的相反数（负值），不是面积本身。若要求"面积"，必须加绝对值或取负号。题目问"面积"和问"定积分"是两个不同的量，先判断函数是否变号。

39:38中值定理的"平均值"直觉

∫abf=f(ξ)(b−a) 中，f(ξ)=1b−a∫abf 就是 f 在 [a,b] 上的平均值：把高低不平的函数"削峰填谷"成一个等高矩形，面积不变。这个解释比死记公式好用，且直接说明了为什么要求 f 连续（连续才能保证取到中间的那个值）。

38:14线性性质能拆加减，但 ∫fg、∫fg 不能拆，为什么

性质三说 ∫(mf+pg)=m∫f+p∫g，这是"线性"，本质是定积分的求和定义里本来就有系数提出来、项加起来。但乘积不能提：∫abf(x)g(x)dx 绝不等于 ∫f⋅∫g，因为左边是每个点先相乘再求和，右边是先各自求和再相乘，完全是两码事（类比 (a+b)(c+d)≠ac+bd）。分式也不能拆。老师特别强调这一点，是因为学生看到 ∫fg 容易本能地想"上下分开"，那是错的。记住：定积分只认"线性组合"，乘法、除法一律不拆。

39:38估值定理与中值定理的区别：一个给范围，一个给等式

估值定理 m(b−a)≤∫abf≤M(b−a) 给的是一个区间，不告诉你积分具体是多少，只说它夹在两层之间，常用于证明不等式。中值定理 ∫abf=f(ξ)(b−a) 给的是一个精确等式，但 ξ 是"存在某点"而不知道具体在哪，常用于理论推导（如证明积分中值、联系平均值）。两者不矛盾：中值定理的 f(ξ) 正是落在 [m,M] 之间的那个值，估值定理是它更松的版本。做题时若只要"大概范围"用估值，若要"精确表达成某点函数值乘区间长"用中值。

20:00可积条件续：为什么定义要求 f 有界

前面说过"连续 ⇒ 可积、有界+有限间断 ⇒ 可积、仅有界 ⇏ 可积"。这里补一句为什么"可积必需要有界"：若 f 无界，黎曼和的每一项 f(ξi)Δxi 都可能因 ξi 取在无界点附近而任意大，无论怎么细分，和都会因取样点不同而上天入地，极限不存在——所以无界函数（在常义黎曼意义下）不可积。这也是为什么定义里老师专门停一下强调"f 在 [a,b] 上有界"。考试里碰到 ∫−111xdx 这类，不能直接套牛顿—莱布尼兹乱代，因为它在 0 处无界，是广义积分的活儿，不属于本页常义定积分的讨论范围。

25:57什么时候才用"定义算积分"

例 1 用定义算 ∫01x2dx，但现实是：一旦学了牛顿—莱布尼兹公式，这种题直接用原函数 x33 代值就行，根本不用定义。那为什么还要练定义算？两个原因：一是考试偶尔会专门出"用定义计算"的题，这时必须走四步；二是它帮你确认"定积分真的是黎曼和的极限"这个底层直觉，否则后面变上限积分、二重积分的定义你都会发虚。所以定义算积分是"平时练手、考场按需"的技能，别因为它麻烦就跳过，更别在它该出场时忘了对 n 等分取右端点这套标准操作。

59:00牛顿—莱布尼兹公式的前提（下一节）

本页只讲定义与性质，不涉及计算。但要提醒：下一节 牛顿-莱布尼兹定理 的牛顿—莱布尼兹公式 ∫abf=F(b)−F(a) 成立的前提是被积函数 f 在 [a,b] 上连续（或至少可积），且 F 是 f 的一个原函数。若 f 在区间内有间断点或无界，不能直接套公式，要用分段积分或广义积分。这正好呼应本页的"可积条件"——可积是计算的前提，不可积的东西代公式必错。
