P039不定积分的性质：把"积分当逆运算"说精确

一句话核心

不定积分有两个最朴素的性质——加减能拆开、常数能外提。它和求导是互逆的，但必须补上一句：先求导再积分，结果和原函数只差一个任意常数 C。这一页就把这句"互为逆运算"讲死、讲准。

先把"不定积分"摆正位置

00:00上一讲（曲率）给了不定积分的定义：∫f(x)dx 表示 f 的全体原函数，结果是一族函数，彼此相差一个常数。这一讲不引入新工具，只讲它作为运算的两条性质——但恰恰是这两条性质，决定了我们后面所有"拆项、提常数"的合法性。

老师一上来就点明：性质本身不难，"理解就行"。真正要小心的只有一处——能拆的是加减，不能拆的是乘除。很多人惯性地把积分当成普通括号，看见乘积也想拆，那是错的。

性质一：加减可以线性拆开

性质一 · 线性（加减）

若 f,g 都有原函数，则

∫(f(x)±g(x))dx=∫f(x)dx±∫g(x)dx

一句话：和的积分等于积分的和，可以一项一项分开积。

为什么加减能拆，相乘却不行 01:13

道理藏在它的逆运算——求导——里。对 (F+G) 求导，正好"朝里分"：

(F+G)'=F'+G'

积分是求导的逆，逆回去自然也能"朝里分"。但乘积没有这种线性：(FG)'≠F'G'，所以 ∫f⋅g 不能写成 ∫f⋅∫g。相除同理。

一句话记死：相加相减可拆，相乘相除不可拆。

性质二：常数因子可以外提

性质二 · 齐次（常数外提）

若 k 为常数，则

∫kf(x)dx=k∫f(x)dx

常数直接从积分号里提出来。

01:50这里要留一个心眼：课上说的 k 是常数。老师顺带预告了一句——将来讲二重积分时，能外提的就不一定非得是常数了：只要那个量与积分变量无关，也能外提。但在不定积分这一层，我们先老老实实记"常数外提"即可。

为什么能提的是"常数"，换成变量就崩 01:50

常数 k 之所以能拎到积分号外面，理由只有一句：它和积分变量 x 毫无关系，在整个积分过程里它就是个"不动的因子"，等价于一个固定的倍数，整体搬出去当然不改变运算。

把 k 换成一个会动的因子，这条规则立刻失效。最刺眼的例子是 ∫x⋅xdx：两个因子都随 x 变，你没法把哪个 x 提到外面去——强行提就会出事：

∫x⋅xdx=∫x2dx=x33+C,x∫xdx=x⋅x22=x32(错)

两个结果相差 x3/6，它随 x 变，根本不是常数。也就是说，这两个答案连"只差一个常数 C"都算不上，是货真价实的错误。判据记死：能提到积分号外的量，必须不含积分变量。常数是这条判据最省事的特例；到了二重积分，"与积分变量无关的变量"会顶替它的位置。

课堂原话（大意）00:00

相加减可以先分开、再一起求不定积分，这个一点毛病都没有。那大家注意，如果它是相乘，你直接给它分开先求不定积分再相乘——这样是不对的哈，相除也不能分。

话音刚落，老师自己替同学把疑问问了出来：相加减可以分，那老师你也没告诉我，为什么相加减就能分呢？——答案就在下面那段"求导可以朝里分"。

一句话把"互为逆运算"讲精确

很多教材爱说"微分与积分互为逆运算"。这句话对，但容易被理解成"完全可逆、毫厘不差"。把它拆成两条才严谨：

逆运算的精确表述

其一（积分再求导，精确还原）：

ddx(∫f(x)dx)=f(x)

其二（求导再积分，差一个常数）：

∫F'(x)dx=F(x)+C
为什么"差一个常数"是必然的 00:00

常数的导数恒为 0。所以任何两个只差常数的函数，它们的导函数完全相同。于是当你由 F' 反推原函数的全体时，必须把所有"加上任意常数后仍然导数相同"的函数都收进来——这就是 +C 的来历。它不是凑出来的摆设，而是"反推时信息天然丢失了一维"的真实记录。

也正因为如此：先积后导不丢信息，精确还原；先导后积丢了一个常数维度，只能还原到"一族"。

一张表看清：求导与积分哪些地方"一样"、哪些地方"不一样"

两个运算的外观高度相似，规则却有明确的对齐与错位。把下面这张表记牢，"能拆不能拆、要不要补 C"就不会再混：

运算加减常数因子乘积 / 商最后要不要补常数
求导 ddx 可拆：(F±G)'=F'±G' 可提：(kF)'=kF' 不可拆：(FG)'≠F'G' 不补（常数被吃掉）
积分 ∫ 可拆：∫(f±g)=∫f±∫g 可提：∫kf=k∫f 不可拆：∫fg≠∫f⋅∫g 必补 +C

读法：前三列两个运算完全对齐——加减都能拆、常数都能提、乘积（和商）都不能拆。唯一"不对称"的是最后一列：求导会把常数吃掉，所以它没有尾巴；积分是负责"找回被吃掉常数"的一方，所以结果必须光明正大地写上 +C。这条"不对称"，就是后面所有扣分点里最冤的那一个。

关于 +C：什么时候写、为什么漏了要扣分

初学最容易丢分的往往不是算错，而是该写 C 的地方没写。先把规矩一次列清。

判据：看整个式子最终停在哪个运算上

最终结果是一个算完的不定积分
必须写 +C。不定积分的定义就是"f 的全体原函数"，少了 C，你写出的只是其中一个。
最终结果落在了求导（或取微分）上
不写 C。例如 (∫f(x)dx)'=f(x)，常数已被求导吃掉，右边本来就干干净净。
式子还在中间步骤
可以暂时不写，等全部积完，最后合并成一个 C。
拆成好几项，为什么最后只写一个 C

看上面那种"拆开逐项积"的写法：每一项各自积完都会带一个任意常数，比如拆成两项就可能是 C1 和 C2。但任意常数加任意常数还是任意常数——C1+C2 同样能取遍一切实数，和单个 C 能起到的作用一模一样。

既然写 C1,C2,… 与写一个 C 描述的是同一族函数，那就没有理由啰嗦，统一收成一个 C。反过来说：真的写了两个常数，也不算答错，只是"没有化简到最简形式"。

漏了 C 扣的是"定义分"，不是"算错分"

考试里不定积分的填空题、计算题，只要最后出现积分、却没有 C，一律按错处理。原因不是老师苛刻，而是漏 C 的答案在数学上根本不是"被问的那个东西"：

  • 题目问 ∫f(x)dx，它的定义是 f 的全体原函数。你写出 x33，等于只交出了那个 C=0 的特例——回答的是"f 的一个原函数"，而不是"f 的不定积分"。
  • 不定积分是一个集合，不是一个函数。去掉 C，答案就从一族退化成一条，信息量少了一整个维度。这也是本页反复强调的那句"结果不是唯一的"。
反过来看：同一道题，答案可以长得不一样

既然答案是一族函数，那么"正确写法"就不唯一。同一个积分可以有两副面孔：

∫sinxcosxdx=12sin2x+C1=−12cos2x+C2

两种写法都对。因为由 sin2x+cos2x=1 可知 12sin2x 与 −12cos2x 只相差常数 12，两个常数 C1,C2 之间也就差这个 12——它们其实在描述同一条曲线族。所以判卷看的是"导数对不对"，而不是"长得像不像标准答案"；你自己算完，最稳的收尾动作也是求导回去验一遍。

例题：直接套公式的家常题

例 103:16求 ∫(x2−5x)dx。

思路：加减拆开、常数外提，再逐项用幂函数公式

把根号写成幂：x=x1/2，然后拆开：

∫(x2−5x1/2)dx=∫x2dx−5∫x1/2dx

对 xn 积分是"指数加一、再除以新指数"：

∫x2dx=x33,∫x1/2dx=x3/23/2=23x3/2

合起来并补上 C（整道题只写一个 C 即可）：

∫(x2−5x)dx=x33−103x3/2+C

例 204:17求 ∫(x−1)3x2dx。

思路：分子先展开，再逐项除以分母

(x−1)3=x3−3x2+3x−1，除以 x2 得到四项：

x3−3x2+3x−1x2=x−3+3x−1x2

逐项积分（注意 ∫x−2dx=−x−1）：

∫(x−1)3x2dx=x22−3x+3ln|x|+1x+C
这一步最容易错

漏掉绝对值或漏掉 +C。∫1xdx=ln|x| 的绝对值不能随手扔（只有题目前提明确 x>0 时才可去）；另外四项积分完毕，全式只补一个 C 即可，不必每一项各写一个。

老师在这道题上反复强调的两个小动作 05:47

其一，展开 (x−1)3 用杨辉三角。硬算是 (x−1)2(x−1) 逐项相乘；更省事的是直接背杨辉三角第四行的系数 1,3,3,1，于是 (x−1)3=x3−3x2+3x−1。老师说得很直白：你如果不硬算，就用杨辉三角 1331，系数就是这个。幂次越高，这个技巧越值钱。

其二，带负指数的项算完要"倒过来"验一遍。例 2 里 ∫x−2dx=−x−1 这个负号最容易掉，因为 x−1 求导既会冒出负号、指数还要再减一次，两个动作叠在一起很容易手滑。老师的习惯是：每次我都稍微倒过来给它验证一下子，因为很容易出错。这个"验算"动作后面每道积分题都能用上。

例 308:01求 ∫(ex−3cosx)dx。

思路：中间是减号，先拆成两项，再各自套表

被积函数由 ex 与 3cosx 相减构成，属于"相加减"，可以放心拆开；第二项的系数 3 按性质二提到积分号外：

∫(ex−3cosx)dx=∫exdx−3∫cosxdx

两项都是积分表里的基本款：ex 求导、求原函数都还是自己，所以 ∫exdx=ex；而 cosx 的原函数是 sinx。于是

∫(ex−3cosx)dx=ex−3sinx+C

回看要点：这道题的"难点"其实只在于敢不敢拆。ex 与 cosx 之间是减号，拆开完全合规；如果它们中间是乘号，就绝不能这么下手了。

例 409:04求 ∫2xexdx。

思路：底数不同、指数相同 ⇒ 先合并底数，凑成 (2e)x

这题不是"拆"的问题，而是要先把两项合成一项。指数相同、底数不同，底数可以直接相乘：2xex=(2e)x。这样一来它就落进了公式 ∫axdx=axlna+C（此处 a=2e）：

∫2xexdx=∫(2e)xdx=(2e)xln(2e)+C=2xexln2+lne+C

因为 lne=1，化简得

∫2xexdx=2xex1+ln2+C
这一步最容易错

把它当成 ex，直接写 ∫2xexdx=2xex+C。∫exdx=ex 只在底数恰好是 e 时成立；这里合并后的底数是 2e≠e，必须用 ax 的公式，分母上会多出一个 ln(2e)。

另外，老师特意把分母写成 1+ln2 这种"常数在前"的次序，而不是 1+ln2 之外的写法——因为 lne 是个 1，为了避免歧义，我们一般倒过来写，就是 1 加 ln2。写成 1+ln2，一眼就能看清这是"1 加上 ln2"，不会被误读成 ln(2e) 之类。

例题：三角函数靠"凑积分表"

10:14积分表（基本公式）里没有 tan2x、没有 sin2x2 这类，但高中那几个三角恒等式能帮它们"落进"表里。老师强调：最常用的是倍角公式与 sec2x、csc2x，万能公式基本用不上。

例 5求 ∫tan2xdx 与 ∫sin2x2dx。

思路：用恒等式把"表外"的式子变"表内"

第一题用 1+tan2x=sec2x，于是 tan2x=sec2x−1。而 ∫sec2xdx=tanx 正好是基本公式：

∫tan2xdx=∫(sec2x−1)dx=tanx−x+C

第二题用倍角公式 sin2x2=1−cosx2：

∫sin2x2dx=12∫(1−cosx)dx=x2−12sinx+C

回看要点：两题都没有"直接可查"的公式，靠的全是"把一个表外的样子改写成表内的样子"。第一题改的是 tan2，第二题改的是半角——手法不同，动机完全一致。

例 612:16求 ∫1sin2x2cos2x2dx。

思路：分母的"两块相乘"和倍角公式长得像，配一个系数把它变成 sin2x

倍角公式是 sinx=2sinx2cosx2，右边正好是分母里那两块相乘、只多了一个 2。为了把分母凑成 sin2x，上下同乘 4：

sin2x2cos2x2=14(2sinx2cosx2)2=14sin2x

于是被积函数变成 114sin2x=4csc2x：

∫1sin2x2cos2x2dx=∫4csc2xdx

csc2x 的原函数是 −cotx（因为 (cotx)'=−csc2x），所以

∫1sin2x2cos2x2dx=−4cotx+C

回看要点：这里配系数的那一步不能省。分母里是"两块相乘"，倍角公式里是"两块相乘再乘 2"，差的那个 2 平方后就是 4——数错这个系数，答案就整错了。这类题的统一目标只有一个：把式子整成积分表里已有的形状。

课堂原话（大意）14:37

三角函数公式对学生来说，已经不是够不够的问题了，是太多了的问题。你高中学的那些我们其实几乎不怎么用——第一，我们不用万能公式；到大学以后我都忘了万能公式长什么样了，因为几乎很少用过。用得最多的就是倍角公式、半角公式，再就是 tan 平方那几个平方关系。

例题：假分式"凑分母"

例 715:31求 ∫2x4+x2+3x2+1dx。

思路：分子凑成"能被分母整除"的形式

这是有理函数（多项式比多项式）。老师不强求多项式除法，而是"凑分母"：把分子配成含 x2+1 的块：

2x4+x2+3=2x2(x2+1)−(x2+1)+4

于是

2x4+x2+3x2+1=2x2−1+4x2+1

前两项直接积，最后一项用 ∫1x2+1dx=arctanx：

∫2x4+x2+3x2+1dx=23x3−x+4arctanx+C
这类题的通用套路 16:36

分子能拆成"若干项除以分母都能整除 + 一个余项"。手段就是：盯住分母（分母不能动），把分子往它的倍数上凑，凑不进的部分留在分子上当余项。老师原话：大家一定是就着分母去配，配完了以后和分母一除能除尽、能整除，这是第一项。

为什么可以绕过多项式除法？因为大学里遇到的这类题相对简单，也不用整什么除法了，大家就凑吧，凑一凑就完事了。老师还专门交代了它的"出身"：这种式子叫有理函数，后面有一小节专门讲，是同学们普遍觉得不好弄的一块；这里只要求会凑，真正难的部分留给那一节。余下的真分式（分子次数低于分母）就是那一节要认真对付的对象。

18:58老师收尾时说得很直白：性质部分的例题相对来说都比较简单。更重要的是那句提醒——大家实际做题或者考试，几乎不会遇到积分表里直接就能有的题，那就太简单了。书上能直接查到公式的题考试几乎不考，真正的重头戏是下一讲开始的换元法。所以这页要带走的，是两条性质本身、"加减能拆、乘除不能拆"这条红线，以及"结果必带 C"这个收尾动作。

记忆入口 · 一眼回忆

两条性质

  • 加减可拆：∫(f±g)=∫f±∫g；常数外提：∫kf=k∫f。
  • 相乘、相除不能拆：∫fg≠∫f⋅∫g。原因：求导对乘积不线性。

逆运算的精确版

(∫f)'=f
先积后导，精确还原（无常数）。
∫F'dx=F+C
先导后积，差一个任意常数 C。

C 的三条规矩

  • 最终结果是积分 ⇒ 必须写 +C；最终结果是求导/微分 ⇒ 不写。
  • 中间步骤可以先不写，最后合并成一个 C（C1+C2 还是常数）。
  • 答案不唯一：12sin2x+C 与 −12cos2x+C 是同一族。

两个坑

  • ∫1xdx=ln|x| 的绝对值不能随手去，除非已知 x>0。
  • 整道题只写一个 C；∫xndx=xn+1n+1（n≠−1），n=−1 时变对数。
  • 底数不是 e 时别用 ∫exdx=ex：∫(2e)xdx=(2e)x1+ln2+C。
