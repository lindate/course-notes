P121【黑板】直线及其方程

一句话核心

直线这一节也只有一个主角——方向向量 ⃗s=(m,n,p)。整页题型都能压成一句话：找一个点、找一个方向向量，代进点向式。方向向量有三条来路：题目直接给、两个平面法向量叉乘、从「平行 / 垂直」这句话里读出来。配上四张夹角公式、两张位置关系表，考试里直线部分的题基本就都在射程内了。新授课见 曲面方程 平面方程 直线方程，姊妹页（平面）见 【黑板】平面及其方程。

一、三种式子，一张速查卡

直线部分的开场和平面部分一模一样：先把「用方程表示一个图形」这件事办完。老师的原话是：下面我们看一下直线，首先我们这里讲的直线是空间的直线——我们之前学的都是平面上的直线。注意这个前提，因为后面每一个「没想到」的结论，根子都在「空间」这两个字上。

定义 · 直线的三种表示
一般式
两个平面方程联立，也就是用大括号把两张平面的方程括起来。两个曲面相交得曲线，两个平面相交得直线——「书的书脊」就是这么来的。
{A1x+B1y+C1z+D1=0A2x+B2y+C2z+D2=0
点向式（对称式）
过点 P0(x0,y0,z0)、方向向量 ⃗s=(m,n,p) 的直线：它把「一个点 + 一个方向」直接写成了式子。
参数式
把点向式的三个分式统统令成同一个参数 t，也就是把 x、y、z 都写成 t 的函数。

三种式子的地位并不平等，老师说得很清楚：我们在做题的时候用的比较多的是点向式，我们的书也叫对称式方程。为什么？因为一般式只是「直线的出身」，点向式才是「直线的身份证」——它把决定直线的两样东西（点、方向）明明白白摆在式子里，一眼就能读出来。

核心公式 · 点向式（对称式）
x−x0m=y−y0n=z−z0p

老师的记法是一句话：你先把这个减这个点——x 减 x0、y 减 y0、z 减 z0 先写完，然后比上、等于、比上、等于、比上，方向向量写在分母上。

推导只有两行，但值得扫一眼：在直线上再取一点 P(x,y,z)，那么向量 P0P⃗=(x−x0,y−y0,z−z0) 与方向向量 ⃗s 平行；而「两个向量平行」在坐标语言里就是对应坐标成比例（【黑板】数量积与向量积 的核心翻译）——写成分式，就是点向式。

还有一条约定俗成的记号要记牢，老师专门点了一下：方向向量我们都是用 ⃗s 来表示的，永远都是用 ⃗s；法向量都用 ⃗n——这是个约定俗成的，你最好是用这个标号，你用其他的标号我们不认识。这条记号在整章里都没变过：看到 ⃗s 就想「平行」，看到 ⃗n 就想「垂直」。

为什么方向向量是「不唯一」的，而这件事反而帮了我们

老师说这一段时连着问了两次同一个问题：那有同学又有问题了——老师啊，你看这条直线，我沿着那是个方向向量；我朝这边是不是也是个方向向量啊？我这个方向向量取这么长是个方向向量，我取这么长是不是也是个方向向量啊？答案是：方向向量不唯一。

把这句话翻译成做题的自由度，有两条：

  • 方向可以反。(4,−1,−3) 与 (−4,1,3) 描述的是同一条直线。所以算完叉乘觉得数字难看，可以整体变号。
  • 长度可以缩。叉乘出来是 (6,3,−12)，就取 (2,1,−4)——往后每一步的分母都小了一截。这是本页例 8 里老师当场做的事：t 算出来带七分之几，向量是 (−127,67,−247)，提出公因子 67 之后取 (−2,1,−4)，干净得多。

同理，直线上的点也不唯一。老师用例 3 演示时，他求出的点和课本给的点完全不一样，他对着镜头说：老师你求错了？老师你点求错了——直线上的点是不是唯一呀？——不唯一，两个都对。所以答案是点向式时，别拿自己的答案去跟课本的答案死磕「一不一样」，要检查的是「点在不在线上、方向对不对」。

写法上有唯一一处「和平时不一样」的地方，老师专门示范了一遍：这个点向式大家在写的时候其实是很痛苦的，我们没太写过这种仨式子一块写的式子——你最好刚开始学的时候仿照我的写法：这个点呢，你先把这个「点减坐标」的式子捣鼓完了。也就是说，先把三个 −x0、−y0、−z0 抄成套，再回头把方向向量填到分母上；反过来做，很容易把某一项的方向向量填错位。

例 1求过点 (1,2,3)、且以 ⃗s=(−1,2,4) 为方向向量的直线方程，并写出它的参数式。

思路：点有了、方向向量有了，先套点向式，再令三个分式等于 t 得参数式

先写点的三个差（这一步单独做完，别急着写分母）：

x−1,y−2,z−3

再把方向向量放分母，得到点向式：

x−1−1=y−22=z−34

令三个分式都等于 t，逐个解出 x、y、z，就是参数式：

{x=1−ty=2+2tz=3+4t(t∈R)

老师说参数式的一个额外好处是：参数式方程它有个好处——x、y、z 三个坐标都有了，那这样的话就相当于那个点有了。t 的系数就是方向向量，这是参数式自带的赠品，读一遍就能验算。

这一步最容易错：分母上的 0 不是「无意义」

老师主动把这个坑挑明了：假设过一个点是 (1,1,1)，它的方向向量是一个 (1,0,0)，沿着这个方向过一点的直线——方向向量是放分母的，1、0、0——耶？零又放分母了，是不是错了呀？答案是：没问题，它那个零放分母其实是一样的——它不是个分母，它其实是一个比。

点向式里的三条式子，本质上是三个比相等，而不是三个分数相除。所以 z−z00 完全合法，它说的是「z−z0 与 0 成正比」，而唯一能这么成正比的数就是 0 ——也就是z=z0：这条直线的高度被钉死了。

错的说法：「分母为零，这个式子里这一项要删掉」。
对的说法：「这一项照写，它表示对应的那个坐标恒等于 z0」。

把三个分式统统令成 t，就得到参数式：

{x=x0+mty=y0+ntz=z0+pt(t∈R)
老师解释参数式用的那个比喻

他把 t 讲成了「3D 打印机」：如果 t=0，是不是就是 (1,2,3) 那个点啊？如果 t 越来越大，x、y、z 是不是也越来越大？他就从一个点开始，用那个 3D 打印机——里边装上那种材料，然后就开始打印，从这个点开始得得得得，打印出来好多点，是不是连起来就是一条直线啊？

他还补了另一半：这个 t 如果取负的，x、y、z 是不是越来越小啊？那就朝那个方向嘚嘚嘚地去打印。所以参数式里那个 t∈R 是不用写的限制之外的全部自由——它把「直线无限延伸」这件事，变成了「t 随便走」。

例 2已知直线的参数式为 x=2,y=t,z=1+t，求它的点向式。

思路：反着来——把 t 一条条「解出来」，凑成三个「等于 t」的式子

这一步有个必须处理的意外：x=2 里没有 t。老师说：这个地方有个问题，x 没有 t，它必须有 t，你不能没有 t，那就是 0。所以要先把 x 改写成「x−2=0⋅t」：

t=x−20,t=y,t=z−1

再把它们连起来，得到点向式：

x−20=y−01=z−11

对照着读：点 = (2,0,1)，方向向量 = (0,1,1)。老师特意问了一句：如果按照你刚才那个写法，那个点和方向向量你能写出来吗？写不出来啊；那我这样搞了以后能写出来不？点、方向向量是不是很清楚啊？

这道题的价值在于它把「分母为零」从「怪事」变成了「工具」：方向向量的某个分量为零，正好对应参数式里某个坐标是常数。

二、一般式 → 点向式：求方向向量的标准套路

这是直线部分最重要的一个机械动作。题目给的是两个平面，要求化成点向式，缺两样东西：方向向量和一个点。方向向量完全不用愁，因为它有一条现成的公式：

核心公式 · 交线的方向向量

由两个平面联立决定的直线，其方向向量等于这两个平面法向量的向量积：

⃗s=⃗n1×⃗n2

理由：交线同时躺在两张平面上，所以它与两个法向量都垂直；而「同时垂直于两个向量的向量」，正是它们的叉乘。

老师说这一步是「比较确定的」：这个题比较确定的是求它的方向向量——这个平面和这个平面相交形成了这条直线，我们现在要求这个直线的方向向量 ⃗s，那么就是要它的法向量和它的法向量，你能看出来这个方向向量和这个法向量、和这个法向量是不是都垂直啊？所以用它两个的法向量做这个叉乘，这个是比较明确的。

他还顺手给自己画的立体图打了个预防针，这句话对空间想象力一般的同学很有用：我这个立体图画的还可以哈——所以我们现在就是这部分的题目，大家画的图都是帮助大家想象的，都不是很严格，你换一个图和我画的可以不一样。草图和课本答案可以不一样，只要「哪个向量垂直于哪个面」这件事没画错就行。

例 3把一般式 {x+y+z+1=02x−y+3z+4=0 化为点向式与参数式。

思路：两件事——先叉乘求方向向量，再拿坐标平面切一刀找点

第一步，读法向量。系数直接读，不用算：⃗n1=(1,1,1)，⃗n2=(2,−1,3)。

第二步，叉乘。

⃗s=⃗n1×⃗n2=|⃗i⃗j⃗k1112−13|=(4,−1,−3)

逐项核对（中间项取负，这是叉乘唯一的失分点）：第一项 |11−13|=3+1=4；第二项 |1123|=3−2=1，取负得 −1；第三项 |112−1|=−1−2=−3。老师看了一眼结果：我一看这个结果呢，也没什么特别好化简的了，所以 ⃗s 我就取做这个。

第三步，找点。令 x=0 代回去，两个方程立刻瘦成两个未知数：

{y+z+1=0−y+3z+4=0

两式相加消掉 y：4z+5=0，所以 z=−54；再代回第一式得 y=14。于是得到点 (0,14,−54)。老师口算完自己也笑了：再整一下 y，口算倒还行。

第四步，写式子。

x−04=y−14−1=z+54−3

令三个分式等于 t，得到参数式：

x=4t,y=14−t,z=−54−3t

老师把他的结果和课本一对：不好意思，和我求的不一样——老师你点求错了？其实没求错。后面他解释得很清楚：直线上的点是不唯一的，方向向量也不唯一，所以最后你的答案是不唯一的。这道题的正确答案是一整族，不是一个。

「令 z=0」为什么不是万能的

老师在这一段问了一个非常好的问题：我现在有个问题哈——所有的题目，令 x=0、令 y=0、令 z=0，一定都能求出来吗？

他的答案是：其实绝大部分的题目都可以，但是这个地方我请大家仔细地想一想：x=0 到底是个什么东西？——x=0 是一张平面（也就是 yOz 面）。所以「令 x=0」这个动作的几何含义是：拿一张坐标平面去「切」这条直线，切出来的那一点就是我们要的点。

那么问题来了：如果这条直线与这张平面平行呢？老师用了一个特别形象的比喻：假设这个阴影的面就是现在黑板的这个面，这条直线呢就很笔直地站在了这个黑板的前面、和这个黑板是平行的——那么这个黑板（x=0 的面）和我在的这条直线有交点吗？没有。所以在这种情况之下令 x=0，你能求出交点吗？求不出来。

错的说法：「求直线上的点，随便令一个变量为零就行」。
对的说法：「三条坐标平面里总有一张切得上——试 x=0，切不上换 y=0，再切不上换 z=0」。

那为什么三张里一定有切得上的？老师给的理由很干脆：x=0、y=0、z=0 是三个坐标平面——空间中的一条直线，你怎么样能让这个直线和这三个面都不相交？你是直线，不可能啊，它总得和一个面相交啊。（严格地说，与某一根轴平行的直线仍会与另两张坐标面相交，所以三选一总能成功。）

三、两条直线：夹角与四种位置关系

两条直线的夹角，用的是它们的方向向量。这一点和两个平面的夹角（用两个法向量）是同构的，理由也一样：直线无限延伸，夹角只有一个客观的值，所以公式的分子要加绝对值。

定义 · 两直线的夹角
cosθ=|⃗s1⋅⃗s2||⃗s1||⃗s2|,θ∈[0,π2]
空间里的两条直线，为什么先要强调「不一定相交」

老师这一段的开场很关键：两个直线的夹角，这个是比较好理解的——但是呢这个是空间的直线，这个和我们平面的其实不太一样的，因为我们画图只能这么画。其实空间的直线的夹角就像我这两个胳膊一样，它的确有个夹角，但是呢它是不一定相交的啊，这点大家注意。

这句话纠正的是一个从平面几何带过来的直觉。在平面里，「两条直线相交」是默认的；在空间里，两条直线可以根本不在同一个平面上——它们照样有夹角，因为夹角是由方向决定的，与位置无关。这正是「用方向向量的夹角来定义两条直线的夹角」这句话的必要性所在。

顺着这条线，后面「垂直」也有了新情况。老师说：空间的直线它不一定相交啊，你比方说我这个胳膊和这个胳膊的确是垂直的，但是它根本就不在一个平面上——所以我们这里说的垂直，一般指的是异面垂直。他紧接着补上边界：那老师那我们俩就刚好相交、就在一个平面上呢？这个也行啊，所以异面垂直也可能是同面垂直。所以「垂直」这个词在空间里是纯粹的向量条件（点乘为零），不附带「有没有交点」的暗示。

位置的分类一共四种，老师是按「哪些是特殊的」这个语气讲的：

位置关系向量条件还要补一步吗
平行（不重合） ⃗s1∥⃗s2，即对应分量成比例 要：再验证一条上的点不满足另一条
垂直 ⃗s1⋅⃗s2=0 不用；可以是异面垂直，也可以是同面垂直
重合 ⃗s1∥⃗s2，且一条上的点也满足另一条 方向平行只是前提，判断的关键在「点」
斜交（既不平行也不垂直） 方向不平行，且不属于上面几种 还可以细分：相交的叫共面斜交，不交的叫异面

老师讲「重合」时把判断逻辑说得特别直白：两个直线重合是什么意思呢？首先它两个的方向向量仍然是平行的，这个没问题吧——那怎么能知道两个直线是重合的呢？判断方法就是任取一条直线上的一点，它也符合另一条直线，就叫两个直线是重合的。所以「方向平行」和「重合」差着一步：平行只比方向，重合还要比点。

第四种他讲得很随意，但里面藏着一个重要的词：因为咱们不管讲的垂直、平行还是重合，这都是很特殊的；人家这两个直线就是斜不拉几的，对吧，那就斜交呗。那么斜交呢大家也注意，它其实是有两种：一种是异面的，一种是同面的。——也就是说，不平行不垂直，只排在「斜」这一档里；至于它们到底相交还是异面，是另一个问题。老师对出题偏好说得很实在：斜交呢我们出题一般不太出，我们比较喜欢出这种比较特殊的。

例 4求直线 L1:x−11=y−4−4=z+31 与 L2:x2=y+2−2=z−1 的夹角。

思路：读出两个方向向量 → 先判平行、再判垂直 → 都不是就套夹角公式

方向向量直接读分母：⃗s1=(1,−4,1)，⃗s2=(2,−2,−1)。

第一步，先看平行。老师把这个顺序说成了条件反射：这两个方向向量大家拿到手以后，第一眼你先判断它是怎么着——平行？因为平行是不是用肉眼可以看出来？就是它的对应分量是不是成比例。1:2、−4:−2=2:1、1:−1，三组比例根本不一致，不平行。

第二步，再看垂直。口算点乘：

⃗s1⋅⃗s2=1⋅2+(−4)⋅(−2)+1⋅(−1)=2+8−1=9≠0

不是零，所以不垂直。老师算到这一步的评语是：不是平行、不是垂直，就是斜交，那这个夹角咱就正常地求呗。

第三步，套公式。模长：|⃗s1|=1+16+1=32，|⃗s2|=4+4+1=3。

cosθ=932⋅3=992=12=22⟹θ=π4

老师算完还自嘲了一句「算出来是一个二分之根二，所以 θ 就是一个四分之派」——这类题只要方向向量读对，剩下的全是口算；真正容易翻车的是第一步读分母时漏抄负号。

四、直线与平面的夹角：四个夹角公式里唯一的 sin

这是全讲最需要「看图」的一处。先看定义。老师讲的时候是先描述做法、再给严格定义：假设这是一个平面，有这么一条直线。首先这个直线和平面的夹角，它其实有一个严格的定义——从这条直线上任意取一点，向这个平面作垂线，这不是有一个垂点吗？有一个交点，然后你把它连起来，那么这儿的夹角其实就是直线和平面的夹角。

定义 · 直线与平面的夹角

直线与它在该平面上的投影之间的夹角，叫直线与平面的夹角。

sinθ=|⃗s⋅⃗n||⃗s||⃗n|,θ∈[0,π2]

用的是直线的方向向量 ⃗s 与平面的法向量 ⃗n——一边一个。

为什么这里换成 sin，而不是继续用 cos

关键在于 ⃗s 与 ⃗n 的夹角和我们要的那个角互余。老师是一边画三角形一边说的：我们要求的直线与平面的夹角 θ 是这个角，但是这个向量（⃗s）和这个向量（⃗n）的夹角是不是这个角啊？——它们两个是互余的。我要求的是 θ，那么因为 s 和 φ 是互余，所以 sinθ 是不是就等于 cosφ 啊？

翻译成一句更好记的话：法向量垂直平面，所以「方向向量与法向量的夹角」总比「线面角」多出 90∘；换成 sin 就是把多出来的那 90∘ 补回去。

老师对这个公式还有个可爱的小插曲：不好意思，我这个公式和我们书上的刚好反了——然后他给出了本节最有价值的一句总结：到目前为止，我们讲的所有的夹角公式都是 cos，只有这个地方是 sin。四个夹角公式里，唯一的 sin 就是「线面角」，这条就是最好的记忆点。

老师在这一段把四个夹角公式当场总结了一遍（他还顺手吐槽自己：「我们老师有一个很神奇的技能——嘴上说话跟手上写字一点都不影响」）。这张表就是他为考试准备的那张：

算谁的夹角用哪两个向量公式分子加绝对值？
两个向量 ⃗a、⃗b 自己 cosθ=⃗a⋅⃗b|⃗a||⃗b| 不加（允许钝角，θ∈[0,π]）
两个平面 两个法向量 ⃗n1,⃗n2 cosθ=|⃗n1⋅⃗n2||⃗n1||⃗n2| 要加
两条直线 两个方向向量 ⃗s1,⃗s2 cosθ=|⃗s1⋅⃗s2||⃗s1||⃗s2| 要加
直线与平面 方向向量与法向量 sinθ=|⃗s⋅⃗n||⃗s||⃗n| 要加，且换成 sin

这张表其实只要三句话就能重建：第一，只有「两个向量」的夹角可以取钝角，所以只有它不加绝对值；图形之间的夹角都是眼见的锐角，一律加。第二，看每个图形手里握着哪个「专属向量」——平面有法向量、直线有方向向量，两个平面就用法向量对法向量，两条直线就用方向向量对方向向量，一个平面加一条直线就一边一个。第三，只有线面角是 sin。老师最后的建议是：有时候这个脑子比较容易晕，所以到时候你画个图自己演示演示就行。记不住就画图，这是这一章最可靠的自救方式。

五、直线与平面：位置关系与交点的套路

直线与平面的位置关系一共四种，老师是按「画个图马上就能理解」的顺序讲的。前两种的判据只差一个字：

位置关系向量条件怎么区分最后两种
垂直 ⃗s∥⃗n（方向向量与法向量平行） —
平行（且不相交） ⃗s⊥⃗n，且直线上的点不满足平面方程 两种都满足 ⃗s⊥⃗n，唯一的分辨办法是拿直线上一点代进平面方程看成立不成立
直线在平面上 ⃗s⊥⃗n，且直线上的点满足平面方程
斜交 ⃗s 与 ⃗n 既不平行也不垂直 —

老师推导前两条时反复强调「这地方有点绕」：直线和平面垂直，这不很清楚吗？平面的法向量不是这个吗，直线的方向向量不是这个吗，那他俩不平行不就完了吗？所以就是它的方向向量和它的法向量是平行的——这地方有点绕，为什么呢？它的方向向量和它的法向量是平行，那么这个直线和这个平面是不是垂直啊？——方向向量垂直于平面，直线才垂直于平面；而「方向向量 ⊥ 平面」翻译过来就是「方向向量 ∥ 法向量」。这里出现的「垂直变平行」，正是本页最容易绕晕的一处。

接着是那对「长得一样」的情况：直线与平面平行、和直线落在这个平面上，这两种情况我都分不开啊——好办，直线在平面上，那就是你从直线上任取一点，它也符合那个平面的要求：你从这个直线上取一点，带到那个平面的方程里头去，是不是能成立就行。

一个必须改掉的说法：「直线与平面重合」

老师说这是他刚教书时也犯过的错：直线落在平面上，老师啊，那你直接就说他俩重合不就完了吗？——不可以的，不能这么说。原因是他打的那个比方：

两根直线能重合，两个平面也可以重合，但是直线和平面不能叫重合，他两个不是对等的概念。为什么呢？平面是整个平面，直线呢就一根线——简单来说是平面大还是线大？平面大。你说俩东西重合，他俩得是一样的才能重合，对吧；人家有俩同学是双胞胎长得一模一样，他俩一样，但他起码两个都是人啊。

所以：两条直线可以叫重合，两个平面可以叫重合，直线与平面不能叫重合，只能说「直线在平面上」。老师说这是个会被扣分的说法。

还有一句相关的边界：老师，那这个直线落在了平面上，这个直线和这个平面是不是也是平行的？——不用。我们说的直线与平面平行，就是在平面外头和它平行，它本身就把直线落在平面上这种情况排除掉了。「平行」这两个字在答题口径上已经隐含了「不在平面上」。

接下来的内容就是「有交点怎么办」。老师在这里给出了本页最实用的一条经验，而且特意要求大家形成条件反射：只要它这个题目是有交点的题，就都是参数式方程。什么叫交点呢？一个直线和一个平面相交是不是交点啊？两个直线相交是不是交点啊？——就是只要这个题目说是和交点有关系，那么它就是参数式方程。

解题模板 · 凡是「交点」，就把点设成 t
  1. 把直线写成参数式：所有点统一记成 (x0+mt,y0+nt,z0+pt)。
  2. 把题目那个几何条件（在平面上 / 与某向量垂直 / 距离是多少）代进去，列出一个关于 t 的一元方程。
  3. 解出 t，代回参数式得到具体坐标；如果需要方向向量，就用两个点相减。

老师说这个形式的价值就在于：参数式方程它有个好处——x、y、z 三个坐标都有了，那就相当于那个点有了。

例 5求过点 (1,−2,4) 且与平面 2x−3y+z−4=0 垂直的直线方程。

思路：把「直线垂直于平面」直接翻译成「方向向量取成法向量」

题目条件里的每个字都已经给出了需要的向量：平面的法向量读出来是 ⃗n=(2,−3,1)；而「直线垂直于平面」⟺ ⃗s∥⃗n。所以根本不用算：

⃗s=⃗n=(2,−3,1)

点有了、方向向量有了，上点向式：

x−12=y+2−3=z−41

老师对这类题的评价是太简单了，因为条件都摆在明面上。这道题的关键不在计算，而在认出「垂直」两个字就是「⃗s 取成 ⃗n」。

例 6求与两平面 x−4z=3、2x−y−5z=1 的交线平行，且过点 (−3,2,5) 的直线。

思路：不求交线，只求它的方向向量——两个法向量叉乘

题目说「与交线平行」，那么交线的方向向量就是所求直线的方向向量；而交线的方向向量就是两个法向量的叉乘。先读法向量：⃗n1=(1,0,−4)，⃗n2=(2,−1,−5)。

⃗s=⃗n1×⃗n2=(1,0,−4)×(2,−1,−5)=(−4,−3,−1)

取个顺眼的方向，三个分量一起变号，得 (4,3,1)。老师说：这个负号咱其实就可以不取了——反正方向反过来还是同一条直线。

x+34=y−23=z−51
这道题示范了「不求交线也能用交线」

题目只给了两个平面，连交线上的一个点都没有给，也不需要。因为我们只需要方向：方向由两个法向量完全决定。这就是「一般式 → 方向向量」那条结论最典型的用法——把「求交线」这种复杂任务，降级成一次叉乘。也正因为如此，老师认为这条路比课本用「平面束」的方法简单得多。

例 7求直线 x−21=y−31=z−42 与平面 2x+y+z−6=0 的交点。

思路：有交点 → 立刻写参数式，把「直线上的点」变成 t 的表达式

令三个分式都等于 t，直线上的任意一点就是 (2+t,3+t,4+2t)。交点当然也在这条直线上，所以把它代进平面方程，就只剩下一个 t：

2(2+t)+(3+t)+(4+2t)−6=0
4+2t+3+t+4+2t−6=5+5t=0⟹t=−1

代回参数式：

x=2−1=1,y=3−1=2,z=4−2=2⟹(1,2,2)

老师提醒这类题做完要顺手拿铅笔在草图上比划一下，看交点是不是落在「合理的位置」上。这个动作不花钱，但能挡住大部分符号错误。

例 8求过点 A(2,1,3) 且与直线 x+13=y−12=z−1 垂直相交的直线。

思路：交点不知道，但它一定在已知直线上——用参数式把它设出来，用「垂直」列方程

老师先澄清了一个容易含混的地方：我们刚才讲那个两个直线垂直，它其实是异面垂直的；但是「过这个点与这个直线垂直」，人家说了是垂直是不是还相交啊？它相交就有交点，就是同面垂直——这地方大家一定要搞清楚。换句话说，「垂直相交」比单纯的「垂直」多了两个条件：在同一个平面里，而且确实交于一点。

第一步，把交点设出来。设交点为 B，它在这条已知直线上，所以

B=(−1+3t,1+2t,−t)

第二步，写出 AB⃗。终点减起点：

AB⃗=(−3+3t,2t,−t−3)

第三步，用「垂直」列方程。AB⃗⊥⃗s1=(3,2,−1)，点乘为零：

3(−3+3t)+2⋅2t+(−1)(−t−3)=14t−6=0⟹t=37

老师在这里停顿了一下：写到这一步，要是哪个地方数算错了，有同学眼尖的能给我说哈，因为有时候容易有这个笔误。——这类题的脾气就是 t 算错一次、后面每一步都跟着错，所以这一步必须回头验一遍（9t+4t+t=14t ✓，−9+3=−6 ✓）。

第四步，求出方向向量。把 t=37 代回 AB⃗：

AB⃗=(−127,67,−247)∼(−2,1,−4)

「∼」这一步就是老师那套实战习惯：这玩意儿这么麻烦呢，咱一般也不直接用——能提个 67 没问题吧？那它的方向向量咱就用这个呗。提出公因子之后，分母全变成了小整数。

第五步，写点向式。

x−2−2=y−11=z−3−4

老师核对了一下课本答案，说和我书上答案是一样的，并且给出了一个明确的态度：这个题我们比较建议大家用我这个方法做——书上那个方法好像是用的平面做的垂直，那个方法不如我这个简单。

这类题的两个常见失手

一、把「垂直」写成了「AB⃗ 与方向向量平行」。垂直是点乘为零，平行是分量成比例，两个字差得很远。这题用的是点乘。

二、方向向量和点弄混。最后写点向式时分子里要放的是 A（或 B）的坐标，别把刚算出来的方向向量当成点填进分子。（本页例 8 的分子是 (2,1,3)，分母才是 (−2,1,−4)。）

六、点到直线的距离

平面那一节给的是「点到平面的距离」，直线这边自然也有一个对应物，而且它和叉乘的关系更直接。点 P0 到过点 P1、方向向量为 ⃗s 的直线的距离是

d=|P1P0⃗×⃗s||⃗s|
这个公式凭什么成立

把 P1P0⃗ 与方向向量 ⃗s 看成两条边，它们张成一个平行四边形。这个平行四边形的面积有两种算法：

  • 用叉乘：面积 =|P1P0⃗×⃗s|；
  • 用底乘高：底取 |⃗s|，那么高就是——点 P0 到这条直线的距离本身。

两种算法算的是同一块面积，让它们相等、再除以底 |⃗s|，就得到上面的公式。所以它不是新公式，而是「叉乘就是面积」这一条几何事实的直接推论。

对照记忆：点到平面的距离用「数量积 + 法向量的模」，点到直线的距离用「叉乘 + 方向向量的模」——一个打点乘、一个打叉乘，和「平面管垂直、直线管平行」的分工完全一致。

七、留个尾巴：平面束（了解即可）

课本最后有一个内容叫平面束（老师念作「平面数」），他明确表态：这个东西其实我们做题的时候用的相对来说比较少一些，既然书上有，咱就给大家解释解释基本原理。

平面束是什么

一条直线既然由两个平面相交得到，那么过这条直线的平面有无穷多张，它们构成了一个「平面束」。用式子写出来就是：

(A1x+B1y+C1z+D1)+λ(A2x+B2y+C2z+D2)=0

λ 取遍实数（它是个可变的常数），就得到全部过这条直线的平面。

老师用的比喻是书的「书脊」：什么东西呢？就是我这个书搭的这个书，我们叫书脊，这个地方书脊就是一条直线。这条直线是确定的，现在问通过这条直线的所有平面怎么表示？是不是跟我翻书这个过程还有点像？那所有的平面就是过这条直线，那蹭蹭蹭蹭地这样画，你看这个书的这么多页，是不是就相当于过这个书脊的所有的平面啊？

他还给了一个用平面束做的例题：把一条直线投影到平面 x+y+z=0 上，求投影直线。思路是——先从直线造出平面束，在无穷多张平面里只挑出「与已知平面垂直」的那一张：把平面束的法向量 (1+λ,1−λ,−1+λ) 与 (1,1,1) 点乘等于零，解出 λ=1，代回去就得到那张垂直平面；最后用这张平面与已知平面联立，就是投影直线。

老师说得很坦诚：我是不太用这个东西，大家稍微了解了解。所以要记的不是公式本身，而是它示范的那个思想：当「过某条线的平面族」能用一个参数写出来时，就可以用「再加一个条件」把参数定死。这个思想在后面的多元函数里还会以别的形式出现。

本页易错清单（六条）

一、把分母为零当成错。z−z00 是合法写法，意思是 z=z0；它对应参数式里 z 是常数。

二、以为答案唯一。直线上的点不唯一、方向向量也不唯一（可以整体变号、可以约公因子）；别拿自己的答案去和标准答案逐字比对，要验「点在不在线上、方向对不对」。

三、叉乘的中间项忘了取负。例 3 里 ⃗n1×⃗n2 的中间分量是 −(3−2)=−1，不是 1。算完顺手验一下：叉乘结果与两个法向量的点乘都应该是零。

四、以为「令 z=0」一定能求出点。那只在直线与 xOy 面不平行时成立；换 x=0 或 y=0 再切。

五、把「直线垂直于平面」写成 ⃗s⊥⃗n。正确的是 ⃗s∥⃗n（方向向量与法向量同向）；⃗s⊥⃗n 是平行或在平面上。

六、说「直线与平面重合」。两者不对等，只能说「直线在平面上」。

记忆入口 · 一眼回忆

一句话

直线靠方向向量：找点、找 ⃗s、套点向式；有交点就改写成参数式。题目里所有「平行 / 垂直 / 夹角」的要求，都是在告诉你 ⃗s 是什么。

一条链

两平面一般式 联立→ ⃗s=⃗n1×⃗n2→ 坐标面切一刀 得点→ 点向式 → 参数式

三个式子

  • 一般式：两个平面方程联立——出生证明，看不出点和方向。
  • 点向式：x−x0m=y−y0n=z−z0p——答案写它，分母可以是 0，不必化简。
  • 参数式：x=x0+mt、y=y0+nt、z=z0+pt——一有交点就用它，t 的系数就是 ⃗s。

四个夹角公式怎么记

  • 平面用法向量、直线用方向向量；两个对两个，一个对一个。
  • 只有「两个向量」的夹角不加绝对值（可以取钝角），其余三种都加。
  • 只有线面角用 sin——因为方向向量与法向量互余。

位置关系（两条判据 + 一条口径）

  • 两直线：⃗s1∥⃗s2 判平行（再验点判重合）；⃗s1⋅⃗s2=0 判垂直（可以是异面垂直）。
  • 线与面：⃗s∥⃗n 判垂直；⃗s⊥⃗n 时要代点区分「平行」与「在平面上」。
  • 「平行」在答题时就是不重合、不在平面上；重合就说重合。

两个坑

  1. 「令 z=0」不是万能——直线与 xOy 面平行就切不上，换一根轴再切。
  2. 答案不唯一：点可以换、方向可以反向或约公因子；验证的方法是「点在线上 + 方向匹配条件」，不是逐字比对。

  • 直线垂直于平面 ⟺ ⃗s∥⃗n；直线平行于平面 ⟺ ⃗s⊥⃗n
  • 两直线夹角用 cos、线面夹角用 sin——四个夹角公式里唯一的例外
  • 「直线在平面上」不能说成「直线与平面重合」
  • 点向式的分母可以为 0（表示该坐标恒定），但这不等于这一项要删掉
