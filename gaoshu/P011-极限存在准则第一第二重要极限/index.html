P011极限存在准则·第一第二重要极限

一句话核心

两条「准则」告诉你极限为什么一定存在：夹逼准则说「被两个同极限的量夹在中间，你只能跟着收敛」，单调有界准则说「单调又跑不出去，必然停在界上」。而两个重要极限 limx→0sinxx=1 与 limx→∞(1+1x)x=e 则是做题时直接调用的硬底牌——第二重要极限最反直觉：「趋于 1 的无穷次方」不是 1，是 e。

夹逼准则：被两头夹住，你跑不掉

00:00第一个准则管「极限存不存在」。设三个数列 xn≤yn≤zn，并且 limn→∞xn=limn→∞zn=A，那么中间的 yn 也被逼着收敛到 A。老师给这个准则起了个很形象的名字：

视频原话（大意）

老外管这个准则叫「汉堡定理」——你看，上面一片面包、下面一片面包，中间夹着肉。你拿着的其实是两片面包，朝嘴里塞的时候，那块肉不也被塞进去了吗？这就是把两头一夹，中间的也跟着进来了。

我自己在数学分析课上喜欢叫它「破脸」——中间这位被两边两个人抱着一起跳河，他能不跟着跳吗？他被逼着也收敛了。

03:44再想想那个画面：假设有一个人，另外一个人抱住他，再一个人也抱住他——这三个人是一串的。旁边那两个人「咚」跳到河里去了，中间这个人是不是也「咚」跟着跳进去了？因为他俩抱着他嘛。三个人，挺形象的。

04:34这个动作你们看着眼熟吧——中国人民大学的校徽就是三个人。我昨天还专门查了一下，他这个手的位置刚好在腰这个位置，特别像。人家校徽的意思大概是「人民、人文、文明」，结果被宋老师玩坏了。

这三个比喻其实在说同一件事 04:34

汉堡是「两片面包夹住肉」，跳河是「两个人夹住中间那位」，校徽是「三个人叠在一起」——外壳不同，内核都是「两边被同一个东西锁住，中间就失去了自由」。数学上那个「同一个东西」就是两条外侧曲线收敛到同一个 A。这也是为什么下面的准则里，条件写成 limxn=limzn=A 而不是「都收敛」：两头必须收敛到同一个值，夹逼才成立。

准则一 · 夹逼准则（数列）

若 xn≤yn≤zn 对充分大的 n 成立，且 limn→∞xn=limn→∞zn=A，则

limn→∞yn=A

04:34夹逼准则对函数极限同样成立：若 f(x)≤g(x)≤h(x)，且 limf(x)=limh(x)=A，则 limg(x)=A。

为什么夹逼在「做题」里其实很难

05:33老师泼了一盆冷水：夹逼准则想法简单、用起来极难。难点不在结论，而在「放缩」。你给 yn 找上下界 xn,zn 不难，难的是放缩完之后，这两头的极限得刚好相等。如果一头极限是 1、另一头是 5，那中间那位是几？不知道。所以夹逼真正能用，必须放得「上界和下界的极限重合」——这往往是整道题最吃功力的地方。

第一重要极限：被反复使用的底牌

06:05接下来是最重要的干货。第一重要极限：

第一重要极限
limx→0sinxx=1

11:48几何上这样理解：x→0 时，弧长和它的正弦、正切近似相等。课本用夹逼准则严格证明（用的是下面的不等式），但做题时我们只认结论。

课堂插曲：「你 X 轴和 Y 轴刻度不一样啊」08:18

前面我讲 sinx 的图像要画得缓一点，有同学就说了：「老师，你 X 轴跟 Y 轴刻度是不一样的呀！」——你说得也没问题，但我们通常画图，X 轴跟 Y 轴的刻度其实是一样的。第二点，你要是真按刻度不一样去画，那你画 y=x 的时候不就顺手把它画得很斜了吗？因为你默认 y=x 就是 45 度。所以为什么要强调 sinx 这个图得画准一点呢——画不准，后面比较大小的时候就会傻眼。

09:54这段插曲最后落到实处，就是「x 与 sinx 在原点附近几乎重合」这句话：直线 y=x 与曲线 y=sinx 都快相交了，越靠近 0 挨得越近，所以两者之比的极限是 1。但这份「几乎重合」只在 x→0 时成立——随便换个过程，比如 x→1，sin11≈0.84，已经差出一大截了。

一个必须圈出来的不等式

11:08课本在证明时给出一个后续会反复用到的重要不等式（在 0<x<π2 时成立）：

sinx<x<tanx

11:48它说：在原点附近，sinx 最小、tanx 最大、x 夹在中间。把 x 除过去就得到 sinxx<1 以及 xtanx=sinxx⋅1cosx 等关系。后面算 1−cosxx2 时，这个不等式就是底子。

这个不等式从哪来：一块饼的面积

11:02课本的证明并不神秘，它只是把上面那个不等式翻译成「三块图形谁大谁小」。在单位圆里取一个圆心角 x（先设 0<x<π2），圆上有两点 A、B，再让 OB 延长出去、与过 A 的切线交于 T。于是图里出现三块层层包住的图形：三角形 OAB、扇形 OAB、三角形 OAT，一块比一块大。

证明的收尾：把两头都逼到 1 11:02

有了 sinx<x<tanx（0<x<π2，三边都是正数），两边同除 sinx，不等号方向不变：

1<xsinx<1cosx

再取倒数（正数取倒数也翻转不等号）：

cosx<sinxx<1

现在看两头。当 x→0+ 时 cosx→1（这是后面要单独证的结论），而右边恒等于 1。两边夹着一个 sinxx，两头极限都是 1，于是由夹逼准则 sinxx→1。

还差 x→0−。这一步不用重新推：cosx 是偶函数，sinxx 也是偶函数（分子分母同时变号），所以左极限与右极限同一个值，x→0− 时同样趋于 1。合起来就是 limx→0sinxx=1。

老师对这段证明的态度 06:54

他在课上明说了：「这个证明啊，和我们后面的做题没有太多的关系，所以这个地方我们也不想讲了。」他只要求做一件事——把 sinx<x<tanx 那个不等式圈出来，「我们后边儿是能用到的」。所以这份证明的定位是：知道结论从哪来、知道那个不等式是干活的工具，就够了。

例 113:28求 limx→0tanxx、limx→01−cosxx2、limx→0arcsinxx。

第一题：把 tanx 拆成 sinxcosx：

limx→0tanxx=limx→0sinxx⋅1cosx=(limx→0sinxx)⋅(limx→01cosx)=1⋅1=1

14:50这里又用到了上一节的「把极限分进去做」——前提是这两块的极限都存在（sinxx→1、cosx→1 都存在），所以合法。

第二题：分子分母同乘 1+cosx 来凑 sin：

limx→01−cosxx2=limx→0(1−cosx)(1+cosx)x2(1+cosx)=limx→0sin2xx2(1+cosx)=12

第三题：换元。令 t=arcsinx，则 x=sint；当 x→0 时 t→0。于是

limx→0arcsinxx=limt→0tsint=1
tanxx→1 为什么值得单记

17:18它和第一重要极限是「双胞胎」：后面讲等价无穷小时，tanx∼x 就是由它而来。所以这一题的结论不用每次重推，直接当已知用。

sinxx 必须配 x→0 才对

11:02老师特意把这一点拎出来强调：「如果 X 它不是趋于零的，它俩的极限就不是一。」最典型的反例是

limx→∞sinxx=0≠1

这里 sinx 有界（|sinx|≤1），1x 是无穷小，由上一页那条「有界 × 无穷小仍是无穷小」立刻得到 0。所以看到 sin□□，第一件事是确认 □→0：是，才等于 1；不是，就得另找办法（比如 □→∞ 时通常直接得 0）。

顺手记一个倒数形式 11:02

把第一重要极限整个取倒数，就得到它的「姊妹版」：

limx→0xsinx=1

道理很简单：sinxx→1，而 1≠0，所以它的倒数也趋于 1。这个形式在 sin 跑到分母上的时候特别好用，比如例 3 第二题里的 2xsin2x。

单调有界准则与第二重要极限

19:09第二个准则管「数列极限存不存在」的另一种情况：

准则二 · 单调有界准则

单调且有界的数列必有极限。具体来说：单调递增又有上界，则必收敛于它的上界；单调递减又有下界，则必收敛于它的下界。

20:08老师的直觉解释很朴素：一个数如果一直往大了走（单调增），同时又被一个「天花板」挡着出不去（有上界），那它只能越靠越近地停在天花板上——那个天花板就是极限。同理，一直往下走又被地板托住，就停在地板处。

这条准则最值钱的地方：不必先知道极限是几

回头看看求极限的常规流程：你总得先猜到答案是 A，再去验证它。可有些数列——尤其是递推式定义的，比如 xn+1=2+xn——你根本猜不出极限是谁，怎么办？单调有界准则开了一条绕路：只要证出「单调」和「有界」这两件事，就直接断定极限存在；至于它等于几，可以留到后面再算（通常是设极限为 A，在递推式两边取极限得到方程，再解出 A）。这就是它和夹逼准则的分工：夹逼准则要求你先把上下两条曲线都准备好，而单调有界准则只要求你检查两个性质。

第二重要极限（三种形式）

以下三者都等于 e（e≈2.71828，是个二点几的常数）：

limn→∞(1+1n)n=e,limx→∞(1+1x)x=e,limx→0(1+x)1x=e
它为什么等于 e：单调有界准则的功劳 22:38

以数列 an=(1+1n)n 为例，证明就两步，正好用上刚学的准则：

  1. 先证有界。把 (1+1n)n 按二项式定理展开，每一项都可以放大：组合数那部分被 nk 压小之后，剩下的是 1k!，而 1k!≤12k−1。把放大后的各项加起来，得到一串等比数：1+1+12+14+⋯<3。所以 an<3，它被 3 挡在天花板下。
  2. 再证单调。把 an 与 an+1 的展开式逐项对比，会发现 an+1 的每一项都不小于 an 的对应项，而且末尾还多出一项正的。所以 an 单调递增。
  3. 下结论。单调递增 + 有界 ⇒ 极限存在。把这个极限定义成 e。

老师课上没讲这套展开（他嫌麻烦），而是直接开了张 Excel 把数值摆出来：「n 取 1,2,3… 一直朝下顺，把这个公式双击抄下来，你会发现随着 n 的增大是 2.6 几。」

n125101001000n→∞
(1+1n)n22.252.48832.59372.70482.7169e≈2.71828

读这一行数字：n 从 1 一路涨到 1000（涨了一千倍），函数值却只从 2 挪到 2.7169，越涨越慢、明显被压住了——这就是「有界」在数值上的样子；而它每一步都在涨、从不回落，就是「单调」。两件事凑齐，准则才敢下结论。注意 n=10 时才是 2.5937，这就是老师说的「2.6 几」；想看到 2.718 得取到十万量级（n=100000 时约 2.71827），所以靠硬算只能看趋势，真正的结论仍要靠准则。

记忆模板（与第一重要极限对称）

把趋于 0 的整块记作 □（且 □≠0），则

lim□→0(1+□)1□=e

配套的口诀就是老师那句：「这里（底数里）是个啥，外边（指数）就得是它的倒数。」底数的形状必须是「1 加上一个趋于 0 的量」，指数则要凑成那个量的倒数；底数里是加号还是减号都无所谓。

最反直觉的一点：「1 的无穷次方」不是 1

24:29老师说这是大家最容易想不通的地方。看见 (1+1x)x，你会想「1 的多少次方还不都是 1 吗？」——错。这里的底数 1+1x 不是真的 1，而是「趋于 1」；指数 x 又在「趋于无穷」。于是这是「趋于 1 的无穷次方」，结果是一个全新的数 e，既不是 1、也不是无穷。它和「1 的无穷次方」是两种完全不同的东西。

例 227:06求 limx→∞(1−1x)x 与 limn→∞(1−3n)5n。

思路：把底数凑成「1 + 某物」，让指数正好是某物的倒数

老师给了一句口诀：「这里（底数里）是个啥，外边（指数）就得是它的倒数。」

第一题：底数里是 −1x，所以它的「倒数」应当是 −x。于是

(1−1x)x=[(1+−1x)−x]−1→e−1=1e

第二题：底数里是 −3n，它的「倒数」应当是 −n3。于是

(1−3n)5n=[(1−3n)−n/3]−15→e−15

29:11注意 5n=(−15)⋅(−n3) 这一步的配凑：先把指数写成「倒数 −n3」的某个倍数，剩下的倍数 −15 就挂到最外面当幂。如果底数里是加号也照此办理，口诀同样成立。

第三题（x→∞ 的变形）：limx→∞(1+2x)x。底数里是 2x，它的倒数是 x2；而外面的 x=2⋅x2，多出来的系数 2 就挂到最后当幂：

(1+2x)x=[(1+2x)x2]2→e2

第四题（x→0 的变形）：limx→0(1−3x)1x。底数里是 −3x，它的倒数是 −13x；而外面的 1x=(−3)⋅(−13x)：

(1−3x)1x=[(1−3x)−13x]−3→e−3

两道题的动作完全一样：先认出「底数里的那个量」，再让指数凑成它的倒数，凑出来的多余系数一律甩到最外层当幂。结果 e2≈7.389、e−3≈0.0498——都是「趋于 1 的无穷次方」型，答案却一个大于 2、一个小于 1，再次证明它绝不是 1。

第一重要极限也要「灵活用」

36:43第二重要极限三种形式要记牢；第一重要极限也一样——它真正的用法是：「一个整体趋于 0 时，sin(整体)整体→1」。那个「整体」可以换成任何趋于 0 的式子，不一定要是 x。

记忆模板

把趋于 0 的整块记作 □，则

lim□→0sin□□=1

□ 可以是 x2、5x、6x、甚至 x−1（只要它趋于 0）。

例 336:43求 limx→0sin5x3x、limx→0sin6xsin2x、limx→11−x2sin(x−1)。

第一题：希望分子分母都是 5x，所以把 3x 配成 35⋅5x：

limx→0sin5x3x=limx→0sin5x5x⋅53=53

第二题：分子分母各自凑出整体：

limx→0sin6xsin2x=limx→0(sin6x6x⋅2xsin2x⋅6x2x)=1⋅1⋅3=3

39:15老师的话：「想要什么就写什么，写完再消。」先把想要的整体写出来，再乘上适当的系数消掉多余部分。

第三题（x→1 的变式）：这里 x→1，但 x−1→0，所以把 x−1 当作那个整体。先分解：

1−x2=(1−x)(1+x)=−(x−1)(1+x)
limx→11−x2sin(x−1)=limx→1[−(1+x)⋅x−1sin(x−1)]=−(1+1)⋅1=−2

40:54关键提醒：第一重要极限要求「整体趋于 0」，这里整体是 x−1→0，完全满足；虽然 x 本身趋于 1 而不是 0，但公式只盯那个整体。

两个重要极限为什么是「硬底牌」

它们是少数几个直接给值的极限工具：不用因式分解、不用抓大头，认出形式就能出答案。后面等价无穷小替换（把 sin□ 换成 □）其实是第一重要极限的「速记版」——但加减项里不能用替换，重要极限却总能硬上。所以重要极限是更底层的保底手段。

柯西准则（了解）

31:03课本在最后还给了柯西极限存在准则：数列 {xn} 收敛的充要条件是，对任意 ε>0，存在 N，使得当 m,n>N 时 |xm−xn|<ε。33:53换句话说，收敛不要求你预先知道极限是谁，只要求「后面的项彼此靠得足够近」。老师明确说这条用得很少，知道它存在、知道它是「充要条件」即可，不必当成考点。
