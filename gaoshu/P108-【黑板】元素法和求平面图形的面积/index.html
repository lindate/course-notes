P108【黑板】元素法和求平面图形的面积

一句话核心

本页是第 12 章（定积分）的复习精讲课。元素法（微元法）不是新公式，而是一种理解顺序：先截一小片、把弯的当直的，再积分加起来。求面积只剩两句口诀——上减下、右减左；真正分胜负的是那个判据：竖着切还是横着切，哪种段数少选哪种。新授课细节见 定积分应用（求面积） 微元法。

一、知识速查：元素法（微元法）四步

00:00微元法不是一套新公式，而是一种理解顺序。定积分的定义是"分割—近似—求和—取极限"；微元法把它倒过来看：先在任意一点处截下一小片，把弯的当直的、把变的当不变的，写出这一小片的量 dU，最后从 a 积到 b。

以面积为例：定积分 ∫abf(x)dx 里，f(x)dx 就是"底乘高"——底是小段的长度 dx、高是这一点的函数值 f(x)。它算出来的是一个小长方形的面积，和真实的曲边小条有一点误差（长方形的顶是平的，真实曲线的顶是弯的）。但当小片越来越细，误差就越来越小，于是把所有小长方形的面积加起来，就得到了曲边梯形的面积。这一小片就叫微元。

  1. 01:53定变量：选 x 还是 y 作积分变量。这一步决定了后面是写一个积分还是两个、轻松还是痛苦。
  2. 写微元：在任意一点取一小片，把它近似成长方形，写出这一小片的量，例如面积微元 dS=底×高。
  3. 定上下限：积分范围就是图形在所选变量上的"投影"——竖切看 x 的范围，横切看 y 的范围。
  4. 积分：把微元从下限积到上限，就是所求总量。
02:54求面积时微元法明明"多余"，为什么还要讲

因为面积本来就是定积分的出身——直接套 X 型、Y 型公式更快，微元法在这里只是"绕远路"。老师仍然保留它，是为了给后面的应用打底：求旋转体体积、极坐标下的面积、弧长、变力做功、水压力，这些题目没有现成公式可套，唯一能依靠的就是"先想清楚一小片长什么样"。所以现在的目标不是背公式，而是练出取微元的手感——把"这一小片是什么形状、面积（或体积）的表达式怎么写"变成条件反射。

二、知识速查：求面积的四种类型与两条公式

04:09求平面图形面积一共有四种典型情形，前两种用 x 作积分变量，后两种用 y。标准流程永远是四步：画图 → 找交点 → 定上下（或左右）→ 定积分。

类型图形面积公式
一（X 型）单条曲线与 x 轴围成S=∫abf(x)dx
二（X 型）上下两条曲线围成S=∫ab(上−下)dx
三（Y 型）单条曲线与 y 轴围成S=∫cdg(y)dy
四（Y 型）左右两条曲线围成S=∫cd(右−左)dy
归一成两句口诀

X 型（竖条）：图形在 x∈[a,b] 上，上边界 y=f上(x)、下边界 y=f下(x)，则

S=∫ab(f上(x)−f下(x))dx

Y 型（横条）：图形在 y∈[c,d] 上，右边界 x=g右(y)、左边界 x=g左(y)，则

S=∫cd(g右(y)−g左(y))dy
10:14为什么是"上减下"，而且一定为正

把大块减小块的思路先摆出来：S=∫ab上dx−∫ab下dx，合并就是 ∫ab(上−下)dx。因为在 [a,b] 上上曲线确实在下曲线上方，所以每一小段里"上减下"都是正的，加起来自然是正面积。

这一点很关键：上减下与曲线在 x 轴上方还是下方无关。两条曲线都在 x 轴下方时，∫ab上dx 和 ∫ab下dx 都是负数，但"上减下"仍然是正的差值。所以做题时只要找对上下关系，不必去管函数值的符号。Y 型同理：右减左永远为正，因为右边的 x 比左边大。

11:14「X 型 / Y 型」这两个名字怎么来的

不是课本上的标准名词，是老师为了方便而起的名字，但非常形象：拿一支笔竖直着（笔杆与 x 轴垂直）、从左往右扫过整个图形，若贯穿全过程的上下边界都各只有一条曲线，就属于 X 型；把笔平着拿（笔杆与 y 轴垂直）、从下往上扫，看左右边界，就属于 Y 型。后面讲二重积分时，这两个名词还会继续用，是理解积分次序的关键，所以现在就要建立画面感。

13:47X 型 / Y 型的选用判据（本页最重要的一句）

哪种切法让积分段数最少，就选哪种。

  • 竖着切扫到一半，上边界突然从一条曲线换成另一条，那就必须拆成两个积分；而横着切从头到尾左右边界都固定，一个积分就够——这时果断用 Y 型。
  • 反过来，如果横着切要拆两段、竖着切只要一段，那就用 X 型。
  • 如果两者都只一段（例如两条曲线只交于两点、且左右也各只有一条边界），那么优先用 X 型——因为用 Y 型时要把每条边界的 x 都反解成 y 的函数，容易在代数上翻车。

三、题型套路一：经典对比题（竖切两段、横切一段）

例 1（经典对比）15:35求由 y=3x、y=x2、y=1 围成的图形面积。

思路：先画图找交点，再用 Y 型；最后用 X 型验证一遍

第一步，找交点。三对曲线联立：y=3x 与 y=x2 交于 (0,0)；y=3x 与 y=1 交于 (13,1)；y=x2 与 y=1 交于 (2,1)。所以这块区域是一个以 (0,0)、(13,1)、(2,1) 为顶点的三角形。

第二步，用 Y 型（最省事）。把两条边界都改写成 x 关于 y 的函数：由 y=3x 得左边界 x=y3；由 y=x2 得右边界 x=2y；而 y 的范围是 [0,1]：

S=∫01(2y−y3)dy=∫015y3dy=[5y26]01=56

17:07第三步，用 X 型验证。竖着切，上边界在 x=13 处更换，所以要拆两段：第一段 x∈[0,13]，上边界 y=3x、下边界 y=x2；第二段 x∈[13,2]，上边界换成 y=1、下边界仍是 y=x2：

S=∫01/3(3x−x2)dx+∫1/32(1−x2)dx=536+2536=56

两段分别是 536 与 2536，加起来正好 56，与 Y 型一致——说明两种切法算的是同一块面积，但工作量差了一倍。

这一步最容易漏

用 X 型时只写一段 ∫02(3x−x2)dx，或者忘了在 x=13 处换掉上边界。竖着切一旦上（下）边界在中途换了曲线，就必须分段。判断的方法很简单：把笔竖直着从图形的左端扫到右端，边界换了几次，就写几个积分。另外 Y 型也有一个必做的动作——把所有边界都改写成 x=⋯(y)，忘记改写直接拿 y=2x 去积就全错了。

例 2（反向对比）18:55求由 y=sinx、y=x2 与直线 x=1 围成的图形面积。

思路：这次正好反过来——竖切一段、横切两段

X 型（竖切）很轻松。在 [0,1] 上恒有 sinx≥x2（可验证 x=1 时 0.8415>0.5），上边界 y=sinx、下边界 y=x2，只有一段：

S=∫01(sinx−x2)dx=[−cosx−x24]01=34−cos1

Y 型（横切）就要拆两段。20:15让笔平着从下往上扫：y 从 0 升到 sin1≈0.841。当 0≤y≤12 时，左边界是反函数 x=arcsiny、右边界是直线 x=2y；当 12≤y≤sin1 时，右边界换成竖直线 x=1、左边界仍是 x=arcsiny：

S=∫01/2(2y−arcsiny)dy+∫1/2sin1(1−arcsiny)dy=34−cos1

两段之和确实等于 X 型的一个积分，但第二段里出现了 arcsiny，积分麻烦得多；而且分段点 y=12 恰好是"右边界由 x=2y 换成 x=1"的转折处——这个 y 值正是点 (1,12) 的纵坐标，来自直线 y=x2 与 x=1 的交点。

这两道题放在一起，才叫掌握了判据

例 1 是"X 型两段、Y 型一段"，例 2 是"X 型一段、Y 型两段"——它们把判据的两个方向都走了一遍。结论不是"哪个更好"，而是"先画图、再数段数"。而且注意例 2 里还有一个隐形门槛：用 Y 型时左边界要写成反函数 arcsiny，这本身就是信号——当反解会引出反三角函数时，能不用 Y 型就不用。

四、题型套路二：书上两道例题

例 321:15求由 y2=x 与 y=x2 围成的图形面积。

思路：两条曲线关于 y=x 对称，两种切法都只一段，选更顺手的 X 型

22:18y2=x 的上半支是 y=x（下半支 y=−x 不参与围成），与 y=x2 的交点由 x2=x 解得 x=0 与 x=1，即 (0,0)、(1,1)。在 [0,1] 上 x≥x2，所以用 X 型"上减下"：

S=∫01(x−x2)dx=[23x3/2−x33]01=23−13=13

这题用 Y 型也是只一段（左边界 x=y2、右边界 x=y，y∈[0,1]），结果同样是 13。但老师建议首选 X 型：用 Y 型时要把 y=x2 反解成 x=y、把 y2=x 反解成 x=y2，反解这一步是很多同学出错的地方，能避开就避开。

例 423:28求由 y2=2x 与 y=x−4 围成的图形面积。

思路：联立求交点，然后判断——这是 Y 型的典型标志

求交点。把直线写成 x=y+4 再代入抛物线：y2=2(y+4)，即 y2−2y−8=0，分解得 (y−4)(y+2)=0，所以 y=4 或 y=−2，对应点 (8,4) 与 (2,−2)。

判断切法。开口朝右的抛物线与一条斜线围成的区域，左右两条边界天然都是 x 关于 y 的显式表达：左边界是抛物线 x=y22，右边界是直线 x=y+4。用 Y 型横着切，从 y=−2 扫到 y=4，左右边界一路不变——只需一段：

S=∫−24(y+4−y22)dy=[y22+4y−y36]−24=18
为什么这里绝对不要用 X 型

用 X 型得先看 x 的范围 [0,8]，然后拆两段：x∈[0,2] 时上下边界是抛物线的下半支 y=−2x 与上半支 y=2x；x∈[2,8] 时上边界换成直线 y=x−4。而且一开始还要处理 ±2x 的符号，复杂度立刻翻倍。识别信号：只要图形的左右边界都是"x= 关于 y 的式子"，就果断用 Y 型。

五、题型套路三：椭圆面积

例 528:16求椭圆 x2a2+y2b2=1 的面积（a,b>0）。

思路一：对称性 + X 型 + 四分之一圆的结论

29:10椭圆关于两条坐标轴都对称，所以只算第一象限那一块、再乘 4。第一象限里把 y 解出来：y=b1−x2a2，x∈[0,a]，于是

S=4∫0ab1−x2a2dx=4⋅ba∫0aa2−x2dx

而 ∫0aa2−x2dx 正是半径为 a 的四分之一圆面积 πa24（见 【黑板】定积分的换元法与分部积分法 例 2）。代进去：

S=4⋅ba⋅πa24=πab

顺手记一个结论：当 a=b=R 时退化为圆，πab=πR2，对得上。

思路二：参数方程 + 点火公式（课本的另一种写法）

30:31椭圆的参数方程是 x=acost、y=bsint（高中内容）。把它代进面积微元 dS=ydx（取第一象限那一小片，底是 dx、高是 y）：

S=4∫0aydx=4∫π/20bsint⋅(−asint)dt=4ab∫0π/2sin2tdt

用 n=2 的偶数链点火公式：∫0π/2sin2tdt=12⋅π2，也就是 π4。于是 S=4ab⋅π4=πab，与思路一一致。

这题最容易错的地方：t 的上下限

认为 "x 从 0 到 a，所以 t 从 0 到 π2"。31:34错了。x=0 时 acost=0，t=π2；x=a 时 cost=1，t=0。所以 t 的限是"从 π2 到 0"，上下限是反的！这时交换上下限会多一个负号，正好与 dx=−asintdt 带来的负号相消，最终才写成 ∫0π/2。不少人凭"直觉"直接写 0→π2，恰好凑对了结果，但过程是错的——参数换元时，上下限必须老老实实由 x 的端点反解，不能靠想当然。

六、易错清单

  • 上减下写成下减上：口诀是"上减下"（Y 型是"右减左"），不是"谁的函数值大减谁"。这一条与曲线在 x 轴上方还是下方无关。
  • 忘找交点或交点算错：上下边界的切换点来自联立方程，必须先联立、再积分。
  • X 型中途换边界却不分段：拿笔竖直扫一遍，换几次边界就写几个积分（例 1、例 2）。
  • 该用 Y 型却硬撑 X 型：左右边界都是 x=g(y) 显式（开口朝左右的抛物线最典型）时，Y 型通常短得多（例 4）。
  • Y 型时忘了把边界改写成 x=⋯(y)：直接用 y=f(x) 去积就全错了。
  • 椭圆/圆面积硬做三角代换：先想几何结论（四分之一圆、四分之一椭圆），别一上来就换元（例 5 思路一）。
  • 参数方程换元时上下限靠"直觉"：必须由 x 的端点反解出 t，可能出现"上限小于下限"的正常情形（例 5 思路二）。
  • 把"面积"与"定积分"混为一谈：∫abf 带符号，f≤0 时是负的；而用"上减下"算出来的面积永远是正的（见 【黑板】定积分的定义与性质）。
记忆入口 · 一眼回忆

一条链

画图 找交点→ 定切法 X 型或 Y 型，比段数→ 上减下 / 右减左 积分

要背的

  • 微元法四步：定变量 → 写微元 → 定上下限 → 积分。
  • X 型：S=∫ab(上−下)dx；Y 型：S=∫cd(右−左)dy。
  • 选用判据：哪种切法段数少选哪种；都只一段时优先 X 型。用 Y 型必须把边界改写成 x=⋯(y)。
  • 椭圆面积 πab；∫0aa2−x2dx=πa24（四分之一圆）。
  • ∫0π/2sin2tdt=π4（点火公式偶数链，n=2）。

三个动作

  1. 拿到题目先画图 + 联立求交点，交点是把区域切段的地方。
  2. 拿笔竖直扫一遍、平着扫一遍，数各要几段，再决定 X 型还是 Y 型。
  3. 写公式前再确认一遍：是"上减下"还是"右减左"？边界是不是都换成了积分变量的函数？

两个坑

  • X 型中途换边界却只写一个积分 —— 例 1 会算错。
  • 该用 Y 型（左右都是 x=g(y)）却硬用 X 型 —— 白写两段，还要处理 ±。
