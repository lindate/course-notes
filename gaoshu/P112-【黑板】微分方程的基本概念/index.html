P112【黑板】微分方程的基本概念

一句话核心

本页是定积分应用之后的复习精讲课。微分方程的定义只有一句——含有未知函数的导数或微分的方程；它带来的观念转变是：以前解方程求一个数，现在要求的是一整条函数。要钉死三件事：阶（看求了几次导，不看几次方）、通解（任意常数个数 = 阶数）、特解（初始条件把常数定死）。新授课细节见 微分方程的基本概念。

一、从一个引例说起

00:00课本的例子是：一条曲线过点 (1,2)，并且在任意一点处它的切线斜率都等于 2x，求这条曲线的方程。关键只有一句：切线斜率就是导数 y'。所以条件翻译成数学语言就是

y'=2x

00:00这个式子就叫一个微分方程。01:25求 y 很好办，两边同时求不定积分：∫y'dx=∫2xdx，得

y=x2+C

注意那个 C——不定积分一定要加任意常数，所以解出来的不是一个函数，而是「y=x2 上下平移出的整整一族函数」。这个解叫通解；又因为方程里只出现 y'，它是一阶方程，通解里正好一个任意常数。

02:18题目还多给了一条：曲线过 (1,2)，即 x=1 时 y=2。代入得 2=1+C，所以 C=1，于是

y=x2+1

这个「过 (1,2)」就叫初始条件；03:18常数解出来后的解，就叫特解。老师说：微分方程的所有相关的概念，其实在这个例子里边我们都给大家讲到了。

为什么「求一个数」变成了「求一条曲线」

你以前解过的 2x+3=7、x2−5x+6=0，出现的是数，答案是一个数或几个数。而 y'=2x 里出现的是 y'，也就是 dydx——它是「y 变化得多快」的度量。

要给它找出 y，你交付的不是一个数，而是一整条函数，甚至一整个函数族。而且解的过程中每做一次不定积分就冒出一个任意常数，所以「答案有多少自由度」不由你决定，而是被方程的阶数提前定死——这正是下面「阶」与「通解」之间的关系。

二、知识速查：定义与阶

04:28定义 · 微分方程

含有未知函数的导数或者微分的方程，叫做微分方程。两个关键词：未知函数（习惯写成 y）和它的导数或微分（y'、y''，或 dy、dx）。出现这两样里的任意一样，它就是微分方程。至于 y 本身、x、ex、sinx 能不能出现——都能，随便怎么出现都行。

05:39接着是阶：微分方程中出现的未知函数的导数的最高阶数。按字面理解很容易：出现 y' 是一阶，出现 y'' 是二阶。05:39比如 y'''+y''+y'+x=ex 最高到三阶。但老师立刻补了一句：这个阶啊，大家在做题的时候，他有时候会给你一些干扰的因素。06:23他一个接一个地设陷阱，排成表最省事：

方程里出现的式子几阶？为什么
y'''+y''+y'+x=ex三阶最高出现 y'''，求了三次导
y'y''=x二阶相乘不是相加，最高是 y''
(y'')3=x二阶三次方只是「怎么组合」，最高仍只求两次导
y''y'=x二阶y'' 与 y' 是两个不同的函数，约不了
y2+y'=x一阶y2 是「y 的二次」，它根本没求导
为什么「阶」必须盯着导数，而不是盯着次数

最容易错的一条是：y2 是「二次」，不是「二阶」。它们一字不差，意思完全不同：「二次」说的是 y 自己被乘了几次，「二阶」说的是 y 被求了几次导。

为什么阶要定义成「导数求了几次」？因为阶是为「答案里有几个任意常数」服务的。方程里最高出现 y''，就意味着要把「求导」倒推两次，也就是做两次不定积分；每做一次不定积分，就冒出一个任意常数。所以一阶方程有 1 个常数、二阶有 2 个、n 阶有 n 个。

而「要积几次分」完全由最高阶导数决定，跟 y 有没有平方一点关系都没有——因为 y 本身不是靠积分求出来的，y'' 才是。记住这个动机，上表五行就不必死记。

三、解、通解、初始条件、特解

解
07:58把函数代进方程，如果方程恒成立，就叫方程的一个解。老师说这个「没什么特别好说的」。
通解
第一，它是解；第二，解里含任意常数，而且常数个数恰好等于方程的阶数。两条都满足才是通解。
初始条件
10:13题目额外给的「某点处的值」，例如 x=1 时 y=2。它一定是题目给的，你只管照着代。
特解
把初始条件代入通解、把常数都解出具体数值之后得到的解。里面不含任何任意常数。

09:21二阶通解的样子，老师说主要记这一条：y=C1cosx+C2sinx 里有 C1、C2 两个独立常数，正好等于阶数 2，所以是通解。他还划了范围：我们后边求的我们最高啊就是求二阶微分方程。所以常数最多两个，数起来不累。

「几个任意常数」和「需要几个初始条件」是同一件事

n 阶方程要积 n 次分，每次积分贡献一个常数，所以通解里恰好有 n 个任意常数。反过来想更有用：通解里有 n 个待定常数，就需要 n 个条件才能全部定下来。而「y 在 x0 处的值」是一个条件，「y' 在 x0 处的值」是另一个。所以一阶方程只要一个初始条件（如 y(1)=2），二阶方程要两个（如 y(0)=1 且 y'(0)=2）。题目给几个条件，不是随手写的，是被「常数个数 = 阶数」掐死的。

四、检验一个函数是不是解：标准动作三步

07:58这类题没有技巧，动作是固定的：把函数求导到方程里出现的最高阶，然后把 y、y'、y'' 一起代进方程左端，看能否化简成 0。

例09:21验证 y=C1cosx+C2sinx 是二阶方程 y''+y=0 的解，并说明它是通解还是特解。

第一步，求到二阶。C1、C2 是常数，按系数处理。cosx 求导得 −sinx、sinx 求导得 cosx，所以 y'=−C1sinx+C2cosx；再求一次得

y''=−C1cosx−C2sinx

第二步，代入左端。

y''+y=(−C1cosx−C2sinx)+(C1cosx+C2sinx)=0

同类项两两相消，恒等于零，所以它确实是解。这里的相消对任意的 C1、C2 都成立，才说明它是一整族解，而不只是某一条曲线。

第三步，判断通解还是特解。看两个数字：方程的阶数是 2（出现 y''）；解里含 C1、C2，常数个数也是 2。两个数一致，所以是通解。

这一步最容易含糊

只要看见「含 C1、C2」就说是通解。表述不完整：通解的定义有两个条件——是解，且常数个数等于阶数。严格做题要把两个数字都写出来：「方程是二阶的，解中含两个任意常数，二者一致，故为通解」。

还有一个隐藏要求：两个常数必须真的「独立」。C1cosx 与 C2sinx 是两个不同的函数，怎么改系数也拼不出对方。若解写成 Ccosx+Ccosx，实际只有 1 个常数，就不是二阶方程的通解了。

五、易错清单

  • 把「次数」当「阶数」。y2 是「y 的二次」，不是「二阶」；(y'')3 仍是二阶。阶只看求了几次导。
  • 看到 y'y''=x 就把阶数加起来。相乘、相除、乘方只是「怎么组合」，不改变阶数。
  • 以为 y''y' 能约成一阶。y'' 与 y' 是两个不同的函数，约不了——仍是二阶。
  • 只说「含 C1、C2」就断定是通解。要补齐两个数字：阶数 = 常数个数。
  • 初始条件给错个数。一阶一个、二阶两个；少给不是题目出错，是被「常数个数 = 阶数」掐死的。
  • 求不定积分时忘了加 C。通解里那些常数全部来自「不定积分要加常数」这条规矩，漏一个，通解就降级成特解。
记忆入口 · 一眼回忆

一句话

微分方程 = 含有未知函数的导数或微分的方程。以前求一个数，现在求一条函数（一族曲线）。

四个关键词

阶
未知函数导数的最高阶数。看求了几次导，不看几次方
通解
是解，且常数个数 = 阶数
初始条件
题目给的「某点处的值」；n 阶方程要 n 个
特解
代入初始条件、常数全解出来之后的解，不含任意常数

一条链

阶数 n 看最高阶导数→ 积 n 次分 得 n 个常数→ 通解 含 n 个任意常数→ n 个初始条件 定死常数→ 特解

要背的

  • y'=2x 通解 y=x2+C；代入 y(1)=2 得特解 y=x2+1。
  • y''+y=0 通解 y=C1cosx+C2sinx，常数个数正好等于阶数。
  • 通解对应的曲线族叫积分曲线，初始条件从中挑出唯一一条。

两个坑

  1. 把次数当阶数。y2 是「y 的二次」，不是「二阶」。
  2. 「是解」不等于「是通解」。还要再数一遍常数个数。
