P012无穷小的比较 · 等价无穷小替换

一句话核心

无穷小之间要比的不是「谁小」，而是谁趋于零更快。比完之后，最有价值的一件事出现了：在乘除的因式位置上，一个无穷小可以被它的等价无穷小直接换掉，极限不变。这一招让一大批极限题从「要硬凑重要极限」变成一眼出答案——但它有一条铁律：只能换因式，不能换加减项。

无穷小的比较，比的是什么

00:00上节课说，极限为 0 的量叫无穷小。那么 x、x2、sinx 在 x→0 时都是无穷小——都是往 0 跑，凭什么还要分个高下？

因为它们跑到 0 的「速度」差得很远。看两个例子：

limx→0x2sinx=0,limx→0x3x=0

两个极限都是 0，含义却完全不同。第一个式子说：分子比分母小得太多，x2 比 sinx 跑得快。第二个式子把 x3 和 x 约掉之后剩下 x2，极限是 0，所以 x3 比 x 跑得快。

01:49老师用了一个很直观的检验：取 x=0.1，那么 x3=0.001。本来就小的数，三次方之后小得离谱——这就是「趋于零更快」的意思。

五个定义，一张表装下

03:28设 α,β 是同一变化过程中的两个无穷小（也就是它们的极限都是 0），看 βα 的极限是几，就给 β 起不同的名字：

βα 的极限名称记号通俗理解
0 β 是 α 的高阶无穷小 β=o(α) β 跑得快得多
∞ β 是 α 的低阶无穷小 — β 跑得慢得多
C≠0（非零常数） β 与 α 同阶无穷小 — 速度相当，只差一个倍数
1 β 与 α 等价无穷小 α∼β 速度几乎一样
βαk→C≠0（k>0） β 是 α 的 K 阶无穷小 — 要用 αk 去比才对得上

06:58表里最要紧的一条关系是：等价无穷小是同阶无穷小的特例——同阶只要求极限是非零常数，等价只是把那个常数指定成 1。21:12那为什么还单独给它一个名字和记号？因为它用得太多了，值得单拎出来。

两个必须养成的习惯

一、说「谁是谁的高阶/低阶/同阶无穷小」时，必须写清楚 x 的变化过程。因为 x2x=x 在 x→0 时趋于 0（高阶），在 x→∞ 时趋于 ∞（低阶）——不写「x→ 什么」，这句话根本没有意义。

二、o(x) 是「比 x 高阶的无穷小」的记号，它不是一个零。04:28定义只说 βα→0，也就是 β 远远小于 α，并不是说 β=0。书写时注意 o 是小写斜体，别写成大圆圈，也别写成数字 0。

五个例子，把五种定义各走一遍

09:25只看定义是空的，走一遍例子才落地。下面五道都是课上讲的：

  1. x→0 时 3x2x→0，所以 3x2=o(x)：3x2 是 x 的高阶无穷小。
    这里的坑：算出 3x2x=3x→0，容易顺手写成「3x2=0」。它不是零，是「比 x 高阶的无穷小」——它本身仍然是个趋于零的量。
  2. n→∞ 时 1/n1/n2=n→∞，所以 1n 是 1n2 的低阶无穷小。
    10:08这里自变量换成了 n：n→∞ 时 1n 趋于 0，它同样是无穷小，只是变化过程写成 n→∞ 而不是 n→0。
  3. x→3 时 x2−9x−3=(x+3)(x−3)x−3=x+3→6，极限是非零常数，所以二者同阶。
    10:51能约掉 (x−3) 的理由要说清：x→3 但 x≠3，所以 x−3 趋于 0 却永远不等于 0，放在分母上没有问题。
  4. x→0 时 1−cosxx2→12，由 K 阶的定义（取 k=2），1−cosx 是 x 的二阶无穷小。
    12:38也可以说它是 x2 的同阶无穷小——两种说法都对，因为 1−cosxx2→12 是非零常数。「二阶（对 x 而言）」和「同阶（对 x2 而言）」是同一件事。
  5. x→0 时 sinxx→1（第一重要极限），所以 sinx∼x，二者等价。
    13:30所有等价无穷小公式都带着「x→ 什么」这个前提，用之前必须核对题目里的 x 是否真的趋向那个值。

例14:07证明：x→0 时 1+xn−1 与 1nx 是等价无穷小。

这道题的证明过程比较麻烦，课上没有展开——但这个结论必须记住，因为它是最常用的一族公式。把 n 取成具体数字就得到两个必背式：

1+x−1∼12x,1+x3−1∼13x

15:15规律是「几次根号就除以几」。做题时几乎不会遇到 n 次根号，基本都是平方根和立方根，所以这两个式子必须条件反射。

定理：等价无穷小 = 大致相等 + 一点点误差

定理

β∼α 的充要条件是

β=α+o(α)

也就是说：β 与 α 之间只差一个「比 α 高阶的无穷小」。

16:24这句话可以讲得很直白：既然 βα→1，那 β 和 α 就差不多大；但「差不多」不等于「相等」，中间那点差别是存在的，只是它比 α 小得多——用小 o 记下来。

证明的思路（必要性）

把 β−α 拿去比 α：

β−αα=βα−1→1−1=0

极限是 0，按高阶无穷小的定义，β−α=o(α)，移项即 β=α+o(α)。

19:15反过来（充分性）同样直接：若 β=α+o(α)，则 βα=1+o(α)α→1，所以 β∼α。

这个定理的价值不在两个变换本身，而在它给了一个更好用的视角：以后看到 ∼，脑子里就翻译成「等于它，再加一个可以忽略的高阶小量」。学泰勒公式时，这个视角会变成主要工具。

27:07带负号的那一半怎么记

表里有一半是带负号的（cosx−1、1−1+x、1−ex……）。看着像两倍工作量，其实只要判断「谁减谁」，符号自己就出来了：

  • cosx 的取值在 −1 到 1 之间，永远不超过 1。所以 1−cosx≥0 为正，cosx−1≤0 为负。
  • ex 在 x>0 时大于 1。所以 ex−1 为正，1−ex 为负。
  • 1+x 在 x>0 时大于 1。所以 1+x−1 为正，1−1+x 为负。

一句话：谁大谁写在前面。所以真正需要背的只有一半，另一半靠符号当场写。

25:54老师还给了另一种理解方式——从图形上看：y=arcsinx 与 y=x 在原点附近几乎重合；1−cosx 是把 −cosx 的图像向上挪一格（挪完正好在原点与 x 轴相切）；ln(1+x) 是把 lnx 向左挪一格；ex−1 是把 ex 向下挪一格。挪完之后，它们全都在原点附近贴着 y=x。

替换定理：为什么因式位置可以换

定理 · 等价无穷小替换

设在同一变化过程中 α∼α'，β∼β'，且 limβ'α' 存在，则

limβα=limβ'α'

一句话：在商的分子、分母位置上，可以把整个无穷小换成它的等价无穷小，极限不变。

32:21证明的思路很简单，把「多出来的」乘进去再约掉：

βα=ββ'⋅β'α'⋅α'α

三块分别看：ββ'→1（因为 β∼β'），α'α→1（因为 α∼α'），中间那块就是 β'α'。三个相乘，极限等于中间那块。前后的因子都趋于 1，等于白搭——这就是替换合法的全部理由。

为什么这件事很重要

34:27以前算 sin2xsin3x，标准做法是「硬凑」第一重要极限：上下各凑出 sin2x2x 与 sin3x3x，再约掉。现在直接替换：

limx→0sin2xsin3x=limx→02x3x=23

一步到位。这就是老师说「第一重要极限以后很少用」的原因——它能做的大部分事，等价替换做得更快。

整体替换：公式里的 x 是一个「位置」

36:27这一条极易被忽略，但极其有用。公式 sinx∼x 里的两个 x，不是「字母 x」，而是「一个趋于零的整块东西」。只要那个东西趋于 0，就可以整体塞进去：

原式因为替换成
x→0 时 sin3x3x→03x
x→1 时 sin(1−x)1−x→01−x
x→0 时 ln(1+x2)x2→0x2
x→0 时 ex3−1x3→0x3

判断标准只有一条：把它整体看成一个数，这个数是不是趋于 0？是就能换，不是就不能换。比如 x→0 时 sin(1+x) 就不能换，因为 1+x→1 而不是 0。

四道课堂例题

例 139:10求 limx→0tan2xsin5x。

x→0 时 2x→0、5x→0，整体替换：

limx→0tan2xsin5x=limx→02x5x=25

例 2求 limx→0sinxx3+3x。

分子换掉，分母不换也可以——替换定理允许只换一个。这里分母本身很好提公因式：

limx→0sinxx3+3x=limx→0xx(x2+3)=limx→01x2+3=13

例 340:11求 limx→01+x23−1cosx−1。

这题同时考「整体替换」和「负号公式」，两步都要小心：

  • 分子：1+□3−1∼13□，这里 □=x2，所以分子 ∼13x2。
  • 分母：cosx−1∼−12x2（用的是带负号的那一个）。
limx→01+x23−1cosx−1=limx→013x2−12x2=−23

最常错的就是分母的符号。cosx 不超过 1，所以 cosx−1 是负的，等价无穷小必须带负号；写成正的，答案就变成 23 了。

例 444:28求 limx→0xsinxx2 与 limx→0xtanx(ex−1)arcsinx(1−cosx)。

第一题：sinx 是分子里的一个因式，可以换。替换后分子变成 x⋅x=x2，与分母约掉，极限为 1。

第二题：整个式子全是乘除，所以每一块都可以换。

limx→0xtanx(ex−1)arcsinx(1−cosx)=limx→0x⋅x⋅xx⋅x22=limx→0x3x32=2

关键观察：只换「乘除关系里的整块」，最前面那个孤立的 x 不必动（它已经是最简形式了）。

铁律：只能换因式，不能换加减项

这是本节课最重要的警告

分子或分母里相乘、相除的部分（因式）可以替换；相加、相减的部分一般不能替换。

46:30原因就藏在替换定理里：定理说的是「商的分子分母可以同时换」，βα 中的 α、β 各自是一整个因子。而加减项不构成一个因子，替换之后各自留下的「高阶误差」并不会被约掉，它们会积累起来，把结果改掉。

反例47:29求 limx→0tanx−sinxx3。先看错误做法。

错解

x→0 时 tanx∼x，sinx∼x，于是

limx→0tanx−sinxx3=limx→0x−xx3=0(这是错的)

这是错的。分子是相减，不是因式，两个替换留下的误差被一起抹掉了——真相是分子并不比 x3 小，它和 x3 是同阶的。

正确做法

先把 tanx 化成 sinxcosx，于是 tanx−sinx=sinxcosx−sinx=sinx(1−cosx)cosx。这时分子变成了乘积，就能放心换：

tanx−sinx=tanx(1−cosx)∼x⋅x22=x32

所以

limx→0tanx−sinxx3=limx→0x32x3=12

对照一下：错解给 0，正确答案是 12。这就是「加减项硬换」的代价——它能把一个非零的极限直接算成零。

那什么时候加减也能换

53:20课上留了一句：加减项在满足一定条件时其实也可以换。那个条件属于后续内容（本质是要求两个量各自的「下一阶项」不互相抵消）。但大一阶段，你为加减项做的替换基本都是错的，所以先把规矩记死：乘除能换，加减别换。真遇到加减，先想办法把它变成乘积——像上面那样提取公因式，是很常见的出路。
