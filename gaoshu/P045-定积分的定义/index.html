P045定积分的定义

一句话核心

定积分是「分割、近似、求和、取极限」夹逼出来的一个确定数值，不是函数。记号里最容易被误读的是 λ→0 —— 它要求每一段都细，而不仅仅是段数多；这是它与「n→∞」的根本差别。

从曲边梯形面积说起

00:00定积分最直观的来源是求一块曲边梯形的面积：底边在 x 轴上从 a 到 b，左边右边是竖线，上边是曲线 y=f(x)。这块面积难求，是因为上边「弯」了——以前只会求矩形（底乘高）。老师的思路非常朴素：把弯的切成直的。

03:32具体做法分四步，这四步就是定积分定义的全部血肉：

  1. 分割：在 [a,b] 里插入分点 a=x0<x1<⋯<xn=b，把区间切成 n 个小段，第 i 段长度记为 Δxi=xi−xi−1。
  2. 近似：在每段里任取一点 ξi，用这一点的函数值 f(ξi) 当「高」，小段长度 Δxi 当「底」，于是第 i 个小条面积 ≈ 矩形面积 f(ξi)Δxi。这一步叫以直代曲。
  3. 求和：把 n 个小矩形面积加起来，得到总面积的一个近似值 ∑i=1nf(ξi)Δxi。
  4. 取极限：让分割越来越细，这个和就越来越接近真实面积——极限值就是定积分。
03:32四步背后的直觉：黎曼和

这四步在数学上叫「黎曼和」的构造：分割对应「把区间切碎」，近似对应「以直代曲」，求和对应「把小矩形垒起来」，取极限对应「让误差消失」。老师强调，定积分的原始定义就是「极限中的那个和式」——所以你看到 ∑f(ξi)Δxi 时，脑子里应当立刻浮现出「一排小矩形」。这个画面在考研和难题里会反复出现：题目表面是求极限，骨子里却是求定积分。

07:17教材里的第二条引例：变速直线运动的路程

书上除了曲边梯形面积，还用了「变速直线运动求路程」来引入定积分：速度 v(t) 随时间变，问这段时间一共走了多远。办法一模一样——把时间段切碎，每一小段里把速度当成常速，用 v(τi)Δti 当这一小段的路程，再求和、取极限。老师课上只讲了面积这一条，理由是「一个道理」。但这两条引例值得并排记住：面积是定积分的几何外衣，路程是它的物理外衣，里子是同一个和式的极限。后面把定积分用去求功、求压力、求质心，靠的都是这层「外衣」。

定义里那个 λ→0 到底在管什么

05:38把第四步写严谨，就要引入一个记号：设 λ=max{Δx1,Δx2,…,Δxn}，也就是所有小段长度里最大的那个。令 λ→0，意思就是「最长的一段也趋于零」。于是定积分的完整写法是

∫abf(x)dx=limλ→0∑i=1nf(ξi)Δxi

07:37这里就是本节课最容易卡住的地方。很多同学想：老师你不是要让段数特别多、特别密吗？那我直接写 n→∞ 不就完了，干嘛绕个弯用 λ→0？老师当场反问：「取无穷多份」和「每一份都特别细」是一回事吗？答案是：不是。

10:10为什么 n→∞ 不够，非得 λ→0

因为你完全可以这样切：把前 n−1 段切得极细，唯独最后一段占掉整个区间的 12。这样 n 照样能趋于无穷，但那段「胖段」的长度恒为 12，永不趋于零，它在以直代曲时留下的误差也永不消失。λ→0 的作用，就是卡死「最长那段」，逼着每一段都细下去——这才是近似精确的真正条件。

定义逐词拆解

13:25把定义正式写出来，每个词都有讲究：

定积分的定义

设 f(x) 在 [a,b] 上有界。在 [a,b] 上任意插入分点

a=x0<x1<x2<⋯<xn=b

把区间分成 n 个小段，第 i 段长 Δxi=xi−xi−1。在每段上任取 ξi∈[xi−1,xi]。令 λ=max{Δxi}。若极限

limλ→0∑i=1nf(ξi)Δxi

存在，且与分法无关、与 ξi 的取法无关，则称此极限为 f 在 [a,b] 上的定积分，记作 ∫abf(x)dx。

有界
对函数的要求很低——只要求值域不跑向无穷，没说要连续。这比导数定义「松」得多。
任意插入分点
不要求等分。定义里区间长度 Δxi 可以不一样。
任取 ξi
每段里取左端点、右端点、中点都行，极限都一样才算数。
与分法、取法无关
这是「极限存在」的潜台词：无论你怎么切、怎么取点，和都收敛到同一个数。
12:33老师原话：不等分是定义的自由，等分是做题的规矩

定义说「任意插入分点」，同学的第一个反应往往是：闹了半天不是等分的哦，这个长度不一样啊？老师回答得很干脆：哎对了，这个长度可以不一样。但他紧接着补了更要紧的一句：这玩意儿不是等分是没法做题了——所以真要用定义去算题，一律 n 等分。同理，「ξi 任取」也是定义给的自由，实战里只取左端点或右端点，因为如果真任意取的话，咱就做不了题了。定义要的是「无论怎么取都对」，做题要的是「挑最好算的那种取」。

11:18为什么「与分法无关、与取法无关」不是废话，而是定义的一部分

因为 limλ→0∑i=1nf(ξi)Δxi 这个写法本身，允许你任意切、任意取点。如果换一种切法、换一个取点，极限值就跟着变，那么符号 ∫abf 就同时指向好几个不同的数，这个定义等于没定。所以定义宁可多写两句，把「无论怎么切、怎么取点，极限都收敛到同一个数」写进去，好让 ∫abf 名正言顺地代表唯一一个数。

换个角度看：定义的前半段（分割、近似、求和、取极限）是在构造一个极限；后半段（与分法、取法无关）是在保证唯一性——保证这个极限只由 f 和 [a,b] 决定。少了后半句，前面造出来的就不是一个数，而只是一个「和某种切法绑定的结果」。这也顺便解释了为什么做题时可以放心地等分、取端点：正因为可积时取法无关，我们才有资格偷这个懒。

21:42定义里说 ξi 是「任取」的，做题时却几乎总取左端点或右端点。这两件事不矛盾：定义要求「无论怎么取极限都相同」才算可积；而一旦可积，为了计算方便，我们当然挑最好算的取法——通常是等分后取右端点 ξi=xi 或左端点 ξi=xi−1。老师特别提醒，若真任取一个乱七八糟的点，这题就没法做了，所以实战中默认等分、取端点。

另外，「有界」这条要求看似宽松，其实划定了定积分的边界：像 1x 在包含 0 的区间上无界，定积分（在通常意义下）就不存在；但 xsin1x 之类虽有振荡却保持有界，反而可能可积。可积性讨论的就是「这个函数乖不乖到能求出那个极限」。

23:45关于符号，它和不定积分长得几乎一样，但处处不同：

记号里的部分含义和「不定积分」的区别
∫ab带上下限不定积分没有上下限
f(x)被积函数同名，但此处它是「被积」的对象
dx积分变量同样表示「对谁积」
整个式子一个确定的数不定积分是一族函数（原函数族）
14:25一个初学者的常见误解：上下限谁大谁小无所谓

刚学时容易以为「定积分必须下限小、上限大」。老师明确说：无所谓——写成 ∫100sinxdx 完全可以，下限比上限大同样是一个合法的定积分，只是按约定它等于 −∫010sinxdx。下一节的两条约定（「交换上下限变号」和「∫aaf=0」）就是专门用来安顿这种写法的。真正会让定积分出问题的不是上下限的大小，而是被积函数在区间上有没有无界点。

25:47定积分与积分变量叫什么无关

∫abx2dx 和 ∫abt2dt 是同一个数。因为定积分只取决于两件事：被积函数是谁、积分区间从哪到哪。积分变量只是一个「哑变量」——你把它换个别的字母，不改变这个数值。这一点和「函数与自变量符号无关」是同一个道理，后面讲变上限积分函数时会特别有用。

把这一节和第四章学过的不定积分摆在一起看，两者的差别就一目了然了。这张表值得看一眼：它把「数」和「函数族」这对最容易混的身份彻底分开。

对比项定积分 ∫abf(x)dx不定积分 ∫f(x)dx
结果是什么一个确定的实数：a,b,f 一给定，它就定死了一族函数 F(x)+C，含任意常数
记号特征带上下限 a,b不带上下限
积分变量换字母数值不变（哑变量）含义不变，但习惯上仍写 x
几何 / 物理含义带符号面积、路程、功——都是一个「量」求原函数，是一类函数的整体
本质操作和式的极限（无穷多小块累加）求导的逆运算

可积条件与几何含义

28:42并不是所有函数都能定义定积分，但条件其实很松。两条充分条件：

  • 连续必可积：若 f 在 [a,b] 连续，则定积分一定存在。
  • 有界 + 有限个间断点也可积：允许有间断，但必须只有有限个。
17:59边界：可积比这两条还要宽，但「有界」是硬门槛

上面两条只是充分条件，并不是可积的全部门槛。真正碰不得的是「有界」这一条：可积必先有界——函数在区间上无界（比如 1x 在含 0 的区间上），那个和式根本没有极限可言，定积分不存在。而「间断点只能有限个」同样只是充分条件，并非必要：一个有界的单调函数哪怕有无穷多个间断点，也仍然可积。所以这句话准确的读法是「有限个间断点一定不坏事」，而不是「间断点一多就完蛋」。记住了这个边界，就不会把「充分」当「充要」用。

31:45几何含义按函数值的正负分三种情况，它在直觉上解释了「定积分为什么可以是负数」：

35:57把三种情况合起来看，定积分其实是一个「带符号的面积账本」：曲线在轴上方记正、下方记负，最后把各段代数相加。这也是为什么 ∫abf 可以是负数，而日常说的「面积」永远非负——后者要把下方的部分也取绝对值再加。做题时若问「图形面积」，记得先分段、再取绝对值求和，不能直接把定积分当答案。

为什么「定积分是数」比「不定积分是函数族」更根本

不定积分 ∫f(x)dx 是一族相差常数的函数，你换写法它还是函数；而定积分 ∫abf(x)dx 一旦 a,b,f 给定，就塌成一个具体的实数。前面算面积、算功、算路程，要的都是这个「数」。弄清这层区别，后面牛顿–莱布尼茨公式把「求函数」和「求数」接起来时，才不会把两边弄混。

用定义算一个定积分

38:52老师强调：考试几乎不会让你真用定义求定积分（太繁琐），但「用定义算」是理解定义本身最好的练习。我们算 ∫01x2dx。

例38:52用定积分定义求 ∫01x2dx。

思路：N 等分，取右端点

把 [0,1] 作 n 等分，每段长 Δxi=1n。取每段右端点 ξi=in（i=1,2,…,n）。代入定义的和式：

∑i=1nf(ξi)Δxi=∑i=1n(in)2⋅1n=1n3∑i=1ni2

用平方和公式 ∑i=1ni2=n(n+1)(2n+1)6：

1n3⋅n(n+1)(2n+1)6=(n+1)(2n+1)6n2

47:08取极限。定义里是 λ→0；这里等分后 λ=1n，所以 λ→0 等价于 n→∞：

∫01x2dx=limn→∞(n+1)(2n+1)6n2=26=13

分子分母最高次都是 n2，系数比就是 13。

38:52为什么还要练「用定义算」

老师原话：考试基本不会让你真用定义去求一个定积分，因为后面有牛顿–莱布尼茨公式，一步出结果。但「用定义算」是检验你是否真懂定义的最好练习——它强迫你把「切、取点、求和、求极限」四步走一遍，也让你亲眼看清 13 是怎么从求和公式里「抓大头」挤出来的。更重要的是，它揭示了定积分的本质：一个数，是无穷多小块累加的极限。

反过来的用法：把极限看成定积分

50:39定义的另一个高频考法是反过来：给你一个极限，认出它其实是某个定积分，从而「用积分算极限」。关键还是抓两件事——积分区间、被积函数。

例50:39将 limn→∞1n∑i=1n1+in 写成定积分并求值。

思路：认出 1n 是 Δx，in 是 ξi

n 等分、区间长 1，取右端点 ξi=in。和式里 1+in 就是把 ξi 代进函数 f(x)=1+x。区间是 [0,1]（从 0=0n 到 1=nn）。于是

limn→∞1n∑i=1n1+in=∫011+xdx

这一步只是「翻译」，真正的计算留给后面的牛顿–莱布尼茨公式。先写出它等于

∫011+xdx=[23(1+x)3/2]01=23(23/2−1)=42−23
求和号在内还是在外

若写成 ∑i=1n(1n1+in) 也一样——把 1n 挪进求和号内外不影响。认定积分时只要盯住「一小段长度」和「代入的点」即可，别被书写顺序迷惑。
