P144【黑板】常数项级数的概念和性质：把「无穷相加」拆成部分和数列

一句话核心

这是黑板习题课：不在黑板上抄定义，而是一块一块地「上手做」。全课的骨架只有一句话——级数敛散 = 部分和数列 Sn 有没有有限极限。两块基准（等比、调和）、四类性质（线性、括号、有限项、必要条件）外加一串反例，就是后面所有判别法的地基。

黑板上第一件事：数列是一列数，级数是把它们加起来

00:00这节课一开始，老师没有写定义，而是先在黑板上摆了两样东西，让你分辨它们差在哪。第一样叫数列：

u1,u2,u3,…,un,…

老师的原话是「数列就是摆在那，啥也没动」——它只是一列数排好队，本身没做任何运算。写成 un 外面套个大括号，是因为数列本质上就是一个由一列数组成的集合。

01:32接着老师把数列分成两类，这个区分很重要：有限数列（u1 到 un 一共 n 项，后头没有点点点）和无限数列（后头有个点点点，有无穷多项）。高中两种都讲过，但级数只对后一种感兴趣。

第二样东西叫无穷级数，简称级数：把无限数列的每一项加起来：

∑n=1∞un=u1+u2+u3+⋯+un+⋯

04:04老师连着强调了三遍同一句话：级数就是一个和。你说「这是个级数」，你的意思就已经是「这是个无穷项相加的和」了。所以两者的区别只有一条——数列摆在那没动，级数把它们全加起来。黑板上举的第一个例子是 1+2+3+⋯+n+⋯（每项都是常数，所以叫常数项级数），以及几个「一看就明白」的：0+0+0+⋯、1−1+1−1+⋯。

07:32整章只有两件正事，先说清楚再动手

老师在黑板上写下了这一章的两个任务：第一，判断这个级数收敛还是发散；第二，如果收敛，它的和是多少（往后再加一条「收敛半径／收敛域」，那是幂级数的事）。

为什么要先说这个？因为初学最容易把力气使错——一上来就想「把和算出来」。事实是：绝大多数级数你根本算不出和，甚至不需要算。下面调和级数那一栏花半节课证它发散，却从没提它的和是多少——因为它压根没有和。所以默认目标只有一个：判敛散。

从「加起来」到「看部分和数列」

05:47老师先给了一版直观版的说法，让概念先落地：

  • 0+0+0+⋯：加起来就是 0，一个固定的常数——这种叫收敛。
  • 1+2+3+⋯：越加越大，最终和是正无穷，极限不存在——这种叫发散。

06:34第三个数是 1−1+1−1+⋯，这是黑板课的第一个「反直觉点」。有同学脱口而出：1−1 不就是 0 吗，加起来自然是 0。老师当场把这句话拆开了：要分奇数项和偶数项看。取偶数项时 1−1 成对出现，和是 0；取奇数项时最后单出来一个 1，和是 1。同一个级数沿两条路走得到两个不同的值，所以它的极限不存在——发散。

08:31直观说完了，才轮到严格定义。先把「前 n 项的和」拎出来，给它起个名字：

定义 · 一般项与部分和

级数 ∑n=1∞un 中的 un 叫一般项（通项）。把前 n 项加起来，记

Sn=u1+u2+⋯+un

称为部分和。注意 Sn 本身又是一个数列 {S1,S2,S3,…}，它和原来的 {un} 是两个不同的数列。

09:44定义 · 收敛与发散（严格版）

若 limn→∞Sn=S（S 为有限常数），则称级数收敛，S 称为级数的和，记作 ∑n=1∞un=S；否则称级数发散。

为什么必须绕一圈，用 Sn 来定义

「无穷多项相加」这件事本身是没法直接执行的：没有人能真的加无穷多次。但「前 n 项相加」可以，n 取多大都行。于是我们把一个不可执行的动作，换成了一个可执行的数列问题：看 Sn 这个数列当 n→∞ 时有没有极限。

这个转换还有一个好处：它把级数这一章接回上一章的数列极限。老师41:22讲加括号时反复提醒的「收敛数列的子列也收敛」，就是从上一章搬过来的。所以真正新的东西很少——级数的大部分结论，都是把 Sn 当普通数列处理得到的。你觉得级数难，多半是因为忘了 Sn 只是个数列。

黑板上先做三道：从部分和公式直接读答案

例 110:31判断 1+2+3+⋯+n+⋯ 的敛散性。

思路：写出部分和公式，取极限

这题的部分和是等差数列求和，高中就做过：

Sn=1+2+⋯+n=n(n+1)2

当 n→∞ 时 Sn→+∞，不是有限常数，所以发散。老师对比了两种讲法：严格的写法是「n(n+1)2 的极限不存在，故发散」，直观的写法是「越加越大、最终是正无穷，所以发散」——两种都能拿分，因为它们说的是同一件事：Sn 无有限极限。

例 211:40判断 1+12+14+18+⋯ 的敛散性。

思路：认出来它是等比数列求和

这是公比 q=12、首项 a1=1 的等比级数。用高中公式：

Sn=a1(1−qn)1−q=1⋅1−(12)n1−12

当 n→∞ 时 (12)n→0，于是 Sn→11−12=2。极限存在，故级数收敛，和为 2。

这里最容易漏的一步

直接写「等比级数所以收敛」。不对——等比级数不是一定收敛的，收敛与否取决于公比。这道题之所以收敛，是因为 |q|=12<1，让 qn 那一项被压成了 0。公比换成 2 就是另一回事了（见下面的表）。所以在黑板上做这类题，一定先点出「q 是多少、|q| 与 1 谁大」，再动笔。

基准级数一：等比（几何）级数

14:07老师把等比级数单拎出来讲，理由是「后面一直要用」：

∑n=0∞aqn=a+aq+aq2+⋯+aqn+⋯

当 q≠1 时，部分和公式是 a(1−qn)1−q。老师分四种情形一条一条推完，结论如下表——这张表必须刻进骨头：

公比 qqn 的走向Sn 的极限结论
|q|<1 qn→0 a1−q 收敛，和为 a1−q
|q|>1 qn→∞ 不存在 发散
q=1 每项都是 a Sn=na→∞ 发散（要求 a≠0）
q=−1 在 1 与 −1 间跳 奇偶子列分别是 a 和 0 发散

18:09合起来就是一句话，老师用加重的语气念了一遍：

等比级数∑aqn:|q|<1 时收敛，和为a1−q;|q|≥1 时发散
q=1 与 q=−1 为什么都要单独拎出来

这两条是初学者最爱栽的地方，因为 q=±1 恰好把「q≠1 时才能用 a(1−qn)1−q」这个前提同时踩掉了，必须回头从级数本身看。

  • q=1：级数变成 a+a+a+⋯，前 n 项和 Sn=na。只要 a≠0，na→∞，发散。（老师补了一句：a=0 时每项都是 0，那种情况不用研究。）
  • q=−1：级数变成 a−a+a−a+⋯，正是前面那个 1−1+1−1+⋯ 的一般版。偶数项时成对抵消，S2k=0；奇数项时多出来一个 a，S2k−1=a。两个子列极限不一样，所以极限不存在，发散。

所以「等比级数」这四个字的完整含义是：只有 |q|<1 才收敛。这句话以后会反复当「标尺」用——比较判别法里那个「瘦子」，指的就是收敛的等比级数。

例 319:36判断 ∑n=1∞1n(n+1) 的敛散性，收敛的话求和。

思路：这是小学四年级学过的「拆项相消」

先把部分和摆出来，再把每一项拆开。关键的一步是：

1n(n+1)=1n−1n+1

老师当场验算了这一条：12−13=3−26=16，对的。于是部分和里中间那些项全部正负对消：

Sn=(1−12)+(12−13)+⋯+(1n−1n+1)=1−1n+1

当 n→∞ 时 1n+1→0，所以 Sn→1。级数收敛，和为 1。老师顺口说这东西「小学四年级的弟弟妹妹都会」——等差求和、等比求和加裂项，就是高中阶段唯一三种能直接求和的办法。

性质：黑板上补充的「增值条款」

22:53老师有一句口头禅在这节课里出现了两次：「书上这条定理没写成充要条件，那它一定不是充要条件」。只给单向结论的，你就得把反例准备好。

性质 1 · 线性

若 ∑un=S，则 ∑kun=kS（k 为常数）。也就是说，常数因子可以整体提到求和号外面来。

性质 2 · 收敛 ± 收敛 = 收敛

若 ∑un、∑vn 都收敛，则 ∑(un±vn) 也收敛，且其和就是两个和相加减。

25:14性质 2 反过来 —— 不成立

「∑(un±vn) 收敛 ⇒ ∑un、∑vn 都收敛」是错的。反例：取 un=1、vn=−1，则 ∑(un+vn)=0+0+0+⋯ 收敛，可 ∑un 与 ∑vn 都发散。原因正是那句口头禅：书上没写「充要」，就意味着反方向有坑。

27:54性质 3 · 收敛 ± 发散 = 发散（一定）

若 ∑un 收敛、∑vn 发散，则 ∑(un+vn) 一定发散。

证明用反证法：假设 ∑(un+vn) 收敛。因为 ∑un 也收敛，由性质 2 两者相减 ∑[(un+vn)−un]=∑vn 应当收敛——这与「∑vn 发散」矛盾。所以原级数必发散。

老师特意只证了「加」，然后说「相减一模一样，我故意没写，让你自己体会」：把 vn 换成 −vn 只是每项换个符号，敛散性不变。

性质 4 · 发散 ± 发散 = 不确定

两个发散的级数相加或相减，可能发散也可能收敛。同两个 1+1+1+⋯：相减得 0+0+0+⋯，收敛；相加得 2+2+2+⋯，发散。再换成 1+1+1+⋯ 与 (−1)+(−1)+⋯：相加收敛、相减发散。同一个「发散 ± 发散」，结论能翻来覆去。

32:05四条性质其实只记一句

把四条排成一排会发现它们沿着一条线走：「已知」越多，结论越硬。

  • 两个都收敛 → 一定收敛。
  • 一个收敛一个发散 → 一定发散（性质 3）。
  • 两个都发散 → 什么都说不了。

道理在于「发散」是个含糊的状态：1+1+1+⋯ 往正无穷冲，1−1+1−1+⋯ 在两个值之间跳。而「收敛」状态明确，所以只要有一边收敛，另一边的「野性」就压不下去。

有限项陷阱：哪一句话动的是「有限项」

32:05性质 5 · 去掉、增加、改变有限项，敛散性不变

级数里去掉、增加或改动有限项，不改变它的敛散性。

老师33:25连着抛了两句话让全班比照着判断，这是黑板课上最典型的一种出题方式：

句子动了几项？敛散性变不变
把级数的前 100 项的奇偶项颠倒位置 100 项，有限 不变
把级数的所有奇数项与偶数项交换位置 无穷多项 可能变——这就是选择题的坑

老师34:39说得很直白：第一句话里明确写了「前 100 项」，那是有限项，敛散性不动；第二句话动的是所有项，敛散性没有保证。他还提醒，这种句子会直接出现在选择题选项里——「给一个级数，交换奇数项和偶数项的位置，它的敛散性不变」，很多同学会判断错。

35:42「敛散性不变」不等于「和不变」

把「增删有限项敛散性不变」顺手推广成「和也不变」，是错的。若原级数收敛、和为 S，去掉前 8 项之后和可能变（少了那 8 项的和）；但若增加的是 100 个 0，和当然不变。所以准确的说法是：收敛时和可能变也可能不变，而敛散性一定不变——两件事要分开说。

老师补了一句很有分量的话：「这些关键点书上都没给你指出来，考试稍微变个花样你就看不出来了。」这句提醒正是黑板课存在的理由——正课讲「是什么」，黑板课讲「容易在哪里翻车」。

加小括号：能加，但不能反推

36:49性质 6 · 收敛的级数加括号后仍收敛，且和不变

若 ∑un 收敛，则任意添加小括号后得到的新级数仍然收敛，且和不变。

38:01老师花了一整块黑板来证这一条，因为「加括号」听着太平常，平常到看不出有什么可证的。他的思路是把加括号后的部分和看成原来部分和的子列：原级数的部分和是 S1,S2,S3,…；如果按 (u1+u2)+u3+(u4+u5+u6)+⋯ 这样加括号，新级数的前几个部分和恰好落在原数列的某些位置上，比如 S2,S3,S6,…。新的部分和数列就是 {Sn} 的一个子列。

41:22而上一章讲过：「收敛数列的任一子列都收敛，且极限相同」。原级数收敛意味着 {Sn} 收敛，子列也收敛到同一个 S——加括号后仍收敛，和也一样。

42:10反过来绝对不成立

「加括号后收敛 ⇒ 原级数收敛」是错的。反例还是那个老熟人：1−1+1−1+⋯ 本身发散（奇偶子列分别趋于 1 和 0）；可一旦加成 (1−1)+(1−1)+⋯，每一项都是 0，加起来是 0，收敛。

43:31为什么会这样？回到子列的类比——「子列收敛」推不出「母列收敛」。纯数列的例子：un=(−1)n 本身发散，可子列 u2k=1 却收敛。44:30所以 1−1+1−1 这种级数，如果你一直想着「1−1 抵消了」，其实已经在偷偷给它加括号了——无穷项相加时，加不加括号可能是致命差别。

46:13性质 7 · 加括号后发散 ⇒ 原级数必发散

这条方向是成立的，理由同样来自子列：若一个数列的某个子列发散，则原数列一定发散。所以加了括号的级数发散，原级数必发散。

必要条件：un→0 与它的「一票否决」用法

47:39性质 8 · 收敛的必要条件

若 ∑n=1∞un 收敛，则 limn→∞un=0。

证明：由 Sn=u1+⋯+un 与 Sn−1=u1+⋯+un−1 相减，孤立出第 n 项：

un=Sn−Sn−1

两边取极限，因为级数收敛，Sn→S 且 Sn−1→S，所以 un→S−S=0。

49:25真正好用的是它的逆否命题

原命题是「收敛 ⇒ 通项趋于 0」，但做题时用得最多的是它的逆否形式：

若 un 不趋于 0（包括极限不存在），则级数一定发散。

老师直接说「这个我不用给你证，因为这是逆否命题，逆否命题一定成立」。好处在于它是一张免费的一票否决票：不用放缩、不用找比较对象、不用算极限比值，只看通项本身就能判。

黑板上一口气走了三个例子：un=n（越加越大，发散）、un=1（1+1+1+⋯ 发散）、un=(−1)n+1（就是 1−1+1−1+⋯，通项在一和负一之间跳，不趋于 0，故发散）。第三个例子老师特别得意：以前判它要费口舌解释奇偶项，现在一行就完事。

52:17反过来不行，而且反过来这条是整章的重点

「un→0 ⇒ 级数收敛」是错的。老师又用那句口头禅收尾：「如果反过来也对，那它就成了充要条件；书上没写成充要条件，说明反过来不对。」

反面教材就是下面这个——调和级数。它的通项老老实实趋于 0，可级数照样发散。

基准级数二：调和级数（发散）

53:15黑板上写的调和级数是：

∑n=1∞1n=1+12+13+14+15+⋯

老师说得很明确：「这个调和级数要记住，后面做题时是很重要的参考级数。」它的通项 1n→0，但级数发散。证明用 S2n−Sn：

54:32证明 · 调和级数发散

把第 n+1 项到第 2n 项加起来（一共 n 项）：

S2n−Sn=1n+1+1n+2+⋯+12n

这 n 项里，每一项的分母都 ≤2n，所以每一项都 ≥12n。把每一项都换成更小的 12n，和就变小了：

S2n−Sn≥n⋅12n=12

55:25如果级数收敛、和为 S，那么 S2n→S、Sn→S，两者之差应当趋于 0。可上面的不等式说这个差永远不小于 12——它怎么可能趋于 0？矛盾。故调和级数发散。

55:59「趋于 0」只是门票，速度才是生死线

有同学不服：15、16 这么小，加起来不该是个固定常数吗？老师说：它是越加越大的。1n 确实趋于 0，但趋于 0 的速度太慢，慢到无穷多项累加仍冲出上界。

56:38老师拿等比级数当对照组：12+14+18+⋯ 也趋于 0，但 12n 掉得飞快，累加起来只到 1；1n 掉得极慢，累加起来没有天花板。所以判断一个级数，不能只看通项是否趋于 0，必须看它趋于 0 的速度够不够快——这是下一节所有判别法的统一来源。

记忆入口 · 一眼回忆

一条链

数列 摆着的一列数→ 级数 用一个 + 串起来→ 部分和 Sn 能算的那个→ 收敛 limSn 是有限常数

两块基准（必须刻死）

  • 等比级数 ∑aqn：|q|<1 收敛、和为 a1−q；|q|≥1 全发散（含 q=±1）。
  • 调和级数 ∑1n：通项 →0 但发散，证法是 S2n−Sn≥12。
  • 裂项型 ∑1n(n+1)=1：分母是相邻因式相乘就先想拆项相消。

性质清单（黑板上补充过的）

  • 线性：∑kun=kS；常数可以提到求和号外。
  • 收敛 ± 收敛 = 收敛；但反推不成立（1 与 −1 的例子）。
  • 收敛 ± 发散 = 一定发散（反证法）。
  • 发散 ± 发散 = 不确定。
  • 增删改有限项：敛散性不变；和可能变。
  • 加括号：收敛的加了仍收敛且和不变；加括号收敛推不出原级数收敛；加括号发散则原级数必发散。
  • 必要条件：收敛 ⇒ un→0；逆否：不趋于 0 ⇒ 一票否决判发散。

三个坑

  • 「极限是无穷大」不是极限存在，那是发散。
  • 「前 100 项奇偶颠倒」是有限项、敛散性不变；「所有奇偶项交换」是无穷项、可能变。读题要找「有限」两个字。
  • un→0 只是必要条件——调和级数就是反例。
