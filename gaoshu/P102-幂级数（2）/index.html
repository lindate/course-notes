P102幂级数（二）：性质与和函数

一句话核心

幂级数不只是求收敛域——它的和函数 S(x) 才是宝藏。四条分析性质里真正干活的是逐项求导与逐项积分：先求和再求导，等于逐项求导再求和。求和函数的套路就三步：消掉碍事的 n、凑成等比级数 11−x、再还原。

本节的目的：把和函数求出来

00:00这一部分仍然属于幂级数这一大块。课本有的叫"幂级数的运算"，有的叫"幂级数的性质"，但无论叫什么，最实质、考试最爱考的动作只有一个：求和函数。上一节我们解决了"级数在哪收敛"——给定 ∑anxn，求出它的收敛域。这一节更进一步：既然它在收敛区间内收敛到一个和函数 S(x)，那这个 S(x) 到底是什么函数？把它显式写出来，才能拿它去算值、去用。这就是"求和函数"，也是本节的全部重心。

42:30在动手之前，先记住一句话，它贯穿整节：到目前为止，你真正会求和的级数只有一个——等比级数。只要把这个事实刻进脑子里，后面所有花哨的例题都会变得顺理成章。下面先列四条性质，其中只有两条是考试真正的高频工具。

四条性质：重点在第三、第四

性质一（加减法）

若 ∑anxn 收敛半径 R1、∑bnxn 收敛半径 R2，则 ∑(an±bn)xn 的收敛半径取交集：min(R1,R2)（在两者都收敛的区间里相加才有意义）。

01:10性质一解释起来很直观：两个级数要能相加，必须两个都收敛，所以公共部分取交集，收敛半径自然取较小的那个。课本上有时还讲乘法，但老师明确说乘法基本不用看，考试也不会考，所以这一条我们心里有数即可，不必深挖。

性质二（连续性）

和函数 S(x) 在其收敛域上连续。考试直接用的机会不多，记住一句话即可。

06:09性质二说的是：只要 x 在收敛域里走，和函数 S(x) 不会突然跳变。这话没错，但它在解题里几乎从不直接出场——你很少需要"因为连续所以怎样"。把它和下面两条对比，就能明白为什么老师把重心放在后两条上。

性质三（逐项积分）

若和函数 S(x)=∑anxn，则在收敛域上可逐项积分：

∫0xS(t)dt=∑n=0∞anxn+1n+1

即先求和再积分 = 先逐项积分再求和。

09:04性质三的写法是：把求和号外面套一个从 0 到 x 的定积分，积分可以"钻"进求和号里面，对每一项分别积分，再把结果加起来。注意这里把积分变量写成 t、上限写成 x，是为了避免和级数里的 x 打架——你也可以用同一个字母，很多书不换，但换了更清爽，尤其是等会儿要做变上限积分求导的时候。

性质四（逐项求导）

在收敛区间内可逐项求导：

S'(x)=∑n=1∞nanxn−1

即先求和再求导 = 先逐项求导再求和。注意：求导对端点 x=±R 可能失效，端点要单独判断。

15:58性质四比性质三多一个"坑"：课本说它在收敛区间 (−R,R) 内成立，把两个端点单独剔除。原因是求导比积分"挑剔"：和函数在端点处未必可导，所以端点要最后回到原级数单独确认。记住"区间内无条件成立、端点另判"，就不会出错。

19:53为什么这些"显然"的事要单列成性质

对有限项求和，交换求和与求导、积分的次序天经地义——三个数相加求导，等于各自求导再相加。但对无穷项级数，很多有限项下成立的直觉会翻车。老师举了两个扎心的例子：第一，1−1+1−1+⋯ 本身是发散的，但如果你乱加小括号变成 (1−1)+(1−1)+⋯ 就"变成"了 0；第二，把奇数项、偶数项的位置调换，无穷级数的和也可能改变。所以"能不能交换求和与求导/积分的顺序"必须作为一个需要单独证明的性质来用。性质三、四正是告诉你：对幂级数，这个交换在收敛区间内是合法的——这是你敢"先求和再求导"的底气，而不是想当然的常识。

15:58四条里为什么只两条是"干活"的

性质一（加减法）只在处理"两个级数相加"时才用，而考试题几乎都是单级数求和，它退居幕后；性质二（连续性）又极少直接出场。真正每次求和函数都要请出来的，是性质三（逐项积分）和性质四（逐项求导）——它们能把幂级数里的 n 干掉或收起来，从而扭成我们认识的等比级数。所以后文所有例题的解法，概括起来就是"在性质三、四之间做选择"，其余两条知道就行。

求和函数的三步套路

42:30老师反复强调：你目前只会一个和函数，就是等比级数

∑n=0∞xn=11−x(|x|<1)

连它的带符号版本 ∑(−1)nxn=11+x 也是从它推出来的。所以求和函数的核心思想就一句话：把题目给的级数，通过求导或积分，变成上面这个等比级数，算完再反操作还原回去。标准流程如下。

42:30再强调一次：你此刻真正会求和的级数只有等比级数这一个。所以无论题目多花哨，终极目标都是把原式通过求导或积分，扭成 ∑xn=11−x（或其带符号版）。掌握不了这一点，三步流程就只是空架子。下面三道例题，正是"扭成等比"的三种典型姿势。

例 1：分母有 n → 先求导

例 137:41求 ∑n=1∞(−1)n−1xnn 的收敛域与和函数。

收敛域（同 P101 例 1）

标准型，系数比得 ρ=1，R=1；端点 x=1 收敛、x=−1 发散，故收敛域 (−1,1]。

思路：n 在分母，先求导消去它

设 S(x)=∑(−1)n−1xnn。两边对 x 求导（用性质四），把求和与求导交换：

S'(x)=∑n=1∞(−1)n−1xn−1=1−x+x2−x3+⋯=11+x

这正好是等比级数（公比 −x，首项 1）。得到 S'(x)=11+x 后，再积分还原：

S(x)=∫0x11+tdt=ln(1+x)

其中用了 S(0)=0。注意 S'(x) 只在 (−1,1) 内成立，但由阿贝尔定理，等式在端点 x=1 处也成立，所以 S(x)=ln(1+x)，x∈(−1,1]。

这一步最容易错

忘写绝对值、或直接写 ln|1+x|。这里积分出来理论上是 ln|1+t|，但因为收敛域是 x&gt;−1，区间上 1+t&gt;0，绝对值可直接去掉。若保留绝对值，会在 x∈(−1,1] 上显得多余甚至误导。另外收敛域从 (−1,1)（求导后）扩回 (−1,1]，这一步别漏。

例 2：分子有 n → 先积分

例 238:36求 ∑n=1∞nxn−1 的收敛域与和函数。

收敛域

标准型，an=n，ρ=limn+1n=1，R=1。端点 x=1 时 ∑n 通项不趋于 0 发散；x=−1 时 ∑n(−1)n−1 同样通项不趋于 0 发散。故收敛域 (−1,1)。

思路：n 在分子，先积分把它收进原函数

设 S(x)=∑nxn−1。两边从 0 到 x 积分（性质三）：

∫0xS(t)dt=∑n=1∞xn=x+x2+⋯=x1−x

再对两边求导还原（变上限积分求导）：

S(x)=(x1−x)'=1(1−x)2

所以 S(x)=1(1−x)2，x∈(−1,1)。

更简洁的写法（认出导数）

直接看出 nxn−1=(xn)'，则 S(x)=(∑n=0∞xn)'=(11−x)'=1(1−x)2，一行搞定。这正是老师说的"反着用性质四"——先求和（你会）、再求导，比先积分再还原更直接。

例 3：分母有 n+1，要"乘 x 再求导"

例 351:28求 ∑n=0∞xnn+1 的收敛域与和函数。

收敛域

标准型，an=1n+1，ρ=1，R=1。x=1 时 ∑1n+1 发散；x=−1 时 ∑(−1)nn+1 交错收敛。故收敛域 (−1,1]。

思路：直接求导消不掉 n+1，先乘 x

设 S(x)=∑xnn+1。若直接对 x 求导，得到 ∑nxn−1n+1，多出来的 n 与分母的 n+1 抵消不了——这正是老师警告的"反例：直接求导在这里行不通"。于是两边先乘 x：

xS(x)=∑n=0∞xn+1n+1

现在对 x 求导，指数上的 n+1 正好抵消分母的 n+1：

(xS(x))'=∑n=0∞xn=11−x

再积分还原：

xS(x)=∫0x11−tdt=−ln(1−x)

故当 x≠0 时，S(x)=−ln(1−x)x。

S(0) 必须单独写

直接写 S(x)=−ln(1−x)x 就完事。这个式子在 x=0 分母为 0，不能用。但原级数在 x=0 时，首项是 001=1（约定 00=1，因为 n=0 项是 x0 而非真零），其余项全为 0，所以 S(0)=1。最终答案要分写：

S(x)={−ln(1−x)x,amp;x≠0,x∈(−1,1]1,amp;x=0

例 4：分子有 n 且整体多一个 x → 提 x 化归

例 441:31求 ∑n=1∞nxn 的和函数（x∈(−1,1)）。

思路：提 x，化归为例 2 的模型

这题和例 2 只差一个 x 因子：nxn=x⋅(nxn−1)。所以

∑n=1∞nxn=x∑n=1∞nxn−1=x⋅1(1−x)2=x(1−x)2

一步到位。它告诉我们：凡是 nxn 这类"分子有 n 且少一次方"的，先把 x 提出来变回 nxn−1，套例 2 结论即可。收敛域与例 2 相同，仍是 (−1,1)。注意这里提出的是 x 而不是 1x，所以不必单独讨论 x=0（原级数在 x=0 时各项为 0，和为 0，代入 x(1−x)2 也得 0，一致）。

判断先求导还是先积分：看 n 的位置

41:31三道题加一个变式做完，规律就清楚了。决定"先求导还是先积分"的，是那个碍事的 n 出现在分子还是分母。下面把考试最常见的六类模型一次说透。

n 的位置典型项操作结果
在分母xnn直接求导∑xn−1=11−x，再积分
xn+1n先提 x 变 xnn同上
xn−1n乘 x 提 1x 变 xnn同上，注意 x≠0 讨论
在分子nxn−1认出是 (xn)' 或用积分1(1−x)2
nxn提 x 变 nxn−1x⋅1(1−x)2
nxn−2提 1x 变 nxn−1同上，注意 x=0 讨论
55:21什么时候要单独讨论 x=0

凡是你为了凑形式而往式子外提了 1x（比如处理 xn−2、xn−1 这类指数比标准少一次的项），就相当于在分母引入了 x，原级数本可以在 x=0 取值，变形后却不行了——这时必须回到原级数单独算 S(0)。反之，如果只是提 x（往外出 x）而不除 x，则不必讨论 x=0。口诀：提 x 不用管，提 1x 必讨论。例 3 提的是 x（乘 x 再求导），但最后结果 −ln(1−x)x 分母有 x，所以仍要补 S(0)=1——它的 x=0 问题是结果自带的，不是提 1x 造成的，但结论一致：凡结果分母出现 x，一律补点。

47:52考场最稳的写法

不记得该先求导还是先积分时，就用"认导数"法：把题目项往等比级数 ∑xn=11−x 及其导数上靠。例如 nxn−1 一眼是 (xn)'；xnn 一眼是 (xn+1)' 再除。只要认出它是哪个已知和函数的导（或原）函数，三步流程就化简成一行操作。例 2 的"反向用法"（先求和再求导）就是这样，比积分还原快得多。

15:58老师的两个反例提醒

有限项成立的东西跟无穷项的东西它不一定都成立。对应到本节：第一，别把"先求和再求导 = 逐项求导再求和"当成对所有级数都成立的常识——它只对幂级数（且在区间内）成立；第二，例 3 的反例说明，看见 xnn+1 想都不想直接求导，会得到消不掉的 n，必须"先乘 x 再求导"。这两条是老师专门挖的坑，考场上绕开就赢了一半。

59:23为什么求导 / 积分后收敛域端点会变

逐项求导、逐项积分能"保收敛半径"，但不保证保端点。直觉上：求导让通项多乘一个 n、积分让通项多除一个 n，端点处原本"勉强收敛"的级数，乘上 n 后可能发散、除掉 n 后可能收敛。所以每一步求导或积分，收敛域的端点都可能改变，最后一定要回到原级数在端点处的敛散性重新确认。例 1 里 S'(x) 在 (−1,1) 成立，但原级数在 x=1 收敛，靠阿贝尔定理把结论延拓到端点；例 3 同理。口诀：动一次导数或积分，端点重新验一次，绝不能直接把中间步骤的收敛域当最终答案。

47:52老师的两个反例提醒（续）

除了"先求和再求导"不能随意用于任意级数，老师还点破一个误区：有人以为"求和函数就是把级数积分或求导一下"，却忘了最终要反操作还原。只求导不积分、或只积分不求导，得到的是导数的导数、原函数的原函数，根本不是 S(x)。三步流程的"消 n → 凑等比 → 还原"中，还原这一步丢不得——它和消 n 同等重要。考试中一半的错误不是不会消 n，而是还原时符号、系数、常数（S(0) 等）算错，所以落笔时把"还原 + 补端点"当成独立一步来对待。
