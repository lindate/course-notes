P001映射：在讲函数之前，先把「对应」这件事说清楚

一句话核心

整章要从「对应」讲到「函数」。映射就是那个铺垫：它只规定一条铁律——一个 x 只能对应一个 y，反过来不要求。这一条铁律往下推出满射、单射、一一映射，再推出「只有单射才倒得过来」（逆映射），以及「前一步的值域必须落进后一步的定义域」（复合映射）。这一页里所有例子都是课上原话举过的：x2、圆投影、sinx、1−u2。映射本身后面几乎不再单独用，但它是函数那张地基的钢筋。

为什么要先讲映射

02:25第一节课的内容安排很容易让人困惑：明明整本书要讲的是函数，为什么开头要先花二十分钟讲一个后面再也用不到的东西？课上老师的解释很直白——他这一章的思路是先从这个映射到函数，如果映射不讲，直接讲函数有点突兀。所以映射这一节是一遍过的：理解就行，不必背，考试也不会单独考。

但它也不是白讲的。函数本质上是「数到数」的对应，而模拟对象要宽得多：04:00老师举的例子是从一个矩阵映射到一个矩阵，也就是线性代数里的线性变换。人也可以映射到学号，点可以映射到点。这些全都叫映射，但都不是函数。所以先在一个更大的舞台上把「对应」这件事的规矩立好，再往函数上收，逻辑才顺。

为什么值得花二十分钟

因为整章后面所有的麻烦，其实都来自同一条规矩：「一个输入只能有一个输出」。反函数为什么要单射？就是因为不单射的话，倒过来一个 y 会对应好几个 x，违反这条规矩。复合函数为什么要检查值域？也是因为要让中间那一步的输出真的落在下一步的「合法输入」里。

换句话说，映射这二十分钟立下的两条规矩——唯一性与定义域的相容性——会在函数、反函数、复合函数里反复出现。先看清楚规矩本身，后面就只是换个名字重讲一遍。

映射的定义：一句话加三个零件

定义 · 映射（02:25）

设 X、Y 是两个非空集合。如果存在一个法则 f，使得对 X 中的每一个元素 x，按照这个法则，在 Y 中都有唯一的一个元素 y 与它对应，那么就称 f 是从 X 到 Y 的映射，记作

f:X→Y

并把 y 叫作 x 的象，x 叫作 y 的原象。

03:16这段定义念起来平淡，但里头有三个零件各自在管事，少一个都不行。

「非空」集合
空集上没法建立对应，先排除掉。这是技术性的前提，不必深究。
「每一个」x
这是定义域那一侧的要求：X 里的元素一个都不能漏，不许有「没人管」的输入。这条保证了映射是个「处处有定义」的规则。
「唯一」的一个 y
这是铁律本身：一个 x 不能同时对应两个 y。老师课上重复了好几遍这句话——一个 x 只能对应一个 y，一个 x 只能有一个 y 和它对应。
不要求：「每一个」y 都有原象
这是最容易忽略的一半。Y 里允许有没被用上的元素。原因马上就会看到：06:02值域 Rf 只是 Y 的一个子集。
不要求：「唯一」的原象
一个 y 可以有好几个 x 对应过来。03:16老师原话是：但是有可能两个 x 对的是同一个 y，这是可以的。这一条正是后面「单射」要额外规定的，换句话说，不单射的映射是合法的映射。
为什么「一个 x 对俩 y」被禁止，而「两个 x 对一个 y」被允许

因为映射的用途是「用输入算输出」。如果同一个输入能算出两个不同的答案，那这个法则就不是一个确定的规则，读它的人永远不知道答案该填哪个，整个映射就没有意义。

反过来，两个不同输入算出同一个答案，一点也不影响「确定的规则」这个性质：你拿 x=2 和拿 x=−2 去算 f(x)=x2，各算各的，都得到 4，规则本身没有任何含糊。所以这条不对称性是由用途决定的，不是由美感决定的。理解这一点，后面单射为什么是个「额外附加条件」就很自然了。

两个记号：Df 与 Rf，以及一个反复被提的坑

04:58课本给两个集合起了名字：X 叫映射的定义域，记作 Df；y 的全体组成的集合叫值域，记作 Rf。老师顺带讲了这两个字母的来历，很有意思：

视频原话（大意）

有的同学问：老师为什么叫 D 呢，是不是「定」的那个 D 啊？不是。定义域是 domain，所以第一个字母是 D。值域这个 R 是 range，范围的意思。

还有一个小细节值得记下来：为什么写 Df 而不直接写 D？04:58因为一个题目里往往同时出现好几个函数，如果都写 D，你说的是谁的定义域？写成 Df、Dg、Df1 才有区分度。

本页第一个必须记住的坑

Y 不是值域。04:58老师课上专门问了同学一句：大家注意哈，这个 X 是它的定义域，当然这个 Y 不是它的值域，大家能理解我的意思吧？

因为映射只要求「x 有唯一的象」，从来没要求「Y 里的每个元素都被用到」。所以 Rf 通常只是 Y 的一部分：

Rf={f(x)∣x∈X}⊆Y

换句话说：定义域是 X 的全部，值域是 Y 的一部分。这个不对称是后面「满射」这个名字的来源——满射就是「难得地，值域恰好把 Y 占满了」。

三要素还是两要素

06:02映射的三个要素是：定义域（就是 X）、值域（Rf）、对应法则（f）。但也有的书只写两要素，把值域省掉。两种说法都对，不矛盾。

原因是：只要定义域和对应法则都定死了，值域就被唯一确定了——你把 X 里每个元素代进去算一遍，得到的那一堆数自然就是值域，没有第二种可能。所以值域是个「推论」，不是「独立的要素」。这一点和后面函数那一节完全一致（函数 里也会再说一遍），记住这个视角比背「三要素」三个字有用得多。

课上三个例子，把定义验一遍

07:55光看定义没用，得拿具体的东西走一遍。老师课上挑了三个例子，一个比一个更能说明问题。

例 107:55设 f:R→R，法则为 f(x)=x2。它的值域是什么？它是单射吗？

思路：先定值域，再回来检查「唯一性」

这是最熟悉的二次函数，但它现在被当成一个映射来看。x 可以随便取（定义域是整个 R），所以先确认合法性：每一个 x 都算得出唯一的一个 x2，是映射没问题。

再看值域。因为任何实数的平方都非负，所以

Rf=[0,+∞)≠R=Y

这个例子把「Rf⊆Y」演示得清清楚楚：虽然写法上是「从 R 到 R」，但真正被用到的那部分只是非负半轴。

09:01接着看唯一性。老师举的是 y=4 这个点：这个 x 等于 2，2 的平方是 4；那 x=−2 也是对的，也是 4。也就是说一个象，它的原象是俩。所以

f(2)=4=f(−2),2≠−2

这不是错误，是合法映射。但它说明了：这个映射不是单射。这个反例后面还会再用一次。

例 210:59设 X 是圆 x2+y2=1 上所有点组成的集合，Y 是 x 轴上满足 |x|≤1 的所有点。法则：把圆上的点 (x,y) 对应到 (x,0)。这是什么意思？

思路：把「法则」翻译成几何动作

这个例子看着绕，其实就是垂直投影：把圆上的每一个点「压」到 x 轴上，横坐标保持不动，纵坐标抹成 0。老师讲的时候是一个点一个点画的：

假设找这个点，那他就只把这个点的 x 值取过来了，y 值呢就是零，那也就是说对应的就是这个点呗。

两个集合要分清：X 是圆上的点组成的集合（是曲线上的点，不是圆盘内部），Y 是横轴上 −1 到 1 那一段的点。

这个映射是满射（横轴上 [−1,1] 每个点都是圆上某点的投影），但它不是单射：圆上 (0.5,0.87) 与 (0.5,−0.87) 这两个点，投影之后都落到 (0.5,0) 上。

(0.5,0.87)→(0.5,0),(0.5,−0.87)→(0.5,0)

同一个象，两个原象。这和例 1 是同一件事的几何版本。

例 313:57设 f 是从 [−π2,π2] 到 [−1,1] 的映射，法则为 f(x)=sinx。它和例 1、例 2 有什么不同？

思路：注意定义域被「砍」过了

关键在那句限定：sinx 本来定义在全体实数上，但这里只取了 [−π2,π2] 这一小片。老师强调的就是「光取这一片」。

在这片区间上，正弦函数是一路往上的：x 越大，sinx 越大，中间没有任何折返。所以不同的 x 一定给出不同的 sinx，撞车的事情不会发生。同时这一片的函数值恰好把 [−1,1] 铺满（sin(−π2)=−1，sinπ2=1，中间连续地经过每一个值）。

于是：它既是单射，又是满射——这也就是下一节要讲的「一一映射」。

这个例子的重要性

例 3 是三个例子里唯一「干净」的那个，而它之所以干净，秘密全在定义域被限制过。后面讲反三角函数时会看到：arcsin 之所以能存在，正是因为把正弦「砍」到 [−π2,π2] 上；arctan 砍到 (−π2,π2) 上。初等函数（补充了cot x 和反三角函数） 会专门补这一块。

满射 / 单射 / 一一映射

13:57三个例子对比完，定义就水到渠成了。老师是从 Rf 和 Y 的关系切进去的：

定义 · 满射（13:57）

设 f:X→Y。如果值域就等于 Y，即 Rf=Y，就称 f 是满射（也叫到上的）。

大白话：Y 里的每一个元素都被用到了，一个都没剩下。

定义 · 单射（15:13）

设 f:X→Y。如果对 X 中任意两个不同的元素 x1≠x2，都有 f(x1)≠f(x2)，就称 f 是单射（也叫一对一的）。

大白话：不允许两个不同的输入撞出同一个输出。

定义 · 一一映射（16:25）

如果 f 既是单射又是满射，就称 f 是一一映射（双射）。

大白话：不遗漏、不撞车。于是每一个 x 对唯一的 y，每一个 y 也反过来只对唯一的 x。

15:13单射的定义还可以换个等价说法：只要 f(x1)=f(x2)，就一定能推出 x1=x2。这两种写法是一回事（一个是逆否命题），做题时哪个顺手用哪个——但证明单射时「f(x1)=f(x2)⇒x1=x2」这个方向通常更好用，因为它是从等式出发去推。

为什么单射要专门定义，「不撞车」难道不是理所当然的吗

不是。映射只要求「一个 x 给一个 y」，它完全不关心「两个不同的 x 会不会给出同一个 y」。例 1 的 x2、例 2 的投影，都是完全合法的映射，可它们都在撞车。

那为什么还要专门把「不撞车」这件事拎出来？因为它决定了一件非常实际的事——能不能倒着走。如果两个 x 都对应到同一个 y，那么当你只知道「答案是 y」时，你根本没法判断原输入是哪一个。所以「单射」这个条件不是数学家的洁癖，而是「能不能求逆」这件事的入场券。下一页的逆映射会把这个逻辑走完。

逆映射：倒着走需要什么资格

19:36现在把箭头倒过来。原来是从定义域到值域，现在想从值域回到定义域。

定义 · 逆映射（19:36）

设 f:X→Y 是单射。则对每一个 y∈Rf，都存在唯一的 x∈X 使 f(x)=y。于是可以定义一个新的映射

f−1:Rf→X

称它为 f 的逆映射。注意它的定义域是 Rf（原来 f 的值域），它的值域是 X（原来 f 的定义域）——刚好交换过来。

定义里那个「唯一」是从哪来的？就是单射给的。19:36老师把理由掰得很细：假设 f 不是单射，那么会有两个 x 都映到同一个 y 上——

视频原话（大意）

如果不要求单射，那反过来的话，这一个 y 有几个 x 和它对应？两个。那这个是不是就不符合映射的要求啦？所以为什么他必须要求是单射呢——一个 x 只能对应一个 y，那反过来这个 y 就只有这一个 x 和它对应。

换句话说：倒过来之后，「唯一性」这条铁律照样要成立，而它能够成立，恰好等价于原来的 f 是单射。单射不是额外加的礼貌条件，而是逆映射存在的充要条件。

22:20回到三个例子，答案立刻分明：

例子是单射吗有逆映射吗为什么
例 1　f(x)=x2不是没有f(2)=f(−2)=4，倒过来 4 有两个候选原象 2 与 −2，选不出来
例 2　圆投影不是没有(0.5,±0.87) 投影到同一点，倒过来那个点的原象有两个
例 3　sinx 限制在 [−π2,π2]是有这一片上正弦一路递增，一个 y 只对应一个 x；这个逆映射就是 arcsinx

22:20老师还顺带提了一句：sin 的这个反函数是反三角函数，是个 arcsin。他还专门停下来问同学有没有学过反三角函数——结果是有学过的有没学过的，挺乱。所以课程后面在讲初等函数时，专门开了一个小专题补这块（就是 初等函数（补充了cot x 和反三角函数） 那页）。

顺带记一句：映射的别名叫法

18:04课本上有一句话说「映射又叫算子、又叫泛函、又叫变换、又叫函数」。老师原话是这些「都是数学的概念，大部分同学都不是数学专业，就不说了」。所以只要知道这几个词在别的场合可能指同一件事就够了，本课程里我们只用「函数」这个词。

复合映射：前一步的出口，得是后一步的入口

24:06最后一个概念是把两步操作接起来。设有两个映射：

g:X→Y1,f:Y2→Z

如果 Y1⊆Y2，那么 X 中的每一个 x 先经 g 变成 g(x)，这个 g(x) 又落在 f 的定义域里，可以再经 f 变成 f(g(x))。这样得到的映射叫复合映射，记作 f∘g，它的效果是

(f∘g)(x)=f(g(x)),f∘g:X→Z

24:06老师提了一句记号的事：这种圆圈写法「我们一般是很少用这种表示方法的」，实际书写时更常直接写成 f(g(x)) 的样子。

条件 Y1⊆Y2 写在定义里显得啰嗦，换算成值域与定义域就是一句更好记的话：

复合的合法性条件（25:09）

记 g 的值域为 Rg、f 的定义域为 Df，则复合 f(g(x)) 有意义的前提是

Rg⊆Df

一句话：里层函数吐出来的东西，外层函数必须全都认得。

为什么不能反着包含

老师课上把同学的典型误解复述了一遍：老师啊，你保证这个 f 映射一定成立的话，那你这么着就是说 f 的定义域小一点，你包在这里头多稳妥啊。听起来很合理，但一推就崩：

复合的动作顺序是「先 g 后 f」。g 的输出完全由 g 自己决定，你控制不了它落在哪。如果 Rg 有一部分落在 Df 之外，那么只要某个 x 被 g 送到那部分去，第二步就卡住了——28:50老师的原话是：你都没在这定义域里头，俺怎么给你映射？

所以正确的画法只有一个方向：内层的值域 ⊆ 外层的定义域。这也正是判断一个复合函数「合不合法」的唯一标准。

例 429:32课上构造的正例：设 g(x)=sinx（定义域 R），f(u)=1−u2。这两个函数能复合吗？复合出来是什么？

思路：先各算定义域/值域，再看包含关系

第一步，求 g 的值域。sinx 的取值在 −1 与 1 之间，所以

Rg=[−1,1]

第二步，求 f 的定义域。根号要求内部非负，1−u2≥0，解得 u2≤1，也就是

Df=[−1,1]

第三步，比大小。Rg=[−1,1] 与 Df=[−1,1] 一模一样，当然满足 Rg⊆Df。合法。

第四步，写出复合。29:32老师当时的做法是把这个 g(x) 当成一个整体带到这个 u 里头去：

f(g(x))=1−sin2x=|cosx|
这个例子的「巧合」值得注意

两个区间恰好相等是运气好，不是必然。老师也正是拿这个例子说明：Rg⊆Df 是可以「刚好卡边」的——只要 Rg 跑出去一点点，复合就会在那些点上断掉。顺带记住一个三角恒等式：1−sin2x=cos2x，开根号之后必须带绝对值，写成 cosx 是错的。

例 531:45课上构造的反例：设 g(x)=2x2（定义域 R），f(u)=1−u。这两个能复合吗？

思路：同样三步，重点看第三步

第一步，g 的值域。2x2 是个平方再乘二，永远不会是负数，且可以取到任意大的正数，所以

Rg=[0,+∞)

第二步，f 的定义域。根号要求 1−u≥0，即

Df=(−∞,1]

第三步，比大小。[0,+∞) 显然不包含于 (−∞,1]——从 1 往右的一大段都跑到 Df 外面去了。所以这个复合不能成立。

验证一下也很快：形式上把 u=2x2 代进去得到 f(g(x))=1−2x2。这根号要有意义，必须 1−2x2≥0，也就是 |x|≤22。可见它只在 R 中间的一小段上活着，而不是在整个 R 上。

这一步最容易错

错误做法：只要「代进去能写成一个式子」就认为复合成立。31:45老师课上模仿同学的语气说：老师不就复函数吗，我我随便来呗，符合映射呗，我把表达式写出来不就成立嘛，这个还有什么难的呢？

问题在于：「写得出表达式」和「是个合法映射」是两码事。1−2x2 这个式子确实能写出来，但它在 |x|>22 处无意义，也就是定义域被砍掉了一大半。而复合映射的定义要求「X 中的每一个元素都能走完两步」，所以这不能算 f∘g:R→Z。

本页第二个必须记住的坑

判断复合是否合法，不能只看表达式，要看 Rg⊆Df。而且请注意：这个条件和映射那一节里「一个 x 对应一个 y」是两条不同的规矩——前者管「输出唯一」，后者管「输入接得上」。老师把这两条分别在开头和结尾各讲一遍，不是重复，是刻意把它们对起来。

一条链

铁律 一 x 只对一 y→ 三分类 满射 / 单射 / 一一→ 单射才有 逆映射 f−1→ 复合 要求 Rg⊆Df

一句话

映射 = 每个输入都有唯一输出；它不管「输出会不会重复」，也不管「输出是不是被用光」。单射管重复，满射管遗漏。

三档定义

满射
Rf=Y：Y 被铺满，一个不剩
单射
x1≠x2⇒f(x1)≠f(x2)：不撞车
一一映射
单射 + 满射：不漏也不撞

三个例子的钥匙

  • f(x)=x2：满射？不是（Rf=[0,+∞)），单射？不是（2 与 −2 都到 4）
  • 圆投影：满射（铺满 [−1,1]），不单射（(0.5,±0.87) 挤到一起）
  • sinx 砍到 [−π2,π2]：一一映射，所以有逆映射 arcsin

两个坑

  • Y 不是值域：Rf⊆Y，通常只是其中一部分
  • 复合不看表达式，看条件：必须有 Rg⊆Df，且方向不能反
