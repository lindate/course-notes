P103函数的幂级数展开

一句话核心

把函数写成幂级数，本质是用多项式顶替难算的函数（如 e0.1 计算器算不出，但 1+0.1+0.12/2 秒出）。考试只考间接展开法：背熟几张必背展开式，再用代换、求导、积分拼出来。注意：泰勒公式带余项，泰勒级数要求余项趋于 0。

目的：把函数"拆"成幂级数

00:43前面两节，我们给定级数求收敛域、求和函数；现在反过来——给定一个函数 f(x)，把它写成幂级数

f(x)=a0+a1(x−x0)+a2(x−x0)2+⋯

这就是"函数的幂级数展开"。系数 an 怎么定？答案就是泰勒（Taylor）级数。老师上课明确说：他不按课本一条一条给你推泰勒展开的证明，因为考试从头到尾只考"间接展开法"——你不需要会严格证明，只要会用现成公式拼装就行。所以本页的重心是：背哪些公式、怎么拼。

定义 · 泰勒级数

若 f(x) 在 x0 处任意阶可导，则称

f(x)∼∑n=0∞f(n)(x0)n!(x−x0)n

为 f(x) 在 x0 处的泰勒级数。取 x0=0 时特称为麦克劳林级数：

f(x)∼∑n=0∞f(n)(0)n!xn

一个关键条件：余项必须趋于 0

03:08注意上面写的是"∼"（形式展开），不是等号。泰勒级数要真的等于 f(x)，需要余项趋于 0。这正是它和 泰勒公式 泰勒公式的区别与联系。

展开条件

设泰勒公式的余项为 Rn(x)=f(n+1)(ξ)(n+1)!(x−x0)n+1。若对某个区间内的 x 有

limn→∞Rn(x)=0

则泰勒级数在该区间内收敛到 f(x)，即展开式成立。

01:56与 泰勒公式 泰勒公式的连接和区别

泰勒公式 的泰勒公式是有限项：f(x)=Tn(x)+Rn(x)，余项 Rn(x) 明确存在（拉格朗日型或佩亚诺型），用来求极限、估误差。泰勒级数则是把 n 推向无穷：只有余项 Rn(x)→0 时，无限和才真的等于 f(x)。一句话：泰勒公式是"截断到 n 次 + 余项"，泰勒级数是"令余项消失后的无穷和"。考试里 ex、sinx 等之所以能放心展开，正是因为它们的余项随 n→∞ 趋于 0（阶乘压住了一切）。

为什么要费劲展开：算得快

03:08老师打了个比方：e0.1 用计算器要按半天（其实计算器内部也是用展开算的），但展开取前三项 1+0.1+0.122=1.105，几乎立刻出结果，误差极小。像 ex、sinx 这些是非线性函数，计算机直接算很费时；而幂级数全是 xn 的加减乘，算得极快。老师还举了导弹制导的例子：导弹速度一马赫、两马赫往外飞，从发射到命中可能就一两秒，对反应时间要求极高、对精度要求相对宽松，正需要这种"用多项式近似"的思路。所以展开不是为了考试炫技，而是工程上"快"的刚需。

必背展开式（标出各自收敛域）

04:56下面是考试直接要用的装备。收敛域是算分的，漏写必扣分。

函数展开式（麦克劳林）收敛域记忆
ex∑n=0∞xnn!=1+x+x22!+⋯(−∞,∞)死记
sinx∑n=0∞(−1)nx2n+1(2n+1)!(−∞,∞)死记，只奇次
cosx∑n=0∞(−1)nx2n(2n)!(−∞,∞)对 sinx 求导
11−x∑n=0∞xn(−1,1)等比，死记
11+x∑n=0∞(−1)nxn(−1,1)把 −x 代入上式
ln(1+x)∑n=1∞(−1)n−1xnn(−1,1]对 11+x 积分
(1+x)α1+αx+α(α−1)2!x2+⋯(−1,1)泰勒展开，少用

17:34必背七式里，收敛域要分三类记，这能帮你少漏写那"一分"：全实数型（ex,sinx,cosx，分母阶乘压住一切，处处收敛）；(−1,1) 型（所有分式等比衍生式，端点一般都不取）；(−1,1] 型（只有 ln(1+x)，因为积分让右端点"捡回"一个收敛）。(1+x)α 一般只取 (−1,1)。把收敛域和公式绑在一起背，考场上才不会漏。

17:34现场推一遍 ln(1+x)（不用死记也能得）

从已知的 11+x=∑(−1)nxn（|x|&lt;1）出发，两边从 0 到 x 积分：左边 ∫0x11+tdt=ln(1+x)（因 x&gt;−1，绝对值可去）；右边逐项积分得 ∑(−1)nxn+1n+1=∑k=1∞(−1)k−1xkk。于是 ln(1+x)=∑(−1)k−1xkk，收敛域由端点 x=1 处交错收敛扩展为 (−1,1]。这条"等比→积分/求导"的推导链，让你即使忘了公式也能现场造出来。

25:14arctanx 的推导值得单独记：由 11+x2（把 11+x 里的 x 换成 x2 得到）两边积分，左边 ∫0x11+t2dt=arctanx，右边逐项积分得 ∑(−1)nx2n+12n+1，收敛域因两端点都交错收敛而扩展为 [−1,1]。它和 ln(1+x) 一样，积分让端点"多收一个"。

30:38ax 也常考，可由 ex 代换得到：ax=exlna=∑(lna)nn!xn，收敛域 (−∞,∞)。(1+x)α（二项式展开）考试很少直接考，真碰到了就用泰勒系数现场推前几项。这些"非死记"的式子，考试若用到又记不住，就当场从 11−x 或 ex 推，不必硬背。

直接法 vs 间接法

33:20把函数展开成幂级数有两条路：

直接法
逐阶求导，代泰勒系数公式 an=f(n)(x0)n!，并验证余项 →0。这就是课本开头的证明式，考试不考。
间接法（考试主流）
利用已知的必背展开式，配合代换、逐项求导、逐项积分，把目标函数拼出来。本节所有例题都用它。

33:20所谓直接法，就是硬算：an=f(n)(0)n!，逐阶求导代进去，并验证余项 Rn(x)→0。比如 ex 逐阶导都是 ex，在 0 处都是 1，直接得 ∑xnn!。课本用整页证明这些公式，但考试从不直接考证明——你只要会"间接法"拼装即可。直接法记住结论、间接法练手上功夫，分工明确。老师特意把直接法一笔带过，就是在帮你把精力放到刀刃上。

例 1：展成 x 的幂级数

例 142:32将 12+x 展开成 x 的幂级数，并求收敛域。

思路：提常数，凑成 11+u

目标是把分母变成"1+ 某物"。提出 12：

12+x=12⋅11+x2

套用 11+u=∑(−1)nun（|u|&lt;1），令 u=x2：

12+x=12∑n=0∞(−1)n(x2)n=∑n=0∞(−1)n2n+1xn

收敛条件 |x2|&lt;1，即 |x|&lt;2，收敛域 (−2,2)。

这一步最容易错

展开写完就收工，忘了收敛域。这道题收敛域从原来的 (−1,1) 整体替换成 (−2,2)，老师明确说"这个点忘写会扣一分"。凡做整体代换，收敛域一定要跟着变。

例 2：再来一个"提常数 + 换元"

例 247:10将 13−2x 展开成 x 的幂级数，并求收敛域。

思路：提 3，凑成 11−u

这里分母是"3−2x"，要凑成"1− 某物"。先提 3：

13−2x=13⋅11−2x3

套用 11−u=∑un（|u|&lt;1），令 u=2x3：

13−2x=13∑n=0∞(2x3)n=∑n=0∞2n3n+1xn

收敛条件 |2x3|&lt;1，即 |x|&lt;32，故 收敛域 (−32,32)。

和例 1 的对比

例 1 是"加号"对应 11+u（带 (−1)n 交错）；本例是"减号"对应 11−u（全正）。看清分母到底加减，决定要不要 (−1)n。这是两道题最容易混的地方，也是老师特意把这两个题放在一块比的原因。

例 3：展成 (x−x0) 的幂级数

例 348:24将 lnx 展开成 (x−2) 的幂级数，并求收敛域。

思路：(x−2) 永远不分开，凑出 ln(1+u)

唯一已知的对数公式是 ln(1+u)。把 x 写成 2+(x−2)，并提取 2：

lnx=ln(2+(x−2))=ln2+ln(1+x−22)

令 u=x−22，套用 ln(1+u)=∑(−1)n−1unn（|u|≤1 且 u≠−1，即右端点可取）：

lnx=ln2+∑n=1∞(−1)n−1(x−2)nn⋅2n

收敛条件 |x−22|&lt;1 得 |x−2|&lt;2，即 (0,4)；代端点：x=4 时 ∑(−1)n−11n 收敛（取），x=0 时 −∑1n 发散（不取）。故 收敛域 (0,4]。

例 4：先拆再展（收敛域取交集）

例 453:33将 1(x−1)(x−2) 展开成 x 的幂级数，并求收敛域。

思路：部分分式拆分

先拆：1(x−1)(x−2)=11−x−12−x。分别展开：

11−x=∑n=0∞xn(|x|&lt;1),12−x=12∑n=0∞(x2)n(|x|&lt;2)

相减并整理（把 12⋅12n 收进系数）得 ∑n=0∞(1−12n+1)xn。两部分收敛域分别是 (−1,1) 与 (−2,2)，取交集得 整体收敛域 (−1,1)。

53:33多个展开式合用时，收敛域要取交集

若一道题同时用了两个展开式（比如把 1(x−1)(x−2) 拆成 11−x 与 12−x 两部分分别展），每一部分都把自己的收敛域换出来，最后整个式子的收敛域是各部分交集。忘取交集、只写其中一个，是这类题第二大失分点（仅次于忘写收敛域本身）。口诀：每写一项展开，就带一个收敛域；最后整体取所有域的交集。

40:43考场清单

① 背熟上表七式及收敛域；② 看清题目要求"展成 x 的"还是"展成 (x−x0) 的"，后者把 (x−x0) 当整体；③ 常数项提出来、把分母凑成 1±u；④ 代换后收敛域整体替换并取交集；⑤ 端点用代入法（常为 ±1 的交错/调和）单独判断；⑥ 看清分母加减，决定系数要不要 (−1)n。

33:20间接法为什么合法：代换 / 求导 / 积分不改"收敛到的函数"

你可能会担心：把 x 换成 u=x2、或者对级数逐项求导积分，得到的还是原来那个函数吗？答案是肯定的，前提是操作在收敛域内进行。代换只是把变量整体改名，函数关系不变；而 幂级数（2） 的逐项求导、逐项积分性质，正是保证了"在收敛区间内，对幂级数求导/积分得到的幂级数，确实收敛到原和函数的导数/积分"。所以间接法的每一步都有 幂级数（2） 的定理撑腰，不是"凑巧算对"。这也解释了本页反复强调的"收敛域内才能乱动"——一旦踩到端点，就要重新验证等号是否成立。

04:56常见的整体代换错误：只换 x 不换收敛域

代换 u=x2 后，11+u 的收敛域是 |u|&lt;1，很多同学写到这里就停了，忘了把它翻回 x：必须解 |u|&lt;1⇒|x2|&lt;1⇒|x|&lt;2，收敛域从 (−1,1) 整体拉伸成 (−2,2)。更隐蔽的错是"只换分子不换收敛域"——比如例 2 得到系数 2n3n+1 后，若随手写"收敛域 (−1,1)"就满盘皆输。记住：每做一次整体代换，收敛域就跟着做一次同样的代数变换，最后再单独判端点。把"代换"和"换收敛域"绑成同一个动作，就不会漏。

30:38为什么 (1+x)α 的收敛域是 (−1,1) 且端点多半不稳

二项式展开 (1+x)α=1+αx+α(α−1)2!x2+⋯ 来自泰勒级数，比值法给出 ρ=1，所以内部 (−1,1) 必收敛。端点 x=±1 是否收敛取决于 α：当 α 为非负整数时级数有限项自然收敛；当 α 非整数或为负时，端点处一般发散。考试几乎不考这个式子的端点细节，所以记住"默认写 (−1,1)"最稳妥，别画蛇添足去讨论端点。它和 ln(1+x) 的 (−1,1] 不一样——后者积分"捡回"右端点，二项式没有这层福利，所以收敛域更"瘦"。

25:14arctanx 与 ln(1+x) 端点对比：都是积分"捡回"一个端点

ln(1+x) 由 11+x 积分得到，右端点 x=1 处交错收敛，收敛域扩为 (−1,1]；arctanx 由 11+x2 积分得到，两端点 x=±1 处都交错收敛，收敛域扩为 [−1,1]。两者的共同点是：被积函数只在 (−1,1) 收敛，但积分能"修补"端点，因为积分对端点级数多除了一个 n，原本临界发散的变得收敛了。相比之下，直接求导（如 cosx 由 sinx 求导）不改变收敛域，仍是 (−∞,∞)。所以"积分可能扩域、求导保域"是记忆收敛域的一条暗线，能帮你预判每个公式端点该不该多写一个括号。

33:20再补一句关于直接法：如果真要手算 ex 的麦克劳林系数，过程是 f(n)(x)=ex，故 f(n)(0)=1，系数 1n!，得到 ∑xnn!；验证余项用拉格朗日余项 eξ(n+1)!xn+1→0。这条路线课本讲得细，但考试从不出"请用直接法展开"这种题，所以理解即可，不必花时间练。把精力留给间接法的"拼装手感"——那才是分。

40:43看到"分母 = 常数 + 一次项"的统一处理

例 1 的 12+x、例 2 的 13−2x，以及它们的变体 1a+bx，都属于"分母是常数加一次项"。统一打法：先提常数让分母变成"1± 含 x 项"，再令 u= 那个含 x 的整体，套 11∓u。提常数这一步不能省，否则你套公式时 −1x 还是 −1x，没法对应到标准等比。熟练后这一步可以心算，但落笔时建议写出"提常数"这一步，既防错也得分，老师改卷时这一步本身就是采分点。

48:24展成 (x−x0) 时，为什么 (x−x0) 不能拆开当普通 x

例 3 把 lnx 展成 (x−2) 的幂，关键一步是令 u=x−22，把"(x−2) 整体"塞进已知公式 ln(1+u)。如果有人不把 (x−2) 当整体，而是硬把 lnx 想成"先展成 x 的幂再加个平移"，就会得到错误的结果——因为 lnx 在 x=0 处根本不定义，没法直接展成 x 的幂级数，必须换中心到 x=2。展成 (x−x0)n 的本质是"以 x0 为新的原点"，所有运算都围绕 (x−x0) 这个整体转，绝不允许把它拆成 x 减常数去套别的公式。一旦拆开，你就丢失了收敛中心的信息，收敛域也会算错。这也是老师用"成双成对、永远不分开"这种生活化比喻反复提醒的原因。记住：看到题目要求"展成 (x−x0) 的幂"，第一反应就是令 u=x−x0，把整个括号焊死，再走间接法三板斧——代换、求导或积分、最后整体回代收敛域。

40:43考场小技巧：先判类型再动手

动手前先问自己两件事：第一，题目要"展成 x 的幂"还是"(x−x0) 的幂"？第二，分母能不能凑成 1±u？这两问定了，方法就唯一了。很多同学一上来就乱代，结果代完发现收敛域不会换，白费功夫。先定型、再套公式、最后换收敛域，三步按顺序走，几乎不会卡壳，也不会漏写那关键的一分。
