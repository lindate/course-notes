P147【黑板】幂级数求收敛半径和收敛域：半径一步、端点三关

一句话核心

求收敛域只有两步：先定半径，再判端点。定半径时，标准型只看系数 ρ=lim|an+1an|、R=1ρ；缺项（只含 x2n 或 x2n−1）绝对不能套这个公式——系数里夹着零，比值会错位，只能带着 x 一起做比值判别。半径只给出开区间 (−R,R)，两个端点收不收敛必须代回去单独判，所以「收敛区间」永远开，「收敛域」是四选一。

黑板课先摆正位置：这一页只干一件事

00:00前面三节正课，幂级数的定义（幂级数（1））、性质与和函数（幂级数（2））、函数展开（函数的幂级数展开）都讲完了。这一页是习题课，任务单一：把「求收敛半径和收敛域」练成手上的条件反射。为什么要单独上一页？因为这块内容在期末考试里几乎是必出的——级数这一章能出题的点本来就不多，求收敛域和求和函数就是两大主力。

先把来路理一遍。之前两章研究的级数，通项写成 un，只和 n 有关。像 ∑1n2 这种正项级数、∑(−1)n−11n 这种交错级数，它们的敛散性是钉死的：收敛就一直收敛，发散就一直发散，你没有任何操作空间。01:43现在通项里多了一个 x，写成 un(x)，每一项都是一个函数，这就是函数项级数。它带来的新现象是：同一个级数，x 取这个值收敛，取那个值就发散。05:13于是要问：哪些 x 让它收敛？这些 x 的全体叫收敛域。

老师原话（附赠一个谐音梗）

如果它取 x0 的时候它是收敛的，那么这个点呢就叫收敛点……这个收敛点这个公式不是很重要，对吧，有的同学上课玩起来了，我就说你给我收敛点，对不对，哎就这个意思，收敛点对吧，收敛一点对吧。

玩笑归玩笑，关键在下一句：收敛点的全体叫收敛域，而收敛域是真正要算的东西。后面「收敛点」这个词几乎不再单独出现，你只需要盯住收敛域。

06:58函数项级数五花八门（∑sin(nx)、∑cosnxn 都算），但考试只考其中最好算的一支——幂级数，因为它的 x 只以「整数次幂」的形态出现，收敛域结构规整到可以用一个半径完全描述。本页剩下的内容，都是在兑现这句话。

宋老师的命名法：标准型与非标准型

课本上没有这个分类，是老师自己起的名字，但它非常好用，直接决定你该套哪个公式。判据只有一条：把级数写成 x（或 x−x0）的整数次幂以后，次数是不是一个不落地齐全。

15:39标准型 / 非标准型

标准型：形如 ∑anxn。注意 16:24老师特意放宽了范围——∑anxn+1、∑anxn−1 同样算标准型，因为奇次、偶次项都在，次数是连着的，系数与次数一一对应。

非标准型只有三种：① 只含偶次项，如 x2n；② 只含奇次项，如 x2n−1；③ 带中心，即 (x−x0)n。

阿贝尔定理：老师用「胖子瘦子」讲清了它只说一半

08:01阿贝尔定理本身考试很少直接用（偶尔出个小填空），但它是「收敛区间为什么关于原点对称」的唯一理由，听不懂它，后面所有结论都只是死记。

阿贝尔定理

对幂级数 ∑anxn：

（1）若它在 x=x0≠0 处收敛，则对一切 |x|&lt;|x0| 的 x，级数绝对收敛；

（2）若它在 x=x0 处发散，则对一切 |x|&gt;|x0| 的 x，级数发散。

12:18老师的原话是「这两句话我们同学一般理解得都不是很好」。于是他换了个讲法，非常有效：

14:13老师原话：胖子瘦子的定义

我说我们这个班，我们要重新定义胖子和瘦子。我们定义 80 斤是瘦子，那 70 斤是不是瘦子？是，因为定义的。90 斤是不是瘦子？不知道。……第二句话，我们定义了 100 斤就是胖子，那 110 斤是不是胖子？肯定是。99 斤是不是胖子？不知道。

15:08这个比喻把定理的单向性一次说明白了。已知某点收敛，相当于已知「x0 是瘦子」，那么比它瘦的一定也是瘦子——也就是 |x|&lt;|x0| 全都绝对收敛。已知某点发散，相当于已知「x0 是胖子」，那么比它胖的一定也是胖子——|x|&gt;|x0| 全都发散。至于比已知收敛的点更远的那些 x（更胖的瘦子），定理一个字也没说。

为什么「只知道 x=2 收敛」推不出「x=3 收敛」

假设有人告诉你某个幂级数在 x=2 处收敛。那 x=1 呢？由阿贝尔定理（1），|1|&lt;|2|，一定绝对收敛，这个能答。那 x=3 呢？|3|&gt;|2|，定理给不出任何信息——它可能是收敛的，也可能是发散的，两种都能构造出例子。所以遇到「已知某点敛散、问另一点敛散」的题，先比较绝对值的大小：小的问大的，答不出来；大的问小的，一定有答案。这就是「胖子瘦子」的全部用法。

同样的道理反过来看发散：已知 x=2 发散，则 x=3、x=4 都发散（在它外头），而 x=1 收不收敛不知道。定理的两条合起来，恰好把数轴切成了「内必收敛」和「外必发散」两块，中间那条分界线正是收敛半径 R。

半径公式：标准型只看系数，xn 那部分不进来

16:58对标准型 ∑anxn，直接上公式。老师强调了两遍这句话：ρ 里只有系数 an，xn 那部分不参与——因为 x 会被提出来，剩下的系数比才决定临界值。17:57至于 ρ 为什么写成后一项比前一项，老师给了个很直白的提醒：这就是上一章正项级数的比值判别法，L&lt;1 收敛、L&gt;1 发散，只不过现在 L 里含 x，所以「L&lt;1」变成了一条关于 x 的不等式。

ρ=limn→∞|an+1an|,R=1ρ
ρ 的取值收敛半径 R收敛区间典型来源
0&lt;ρ&lt;∞R=1ρ(−R,R)系数是 n 的有理式
ρ=0R=∞(−∞,∞)系数含 1n!，衰减极快
ρ=∞R=0只有 x=0系数含 n!，增长极快

19:53三种情况不用背三段，老师教了个「偷偷记」的办法：把 R 一律写成 R=1ρ。ρ=0 就想象「零放分母，取极限是无穷大」，ρ=∞ 就想象「无穷大倒过来是零」。老师自己说「我只是说去想象，我这个地方不是严格的一个证明」——但对做题足够了，因为真正的推导（|x|ρ&lt;1）已经把三种情况统一在一个不等式里。

为什么 ρ=0 是「处处收敛」而不是「处处发散」

把 x 提出来以后，收敛的判据是 |x|⋅ρ&lt;1。ρ=0 时，无论 x 多大，左边都是 |x|⋅0=0&lt;1——不等式恒成立，所以 x 随便取都收敛。这里的 0 是真正的零，|x|⋅0 就是 0，不存在洛必达里那种 0⋅∞ 的未定式问题（x 是取定的有限数，零乘任何有限数都是零）。

反过来，ρ=∞ 时只要 x≠0，|x|⋅∞=∞¬&lt;1，不收敛；只有 x=0 时 0⋅∞ 按「真零」处理得 0&lt;1，才收敛。所以 R=0 的含义是收敛域退化成孤零零的一个点，而不是「没有收敛点」。

收敛半径、收敛区间、收敛域：三个词，三个不同的东西

21:18这是本页最容易被审题坑到的地方。老师把三个概念并列摆出来：收敛半径 R 是一个数；收敛区间是 (−R,R)，两边永远开、不判端点；收敛域要判两个端点，是四种写法之一。题目问「求收敛区间」就写开区间收工，问「求收敛域」就必须往下做。

23:20端点上为什么「公式失效」而不是「公式给答案」

把 x=R 代进去，级数变成 ∑anRn，是一个常数项级数。原来那条判据 lim|un+1un|=|x|ρ 在 |x|=R=1ρ 处正好等于 1——比值判别法在极限等于 1 时本身就不下结论。所以这不是「端点算不出来」，而是「端点处那件工具恰好失效」，只能换工具：把 x=±R 代回去，认清它变成的是交错级数、p 级数还是调和级数，用莱布尼茨定理或已知结论判。

这也是为什么端点必须两个都代：x=R 代入后是 ∑anRn，x=−R 代入后是 ∑(−1)nanRn，两者一个是正项一个是交错，敛散性可以完全不同。

三个典型题：把三种结局演一遍

例 124:26求 ∑n=1∞(−1)n−1xnn 的收敛半径与收敛域。

思路：标准型，ρ 只取系数

系数是 an=(−1)n−11n。老师边写边强调：后一项朝里带、前一项朝里带，xn 不拿，绝对值一加，(−1) 那部分自动消失：

ρ=limn→∞|(−1)n1n+1(−1)n−11n|=limn→∞nn+1=1

于是 R=1ρ=1，收敛区间是 (−1,1)。25:37再判两个端点：

x=1 时原级数变成 ∑(−1)n−11n，是交错级数，1n 递减趋于 0，由莱布尼茨定理收敛。

26:28x=−1 时，(−1)n−1 与代入的 (−1)n 相乘得 (−1)2n−1=−1，级数变成 −∑1n，是调和级数加负号，发散。

所以收敛域是 (−1,1]——左开右闭，一个关于原点不对称的收敛域。

这一步最容易错

看到 (−1)n−1 就以为两个端点都是交错级数、都收敛。端点必须把 x 代进去再数符号：x=−1 时两个 −1 的幂叠起来变成纯负号，交错结构被抵消掉了。老师原话：这个端点是收敛的，这个端点是发散的——同一道题的两个端点，命运可以完全不同。

例 2 与例 328:03求 ∑n=0∞xnn! 与 ∑n=0∞n!xn 的收敛域。

例 2：分母是阶乘 → ρ=0 → R=∞
ρ=limn→∞|1/(n+1)!1/n!|=limn→∞1n+1=0

R=∞，收敛域是 (−∞,∞)，x 随便取，也没有端点可判。

例 3：分子是阶乘 → ρ=∞ → R=0
ρ=limn→∞|(n+1)!n!|=limn→∞(n+1)=∞

31:25R=0，只有 x=0 收敛。老师在这里专门停下来纠正一个写法：收敛域是不是就是零啊？不对，收敛域是个集合，它只有一个点是不是零，那写集合怎么写啊，是不是由零这一个点组成的集合——答案是 {0}，一个点集，不是区间。

33:13「猛不猛」：收敛域的大小是由系数决定的

为什么例 2 处处收敛、例 3 只在一个点收敛？老师用的词是猛不猛。∑xnn! 的分母是 n!，「n! 是不是特别猛啊？它放分母上，它趋于零老猛了」——只要你取定的 x 是有限数（哪怕 1000、1 万、1 亿），n! 迟早压住 xn，所以处处收敛。34:19反过来 ∑n!xn 里 n! 在分子上，「它趋于无穷的速度忒大了，这个 x 就是取个 0.1，乘上 n! 以后也老大」，除非 x=0 让每一项直接归零。

35:05老师当场出了个预测题：∑2nxn 与 ∑3nxn 谁的收敛域大？答案是后者——3n 在分母上更猛，压得更快，x 就允许取到更大。算出半径分别是 2 和 3 正好印证。所以 R 的本质是一个「赛跑」结果：xn 与系数谁增长得更快。这也解释了为什么看到阶乘要先想「它在分子还是分母」——位置直接告诉你半径是 0 还是 ∞。

大坑：缺项时不能用系数比值公式

38:56这是本页最重要的一段。老师先让同学自己在书上记一句：遇到 ∑(2n)!(n!)2x2n 这种只含偶次项的，先标上「非标准形式」。39:59然后明确给出非标准型的公式与标准型的差别：标准型只把系数 an 拿过来，带 x 的部分不拿；非标准型必须把带 x 的部分通通拿过来，即用 lim|un+1(x)un(x)|&lt;1。

例 4（缺项）39:59求 ∑n=0∞(2n)!(n!)2x2n 的收敛半径与收敛域。

思路：带着 x 一起比，让次数差回到 1

写出后一项比前一项，注意 x 的部分也要朝里带：

limn→∞|un+1un|=limn→∞(2n+2)(2n+1)(n+1)2⋅|x|2=4|x|2

41:05阶乘相消后剩下 (2n+2)(2n+1)/(n+1)2，抓大头得 4；而 x 的部分相除得 x2n+2/x2n=x2，取绝对值就是 |x|2。41:50老师把这一步说成「非标准形式是后一项比前一项，比完直接小于一」，即令

4|x|2&lt;1⟹|x|&lt;12

所以 R=12，收敛区间 (−12,12)。端点 x=±12 代入后，通项是 (2n)!(n!)214n，用中心二项式系数估计，它约等于 1πn——虽然趋于 0，但衰减太慢，∑1n 发散，所以两个端点都发散，收敛域是 (−12,12)。

这一步最容易错

把 x2n 当成 xn，直接对系数 (2n)!(n!)2 套 ρ 公式。那样算出的 ρ=4，R=14——整整差一倍。错在哪里？系数公式默认相邻两项次数差 1，而这里第 n 项是 x2n、第 n+1 项是 x2n+2，中间的 x2n+1 系数是 0：你比的其实是「隔了一个零」的两个系数，比值里隐含的 |x|2 因子被无视了。老师原话就是这个意思：这种啊叫做非标准形式，非标准形式带 x 的部分通通拿过来。

另一种算法：换元 t=x2

43:03老师说只有偶次项时还有第二条路：令 t=x2，级数变成 ∑(2n)!(n!)2tn，这是 t 的标准型，套公式得 ρ=4、Rt=14，即 |t|&lt;14，代回 x2&lt;14 得 |x|&lt;12，与直接比一致。

为什么只有偶次项能换元

老师强调：只有偶次项可以换元，只有奇次项不能。因为 t=x2 会把奇次项打乱成 t 的半整数次幂，没法再叫标准型；偶次项则被整齐地压成 tn。所以碰到缺奇次的（如 x2n−1），老老实实带着 x 直接比，别硬换元。

带中心的 (x−x0)n：两种写法都行

例 543:56求 ∑n=1∞(x−1)n2nn 的收敛域。

做法一：换元 t=x−1

令 t=x−1，级数化为 ∑tn2nn，是 t 的标准型。系数比 2nn2n+1(n+1)→12，所以 ρ=12、R=2，即 t∈(−2,2)。

49:47代端点：t=2 时 ∑2n2nn=∑1n 发散；t=−2 时 ∑(−1)nn 收敛。所以 t 的收敛域是 (−2,2]，换回 x−1∈(−2,2]，得 x∈(−1,3]。50:37老师特别提醒这一步：算出的 R 是关于 t 的，「它是关于 t 的，因为咱现在搞的是 t」，一定要换回 x 再判端点。

做法二：带着 x 直接比

老师把两条路都写在黑板上让大家对照。直接比时把 x−1 当成整体，后项比前项：

|un+1un|=n2(n+1)|x−1|→12|x−1|

令它 &lt;1 得 |x−1|&lt;2，同样得到 x∈(−1,3)。50:37两条路结果完全一致——老师说这正说明「标准形式和非标准形式做题怎么回事，我给你讲清楚了没有」。

换元后忘记换回

算出 R=2 就写「收敛域 (−2,2]」收工。那是 t 的收敛域。题目问的是 x，必须做一次平移：x−1∈(−2,2]⇒x∈(−1,3]。这个错误和 幂级数（1） 里「缺项换元后忘换回」是同一个病根。

例 6（老师临时出的一道）52:28求 ∑n=1∞xn+1n2 的收敛域。

思路：xn+1 也属于标准型

老师先让同学判断型：有人会看着 xn+1 觉得「不像标准型」，但标准型里明确包含 xn±1，次数是连着的、系数一一对应，所以照套公式，只取系数之比：

ρ=limn→∞|1/(n+1)21/n2|=limn→∞n2(n+1)2=1,R=1

收敛区间 (−1,1)。53:16代端点：x=1 时级数变成 ∑1n2，这是 p=2 的 p 级数，收敛；x=−1 时是 ∑(−1)n+1n2，交错且绝对值级数收敛，也收敛。所以收敛域是 [−1,1]——两个端点都捡回来了。

黑板上的四行检查清单

① 先认型：次数齐全 = 标准型套 ρ；缺偶次 / 缺奇次 / 带中心 = 非标准型，带着 x 直接比或换元。
② 再求半径：只取系数比，xn 不参与；ρ=0⇒R=∞，ρ=∞⇒R=0。
③ 写区间：收敛区间 (−R,R) 永远开；R=∞ 无端点可判，R=0 的收敛域是点集 {0}。
④ 判端点：x=±R 代回原级数，认清它变成交错级数、p 级数还是调和级数。

记忆入口 · 一眼回忆

一条链

认型 标准 / 非标准→ 求 ρ 只取系数（或带 x 直接比）→ 得半径 R=1ρ→ 写收敛区间 (−R,R) 必开→ 判端点 代回原级数

核心两式

ρ=limn→∞|an+1an|,R=1ρ
limn→∞|un+1(x)un(x)|&lt;1（非标准型专用）

要背的

  • 标准型包含 xn、xn+1、xn−1；非标准型只有缺偶次、缺奇次、带中心三种。
  • ρ=0⇒R=∞（系数衰减超快，如 n! 在分母）；ρ=∞⇒R=0（如 n! 在分子）。
  • 收敛区间永远开；收敛域是 (−R,R)、(−R,R]、[−R,R)、[−R,R] 之一。
  • R=0 时收敛域是点集 {0}，不是区间。

三个坑

  • 缺项还套系数公式。x2n 型会少乘一个 |x|2，半径差一倍（R=12 被算成 14）。
  • 换元后不换回。算出的是 t 的半径，必须换回 x 再判端点。
  • 只算一个端点。两个端点一个是正项、一个是交错，敛散性可以完全不同——例 1 就是 (−1,1]。

容易混
