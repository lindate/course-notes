P143【黑板】格林公式及应用：三查、挖洞、凑全微分

一句话核心

格林公式把闭曲线上的第二型曲线积分与区域上的二重积分焊在一起：∮LPdx+Qdy=∬D(∂Q∂x−∂P∂y)dσ，其中 L 取正向、P、Q 在 D 上有一阶连续偏导。黑板课上真正决定成败的不是公式，而是套公式之前那三查：曲线闭吗？方向正吗？区域内有没有让偏导失效的奇点？三查里任一条不过关，就要请出补线、变号和挖洞。

先认两个区域、一条边界、一个方向

03:56格林公式只用到两个新概念，而且都很直观。老师说得很松：没有洞的一大块，叫单连通区域；中间挖了一个洞的，叫复连通区域。平面上整个圆盘是单连通的；环形区域、挖掉一个点的圆盘都不是。这两个词平时用不上，但一旦遇到「奇点」的题，它们就是唯一的出路。

05:04围成区域的这条曲线叫边界曲线。边界曲线要谈方向，方向只有一个判据：

05:04正向的定义

沿着边界曲线行走，如果区域始终在你左手侧，这个方向就叫正向。

推论：单连通区域只有一条边界，它的正向就是逆时针；复连通区域有两条边界，外面那条的正向仍是逆时针，而里面那条（洞的边界）的正向是顺时针——因为只有顺时针走，洞外面的区域才在你的左手边。

格林公式，以及那个必须死记的地方

07:29定理 · 格林公式

设闭区域 D 由分段光滑的闭曲线 L 围成，P(x,y)、Q(x,y) 在 D 上具有一阶连续偏导数，则

∮LPdx+Qdy=∬D(∂Q∂x−∂P∂y)dσ

其中 L 取正向（沿 L 行走时 D 在左手侧）。左边的一圈圈儿（∮）说明它是闭曲线上的积分。

公式里有两处必须逐字核对，错了整道题就废：09:26第一，右边是 ∂Q∂x−∂P∂y——Q 对 x 求偏导，减 P 对 y 求偏导，交叉着的，而且顺序是「先减号后那一项」；第二，左边是第二型曲线积分（对坐标），不是对弧长的第一型。老师直说这条得死记。

15:03为什么要有格林公式：把难的换成熟的

公式存在的理由只有一句话：曲线积分难算，二重积分熟。

回头看例 1 就知道差距有多大。直接按第二型的算法硬做，要写出 x=acost、y=asint，把被积函数代进去、把 dx、dy 分别求出来，再定限、再算一个全是三角函数乘方的定积分——26:32老师原话是「我写了这一大堆式子，这个还真不一定怎么好记」。而在右边做二重积分，被积函数极坐标化以后只剩 −r3，几行就完事。

所以格林公式的正确身份是一件降计算量的工具，不是一条定义。15:03老师还问了句实在话：「二重积分你是喜欢做还是曲线积分喜欢做？」答案是谁都不喜欢，但两个里头总得挑一个——挑那个熟一点的。

套公式之前先过三关

09:26公式的三个条件看着抽象，落到题目上其实是三句具体的追问。任何一句答「不」，都要先做补救：

三查条件不满足时会发生什么补救办法
① 曲线闭吗 不闭就没有「围成的区域 D」，右边那个二重积分无从谈起 补线法：补一段曲线凑成闭环，整体用格林公式算出结果，再单独算出补上的那一段并减掉。补哪条线很自由，通常选坐标轴上的直线或好算的线段
② 方向是正向吗 反向绕行，公式两边的符号都要翻 先把区域在左手侧的判据用一遍；如果题目给的是反向，就先按正向算出结果，整体加一个负号
③ P、Q 在 D 上处处有一阶连续偏导吗 09:26若 D 里有让分母为零的点，偏导在那里不存在，公式的前提塌掉 挖洞法：在奇点周围作一条很小的圆，把奇点从区域里挖出去；剩下的是复连通区域，格林公式仍然成立，只要两条边界都按正向取

例题

例 116:34计算 ∮Lx2ydx−xy2dy，其中 L 是正向圆周 x2+y2=a2。

思路：先过三关——闭、正向、偏导连续，三关全过就直接套公式

三查：L 是整圆，闭；题目明说是正向；P=x2y、Q=−xy2 是多项式，处处有一阶连续偏导。可以用格林公式。

先把 P、Q 认准（13:01dx 前面的是 P，dy 前面的是 Q），再算那个交叉偏导：

∂Q∂x=−y2,∂P∂y=x2,∂Q∂x−∂P∂y=−(x2+y2)

于是积分变成一个圆面上的二重积分。26:32区域是圆面，上极坐标：x2+y2=r2，还要多一个 r，

∮L=∬D−(x2+y2)dσ=−∫02πdθ∫0ar2⋅rdr=−2π⋅a44=−πa42
26:32对比一下：不用格林公式要写多少东西

直接算这条曲线积分，得先写 x=acosθ、y=asinθ，θ 从 0 到 2π（因为题目给了逆时针），然后

dx=−asinθdθ,dy=acosθdθ

再把 x2ydx 与 −xy2dy 两项分别代、分别积，全程四五个三角函数乘方。结果当然一样，但时间和出错概率都翻好几倍。这就是格林公式存在的意义。

要点：只要 ∂Q∂x−∂P∂y 化简后是常数或者只跟 r 有关，格林公式几乎稳赢。13:01唯一的死记点是别把 P、Q 认反、别把减号写错。

例 233:21计算 ∬De−y2dσ，其中 D 是由 O(0,0)、A(1,1)、B(0,1) 围成的三角形区域。

思路：这是个二重积分，但用普通方法做不出来——只好反过来用格林公式

先按老办法试一遍。用 X 型：先对 y 积，被积函数是 e−y2——33:21这个函数对 y 求原函数是积不出来的（它的原函数不是初等函数），所以 X 型这条路直接堵死。改用 Y 型：y 从 0 到 1，x 从 0（左边）到 y（右边），

∬De−y2dσ=∫01dy∫0ye−y2dx=∫01ye−y2dy

这一步之所以能过，是因为对 x 积分时 e−y2 是常数，可以提出来，剩下的 ∫0ydx 就是 y。接下来把 y 凑进微分：ydy=12d(y2)，于是

=12∫01e−y2d(y2)=12(1−e−1)

33:21课本给的是另一条路：把格林公式反着用。既然公式说 ∮LPdx+Qdy=∬D(∂Q∂x−∂P∂y)dσ，那就找一个 Q 使得 ∂Q∂x=e−y2，于是取 Q=xe−y2、P=0（33:21书上没写这个 0，建议自己补上 0dx，不然看不出 P 在哪）：

∬De−y2dσ=∮L0dx+xe−y2dy

右边这条闭曲线按正向是 O→A→B→O（OA:y=x，AB:y=1，BO:x=0）。三段分开算：AB 上 y=1 是常数，dy=0，贡献 0；BO 上 x=0，被积函数整个是 0，贡献也是 0；只剩 OA：

∫OAxe−y2dy=∫01xe−x2dx=12(1−e−1)

要点：两种做法答案一致。反着用格林公式的价值在于——它可以把「积不出来的二重积分」变成「好算的曲线积分」，这也说明公式是双向的，哪边好算就往哪边走。另外这道题里 AB、BO 两段之所以白送，正是因为其中一段有常数微分为零，这也是选边界时优先挑坐标轴平行线段的理由。

例 348:33计算 ∮Lxdy−ydxx2+y2，其中 L 是一条不经过原点、分段光滑的闭曲线，方向为逆时针。分两种情况：① L 不包围原点；② L 包围原点。

思路：第三关过不去——分母里有 x2+y2，原点是一个奇点

先认 P、Q：dx 前面是 P=−yx2+y2，dy 前面是 Q=xx2+y2。求交叉偏导：

∂P∂y=y2−x2(x2+y2)2,∂Q∂x=y2−x2(x2+y2)2

两者相等，所以 ∂Q∂x−∂P∂y=0。但别急着写答案 0。48:33题目只说「曲线不经过原点」，并没有说曲线围的区域不包含原点——这句话是本页最要命的一个措辞。原点处两个偏导都没有定义，三查的第三关能不能过，全看 L 到底圈没圈住原点。

情况 ①：L 不包围原点。这时原点不在区域 D 内，D 上处处 x2+y2≠0，P、Q 一阶连续偏导，三关全过。被积函数是 0，二重积分为零：

∮L=0

情况 ②：L 包围原点。这时 D 里有原点，第三关过不去。56:26办法是挖洞：在原点周围作一个半径 r 很小的圆 l（x2+y2=r2），把它整个塞在 L 的内部。于是 L 与 l 围成的复连通区域 D1 上，P、Q 处处有一阶连续偏导，格林公式可以用了。

方向要当心。由正向判据，L（逆时针）是正向，而 l 的正向是顺时针。为了记法统一些，老师写成 L+l−，意思是「L 逆时针，l 再取反方向」，这样两条边界都是正向。在 D1 上用格林公式：

∮L+l−xdy−ydxx2+y2=∬D10dσ=0

再由可加性拆开，并利用「反向变号」∫l−=−∫l：

∮L=−∫l−=∫l

也就是说，绕大圈的积分等于绕小圈的积分。小圈上 x2+y2=r2，可以直接代进被积函数（它是一条曲线，曲线上的方程当然能带）：

∮L=1r2∫lxdy−ydx

再把 l 参数化：x=rcosθ、y=rsinθ，θ 从 0 到 2π，则 dx=−rsinθdθ、dy=rcosθdθ，

xdy−ydx=r2(cos2θ+sin2θ)dθ=r2dθ
∮L=1r2∫02πr2dθ=2π

要点：同一个被积函数，绕不绕原点结果完全不同（0 与 2π）。这说明「交叉偏导相等」这件事，在区域有洞的时候不再能推出「闭路积分为零」——两种情况的差别不在函数，而在「区域是不是把奇点圈进去了」。这也正是需要单连通概念的场合。

路径无关：一个条件，四种说法

1:06:49格林公式的第二个大用途，是回答「这条曲线积分能不能换条路走」。先把话说清楚：这里讲的是平面上的曲线积分。

1:09:10定理 · 与路径无关的充要条件

设 G 是单连通区域，P、Q 在 G 内具有一阶连续偏导数，则曲线积分 ∫LPdx+Qdy 与路径无关（只与起点、终点有关）的充要条件是

∂P∂y=∂Q∂x在 G 内处处成立
1:06:49证明只是「拼一个闭曲线」，但那条小圈圈不许乱加

思路一共三句：

取两条都从起点到终点的曲线 L 和 L1，把 L1 掉个头（记作 L1−），与 L 首尾相接，就缝出了一条闭曲线。因为它围成的区域是单连通的、P、Q 又有一阶连续偏导，格林公式可以用，被积函数因 ∂P∂y=∂Q∂x 而恒为零，所以这条闭曲线上的积分为零。

再用可加性把闭曲线拆回两段：∫L+∫L1−=0，也就是 ∫L=∫L1。换一条路 L2 再做一遍，得到同样的结论，于是「怎么走都一样」。

1:12:23这里有一个细节老师单独点了出来：小圈圈只能加在封闭曲线上。原来 L 与 L1− 拼起来是闭的，所以能写 ∮；一旦拆开成 L 和 L1，两条都不再封闭，那个圈就必须去掉。「∮ 与 ∫」的区别不是排版习惯，它是在声明「这条曲线闭不闭」。

例 41:17:03验证 ∫(1,0)(2,1)(2xy−y4+3)dx+(x2−4xy3)dy 与路径无关，并求它的值。

思路：先验条件（一求导就知道），再挑最好走的路，最后还可以用原函数直接做差

第一步：验证。认出 P=2xy−y4+3、Q=x2−4xy3，各求一个偏导：

∂P∂y=2x−4y3,∂Q∂x=2x−4y3

处处相等，且整个平面是单连通的，所以与路径无关。

第二步：换一条好走的路。1:17:03既然与路径无关，就挑最简单的折线：先从 (1,0) 水平走到 (2,0)，再竖直走到 (2,1)。

第一段 y≡0，于是 dy=0，P=2x⋅0−0+3=3，只剩 ∫123dx=3。

第二段 x≡2，于是 dx=0，Q=4−8y3，只剩 ∫01(4−8y3)dy=4−2=2。

两段相加：

∫(1,0)(2,1)=3+2=5

第三步：更高级的做法——凑全微分。1:21:14既然与路径无关，就说明存在一个二元函数 u(x,y)，使 du=Pdx+Qdy。找它的窍门是「一条一条对」：看 ∂u∂x=2xy−y4+3，里面的 2xy 只能来自 x2y（因为对 x 求导会掉一个 2x 出来），−y4 提示要对 y 求导前是 −xy4，常数 3 来自 3x。合起来

u(x,y)=x2y−xy4+3x

验证：ux=2xy−y4+3 ✓，uy=x2−4xy3 ✓。于是积分等于原函数在两端点的差：

u(2,1)−u(1,0)=(4−2+6)−(0−0+3)=8−3=5

要点：三种做法（折线硬算、凑原函数、直接观察）都给 5。凑原函数这一步值得练——它就是「二元函数的不定积分」，考试里如果是填空题，很多时候可以直接猜：1:21:14看到 cosxsinydx+sinxcosydy 就要立刻想到 u=sinxsiny。猜出来的答案，用两条偏导回去验一遍即可。

顺带一用：面积公式

26:32在格林公式里取 P=−y2、Q=x2，被积函数 ∂Q∂x−∂P∂y=12+12=1，右边就退化成区域面积：

A=12∮Lxdy−ydx

例 530:05用面积公式求椭圆 x=acost、y=bsint 所围图形的面积。

思路：正不用背椭圆面积公式，只要会参数化边界

椭圆转一圈，t 从 0 到 2π（这个方向就是逆时针，即正向）。先算 dx=−asintdt、dy=bcostdt，于是

xdy−ydx=abcos2tdt+absin2tdt=abdt
A=12∫02πabdt=12⋅2πab=πab

取 a=b=R 就回到圆的面积 πR2。要点：这个公式的适用条件与格林公式完全一样——闭、正向、偏导连续。P=−y2、Q=x2 都不含分母，处处光滑，所以对任意分段光滑的闭曲线都好用。

记忆入口 · 一眼回忆

一句话

格林公式：闭曲线上的第二型积分 = 它围成的区域上的二重积分。用之前先过三关：闭、正向、偏导连续。

核心两式

∮LPdx+Qdy=∬D(∂Q∂x−∂P∂y)dσ
A=12∮Lxdy−ydx

一条链

过三关 闭 · 正向 · 偏导连续→ 不过就补救 补线 / 变号 / 挖洞→ 换上二重积分 极坐标或 Y 型→ 算出结果

要背的

  • P 是 dx 前面的，Q 是 dy 前面的；右边是 ∂Q∂x−∂P∂y，交叉、带减号。
  • 正向 = 区域在左手侧：外边界逆时针，内边界顺时针。
  • 路径无关的判据：∂P∂y=∂Q∂x，前提是单连通。
  • 与路径无关后，换折线（一段 dy=0、一段 dx=0）或凑原函数做差。

三个坑

  • 看到 ∂Q∂x=∂P∂y 就直接答 0。还得看曲线有没有圈住奇点（例 3 的两种情况答案差 2π）。
  • 只按「逆时针」判断正向。有洞时内边界必须顺时针，判据只有「区域在左手侧」。
  • 把 ∮ 随便写在没封闭的曲线上。拆段以后曲线不闭，小圈圈必须去掉。
