P022复合函数求导

一句话核心

复合函数求导是整章的必考点：考试不会考光秃秃的基本公式，一定考套了层的复合函数。核心就是链式法则 dydx=dydu⋅dudx，宋老师更爱叫它洋葱法则——从最外层一层一层往里剥，每层求导、最后全部相乘。

为什么要打五角星：这是考试必考点

00:03老师一上来就提醒：这部分打上一个五角星，最最重要。原因很现实——这一章叫「导数」，考试就考「求导」；而前面那些简单的基本公式（(sinx)'=cosx、x2 求导是 2x）太简单，不会直接考，真正考的一定是套了层的复合函数。所以复合函数求导，任何考试都要考到。

先回想复合函数长什么样。比如

y=ln(tanx)

把它拆开：令 y=lnu，而 u=tanx 塞进去，就得到 ln(tanx)。这里 u 叫中间变量。带进去之后，y 最终只和 x 有关，但中间隔了一层——这就是复合函数。

复合函数求导定理（链式法则）

设 u=g(x) 在 x 处可导，y=f(u) 在 u=g(x) 处可导，则复合函数 y=f(g(x)) 在 x 处也可导，且

dydx=f'(u)⋅g'(x)=dydu⋅dudx
01:46为什么定理要写全那两个条件

定理的两个前提不是在凑格式：「u=g(x) 在 x 处可导」和「y=f(u) 在 u=g(x) 处可导」。老师把第一句拆开讲了：咱这个 x 取定以后，这个 u 就是一个固定的值了；那这个 f 它是 u 的函数，所以 f 就是在 u 这个地方可导。

说人话：f'(u) 里的 u 必须先落到实处（是 g(x) 在某个 x 上的取值），「f 在这一点的导数」才有意义，不然 u 还在跑，导给谁看？换成变化率的语言——链式法则要的是两段局部变化率：u 随 x 变得多快、y 随 u 变得多快。两段都真实存在，才能乘起来。少任何一段，链子就断了。

定理在说什么：先对中间变量求，再乘里面

02:38结论写成 dydx=f'(u)⋅g'(x)。这里两个导数要分清角色：

f'(u)
是对 u 求导。因为 f 本来就是 u 的函数，u 在这里只是个变量名。
g'(x)
是对 x 求导，这个我们比较熟。
04:19得改掉一个旧习惯：谁对谁求导只是变量名

以前大家的脑子里只有「y 对 x 求导」：(sinx)'=cosx，(x2)'=2x。但复合函数求导要求你接受：「对谁求导」本质上只是换个变量名。sinu 对 u 求导也是 cosu；u2 对 u 求导也是 2u。

老师原话：「说白了不就是个变量名吗？你 Y 对 X 求导，Y 和 X 是不是就是个变量名而已。」一旦接受了这点，链式法则就不再是死记硬背，而是「外层函数对它的自变量求，再乘内层对 x 求」。

链式法则：把两个导数「链」起来

04:57英文叫 chain rule（链式），因为它把两个微分像链子一样串起来：

dydx=dydu⋅dudx

左边是「y 对 x 的导数」，右边是「y 对 u 的导 × u 对 x 的导」。中间的 du 像约分一样消掉了——虽然微分严格说不能随便约，但这个乘法结构正是链式法则的样子。

多层复合：链子可以很长

06:06如果复合不止两层，比如 y 是 u 的函数、u 是 t 的函数、t 又是 x 的函数，那么

dydx=dydu⋅dudt⋅dtdx

07:20老师的比喻很形象：「这仨式子就跟那个链子一样给它串在一起。」他本想从家里找条大铁链子挂脖子上，结果孩子只给了他一条小链子——但「一层套一层」的意思到了。链式的名字就是这么来的：有多少层中间变量，就乘多少段导数。

06:06多层复合的「展开书写」：给自己留一条检查的路

层数一多，光靠脑子里数「外、中、里」很容易漏。稳当的做法是把中间变量一个个写出来、把连乘式摊平，最后再代回去。以 y=ln(cosex) 为例：

y=lnu,u=cost,t=ex
dydu=1u,dudt=−sint,dtdx=ex

按链式法则逐段相乘：

dydx=1u⋅(−sint)⋅ex

最后一代：u=cosex、t=ex，得 y'=−sinexcosex⋅ex=−extanex，和直接剥洋葱的结果一致。

这么写为什么更安全？看相邻两段的接口：dydu 的分母是 u，下一段 dudt 的分子恰好也是 u；再接 dtdx，一路首尾相接、最后收口到 x，像约分一样串起来。写完只要检查「接口对不对得上」，漏层或写错变量立刻现形。熟练之后这一步当然可以省掉，直接心里剥。

洋葱法则：宋老师的「一层一层剥」

10:08老师话锋一转：「刚才讲的那些，从开头到现在你一个字也不用学——不用学！」乍一听吓人，其实他想引出一个更好用的说法：洋葱法则（onion rule）。

11:17核心就一句：复合函数求导，从最外层开始，一层一层往里剥，每层先求导，最后全部相乘。为了好记，老师让大家把所有内层都叫「what」（就是 u）：

  • x2 求导是 2x；做题时它不一定是 x，可能是个整体 u，所以记住：「what 平方求导 = 2 what」。
  • (sinu)'=cosu → 「sin what 求导 = cos what」。
  • (lnu)'=1u → 「ln what 求导 = what 的倒数」。

13:45这个「what 语言」老师是给留学生讲课时想出来的，结果老外教材真叫它 onion rule（洋葱法则）——一层包一层，跟平常吃的洋葱一模一样。所以：复合函数求导 = 洋葱法则，从外往里一层层求，逐层相乘。

13:45顺带交代：「洋葱法则」这名字是宋老师自己起的

老师自己承认这名字是编的：老师你自己又在那瞎琢磨名字吗？真有这个洋葱法则吗？前面这个夹逼定理的时候，还给我们讲过一个汉堡定理，对不对？汉堡法则——现在又出现一个洋葱法则。这两个名字呢，是我给留学生上课的时候我想的啊。后来我看老外的教材，他们也这么叫，真的叫 onion rule。

所以要分清楚：课本上印的是「链式法则」，课堂上喊的是「洋葱法则」，指的是同一个东西。名字是特意起得顺口好记的，操作还是那一条——从外往里逐层求、逐层乘。别因为卷子上写的是「链式法则」就以为是没学过的知识点。

下刀之前：先看清最外层是「复合」还是「四则」

14:21洋葱法则管的是「怎么剥」，但剥之前还有更前面的一步——看清这一整坨式子的最外层到底套着什么。同一堆字符，最外层是「一个函数」还是「两块相乘、相除」，做法完全不同。下面四行是最容易混的对照：

式子最外层是什么第一刀怎么砍
(lnx)2「神马的平方」——幂在最外面先得 2lnx，再补里层 (lnx)'=1x
ln(x2)「ln 神马」——对数在最外面先得 1x2，再补里层 (x2)'=2x
x2lnx两块相乘，外面没有东西包着乘积法则 (uv)'=u'v+uv'
sinxx商，被一条分数线分成上下两块商法则 (uv)'=u'v−uv'v2
为什么 (lnx)2 和 ln(x2) 必须当成两道题

这两条是最经典的「长得像、做法完全不同」。(lnx)2 的最外层是平方，所以第一刀按幂函数砍——「神马的平方求导 = 2 倍神马」，得到 2lnx，再对里层的 lnx 补一刀 1x，结果是 2lnxx。而 ln(x2) 的最外层是对数，第一刀按 ln 砍——「ln 神马求导 = 神马的倒数」，得到 1x2，再对里层的 x2 补一刀 2x，结果是 2x。

两个答案不一样，根源就在「谁在最外面」。判断标准也只有一条：哪个函数是最后一步作用在 x 上的，它就在最外层，就先对它下刀。所以做复合题的第一句话永远是「先找最外层是什么」——这句说对了，后面就不会用错法则。同理，x2lnx 外面没有任何函数包着，它根本不是复合结构的第一刀对象，必须先上乘积法则，把每一块内部再各自剥洋葱。

例题：一层一层剥（洋葱法则实战）

14:21下面这些才是考试会考的样子。统一用洋葱法则：找外层、找里层，每层求导相乘。前几道先热身，看清结构即可。

题目外层 → 里层结果

例17:14求 y=lnsinx 的导数。

思路：只有两层，先找最外层

扫一眼结构：最外层是 ln 套着一个「神马」，那个神马是 sinx。按洋葱法则把口诀念一遍：

  1. 最外层「ln 神马」求导 = 神马的倒数 → 1sinx；
  2. 里层 sinx 求导 → cosx；
  3. 两层相乘 → y'=1sinx⋅cosx。

再化一步：cosxsinx=cotx，所以

y'=cotx

回看要点：老师讲这道题只用了两句——「外层是 ln 神马，里层是 sin」，因为它和后面那道三层的 ln(cosex) 是同一件事，只是少了一层。结果能化成 cotx，纯粹因为 cossin 正好是余切的定义；写成 cosxsinx 也不算错，但化成 cotx 更整齐。

例 520:06求 y=1−2x23 的导数。

思路：先看外层是「几分之一次方」，里层是「1−2x2」

把式子写成 y=(1−2x2)1/3。用洋葱法则，外层是「某整体的 1/3 次方」：

y'=13(1−2x2)−2/3⋅(1−2x2)'

里层 1−2x2 对 x 求导：常数 1 导数为 0，(−2x2)'=−4x。乘进去：

y'=13(1−2x2)−2/3⋅(−4x)=−4x3(1−2x2)2/3
这一步最容易漏

只写出 13(1−2x2)−2/3 就停手。错在忘了乘里层导数 −4x。洋葱法则是「每层都要求、最后相乘」，少乘一层就等于整个链式法则少了一节链子——这是复合函数求导最常见的失分点。

例 621:25求 y=ln(cosex) 与 y=esin(1/x) 的导数。

思路：三层的洋葱，从外往里剥三层

第一题 y=ln(cosex)，三层结构：外层 ln(⋅)、中层 cos(⋅)、里层 ex。逐层：

  1. 外层 ln(⋅) 导数 = 1(⋅)，即 1cosex；
  2. 中层 cos(⋅) 导数 = −sin(⋅)，即 −sinex；
  3. 里层 (ex)'=ex。

三层全乘：

y'=1cosex⋅(−sinex)⋅ex=−extanex

第二题 y=esin(1/x)，也是三层：外层 e(⋅)、中层 sin(⋅)、里层 1/x。注意 1/x=x−1 的导数是 −x−2=−1/x2：

y'=esin(1/x)⋅cos(1/x)⋅(−1x2)=−esin(1/x)cos(1/x)x2

关键观察：无论套几层，方法完全一样——从外往里数，数到 x 为止，每一层的导数乘起来。老师原话：「甭管多少层，你按照咱们的洋葱法则就直接做。」

08:16课本那个 y=ex3 为什么不用记

课本常用 y=ex3 当例题：y=eu,u=x3，于是 y'=ex3⋅3x2=3x2ex3。老师说这个「也不用学」——因为它和上面所有题是同一个套路，真正上考场遇到的是更花哨的复合，所以把洋葱法则练熟比背某个具体例子重要得多。

为什么链式法则「乘」而不是「加」

直观上可以这样想：当 Δu≠0 时，

ΔyΔx=ΔyΔu⋅ΔuΔx
两端一起让 Δx→0（此时 Δu→0），左边趋于 dydx，右边两段分别趋于 dydu 与 dudx，乘积就是链式法则。多层情形只是把这个等式反复套用：先拆 y→u，再拆 u→t，再拆 t→x，每一道「分数线」都对应一次相乘。所以它是「乘」，不是「加」——加号那是乘积法则 (uv)'，别串台。
