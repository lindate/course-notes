P088二重积分·直角坐标：把区域写成不等式，把积分写成两次定积分

一句话核心

这一页真正的功夫不在积分，而在画图定限——老师说得很直白：把二维区域用 x、y 的取值范围描述出来，上下限就确定了，题也就做完了。区域分两类：X 型（笔从左划到右，看上下边界）与 Y 型（笔从下划到上，看左右边界），二重积分随之变成两个「先一后二」的累次积分。这里最有价值的一项技能是交换积分次序：有些题原序根本积不出来，换一种切法立刻通透；而能不能少分段、要不要换序，看的是边界是否垂直于某个轴与被积函数积不积得出来。

先练基本功：把二维区域「写成不等式」

00:04这一讲从头到尾只干一件事，但老师把它说得很重：「你看的是二重积分的计算，其实这是对二维平面区域的一个表示的基本训练」。区域能用 x、y 的取值范围描述清楚，上下限就确定了，题也就会做了。所以他先花了大量时间在「怎么把阴影部分写成不等式」上。

区域只有两大类型，判据是一句口诀：

  • X 型：00:54把笔竖着放，从区域的最左边划到最右边。这时 x 的范围是一个固定区间 a≤x≤b；在划的过程中，看上面的函数是谁、下面的函数是谁，y 就夹在这两条曲线之间。
  • Y 型：02:57把笔横着放，从区域的最下边划到最上边。这时 y 的范围是一个固定区间 c≤y≤d；在划的过程中，看左边的函数是谁、右边的函数是谁，x 就夹在它们之间。
两类区域的精确写法（点集形式）

X 型：若区域 D 可写成

D={(x,y)∣a≤x≤b,φ1(x)≤y≤φ2(x)}

则称 D 为 X 型区域，其中 φ1(x) 是下边界、φ2(x) 是上边界。

Y 型：若区域 D 可写成

D={(x,y)∣c≤y≤d,ψ1(y)≤x≤ψ2(y)}

则称 D 为 Y 型区域，其中 ψ1(y) 是左边界、ψ2(y) 是右边界。

点集写法看着吓人，其实可以省掉

老师说点集是「比较严谨的写法」，但实际做题时不必写出来，直接把它变成累次积分的上下限就行。

不过点集写法有一个好处：它把两件事说得很清楚——外面那一层变量的范围必须是「常数到常数」，里面那一层才是「函数到函数」。做题时如果发现外面套着函数，那一定是写反了。

02:57写 Y 型时最容易忽略的一步

直接抄题目给的函数。题目给的曲线几乎总是写成 y=f(x) 的样子（比如 y=x2），但 Y 型区域要的是x 关于 y 的函数。所以写 Y 型之前，必须先把每条边界曲线改写成 x=⋯(y)：y=x2 要改成 x=y，y=x−1 要改成 x=y+1。

老师说这是「同学们做题时非常容易忽略的问题」。判断有没有忘，就看你的内层上下限里是不是含有 y——如果里面还是 x 的式子，那一定写错了。

从「土豆切片」到累次积分

14:18现在回到二重积分的几何意义。设 f(x,y)≥0，∬Dfdxdy 就是曲顶柱体的体积。老师用的方法和当年求旋转体体积时一模一样——切土豆：「假设这是个土豆，上面有一些小点点，我垂直于 x 轴去做它的切平面」，切出一片横截面，面积记作 A(x)，那么

V=∫abA(x)dx

这一步是定积分的应用，早就学过。问题只剩下：这一片的面积 A(x) 怎么算？

16:59把这一片「推到墙上」（也就是投到 yOz 平面上）看：此时 x 已经被这个切面固定住了，x 可以看成一个常数，于是曲面的方程 z=f(x,y) 就退化成只含 y 的一元函数。这一片横截面是一个曲边梯形：y 从下边界 φ1(x) 走到上边界 φ2(x)，高就是 f(x,y)。用一元定积分算面积：

A(x)=∫φ1(x)φ2(x)f(x,y)dy

把它代回体积公式，就得到「先对 y 积分、再对 x 积分」的公式：

∬Df(x,y)dxdy=∫ab[∫φ1(x)φ2(x)f(x,y)dy]dx

这个式子太啰嗦，做题时都写成更简洁的形式：

∬Df(x,y)dxdy=∫abdx∫φ1(x)φ2(x)f(x,y)dy

这就是二次积分，也叫累次积分——「对 y 求一次、对 x 求一次，一共求了两次」。老师特别强调了两句：

  1. 先积里面那个，再积外面那个。计算顺序是从右往左：先把 x 当成常数，对 y 积出一个含 x 的式子；上限与下限都代进去之后，这个式子就只和 x 有关了；再把它作为被积函数，对 x 积一次。
  2. 代上下限时「替换谁」要看刚才积的是谁。1:08:44第一次是对 y 求的积分，所以上下限代进去时替换的是 y；第二次再替换 x。这一步搞混了，整道题就废了。
24:34一个几乎人人都要犯一次的错

先算 ∫abdx。因为定积分里确实有 ∫abdx=b−a 这条性质，很多同学一看见 ∫abdx 就顺手算成 b−a，然后拿它去乘里面的积分。

这是严重错误。关键问题是：内层的 ∫φ1(x)φ2(x)fdy 积出来以后还是一个含 x 的式子，它必须待在 ∫ab⋯dx 的被积函数位置上。而「∫abdx=b−a」这条性质成立的前提是被积函数与 x 无关，这里根本不符合。

老师说得很形象：这个写法只是「看起来能先算」，本质上是 ∫ab[一个含 x 的东西]dx，绝不能拆成两半。

为什么这种写法可以去括号

严格写应该是 ∫ab[∫φ1(x)φ2(x)f(x,y)dy]dx，方括号先表出「里面那一层已经是一个只与 x 有关的整体」。

之所以可以把它简写成 ∫abdx∫φ1φ2fdy，是因为这个形式一眼就能看出计算顺序——从左到右读，先读到的先写，最后写的先算。教学上它更好记，代价是必须自己记住「先算右边那个」。

形式越简洁，越容易踩坑，这就是这个坑存在的原因。

为什么第 ③ 张图按 Y 型写就要分两段

横着扫的时候，y 从 0 一路走到 2，可中间在 y=1 处遇到了三角形的「上顶点」(1,1)——过了这一点，右边界换人了。

  • 0≤y≤1 这一段：左右边界分别是 x=y2 与 x=y（也就是射线 y=2x 与 y=x 反解出来的）；
  • 1≤y≤2 这一段：左边界还是 x=y2，但右边界变成了竖直线 x=1。

反过来，按 X 型竖着扫时，x 从 0 走到 1，一路上下边界始终是 y=x 与 y=2x，一次都不用换。「要不要分段」只取决于一件事：沿着这个方向走，边界会不会中途换人。

例题：按 X 型算两个积分

例 131:08计算 ∬Dxydxdy，其中 D 由 y=x、y=0、x=1 围成。

思路：先把区域读成不等式，再落成累次积分

这个区域的 X 型写法前面已经练过：0≤x≤1，0≤y≤x。于是

∬Dxydxdy=∫01dx∫0xxydy

先算里面那个。此时 x 是常数，对 y 求原函数：xy 关于 y 的原函数是 12xy2（那个 x 只是一个「系数」，原样抄下来）。上下限 0 与 x 代进去，替换的是 y：

∫0xxydy=[12xy2]0x=12x⋅x2−0=12x3

注意这里出现了一个很容易看花眼的地方：那个 x 已经变成了 x3。再把结果放回外层，对 x 积一次：

∫0112x3dx=[18x4]01=18

所以 ∬Dxydxdy=18。

顺带验算一下

如果按 Y 型写（0≤y≤1，y≤x≤1），会得到 ∫01dy∫y1xydx=∫01y⋅1−y22dy=12(12−14)=18，答案一样。这正是累次积分的一个好处：换一种次序算，可以作为一道免费的验算。

例 235:18计算 ∬D(x+y)dxdy，其中 D 由 y=1、y=x2、x=0 围成。

思路：下限带 x2，正好练「代入的是谁」

区域写成 X 型：0≤x≤1，x2≤y≤1，于是

∬D(x+y)dxdy=∫01dx∫x21(x+y)dy

对 y 求原函数：x 关于 y 的原函数是 xy，y 关于 y 的原函数是 12y2，所以内层是 [xy+12y2]。把 1 与 x2 代入 y：

[x⋅1+12]−[x⋅x2+12x4]=x+12−x3−12x4

再对 x 从 0 到 1 积分，四项分别是一元幂函数，各自算原函数：

∫01(x+12−x3−12x4)dx=12+12−14−110=1320

所以结果是 1320。

这一题的两个坑

坑 1：把下限 x2 代进了 x 的位置。第一次积分是对 y 求的，所以 1 和 x2 都只替换 y。写成 [x⋅x2+12(x2)2] 是对的（因为 y 被 x2 换了），但把 x+12 里的 x 也换掉就错了。

坑 2：算 12+12−14−110 时通分出错。34−110=1520−220=1320。这类尾部的算术错误在白纸考试里非常致命，算完最好回头扫一眼。

例 337:30计算 ∬D(x+y)dxdy，其中 D 由 y=x、y=2x、x=1 围成。

思路：这一题 X 型只写一个积分，Y 型要写两个——先挑省事的

按 X 型：0≤x≤1，x≤y≤2x。

∬D(x+y)dxdy=∫01dx∫x2x(x+y)dy

内层对 y 积：[xy+12y2]，把 2x 与 x 代入 y：

(2x2+2x2)−(x2+12x2)=4x2−32x2=52x2

外层再积：∫0152x2dx=[56x3]01=56。

对照一下 Y 型的代价：要分成 0≤y≤1 与 1≤y≤2 两段，写两个累次积分再相加。题目一样、答案一样，可是工作量翻倍——这就是「先看边界再动手」的价值。

怎么选型：三个判据

1:04:26老师给了三条经验，按优先级排列：

判据具体怎么看怎么做
① 尽量只写一个积分 沿某个方向扫过去，边界会不会中途换人 哪个方向不换人就用哪个（例 3 选 X 型）
② 边界垂直于哪个轴 看阴影部分的边缘：垂直于 x 轴 → 适合 X 型；垂直于 y 轴 → 适合 Y 型 有明显的竖直线边就按 X 型；有明显的水平线边就按 Y 型
③ 被积函数积不积得出来 先瞄一眼被积函数：有没有 e−y2、sinyy 这类「原函数求不出」的东西 按原序积不出来，就换另一种次序（见下一节）
1:05:29老师看被积函数的那一眼

他说，拿到题先「偷偷地瞄一眼」被积函数：如果里面有 ex、tan、arcsin 或者带根号的东西，就要提高警惕；如果只是 xy、x+y、1−x−y 这种，那就是「放水的」——「一看就知道它是不想给你制造任何麻烦」。

反过来，如果区域怎么切都别扭，那就说明这道题考的不是选型，而是换序。

交换积分次序：本页最有价值的技能

1:17:42所谓交换积分次序，就是把 ∫dx∫fdy 改写成 ∫dy∫fdx（或者反过来）。它本身不改变积分值——因为二者都等于同一个二重积分——改变的只是怎么切、先积谁。

标准流程是四步，第二步画图是整件事的枢纽：

  1. 由原来的上下限，反推区域 D 的不等式。外层是常数到常数（写成 x 的范围或 y 的范围），内层是函数到函数。
  2. 把区域画出来。这是关键一步，「你必须把那个阴影部分画出来，你才有依据来交换次序」。
  3. 换一个方向重新扫一遍，写出新的上下限。
  4. 把新的累次积分写出来。被积函数 f(x,y) 原样照抄——它的形式在做积分时一个字都不用改。
画图技巧：先画带变量的，常数最后用来「卡范围」

1:19:00老师说刚开始画图会比较迷茫：「你能把上下限写出来，画图却不容易。」他给了一个非常实用的技巧——

先别管那些常数上下限（0、1 这种），先看带变量的那两个函数，把它们当成曲线画出来。比如内层上下限是 x=1−y2 与 x=y+1，那就先画 1−y2（它来自 x2+y2=1，是右半圆）和 y=x−1 这两条线。

画完之后，再用常数上下限（这里是 0≤y≤1）去「卡」一个范围出来——区域永远是两条曲线夹着、被两条常数线截下的那一块。老师还专门提醒：这一步「很容易画错」，画错了后面全错。

例 41:17:42交换积分次序：∫01dy∫1−y2y+1f(x,y)dx。

第一步与第二步：把区域读出来、画出来

原式是「先 x 后 y」，外层 0≤y≤1 是常数范围，内层说明 x 夹在两条曲线之间：左边界是 x=1−y2，右边界是 x=y+1。

按老师的技巧先把两条曲线认出来：

  • x=1−y2 平方一下得 x2+y2=1，且取的是正根，所以是单位圆的右半圆；
  • x=y+1 就是直线 y=x−1（习惯写成 y 关于 x 的样子，好画）。

再用 0≤y≤1 卡一下：两条曲线在 y=0 处都交于 x=1，在 y=1 处分别是 x=0 与 x=2。所以区域是右半圆、直线与直线 y=1 围成的那块曲边三角形。

第三步与第四步：竖着扫，写出新次序

竖着扫，x 的范围是 0≤x≤2，但要在 x=1 处停下换一次下边界：

∫01dy∫1−y2y+1fdx=∫01dx∫1−x21fdy+∫12dx∫x−11fdy

逐项对一遍：0≤x≤1 时，下边界还是那条圆弧（把它写成 y 的显式，就是 y=1−x2），上边界是 y=1；1≤x≤2 时，下边界换成直线 y=x−1，上边界仍是 y=1。被积函数 f(x,y) 一个字都没动。

什么时候「必须」交换次序

前面都是「换得更省事」，接下来是「不换就做不了」。

例 547:59计算 ∬De−y2dxdy，其中 D 由 y=x、y=2、x=0 围成。

先按 X 型试一下，立刻卡住

区域是三角形：0≤x≤2，x≤y≤2。按 X 型写出来是

∫02dx∫x2e−y2dy

问题出在内层：e−y2 关于 y 的原函数根本不是初等函数，这个积分「积不出来」。这不是技巧不够，而是这条路本身走不通。

换成 Y 型：内外一调，立刻通了

把区域按 Y 型读：y 从 0 到 2，此时 x 左边是 x=0、右边是 x=y（由 y=x 反解），所以 0≤x≤y。

∬De−y2dxdy=∫02dy∫0ye−y2dx

关键来了：内层是对 x 积分，而 e−y2 里根本没有 x，所以它可以当作常数提出来：

∫02e−y2(∫0y1dx)dy=∫02e−y2⋅ydy

现在好办了：凑微分，ydy=12d(y2)，于是

∫02e−y2ydy=12∫02e−y2d(y2)=[−12e−y2]02=12(1−e−4)

答案就是 1−e−42≈0.4908。

为什么同样一个函数，换个次序就能积了

因为积分的「难度」不仅取决于被积函数，还取决于对谁积。e−y2 对 y 积是死路，但作为「关于 x 的常函数」时，它只是一个常数因子，提出来就完事，剩下的 ∫0ydx=y 把它救活了：最后要算的变成了 ∫e−y2ydy，而 y 恰好是 y2 的导数（差一个常数），凑微分立刻成功。

这就是「必须换序」的本质：不是换一个算法，而是换一个「谁当常数、谁当变量」的身份。

例 658:14计算 ∬Dy1+x2−y2dxdy，其中 D 由 y=x、y=1、x=−1 围成。

选型：先按 Y 型试，发现内层对 x 积分要带根号

区域按 Y 型是 −1≤y≤1、x 从 −1 到 y（左边界是竖直线 x=−1，右边界是 y=x 反解出的 x=y）。内层要算 ∫y1+x2−y2dx——对 x 积的时候根号里带着 x2，得用第二换元，非常难积。

改用 X 型：y 恰好可以凑进微分

按 X 型：−1≤x≤1，下边界是 y=x，上边界是 y=1，于是

∬Dy1+x2−y2dxdy=∫−11dx∫x1y1+x2−y2dy

内层对 y 积分时，x 是常数，于是 1+x2 也是一个常数。「原来说的可以任意加减常数」在这里派上了大用场：把根号里的 1+x2−y2 整体看成 u，因为 du=−2ydy，所以 ydy=−12du：

∫y1+x2−y2dy=−12⋅23(1+x2−y2)3/2=−13(1+x2−y2)3/2

代入 y=1 与 y=x（替换的是 y）：y=1 时括号里是 x2；y=x 时括号里是 1。所以内层等于

−13[(x2)3/2−1]=13(1−|x|3)
1:02:03这里有一个「严重的错误」，老师说他也犯过一次

把 (x2)3/2 直接写成 x3。看着好像只是「2 和 32 里的分母约掉」，其实完全错了：

  • (x2)3/2 里先是 x2——它是非负的，再开 32 次方仍然是非负的；
  • 而 x3 在 x<0 时是负的。

所以正确写法是 x2=|x|，进而 (x2)3/2=|x|3。「二和二是不能直接消掉的」——凡是「平方再开方」，都要想起绝对值。

用偶函数性质收尾

于是原积分变成

13∫−11(1−|x|3)dx

积分区间 [−1,1] 关于原点对称，被积函数 1−|x|3 是偶函数（|x| 是偶的，1 也是偶的），所以可以用「偶函数积分 = 两倍」：

13×2∫01(1−x3)dx=23(1−14)=12

答案是 12。

两个可以「偷懒」的特殊情形

情形一：区域是长方形，被积函数能拆成「x 的函数 × y 的函数」。1:10:27如果 D:a≤x≤b,c≤y≤d 是长方形，且 f(x,y)=f1(x)f2(y)，那么二重积分等于两个定积分的乘积：

∬Df1(x)f2(y)dxdy=(∫abf1(x)dx)(∫cdf2(y)dy)

道理不难：按 X 型先对 y 积分时，f1(x) 和 x 无关吗？不，它和 y 无关，所以它可以提出内层积分：∫cdf1(x)f2(y)dy=f1(x)∫cdf2(y)dy。而 ∫cdf2(y)dy 上下限都是常数、被积函数里没有 x，它是一个常数，再提到外层去，就成了两个定积分相乘。

1:13:32那个「小点点」的区别，比什么都重要

老师说这里必须盯住一点：有没有乘号，意思完全不同。

  • ∫abdx∫cdf1(x)f2(y)dy：这是累次积分，必须先算后面的 ∫cd⋯dy，再把结果带回外层对 x 积分。dx 后面的部分全是外层被积函数。
  • (∫abf1(x)dx)⋅(∫cdf2(y)dy)：中间有一个乘号，这是两个定积分相乘，两边各算各的、互不影响。

能写成第二种形式的前提有两条，缺一不可：① 积分区域必须是长方形（上下限全是常数）；② 被积函数必须能分离成 f1(x)f2(y)。相加、相减都不行，必须是相乘。

1:15:14他还当场「反面示范」了一遍：∫01dx∫23y2dy 这种，内层的被积函数和上下限都与 x 无关，是个常数，所以可以先把 ∫01dx=1 单独算出来再乘。但这一步只有在「内层的上下限与被积函数都与外层变量无关」时才允许——这正是最开始那个 ∫abdx=b−a 的坑不能乱踩的原因。

情形二：区域具有对称性，而被积函数有奇偶性。这类题能直接砍掉一半甚至全部计算量。以关于 x 轴对称的区域为例：若 D 关于 x 轴对称，则

  • 当 f(x,−y)=−f(x,y)（关于 y 为奇函数）时，∬Dfdσ=0——上下两半的贡献一正一负，正好抵消；
  • 当 f(x,−y)=f(x,y)（关于 y 为偶函数）时，∬Dfdσ=2∬D上半fdσ。

例 6 最后那一步用的正是第二条：|x|3 是偶函数，于是 ∫−11 改成 2∫01。注意前提是「区域关于原点对称」，两个条件要配成一对才能用。

一道综合题：两个圆柱面相交

例 71:23:11求两个圆柱面 x2+y2=R2 与 x2+z2=R2 相交所围立体的体积。

思路：先认清「上面」是谁，再靠对称性把体积缩小到一块

这个立体是个「交叉管」，不太好想象（老师说「大家可以去厕所看看那个水管」）。但不管怎么绕，二重积分的思路只有一条：找出它在 xOy 平面上的投影区域 D，再分别问「上表面 z 等于什么」。

1:25:07由于两个圆柱面关于各个坐标面都对称，整个立体由 8 块完全相同的部分拼成，我们只算第一卦限那一块，最后乘 8。在第一卦限里的投影区域 D 是四分之一圆：x≥0、y≥0、x2+y2≤R2。上表面取自圆柱面 x2+z2=R2，所以 z=R2−x2。

按 X 型写：0≤x≤R，0≤y≤R2−x2，于是

V=8∬DR2−x2dxdy=8∫0Rdx∫0R2−x2R2−x2dy

这里有一个非常好用的观察：被积函数 R2−x2 里没有 y，对 y 积分时它是常数，可以直接提出来；而剩下的 ∫0R2−x2dy 积出来「上限减下限」，正好是 R2−x2：

8∫0RR2−x2⋅R2−x2dx=8∫0R(R2−x2)dx

两个根号相乘刚好把根号消掉——这是这道题最漂亮的地方。剩下的是一个普通的一元积分：

8[R2x−13x3]0R=8⋅23R3=163R3
为什么这个例子值得放在直角坐标这一讲

它的投影区域是圆，按道理后面用极坐标会更舒服（老师也承认「和圆有关的我们一般用极坐标」），但这里因为还没讲极坐标，就用直角坐标硬做了一遍。真正值得记住的是那个套路：被积函数与内层变量无关时，内层积分退化成「长度」，可以直接提出去。下一讲换到极坐标，同一道题会变得短很多。

记忆入口 · 一眼回忆

一句话

二重积分 = 先把区域写成不等式，再落成两次定积分；哪一步卡住，就换个方向切。

两种型的公式

X 型：∬Dfdσ=∫abdx∫φ1(x)φ2(x)fdy
Y 型：∬Dfdσ=∫cddy∫ψ1(y)ψ2(y)fdx

口诀

  • X 型：笔竖着放，从左划到右 —— 上边界做上限，下边界做下限
  • Y 型：笔横着放，从下划到上 —— 右边界做上限，左边界做下限
  • 写 Y 型之前，务必把 y=f(x) 改写成 x=g(y)

计算顺序与代入

  1. 先算右边那一层（内层），另一个变量当常数
  2. 上下限代进去时，替换的是刚才积分那个变量
  3. 结果再作为外层被积函数，积第二次
  4. 绝不能先把外层 ∫abdx 算成 b−a

选型三判据

  • ① 尽量只写一个积分（边界会不会中途换人）
  • ② 边界垂直于哪个轴 → 就按那种型
  • ③ 被积函数积不出来 → 赶紧换序（e−y2、sinyy 是信号）

交换次序四步

读区域 由上下限写不等式→ 画图 先画带变量的曲线→ 换方向扫 写新上下限→ 照抄 被积函数不动

两个坑

  • (x2)3/2=|x|3，不是 x3——平方再开方必带绝对值
  • ∫abdx∫cdf1f2dy（累次积分）与 (∫abf1dx)(∫cdf2dy)（两个积分相乘）是两回事，差一个乘号
