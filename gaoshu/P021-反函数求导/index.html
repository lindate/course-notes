P021反函数求导

一句话核心

反函数求导一句话：反函数的导数 = 原导数的倒数，即 dydx=1dx/dy。它做题用得不多，价值在于推出反三角与对数的一族导数公式。几何上看，反函数图像关于 y=x 对称，切线也对称，斜率自然互为倒数。

课堂原话（大意）00:00

老师一上来先把这节的分量交代清楚：下面内容是反函数的求导法则。这部分我们其实在做题的时候用的是比较少的——借助反函数来求导，这个部分用得很少很少，而且这部分大家不是很好理解。

那学它干什么？老师也直说了目的：这一小节你最终就记住这六个公式就可以了。也就是说，定理本身是"工具"，真正的产出是那六个反三角与对数的导数公式——价值在推出一族新公式，不在拿它去算题。

定理：反函数的导数 = 原导数的倒数

反函数求导定理

设 x=f(y) 在区间 Iy 上单调、可导，且 f'(y)≠0，则其反函数 y=f−1(x) 在对应区间 Ix 上也可导，并且

dydx=1dxdy即(f−1)'(x)=1f'(f−1(x))

一句话：反函数对 x 求导，等于原函数对 y 求导的倒数。

00:48三个条件，每个都有交代

定理列了三个条件，不是凑数：

  • 单调 + 连续 ⇒ 反函数存在。「可导必连续」我们上节课证过，所以「单调且可导」自动保证单调且连续；而单调连续函数才有反函数。这一条保证「反函数 y=f−1(x) 确实存在」。
  • f'(y)≠0 ⇒ 分母不为零。看结论：原导数 f'(y) 出现在分母上。分母不能为零，所以必须要求它处处不为零。

老师原话点明：「这个条件我稍微给大家解释解释……可导必连续没问题，它单调并且连续呢它就存在反函数」「F'(y) 还不能等于零，因为这个东西一会会放在分母上」。两个条件，一个管「反函数有没有」，一个管「公式有没有意义」。

把 f'(y)≠0 去掉会怎样：y=x3 在原点没有有限导数

那条 f'(y)≠0 看着像"技术性条款"，其实是命门。看一个最朴素的例子：y=x3，它的直接函数是 x=y3。对 y 求导：

dxdy=(y3)'=3y2

问题来了——3y2 在 y=0 处恰好等于 0，定理的第三个条件被踩掉。此时结论里的 dydx=1dx/dy 变成 10，根本没有意义。

这也不是"公式暂时失灵"，而是"导数真的不存在"：y=x3 在原点处的切线与 y 轴平行、是竖直的，斜率趋于无穷大，取不到有限值。可见 f'(y)≠0 保证的正是"倒数仍是个有限数"；分母为零，这步就断了。

先把两个函数分清：谁是自变量、对谁求导

这一节最容易晕的根源，是同名符号在两个函数里扮演的角色不一样。把下面这张表竖起来读一遍，角色就清楚了：

直接函数反函数
写法x=f(y)y=f−1(x)
谁是自变量yx
定义域 / 值域定义域 Iy，值域 Ix定义域 Ix，值域 Iy
我们要的导数dxdy（对 y 求导）dydx（对 x 求导）
两者的关系互为倒数：dydx=1dx/dy

11:25注意第三行：直接函数与反函数的定义域、值域刚好互换。老师原话：直接函数和它的反函数，它的定义域和值域刚好是交换过来的。所以 arcsinx 的定义域 [−1,1] 根本不用背——它就是 siny 的值域换过来的。同理，y 是自变量时写 dxdy，x 是自变量时写 dydx，谁当自变量，就对谁求导。

结论与证明：为什么是倒数

02:06结论写成 dydx=1dx/dy。有同学立马「大聪明」上线：「老师，把这个一倒过来不就完了吗？」老师回应：这个理解其实不算完全错——因为后面我们会学到，dx,dy 在某些语境下确实可以拆开看。但现在刚入门，还是从定义老老实实推一遍最稳。

03:19证明只用到一个朴素的等式：

ΔyΔx=1ΔxΔy

这里 Δx,Δy 本来就是分开的（一个是自变量改变量，一个是函数值改变量），所以把分式整体取倒数完全合法。两边对 Δx→0 取极限，左边变成 dydx，右边分母变成 dxdy，于是

dydx=1dxdy
「Δx 与 Δy 凭什么能倒过来？」03:19

证明里最关键的一步是 ΔyΔx=1Δx/Δy。马上有同学反问：导数的记号 dydx 是个整体符号，凭什么能像分数那样一倒就倒？

关键在于：这里的 Δx,Δy 是真正分开的两个数——Δx 是自变量的改变量，Δy 是函数值的改变量，各是一个独立的实数。两个数组成的比值整体取倒数，是初等代数里就成立的等式，所以这一步完全合法。

但要分清时机：等到取完极限之后，dydx 才被打包成一个整体记号，那时就不能随手"约分"了。老师在这里埋了一句伏笔：这个符号是个整体的，但是后面有一些部分其实是能够看作是分开的，我们等到后面再说。——那就是下一章的微分。

04:23书上两种写法，挑好懂的记

课本给的形式是 (f−1)'(x)=1f'(f−1(x))——里面有 f−1，很多同学一看就懵。老师建议记简单形式 dydx=1dx/dy：它没出现 f−1，意思就是「反函数对 x 的导数 = 原直接函数对 y 的导数的倒数」。做题时先写出直接函数对 y 的导数，再取倒数最方便。

「互为倒数」的几何解释：一次对折，角度变成余角

把这件事拆成两步，就能看透它为什么必须是倒数：

  1. 反函数的图像 = 原图像关于 y=x 对折。因为 y=f−1(x) 等价于 x=f(y)，把横纵坐标互换一下，得到的就是同一条曲线。所以"求反函数"在图上不做任何拉伸、只做一次对折。
  2. 对折是刚性变换，切线被原样带过去。设原切线的倾斜角是 θ，它关于 y=x 对折后，倾斜角变成 90∘−θ（两条互为镜像的直线，倾斜角互补成直角）。
  3. 算斜率。对折后的倾斜角是 90∘−θ，于是
    反函数切线斜率=tan(90∘−θ)=cotθ=1tanθ=1原切线斜率

所以 dydx=1dx/dy 不是"代数上凑巧能倒过来"，而是图像对称的必然结果：斜率之所以取倒数，是因为切线的倾斜角被对折成了余角。

先用一个例子验证（不是证明，是「说人话」）

05:16直接套抽象公式容易晕，老师先用 y=x2(x≥0) 验一遍。这个函数的反函数是 x=y（注意把变量名互换了）。

  1. 直接函数 y=x2 对 x 求导：dydx=2x。
  2. 反函数 x=y=y1/2 对 y 求导：
    dxdy=12y−1/2=12y
  3. 按定理，两者应互为倒数。乘一下验证：
    2x⋅12y=xy
  4. 07:41因为反函数关系里 x=y，所以 xy=1。于是乘积恰为 1，互为倒数成立。

老师原话很接地气：「我是通过一个例子来给大家再做一次验证……说点人话。」这个例子不替代证明，但能让你相信公式不是凭空来的。

课堂原话（大意）05:16

这个不是证明，就是给大家举一个简单的例子验证验证。用句通俗的话说，就是给大家说点人话。——说完这句，老师自己先笑了一下：大家会觉得数学课老师说的都不是人话。

他还交代了自己的"土办法"：把 x=y 换成看着顺眼的写法再来一遍，因为这个地方原来是 x 对 y 求导，所以要把你写回 x 的函数，要变回来。

最容易错的一步：名字换了，最后要换回来 06:01

反函数求导里，x 与 y 的角色是互换的：直接函数写成 x=f(y)，此刻 y 才是自变量。很多人不习惯"对 y 求导"，会下意识地把名字对调、当成熟悉的 y=f(x) 来算——这个动作本身没错，但算完必须把名字换回去，否则会把 dydx 和 dxdy 彻底弄反，整道题就南辕北辙了。

老师演示时正是这么做的：先把 x=y 改写成顺眼的 y=x，求导得 12x；然后立刻提醒自己"原来的角色是反的"，换回来得到 dxdy=12y。两次改名，一步都不能漏。

本题也印证了这一点：算出的 12y 里还留着 y，而题目问的是关于 x 的导数——所以最后必须用 x=y 把它换成 12x。谁当自变量，答案里就只能留谁。

推公式：反三角与对数的导数（本节的真正产出）

14:49反函数求导「做题用得很少」，但它用来把六个重要公式推出来，以后直接当结论用。先看反三角函数。

例08:33推导 (arcsinx)'。

思路：把要求的东西设为反函数，先写出它的直接函数

要求 y=arcsinx 的导数，先写出它的直接函数：x=siny，并限定 y∈[−π/2,π/2]。为什么限定这段？因为 siny 整体震荡、不单调，只有取这一片单调区间才存在反函数——这正是定理里「单调」条件的来历。

对直接函数 x=siny 求 y 的导数：

dxdy=(siny)'=cosy

取倒数得反函数导数：

dydx=1cosy

10:02现在要把 cosy 换成 x。由 sin2y+cos2y=1 得 cosy=±1−sin2y。因为限定了 y∈[−π/2,π/2]，在这段上 cosy≥0，所以取正号：

cosy=1−sin2y=1−x2

代入得

(arcsinx)'=11−x2
14:12定义域为什么要取开区间

arcsinx 本身的定义域是 [−1,1]（它是 siny 的值域）。但上面这个公式的分母是 1−x2，当 x=±1 时分母为 0，导数不存在。所以求导公式只在开区间 (−1,1) 成立。端点处要谈导数得另外看左右导数，别想当然地把 ±1 代进去。

14:49为什么 arcsin、arctan 带正号，arccos、arccot 带负号

六个反三角导数里，正负号不是随机的，它由直接函数在所取单调区间上的单调性决定：

  • arcsinx：直接函数 siny 在 [−π/2,π/2] 上递增（导数 cosy>0），反函数也递增 ⇒ 导数正。
  • arccosx：直接函数 cosy 在 [0,π] 上递减（导数 −siny<0），反函数递减 ⇒ 导数负。
  • arctanx：直接函数 tany 在 (−π/2,π/2) 上递增（导数 sec2y>0）⇒ 正。
  • arccotx：直接函数 coty 在 (0,π) 上递减（导数 −csc2y<0）⇒ 负。

所以记忆法：正、负、正、负成对记。arccosx 和 arccotx 前面那道负号，就是「直接函数递减」留下的记号。

练照上面 arcsin 的三步走，把 (arctanx)' 自己推一遍（老师说"下边两个我也不证了"，但方法一模一样）。

思路：照搬三步走，只更换直接函数与单调区间

要求 y=arctanx 的导数，先写出直接函数 x=tany，并限定 y∈(−π/2,π/2)。为什么要限定？tany 在长度为 π 的每个区间里单调，为了"存在反函数"必须只取一片；而 arctanx 的值域恰好就是 (−π/2,π/2)。

对直接函数求导：dxdy=(tany)'=sec2y。按定理取倒数：

dydx=1sec2y

最后把 sec2y 换回 x。用 1+tan2y=sec2y，而 tany=x，所以 sec2y=1+x2。代入得

(arctanx)'=11+x2

回看要点：这一步完全没有正负号的纠结，因为 sec2y 恒为正，开不出两个根来——这正是它比 arcsin 好推的地方。顺便也把上面那条规律落实了：符号由直接函数在所取单调区间上的增减性决定，tany 递增，所以 arctan 不带负号。

六个公式卡 + 对数导数

14:49本节最终要死记住的，就是下面这六个（反三角函数）再加一个对数：

函数导数符号定义域
arcsinx11−x2正x∈(−1,1)
arccosx−11−x2负x∈(−1,1)
arctanx11+x2正x∈(−∞,+∞)
arccotx−11+x2负x∈(−∞,+∞)
logax1xlna—x>0,a>0,a≠1
lnx1x—x>0

15:51最后两个来自对数：把 y=logax 看成反函数，它的直接函数是指数函数 x=ay。老师原话：当然不需要证明，对不对……这六个公式做成公式直接记住。不过下面还是推一遍——它和前面求 (arcsinx)' 用的是同一套三步走。

例15:51用反函数求导，推出 (logax)'=1xlna，并由此得到 (lnx)'=1x。

思路：把对数看成指数函数的反函数，先对直接函数求导

要求 y=logax(a>0,a≠1) 的导数，先写出它的直接函数——指数函数 x=ay。对 y 求导，用指数函数的求导公式 (ay)'=aylna：

dxdy=(ay)'=aylna

按定理取倒数，得到反函数对 x 的导数：

dydx=1aylna

接着做那个必须做的收尾动作——把表达式里的 y 换回 x。直接函数的关系 x=ay 正好给了替换：ay=x。于是

(logax)'=1xlna

最后令底数 a=e。此时 lna=lne=1，公式立刻退化成

(lnx)'=1x

回看要点：三步走和 arcsin 那道题完全一样——写直接函数 → 对 y 求导 → 取倒数并把 y 换回 x。老师的态度是"做成公式直接用"，但知道它从哪来，记起来会牢得多。这也正是本节定理唯一的"产出"途径：arcsin,arccos,arctan,arccot,logax 这些新公式，全是从它推出来的。

记忆入口 · 一眼回忆

核心公式

dydx=1dx/dy
反函数对 x 求导 = 直接函数对 y 求导的倒数。

几何解释：反函数图像 = 原图像关于 y=x 对折，切线倾斜角由 θ 变 90∘−θ，斜率取倒数。条件 f'(y)≠0 保证这个倒数有限。

六个要背的公式

  • (arcsinx)'=11−x2（正），x∈(−1,1)
  • (arccosx)'=−11−x2（负）
  • (arctanx)'=11+x2（正）
  • (arccotx)'=−11+x2（负）
  • (logax)'=1xlna；(lnx)'=1x

三个坑

  • 开根号时正负号由单调区间决定：arcsin 段的 cosy 取正、arccos 段的 siny 取正，别乱加 ±。
  • arcsinx,arccosx 的导数公式只在 (−1,1) 成立，x=±1 时分母为 0。
  • 算到 dxdy 后，要把 y 换回 x（用直接函数的关系）。谁当自变量，答案里就只能留谁。
  • f'(y)=0 时必须停手：如 y=x3 在原点，dxdy=3y2=0，切线竖直、导数不存在。
