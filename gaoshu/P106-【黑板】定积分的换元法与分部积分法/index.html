一、知识速查：定积分的换元法

00:01不定积分也有换元，但定积分的换元麻烦得多、也更容易出问题，原因只有一个：自变量从 x 换成了 t，而积分区间是用 x 写的——上下限必须跟着一起换。把流程拆成四步，每一步都要落在答题纸上（这些都是要算分的步骤，不是草稿）：

  1. 写换元式：x=φ(t)，或它的反解 t=ψ(x)（哪种方便用哪种）。
  2. 求微分：由微分公式得 dx=φ'(t)dt。这一步最容易漏写，而漏了它后面全错。
  3. 换上下限：把原下限 x=a、原上限 x=b 分别代入换元式，得到新下限 α 与新上限 β。下限对下限、上限对上限。
  4. 在新变量上积分：在 t∈[α,β] 上求原函数、直接代限出数——不回代。
04:03为什么「不用回代」在定积分里反而更省事

不定积分换元后必须把 t 翻译回 x，因为答案要写成 x 的函数。而定积分算的是一个数：只要新变量对应的区间没错，积出来的数就是最终答案，t 和 x 谁在式子里根本无所谓。这正是三角代换在定积分里比在不定积分里好用得多的根本原因——你不必去画辅助三角形、把 sint、cost 再翻译回 x，直接对新变量代限即可。省下的不只是时间，更是出错的机会。

02:34上下限到底怎么换，α 和 β 谁大谁小要紧吗

记住一句大白话：下限对下限、上限对上限。原下限 a 对应新下限 α，原上限 b 对应新上限 β，一一对应写出来就完事。

至于 α 和 β 谁大谁小——完全不用管。定积分本来就允许下限大于上限（此时交换上下限要变号，公式早已替你处理好了）。老师课上举过一个让人发懵的换元：∫12f(x)dx 里令 x=−t，则 x=1 时 t=−1、x=2 时 t=−2，新品种下限写成 α=−1、上限写成 β=−2。写成"−1 到 −2"完全合法，不是写反了——只是它等于"−2 到 −1"的相反数，这一点由公式自动保证。所以上面那句"或 β 到 α"的别扭说法，做题时根本不必理会。

例 108:10用换元法计算 ∫04xdx。

思路：带根号就令 t 等于根号那整块，把根号消掉

令 t=x，则 x=t2，dx=2tdt。换限：x=0⇒t=0，x=4⇒t=2。四步备齐后代入：

∫04xdx=∫02t⋅2tdt=2∫02t2dt=2⋅[t33]02=163

最后一步直接把 t=2、t=0 代进 t33，没有把 t 换回 x——这正是定积分换元省事的地方。老师在这题上停得最久，强调的不是答案，而是前面那一串"准备工作"：换元式、dx、上下限的对应，三样都要写出来，"你这些步骤都写齐了，这个题你不太可能做错"。

这一步最容易错

换了被积函数却忘了换上下限，仍然写 ∫04。这是定积分换元第一大错。0∼4 是 x 的取值范围，你的积分变量已经是 t 了，t 只从 0 跑到 2。写成 ∫04t⋅2tdt 会把结果放大一倍。凡是换元，先把限算出来写在卷面上，再往下走。同理，漏写 dx=2tdt 也是致命伤——没有它，量纲都不对。

二、三角代换：定积分里的真正优势

16:12遇到 a2−x2、x2+a2、x2−a2 这三类根式，三角代换是标准武器。但在定积分里，先用眼睛想一件事值得养成习惯：这个积分能不能看成一个已知图形的面积？

例 216:12计算 ∫0aa2−x2dx（a>0）。

思路：先想几何（四分之一圆），再练一遍三角代换

y=a2−x2 正是圆 x2+y2=a2 的上半支，x 从 0 到 a 覆盖的是第一象限那一块，也就是四分之一圆。所以答案立刻是 14πa2——老师的原话是：神经病才用换元做这个题。

但作为代换的练习，走一遍：令 x=asint，则 dx=acostdt，t 的限由 x=0⇒t=0、x=a⇒t=π2 得到。此时 a2−x2=a2−a2sin2t=a|cost|；因为在 [0,π2] 上 cost≥0，绝对值可以直接去掉：

∫0aa2−x2dx=∫0π/2a2cos2tdt=a2∫0π/21+cos2t2dt=πa24

两种算法结果一致。结论：见到 a2−x2 在 [0,a] 上，先想圆，别急着换元。

例 322:51计算 ∫014−x2dx。

思路：这次"圆面积"帮不上整块的忙，要拆成扇形 + 三角形

被积函数还是上半圆（半径 2），但 x 只从 0 走到 1，不是四分之一圆。老师说：看见 ∫024−x2dx 就直接用四分之一圆面积；但换成 ∫01 就开始"滥用"了，不能照搬。

用一点点高中几何把它拼出来：记 A=(0,0)、B=(1,0)、C=(1,3)（因为 4−1=3），并记圆与 y 轴的交点为 D=(0,2)。

  • 扇形：在直角三角形 ABC 里，AB=1、AC=2，直角边等于斜边的一半，所以 ∠BAC=60∘，从而 ∠CAD=30∘=π6。半径为 2、圆心角 30∘ 的扇形 ACD 占整圆的 112，面积为 112π⋅22=π3。
  • 三角形：△ABC 的两条直角边是 AB=1、BC=3，面积是 12⋅1⋅3=32。
  • 所求区域 = 扇形 ACD + 三角形 ABC，所以
    ∫014−x2dx=π3+32

当然也可以用三角代换硬算（令 x=2sint，t 从 0 到 π6），结果一样。这里要记住的不是答案，而是判据：只有当积分区间恰好对应四分之一圆、半圆这类"整块"时，才能直接套面积；否则要么老老实实代换，要么像上面这样拆成扇形与三角形。

三、"凑微分"型换元，以及一个写法上的歧义

25:16并不是所有换元都要写 x=φ(t)。更常见的做法是把某个因子凑到微分号后面，例如 sinxdx=−d(cosx)。这时被积函数整体变简单，但上下限还是用 x 写的——于是出现了一个"写法上的歧义"，老师专门花时间解释过。

例 427:56计算 ∫0π/2cos5xsinxdx。

思路：把 sinx 凑进微分号，整体换成 cosx

因为 sinxdx=−d(cosx)，令 t=cosx。换限：x=0⇒t=1，x=π2⇒t=0。于是

∫0π/2cos5xsinxdx=−∫10t5dt=∫01t5dt=[t66]01=16

注意中间那个负号：换限后区间变成从 1 到 0，交换上下限又出一个负号，两个负号相消，所以最终等于 ∫01t5dt。这一步的负号是本题唯一的风险点。

另一种写法是不引入 t，直接写 −[cos6x6]0π/2，代限也得 16。老师指出：这种写法在教科书里很常见，做题也不会错，严格说有一点小瑕疵——积分变量已经变成 cosx 了，上下限却仍写着 x 的 π2（对应 cosx 的 0）。不过因为马上就要代限出数，结论完全正确，所以放心这么写。

例 532:14计算 ∫04ex2xdx。

思路：认出 12xdx=d(x)

被积函数里那个 12x 恰好是 x 的导数，所以它整体是 d(x)：

∫04ex2xdx=∫04exd(x)=[ex]04=e2−1

这里同样有"上下限该写 0∼4 还是 0∼2"的歧义：把 x 看成积分变量时它只从 0 跑到 2。老师的态度很明确——只要最终结果对，这两种写法都可以；有的教材干脆跳过中间这一步，为的就是躲开这个别扭。所以看到别人这么写，不必纠结。

例 635:08计算 ∫0πsin3x−sin5xdx。

思路：提公因式去根号，但去根号要加绝对值——这是本题的真正考点

先把根号里的式子提公因式：sin3x−sin5x=sin3x(1−sin2x)=sin3xcos2x。于是被积函数是 sin3xcos2x=sin3/2x|cosx|。

这里必须小心：[π2,π] 上 cosx≤0，所以 cos2x=|cosx|=−cosx。在瑕点 π2 处把区间切开：

∫0πsin3/2x|cosx|dx=∫0π/2sin3/2xcosxdx−∫π/2πsin3/2xcosxdx

两段都用 cosxdx=d(sinx)：

=[25sin5/2x]0π/2−[25sin5/2x]π/2π=25−(0−25)=45
这一步最容易错

直接把 cos2x 写成 cosx。平方开根号永远是绝对值，只有在你能确定符号的区间上才能去掉。本题区间 [0,π] 上 cosx 先正后负，必须以 π2 为界拆成两段，负的那段要么写成 −cosx（如上面），要么把区间反过来让 cosxdx 自带负号。忘了绝对值、忘了分段，就会把答案写成 0。

例 737:56计算 ∫04x+22x+1dx。

思路：根号里有 x，必须整体换元把 x 全部消掉

这次不能凑微分（根号里是 2x+1，不是 x 的简单函数），老老实实换元。令 t=2x+1，则 t2=2x+1，即 x=t2−12，且 dx=tdt。换限：x=0⇒t=1，x=4⇒t=9=3。

注意此时 x+2=t2−12+2=t22+32，而分母里的根号正好是 t，与 dx 中的 t 相消：

∫04x+22x+1dx=∫13(t22+32)dt=[t36+3t2]13=223

为什么这题值得记：它示范了根式换元的通用套路——把整个根号设成 t，反解出 x，把 x、dx、上下限三样一起换干净，最后剩下的必定是一个多项式，直接就能积。

四、奇偶函数在对称区间上的简化（考试必用）

40:18这一条老师原话是「考试必用」，所以单拎一节。它能把一大批积分的计算量直接砍掉一半甚至全部。

对称区间上的积分性质

设 f 在对称区间 [−a,a] 上连续，则

∫−aaf(x)dx={2∫0af(x)dx,f为偶函数0,f为奇函数
41:52证明就靠一次换元

把积分拆成 ∫−a0+∫0a。对前半段令 x=−t，则 dx=−dt，限从 t:a→0；交换上下限又出一个负号，与 dx 的负号相消，于是前半段变成 ∫0af(−t)dt。再用"积分变量换个字母不影响结果"，把它写回 ∫0af(−x)dx。这时两段可以直接合并：

  • f 偶（f(−x)=f(x)）：两段一模一样，加起来是 2∫0af(x)dx。
  • f 奇（f(−x)=−f(x)）：两段互为相反数，加起来是 0。

关键前提是"区间关于原点对称"——拆出来的两段必须一样长，才能用 f(−x) 与 f(x) 的关系。这一条在证明里是隐形的，但它在做题时最容易出事。

例 841:00计算 ∫−ππcos2xdx。

思路：先判奇偶，再决定要不要翻倍

cos2x 是偶函数（cos2(−x)=cos2x），区间 [−π,π] 关于原点对称，所以可以翻倍：

∫−ππcos2xdx=2∫0πcos2xdx=2∫0π1+cos2x2dx=2⋅π2=π

老师的提醒很实在：翻倍之后计算量只是"减小了一点"——毕竟 ∫0π 也得老实算。但该用一定要用：把 0 代进原函数永远比把 −π 代进去省事，考试里这一点点省下来的时间很值钱。

一个"严重错误"

看到 ∫−12sinxdx 就写 0，理由是"sinx 是奇函数"。47:05老师把这称为严重的错误：奇函数性质要求积分区间形如 [−a,a]，必须关于原点对称。[−1,2] 左边长 1、右边长 2，两块面积根本不相等，抵消从何谈起？正确做法是老实求出原函数 −cosx，直接代限。

例 9计算 ∫−π/2π/2sin4xdx。

思路：偶函数翻倍 → 交点火公式（下一节会讲）

sin4x 是偶函数，所以

∫−π/2π/2sin4xdx=2∫0π/2sin4xdx=2⋅34⋅12⋅π2=3π8

如果不用奇偶性质、硬按 [−π2,π2] 上的倍角公式展开，计算量会成倍增加。奇偶性质的价值在"配合"：它先把区间砍一半，剩下的一半再交给别的工具。

五、周期函数的积分性质

47:58周期函数性质

设 f 是以 T 为周期的连续函数，则对任意实数 A，

∫AA+Tf(x)dx=∫0Tf(x)dx,∫AA+nTf(x)dx=n∫0Tf(x)dx

一句话：一个完整周期的积分与起点无关；n 个周期就是 n 倍。

1:00:30为什么"从哪剪一刀都一样"

把左边看成 A 的函数：F(A)=∫AA+Tf(x)dx。它的上下限都是 A 的函数，套变上限求导的第五套公式（见 【黑板】积分上限函数与牛顿莱布尼兹公式）得

F'(A)=f(A+T)⋅1−f(A)⋅1=f(A+T)−f(A)

因为 f 以 T 为周期，f(A+T)=f(A)，所以 F'(A)≡0。导数恒为零的函数必为常数，于是 F(A) 与 A 无关；取 A=0 即得 ∫0Tf。第二式把 [A,A+nT] 按 T 切成长度相同的 n 段，每段由第一式都等于 ∫0Tf，加起来就是 n∫0Tf。直观上：一个周期波形不管从哪儿剪一刀，剪出来的那一块面积总是相等的——因为波形自己会"接上"。

例 101:05:19计算 ∫0nπ1+sin2xdx（n 为正整数）。

思路：配方成完全平方 → 找出周期 → 用 n 个周期性质

先把根号里的式子配成完全平方（1=sin2x+cos2x，2sinxcosx=sin2x）：

1+sin2x=sin2x+2sinxcosx+cos2x=(sinx+cosx)2

开根号要加绝对值，再用辅助角公式合并：|sinx+cosx|=2|sin(x+π4)|。而 |sin(x+π4)| 的周期是 π，于是 [0,nπ] 恰好包含 n 个完整周期：

∫0nπ1+sin2xdx=n∫0π2|sin(x+π4)|dx=n⋅22=22n

式中第二个积分就是一个"振幅为 2 的绝对值正弦"在一个周期上的积分：

∫0π2|sin(x+π4)|dx=22
（绝对值正弦在任意长度为一个周期的区间上积分为 2，乘振幅 2 即 22。）这一步也正是周期性质第二次登场——π4 这个起点不重要，长度是 π 就行。

这一步最容易错

把 1+sin2x 的周期当成 2π。sinx 的周期是 2π，但 sin2x 的周期是 π；由于外层还取了绝对值，实际周期仍是 π。周期找错，n 倍就无从谈起。判周期的正确做法：把式子化简到最简形式（这里是 2|sin(x+π4)|）再看一个周期有多长。

六、两个反复出现的对称公式

57:27下面两条在考试里出现得非常密集，本质都是"换元 + 变量改名"。

两个对称公式

设 f 连续，则

∫0π/2f(sinx)dx=∫0π/2f(cosx)dx
∫0πxf(sinx)dx=π2∫0πf(sinx)dx
52:05两条公式的证明思路完全一样

第一条：令 x=π2−t，则 dx=−dt，限由 x:0→π2 变成 t:π2→0。负号与交换上下限的负号相消，而 sin(π2−t)=cost，于是左边化为 ∫0π/2f(cost)dt，再把 t 改写成 x 就行。

第二条：令 x=π−t，则 dx=−dt，限由 0→π 变成 π→0。左边化为 ∫0π(π−t)f(sint)dt，拆成两项：

π∫0πf(sinx)dx−∫0πxf(sinx)dx

它等于原来的 I=∫0πxf(sinx)dx，于是 2I=π∫0πf(sinx)dx，移项得 I=π2∫0πf(sinx)dx。注意这里用到的关键事实是：f(sin(π−t))=f(sint)——所以公式只对"被积函数是 sinx 的函数"时成立，f 里不能混进 cosx 的奇次幂。

例 1155:21计算 ∫0πxsinx1+cos2xdx。

思路：先"改造"成 f(sinx) 的样子，再套第二条公式

公式要求 f 只含 sinx，可分母里是 cos2x。用 cos2x=1−sin2x 改写一下，分母就变成了 1+1−sin2x=2−sin2x——现在整个被积函数（除那个 x）都只是 sinx 的函数了。

套第二条公式：x 被换成常数 π2，剩下一半是纯粹的 f(sinx)：

∫0πxsinx2−sin2xdx=π2∫0πsinx2−sin2xdx

后一个积分用 sinxdx=−d(cosx) 凑微分，记 u=cosx（限由 1 到 −1）：

∫0πsinx1+cos2xdx=∫−11du1+u2=[arctanu]−11=π4−(−π4)=π2

所以原式

=π2⋅π2=π24
这一步最容易错

直接对 xsinx1+cos2x 用分部积分。分部积分在这里完全走不通：sinx1+cos2x 的原函数是 −arctan(cosx)，但那个多余的 x 没法消掉。见到"x 乘以一个只含 sinx 的函数"，第一反应应该是第二条对称公式，它专门干这件事。

七、知识速查：分部积分法

1:13:36定积分的分部积分只是把不定积分的公式两端加上限，别无新意：

∫abudv=[uv]ab−∫abvdu

最容易被漏掉的是 [uv]ab 这一项：它也必须代限，而且它常常占答案的一大部分。很多同学算完后半段就收笔，把边界项整个丢掉，分数直接减半。

例 121:14:24计算 ∫01/2arcsinxdx。

思路：反三角函数不能直接积，只能凑成 udv 用分部

取 u=arcsinx、dv=dx，则 v=x，而 du=dx1−x2：

∫01/2arcsinxdx=[xarcsinx]01/2−∫01/2x1−x2dx

第一项代限：x=12 时 arcsin12=π6，所以是 12⋅π6=π12；x=0 时为 0。第二项里 xdx1−x2=−d1−x2，于是

−∫01/2x1−x2dx=[1−x2]01/2=32−1

合并得

∫01/2arcsinxdx=π12+32−1

注意最后的符号：第二项外面本来有负号，而 [1−x2] 从 0 到 12 是 32−1<0，负负得正，所以最终是加上 (32−1) 这两个数。

例 131:16:13计算 ∫01exdx（换元 + 分部两步走）。

思路：先换元去根号，再分部积分

被积函数里有 x，先把它换掉。令 t=x，则 x=t2，dx=2tdt，限 x:0→1 对应 t:0→1：

∫01exdx=2∫01tetdt

对 tet 分部：取 u=t、dv=etdt，则 du=dt、v=et：

=2([tet]01−∫01etdt)=2(e−(e−1))=2

这题是"换元 + 分部"的组合拳范例：根号先换掉，剩下的 tet 才轮得到分部积分。顺序反了就做不动。

八、点火公式（Wallis 递推）

1:18:23这是定积分里的"送分公式"，考试点名率极高。对 n≥2：

∫0π/2sinnxdx=∫0π/2cosnxdx={n−1n⋅n−3n−2⋯12⋅π2,n为偶数n−1n⋅n−3n−2⋯23⋅1,n为奇数
1:19:31"4321 点火"怎么用

从 n 开始连乘 n−1n⋅n−3n−2⋯，分子分母各降 2，一直乘到不能乘为止。规律只有一句：偶数到底多带一个 π2，奇数到底乘到 1、不带 π/2。sin 和 cos 完全一样，用哪个都行。

  • 奇数例：n=5，连乘过程是 45⋅23⋅1，结果为
    ∫0π/2sin5xdx=815
    （奇数链乘到 1 为止，不带 π/2。）
  • 偶数例：n=6，连乘过程是 56⋅34⋅12⋅π2，结果为
    ∫0π/2cos6xdx=5π32
    （偶数链末尾补 π2，所以结果里带 π。）

1:20:29老师给了个"防忘"的小技巧：把奇数链末尾那个 1 也写出来，它占住了"最后一个位置"。这样偶数链因为被 12 占了位，就只剩 π2 可加；奇数链末尾已经是 1，自然不加 π/2。位置对应上了，就不会记反。注意 n=1 不适用（公式要求 n≥2），∫0π/2sinxdx=1 直接算。

1:25:48递推式怎么来的（了解即可）

记 In=∫0π/2sinnxdx。把 sinnx 拆成 sinn−1x⋅sinx，并把 sinxdx 凑成 −d(cosx)，用分部积分：

In=[−sinn−1xcosx]0π/2+∫0π/2cosxd(sinn−1x)

边界项在两端都为零（x=0 时 sinn−1x=0，x=π2 时 cosx=0），所以只剩第二项。而 d(sinn−1x)=(n−1)sinn−2xcosxdx，于是出现了 cos2x；用 cos2x=1−sin2x 拆开，得到

In=(n−1)∫0π/2sinn−2xdx−(n−1)∫0π/2sinnxdx=(n−1)In−2−(n−1)In

把含 In 的项移到左边：nIn=(n−1)In−2，即 In=n−1nIn−2。证明过程不要求掌握，但公式必须用到条件反射。

例 141:28:00计算 ∫−π/2π/2sin3xdx 与 ∫−π/2π/2sin4xdx。

思路：一个靠奇偶直接归零，一个靠奇偶 + 点火

第一题：sin3x 是奇函数，区间 [−π2,π2] 关于原点对称，所以答案直接是 0——不用算。

第二题：sin4x 是偶函数，先翻倍把区间搬到 [0,π2]，再交点火的偶数链（n=4）：

∫−π/2π/2sin4xdx=2∫0π/2sin4xdx=2⋅34⋅12⋅π2=3π8

这两小问放在一起，正好示范了"奇偶定区间、点火定数值"的配合套路：遇到对称区间上的幂函数积分，先问奇偶，再问点火。

九、易错清单

  • 换元忘换限：原限 0∼4，令 t=x 后 t 是 0∼2。这是第一大错。
  • 漏写 dx=φ'(t)dt：换元四步里的第二步必须写在卷面上，否则后面量纲全错。
  • 换限时把上下限调换：α 比 β 大是允许的，照写即可，不要"贴心"地调过来。
  • 三角代换后还回代：定积分不必回代，直接对新变量代限出数。
  • 平方开根号不加绝对值：cos2x=|cosx|，在 [0,π] 上必须分段（例 6）。
  • 奇偶性质用错区间：必须形如 [−a,a] 关于原点对称；[−1,2] 上不能写 0。
  • 周期找错：1+sin2x 的周期是 π 不是 2π；先把式子化简到最简形式再判周期。
  • 对称公式用错对象：∫0πxf(sinx)dx 的公式要求 f 只含 sinx，遇到 cos2x 先用 cos2x=1−sin2x 改造成 sinx 的函数。
  • 分部积分忘代 [uv]ab：边界项往往就是答案的一半。
  • 点火公式记反奇偶：偶数带 π2、奇数不带；n=1 不适用公式。
记忆入口 · 一眼回忆

一条链

换元 换元式 + dx + 换限→ 在 t 上积分 不回代→ 代限出数

要背的

  • 换元四步：换元式 → dx → 换上下限（下限对下限、上限对上限）→ 积分不回代。
  • 奇偶：∫−aaf 偶 =2∫0af，奇 =0；区间必须关于原点对称。
  • 周期：∫AA+Tf=∫0Tf，∫AA+nTf=n∫0Tf。
  • 两个对称公式：把 sinx 换成 cosx 不改变 ∫0π/2 上的积分值；而 ∫0πxf(sinx)dx 等于 π2 乘上 ∫0πf(sinx)dx。
  • 分部：∫abudv=[uv]ab−∫abvdu。
  • 点火：4321 连乘，偶数带 π2、奇数不带，n≥2。

三个动作

  1. 见根号 → 先把根号整块设成 t（或凑微分），把 x 彻底换干净。
  2. 见对称区间 [−a,a] → 先查奇偶，能归零就归零、能翻倍就翻倍。
  3. 见 ∫0π/2sinn 或 cosn → 直接点火，别再硬算。

三个坑

  • 换元不换限 —— 最致命的低级错误。
  • 平方开根号不加绝对值、不分段 —— 例 6 会算成 0。
  • 奇函数在非对称区间 [−1,2] 上写 0 —— 老师称之为严重错误。
