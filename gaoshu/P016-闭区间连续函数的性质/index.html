P016闭区间上连续函数的性质

一句话核心

四个定理都挂着同一个前缀：闭区间 + 连续函数。结论很直白——闭区间上的连续函数「一定有界、一定有最大值和最小值、异号端点之间必穿过 x 轴、介乎两端函数值之间的值都取得到」。但「闭区间」三个字一个都不能少：换成开区间、或中间断一下，结论立刻垮掉。这一页就专门把「少了条件会怎样」的反例讲透。

先看标题：两个词缺一不可

00:00老师一上来就点题：这一节叫「闭区间上连续函数的性质」，你要注意两点——第一，性质必须发生在闭区间上；第二，函数必须连续。两个条件都满足，下面四条结论才成立。整页内容其实就是围绕这两条「为什么要这样要求」展开。

最大值与最小值：先把概念掰清

00:51在讲定理之前，先理解「最大值」是什么。设在区间 I 上有 x0∈I，使得对一切 x∈I 都有 f(x)≤f(x0)，那么 f(x0) 就叫做函数在 I 上的最大值，点 x0 叫最大值点。最小值对称定义。

01:30两个容易混的点

老师特意强调：最大值是一个函数值（y 的取值），最大值点才是 x 的位置。比如函数在 x=1 处取得最大值 5——「5 是最大值，1 是取最大值的点」，别把 x 和 y 搞反。

02:04接着老师连抛几个反问，把最值概念彻底澄清：

  • 最大值唯一吗？唯一。最大就是最大，那个最大的数值只有一个。
  • 取最大值的点唯一吗？不一定。图上可能有两个甚至更多点，都取到同一个最大值 1。
  • 最大值和最小值能相等吗？能。y=1 这种常函数，最大值 =1，最小值也 =1。
  • 最大值可能比最小值小吗？不可能——区间固定时，最大值不会小于最小值。
  • 最值一定存在吗？不一定！这是关键。
03:24为什么「最值不一定存在」要单独拎出来说

因为初学者常默认「函数总有最大最小」。老师举了两个反例：

  • y=1x 在定义域内：越往 0 靠函数值越大，可以冲到无穷，没有最大值（不是「最大值是无穷大」，无穷大不是数，所以叫「不存在」）。
  • y=x 在开区间 (−1,1) 上：最高点该是 1，但 x=1 这个端点不被包含，所以取不到，既无最大值也无最小值。

这两个例子正是后面「为什么必须闭区间」的伏笔。

定理一：有界性与最大值最小值定理

定理 · 闭区间上连续函数的最值定理

设函数 f(x) 在闭区间 [a,b] 上连续，则 f(x) 在 [a,b] 上

  1. 一定有界；
  2. 一定有最大值和最小值。

05:56老师没给严格证明，而是用一句大白话让结论「长」在脑子里：闭区间 [a,b] 要求你把 a、b 这两个端点都包含进去；连续要求你一笔画——笔不能抬。那么从 a 点起笔画起，中间不管冲多高，最后必须落回 b 点。

05:56视频原话（大意）

你画这个图的时候，你还得一笔画，也就是说你从这个点开始离开，一笔给他画出来，并且最终这个 b 点你必须还得落在这个点。那么你跑得再怎么远你也得回来啊——因为你妈妈叫你回家吃饭了！所以他必须是有界的，并且一定有最大值最小值。

08:59为什么「闭区间 + 连续」少一个都不行（反例必须给）

老师给了两个反例，正好对应少掉的两个条件：

  • 少了「闭」：仍然连续，但区间是开区间。比如 y=x 在 (−1,1)——有界没问题，但最高该是 1 的那个点是空心的、取不到，所以没有最大值也没有最小值。
  • 少了「连续」：区间仍是闭的 [0,2]，但中间有个间断点。图上最高那个点恰好是间断点，画成空心，于是最大值取不到；同样最小值也可能取不到。

两条反例合起来说明：「闭区间」保证两端点被收纳、曲线被框住；「连续」保证中间没有「漏掉的高度」。任何一个条件缺失，最值都可能凭空消失。

定理二：零点定理

14:08先说什么叫零点：如果 f(x0)=0，那么 x0 就叫函数 f 的一个零点（注意零点是 x 的值，不是函数值）。

定理 · 零点定理

设 f(x) 在闭区间 [a,b] 上连续，且 f(a) 与 f(b) 异号（即 f(a)f(b)<0），则在开区间 (a,b) 内至少存在一点 ξ，使得

f(ξ)=0

15:39几何上极其直观：两端一正一负，曲线又必须连续（一笔画），那就一定穿过 x 轴，穿过去的那一点函数值就是 0。老师用了一个生活比喻：

17:24视频原话（大意）

假设这是一条河，你女朋友在河对岸等你，你肯定得过河才能找到她——你一定要过河。过河，就必然经过水位为 0 的地方。这就是零点定理。

18:45为什么定理说的是开区间 (a,b)，不是闭区间 [a,b]

因为两端点 a,b 的函数值异号、不等于 0（异号意味着一个正一个负，都不为 0）。所以零点不可能在端点处出现，只能在内部。课上有同学问「为什么不直接写闭区间」，老师答：「写闭区间没啥用，因为 a、b 处函数值都不等于 0，取不到零点。」

另外「至少存在一点」是说可能不止一个。如果曲线在内部上下穿越 x 轴三次，那就有三个零点——「至少一个」永远成立，多几个也不矛盾。

定理三：介值定理

定理 · 介值定理

设 f(x) 在闭区间 [a,b] 上连续，f(a)=A，f(b)=B，且 A≠B。则对于 A 与 B 之间的任意一个数 C，在开区间 (a,b) 内至少存在一点 ξ，使得

f(ξ)=C

22:13直观理解：从高度 A 连续画到高度 B，中间每一个高度都会扫到。老师用反证讲：假如某个介于 A,B 之间的 C 取不到，那曲线在 C 这个高度就出现一个「空洞」——可你明明是连续（一笔画）画过来的，怎么会凭空缺一块？所以不可能缺。

23:53介值定理和零点定理是什么关系

零点定理其实是介值定理的特例：把 C 取成 0，要求 f(a) 与 f(b) 异号——异号无非就是「0 落在 f(a) 与 f(b) 之间」。所以记住介值定理这一条，零点定理就自动含在里面了。

推论：值域就是 [m,M]

27:15把介值定理用到最值上，得到课本的一个说法：设 m,M 分别是 f 在 [a,b] 上的最小值和最大值，则 f 的值域是 [m,M]。也就是说，从 m 到 M 之间的每一个值都被取到。

28:20端点函数值 ≠ 最值（一毛钱关系没有）

老师反复提醒一个错觉：看书上画的图，端点 a,b 处的函数值常常正好是最值，于是误以为「端点值就是最值」。其实完全没关系。他画了一条两端平平、中间鼓个包的曲线：端点函数值都一般高，但最大值在中间鼓包处、最小值在另一处凹陷——端点和最值毫不相干。所以介值定理里的 A=f(a)、B=f(b) 与 m,M 是两套独立的东西，别混。

28:20视频原话（大意）

你这画的这不是最小值、这是最大值吗？因为我画的其实是最简单的一种图。这两个端点的函数值啊，和它的最大值最小值啊，其实一毛钱的关系都没有。我给大家举个例子——如果函数的图是这样的，这两个端点的函数值是不是这么大呀，它的最大值在哪呀？最小值在哪呀？是不是？

例题：证明方程在 (0,1) 内至少有一根

例33:31证明方程 x3−4x2+1=0 在区间 (0,1) 内至少有一个根。

思路：构造辅助函数，套零点定理

令 f(x)=x3−4x2+1。它是多项式函数，所以在任何区间上都连续，自然在闭区间 [0,1] 上连续。算两端函数值：

f(0)=03−4⋅02+1=1>0,f(1)=13−4⋅12+1=−2<0

两端异号（f(0)>0、f(1)<0）。由零点定理，在开区间 (0,1) 内至少存在一点 ξ，使得

f(ξ)=0

即 ξ3−4ξ2+1=0，说明方程在 (0,1) 内至少有一个根。

35:31两个书写细节

一是区间：定理要求闭区间 [0,1] 上连续，所以先写 [0,1]；但零点 ξ 落在开区间 (0,1) 内——因为 f(0),f(1) 都不等于 0，取不到端点。二是「至少有一个根」对应「至少存在一点 ξ」，不要写「有且仅有一个」，定理只保证存在、不保证唯一。

老师关于「最值唯一吗」的连珠炮

03:24在引入定理前，老师对「最值」问了一串反问，把容易想当然的地方全抖落出来。原话大意是：

03:24视频原话（大意）

最大值是不是唯一的？是。但是取最大值的那个 x 是不是一定是唯一的？这个不一定。比方说在这个点它取一，在这个点它也取一，最大值是一、是唯一的，但 x 的取值可以不相同。最大值和最小值能不能相等？能，比如 y=1。最大值有没有可能比最小值小？不可能——区间固定的话，最大值不会比最小值小。

这四个反问，其实在区分四对概念

把它们并排看就清楚了：

  • 最大值（数值）唯一；最大值点（x 的位置）可以不唯一。
  • 最大值与最小值可以相等（常函数），但最大值不会小于最小值。
  • 最值不一定存在——这正是后面「为什么必须闭区间」的伏笔。

初学者最大的错觉是「函数总有最大最小」，老师用 1/x 和开区间上的 y=x 把这条错觉打碎，再引出最值定理：只有「闭区间 + 连续」同时成立，最值才 guaranteed 存在。

把四个定理的关系理一遍

四条性质听起来多，其实是一条主线的四个侧面。最值定理说「闭区间连续 ⇒ 有界且有最值」；零点定理和介值定理则是「连续曲线不会跳空」的两种说法——前者是取不到 0 的高度（端点异号、中间必穿 x 轴），后者是取不到 A,B 之间任一高度（中间必被扫过）。而介值定理取 C=0 就退化成零点定理。

定理前提结论
有界性与最值闭区间 + 连续有界，且有最大、最小值
零点定理闭区间连续，f(a)f(b)<0∃ξ∈(a,b),f(ξ)=0
介值定理闭区间连续，C 介于 f(a),f(b) 之间∃ξ∈(a,b),f(ξ)=C
值域推论闭区间连续，m,M 为最值值域恰为 [m,M]
为什么零点定理要求「开区间」而最值定理要求「闭区间」

这俩区间要求恰好相反，但理由一致：最值定理要让端点也参与比较（最大值可能在端点取得），所以必须闭；零点定理里端点函数值非 0（异号），零点只可能出现在内部，所以结论落在开区间。一个要端点的函数值，一个排除端点的函数值——同一个「闭区间」前提，在两个定理里扮演的角色完全不同。

记忆入口 · 一眼回忆

一条链

前提 闭区间 + 连续→ 最值定理 有界且有最大/最小→ 零点定理 两端异号 ⇒ 穿过 x 轴→ 介值定理 两端之间每值都取到

四个结论（都挂「闭区间连续」）

  • 有界性 + 最值：必有最大、最小值
  • 零点定理：f(a)f(b)<0 ⇒ ∃ξ∈(a,b),f(ξ)=0
  • 介值定理：C 介于 f(a),f(b) 之间 ⇒ ∃ξ∈(a,b),f(ξ)=C
  • 值域推论：值域恰为 [m,M]（最小到最大全取到）

两个坑（反例）

  • 开区间连续（如 y=x 在 (−1,1)）：有界但无最值
  • 闭区间但不连续（间断点恰在最高处）：最值取不到

三个易混

  • 零点定理是介值定理取 C=0 的特例
  • 零点落在开区间内，端点的函数值非 0
  • 端点函数值 f(a),f(b) 与最值 m,M 没关系
