P076偏导数：把另一个变量钉死，就退回一元

一句话核心

偏导数没有新东西。求 ∂z∂x 就是把 y 当成一个常数，然后对 x 用一元函数的求导法则；求 ∂z∂y 就把 x 当常数。真正要花力气理解的是两件事：它的几何意义（拿刀把曲面切开，看截面曲线的切线斜率），以及它带来的第一个反直觉结论——两个偏导数都存在，函数仍可能不连续。

偏导数没有新东西：把另一个变量钉死

00:00老师开场就把话说清了：「从偏导数这一部分，我们就进入到了学习的重点。」但重点的门槛其实很低——偏导数在计算上完全没有引入新工具，它只是把一元函数的导数按不同的变量各做一遍。真正的新东西只有两个：几何意义，和一个反直觉的结论。

先把一元导数的定义摆出来对照。一元函数 y=f(x) 在 x0 处的导数是

f'(x0)=limΔx→0f(x0+Δx)−f(x0)Δx

老师提醒我们看清分子的身份：它是变化以后的函数值减去变化以前的函数值，也就是增量的精确值 Δy，整个式子就是 ΔyΔx 的极限。偏导数要做的事，就是把这里「变一个变量」改成「只变其中一个变量」。

定义：每次只放一个变量动

01:27定义 · 偏导数

设 z=f(x,y) 在点 (x0,y0) 的某邻域内有定义。把 y 固定在 y0，让 x 在 x0 处有增量 Δx。如果极限

limΔx→0f(x0+Δx,y0)−f(x0,y0)Δx

存在，就叫这个极限是 z=f(x,y) 在 (x0,y0) 处对 x 的偏导数，记作

∂z∂x|(x0,y0),∂f∂x|(x0,y0),zx|(x0,y0)

同理，把 x 固定在 x0，让 y 动，极限

limΔy→0f(x0,y0+Δy)−f(x0,y0)Δy

存在，就叫对 y 的偏导数。

定义里最要紧的是那句「令 y=y0 保持不变」。老师强调：「因为 y 等于 y0 是不变的，所以 ∂z∂x 这个式子里的两个 y0 都不变；变化以后的函数值减变化以前的函数值，比上 Δx。」05:08对 y 的偏导数完全对称：「x0、x0、x 是不动的，只有 y 发生了变化——原来是 y0，现在变成 y0 加 Δy。」

为什么钉死一个变量之后，问题就退回一元了

把 y=y0 代进去之后，f(x,y0) 里只剩下 x 一个字母，它就是一个彻头彻尾的一元函数。既然只是一元函数，那个极限就是一元函数在 x0 处的导数，一切一元求导法则照搬即可。

所以老师给的那句口诀并不是「简化技巧」，而是定义的直接改写：对 x 求偏导时 y 不动，对 y 求偏导时 x 不动。「这两个原始定义非常重要，咱做题的时候经常会用。并且这两个偏导数的定义大家先记住一句话——对 x 的偏导数求的时候是 y 不动，对 y 的偏导数求的时候是 x 不动。」

符号：一堆写法都要认，但意思是同一个

03:10偏导数最烦人的地方是符号。老师原话：「这个符号就比较花哨了。」最直观的差别是：一元求导的记号是 d（derivative），偏导数用的是 ∂——一个「圆肚子的 d」。下面这几种写法指的是同一个东西：

写法怎么读用在哪
∂z∂x偏 z 偏 x最标准的写法，把函数记作 z 时用
∂f∂x偏 f 偏 x把函数记作 f 时用
zxz 对 x 求偏导手写最快，x 写在右下角、别写太大
fx(x,y)f 对 x 求偏导强调「结果还是 x,y 的函数」时用
fx'(x,y)同上，多一撇加撇不加撇都行，同济课本不加、很多书加
∂z∂x|(x0,y0)在 (x0,y0) 处的值写成具体的数、把点代进去以后

老师特意交代：「一会儿怎么整了六个符号，老师你能不能给我说说哪个符号比较常用？不好意思，哪个符号都有用——你看到的所有的书用的都不一样，他要想起来就用什么，所以你都得会。」08:21还有一句提醒要刻在脑子里：「求导」指的是一元函数的求导，「偏导」才是多元函数的。「大家从现在开始，你说求导的时候一定要想想你到底是求导还是求偏导。」

求法：另一个变量就是常数

课本上有一句轻描淡写的话，但它就是全部方法：「求对 x 的偏导时，将 y 视为常数，然后对 x 求导就行；求对 y 的偏导时，把 x 视为常数，直接对 y 求导就行。」08:21「光求偏导这个事太简单了。」

例 1设 z=x2sin2y，求 ∂z∂x 与 ∂z∂y。

思路：先判断「谁是常数」，再看剩下的是什么初等函数

对 x 求偏导：y 是常数，那么 sin2y 整块就是一个常数系数，x2 才是真正的变量。按幂函数求导：

∂z∂x=sin2y⋅2x=2xsin2y

对 y 求偏导：x 是常数，那么 x2 是一个常数系数，sin2y 才是变量。按正弦求导，别忘了链式法则里那个 2：

∂z∂y=x2⋅2cos2y=2x2cos2y

两道题的形状完全一样，只是把「常数」和「变量」的角色对调了。这就是偏导计算的全部手感。

例 2设 z=x2+3xy+y2，求它在点 (1,2) 处的两个偏导数。

思路：先求偏导函数，再把点代进去

先求两个偏导函数，一路只用「另一个变量是常数」这条规矩：

∂z∂x=2x+3y+0,∂z∂y=0+3x+2y

逐项核对一下：对 x 求偏导时，x2 求导得 2x；3xy 里 3y 是系数，x 求导得 1，所以是 3y；y2 是常数，求导得 0。对 y 求偏导时同理，x2 得 0，3xy 里 3x 是系数得 3x，y2 得 2y。

再把 (1,2) 代进去：

∂z∂x(1,2)=2⋅1+3⋅2=8,∂z∂y(1,2)=3⋅1+2⋅2=7

例 313:45设 z=xy（x>0），求两个偏导数。

思路：同一个式子，换个变量看就换了「身份」

这道题的价值在于它逼你切换视角：

  • 对 x 求偏导时，y 是常数，xy 就是一个幂函数 x常数，用幂函数法则：
∂z∂x=yxy−1
  • 对 y 求偏导时，x 是常数，xy 就是一个指数函数 ay（底数 a=x），用指数函数法则 aylna：
∂z∂y=xylnx
同一个 xy，两种身份

老师借着这道题说了这一节最需要「转脑子」的地方：「我们同学原来讲一元函数，老觉得 y 是 x 的函数；现在这个二元函数，x、y 是两个平等的、独立的、都是自变量。所以大家脑子在这个地方先得转一转。」转过来之后，xy 就不再是「一个函数」，而是「两个不同的初等函数」——取决于你把谁当常数。

几何意义：拿刀切一刀，看截面曲线的切线

一元函数导数的几何意义是「曲线在 x0 处切线的斜率」，这个大家都熟。偏导数把同一件事搬到了曲面上，只是多了一步：先用刀把曲面切成一条曲线。

切这一刀到底切掉了什么

15:58求 ∂z∂x 时，条件里写着 y=y0 不变。老师把它翻译成几何语言：「y0 是这个点的纵坐标，你拿着刀，过 y0 这个点、垂直于 y 轴，去切一刀。切下去，它和上面这个曲面切出来的是一条曲线。」

关键在于：切完之后，y 已经被钉成常数了，所以曲面上剩下的就只是「z 随 x 变化」的一条曲线——它是一条平面曲线，完全落在那张切出来的平面里。17:51「这时候二元函数其实就变成了 x 的一元函数。一元函数导数的定义咱说过了，就是过这点切线的斜率。」

所以：∂z∂x 就是这条截线在该点处切线对 x 轴的斜率。对 y 的偏导完全对称：「令 x=x0 保持不动，x0 不是在这吗？所以我们再拿着刀，过 x0 点、朝 x 轴垂直地切下去，也切出一条曲线，同样也是过这点切线的斜率。」

易错点：先代入再求导，能不能干

11:05老师在这里插了一道「回忆题」，用一元函数来反衬，非常值得记下来。

辨析一元函数 y=x3 求在 x=1 处的导数，能不能先把 1 代进去？

先看错误示范

如果把 x=1 代进去，就得到 y=1——一个常数。常数求导是 0，于是「导数 =0」。老师问：「这样做对还是不对？」答案是当然不对，正确答案是 3（因为 y'=3x2，代入得 3）。

为什么错？因为导数是一个极限过程：它关心的是 x 在 x0 附近怎么变。你把 x 钉成 1，一切变化都被抹平了，剩下的只有「不动的常数」。所以一元函数的铁律是：先求导，再代入。

辨析12:23那二元函数呢？求 z=x2+3xy+y2 在 (1,2) 处的 ∂z∂x，能不能先把 y=2 代进去？

这一次答案是「可以」，而且理由就在定义里

先把 y=2 代进去：z=x2+6x+4。现在这个式子只跟 x 有关，对它求导得 2x+6，再把 x=1 代入得 8。

「我先把 y=2 代入，再对 x 求偏导，再把 x=1 代进去，请问这样做对还是不对？」答案是对的。理由也由老师自己给出：「因为刚才我们在求偏导数定义的时候，对 x 的偏导数是不是要把 y 取定，y=y0 保持不变？所以这样做是对的。」

两种做法结果完全一样（都是 8），但先代 y=y0 往往能省掉一大截运算——因为一元函数的求导比「带着一堆常数项求偏导」要清爽得多。

这一组对比的关键，别记反了

一元函数：先代入再求导 —— 错。理由是代入把自变量钉死，导数的「变化」没了。

二元函数求 ∂z∂x：先代 y=y0 再求导 —— 对。理由是定义里本来就要求 y 固定，代入的正是定义要求你固定的那个变量。

但要注意别推过头：你不能在求偏导的时候先把 x=x0 代进去——那和一元的情况一样，会把要研究的那个变量钉死。一句话：代入「要当常数的那个变量」可以，代入「要求导的那个变量」不行。

12:23老师还提了一句实战价值：「这种方法我们在解题的时候比较少用，但是考研的题目里这种先代入再求导用得比较多，因为考研题目相对难——你如果先求导再代入，可能这个式子很麻烦。」

一个反直觉的结论：偏导都存在，函数却可能不连续

要理解这个结论，得先回到一元函数。一元函数有一条铁律：可导必连续。老师当场把证明写了一遍，并且强调「这部分的证明是需要掌握的」。

  1. 从可导的定义出发。可导就是 limΔx→0ΔyΔx 存在，而这个极限就是导数。
  2. 分母趋于零，整体极限存在 ⇒ 分子必趋于零。因为一个趋于 0 的分母配上「极限存在」，若分子不趋于 0，比值必然发散。所以 limΔx→0Δy=0。
  3. 把 Δy 展开，用「扣项法」凑出连续性。注意到 Δx→0 这件事和 f(x0) 本身「一毛钱的关系都没有」——它只和自变量有关。所以可以把它当作常数处理：
limΔx→0f(x0+Δx)=limΔx→0[Δy+f(x0)]=0+f(x0)=f(x0)

最后这行就是「f 在 x0 处连续」的定义。证毕。这一步的巧妙之处在于：可导给出的是「增量趋于零」，而连续需要的是「函数值趋于函数值」，两者之间差一个 f(x0)——而 f(x0) 在 Δx→0 的过程中是个定值，可以直接搬出去。

为什么二元里同样的推导会「差一口气」

23:29同学很自然地会想：仿照一元的证明，把偏导存在代进去不也能推出连续吗？推是能推，但推出来的东西不一样。用 ∂z∂x 存在的定义，可以得到：

limΔx→0f(x0+Δx,y0)=f(x0,y0)

再用 ∂z∂y 存在，得到：

limΔy→0f(x0,y0+Δy)=f(x0,y0)

看这两个式子的形状：第一个把 y 死死钉在 y0、只让 x 变；第二个把 x 钉在 x0、只让 y 变。它们都属于「沿着平行于坐标轴的方向逼近 P0」——25:19说白了只有四条路：从左边来、从右边来、从上边来、从下边来。

而连续的定义要求的是「从四面八方、以任何方式逼近，极限值都等于定义值」。四条路上的表现好，推不出所有路上都好。老师对课本那句拗口的解释作了点评：「各偏导数存在，只能保证这个点 P 沿着平行于坐标轴的方向趋于 P0 时极限值等于定义值——他说这句话还不如我画这个图。就是沿着这四个白色箭头的方向逼近的时候，极限值的确等于定义值，但是不能保证四面八方。」

例 429:23设 f(x,y)=xyx2+y2（x2+y2≠0），f(0,0)=0。证明它在原点处两个偏导数都存在，但在原点不连续。

思路：偏导必须用定义老老实实算，连续性则用路径法否掉

这是个分段函数：x2+y2=0 就是原点，那一点单独规定为 0；其余点用上面的表达式。所以「在原点处」的一切结论，都得回到定义去算。

第一步：算 ∂z∂x(0,0)。按定义，y 要固定在 y0=0：

∂z∂x(0,0)=limΔx→0f(Δx,0)−f(0,0)Δx=limΔx→00−0Δx=0

分子之所以是 0，是因为 y=0，乘积 xy 直接等于零。老师笑着说：「y 直接是零，相乘分子是不是直接就是零？那这个地方就是个零减后边的零。」

第二步：算 ∂z∂y(0,0)。完全对称，这次固定 x0=0：

∂z∂y(0,0)=limΔy→0f(0,Δy)−f(0,0)Δy=limΔy→00−0Δy=0

两个偏导数都存在，而且都等于 0。

第三步：看它连不连续。沿直线 y=kx 让 x→0，把 y=kx 代进去：

xyx2+y2=kx2x2+k2x2=k1+k2

这个值随 k 变化：k=1 得 12，k=2 得 25，k=3 得 310。不同的路径给出不同的值，所以极限根本不存在。

极限不存在⇒不连续

33:34老师补了一句很关键的逻辑：「极限都不存在，你还谈啥连续不连续？连续的定义要求极限存在并且等于定义值——你连个极限都不存在，还什么连续？」

这道题的身份

它是本节的「收官反例」：偏导数存在 ⇏ 连续。注意它是和一元函数对照着看的——一元里可导必连续，二元里偏导存在却推不出连续，差别就在「四条路」和「所有路」之间。

本节收尾时老师把重点又说了一遍：「具体求偏导数的计算不是很麻烦——对 x 求偏导把 y 看作常数，对 y 求偏导把 x 看作常数，计算没有很大的障碍。但是呢，就是这个结论：二元函数如果偏导都存在，它在这点是未必连续的。」他也承认「这个概念大家不是很好理解」——所以上面那张十字图与四面八方图的对比，值得反复看几遍。

一句话

偏导数 = 把另一个变量当常数，对剩下的变量做一元求导。

∂z∂x:y不动;∂z∂y:x不动

两条几何意义

∂z∂x
用平面 y=y0 切曲面，得截线 z=f(x,y0)，它在 P0 处切线对 x 轴的斜率
∂z∂y
用平面 x=x0 切曲面，得截线 z=f(x0,y)，它在 P0 处切线对 y 轴的斜率

先代后导：一元不行，二元对 x 求导可以

  • 一元 y=x3 在 x=1：先代得常数 1，求导得 0 —— 错，答案 3。
  • 二元 z=x2+3xy+y2 求 ∂z∂x(1,2)：先代 y=2 得 x2+6x+4，求导再代 x=1 得 8 —— 对。
  • 规矩：可以代入「要当常数的那个变量」，不能代入「要求导的那个变量」。

必考的对照

  • 一元：可导 ⇒ 连续（证明要会：分母趋零且极限存在 ⇒ 分子趋零）。
  • 二元：偏导存在 ⇏ 连续。因为偏导只管四条平行于坐标轴的路。
  • 反例：f=xyx2+y2 在原点两个偏导都是 0，但沿 y=kx 极限是 k1+k2，随 k 变 ⇒ 极限不存在 ⇒ 不连续。
