P003函数：对应关系、四大性质、反函数与复合

一句话核心

函数是高数里做题用得最多的对象。它把映射的「集合」收紧成「数到数」：D⊆R 上的对应法则。这一页干四件事——说清函数是什么、四大性质各自的定义与反例、反函数为什么要求单射且图像关于 y=x 对称、复合函数为什么还要看「中间变量的值域是否落进定义域」。

函数到底是什么

00:00映射研究的对象可以是任何东西，而函数把它收紧了：设数集 D⊆R，如果 f 是从 D 到 R 的一个映射，就称 f 是函数，记作 y=f(x),x∈D。其中 x 叫自变量，y 叫因变量，D 叫定义域（记作 Df 以免和别的函数混淆），Rf={f(x)∣x∈D} 叫值域。一句话：函数就是「数到数」的对应，而映射可以「矩阵到矩阵」「人到学号」。

01:45函数的要素，课本有时写三要素（定义域、对应法则、值域），但老师强调本质是两要素：定义域 + 对应法则。因为只要这两者定了，值域就被唯一确定，多写一个只是重复。所以当你面对好几个函数时，写 Df、Dg 而不是笼统的 D，正是为了区分「这是谁的定义域」。

四个入门例子，把定义域和值域练熟

03:01例五：y=2。式子里没有 x，说明 x 可以随便取，所以定义域是 (−∞,+∞)。不管 x 取什么，函数值永远是 2，所以值域是由单个数 2 组成的集合 {2}。注意：定义域和值域都是集合，不能光写「值域是 2」，要写成 {2}。

03:56例六：y=|x|。定义域还是 (−∞,+∞)。绝对值的图像大家都熟——负半轴翻上去，所以值域是 [0,+∞)。老师插了一句：高中爱写「R」，但大学里更习惯写 (−∞,+∞)，因为 R 同时又是值域的记号，混用容易歧义。

05:30例七：符号函数，记作 sgn(x)（也写 sgn）：

sgn(x)={1,x>00,x=0−1,x<0

定义域是 (−∞,+∞)，值域是三个值组成的集合 {−1,0,1}。它的图像是三截：正半轴恒为 1，负半轴恒为 −1，原点为 0。下面这张图把「空心 / 实心」的讲究画出来：

输入 x101.80.90−0.9−3.8

性质一：有界性（必须先指定范围）

14:57讨论有界性，第一件事是必须指定在哪一个范围上，脱离范围谈有界没有意义。设 X⊆D：

定义 · 上界 / 下界 / 有界（14:57）

上界：若存在 K1 使对一切 x∈X 有 f(x)≤K1，则 K1 是 f 在 X 上的一个上界。

下界：若存在 K2 使对一切 x∈X 有 f(x)≥K2，则 K2 是 f 在 X 上的一个下界。

有界：若存在 M>0 使 |f(x)|≤M 对一切 x∈X 成立，则 f 在 X 上有界。

无界：若对任给的 M>0，都存在某个 x1∈X 使 |f(x1)|>M，则 f 在 X 上无界。

15:40上界、下界、那个框住图像的 M，全都不唯一。比如 sinx 满足 |sinx|≤1，你也完全可以写 |sinx|≤2——把框子放大一点，曲线照样出不去。所以「有界」只是说「存在某对线能框住」，不是指定唯一的框。

同一函数，换个区间有界性就变了（18:33）

看 f(x)=1/x：在 (0,1) 上，它有下界（图像在 x 轴上方）但没有上界——你画再高的线，靠近 0 时函数值都能突破，所以 (0,1) 上无界。可一旦换到 (1,2) 上，函数值稳稳落在 (1/2,1) 之间，既有上界又有下界，于是在 (1,2) 上有界。这正是「必须先指定范围」的铁证。

为什么「有界」等价于「既有上界又有下界」

若 |f(x)|≤M，则 −M≤f(x)≤M，所以 −M 是下界、M 是上界。反过来，若有上界 M1、下界 M2，取 M=max{M1,|M2|}，就有 −M≤M2≤f(x)≤M1≤M，即 |f(x)|≤M。上下两条线一合，自然得到框住全局的 M。

性质二：单调性（区间不能省）

26:52设 I⊆D 是一个区间。若对 I 上任意 x1<x2 都有 f(x1)<f(x2)，叫单调增；都有 f(x1)>f(x2)，叫单调减。老师强调两点：

  • 必须指定区间。看 y=x2：在 (−∞,0] 上单调减（朝下走），在 [0,+∞) 上单调增（朝上走）。问「它在全体实数上单调性如何」——没有答案，必须拆成两段。
  • 端点 0 归属无所谓。把 0 算进减区间或增区间都行，因为单调性考察的是「区间内部的走势」，单个点的归属不影响结论，不算错。
老师的比方（29:22）

比方说体重，原来特别重，减肥减到今天特别瘦，然后从今天开始猛吃又上去了。问「今天」算增肥阶段还是减肥阶段？都算。单调性对单个端点不较真。

性质三：奇偶性（先看定义域对称）

31:40判断奇偶性的第一道关卡：定义域 D 必须关于原点对称。若不过关，连讨论都不必，直接判非奇非偶。然后：

定义 · 奇 / 偶

对一切 x∈D，若 f(−x)=f(x) 则偶；若 f(−x)=−f(x) 则奇。几何上，偶函数图像关于 y 轴对称，奇函数图像关于原点对称。

32:33老师给的反例很扎心：你说 y=x2 是偶函数？是的。但如果你把它的定义域限制成 [−1,2]，那 [−1,2] 不关于原点对称，它就成了非奇非偶。所以「x2 是偶函数」这句话是有前提的——默认定义域对称。再看 y=lnx，定义域 x>0，显然不对称，直接非奇非偶，根本不用代入公式。

为什么负的 x 必须也在定义域里

奇偶性要比较 f(x) 和 f(−x)，如果 −x 不在定义域里，f(−x) 根本没意义，等式无从谈起。所以「定义域关于原点对称」不是客套，而是奇偶性的必要门票。做题时务必先查这一条，老师反复说这是同学最容易忽略的。

性质四：周期性（大学里不拓展）

35:13若存在 T>0 使对一切 x 有 f(x+T)=f(x)，则 f 是周期函数，T 叫周期；通常说的「周期」默认指最小正周期。高中学的那点够用：sinx、cosx 以 2π 为周期；tanx、cotx 以 π 为周期（后面 P004 会补 cotx）。

并非每个周期函数都有最小正周期（39:16）

狄利克雷函数：当 x 为有理数时取 1，为无理数时取 0。它显然是周期的——给 x 加上任意一个有理数，有理仍是有理、无理仍是无理，函数值不变。但有理数可以任意小（如 0.01、0.0001），所以不存在最小的正周期。它的图像不是两条连续线，而是密密麻麻的有理点取 1、无理点取 0，老师提醒这是周期性里一个「反常识」的特殊例子。

反函数：为什么要求单射，为什么关于 y=x 对称

44:58设 f 是从 D 到 Rf 的单射，则存在逆映射（反函数）f−1:Rf→D。判断一个曲线是不是函数用竖线法则（竖线和曲线只能有一个交点）；判断一个函数有没有反函数用横线法则：横线和曲线只能有一个交点——否则同一个 y 会对应两个 x，逆映射就不合法。

例49:01求 y=2x−3 的反函数，并说明图像关系。

思路：解 x，再换回 y

由 y=2x−3 解出 x=(y+3)/2，这就是反函数，记作 x=f−1(y)。但习惯上把自变量仍叫 x、因变量叫 y，所以改写成

y=x+32

50:18关键点：原函数是 y=f(x)，反函数是 y=f−1(x)——**把原来的 x 和 y 互换了符号**。正是因为这一步互换，原曲线上的点 (a,b) 变成了反曲线上的 (b,a)，而 (a,b) 与 (b,a) 天然关于直线 y=x 对称。

为什么关于 y=x 对称

如果你停在 x=f−1(y) 这一步不换符号，反函数的图像和原函数完全重合（同一个点）。只有把 x,y 互换写成 y=f−1(x)，图像才「翻」到 y=x 的另一侧。所以对称是「换符号」这一步带来的，不是凭空来的。

「直接函数」不是「原函数」（53:52）

有反函数时，原来的函数叫直接函数，不叫「原函数」。因为「原函数」这个词在后面不定积分里另有含义（求导之前的那个函数）。两个概念别混。

复合函数：中间变量也要守规矩

55:11设 y=f(u) 定义域为 Df，u=g(x) 定义域为 Dg，把 u 整体代入得到 y=f(g(x))，其中 u 叫中间变量。这条规矩和 P001 复合映射完全一样：g 的值域 Rg 必须包含于 f 的定义域 Df，否则复合在有些点无意义。

例57:38考察 y=u,u=tanx 能否复合，何时成立。

思路：根号要求内部非负

代进去得 y=tanx。tanx 本身可以取遍 (−∞,+∞)，但根号要求 tanx≥0。若 x 随便取（比如让 tanx<0），根号下为负，复合在实数范围不成立。

58:15但只要把范围限定，比如 x∈[0,π/2)，此时 tanx≥0 恒成立，复合就有意义。可见「取定一个范围」常常能救活复合；反之有些范围怎么取都救不活（如 y=1−x2 中若强行让 1−x2<0，永远无意义）。

函数的四则运算

1:00:49设 f,g 定义域分别为 Df,Dg，且交集非空，则：

运算定义额外条件
和 / 差(f±g)(x)=f(x)±g(x)无（要求交集非空）
积(fg)(x)=f(x)g(x)无
商(f/g)(x)=f(x)/g(x)分母 g(x)≠0，并从交集里挖掉使 g(x)=0 的点

这些符号做题时其实都直接用，不必死记；唯一要绷紧的弦是商的分母不能为零——从定义域里把使 g(x)=0 的那些 x 扣掉。

例（构造题）1:02:02设 f(x) 定义域关于原点对称，证明它可拆成「偶函数 + 奇函数」。

思路：利用 f(x) 与 f(−x) 配对

猜 f(x)=g(x)+h(x)，其中 g 偶、h 奇。把 x 换成 −x 得 f(−x)=g(x)−h(x)（偶函数不变、奇函数变号）。两式相加消去 h，两式相减消去 g：

g(x)=f(x)+f(−x)2,h(x)=f(x)−f(−x)2

1:03:21验证：g(−x)=f(−x)+f(x)2=g(x) 确为偶；h(−x)=f(−x)−f(x)2=−h(x) 确为奇。所以任意（定义域对称于原点）的函数都能唯一拆成「偶 + 奇」。

记忆入口 · 一眼回忆

一句话

函数 = 数到数的映射；要素是定义域 + 对应法则。四大性质（有界/单调/奇偶/周期）都要先指定范围；反函数要单射、关于 y=x 对称；复合看 Rg⊆Df。

四大性质 · 各自的反例

  • 有界：1/x 在 (0,1) 无界，在 (1,2) 有界——范围决定一切
  • 单调：x2 必须分 (−∞,0] 减、[0,∞) 增，全实数上无单调
  • 奇偶：x2 在 [−1,2] 上非奇非偶（定义域不对称）
  • 周期：狄利克雷函数周期任意小，无最小正周期

两个坑

  • 反函数存在 ⟺ 原函数单射（横线法则：横线和曲线只一个交点）
  • 复合函数别只写表达式，先查中间变量的值域是否落进外层定义域
前置知识
  • 映射 映射（函数是映射的特例）
  • 集合、绝对值、对数与三角函数初步
