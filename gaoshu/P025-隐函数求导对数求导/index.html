P025隐函数求导与对数求导法：当 y 写不出、底数指数都有 x

一句话核心

这一页解决两类「常规公式够不着」的求导：隐函数（方程里 y 提不出来）和幂指 / 连乘除函数。隐函数的命门只有一句——y 是 x 的函数，对含 y 的式子求导要当复合函数处理；对数求导则是用「取对数把乘除变加减、把幂指变乘积」来化难为易。

先分清楚：显函数与隐函数

00:01老师先厘清两个词：

显函数
y 能明明白白写成 x 的表达式，如 y=x2+6。「显」就是显式、直接。
隐函数
x,y 混在一个方程里、y 提不出来，如 ey+xy+ln(x+y)=8。「隐」就是藏起来。

01:05关键认知：隐函数也是函数。只要满足函数定义（一个 x 对应唯一 y），它就是函数——只是不像 y=x2+6 那样能「滴漏」出 y= 什么 x。所以写不出显式，不等于不是函数，照样能求它对 x 的导数。

隐函数求导的命门：两边对 x 求导，y 是 x 的函数

01:56这是整页最重要的一句话。老师讲了又讲：你一定要注意，y 也是 x 的函数。所以对 y 的表达式求导，要按照复合函数求导去处理。

操作只有三步：

  1. 方程两边同时对 x 求导。左对 x 求导、右对 x 求导（右边是常数就导 0）。
  2. 遇到含 y 的式子，把 y 当复合内层。如 ddxey=ey⋅y'，ddxy2=2y⋅y'。
  3. 把含 y' 的项提出来，解出 y'。

例 101:56设 ey+xy+ln(x+y)=8，求 y'。

思路：逐项按「对 x 求导、含 y 当复合」走

两边对 x 求导：

  • ey 对 x 求导：ey⋅y'（内层 y 还要导）。
  • xy 是乘积：(x)'y+x(y)'=1⋅y+x⋅y'。
  • ln(x+y) 是复合：1x+y⋅(x+y)'=1x+y(1+y')。
  • 常数 8 求导为 0。
eyy'+y+xy'+1+y'x+y=0

04:34把含 y' 的项归到一起、其余挪到右边：

y'(ey+x+1x+y)=−(y+1x+y)
y'=−y+1x+yey+x+1x+y
这一步最容易错

把 ey 直接导成 ey 就结束。那是「对 y 求导」的结果；这里整条方程是对 x 求导，y 是 x 的函数，必须补乘 y'。老师原话：你这个 ey 对 Y 求导就是 eY 完事了——但它是不是对 X 求导？y 也是 x 的函数！

另一条路：公式法 y'=−FxFy

01:56两边对 x 求导是课上主打的路子，但它不是唯一的路。把方程所有项都挪到一边、写成 F(x,y)=0 的形状之后，还有一条「公式法」可以直接代：

dydx=−FxFy,Fx=∂F∂x,Fy=∂F∂y

读法是：分子是 F 对 x 的偏导，分母是 F 对 y 的偏导，前面再带一个负号。「偏导」没什么玄机——求 Fx 的时候把 y 当常数看，求 Fy 的时候把 x 当常数看。

这条公式哪来的：其实就是两边求微分

对 F(x,y)=0 两边求全微分，得 Fxdx+Fydy=0。这一步和「两边对 x 求导」是同一件事，只是写成了微分的样子。把 Fydy 挪到右边、两边再同除以 Fydx：

dydx=−FxFy

所以公式法不是新方法，只是两边求导法的「成品包装」——它把「逐项列式 → 提出 y' → 解出来」这三步预先算完了，你只要会算两个偏导就能直接代。反过来说，Fy=0 的地方公式失效，那正对应两边求导法里「y' 解不出来」的情形：两条路的有效范围是同一个。

两边对 x 求导公式法
适用面任何隐函数方程，不必先整理成 F=0必须先写成 F(x,y)=0 的标准形
操作逐项求导 → 提 y' → 解出算两个偏导 → 代公式
优点过程透明，哪儿错了看得见；忘了乘 y' 会立刻暴露快，项数一多优势明显，适合选择填空
风险项一多容易漏乘 y'容易丢负号，或把 Fx、Fy 写反

拿例 1 验一下两法是否一致。先把方程整理成

F(x,y)=ey+xy+ln(x+y)−8=0

再分别求两个偏导（求 Fx 时把 y 当常数，求 Fy 时把 x 当常数）：

Fx=y+1x+y,Fy=ey+x+1x+y

代入公式：

y'=−FxFy=−y+1x+yey+x+1x+y

和例 1 两边求导得到的答案分毫不差——两条路的差别只在「先解还是后解」，结果必然一致。考场上用哪条都行，但建议先把两边求导法练熟：它对「y 是 x 的函数」这个意识的训练，是直接套公式给不了的。

为什么结果里可以既有 x 又有 y

07:41有同学问：你这求导以后既有 x 又有 y，这不对吧，你没做完。老师答：隐函数求导的结果本来就可以含 x 也含 y，完全没问题。因为 y 没被显式解出，导数写成「x,y 混着」就是它的正常形态。要算某一点的斜率，就把那点的 (x,y) 代进去——就像例 2 那样。所以看到 y' 里还带着 y，别慌，那是正常的。

08:37再进一步：隐函数的答案根本不止一个写法

老师紧接着补了一句更容易被忽略的话：隐函数求导这个结果，它不是唯一的。你把原来的式子给它朝里带，也成立。道理很直白——既然 x 与 y 本来就满足 ey+xy+ln(x+y)=8，那么答案里出现的任何一项都可以用这个关系替换掉，得到一条长得完全不同、但在曲线上每一点取值都相同的表达式。

所以核对答案别只看「像不像」：先检查两边是不是都合法地用了原方程。隐函数求导的正确答案从来不是唯一的一条式子，而是「在这条曲线的每一点上都给出正确的斜率」。

例 209:14设 y5+2y−x−x7=0，且 x=0，求 y'。

思路：先求导，再代点；代点前要先把对应的 y 求出来

两边对 x 求导（注意 y5 是复合：5y4y'）：

5y4y'+2y'−1−7x6=0⟹y'=1+7x65y4+2

11:25代 x=0 前，先由原方程求此时的 y：

05+2y−0−0=0⟹2y=0⟹y=0

这里有个小技巧：方程 y5+2y=0 即 y(y4+2)=0，而 y4+2>0 恒正，所以只可能是 y=0。代入 x=0,y=0：

y'(0)=1+00+2=12
这一步最容易错

拿到 x=0 直接往 y' 里代，忘了先求 y。因为导数里既有 x 又有 y，必须先把这一点的 y 值从原方程解出来。老师提醒：隐函数题给初始条件时，解 y 往往有巧劲（靠符号/因式判断），不会让你真的解五次方程。

10:05顺手说清符号：dydx 与 y' 谁更准确

做例 2 时老师一会儿写 dydx、一会儿写 y'，他专门停下来解释了一句：这个 dydx 表示 y 对 x 求导，这个符号是非常准确的；我这个地方写个 y' 呢，是比较方便的，但是准确度上差点意思。

差在哪儿？y' 只说了「求导」两个字，对谁求导要靠上下文去猜；而 dydx 把「y 对 x」直接写死在符号里。隐函数恰好是最需要这份准确的场景——同一个 y，对 x 求导和（假想的）对 y 求导完全是两码事，这正是本页反复强调的那件事。做题时写 y' 没问题，但心里要清楚它指的是 dydx。

例 312:44求椭圆 x28+y29=1 在点 (2,332) 处的切线方程。

思路：隐函数求导得斜率，再代切线方程

两边对 x 求导：

2x8+2y9y'=0⟹y'=−9x8y

代入点 (2,332)：

y'=−9⋅28⋅332=−18123=−34

切线方程 y−y0=y'(x−x0)：

y−332=−34(x−2)

整理（乘 4 消分母）得

3x+4y−83=0

这正是老师写出的结果。隐函数求导在这里的价值：椭圆方程解不出 y 的显式，却照样能拿到任意点的切线斜率。

例 415:30设如 x−y+12siny=0，求 d2ydx2。

思路：一阶导求完，再对 x 走一次复合

先一阶导。两边对 x 求导：

1−y'+12cosy⋅y'=0⟹y'=11−12cosy=22−cosy

再求二阶导：d2ydx2 就是「y' 再对 x 求一次导」。

d2ydx2=ddx(2(2−cosy)−1)

外层 (2−cosy)−1 求导得 −(2−cosy)−2，里层 (2−cosy) 对 x 求导得 siny⋅y'（因为 cosy 的 y 还是 x 的函数），所以

d2ydx2=−2⋅siny⋅y'(2−cosy)2

把 y'=22−cosy 代回：

d2ydx2=−4siny(2−cosy)3
二阶导最容易错

求二阶导时又忘了 y 是 x 的函数。哪怕一阶导已经算出来了，里面的 y 依然藏着 x。对 (2−cosy) 求导，必须再乘 dydx。老师把这步念得很慢：这个 cosy 求完导以后，这个 y 还得再对 x 求导。

17:19二阶导的符号为什么长这样

老师特意把 d2ydx2 拆开念了一句：还是提醒大家注意这个二阶导哈，这个符号——这个平方在这、这个平方在这。注意它是 d2y 比上 dx2：分子上的平方在 y 前面，分母上的平方在 x 后面，不是 dy2dx2。含义也不难记：ddx 是一个「对 x 求导」的算符，连用两次就是 (ddx)2=d2dx2。理解到这一层，符号就再也写不反。

对数求导法 · 场景一：幂指函数

20:19什么叫做幂指函数？底数有 x、指数也有 x，形如 y=u(x)v(x)。比如 y=xx。

为什么不能直接用现成公式

我们只会两类公式：底数是变量、指数是常数时 (xa)'=axa−1；底数是常数、指数是变量时 (ax)'=axlna。而 xx 底下有 x、上面也有 x，两套公式都只沾一半边，用哪个都不对。所以必须另想办法——对数求导。

老师给了两种方法，都推荐、都得掌握。

方法一：两边取对数

21:24以 y=xx 为例，两边取自然对数，把指数「拉下来」：

lny=ln(xx)=xlnx

再两边对 x 求导（左是复合：1y⋅y'）：

1yy'=1⋅lnx+x⋅1x=lnx+1

于是

y'=y(lnx+1)=xx(1+lnx)

21:24不过老师课上的第一个幂指例子并不是 xx，而是指数也带 x 的 y=xsinx。它比 xx 更一般，多出来的那一步正好练到乘积法则。

例21:24设 y=xsinx(x>0)，求 y'。

思路：幂指函数，两边取对数，右边成「乘积」

第一步，两边取 ln。指数里的 sinx 被拉到前面，变成一个因子：

lny=sinx⋅lnx

第二步，两边对 x 求导。左边是复合，得 1yy'；右边是乘积，必须用 (uv)'=u'v+uv'——这一步就是它和 xx 唯一的区别（xx 那边右边是「x 乘 lnx」，也只有两项，但结构完全相同）：

1yy'=cosx⋅lnx+sinx⋅1x

第三步，两边乘 y，把 y 代回去。y 就是原来的 xsinx：

y'=xsinx(cosxlnx+sinxx)

回看要点：把 sinx 换成任何关于 x 的函数，做法都不变——取对数拉下指数，右边化成乘积或商，再求导。这也是「幂指函数」这一类题的统一套路。

方法二：写成指数 evlnu

24:03把幂指函数直接改写成以 e 为底：

y=u(x)v(x)=ev(x)lnu(x)

这样它就成了普通的指数复合，用洋葱法则即可。以 y=xx 为例：

y=exlnx,y'=exlnx⋅(xlnx)'=xx(lnx+1)

25:54老师特意说：这个公式太好了我还得赶紧背下来？不用背——做题时用同样的思路去做就行。所以方法二不用记公式，记住「化回 e 的指数」这个念头就够了。

对数求导法 · 场景二：一堆连乘连除

27:46当函数是一长串因子的乘积、商、根式（比如根号下还套着分式），直接套四则法则会恶心到「几乎不可能」。这时取对数，乘除立刻变加减。

取对数前的「暗号」：定义域

取 lny 默认 y>0。老师课堂上举过 x>4 让各因式为正的例子，前提是 x 大于四，这样每部分都大于零。但老师随后泼了冷水：其他区间结果其实一样，取值范围咱可以不取，对最终结果没影响。所以实战里一般直接取、最后把 y 乘回去即可，不必为定义域纠结。

例 528:54设 y=(x−1)(x−2)(x−3)(x−4)，求 y'（课上先设 x>4）。

思路：一堆乘除还套着根号 → 取对数，把它们全拆开

老师先点破这类题的「货色」：这种类型的题目是什么类型呢？就是相乘的、相除的，好多式子，巨复杂。就这个题来说，打眼一看，你先浮现出来的是不是应该是相除求导啊？但做起来巨麻烦，impossible，几乎不可能。所以上对数。

第一步，取对数并拆开。根号外的次数 12 提到前面，乘除变加减：

lny=12[ln(x−1)+ln(x−2)−ln(x−3)−ln(x−4)]

老师交代了取 x>4 的原因：前提是 x 大于四，这样的话这部分大于零，这部分、这部分、这部分都大于零。这样每个 ln 里的东西都是正的，取对数才合法。

第二步，两边对 x 求导。左边是复合 1yy'；右边每一项都是「ln 神马」，里层的 x−1 等本身还要再乘一次自己的导数（恰好等于 1）：

1yy'=12(1x−1+1x−2−1x−3−1x−4)

第三步，把 y 乘回去。这个 y 就是原来的函数式，照抄即可：

y'=12(x−1)(x−2)(x−3)(x−4)(1x−1+1x−2−1x−3−1x−4)

回看要点：整道题最容易翻车的地方是符号——分母上的两个因式对应负号（因为 lnAB=lnA−lnB），所以 x−3、x−4 那两项前面是减号，千万别一律写成加。另外，虽然课上先设了 x>4，老师随后又说：其他区间它的结果是一样的，所以我们在做题的时候，x 的取值范围咱可以不取，最终对结果没有影响。

最容易漏的一处

对 ln(x−1) 求导只写 1x−1，忘了里层还有 (x−1)'。老师原话：大家经常漏的就是 x−1 是不是还得再求导啊？复合函数嘛。这里 (x−1)'=1，乘了看不出差别，所以侥幸过关；可一旦换成 ln(2x+1)，漏掉那个 2 就立刻暴露。习惯要从现在养成：凡是 ln(⋅)，括号里不是光秃秃一个 x 的，都要补一刀里层导数。

例 633:11设 y=ex(1+x2)sinx1+x(x>0)，求 y'。

思路：取对数把乘除拆成加减，再两边求导

两边取 ln（根式 1+x 提出 12）：

lny=x+ln(1+x2)−ln(sinx)−12ln(1+x)

对 x 求导（左是复合 1yy'）：

1yy'=1+2x1+x2−cosxsinx−12(1+x)

把 y 乘回去：

y'=y(1+2x1+x2−cotx−12(1+x))
这一步最容易错

非要通分、硬把括号里化简。老师原话很逗：这些你不通分啥的、约约一约？不约！宋老师不约。对数求导法得出的这种「y 乘一个长括号」就是标准答案形态，不化简、不约分。越通分越容易算错，而且考试就认这个形式。

为什么「不约」反而对

对数求导法的价值恰恰在「保留结构」：括号里每一项分别对应原式的一个因子（指数项、多项式项、三角函数项、根式项），一眼能看出从哪来。一旦通分，这个对应关系就毁了，既难检查又易错。所以它本来就不是给你化简的，是给你「安全地求导」的——拿到 y'=y⋅(⋯) 这步，任务就完成了。

记忆入口 · 一眼回忆

一句话

隐函数：两边对 x 求导，含 y 当复合（乘 y'）。对数求导：取对数打散结构。

隐函数两条路

  1. 两边对 x 求导：含 y 的项按复合处理，补 y'（如 (yn)'=nyn−1y'），再提 y'、解出；代点时先由原方程求 y。
  2. 公式法：写成 F(x,y)=0，则 y'=−FxFy（求 Fx 把 y 当常数，求 Fy 把 x 当常数）。

对数求导两种场景

  • 幂指 u(x)v(x)（如 xx、xsinx）：取 ln 拉下指数，或化 evlnu
  • 连乘连除带根号（如 (x−1)(x−2)(x−3)(x−4)）：取 ln 把乘除变加减

两个必背结果

(xx)'
xx(1+lnx)
隐函数二阶导
一阶导再对 x 走一次复合，里面的 y 仍要乘 y'
符号
dydx 准确、y' 方便；二阶导是 d2ydx2

四个坑

  • 含 y 的项忘乘 y'（头号错误）
  • 代点前忘先从原方程解出 y
  • 对数求导后硬通分化简（应「不约」）
  • 公式法丢负号，或把 Fx、Fy 写反
