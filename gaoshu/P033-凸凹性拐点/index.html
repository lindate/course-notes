P033凸凹性与拐点：用二阶导数看曲线往哪边弯

一句话核心

曲线的「凹」与「凸」有两个口径，但说到底是一回事：几何上弦在曲线上方就是凹，下方就是凸；代数上 f''(x)>0 是凹、f''(x)<0 是凸。拐点是凸凹性发生改变的那个二维点 (x0,f(x0))——f''(x0)=0 只是嫌疑，左右不变号就不是拐点（y=x4 就是反例）。

先认形状：凹进去与凸出来

00:00「凸凹」这两个字本身就像形——凹是凹进去一块，凸是凸出来一块。老师强调这是相对的：同一个图形，你从下往上看是凸，从上往下看可能就成了凹。更麻烦的是，不同教材对这两个字的定义可能正好相反：有的书把碗口朝上叫凸，有的叫凹。所以本节认准我们这套定义即可：

本套约定

f''(x)>0 时曲线是凹的（碗口朝上、像「凹」字底部那块平的）；f''(x)<0 时曲线是凸的（拱起来、像「凸」字顶上那块鼓的）。

01:30视频原话（大意）

凸凹这两个字，是我写汉字写得最难的。上大学时那位数学老师，不知道是山东哪儿的，念这个东西叫「娃凹性」——把凸念成了娃。还有一次去听别的老师讲课，他说「奇函数」，我学了一辈子也不知道什么叫奇函数，一看这不就是奇函数吗？原来他念的是奇偶的那个「奇」。

老师说这些，正为了说明一件事：名字和读音会骗人，形状不会。凸凹的名字各书可能正好相反，认准 f'' 的正负和那张「弦与曲线」的图，就够了。

02:46为什么「凸凹」是相对的，必须约定口径

同一张图，从下面看是凸，从上面看可能就是凹。老师举了一把两个把手的「井」字型的例子，又打了个比方：有半杯水，你说它是半杯满的，人家偏爱说半杯是空的——说法对立，描述的却是同一个事实。所以数学书必须硬性约定一个口径，否则「这段曲线是凹是凸」这种话就没有意义。不同的书约的可能相反，我们这套的定义只是其中一种，好在它和汉字的形状比较贴近。

两种定义口径，其实是一回事

03:03课本先给了一个「严格定义」，靠弦和曲线中点的位置关系：

严格定义（几何口径）

任取 x1<x2，记中点 x1+x22。若

f(x1+x22)<f(x1)+f(x2)2

则称为凹；不等号反向（左边大于右边）则称为凸。

06:39翻译成图上的话：把 (x1,f(x1)) 和 (x2,f(x2)) 连成一条弦，弦的中点是 (x1+x22,f(x1)+f(x2)2)。如果曲线在弦的下方（即曲线中点比弦中点低），就是凹；曲线在弦的上方，就是凸。老师直言这个严格定义「做题完全不用」，但它把「凹」「凸」的几何含义钉死了。

04:40严格定义里的那个「中点」为什么正好是梯形中位线

老师带着大家把定义「拆成边」看过一遍：设 x1<x2，曲线上的两点对应纵坐标 f(x1)、f(x2)。把这两点连成弦，f(x1)+f(x2)2 正是弦中点的纵坐标——因为 x1、x2 的中点在横轴上，弦在这处的纵坐标就是两端纵坐标的平均（梯形中位线）。而 f(x1+x22) 是曲线上同一横坐标处的纵坐标。所以 f(中点)<f(x1)+f(x2)2 这句话，就是「曲线中点比弦中点低」，也就是曲线在弦的下方。

判定定理（代数口径，做题就靠它）

设 f(x) 在 [a,b] 上连续，在 (a,b) 内有一阶、二阶导数，则

f''(x)>0⇒凹,f''(x)<0⇒凸
两种口径为什么等价

几何口径说「曲线在弦下方 = 凹」，代数口径说「f''>0 = 凹」。前者是形状描述，后者是计算公式。可以证明：当 f''>0 时，函数是「加速上升 / 减速下降」的，曲线被「托」在弦的下方，于是几何口径的「凹」和代数口径的「f''>0」指向同一件事。所以记判定定理就够了，但心里要清楚它背后是那张弦与曲线的图——这样名字反了你也不会慌。

07:27判定定理为什么要求「一阶、二阶导数都存在」

因为结论用的就是 f'' 的符号，而 f'' 是「把 f' 再求一次导」——它要存在，前提是先有 f'。所以条件必须一次性写上「有一阶、二阶导数」，缺一不可。课本对这个定理有很详细的证明，老师让大家不用看：平时用的时候直接用结论，把条件记牢就行。真正要留心的是条件够不着的情形——比如 f'' 不存在的点，判定定理就管不到那里，只能退回图像和定义，去看左右两侧的凸凹有没有变（后面 y=x3 那题正是如此）。

记忆法：正字平顶 = 凹，凸字鼓包 = 凸

08:42判定定理谁都背得下来，一做题就晕。老师给了一个画面感极强的办法：

四字记忆 · 12:22正→凹，负→凸

「正」字上面是平的（一横平平），对应 f''>0 是凹（凹字底下那块也是平的）；「凸」字上面鼓出来一块，对应 f''<0 是凸。这样下次大脑一看到 f''<0，立刻弹出一个「凸」字鼓包的形象，比死记硬背牢得多。

为什么这个记忆法靠谱（从一阶导看）

f'' 是 f' 的导数。f''>0 说明 f' 单调增——画个凹的碗，从左到右切线斜率由负变正、越变越大，确实是「增」的；f''<0 说明 f' 单调减——拱形曲线切线斜率由正变负、越来越小。所以「f'' 正→凹」其实和「一阶导判断单调性」是同一套逻辑，只是把原函数换成了它的一阶导。

和单调性什么关系：一阶看增减，二阶看弯向

09:21凸凹性的判定和单调性像得让人发晕：单调性看一阶导的正负，凸凹性看二阶导的正负。老师把这两件事的关系说得非常清楚——f'' 就是 f' 的导数，所以

  • f''>0 ⟺ f' 单调增 ⟺ 曲线的切线斜率越来越大 ⟺ 凹；
  • f''<0 ⟺ f' 单调减 ⟺ 切线斜率越来越小 ⟺ 凸。

关键在同一套逻辑被用了两遍：判断单调性时，观察的对象是原函数 f；判断凸凹性时，观察的对象换成了切线斜率 f'。所谓「f''>0 就是凹」，说的不过是「f' 是增函数」而已。

10:45为什么「斜率在增大」就是凹

在凹的曲线（碗）上从左往右走，切线斜率从负的一路变到正的，的确在增大；在凸的曲线（拱）上走，斜率从正变到负，越来越小。反过来，如果图上只给你一小片曲线、也不告诉你它是哪一段，怎么认？老师给了个很实用的办法——把这一小片「补全」成一个完整的碗或拱：能补成碗口朝上的，就是凹；能补成拱起来的，就是凸。

还要留心一点：增减与弯向互不干涉。上升的曲线可以是凹的（越升越陡），也可以是凸的（越升越缓）；下降的曲线同理。下面四块「碎片」，就是全部四种组合。

练习16:12只给一小片曲线，怎么判断它是凹的还是凸的？

思路：把它「补全」成一个完整的碗或拱

考试不会给你一整条曲线、旁边还标好凹凸；往往只给你一小片。老师给的办法是：顺着这一片的趋势，把它补成一个完整的形状——

  • 能补成碗口朝上的碗 → 凹（f''>0）；
  • 能补成向上拱起的拱 → 凸（f''<0）。

碎片本身往往只画了「上升的一段」或「下降的一段」，看不出碗还是拱，但把两端延长的趋势在脑子里补出来，形状立刻就定了。老师反复练的就是这个动作。

别被「上升」骗了

看到曲线在上升就判成凹。上升只说明 f'>0，跟弯向无关。同样是上升的一小片，可能是越升越陡（凹），也可能是越升越缓（凸）。判凹凸只看 f'' 的符号，或者看它补全后是碗还是拱。

例题：几个常见曲线的凸凹性

例 113:43判断 y=lnx 的凸凹性。

思路：求导两次看符号

定义域 (0,+∞)。

y'=1x,y''=−1x2

无论 x>0 取什么，y''=−1x2<0 恒成立。由判定定理，y=lnx 在整个定义域上是凸的。对照图像——lnx 那条增速越来越慢的曲线，正是拱起来的凸形。

例 217:29判断 y=x3 的凸凹区间。

思路：f'' 变号处就是凸凹分界

y'=3x2,y''=6x。

  • x<0 时 y''<0 → 凸区间 (−∞,0]；
  • x>0 时 y''>0 → 凹区间 [0,+∞)。

分界点 x=0 在定义域内有定义，所以区间端点把 0 写进去（和单调区间同理：有定义就含端点）。x=0 处左右凸凹性相反，它就是一个拐点。

例 320:50判断 y=1x 的凸凹区间。

思路：零不在定义域，区间绝不能写零

y'=−1x2,y''=2x3。

  • x<0 时 x3<0 → y''<0 → 凸区间 (−∞,0)；
  • x>0 时 x3>0 → y''>0 → 凹区间 (0,+∞)。

这里 x=0 不在定义域内，所以两个区间都必须用「并」分开，绝对不能写成含 0 的闭区间。这是和例 2 最关键的差别：端点能不能写，只看它有没有定义。

拐点：凸凹性改变的那个「点」

22:44拐点是这么来的：当曲线经过某一点时，凸凹性发生了变化（左边凸、右边凹，或反过来），这个点就叫拐点。但有两个铁规矩：

规矩一：拐点是二维点
必须写成 (x0,f(x0))，不能写成「x=x0 是拐点」。拐点是平面上的一个点，不是一个数。
规矩二：点必须在曲线上
要求曲线经过该点且在此凸凹性改变。这一点函数没定义，就谈不上拐点。
22:44最经典的错误

上面例 3 的 y=1x，在 x=0 左右凸凹性确实变了（左凸右凹），于是很多人脱口而出「x=0 是拐点」。错！x=0 处函数根本没定义，曲线不经过它，凭什么叫拐点？正确说法是：这里没有拐点。y=1x 没有拐点。

怎么求拐点

26:38书上的步骤很固定：

  1. 求二阶导数 f''(x)。永远先确认定义域。
  2. 找嫌疑点：令 f''(x)=0 的点，以及 f''(x) 不存在的点。这两类只是「疑似拐点」，不一定是。
  3. 看左右符号：考察每个嫌疑点两侧 f'' 的正负号是否改变。变了 → 是拐点；没变 → 不是拐点。
为什么 f''(x0)=0 只是嫌疑

因为 f'' 在 x0 为零，左右可能「都是正的」（或都是负的），凸凹性压根没变。零只是「可能变号」的位置，不是「一定变号」的保证。同理 f'' 不存在的点，只要左右凸凹性变了，照样是拐点——它和「函数本身没定义」完全是两码事。

43:06「二阶导不存在」和「函数没定义」是两回事

这是本节最容易含混的一句，老师反复强调。三种情况必须分清：

  • 函数在 x0 没定义（如 y=1x 在 0）：点不在曲线上，谈不上拐点——直接排除；
  • 函数有定义，但 f''(x0) 不存在（如 y=x3 在 0）：点在曲线上，只是判定定理用不上，得退回定义看左右凸凹有没有变；
  • 函数有定义，f''(x0)=0（如 y=x4 在 0）：定理能用，但结论待定，看左右符号是否变。

一句话：拐点的门槛是「点在曲线上」，不是「二阶导算得出来」。所以做题的第三步永远要问自己：这个嫌疑点，函数到底有没有定义？

52:38三个函数放一起记，最省事

课本里的三个经典例子，恰好把三种结局演全了，建议成组记：

函数x=0 处的 f''左右是否变号结论
y=x3f''(0)=0左负右正，变(0,0) 是拐点
y=x4f''(0)=0两侧都为正，不变没有拐点
y=x3f''(0) 不存在左正右负，变(0,0) 是拐点

规律一眼可见：f''(0) 是零还是不存在，都只是「有没有资格当嫌疑」，真正拍板的永远是「左右变不变号」。

例 430:04求 y=2x3+3x2−12x+14 的拐点。

思路：解 y''=0 再验左右

y'=6x2+6x−12,y''=12x+6。令 y''=0 得 x=−12。

当 x<−12 时 y''<0（凸）；当 x>−12 时 y''>0（凹）。左右变号，故 x=−12 确实是拐点。代入求函数值：

y(−12)=2(−18)+3(14)−12(−12)+14=−14+34+6+14=20.5

所以拐点是 (−12,20.5)。注意写的是二维点。

例 534:42求 y=3x4−4x3 的拐点（以 0、23 分点列表判断）。

思路：列表看 f'' 符号，比写一大段文字清楚

y'=12x3−12x2，y''=36x2−24x=12x(3x−2)。令 y''=0 得 x=0、x=23。用这两个点把定义域切开：

区间(−∞,0)(0,23)(23,+∞)
12x−++
3x−2−−+
y''+（凹）−（凸）+（凹）

在 x=0：左凹右凸，变号 → 拐点，代入得 y(0)=0，即 (0,0)。在 x=23：左凸右凹，变号 → 拐点，y(23)=3⋅1681−4⋅827=−1627，即 (23,−1627)。

两个反例：把「疑似」和「真拐」分清

反例 138:12y=x4 有没有拐点？

思路：f''(0)=0 不代表变号

y'=4x3,y''=12x2≥0 恒成立。在 x=0 处 y''=0，但 x<0 与 x>0 时 y'' 都严格大于 0，左右都是凹的，凸凹性根本没变。所以 y=x4 没有拐点。

老师的提醒

不是所有曲线都必须有拐点。x4 的图像比 x2 更「窄」地一直凹下去，全程一个弯向都不改变。这个反例专门用来破除「f''(x0)=0 就一定是拐点」的错觉。

反例 240:05y=x3 在 x=0 是拐点吗？

思路：f'' 不存在也能是拐点

y'=13x−23，y''=−29x−53=−29x5/3。在 x=0 处 y'' 不存在（分母为零），但：

  • x<0 时 x5/3<0 → y''>0 → 凹；
  • x>0 时 x5/3>0 → y''<0 → 凸。

左右凸凹性变了，且点 (0,0) 在曲线上、有定义，所以 (0,0) 是拐点。这里 f'' 不存在反而成了拐点——正好印证「不存在的点也是嫌疑点」。

别把「函数没定义」和「二阶导没定义」搞混

有人一看到 y'' 在 x=0 不存在，就说「这点都不存在了还管它干嘛」。两码事！x=0 处原函数 y=03=0 明明有定义，只是二阶导数算不出来。原函数在，且左右凸凹变了，它就是拐点。

把拐点和极值点彻底分开

40:05两节连着学，最容易混的就是这两个词。它们都出现在「导数等于零或不存在」的位置上，但盯的根本不是同一件事：极值点关心函数值的局部高低（看 f' 变号），拐点关心曲线弯向的改变（看 f'' 变号）。

对比项极值点拐点
一句话定义邻域内函数值最大 / 最小的位置曲线经过它时凸凹性改变的位置
靠哪个导数判一阶导 f' 左右是否变号二阶导 f'' 左右是否变号
怎么写才对是 x 值：「x=x0 是极值点」是二维点：「(x0,f(x0)) 是拐点」
候选点来源驻点（f'=0）与不可导点f''=0 的点与 f'' 不存在的点
可导处的切线一定水平（斜率 0）一般斜着（斜率可以不为 0）
用同一批函数记差别
  • y=x2：x=0 是极小值点（谷底），切线水平。它不是拐点——全程都凹，弯向压根没变。
  • y=x3：(0,0) 是拐点（左凸右凹），但 x=0 不是极值点——曲线从下坡直接穿过原点继续上坡。这里切线也恰好水平（f'(0)=0），属于巧合。
  • 例 4 的 y=2x3+3x2−12x+14：拐点 (−12,20.5) 处切线斜率是 −272，斜得厉害。可见「拐点」和「水平切线」之间没有任何必然联系。
为什么两个「嫌疑点」的清单长得像

找极值点，要找 f' 为零或不存在的地方；找拐点，要找 f'' 为零或不存在的地方。形式一样，是因为背后的推理一样：能用「变号」下结论的位置，只能是导数为零或导数不存在的位置（变号的地方导数不可能取一个非零的普通值）。区别只在「谁在变号」——是 f' 变号（函数掉头，出极值），还是 f'' 变号（弯向掉头，出拐点）。

记忆入口 · 一眼回忆

两种口径（等价）

几何：弦在曲线上方 = 凹，下方 = 凸。代数：f''>0 凹，f''<0 凸。

记忆口诀

正→凹，负→凸；正字平顶=凹，凸字鼓包=凸。

拐点

  • 定义：过该点凸凹性改变
  • 必须是二维点 (x0,f(x0))，不能写「x=x0」
  • 点必须在曲线上（有定义且经过）
  • 求法：f''=0 与 f'' 不存在 → 看左右是否变号

两个反例

  • y=x4：f''(0)=0 但左右都凹 → 无拐点
  • y=x3：f''(0) 不存在但左右变号 → (0,0) 是拐点
  • 对照组 y=x3：f''(0)=0 且左右变号 → (0,0) 是拐点

两个坑

  • f''(x0)=0 只是嫌疑，不变号就不是拐点
  • 区间端点写不写零，只看该点有没有定义

别和极值点混

  • 极值点看 f' 变号（局部高低）；拐点看 f'' 变号（弯向改变）
  • 极值点是 x 值；拐点是二维点 (x0,f(x0))
  • 可导的极值点切线必水平；拐点切线可以斜着（例 4 斜率 −272）

四种组合

增 · 凹 = 越升越陡；增 · 凸 = 越升越缓；减 · 凹 = 越降越缓；减 · 凸 = 越降越陡。增减看 f'，弯向看 f''，互不干涉。
