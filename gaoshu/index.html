CH第一章系统梳理：函数与极限
不按课次平铺，按「为什么引入 → 定义 → 条件 → 用法」重写整章；含知识网络、题型流程、易错清单与自测。
P001映射：在讲函数之前，先把「对应」这件事说清楚
整章要从「对应」讲到「函数」。映射就是那个铺垫：它只规定一条铁律——一个 x 只能对应一个 y，反过来不要求。这一条铁律往下推出满射、单射、一一映射，再推出「只有单射才倒得过来」（逆映射），以及「前一步的值域必须落进后一步的定义域」（复合映射）。这一页里所有例子都是课上原话举过的：x2、圆投影、sinx、1−u2。映射本身后面几乎不再单独用，但它是函数那张地基的钢筋。
P003函数：对应关系、四大性质、反函数与复合
函数是高数里做题用得最多的对象。它把映射的「集合」收紧成「数到数」：D⊆R 上的对应法则。这一页干四件事——说清函数是什么、四大性质各自的定义与反例、反函数为什么要求单射且图像关于 y=x 对称、复合函数为什么还要看「中间变量的值域是否落进定义域」。
P004初等函数：六类基本初等函数与老师补充的 cot、反三角
这一页把「能用一个式子写出来的函数」盘点清楚。六类基本初等函数（幂 / 指 / 对 / 三 / 反三 / 常）是搭乐高的零件；老师特意补了高中不讲、大学却常用的 cotx 与反三角函数。最后一句判据要记死：分段函数一般不是初等函数——y=|x| 是，但 y=[x] 不是。
P005数列的极限：把「越来越接近」变成一句能检查的话
这节课只干一件事：给「n 越大，an 越接近 A」这句大白话装上刻度。办法是——你随便报一个多小的容许误差 ε，我都能指给你看某一项，从它之后所有的项全都待在 A 的 ε 范围里。就靠「存在 N」这一句，用有限管住了无限。
P006收敛数列的性质：唯一、有界、保号、子列
上一节把「收敛」写成了一个可以逐字检查的判据；这一节把它能推出什么一次结清：极限唯一、收敛必有界、极限的正负会保号地传给尾部、任意子列与母列同极限。真正要盯住的不是这四条本身，而是它们每一条「反过来」都不成立——那些反例才是这一节的边界。
P007函数极限定义：把 ε–N 换成 ε–δ
数列极限是「n 越大越靠近」；函数极限是「x 越接近 x0、f(x) 越接近 A」。把 [[5]] 的 ε–N 语言里的「第几项」换成「x0 旁边多大一个邻域」，就得到 ε–δ 定义。本课还拆出左/右极限与x→∞ 两种情形，并引出水平渐近线。
P008函数极限的性质：局部有界、局部保号、与数列极限的桥
和 [[6]] 的数列极限性质同构，只是把「项数 N 之后」换成了「x0 旁边一小段」。本课三条：极限唯一、局部有界、局部保号；再加一座桥——函数极限存在时，沿任意数列逼近都得同一极限。正因「只保局部」，有界不保收敛那套陷阱在这里换了个样子重现。
P009与极限为 ∞ 的量
极限为 0 的量叫无穷小，极限为 ∞ 的量叫无穷大。它们都是「极限的语言」：前者把「趋于零」符号化，后者把「趋于无穷」符号化。最关键的两句话——「趋于零」不是「等于零」，且「极限是无穷大」其实属于极限不存在。二者还互为倒数。
P010极限运算法则
极限有两个层次的工具：一是无穷小自己的算术（和、积、被有界量乘，仍然是无穷小）；二是极限的四则运算——但第二条有个铁门槛：只有两个极限都存在，才能把极限「分进去」先算。再加上一套专治 x→∞ 多项式商的「抓大头」，做题的骨架就齐了。
P011极限存在准则·第一第二重要极限
两条「准则」告诉你极限为什么一定存在：夹逼准则说「被两个同极限的量夹在中间，你只能跟着收敛」，单调有界准则说「单调又跑不出去，必然停在界上」。而两个重要极限 limx→0sinxx=1 与 limx→∞(1+1x)x=e 则是做题时直接调用的硬底牌——第二重要极限最反直觉：「趋于 1 的无穷次方」不是 1，是 e。
P012无穷小的比较 · 等价无穷小替换
无穷小之间要比的不是「谁小」，而是谁趋于零更快。比完之后，最有价值的一件事出现了：在乘除的因式位置上，一个无穷小可以被它的等价无穷小直接换掉，极限不变。这一招让一大批极限题从「要硬凑重要极限」变成一眼出答案——但它有一条铁律：只能换因式，不能换加减项。
P013连续：把「笔不离纸一笔画出来」变成三句可检查的话
连续就是画函数图像时笔不离纸、一笔画出来。它等价于三句话：在 x0 处有定义、x→x0 时极限存在、且极限正好等于函数值。把最后一句拆开，又得到左连续与右连续——而连续 ⇔ 左右都连续。
P014间断点：连续三要素坏掉哪条，就归哪类
间断点就是连续三要素里至少坏了一条的地方。按「左右极限是否存在」一刀切开：左右极限都存在的叫第一类（可去、跳跃），至少有一个不存在的叫第二类（无穷、震荡）。记住六字口诀：一可跳，二无荡。
P015连续函数的运算 · 反函数与复合函数的连续性
这一节存在感很低——自己看也能做题。但它给了三句话：连续函数四则运算后仍连续；单调连续函数的反函数仍连续；复合函数的极限可以「写进里面去」。最后一句话正是后面所有等价无穷小替换题的底层依据：求 limesinx（x→0）时，直接把「x→0 让 sinx→0」代进去得到 e0=1，用的就是它。
P016闭区间上连续函数的性质
四个定理都挂着同一个前缀：闭区间 + 连续函数。结论很直白——闭区间上的连续函数「一定有界、一定有最大值和最小值、异号端点之间必穿过 x 轴、介乎两端函数值之间的值都取得到」。但「闭区间」三个字一个都不能少：换成开区间、或中间断一下，结论立刻垮掉。这一页就专门把「少了条件会怎样」的反例讲透。

第 2 章 导数与微分12 / 12

P017导数的定义
全书最基础的一页。导数就是切线的斜率，而切线是「割线让两点无限靠近」的极限。一句话钉死：f'(x0)=limΔx→0f(x0+Δx)−f(x0)Δx。重点分清两件事：「在一点可导」得到一个数，「导函数」是一个新函数；还有——连续是「一笔画」，可导是「一笔画且光滑」，带尖角就不可导。
P018导数的几何含义
导数 f'(x0) 就是过曲线上点 (x0,y0) 的切线斜率，而切线本身是割线的极限位置——「与曲线只有一个交点」定义不了它。由此得到两个公式：切线 y−y0=f'(x0)(x−x0)，法线 y−y0=−1f'(x0)(x−x0)。关键要分清「在曲线上某点」与「过曲线外一点」两种切线题（后者要先设切点），并记住可导 ⇔ 有非竖直切线——有竖直切线时不可导。
P019可导与连续的关系
一句话：可导必连续，连续未必可导。「可导」比「连续」多一道关卡——不仅要一笔连得上，曲线还要光滑。所以可导函数一定连续，但连续函数可能因为尖角、垂直切线或无穷振荡而不可导。记住这条方向不能倒着用：不连续就一定不可导，但连续只是入场券，进了场才谈得上求导。
P020求导公式
本节把「能直接拿来用」的求导公式一次讲清：先是最常用的四则运算求导（加减、乘积、商、常数提出），再由此推出三角函数的导数。乘积法则是「交叉相加」，商法则是「分母平方、分子交叉相减」——谁减谁、减号方向是最容易翻车的地方。文末把16 条基本初等函数求导公式汇成一张总表，并给出「负号跟着『余』走」的统一记忆法。
P021反函数求导
反函数求导一句话：反函数的导数 = 原导数的倒数，即 dydx=1dx/dy。它做题用得不多，价值在于推出反三角与对数的一族导数公式。几何上看，反函数图像关于 y=x 对称，切线也对称，斜率自然互为倒数。
P022复合函数求导
复合函数求导是整章的必考点：考试不会考光秃秃的基本公式，一定考套了层的复合函数。核心就是链式法则 dydx=dydu⋅dudx，宋老师更爱叫它洋葱法则——从最外层一层一层往里剥，每层求导、最后全部相乘。
P023基本求导法则与公式：全书的工具箱
前面几节课我们已经把绝大部分求导公式逐个推导过了，这一页是把它们一次性汇总成一张可查的表。它不像概念页需要你理解「为什么」，它更像一把要用就抽的刀：四则运算法则管「怎么把复杂式子拆开」，基本初等函数公式管「拆开后的每一小块各自等于什么」。务必死记。
P024高阶导数：把导数再求一次、再求一次
高阶导数没有新概念——它就是把一阶导数当成新函数，再求一次导。难点全在记号和找规律：二阶导 y'' 既是加速度也是凹凸，而 sinx、ex 的 n 阶导有漂亮的通式，莱布尼茨公式则是乘积高阶导的「杨辉三角」。
P025隐函数求导与对数求导法：当 y 写不出、底数指数都有 x
这一页解决两类「常规公式够不着」的求导：隐函数（方程里 y 提不出来）和幂指 / 连乘除函数。隐函数的命门只有一句——y 是 x 的函数，对含 y 的式子求导要当复合函数处理；对数求导则是用「取对数把乘除变加减、把幂指变乘积」来化难为易。
P026参数方程求导：借一个中间变量 t 把曲线求导
当曲线用 x=φ(t),y=ψ(t) 给出时，y 仍是 x 的函数，只是隔了一层参数 t。核心公式一句话：dydx=dy/dtdx/dt——分子分母同除以 dt 即得。二阶导不必硬记公式，把一阶导再「比上 dt 比上 dt」重做一遍即可。
P027微分：给函数增量找一个线性替身
微分就是给「函数值的改变」找一个线性近似：把 Δy 里最要紧的那块 f'(x)Δx 单独拎出来叫 dy。Δy 是真实增量，dy 是近似值——这一字之差，正是「以直代曲」的数学表达。
P028微分在近似计算中的应用：拿直线换掉曲线
微分给了一个超好用的近似公式：f(x0+Δx)≈f(x0)+f'(x0)Δx。思路就一句：用切线在 x0 处的值，顶替曲线在 x0+Δx 处的值。前提只有一条——Δx 必须足够小。

第 3 章 微分中值定理与导数的应用9 / 9

P029微分中值定理：罗尔、拉格朗日、柯西
这三个定理长得像，其实是一条链：罗尔要求两端等高，结论是「有一点切线水平」；把图整体倾斜一下，等高这个条件就没了，得到拉格朗日——「有一点，切线平行于弦」；再把 x,y 都换成参数方程，就是柯西。它们都只说一件事：那个点存在，但不必知道它在哪。
P030洛必达法则：把未定式极限交给求导来解决
洛必达法则是求极限的「通法」：遇到 0/0 或 ∞/∞，只要分子分母分别求导再取极限，能求出来就与原极限相等。但它不是万能钥匙——导数极限不存在时它直接失效，而且 0⋅∞、∞−∞、00、1∞、∞0 都得先「转化」成基本型。
P031泰勒公式：用多项式完整复刻一个函数
等价无穷小是泰勒公式的一次项版本——它只保留 f'(x0)。泰勒做的事情是：把「用一条切线代替曲线」推广到用一条 n 次多项式代替曲线，并且给出误差的确切表达式。它把「近似」从一种手感变成了一种可以估算的运算。
P032函数的单调性：用导数的符号给增减「定罪」
单调区间可以靠图像「看」，但更可靠的是靠导数算：在区间内 f'(x)&gt;0 就单调增，f'(x)&lt;0 就单调减。这里最容易被忽略的是边界——导数在有限个点等于 0（甚至不存在）并不会破坏单调性，它们只是把区间「切开」的界点。
P033凸凹性与拐点：用二阶导数看曲线往哪边弯
曲线的「凹」与「凸」有两个口径，但说到底是一回事：几何上弦在曲线上方就是凹，下方就是凸；代数上 f''(x)&gt;0 是凹、f''(x)&lt;0 是凸。拐点是凸凹性发生改变的那个二维点 (x0,f(x0))——f''(x0)=0 只是嫌疑，左右不变号就不是拐点（y=x4 就是反例）。
P034极值：局部的高与低，和驻点、最值分清
极值是局部概念——在 x0 旁边一小圈里最大或最小，跟全局无关（极大值甚至可能比极小值还小）。可导时极值点必是驻点（f'=0），但驻点不一定极值（y=x3）；判断靠第一充分条件（看 f' 变号）或第二充分条件（看 f''）。
P035最值 · 闭区间上连续函数的最大值与最小值
闭区间上连续的函数，最值只可能藏在三类点里——不可导点、驻点、区间端点。把它们仨的函数值都算出来比一比，最大的就是最大值、最小的就是最小值。先把一件事掰开：极值是「方圆一米内最大」，最值是「全校最高」，这是两件事。
P036函数图形的绘制 · 六步法
画图不是「凭感觉描点」，而是把定义域 / 奇偶周期 / 一二阶导 / 渐近走向逐项算清，再落笔。核心口诀：一阶导管单调与驻点，二阶导管凹凸与拐点；最后把所有信息收进一张表，照表描图。渐近线要分水平、铅垂、斜三种，按「铅垂 → 水平 → 斜」的顺序排查。
P037曲率 · 曲线「弯得多狠」的度量
曲率 K 就是给一条曲线「弯曲程度」打分：同样长的一段弧，拐的弯越急，曲率越大。记住唯一要背的公式 K=|y''|(1+y'2)3/2——注意是 (1+y'2) 的 3/2 次方，不是 1/2 次方。圆的曲率最规整：K=1R，曲率半径 ρ=1K=R。

第 4 章 不定积分7 / 7

P038不定积分的定义 · 求导的逆运算
不定积分就是求导反过来：已知导函数 f(x)，找回「谁求导得到它」的原函数。关键结论有两条——连续函数一定有原函数；原函数的全体之间只差一个常数，所以不定积分永远写成 F(x)+C，那个 C 一个都不能丢。积分表与求导表互为逆运算。
P039不定积分的性质：把"积分当逆运算"说精确
不定积分有两个最朴素的性质——加减能拆开、常数能外提。它和求导是互逆的，但必须补上一句：先求导再积分，结果和原函数只差一个任意常数 C。这一页就把这句"互为逆运算"讲死、讲准。
P040第一换元积分法（凑微分）
不定积分里 dx 的那个 d 就是微分号，所以它同时也能反向读：把被积式里的某一截缩回 d 的里面，就完成了一次「求原函数」。第一换元积分法（凑微分法）做的全部事情，就是这个动作——把 dx 凑成 dφ(x)，再整体套基本积分公式表。口诀一句：凑谁换谁。它的两条万能技巧是：相乘的常数直接进 D、D 里面可以任意加减常数。
P041第二换元积分法
第二换元积分法和第一换元刚好反过来：把藏在 D 里的 x 朝外拿成 x=φ(t)，靠三角函数公式把根号消掉。三角代换后必须画辅助直角三角形换回 x——这条是绝大多数人丢分的地方。
P042分部积分法
分部积分法就一个公式 ∫udv=uv−∫vdu，名字是「分部」不是「分步」。选 u 的口诀是「反·对·幂·三·指」——幂函数要当 u，因为分部一次幂次就降一。
P043有理函数的积分（上）
有理函数就是多项式除以多项式。假分式（分子次数高）先化真分式，真分式再按分母的四种因式分解情形做部分分式分解。二次因式的分子必须设 Ax+B，不是只设 A。
P044有理函数的积分（下）：待定系数法与总流程
有理函数的积分只有一条流水线：假分式先做多项式除法 → 分母因式分解 → 设部分分式 → 逐项积分。第三步是待定系数法的主场，设的「形状」由分母因式的类型决定，而系数可以用比较系数或代入特值两套手法定出来。

第 5 章 定积分9 / 9

P045定积分的定义
定积分是「分割、近似、求和、取极限」夹逼出来的一个确定数值，不是函数。记号里最容易被误读的是 λ→0 —— 它要求每一段都细，而不仅仅是段数多；这是它与「n→∞」的根本差别。
P046定积分的性质
定积分有六条常用性质，它们几乎都对应一个几何画面：线性是「拆开求」，可加性是「拼面积」，保号性是「在上方就非负」，估值与中值定理是「用长方形把曲边面积夹住」。中值定理多出的连续条件不是摆设——它靠介值定理把平均值「钉」在曲线上。
P047变上限积分函数
定积分本是「上下限固定」时的一个常数；一旦让上限动起来，它就变成 x 的函数 Φ(x)=∫axf(t)dt。在 f 连续的条件下，Φ'(x)=f(x)——这条结论不仅给出了一套求导公式，更证明了「连续函数必有原函数」。
P048牛顿–莱布尼兹公式
在这页之前，「定积分」只是一个黎曼和的极限，谁也算不出它的具体值。牛顿–莱布尼兹公式把这个死结一刀解开：只要 f 在 [a,b] 上连续，定积分就等于原函数在两端取值之差——求定积分从此变成「先求不定积分、再把上下限代进去」两步。但它有一条不能碰的红线：被积函数在积分区间上必须处处「正常」，一旦区间内部藏着无界点，公式会给出荒谬的负数。
P049定积分的换元法（上）
定积分的换元法和不定积分很像，但多了一条自己的规矩：变量换成 t 以后，积分限也必须跟着换成 t 的范围——口诀是换元必换限。换来换去之后还有一件好事：定积分算完直接就得数，不用回代。这一页把「限怎么对应」和「为什么不用回代」两件事讲透。
P050定积分的换元法（下）
这一页把换元法的三件「额外红利」讲完：奇偶函数在对称区间上的定积分（奇函数为 0、偶函数是半区间的两倍）、两个区间反转恒等式（sin 与 cos 互换、带 x 的积分化成不带 x 的）、以及周期函数一个周期内积分与起点无关。老师说：拿到定积分题，只要积分区间关于原点对称，第一反应就该是奇偶性——它的应用排在第一位。
P051定积分的分部积分法
定积分的分部积分就是不定积分那条公式再加一次代入：∫abudv=[uv]ab−∫abvdu。真正需要提防的是那个 [uv]ab——它必须把上下限代进去，不能只写 uv。本页最后一节讲一条几乎必考的工具：∫0π/2sinnxdx 的递推，也就是老师口中的「点火公式」。
P052无穷限的反常积分：把「积到无穷远」写成一次取极限
牛顿–莱布尼兹公式其实一直藏着两个前提：区间有限、被积函数连续。这一讲先拆掉第一个——让积分区间一直往无穷远伸。解法没有新工具，只是把「上限」换成一个会跑动的 t，再让 t→+∞：反常积分 = 带极限的牛顿–莱布尼兹公式。但从此多了一件事要判断：它到底收敛还是发散。
P053无界函数的反常积分：找出瑕点，在瑕点处取极限
上一讲拆掉了「区间有限」，这一讲拆掉「函数连续」。积分号长得和普通定积分一模一样，问题却藏在函数爆掉的那一点（叫瑕点）上。补救手法仍是取极限——在瑕点旁边退开一点点，逼过去。真正会要命的是瑕点落在区间内部：这时必须把积分拆成两段，否则你会得到一个有限的、看起来还挺像样的错误答案。

第 6 章 定积分的应用7 / 7

P054定积分的应用 · 求面积：上减下、右减左
面积公式只有一句话：上面的函数减下面的函数，从 a 积到 b。要说清的不是公式，而是两件事——「谁减谁」不看大小，看上下（所以曲线跑到 x 轴下方也照样成立）；以及什么时候该改对 y 积分。选错型，一道题会从「一个积分」变成「两个积分」。
P055微元法：先把一小块看清，再把它加起来
微元法不是一套新公式，而是一种理解的顺序。定积分的定义是「分、近似、求和、取极限」，微元法把这个过程倒过来看：先在任意一点处取一小块，把「弯的」当成「直的」、「变的」当成「不变的」，写出这一小块的量 dU，最后从 a 积到 b。求面积时它显得多余，到了体积和物理应用里就成了唯一的抓手。
P056定积分应用 · 求面积（极坐标）：扇形微元
极坐标下的面积公式只有一句话：把阴影切成一片片小扇形，每片面积是 12ρ2dθ，再把 θ 从 α 累加到 β。公式本身不难，难的是两件小事——积分限要从图上「扫」出来，以及角度必须用弧度。这一节只讲微元和一个例题，因为极坐标的完整内容要等到二重积分那一章才仔细展开。
P057求旋转体的体积：先画半径，再套公式
旋转体的体积公式一共只有四个，而且它们其实是同一句话的四种写法——把立体切成一片片薄片，每一片的横截面是一个圆（或圆环），把截面面积从一头积到另一头。真正让同学翻车的从来不是积分，而是「半径到底是谁」：绕 x 轴转半径是 y，绕 y 轴转半径是 x，每次动笔前都要把它画出来。
P058壳法求旋转体的体积：把筒剪开铺平
壳法（柱壳法）是绕 y 轴旋转的第二条路：不横着切成圆环，而是竖着切成一条条细条，每条绕 y 轴转出一层薄圆筒，把它剪开铺平就是一个长方体，体积是 2πxf(x)dx。它出现的全部理由只有四个字——不用反解。
P059非旋转体的体积：平行截面法
前面两节的立体都是「转出来」的，横截面永远是圆。这一节把限制去掉——只要每个位置的横截面面积 A(x) 知道，体积就是 ∫abA(x)dx。道理只有一句：把立体切成薄片，每片近似是一个柱体，底面积乘厚度再累加。经典例子是「圆柱过底面圆心斜切一刀」切出来的那块楔形，用两种切法都必须算出 23R3tanα。
P060平面曲线的弧长：以直代曲，量任意一条曲线
「平面曲线的弧长」这六个字里，除了那个「的」，每个字都有讲究。真正要做的事只有一件：把曲线剁成无数小段，每一段用一根直线顶替，再用勾股定理把这一小段的长度写出来。于是三种公式——参数方程、直角坐标、极坐标——其实只有同一个来源，区别只在「参数是谁」。

第 7 章 微分方程9 / 9

P061微分方程的基本概念：未知的是一个函数，不是一个数
从小学到现在，解方程都是「求一个数」；从这一讲起，要求的变成一条函数。定义只有一句话——含有未知函数的导数或微分的方程。真正要弄透的只有三件事：阶（看最高阶导数求了几次，别把「平方」当「阶」）、通解（任意常数个数恰好等于阶数）、特解（初始条件把常数定死）。
P062可分离变量的微分方程：分家、积分、回头看
这是微分方程里最简单的一类，也是后面所有方法的底子。套路只有一句话——把 x 和 dx 挪到一边，把 y 和 dy 挪到另一边，两边同时积分。但有一个必须养成的习惯：分离时除以过谁，就要回头问一句「那个东西等于零算不算解」——漏掉常数解，是这一节最真实的失分点。
P063齐次方程：换元三板斧，把 y/x 变成一个字母
齐次方程的形式特征只有一条——yx 整体出现。它的解法老师叫「三板斧」：设 u=yx、写 y=xu、把 dydx 换成 u+xdudx。三斧砍下去，方程就变成一个可分离变量的方程；而最后必须做、也最容易被忘掉的一步是——把 u 换回 yx。
P064一阶线性微分方程：一个必须背下来的通解公式
「一阶线性」只看一件事：y' 与 y 的关系是不是线性的，x 的表达式一律当常数。认准标准形式 y'+P(x)y=Q(x) 之后，通解就是一个只能死记的公式；本页先把它是怎么来的讲透（常数变易法），再把记忆要点、易错点、以及「把 x 看成 y 的函数」这种变形一次说清。
P065伯努利方程：多一个 y 的幂，换元后就变回一阶线性
伯努利方程只比一阶线性方程多一个 yn（n≠0,1）。多出来的这个幂让方程不再是线性的，但也只多了一件事要做：两边同除 yn，再把 y1−n 整体打包成一个新变量 z。换完之后，它就是一个标准的 z'+P1(x)z=Q1(x)——下一页的方法照搬，最后别忘了把 z 换回 y。
P066可降阶的高阶微分方程：缺什么，就换什么
高阶方程一般很难，但有一批「残缺」的高阶方程可以从容降阶。判断的依据只有一条：方程里缺了谁——右边只有 x，就两边直接积分；缺 y、只剩 y(n) 与 y(n−1)，就令 u=y(n−1)；缺 x、右边出现 y 与 y'，就令 p=y' 并把 p 看成 y 的函数。降成一阶之后，前面三节的工具全部照用。
P067二阶常系数齐次线性微分方程：特征方程与三种根
这一族方程的全部秘密可以用一句话说完：拿 y=erx 去试。因为 erx 求导后形式不变、又永远不等于零，代进去之后剩下的只能是一个关于 r 的二次方程——特征方程。特征方程的三个根的情形，对应三种通解；本页把「为什么这样设」「为什么重根要多乘一个 x」「共轭复根为什么会冒出 cos 与 sin」都讲清楚。
P068二阶常系数齐次线性微分方程（做题）
上一页把「为什么」讲完了，这一页只干「怎么做」：认形状 → 写特征方程 → 解根 → 对号入座抄通解。三种根对应三行公式，把它们做成一张照着抄的卡片；再配上两条写卷面的规矩（根从小到大、复根把 α 与 β 单独写一行），这一类题就再没有失手的余地。
P069常系数非齐次线性微分方程（观察法）
右边不再是 0，而是多了一个 f(x)。好消息是通解的结构已经定了：非齐次的通解 = 齐次的通解 + 一个特解。齐次那一半上一页已经解决，剩下的只有一件事——想办法凑出一个特解。本节课教的凑法叫「观察法」，说白了就是朝最简单的地方想。

第 8 章 向量代数与空间解析几何5 / 5

P070向量·线性运算·空间直角坐标系·向量模
第 8 章一开场就先把话说清楚：这不是高中立体几何，而是「用代数办法解题」的向量代数。所以本页只建立两样东西——向量的几何直觉（有向线段、加减法、数乘）和把向量翻译成坐标的机制（空间直角坐标系、⃗i⃗j⃗k、坐标分解式）。翻译一旦完成，后面所有的向量题都变成三项坐标的算术，图只是为了帮你想明白。
P071方向角·方向余弦·数量积·向量积
这一页装着「向量的两把乘法」。第一把是数量积（点乘）：⃗a⋅⃗b=|⃗a||⃗b|cosθ，算出来是一个数，它管「垂直」；第二把是向量积（叉乘）：⃗a×⃗b 算出来是一个向量，大小是平行四边形的面积、方向靠右手法则，它管「平行」和「面积」。再加上一组描述方向的数据——方向角与方向余弦，以及那条 cos2α+cos2β+cos2γ=1 的恒等式。
P072曲面方程·平面方程·直线方程
空间解析几何真正开始做题，是从这一讲起的。整讲只有两个核心角色：平面的法向量 ⃗n=(A,B,C) 和直线的方向向量 ⃗s=(m,n,p)。看懂「法向量垂直于平面上的每一个向量」「方向向量平行于直线」这两句话，点法式、点向式、两平面夹角、直线与平面夹角就全串成了一条线：平面管垂直、直线管平行。
P073习题讲解（向量代数与空间解析几何）
这一讲是第 8 章的「题库」。题目看上去五花八门，其实只有六种题型；而六种题型里，绝大多数只做同一个动作——把题目里的几何条件翻译成向量，再用一次叉乘或一次点乘把它算出来。所以这一页不按时间顺序写，而是按题型归组：每类先给「识别标志」，再给「固定套路」，最后点出这一类的招牌陷阱。
P074曲面基本问题·旋转曲面·柱面
这一讲把「怎么用一个方程表达一张曲面」讲成了两套可以动手的套路。第一套是旋转曲面：一条平面曲线绕着某根轴转一圈，就长成一张曲面，它的方程有一条口诀——绕谁转、谁不变，另一个变量的平方换成「另外两个变量的平方和」。第二套是柱面：方程里缺哪个变量，它就是沿着哪根轴的柱面。两句话，管掉本章一大半的图形题。

第 9 章 多元函数微分法及其应用12 / 12

P075平面点集 · 多元函数 · 二重极限 · 连续
一元函数往一个点逼近，只有左边、右边两条路；到了二元，逼近一个点的方式有无穷多种——直线的、折线的、抛物线的都算。二重极限要求所有走法都通到同一个数。于是「证明极限不存在」变得异常便宜：随便挑两条路，走出两个不同的数就够了。
P076偏导数：把另一个变量钉死，就退回一元
偏导数没有新东西。求 ∂z∂x 就是把 y 当成一个常数，然后对 x 用一元函数的求导法则；求 ∂z∂y 就把 x 当常数。真正要花力气理解的是两件事：它的几何意义（拿刀把曲面切开，看截面曲线的切线斜率），以及它带来的第一个反直觉结论——两个偏导数都存在，函数仍可能不连续。
P077高阶偏导数：再求一次，以及那个「连续」的条件
二阶偏导数就是把一阶偏导数再求一次，算起来没有新东西。这一节真正值钱的只有一条定理：二阶混合偏导数在连续的条件下与求导次序无关。考试就考「连续」这两个字——条件一旦去掉，相等的结论立刻垮掉。
P078全微分：可微、偏导存在、连续，谁推谁
全微分的定义只有一句话：函数的全增量能被一个「线性主部」加上一个高阶无穷小表示。真正的价值不在定义，而在它牵出的一张关系网——偏导连续 ⇒ 可微 ⇒ 偏导存在，且可微 ⇒ 连续；反过来，每一条箭头都不成立。这一页最重要的就是那张关系图。
P079多元复合函数求导：几条路相加，每条路上相乘
一元复合函数只有一条链，多元复合函数的变量关系却会长成一棵树。整节内容可以压成一句话：从 z 走到 x 有几条路，右边就有几项；每一条路上把各个偏导（或导数）乘起来。真正让人发晕的不是公式，而是哪一步写 ∂、哪一步写 d。这一页把五种情形一次讲透，重点攻破 z=F(u,x,y) 里 ∂z∂x 与 ∂F∂x 的区别。
P080全微分形式不变性：不管 u、v 是什么身份
同一个函数 z=f(u,v)，u,v 既可能是自变量，也可能只是中间变量。形式不变性说的是：这两种身份下，dz=∂z∂udu+∂z∂vdv 这个式子长得一模一样。它的价值不在式子本身，而在于——求全微分时你可以先不管变量关系，把每一步都当自变量拆，最后再逐层拆到底。
P081隐函数求导：直接法、公式法，与同一个 F 的两副面孔
由一个方程确定的隐函数，导数可以用一条公式直接算出来：dydx=−FxFy，三元情形是 ∂z∂x=−FxFz。公式好记（一个负号 + 交叉对应），但这一节真正的难点是理解它怎么来的：直接法里 y 是 x 的函数，公式法里 F 是 x,y 的两个独立变量——同一个 F，两副面孔。
P082一元向量值函数及其导数：把空间曲线写成向量
空间曲线本来是用三个参数方程 x=x(t)、y=y(t)、z=z(t) 描述的。把这三个数捆成一个向量，就得到一元向量值函数 ⃗r(t)——「一元」指自变量只有一个 t，而函数值是向量。它的极限、连续、导数全部按分量各自进行；导数 ⃗r'(t) 就是曲线在该点的切向量，方向指向 t 增大的一侧。
P083空间曲线的切线和法平面：切向量是唯一的钥匙
空间曲线在一点处的切线方向，就是曲线在该点的切向量 ⃗r'(t0)；过这一点并且与切线垂直的平面叫法平面，它的法向量取的还是同一个切向量。于是整节真正需要算的只有一件事：先把切向量求出来，剩下的全是往点向式、点法式里代数。
P084曲面的切平面和法线：法向量从哪里来
曲面上过一点的切线有无数条，所以这一节求的不是切线而是切平面；与切平面垂直、并且过该点的那条直线叫法线。整节的结论只有一行：曲面 F(x,y,z)=0 在 P0 处的法向量就是 ⃗n=(Fx,Fy,Fz)|P0。它不是背出来的，是用「曲线在曲面上」这条约束推出来的。
P085方向导数与梯度：把「变化率」对准任意一个方向
偏导数只在「沿 x」「沿 y」两个方向上说话，而实际问题不会挑方向。把这两个方向放开成任意方向，得到的就是方向导数 ∂f∂l——它是一个数；把它的计算公式 fxcosα+fycosβ 看成两个向量的数量积，另一个向量就是梯度 gradf=(fx,fy)——它是一个向量。全部结论压缩成一句：方向导数 = 梯度 · 方向单位向量，所以沿梯度方向爬升最快，最大变化率就是 |gradf|。
P086多元函数的极值：驻点、判别式 AC − B² 与它的失效区
一元极值要做两件事——用 f'(x0)=0 找点，用 f''(x0) 的符号定性。二元极值把这两件事各做一遍：必要条件是两个一阶偏导同时为零（这样的点叫驻点），充分条件是三个二阶偏导拼出来的判别式 AC−B2。它只给三种结局：&gt;0 必有极值（A&gt;0 极小、A&lt;0 极大）、&lt;0 一定没有极值、=0 时判别法当场哑火，得另想办法。最后一句话最容易被跳过：驻点不一定是极值点，而极值点也不一定有偏导数。

第 10 章 重积分与曲线曲面积分12 / 12

P087二重积分：把「曲顶柱体的体积」写成一次四步的极限
这一页只做一件事——给「曲顶柱体的体积」和「不均匀薄片的质量」找一个共同的算法：分割、近似、求和、取极限。两步例子形式完全不同，却逼出了同一个式子，于是把它抽象成定义 ∬Dfdσ=limλ→0∑f(ξi,ηi)Δσi。里面的每个符号都在防错，尤其是 λ：它取的是所有小块直径的最大者，趋于零的是它，不是块数。算这种积分靠的不是定义，而是它的七条性质——而那些性质，几乎是把定积分那一套原样搬过来的。
P088二重积分·直角坐标：把区域写成不等式，把积分写成两次定积分
这一页真正的功夫不在积分，而在画图定限——老师说得很直白：把二维区域用 x、y 的取值范围描述出来，上下限就确定了，题也就做完了。区域分两类：X 型（笔从左划到右，看上下边界）与 Y 型（笔从下划到上，看左右边界），二重积分随之变成两个「先一后二」的累次积分。这里最有价值的一项技能是交换积分次序：有些题原序根本积不出来，换一种切法立刻通透；而能不能少分段、要不要换序，看的是边界是否垂直于某个轴与被积函数积不积得出来。
P089二重积分·极坐标：那个多出来的 r 是怎么来的
直角坐标切区域用的是横线加竖线，极坐标切区域用的是一族射线加一族同心圆——切法一换，面积元素就变了：dσ=rdrdθ，绝不能顺手写成 drdθ。多出来的那个 r 不是规定，而是「弧长 = 半径 × 角度」逼出来的：沿圆周方向的真实长度是 rΔθ 而不是 Δθ。什么时候该用极坐标？看两个信号——区域是圆（含圆环、扇形、偏心圆），或者被积函数里出现 x2+y2。真正难的也不是积分，而是把 θ 和 r 的范围写对，尤其是偏心圆的角度范围。
P090二重积分的换元法：多出来的那个因子，是雅可比行列式
上一讲的极坐标不是天上掉下来的技巧，它只是换元法的一个特例：∬Dfdxdy=∬D'f|J|dudv，其中 |J| 是雅可比行列式的绝对值。极坐标里那个「平白无故多出来的 r」，本质就是 |J|=r。换元会同时改两件事——区域从 D 变成 D'，面积元素前面乘上 |J|。
P091三重积分：把重积分一次打通，再选坐标系
三重积分 ∭ΩfdV 就是对空间立体里每一个点求它的函数值再累加——和定积分、二重积分是同一句话，只是积分区域从线段、平面区域升到了立体。算的时候只有两个动作：把 Ω 的上下限写出来，以及挑一个合适的坐标系。直角坐标有投影法（先一后二）与截面法（先二后一）；柱面坐标多一个 r，球面坐标多一个 ρ2sinφ——这两个因子和 [[90]] 里的 |J| 是同一件事。
P092第一、二类曲线积分：一个有方向，一个没方向
第一类曲线积分 ∫Lf(x,y)ds 是对弧长积分——ds 是一小段弧长，永远为正，所以它不分方向，上下限必须从小到大。第二类曲线积分 ∫LPdx+Qdy 是对坐标积分——dx 可正可负，所以它严格讲究方向，换了方向就变号，上下限谁大谁小由方向决定。这一页最容易混的，就是这两个「ds」与「dx, dy」。
P093两类曲线积分之间的联系：那条弧上的两条投影
上一页的两类曲线积分各管一摊，这一页把它们焊起来：dx=cosαds、dy=cosβds——第二类积分由此可以全部改写成对弧长的积分。cosα、cosβ 不是随便的角，它们正是这一点的有向切向量的方向余弦。这一页是三页里最短的，却直接决定了 [[94]] 格林公式能不能用对。
P094格林公式与路径无关：一条边界，两边在讲同一件事
格林公式把区域上的二重积分和边界上的曲线积分焊成了一件事。而「积分与路径无关」的四个等价说法，只有在单连通区域里才互相等价——挖掉一个点，等价关系立刻断裂。这一讲的重点不在公式，而在条件与条件之间的依赖关系。
P095对面积的曲面积分：一投、二代、三换
第一类曲面积分 ∬Σf(x,y,z)dS 与我们刚学完的对弧长曲线积分是同一个套路换了一个舞台：dS 是曲面上的一小块面积，恒为正，所以它与曲面的侧无关。计算只做三件事——投到坐标面上、把变量代成投影面上那两个变量、把面积微元换成 1+zx2+zy2dxdy。真正需要想清楚的只有一句：为什么要多乘那个根号。
P096对坐标的曲面积分：符号是怎么长出来的
第一类曲面积分只问「曲面有多大」，第二类曲面积分多问了一件事——这块面朝哪一边。ΔSxy 记的不是几何面积，而是带着侧的、有正负的投影面积：上侧为正、下侧为负、与坐标轴平行时为零。整页所有的符号规则、每一次变号，都从这一条里长出来。而计算方法的反常识之处在于：对面积的曲面积分要乘一个根号，对坐标的曲面积分反而不乘。
P097两种曲面积分之间的联系：那张曲面上的三个方向余弦
上一页的两种曲面积分各管一摊，这一页把它们焊起来：∬ΣPdydz+Qdzdx+Rdxdy=∬Σ(Pcosα+Qcosβ+Rcosγ)dS。cosα,cosβ,cosγ 是有向曲面法向量的方向余弦——它不是切向量，而是法向量。这一页和 [[93]] 是同一个手法从曲线搬到曲面上。
P098高斯公式与斯托克斯公式：三维里的格林，以及它的曲面积分版
格林公式是二维的「区域=边界」，高斯公式是它的升维：把闭曲面上的第二类曲面积分变成三重积分。斯托克斯公式则是「空间闭曲线积分 ↔ 曲面积分」。三者加上牛顿–莱布尼茨，是同一个模式在不同维度上的重演。

P100常数项级数的敛散性判断：拿到一个级数，先试哪一步

P101幂级数（一）：收敛半径与收敛域
幂级数把常数项级数升级成函数项级数——通项里多了 x。阿贝尔定理告诉我们：它的收敛域一定以原点为中心对称成一个区间，内部绝对收敛、端点必须单独判。求收敛半径用比值法 R=lim|an+1an|；但缺项时不能直接套公式，要直接比值判别或换元。
P102幂级数（二）：性质与和函数
幂级数不只是求收敛域——它的和函数 S(x) 才是宝藏。四条分析性质里真正干活的是逐项求导与逐项积分：先求和再求导，等于逐项求导再求和。求和函数的套路就三步：消掉碍事的 n、凑成等比级数 11−x、再还原。
P103函数的幂级数展开
把函数写成幂级数，本质是用多项式顶替难算的函数（如 e0.1 计算器算不出，但 1+0.1+0.12/2 秒出）。考试只考间接展开法：背熟几张必背展开式，再用代换、求导、积分拼出来。注意：泰勒公式带余项，泰勒级数要求余项趋于 0。

直线这一节也只有一个主角——方向向量 ⃗s=(m,n,p)。整页题型都能压成一句话：找一个点、找一个方向向量，代进点向式。方向向量有三条来路：题目直接给、两个平面法向量叉乘、从「平行 / 垂直」这句话里读出来。配上四张夹角公式、两张位置关系表，考试里直线部分的题基本就都在射程内了。新授课见 [[72]]，姊妹页（平面）见 [[120]]。
P122【黑板】曲面
曲面这一节的内容比直线少，但它的两句口诀是整章的图形底座：旋转曲面——绕谁转，谁不变，另一个换成「正负根号（另外两个变量的平方和）」；柱面——方程里缺哪个变量，就是沿着哪根轴的柱面。最后再记一张「九个名字」的对照表，和一套「看缺谁、看次数、看符号」的识别技巧，本页的题就做完了。新授课见 [[74]]，后续 [[123]] 的空间曲线正是「两个曲面相交」。
P123【黑板】空间曲线
空间曲线只有两套东西：一般方程（两个曲面相交）和参数方程（x、y、z 都由一个参数控制）。这一节唯一需要动手练的是空间曲线在坐标面上的投影：先从方程组里消掉投影方向上那个变量得到投影柱面，再把它和投影面联立。老师原话是这一段在三重积分、曲面积分里「挺重要」。新授课见 [[74]]，用到的曲面知识见 [[122]]。
P124【黑板】平面点集
这一节是多发词汇、少见计算的一段：老师自己都说它「讲了吧也没啥用，不讲吧你又嫌我不讲」。但后面谈二元函数的定义域、极限、连续时，一张嘴就要用这些词。所以本页只做两件事：把名字和定义对上号，再用「一句话定义 + 一个正例 + 一个反例」把每个词钉死。新授课见 [[75]]。
P125【黑板】二元函数的定义 · 极限 · 连续
这一页是第九章第一块的复习黑板：把 [[75]] 里那三段骨架重新拎出来。二元函数的定义域必须写成点集，不能只丢一句不等式；二重极限唯一的新东西是「趋近方式任意」——正因为任意，证明它不存在只要找两条路走出两个数，而证明它存在却要管住所有路。
P126【黑板】偏导数
偏导数一点新工具都没有：对 x 求偏导就是把 y 当一个常数，用一元法则照常求导；对 y 求偏导就把 x 当常数。这一页要钉住的是三件事——几何意义（拿刀把曲面切开，看截线的切线斜率）、先代入的适用边界（求对 x 的偏导可以先代 y=y0，但绝不能先代 x=x0），以及那个反直觉结论：两个偏导都存在，函数仍可能不连续。
P127【黑板】高阶偏导数
二阶偏导数就是把一阶偏导再求一次，计算上没有新东西。这一页真正值钱的只有一条定理：二阶混合偏导数在连续的条件下与求导次序无关。考试就考「连续」这两个字——条件一旦换成「存在」，相等的结论立刻垮掉。
P128【黑板】全微分
全微分的定义只有一句话：全增量能被一个「线性主部」加一个高阶无穷小表示。真正的价值不在定义，而在它牵出的那张关系网——偏导连续 ⇒ 可微 ⇒ 偏导存在，且可微 ⇒ 连续；反过来，每一条箭头都不成立。这一页最重要的就是那张关系图和它下面的三个反例。
P129【黑板】多元复合函数求导（一）：几条路相加，每条路上相乘
老师开场第一句话就是「大家会很晕，乱七八糟，既有求导也有求偏导」。整节内容可以压成一句口诀：从 z 走到终点变量有几条路，右边就写几项；每一条路上，把经过的每条边上的偏导（或导数）乘起来。真正要练的不是公式本身，而是数分支——一个点朝外伸出两条以上的线就写 ∂，只有一条线出去就写 d。
P130【黑板】多元复合函数求导（二）：抽象函数与二阶偏导
上一节把链式法则的各种情形摆了一遍，这一节往里走一层。核心只有两件事：抽象函数 f(u,v) 的偏导写不出表达式，就给它一个名字 f1'、f2'；而一旦要对它再求一次偏导，就必须记住 f1' 仍然与 u、v 都有关——老师举 f=u2v3 验证 fu'=2uv3，v 还在里面。漏掉 f12'' 是这一类题最常见的失分点。
P131【补充】克莱姆法则：为什么高数课要插一节线性代数
这 8 分钟是老师为下一节「方程组确定的隐函数求导」专门补的工具课。克莱姆法则把 n 元线性方程组的解写成分式：系数行列式 D≠0 时 xi=DiD，其中 Di 是把 D 的第 i 列换成右端常数项。要记住的只有三点：分母是系数行列式、分子是替换第 i 列、前提是 D≠0。
P132【黑板】隐函数求导：公式法、直接法与同一个 F 的两副面孔
由一个方程确定的隐函数，导数可以用一条公式直接算：dydx=−FxFy，三元情形是 ∂z∂x=−FxFz、∂z∂y=−FyFz。公式好记（一个负号 + 交叉对应），但这一节真正的难点是理解它怎么来的：直接法里 y 是 x 的函数，公式法里 F 是 x,y 的两个独立变量——同一个 F，两副面孔。
P133【黑板】多元函数微分学的几何应用：曲线与曲面的两套向量
这一页把 [[83]] 与 [[84]] 压成一张速查表。曲线的关键量是切向量——逐分量求导就能拿到；曲面的关键量是法向量——隐式 F=0 时取 (Fx,Fy,Fz)，显式 z=f(x,y) 时取 (fx,fy,−1)。这个向量只有两个出口：当方向向量用（点向式，写切线 / 法线），或者当法向量用（点法式，写法平面 / 切平面）。输入形式有四种，名字有四个，真正要算的东西永远只有那一个向量。
P134【黑板】方向导数与梯度：一个数、一个向量、两条结论
偏导数只回答「沿 x」「沿 y」两个方向的问题，方向导数把方向放开成任意。方向导数是数，可正可负可零；梯度是向量，是两个偏导拼成的平面箭头。两者的桥梁是一个点乘：方向导数 = 梯度 · 方向单位向量 = |gradf|cosθ。由此立刻得到两条核心结论：① 方向导数的最大值是 |gradf|，且就在梯度方向上取到；② 梯度垂直于等值线（等值面），并指向函数值增大的那一侧。
P135【黑板】极值：驻点专项训练、判别式的书写纪律与拉格朗日乘数法
黑板课把「极值」压成三块硬功夫。第一块是求驻点——两个方程必须同时成立，驻点是两组解的「全部合法搭配」，不能凭式子像不像硬配。第二块是走标准格式：先写出三个二阶偏导的表达式，再逐个驻点代入、列表、落进判别式的三个分支，不许一上来就写 A、B、C。第三块是条件极值：约束能解出 y=g(x) 就代入降成一元；解不出来就上拉格朗日乘数法——而它只回答「是不是极值」，判不出极大还是极小。
P136【黑板】二重积分的定义和性质：符号怎么读、性质怎么推
黑板课对这一段的第一句交代就很老实：讲定义和性质「仅仅是一个前奏」，你现在一个题都还不会解——真正解二重积分要等到直角坐标和极坐标。所以这一页不堆套路，只做两件事：把符号读清楚（两个积分号、区域 D、被积函数、面积微元 dσ，以及为什么直角坐标下它就写成 dxdy），以及把七条性质各自推一遍——尤其是保号性里那句「因为 Δσi 是正的，所以不等号不变」和估值性质里「m、M 是常数，可以提到求和号外面」。二重积分可积的条件比连续低得多，只要「有界」就够了。
P137【黑板】二重积分·直角坐标：选型、换序与题型手册
直角坐标是二重积分真正用来计算的方法，老师说得很重：「前面讲的定义跟性质你一个字都没听懂都不要紧，但这个地方你必须听懂，要不然你二重积分就真的一个字都不会了。」整件事只有两条动作线：把区域画出来、写成不等式（定限），以及落成两次定积分再算。据此分出四种题型：基本款、要分段、必须换序、次序选得好省一半力气。三个判据决定你选 X 型还是 Y 型——尽量只写一个积分、边界垂直于哪个轴、被积函数积不积得出来；而「先积后头那个」与「代入时替换的是刚积完的那个变量」是绝不能错的两条纪律。
P138【黑板】二重积分{极坐标}
极坐标二重积分的题，九成的错都发生在动笔之前——θ 从哪转到哪、r 的上限写成什么，这两步定不下来，后面的积分再熟也没用。这一页是黑板精讲，重点不是那条公式（公式当然还是 dσ=rdrdθ），而是一套「转角度、画射线」的区域扫描动作：先把常见区域——整圆、扇形、圆环、偏心圆、被直线截出的角形——的极坐标表示练成条件反射，再谈积分。偏心圆与直线题是本节的重头：那里的 r 上限几乎都不是常数。
P139【黑板】三重积分
三重积分只有两个动作：把 Ω 的上下限写出来，和挑一种切法。这一页是黑板精讲，正课的定义一个字不重复（老师说「看完定义你会发现跟二重积分差不太多，对做题实打实没有作用」），只讲三件事：投影法该怎么「照」、截面法该怎么「切」、球面坐标该怎么「扫」。最需要练成条件反射的是——看到立体先判断截面会不会随 z 变：不变，截面法最舒服；会变，就得把截面半径老老实实写成 z 的函数（z 而不是 z）。
P140【黑板】多重积分的应用
这一节没有新思想。老师说「没有什么特别难的技巧，就是你照着公式朝里搬就行」——三个应用（曲面面积、质心、转动惯量）用的是同一套动作：把区域切成小块，让「小块 × 某个与位置有关的量」跟着累加。真正需要刹一脚的只有两处：曲面面积里那个 1+zx2+zy2 是怎么冒出来的（法向量与 z 轴的夹角 γ）；以及球面面积那道例题——被积函数在边界上无界，不能把 r=a 直接代进去。
P141【黑板】第一型曲线积分：一代二换三定限
第一型曲线积分（对弧长）的全部动作只有三步：把曲线参数化、把 x、y 代进去、把 ds 换成 x'2+y'2dt。它不讲方向，所以换元以后定限永远是「小在下、大在上」。黑板课真正要练的只有两件事：什么时候可以把曲线方程直接朝里带，以及一条曲线分成几段时怎么各段算完再相加。
P142【黑板】第二型曲线积分：方向、代入、三类题
第二型曲线积分（对坐标）比第一型多一件东西——方向，也因此少了一件东西——那个根号。所以它的算法反而更短：参数化 → 代入并求微分 → 定限由「起点对谁、终点对谁」决定。定限可以大在下、小在上，这是它与第一型最大的分野。黑板课上的题目只有三类：只对 dx 积、只对 dy 积、两样都有。
P143【黑板】格林公式及应用：三查、挖洞、凑全微分
格林公式把闭曲线上的第二型曲线积分与区域上的二重积分焊在一起：∮LPdx+Qdy=∬D(∂Q∂x−∂P∂y)dσ，其中 L 取正向、P、Q 在 D 上有一阶连续偏导。黑板课上真正决定成败的不是公式，而是套公式之前那三查：曲线闭吗？方向正吗？区域内有没有让偏导失效的奇点？三查里任一条不过关，就要请出补线、变号和挖洞。
P144【黑板】常数项级数的概念和性质：把「无穷相加」拆成部分和数列
这是黑板习题课：不在黑板上抄定义，而是一块一块地「上手做」。全课的骨架只有一句话——级数敛散 = 部分和数列 Sn 有没有有限极限。两块基准（等比、调和）、四类性质（线性、括号、有限项、必要条件）外加一串反例，就是后面所有判别法的地基。
P145【黑板】正项级数的敛散性：四件武器，和一张「谁猛谁不猛」的阶梯
黑板课的第二站，正项级数（un≥0）的判敛工具箱。比较判别法听着好用，实际上「放还是缩、跟谁比」两个难题让我们做题时最后一个才考虑它；真正上场的是比较判别法的极限形式（配「抓大头」与「等价无穷小替换」两把钥匙）、比值和根值。而全课的灵魂是一句话：级数敛散取决于通项趋于 0 的速度——谁猛谁不猛，谁在分母上谁就赢。
P146【黑板】交错级数：莱布尼茨的两个前提，一个都不能少
交错级数只有一件武器——莱布尼茨判别法，而它要求两件事同时成立：去掉符号后的 un 单调递减，且 un→0。少任何一条，结论就作废。这一页还要把绝对收敛与条件收敛分清楚：先取绝对值走正项级数的老路，绝对值收敛就叫绝对收敛（必收敛）；绝对值发散、原级数却收敛，才叫条件收敛——(−1)n−11n 就是标准样本。
P147【黑板】幂级数求收敛半径和收敛域：半径一步、端点三关
求收敛域只有两步：先定半径，再判端点。定半径时，标准型只看系数 ρ=lim|an+1an|、R=1ρ；缺项（只含 x2n 或 x2n−1）绝对不能套这个公式——系数里夹着零，比值会错位，只能带着 x 一起做比值判别。半径只给出开区间 (−R,R)，两个端点收不收敛必须代回去单独判，所以「收敛区间」永远开，「收敛域」是四选一。
P148【黑板】幂级数求和函数：你会求和的和函数只有一个
到现在为止，你真正会求和的级数只有等比级数 ∑n=0∞xn=11−x。所以求和函数的全部工作就是把题目扭成等比：n 在分母就先求导再积分，n 在分子就先积分再求导（或者一步认出它是等比级数的导数）。四步走完还要回头补两件事：端点重新验、结果分母带 x 就单独算 S(0)。
P149【黑板】函数的幂级数展开：间接展开法三步走
展开是求和的逆运算：给定 f(x)，把它写成幂级数。考试只考间接展开法——背熟八张常用展开式，再用代换 / 逐项求导 / 逐项积分拼装。三件事决定成败：把 (x−x0) 当整体焊死、整体代换后收敛区间跟着变、多式合用取交集。收敛区间是算分的，漏写必扣。
