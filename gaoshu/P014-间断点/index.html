P014间断点：连续三要素坏掉哪条，就归哪类

一句话核心

间断点就是连续三要素里至少坏了一条的地方。按「左右极限是否存在」一刀切开：左右极限都存在的叫第一类（可去、跳跃），至少有一个不存在的叫第二类（无穷、震荡）。记住六字口诀：一可跳，二无荡。

间断就是「三要素坏了一条」

00:00上一页把连续拆成三要素：在 x0 有定义、极限存在、极限等于函数值。这三样只要有一样不满足，函数在 x0 就不连续——不连续，就叫在 x0 处间断，x0 叫做一个间断点。所以判断间断点，本质上就是拿着三要素去逐条检查；而间断点的分类，也正是按「到底是哪条坏了、怎么坏的」来分的。

定义 · 间断点

设函数 f(x) 在点 x0 的某去心邻域内有定义。如果 f(x) 在 x0 处不连续，就称 x0 为 f(x) 的间断点（也叫不连续点）。

00:00为什么间断点的前提是「去心邻域」，连续却是「邻域」

连续的定义里出现了 f(x0)，所以 x0 自己必须有定义，前提写成「邻域」（含芯）。而判断间断点靠的是两个单侧极限 limx→x0±f(x)，它们只看 x≠x0 那部分函数值，压根用不到 f(x0)，于是前提就放宽成「去心邻域」（不含芯）。

这一步放宽是必需的：y=1x 在 x=0、y=sin1x 在 x=0 都是根本没定义的点，而它们恰恰是最典型的间断点。若坚持「邻域有定义」才算，这些例子反而被挡在门外了。所以定义先把中心点搁在一边，只要求它周围有定义；x0 自己有没有定义，留给后面逐条检查。

老师一口气用几个例子把三种「坏法」都演示了一遍：

坏第一条：没定义
比如 y=1x 在 x=0，分母为零，根本没定义。
坏第二条：极限不存在
同样是 x=0，1x 的极限是无穷大（不存在）；而 y=sin1x 则来回震荡，极限也不存在。
坏第三条：极限 ≠ 函数值
点在曲线上，但「该在的位置」和「实际画的位置」对不上——图上会有一个孤零零挪了窝的点。
03:37视频原话（大意）

有一个函数，在这个点它给的定义是这么大；但朝这个点逼近的时候，函数值的极限是另一个值。它俩相不相等？不相等。那你画图的时候，这个点你是不是得把笔提起来单独画一下？

这正是「坏第三条」的画面：左右逼近给出的极限是一个高度，而函数在这一点被硬生生定义成了另一个高度，于是必须提笔补一个点——断开了。

四个代表函数，四种间断点

05:30老师把四类典型间断点各配了一个函数，逐个画了草图。先各自看一眼，再在后面的对比表里归总。

无穷间断点

05:30y=tanx 在 x=π2 处，图像「唰」地一下冲到正无穷、再从负无穷回来，中间断开；1x 在 x=0 也一样，两侧都趋于无穷。这类叫无穷间断点。注意：趋于无穷属于「极限不存在」的一种。

05:30两侧跑向无穷，符号可以相反

1x 在 x=0：左极限 −∞、右极限 +∞；tanx 在 x=π2 恰好反过来，左边冲到 +∞、右边掉到 −∞。符号相反不影响归类——只要有一侧的极限是无穷（也就是不存在），就归第二类·无穷间断点。几何上，曲线在这里是骑着一条竖直渐近线冲出去的，图像必然断开。

震荡间断点

06:37y=sin1x 在 x=0：函数在那里没定义；而当 x→0 时 1x→∞，sin 面对一个冲向无穷的自变量，只能一直上下波动。更糟的是 x 越靠近 0，1x 跑得越快，函数值就摆得越密集、越猛烈——上上下下，始终攒不出一个安定的值。这类叫震荡间断点。

07:23它凭什么不算「无穷间断点」

看图像就清楚：sin1x 的函数值被死死夹在 −1 与 1 之间（正弦的振幅恒为 1），它再怎么疯也「冲不上天」。既然不是趋于无穷，它就不是无穷间断点；又因为摆动不收敛，左、右极限都不存在，于是落到第二类的另一支——震荡。一句话区分：无穷是「没有界地冲出去」，震荡是「有界，但定不下来」。

可去间断点

08:44看 x2−1x−1。在 x=1 分母为零，没定义，所以间断。但极限存在：

limx→1x2−1x−1=limx→1(x+1)=2

极限是 2，只是这一点「没画上去」或「画错了」。如果把 x=1 处的函数值补成 2，这个洞就填上了，函数立刻连续。正因为「这个间断可以去掉」，所以叫可去间断点。

09:48为什么叫「可去」而不是「我去」

老师特意吐槽了这个名字——它说的是「这个间断点可以被去掉」：只要重新定义（或补上）那一个点的函数值，洞就补圆了。它和「我去」毫无关系，纯属译名拗口。判断标准只有一句：左右极限都存在且相等，但函数在此没定义、或定义值不等于这个极限。

10:35视频原话（大意）

我问大家一个非常高级的问题，大家一定要仔细回答——y=x2−1x−1 这个函数的图像怎么画？一个二次的图像比上一个一次函数的图像……老师我没学过啊。我其实是在忽悠你，你是不是被我成功忽悠住了？

这个「忽悠」的谜底是：x 不能等于 1，把 x−1 约掉之后式子就是 x+1。所以图像就是那条最熟的直线 y=x+1，只把 x=1 那一点抠掉、画成一个大空心。可去间断点长的正是这个样子：一条完完整整的直线，缺一个点。

12:54结论 · 可去间断点「补一刀」就连续

若 x0 是 f 的可去间断点，即 limx→x0f(x)=A 存在，那么只要重新规定 f(x0)=A（原本没定义的就补上，原本定义错的就改掉），f 就在 x0 处连续。这就是「可去」两个字的全部含义——这个间断点可以被抹掉。四个类型里，只有它具有这个性质。

例13:57设 f(x)=x(x≠1)，而 f(1)=12，判断 x=1 处间断点的类型。

思路：这里函数「有定义」，坏的是第三条

和前面那个 x2−1x−1 不同，这个函数在 x=1 处是有定义的（硬性规定成 12），所以坏的不是第一条。先算极限：

limx→1f(x)=limx→1x=1

左极限、右极限都存在且相等，都是 1；可是 f(1)=12≠1。极限存在、函数也有定义，唯独「极限值等于函数值」这一条塌了。

结论：x=1 是第一类·可去间断点。要让它连续，只需把定义改回来——令 f(1)=1。几何上，直线 y=x 本该经过 (1,1)，这个点却被挪到了 (1,12)，成了「孤零零挪了窝的点」。

别以为「有定义」就万事大吉

一个有定义的点也可以是间断点。三要素里第三条（极限 = 函数值）独立于前两条：有定义、极限也存在，两样都齐了，照样可能因为「对不上」而间断。这类间断点最好认——图像上总有一个离开曲线、单独挂着的实心点。

跳跃间断点

15:08再看分段函数：

f(x)={x−1,x<00,x=0x+1,x>0

在 x=0 处，左极限 limx→0−(x−1)=−1，右极限 limx→0+(x+1)=1，两边极限都存在，但不相等——图像像下台阶一样「蹦」了一下。这类叫跳跃间断点。左右极限不相等，那个「台阶」补不上，所以不可去。

15:46视频原话（大意）

这不蹦了一下嘛，就叫跳跃间断点。

老师随便换一个图，左右两段高度对不上，他也说「这不嘚儿嘚儿跳了一下嘛」——「跳」这个字，说的就是左极限与右极限各站一个高度、中间落差补不上。记住这个画面，就不会再把跳跃和可去搞混：可去是「同一个高度、只缺一个点」，跳跃是「两个高度、怎么补都接不上」。

分类总纲：第一类与第二类

17:33把所有间断点按「左右极限是否存在」一刀切开：

类别判定（看左右极限）包含典型函数
第一类间断点 左极限、右极限都存在 可去间断点（左右极限相等）
跳跃间断点（左右极限不等）		 x2−1x−1、左右跳变的分段函数
第二类间断点 左、右极限至少有一个不存在（含趋于无穷） 无穷间断点
震荡间断点		 1x、tanx、sin1x
关键提醒 · 17:33「无穷」属于极限不存在

很多人下意识觉得「趋于无穷也算个极限」。不对——在严格的极限语言里，趋于无穷是极限不存在的一种。所以「左右极限至少有一个是无穷」仍然归到第二类。只要左右极限「安定不下来」，无论是因为冲上天还是因为乱摆动，都算第二类。

17:33第二类真的只有「无穷」和「震荡」两种吗

老师专门点了一句：教材在这一点上写得并不死。按定义，第二类 = 左、右极限至少有一个不存在，凡是「极限安定不下来」的点都算，无穷与震荡只是最常撞见的两副面孔。所以做题别去背名字，抓住那句判据——先看左右极限是否存在——比什么都牢靠。考试里你真能碰到的第二类，基本就是这两类。

六字口诀 · 19:33一可跳，二无荡

第一类间断点 = 可去 + 跳跃；第二类间断点 = 无穷 + 震荡。背成「一（类）可（去）跳（跃），二（类）无（穷）荡（震荡）」，谁属哪类就再也不会混。

判断间断点的思维导图

20:54见到一个函数问「在某某点是什么间断点」，按下面这条顺序走，不会乱。注意这三步是依次递进的，跳步就会出错：

  1. 算左极限、右极限，看是否都存在。这是总开关：有一侧不存在（含趋于无穷）→ 直接归第二类；两侧都存在 → 第一类，继续往下。
  2. 都存在时，看两者是否相等。相等 → 可去；不相等 → 跳跃。到这一步只定出了第一类的两种，还没收工。
  3. 最后看极限值是否等于函数值。极限存在、函数也有定义，可两者对不上，那依旧是可去间断点（把定义改过来就连续）；只有「有定义 + 极限存在 + 两者相等」三条全占，才判为连续、不是间断点。

把三步连成一句话：先问「存在不存在」，再问「相等不相等」，最后问「等不等于函数值」。顺序一颠倒，最容易把趋于无穷误判成可去。

为什么一定要先分「左右极限是否存在」

因为第一、二类的分界线就钉死在这一步。如果不先分，直接在「可去还是无穷」之间纠结，很容易把趋于无穷误判成可去。先问「存在不存在」，再问「相等不相等」，顺序不能反。

例题：同一个分母零点，类型却不同

23:05视频原话（大意）

我想先问一件事：这个 x−1 跟这个 x−1 能不能直接约掉？我举个例子，f(x)=x2x 和 f(x)=x——老师，x 跟 x 比掉不就是 x 吗，这俩有什么区别？这个 x 可以随便取，那个 x 不能等于零，当然是有区别的呀。

所以约分只在「算极限」时用得上，不能当成「函数没这回事」。分母的零点永远都是候选间断点，一个都不能漏。

例23:05求 f(x)=(x+1)(x−1)(x−2)(x−1) 的间断点，并判断类型。

思路：分母为 0 的点就是候选间断点

分母 (x−2)(x−1)=0 给出两个候选：x=1 与 x=2。注意这里分子也有 (x−1)，绝不能随手约掉就当没这回事——约掉只在 x≠1 时合法，而 x=1 恰恰是正要检查的点。

先看 x=2：分母趋于 0，分子趋于 (2+1)(2−1)=3≠0，所以

limx→2f(x)=∞

再细一点：两侧的符号其实是相反的，x→2− 时趋于 −∞，x→2+ 时趋于 +∞。这不要紧——两侧都是无穷、都不存在，故 x=2 是第二类·无穷间断点。

再看 x=1：此处 x≠1 时可约去 (x−1)，于是

limx→1f(x)=limx→1x+1x−2=2−1=−2

极限存在（等于 −2），只是 x=1 处没定义（原式分母为 0）。补上定义 f(1)=−2 即可连续，故 x=1 是第一类·可去间断点。

这道题最坑的地方

x=1 和 x=2 都是分母为零，却不是同一种间断点。一个可去、一个无穷，差别全在「约去之后极限是否存在」。所以不能用「分母为零 = 无穷间断点」一刀切，必须把每个点单独算极限。

老师点出一个现实：教材讲完间断点分类后，往往没有足够的配套题目；而考试偏偏爱考「判断间断点类型」。所以这类题一定要自己多练——套路固定（看左右极限），但符号容易看花眼。

记忆入口 · 一眼回忆

一句总纲

间断 = 连续三要素（有定义 / 极限存在 / 极限=函数值）至少坏一条；前提是函数在 x0 的某去心邻域有定义。

判类三步（顺序不能反）

  1. 左右极限是否都存在？——总开关，分第一 / 第二类
  2. 都存在时是否相等？——分可去 / 跳跃
  3. 极限是否等于 f(x0)？——决定这一点连不连续

分类（按左右极限）

左右极限都存在 → 第一类 → 相等=可去；不等=跳跃
至少一个不存在 → 第二类 → 冲向无穷=无穷；摆动=震荡

六字口诀

一可跳，二无荡：第一类（可去、跳跃）；第二类（无穷、震荡）。

四个代表

  • 可去：x2−1x−1（x=1，极限 2，补定义即连续）
  • 跳跃：分段函数左右极限不等（−1 与 1）
  • 无穷：1x、tanx（两侧冲向 ±∞）
  • 震荡：sin1x（近 0 猛摆，但振幅有界）

一条独家结论

四类里只有可去间断点能被「抹掉」：令 f(x0)=limx→x0f(x)，它就连续了。其余三类无论怎么改定义都救不回来。

三个坑

  • 趋于无穷 算极限不存在，归第二类
  • 分母为零 ≠ 必为无穷间断点，要逐个算极限（如本页例题的 x=1）
  • 「有定义」不等于连续——极限和函数值对不上，照样是可去间断点
