P057求旋转体的体积：先画半径，再套公式

一句话核心

旋转体的体积公式一共只有四个，而且它们其实是同一句话的四种写法——把立体切成一片片薄片，每一片的横截面是一个圆（或圆环），把截面面积从一头积到另一头。真正让同学翻车的从来不是积分，而是「半径到底是谁」：绕 x 轴转半径是 y，绕 y 轴转半径是 x，每次动笔前都要把它画出来。

01:33第一种理解：圆面积积起来就是体积

设曲线 y=f(x) 在区间 [a,b] 上，把它绕 x 轴旋转一周，得到一个立体。求它的体积。

思路是这样：在 x 处垂直于 x 轴切一刀，刀口是一个圆。这个圆的半径是多少？从 x 轴往上量到曲线，正好是那个高度的函数值，所以

半径=y=f(x),圆的面积=πy2=πf2(x)

把每一个 x 处的圆面积都算出来，再从 a 累加到 b，就是体积：

V=π∫abf2(x)dx

01:33老师说这就是旋转体体积的第一种理解：对横截面面积积分。它还有一个很漂亮的说法——面积是二维的量，积分一次就升成三维的体积，相当于「维数加了一级」。这个说法在后面讲平行截面法时还会再用一次。

02:57第二种理解：切一小片，它差不多是个圆柱

同一个公式，用微元法再走一遍，会看得更清楚每一块是从哪来的。

  1. 切一小片。02:57在 x 处切出一薄片，厚度是 dx。
  2. 把这一片近似看成圆柱体。因为切得非常细，这一片的两个底面几乎一样大，可以当圆柱处理。半径是 y，高是 dx。
  3. 算圆柱的体积。圆柱体积 = 底面积 × 高，底面积是 πy2，所以
    dV=πy2dx
  4. 累加。把 y 换成 f(x)，再从 a 积到 b，就回到上面那个公式。
为什么「很薄的一片」可以当成圆柱

因为它是旋转出来的，所以两个底面都是圆；而这一片又非常薄，所以两个圆的半径几乎相等。两个条件凑在一起，它就是一个圆柱。

「几乎」两个字要较真一下：两侧半径的差别是 dy 量级，乘上底面积之后是高阶小量，累加起来不会影响结果。这正是微元法一贯的逻辑——04:54老师反复强调的那句话就是这个意思：不是「差不多所以对」，而是「误差是高阶的，求和之后自动消失」。

04:54关键的一步：半径是 y 还是 x

公式可以背，半径必须画

老师说，这一部分做题最重要的不是公式，而是这句话：每次做题，先把半径画出来。为什么？因为题目稍微一变，半径就换人。

  • 绕 x 轴转：转轴是 x 轴。立体上任意一点到转轴的距离是竖着量的，所以半径是 y。
  • 绕 y 轴转：转轴是 y 轴。点到转轴的距离是横着量的，所以半径是 x。

一句话：半径是「点到转轴的垂直距离」，转轴是谁，量的方向就垂直于谁。

为什么要反复强调？因为同学最容易犯的错不是积分算错，而是把 y 当成了半径、把 x 当成了积分变量，然后一路算到底。这种错往往要到最后才发现，代价很大。

05:34把四种情形一次集齐

05:34只要边界是「一条曲线」还是「两条曲线」、转轴是 x 轴还是 y 轴，两两组合，一共四种。老师说得很干脆：旋转体的体积公式只有这四个，够用了。

绕谁转边界横截面体积公式
x 轴 y=f(x)，x∈[a,b] 圆，半径 y V=π∫abf2(x)dx
x 轴 夹在 f 与 g 之间 圆环，外 f 内 g V=π∫ab[f2−g2]dx
y 轴 x=φ(y)，y∈[c,d] 圆，半径 x V=π∫cdφ2(y)dy
y 轴 夹在两条曲线之间 圆环，外减内 V=π∫cd[f22−f12]dy

07:40表里第三、四行是绕 y 轴的情形，也是同学出错最多的地方。老师把它拆成三个必须同时记住的点：

  1. 积分变量是 y，上下限是 y 的范围。从 c 积到 d，不是从 a 到 b。老师说得很实在：我们同学从一重积分过来以后，脑子还停留在只对 x 求积分，慢慢才能适应对 y 求积分。
  2. 半径是 x。这一点上面已经讲过理由：轴是竖直的，就横着量。
  3. 题目给的一般是 y=f(x)，得自己反解。他补充说：这个函数它一定不会老老实实地给你出成 x 是 y 的函数。比如给你 y=2x−3，你得先把它改写成 x=y+32 才能用。 因为多了这一步「反解」，绕 y 轴的题目出错率明显更高。凡是看到 x=f(y) 这样的写法出现在题目里，先警觉起来。

12:48例 1：先把公式跑通

例 112:48设 y=x2，x 从 0 到 1，绕 x 轴旋转一周，求所得旋转体的体积。

思路：画横截面，提醒自己半径是 y

13:29老师说他每做一道题都要提醒自己一遍：这个半径我每次一定要给它写出来。这道题的转轴是 x 轴，所以半径是竖直方向的 y，而 y=x2。于是

V=π∫01(x2)2dx=π∫01x4dx=π[x55]01
V=π5
这一步最容易错

把 y=x2 直接代进去写成 π∫01x2dx。公式里要的是 y2，而 y=x2，所以 y2=(x2)2=x4。「先写半径、再平方」，两步都不能省。

要点：这类题的价值不在于积分本身，而在于把「转轴 → 半径 → 平方 → 积分变量」这条链走顺。

14:12例 2：绕 y 轴 + 圆环，多了一道反解

例 214:12设两条直线 y=x3 与 y=3x 围出一块区域，取其中 1≤y≤2 的那一段，绕 y 轴旋转一周，求所得立体的体积。

思路：绕 y 轴，第一步永远是把 x 写成 y 的函数

15:39老师说这道题「你只要把式子写出来差不多就可以了」，可见考点全在列式。三步：

  1. 反解。由 y=x3 得 x=3y；由 y=3x 得 x=y3。
  2. 判断谁是外、谁是内。在 y∈[1,2] 上，3y 比 y3 大得多，所以外半径是 3y，内半径是 y3。横截面是一个圆环。
  3. 写圆环面积再积分。半径是 x，所以要把上面两个表达式平方：
    π(3y)2−π(y3)2=π(9y2−y29)

把它们并起来，9−19=809，于是

V=π∫12809y2dy=80π9[y33]12=80π9⋅8−13
V=56027π≈65.16
这一步最容易错

忘记反解，直接把 y=x3 当成半径写进去。那样被积函数里会同时出现 x 和 y，而积分变量是 y，式子根本积不下去。

半径只平方了一个。外半径 3y 平方得 9y2，内半径 y3 平方得 y29——两个都要平方，别只管外面那个。

16:56例 3：被积函数是 sin2x 怎么办

例 316:56设 y=sinx，x 从 0 到 π，绕 x 轴旋转一周，求所得旋转体的体积。

思路：先把式子列出来，剩下的全是积分技巧

转轴是 x 轴，半径是 y=sinx，所以

V=π∫0πsin2xdx

17:49到这里式子就列完了，接下来只是「能不能积出来」的问题。sin2x 不能直接积，必须先用降幂公式把它变成一次式：

sin2x=1−cos2x2

代进去，π2 提出来：

V=π2∫0π(1−cos2x)dx=π2[x−sin2x2]0π

上限代入得 π−sin2π2=π；下限代入得 0。所以括号里是 π，

V=π2⋅π=π22
这道题教的是「套路之外的套路」

旋转体的题，列式永远是那四张面孔之一；真正分出高下的是被积函数能不能积出来。sin2x、cos2x 一律走降幂公式；sin3x 走「拆一个出来凑微分 + 剩下的用 sin2+cos2=1 换掉」。这两招在这一章会反复出现，值得单独记一笔。

19:02例 4：圆绕 y 轴转出一个「游泳圈」

例 419:02设圆 x2+(y−b)2=a2（b>a>0），把这个圆面绕 y 轴旋转一周，求所得立体的体积。

思路：先看清横截面是圆环，再用平方差

19:46老师坦言这道题的图画起来很痛苦，画出来「这个地方其实就是个游泳圈，或者是个甜甜圈」。图画不好没关系，看懂结构就行：圆心在 (0,b)、半径 a，而 b>a，所以整个圆都落在 y 轴右侧，没有碰到转轴。绕 y 轴转一周，中间就会留下一个洞。

第一步：确认横截面是圆环

19:46垂直于 x 轴切一刀，切出来的是一个圆环：外圈由圆的上半支给出，内圈由下半支给出。这正是「游泳圈」中间那个洞的来源。

第二步：把两条半径分别写出来

20:57由圆方程解出 y：

y−b=±a2−x2⇒y=b±a2−x2

上面那支取「+」，是大半径；下面那支取「−」，是小半径。x 从 −a 走到 a，于是

V=π∫−aa[(b+a2−x2)2−(b−a2−x2)2]dx
第三步：用平方差，别展开

22:20老师说得很明确：咱也别完全平方展开，肯定是麻烦，咱就来个平方差公式。两个半径：相加得 2b，相减得 2a2−x2，所以被减出来的那一坨是

2b⋅2a2−x2=4ba2−x2

常数 4πb 提到外面：

V=4πb∫−aaa2−x2dx
第四步：那个根号千万别换元

23:12这是本页最漂亮的一步。老师说：大家千万不要傻傻地用换元，换元那个东西做的也不太熟，并且特别容易出错。理由很简单——

∫−aaa2−x2dx 就是半圆的面积

y=a2−x2 两边平方，得到 x2+y2=a2，而且 y≥0，所以它是半径为 a 的圆的上半支。从 −a 积到 a，积的正是「上半支曲线与 x 轴之间」的那块面积，也就是半个圆。

∫−aaa2−x2dx=12πa2

一句话：遇到 a2−x2 在 [−a,a] 上积分，先想圆的面积，别想换元。老师说这道题经常会考，所以这个「半圆」的识别必须练成条件反射。

把它代回去：

V=4πb⋅12πa2=2π2a2b

要点：这道题把两件技巧合在一起——平方差公式（避免展开六项）和半圆面积（避免换元）。x 的积分区间 [−a,a] 关于原点对称这件事在别的方法里是「偶函数取两倍」，在这里则直接变成了「半个圆」。

25:10例 5：参数方程——别忘了换上下限

例 525:10设摆线 x=a(t−sint)，y=a(1−cost)，t 从 0 到 2π，绕 x 轴旋转一周，求所得旋转体的体积。

思路：先按老套路列式，列不下去时再换元

摆线的形状，老师给了一个很好记的画面：像一个圆轮在地上滚，轮子边缘上的一个点画出来的轨迹，他让同学回去自己查一查。图形本身不复杂，麻烦的是方程——x 和 y 都是 t 的函数，谁也不是谁的显式函数。

第一步：照旧列式

25:52绕 x 轴，半径是 y。x 的范围要看清楚：t=0 时 x=a(0−0)=0；t=2π 时 x=a(2π−0)=2πa。所以

V=π∫02πay2dx
第二步：x、y 全换成 t 的表达式

到这里就「没法再按照以前的那种模式求了」，因为被积函数和微分变量互不相干。出路是做变量替换：y=a(1−cost)，而 dx=x'(t)dt=a(1−cost)dt。

26:51这里出现了本页最重要的一个坑。老师说：

上下限要跟着换

换了变量却还写着 ∫02πa。老师原话说得很直接：你以为还是原来这个上下限，其实不是，上下限现在 t 是从 0 到 2π 的。

规则：积分变量从 x 换成 t，积分限就必须跟着从「x 的范围」换成「t 的范围」。原来 x 从 0 到 2πa，对应 t 从 0 到 2π，所以积分限写成 ∫02π。

第三步：算出来

把两个 (1−cost) 乘起来，一共三个：

V=π∫02πa2(1−cost)2⋅a(1−cost)dt=πa3∫02π(1−cost)3dt

27:47接下来是纯技术活：把 (1−cost)3 展开成 1−3cost+3cos2t−cos3t，然后逐项积。好在有两条省事规律：

  • ∫02π1dt=2π；
  • ∫02πcostdt=0，∫02πcos3tdt=0——整周期上积分为零，两项直接划掉；
  • ∫02πcos2tdt=π（用降幂公式，剩下的 cos2t 那一项又整周期积掉）。

所以括号里的积分是 2π−0+3π−0=5π，

V=5π2a3

要点：参数方程求体积，列式、换元、换限三步一步都不能少，而最容易漏的是第三步。

记忆入口 · 一眼回忆

一句话

旋转体的体积 = 把立体切成无数薄片，每片的横截面是圆（或圆环），把截面面积从一头积到另一头。

四个公式（只用这四个）

V=π∫abf2(x)dx(绕 x 轴，半径 y)
V=π∫ab[f2−g2]dx(绕 x 轴，圆环)
V=π∫cdφ2(y)dy(绕 y 轴，半径 x)
V=π∫cd[f22−f12]dy(绕 y 轴，圆环)

一条链

看转轴 定半径是 x 还是 y→ 看边界 一条曲线是圆、两条是圆环→ 定变量与上下限 绕谁就对谁积分→ 半径平方再积 得体积

要背的

  • 半径是点到转轴的垂直距离：绕 x 轴是 y，绕 y 轴是 x。动笔前先把它画出来。
  • 两条曲线夹着转 → 横截面是圆环，用外半径的平方减内半径的平方，不是 (f−g)2。
  • 绕 y 轴三件事：对 y 积分、上下限是 y 的范围、半径是 x；题目给的 y=f(x) 要自己反解。
  • a2−x2 在 [−a,a] 上积分 = 半圆面积 12πa2，别换元。
  • 参数方程换元之后，上下限必须换成 t 的范围。
  • 公式里是 y2：y=x2 时要平方两次，得 x4。

两个坑

  1. 半径认错。绕 y 轴却按 y 算半径，一路错到底。破解办法只有一个：每次先在草图上把半径那条线段画出来。
  2. 换了元不换限。∫02πa 写成 ∫02π 只在一念之间，但答案会差一整个 a 的量级。
