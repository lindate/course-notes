P111【黑板】平面曲线的弧长

一句话核心

本页是第 12 章（定积分的应用）的复习精讲课。所有弧长题都只靠一句地基：把曲线剁成无数小段，每段用一根直线顶替，再用勾股定理把这一小段的长度写成 ds=dx2+dy2。三种公式——参数方程、直角坐标、极坐标——不是三个公式，而是同一句话换三种说法，区别只在「参数是谁」。新授课细节见 定积分应用（求平面曲线的弧长）。

一、知识速查：一条地基，一句「以直代曲」

00:00「弧长」这个词以前见过，但见过的都是极特殊的情形：圆的周长 2πR、三角形的周长 a+b+c、正方形的 4a。它们都有现成公式，因为它们太规则了。考场上真给一条只写着一个方程、曲里拐弯的曲线，它有多长？

这件事之所以能做成，靠的是一件早就熟练的手艺——先切碎、再求和、最后取极限。求面积是这么干的，求体积是这么干的，求弧长还是这么干。

00:52为什么「碎」了以后就能算

关键在一条朴素的经验：一条足够短的曲线，看起来就是一条直线段。

你拿一根稍微弯的钢丝，截出很短的一小段，那一小段几乎就是直的——用尺子量它，和量它两个端点之间的直线，读数几乎一样。曲线本身没法用尺子量，直线段可以；所以把曲线剁碎，就把「量曲线」换成了「量一大堆小直线」。老师课上把它说得更直白：这一小片是个圆弧，并不是一个线段，但因为它取得比较小，我们可以近似地看成是一个线段。

这句话就是后面三条公式唯一的一块地基——「以直代曲」。三种形式的三个 ds 表达式长得完全不一样，但它们出生在同一句话里。

02:12设曲线从 A 到 B，在上面依次取许多分点，切成 n 小段，取典型的一小段。把这一段弧近似看成线段，再过两端点分别作水平线和竖直线，交出一个直角三角形：横着的直角边是 Δx，竖着的直角边是 Δy，斜边就是这一小段。于是

Δs≈(Δx)2+(Δy)2

04:41接下来要把「近似」升级成「微元」，这一步要先复习一下微分。老师把微分那节课的图又讲了一遍：Δy=f(x+Δx)−f(x) 是函数值变化的精确值；而 dy=f'(x)Δx 是过那一点作切线、沿切线量出来的那一段，是近似值。两者之差是比 Δx 更高阶的无穷小。

05:26把分点取到无限密，Δx、Δy 就升级成微分，于是得到这一节的全部来源：

ds=dx2+dy2

这一行必须记死。后面三种形式的公式全都是它的不同写法，推导时也只需要从它出发。

二、知识速查：三种形式，一张表

07:12第一种情形最基础：曲线由参数方程给出

x=x(t),y=y(t),α≤t≤β

看到 x、y 都挂在 t 上，有些同学会以为这是「立体图」。要纠正：它仍然是一条平面曲线——x 是横坐标、y 是纵坐标，只不过这两个坐标被第三个量 t 统一调度。t 不是坐标轴上的任何一根轴，它只是「走到哪儿了」的计时器。

04:41把 dx、dy 换成对 t 的微分：dx=x'(t)dt、dy=y'(t)dt（这一步的依据就是刚才复习的微分）。两式一起塞进 ds 的表达式，两个括号里都含同一个因子 dt2，提出来再开方就是 dt：

S=∫αβx'(t)2+y'(t)2dt

07:12老师专门叮嘱过这一条：这个公式不好意思，你得把它死记住，因为后边还有两个公式是用它推出来的。所以它是母公式——另外两条不必硬背，需要时推一两行就出来。

曲线怎么给弧长公式怎么从母公式得到
参数方程 x=x(t)、y=y(t)S=∫αβx'2+y'2dt母公式，直接用
直角坐标 y=f(x)，x∈[a,b]S=∫ab1+y'2dx取 t=x，于是 x'=1
极坐标 ρ=ρ(θ)S=∫αβρ2+ρ'2dθ代 x=ρcosθ、y=ρsinθ
为什么说这三条其实是同一条（本节最该记住的一句话）

把三种形式的差别抽掉，剩下的是同一件事：弧微元 ds 永远是一个直角三角形的斜边，只是那两条直角边换了名字。

  • 参数方程：两条直角边是 dx=x'dt 与 dy=y'dt——「横向走完这一程」和「纵向走完这一程」。
  • 直角坐标：把 x 派去当参数，于是横向那一条直接就是 dx（系数是 1），根号里只剩 1+y'2。它不是新公式，只是母公式的一个特例。
  • 极坐标：两条直角边换成「沿射线往外走」贡献的 dρ，和「绕着原点拐弯」贡献的 ρdθ。这两件事的方向互相垂直，所以平方相加就是 ds2。

所以三者的统一性只有一句：「以直代曲」之后，弧永远是 (横向改变量)2+(纵向改变量)2 开根号；直角坐标与极坐标只是把「横向」「纵向」翻译成了各自习惯的语言。老师说不建议死背三条公式，宁可每次花二十秒推一遍，就是这个道理。

三、极坐标那一支的推导：ρ2+ρ'2 是怎么来的

12:43极坐标下的曲线写作 ρ=ρ(θ)，θ 从 α 走到 β。思路和直角坐标完全一样：想办法把它变成参数方程。转换关系是每个人都该记住的两行：x=ρcosθ、y=ρsinθ。

这里有一处极容易被误会的地方。有人说：「你这儿不是还有个 ρ 吗？怎么能说是 θ 的参数方程？」——注意，ρ 本身就是 θ 的函数，代进去以后，表达式里就只剩下 θ 了，可以放心把它当参数方程用。

  1. 15:07两个坐标分别求导。x 是「ρ 与 cosθ 相乘」，按乘积求导法则：
    x'=ρ'cosθ−ρsinθ,y'=ρ'sinθ+ρcosθ
  2. 16:58各自平方，再相加。平方之后一共出现四类项：ρ'2cos2θ、ρ'2sin2θ、ρ2sin2θ、ρ2cos2θ，还有两组交叉项 2ρρ'sinθcosθ 与 −2ρρ'sinθcosθ。
  3. 消。两组交叉项一个正一个负，正好抵消；剩下的四类里，ρ'2 的两项用 cos2θ+sin2θ=1 合成 ρ'2，ρ2 的两项合成 ρ2。
  4. 开方。x'2+y'2=ρ2+ρ'2，积分限换成 θ 的范围。
ds=ρ2+ρ'2dθ,S=∫αβρ2+ρ'2dθ

17:59老师说书上这一步「简略了很多」——直接给出结果，中间那些求导、平方、消项的过程全跳过了。他让同学自己补一遍，因为亲手推过一次，考场上才敢用。

16:58为什么交叉项一定会消掉

这不是巧合，而是极坐标的「正交性」在替你干活。ρ 变化的方向是沿着射线往外走，θ 变化的方向是垂直于射线拐弯，这两个方向互相垂直，所以 dρ 与 ρdθ 是另一组互相垂直的直角边，它们的平方和就是 ds2：

ds2=(dρ)2+(ρdθ)2

两边同除 dθ2，立刻得到 ρ2+ρ'2。这就是把这个公式记牢的最省力的办法：在极坐标里，「往外走」贡献 dρ，「绕圈走」贡献 ρdθ，两者垂直、平方相加。

顺带对比一下容易混的邻居：算面积时出现的是 dS=12ρ2dθ，那里不带 ρ'。两个式子长得像，一个带撇一个不带，考试时千万别串行。

四、四道例题

例 110:41求曲线 y=23x3/2 在 A≤x≤B 上那一段的弧长（A,B 为已知常数）。

思路：直角坐标题，直接用 1+y'2，不用微元法

10:41这一条给的是 y=f(x) 的形式，属于第二种情形，所以套 S=∫ab1+y'2dx。老师说这道题「咱就别客气了，就直接套公式呗」——已经推出公式的题型，不必再回到根号从零开始。

第一步：求导

y=23x3/2，前面的系数 23 与 x3/2 求导后冒出来的 32 正好抵消成 1，指数从 32 减一次变成 12：

y'=x1/2=x
第二步：平方并代入

y'2=x，所以根号里是 1+x，被积函数变得极简单：

S=∫AB1+xdx
第三步：凑微分求原函数

把 1+x 看成一个整体（x 加常数不改变微分），它相当于 u1/2 求原函数，指数加一得 u3/2，前面配一个系数 23：

S=23[(1+x)3/2]AB=23[(1+B)3/2−(1+A)3/2]

这就是答案。11:41老师说得很实在：这里是个 x 加一，在 d 的里头可不可以任意的加减常数？可以。「dx 里加减常数不影响结果」是这一类题最常用的省力动作。

这一步最容易错

把系数 23 留着不管，写成 y'=23⋅32x1/2 却忘了两个数正好约掉。约掉之后 y' 才等于 x，y'2 才等于 x，根号里才干净。如果没约、平方之后就会出现一堆系数，越算越乱。

另外注意：这道题的答案不是一个数，而是一个含 A、B 的表达式。题目给的是字母端点，那就老老实实带着字母写，不必代入具体值。

例 220:14求摆线 x=a(t−sint)、y=a(1−cost) 的一拱（0≤t≤2π）的长度，其中 a>0。

思路：标准参数方程，直接套母公式

摆线是「圆在直线上滚动时，圆周上一个定点划出的轨迹」——19:21老师说它上面最高处的点是 2a（因为 cost 最小时等于 −1，1−(−1)=2）。t 从 0 走到 2π 正好画出一个「拱」。给的就是参数方程，不必翻译，直接代：

S=∫02πx'(t)2+y'(t)2dt
第一步：求导

x'=a(1−cost)，y'=asint。

第二步：平方相加（这是全题的核心）
x'2+y'2=a2(1−cost)2+a2sin2t=a2(1−2cost+cos2t+sin2t)

22:41括号里 cos2t+sin2t=1，再和前面的 1 合成 2，于是

x'2+y'2=a2(2−2cost)=2a2(1−cost)
第三步：用半角公式把根号拆开

由 1−cost=2sin2t2，根号里变成 4a2sin2t2，开方出来是 2a|sint2|。所以

S=∫02π2a|sint2|dt=4a∫02πsint2dt2=4a[−2cost2]02π

上限代入 −8acosπ=8a，下限代入 −8acos0=−8a，相减得

S=8a
开方之后的绝对值，绝对不能扔

直接写 sint2，把绝对值符号去掉。sin2u=|sinu| 是恒等式，sinu 本身可能是负的。

这道题能去掉绝对值，是因为有「t2 落在 [0,π]」这个条件撑腰——在这段上 sin 非负。若换成积分区间 [0,4π]，t2 就跑到 [0,2π]，其中一半的 sin 是负的，去掉绝对值会把正负抵消掉，答案直接变成 0。

凡是开方得到含 sin、cos 的式子，先问一句：在这个区间上它是正的吗？这是本页最贵的一个坑。

例 3求星形线 x=acos3t、y=asin3t（0≤t≤2π，a>0）的全长。

思路：和摆线一模一样的流程，只是化简步骤长一点

星形线是四条向内凹的弧拼成的封闭曲线，四个尖点分别落在两条坐标轴上（(±a,0)、(0,±a)）。它同样给的是参数方程，直接套母公式。

第一步：求导

cos3t 求导要连着用两次链式法则：x'=3acos2t⋅(−sint)=−3acos2tsint；同理 y'=3asin2tcost。

第二步：平方相加
x'2+y'2=9a2cos4tsin2t+9a2sin4tcos2t=9a2sin2tcos2t(cos2t+sin2t)

括号里又是 1，所以 x'2+y'2=9a2sin2tcos2t。

第三步：开方、用倍角公式收拾干净

开方得 3a|sintcost|。用倍角公式 sintcost=12sin2t 换成一次角，绝对值留在外面：

S=∫02π3a|sintcost|dt=3a2∫02π|sin2t|dt
第四步：处理绝对值，用周期性

|sin2t| 的周期是 π2，在 [0,2π] 上一共有 4 个完整周期，而每个周期上的积分都是 ∫0π/2sin2tdt=1。所以不必分段去绝对值，直接用周期性数出 4 个周期：

∫02π|sin2t|dt=4×1=4
S=3a2×4=6a
这道题教的是「怎么处理绝对值」的第二种办法

例 2 里，去掉绝对值靠的是「在积分区间上它非负」；这道题里它中间变号，靠的是周期性——数出有多少个完整周期，每个周期上积分值相同，乘起来就行。

两个办法合起来，就是把「 开出来带绝对值」这件事彻底摆平。处理绝对值永远只有两条路：确认非负，或者按分段／周期拆开。

顺带记一个结果：星形线的全长是 6a，摆线一拱是 8a，两条形状差很远的曲线，答案都是 a 的简单倍数——这是弧长题的常见「手感」。

例 423:22求阿基米德螺线 ρ=aθ（a>0）在 0≤θ≤2π 上那一段的弧长。

思路：这次是极坐标，用第三条公式

23:22老师说这是「真真正正的极坐标题」——因为 ρ 本身就是 θ 的函数，x、y 都不出现。套 S=∫αβρ2+ρ'2dθ，先算两样东西：ρ2=a2θ2（就是求面积时已经算过的那个平方），而 ρ'=a，所以 ρ'2=a2。

S=∫02πa2θ2+a2dθ=a∫02π1+θ2dθ

把常数 a 提出来之后，剩下的积分是 ∫1+θ2dθ。

这个积分怎么算

24:24老师说得很直白：这个结果还挺麻烦的。它不是基本积分表里的形式，要用第二换元积分法——24:24他提到「第二换元积分法不是有三种公式吗？这应该是最后一种」。做法是令 θ=tanu，于是 1+θ2=secu、dθ=sec2udu，积分变成 ∫sec3udu（这正是第二换元里那条最难记的公式）。

算完之后把 u 换回 θ，得到的原函数是

∫1+θ2dθ=12[θ1+θ2+ln(θ+1+θ2)]

代入 0 到 2π（下限代进去是 0），最终

S=a2[2π1+4π2+ln(2π+1+4π2)]≈21.26a
这道题的「要点」不在答案

螺线的弧长算出来带了根号和对数，长得不好看——这不是你做错了，而是它本来就长这样。弧长公式给出的定积分不保证都能算出初等结果；椭圆周长就是历史上最著名的「算不出来」的例子（见 定积分应用（求平面曲线的弧长） 例 2）。

所以螺线这道题真正要练的是两件事：一、ρ' 要算对（ρ=aθ 求导得 a，别忘了它）；二、认出 ∫1+θ2dθ 属于哪一类积分。至于最后的代入，那是体力活。

五、易错清单

  • 把 sin2u 直接写成 sinu。开方一定带绝对值。能不能去掉，取决于 u 的取值范围撑不撑腰（例 2），或者靠周期性分段数（例 3）。
  • 只算一半。心形线、椭圆这样的封闭曲线，要么从 0 积到 2π，要么算一半再乘 2；写成 ∫0π 答案就少一半。
  • ρ' 算错或漏掉。ρ=aθ 的导数是 a 而不是 0；ρ=a(1+cosθ) 的导数是 −asinθ。漏了负号在平方后看不出来，但不平方就错得很离谱。
  • 把 dx、dy 当成「随便的小量」。它们是微分，代换时 dx=x'dt 这一步不能省；这一步错了，dt 就提不出来，整个根号也开不了。
  • 参数方程换元后忘了换积分限。积分变量从 x 换成 t，上下限必须从 x 的范围换成 t 的范围；必要时可以先由端点反解（出现「上限比下限小」是正常的）。
  • 把弧公式与面积公式记混。极坐标下：弧是 ρ2+ρ'2dθ（带撇），面积是 12ρ2dθ（不带撇、带 12）。
  • 把弧长的 1+y'2 与曲率公式里的 1+y'2 认成同一个。曲率里它出现在分母，外面还挂着 y''；弧长是把整个 1+y'2 积起来（见 曲率）。
  • 以为弧长一定算得出漂亮答案。螺线、椭圆周长都算不出初等结果，写不出好看的封闭形式是正常的，把式子化简到位就算完成任务。

  • 摆线一拱 =8a；星形线全长 =6a；心形线 ρ=a(1+cosθ) 全长 =8a（见 定积分应用（求平面曲线的弧长））。
  • 极坐标公式的本质：「往外走」贡献 dρ，「绕圈走」贡献 ρdθ，两者垂直、平方相加。
  • ∫1+θ2dθ 要用第二换元（令 θ=tanu），结果带根号和对数。
  • 定积分的值只与积分区间和被积函数有关，与积分变量用什么字母无关。

三个坑

  1. 开方后忘绝对值。处理绝对值只有两条路：确认非负，或者按分段／周期拆。
  2. 只算一半。封闭曲线要乘 2 或从 0 积到 2π。
  3. 把 dx、dy 当成「随便的小量」。它们是微分，dx=x'dt 这一步不能省。
