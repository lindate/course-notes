P064一阶线性微分方程：一个必须背下来的通解公式

一句话核心

「一阶线性」只看一件事：y' 与 y 的关系是不是线性的，x 的表达式一律当常数。认准标准形式 y'+P(x)y=Q(x) 之后，通解就是一个只能死记的公式；本页先把它是怎么来的讲透（常数变易法），再把记忆要点、易错点、以及「把 x 看成 y 的函数」这种变形一次说清。

先把「一阶线性」这四个字拆开

微分方程这一章走到这里，手里已经有了两件工具：可分离变量（可分离变量的微分方程）和齐次方程（齐次方程）。老师说，接下来这个一阶线性微分方程是「微分方程里边特别重要、也最容易考到」的一种——考试里二阶方程考到的可能性还小一些，一阶线性却几乎年年有。

名字里的「一阶」很好办：方程里出现的最高阶导数就是 y'。真正需要解释的是「线性」。

什么叫做「线性」

在我们这一章里，「线性」只针对 y' 与 y 这两个量本身：它们各自只能以一次方出现，不能相乘、不能相除、不能开方、不能进分母。至于 x、或者说「x 的一堆表达式」，一律当作常数看，根本不管它。

这句话听着抽象，拿四个式子过一遍就实了：

式子是不是一阶线性理由
y'+3y=sinx是y'、y 都是一次方，sinx 属于「x 的表达式」，不管
y'+xy=ex是那个 x 只是 y 的系数，按常数看待
y'+1xy=x是1x 也只是 y 的系数，它随 x 变没关系
y'+x⋅1y=0不是y 跑到分母上去了，已经不是一次
y'y=x不是两个 y 乘在一起，出现二次

第三行最容易让人犹豫：系数里明明有 x，怎么能算「常系数」？——注意线性方程从来不要求系数是常数。「y 的系数可以随 x 变」正是这一节的全部难度所在，真正被禁止的只有一件事：y 或者 y' 之间发生了非线性运算。

标准形式：P 和 Q 到底是什么

把方程整理成下面这个样子，叫做一阶线性微分方程的标准形式：

dydx+P(x)y=Q(x)

其中 P(x)、Q(x) 都是已知函数。老师的提醒很直白：这里头乘以的这个 P(x)，我们就看到这个常数了，不管它。也就是说，P 就是「贴在 y 前面的那一整块」，Q 就是「等号右边那一整块」。

按 Q(x) 是不是恒等于零，方程分成两类：

Q(x)≡0
叫做一阶齐次线性微分方程。方程变成 y'+P(x)y=0。
Q(x)≡0
叫做一阶非齐次线性微分方程。这是考试的正戏。
「齐次」这两个字，在这一章里有两个意思

齐次方程 里的「齐次方程」指的是右边只出现 yx 这一整块（写成 φ(yx) 的样子）。而这里的「线性齐次」说的完全是另一件事——方程右端的自由项为零。

两个「齐次」只是恰好共用了同一个词，跟「齐次」这两个汉字本身的意思没有关系。看到题目先看形式：右边是 yx 的函数，走三板斧；右边是个纯零，那是本页的退化情形。

先看退化的情形：Q≡0

老师说，齐次的这种其实一点意思都没有，因为它就是一个可分离变量方程。把它写开：

dydx=−P(x)y⟹1ydy=−P(x)dx

两边积分，左边是 ln|y|，右边是 −∫P(x)dx：

ln|y|=−∫P(x)dx+C1⟹|y|=eC1⋅e−∫P(x)dx

05:19最后把绝对值去掉，会多出一个正负号，那个 ±eC1 我们统一收成一个任意常数，于是：

y=Ce−∫P(x)dx

这个式子老师建议干脆不要背——它本来就是「分离变量 + 两边积分」的产物，题目给了直接算就行。但它在下一页要当主角：非齐次方程的通解里，会有它完整的一个身影。

通解公式是怎么来的：常数变易法

现在来看 Q(x)≡0 的正题。老师先声明：这个推导过程不要嫌麻烦，你愿意听就听，不听也无所谓，但是最终的那个公式你必须记住。——虽然如此，这一段的思路其实只有一个动作，听懂以后公式就不会记混了。

  1. 先把 y 收拢成公因子，凑出可分离变量的样子。把方程写成 dydx=Q(x)−P(x)y，然后把 y 提出来：
    dydx=(−P(x)+Q(x)y)y⟹1ydy=(−P(x)+Q(x)y)dx

    这一步是「硬凑」——右边的括号里还留着 y，本来就不该能分开。但老师要的只是这个形状。

  2. 两边积分，看出解的骨架。左边积出 ln|y|，右边拆成两块：
    ln|y|=−∫P(x)dx+∫Q(x)ydx

    取指数之后得到 y=e−∫Pdx⋅e∫Qydx。前一个因子完全知道（P 是已知的），后一个因子什么也不知道（因为它里面藏着 y）。

  3. 把不知道的那部分，打包成一个待定函数。既然前一个因子已知、后一个因子未知，那就先记
    y=C(x)e−∫P(x)dx

    这就是「常数变易法」：齐次方程的解是 y=Ce−∫Pdx，其中 C 是常数；非齐次的时候，我们猜那个常数其实不是常数，而是一个随 x 变化的函数 C(x)，「变易」就是「把它变成函数」的意思。

  4. 代回原方程，把 C(x) 定出来。对 y=C(x)e−∫Pdx 求导，这是乘积求导：
    y'=C'(x)e−∫P(x)dx+C(x)(−P(x)e−∫P(x)dx)

    再算 y'+P(x)y，把上面这个 y' 和 P(x)⋅C(x)e−∫Pdx 加起来：

    y'+P(x)y=C'(x)e−∫P(x)dx

    中间那两项一正一负，正好抵消。而原方程要求 y'+P(x)y=Q(x)，所以

    C'(x)=Q(x)e∫P(x)dx
  5. 积分出 C(x)，回代收工。两边对 x 积分（这是求导的逆运算，所以 e 的指数符号翻了回来）：
    C(x)=∫Q(x)e∫P(x)dxdx+C

    把它塞回第 3 步的式子里，通解公式就到手了。

整段推导的关键，其实只有「两项抵消」这一句

第 4 步里 y' 与 P(x)y 相加，得到的不是一大堆东西，而是干干净净的 C'(x)e−∫Pdx。为什么会这么巧？因为 y=Ce−∫Pdx 本来就是齐次方程的解——C 取成常数时，C'e−∫Pdx=0 正好对应 y'+Py=0。现在我们让 C 动起来，方程右边就从 0 变成了 C'(x)e−∫Pdx，多出来的这一块刚好拿去顶替 Q(x)。

换句话说：非齐次的解 = 齐次的解 × 一个待定函数。老师把它叫「变易」，其实是在说「让常数动起来」。这条思路在后面对付二阶非齐次方程时还会原封不动地用一次。

公式长什么样，怎么记

一阶非齐次线性微分方程的通解

方程 dydx+P(x)y=Q(x) 的通解是

y=e−∫P(x)dx(∫Q(x)e∫P(x)dxdx+C)

其中 C 是任意常数。这个公式必须背到条件反射——老师原话：公式就得死记，死记了以后朝里做就能做出来。

老师的记忆法是「按顺序念出来」：y 等于 e 的负的 ∫Pdx，小括号，积分号，Q，e 的正的 ∫Pdx，dx，再加 C，括号结束。他特别强调了两件小事：一个是「P 前面是负的、Q 前面是正的」这一对符号；另一个是「dx 写了一遍以后，大的那个经常漏」——其实我也经常漏。

用公式前的第一步：化成标准形式

老师说这一步「非常非常的重要」：你在做题的时候，必须把你的原方程写成这个形式。这个地方系数必须是个一。三条要求，缺一条 P、Q 就取错：

  1. y' 的系数必须是 1。原题系数不是 1，就两边同除把它变成 1。
  2. y 必须在左边。原题把 y 放在右边，就挪过来。
  3. 不含 y 的部分（也就是「x 的表达式」）必须全在右边，那就是 Q(x)。

课上给的例子是 xy'+x5y−x=0。按上面三条走一遍：

xy'+x5y−x=0→y'+x4y−1=0→y'+x4y=1

于是 P(x)=x4，Q(x)=1。只有化成标准形式之后读出来的 P、Q 才是准的。老师还提醒了一个得分点：答题纸上要把「P(x)=⋯，Q(x)=⋯」明明白白写出来——这一步有过程分。

例 1求方程 y'+y=5x 的通解。

第一步：先报出 P 和 Q

方程已经是标准形式：y' 系数为 1，y 在左边，x 的表达式全在右边。所以

P(x)=1,Q(x)=5x

这两个式子在答题纸上是要写出来的，别嫌啰嗦。

第二步：套公式

代进通解公式。这里可以顺手把「先算 ∫Pdx」当固定动作：∫Pdx=∫1dx=x。于是外层是 e−x、里层是 ex：

y=e−x(∫5x⋅exdx+C)
第三步：算里层的积分（分部积分）

∫5xexdx 是「多项式乘指数」，属于典型的分部积分（分部积分法）。把 ex 挪进微分号：

∫5xexdx=5∫xd(ex)=5(xex−∫exdx)=5(xex−ex)

这里没有再加常数——任意常数统一由公式里那个 C 负责（下一小节会专门解释）。

第四步：回代整理
y=e−x(5xex−5ex+C)=5x−5+Ce−x

这就是通解。可以口算验一下：y'=5−Ce−x，而 y'+y=5−Ce−x+5x−5+Ce−x=5x，与题目一致。

两个细节：为什么只写一个 C、为什么 ln 不加绝对值

21:32里层积分的时候，为什么不加常数

有同学会问：算 ∫1dx=x 的时候，是不是该写成 x+C1？老师给的理由是「随便你加，加了也白加」：如果里层写成 x+C1，那么内层积分会多出一个因子 eC1，外层一圈走下来，最后会变成 C⋅eC1——它仍然是一个任意常数。

更根本的原因在于：一阶方程的通解里只能有一个任意常数。既然公式的末尾已经有一个 C 兜着，中间那些积分再各加一个，最后也必然被合并进来。所以干脆只写在最后一个位置，省事又不出错。

P 里含 1x 时，ln 不要加绝对值

课上第二个练习题是 P(x)=1x、Q(x)=1。这时 ∫1xdx 我们直接写 lnx，不写 ln|x|。理由是外层与里层的两条对数会一正一负，正负号最后被那个任意常数 C 一并吸收，写上绝对值反而碍事。

老师说的原话是：这个正负号我们也给它看成由最后的那个 C 统一给它包进去。这是本节的约定，照着写即可。

反过来做：把 x 看成 y 的函数

这是本页最难的一类题，但它难在「敢不敢换角色」，不在计算。方程（整理后）是

y3dxdy+2xy2=1

按 y 为主来看，它既不是可分离变量，也不是齐次：方程里有 y3、有 y2，偏偏没有单独出现的 y——想凑成 y'+P(x)y=Q(x)，「怎么凑也凑不上去」。这正是 齐次方程 里那条经验的用武之地：变量互换。

做法很干脆：承认 x 是 y 的函数，两边同时除以 y3：

dxdy+2yx=1y3

这个式子的形状，和 y'+P(x)y=Q(x) 一模一样——只是「谁是函数」换了个位置。所以公式一个字都不用改，只把所有的 x 与 y 对调、把 dx 与 dy 对调：

x=e−∫P(y)dy(∫Q(y)e∫P(y)dydy+C)

例 2解方程 y3dxdy+2xy2=1。

第一步：化成关于 x 的标准形式并报出 P、Q

两边同除 y3，就得到上面那个标准形式。所以

P(y)=2y,Q(y)=1y3
第二步：算两条积分（这里的坑是别把 dy 漏了）
∫P(y)dy=∫2ydy=2lny,e−∫Pdy=1y2,e∫Pdy=y2
第三步：套公式
x=1y2(∫1y3⋅y2dy+C)=1y2(∫1ydy+C)

里层那个 1y3⋅y2 化简成 1y，是这道题最舒服的地方——y 的幂次刚好降到能直接积出来。

第四步：写答案，注意「分母上不留变量」
x=ln|y|+Cy2⟺xy2=ln|y|+C

老师最后把答案写成了 x 等于一个分式。如果评卷时不喜欢分母上的 y，按 齐次方程 的习惯也可以整理成 xy2−ln|y|=C（把任意常数吸进 C）。两种写法都对，别写成 x 单独等于一个含 C 的复杂式子就行。

这一步最容易错的地方

里层的 ∫Q(y)e∫Pdydy 里，末尾那个 dy 被漏掉。老师说这是他自己也常犯的毛病：这个大的 dy 特别容易漏。公式里一共有两处积分号，每一处都要有一个对应的微分，写成 ∫Qe∫Pdy 就没有收尾的变量了。

把 ∫2ydy 的结果写成 lny2 之后就直接当 y2 用。要小心：e2lny=y2，e−2lny=1y2，一正一负分别对应里层与外层，别把两个位置抄反。

拿到一道题，先判断它是什么类型

老师说得很实在：谁也不是神仙，谁拿过来一个方程也没有办法一眼看出来它到底是什么方程。判断类型是有先后顺序的，先试最容易的，一条一条排除：

33:13老师判齐次的「男生女生」比喻

齐次方程里的 yx 总是整体出现，题目又常常把它藏起来。老师给了一个很好用的观察法：只要有一个学生出来，一定是一个男生和一个女生一起出来。张三和小红出来了，李四和小花出来了……那就说明你班的男生跟女生一定是一样多。所以它的 x 跟 y 的次数一定是一样多的。

翻译成做题的动作：看到 x3y3 这种「次数打平」的结构，就该怀疑它是伪装的齐次方程——这正是 齐次方程 里那条「一条蛇进去、出来个乌龟」的意思。

出题老师的「巧劲」，其实在帮你

25:06老师说了一句很有意思的话：他担心的不是学生，而是出题的时候一定要小心。因为 P、Q 不能随便取——要保证两件事同时成立：第一，∫Pdx 能算出来；第二，e∫Pdx 与 Q(x) 相乘以后那个积分也能算出来。

这两个条件把 P 的选择压得很窄，于是有了一个非常实用的经验：P(x) 常常就是 1x 或者类似于 1x 的东西。好处是 ∫1xdx=lnx，而 e 一碰上 ln 就抵消，出来一个干干净净的 x 的幂；这个幂再与 Q(x) 相遇，往往正好能约掉一片。

所以做题时看到 1x 不必发愁，反而应该心里一松：这是命题人给你留的台阶。反过来说，备考时也不必去啃那些积不出来的怪题——那种题不会出现在卷子上。

一句话

一阶线性 = y' 与 y 只以一次方出现（x 的表达式当常数）。认准标准形式，套通解公式。

核心两式（要背死）

dydx+P(x)y=Q(x)
y=e−∫Pdx(∫Qe∫Pdxdx+C)

一条链

第一步 化成标准形式，报出 P、Q→ 第二步 算 ∫Pdx→ 第三步 套公式，算里层积分→ 第四步 整理，分母上不留变量

四个零件

外层指数
−∫Pdx，带负号
里层指数
+∫Pdx，带正号（与外面配成一对）
Q 的位置
在括号里的积分号下，不能提到外面
微分与常数
两个 dx，括号外一个 C；里层的 dx 最容易漏

三个坑

  1. 没化标准形式就读 P、Q。例：xy'+x5y−x=0 必须先变成 y'+x4y=1，P=x4、Q=1。
  2. 里层积分顺手多加一个常数。一阶方程的通解只有一个任意常数，中间那几处不用加。
  3. 忘了「变量互换」这一招。出现「有 y2、y3 却没有单独的 y」这种怪相，就把 x 看成 y 的函数，公式照抄。

  • y'+y=5x 的通解：y=5x−5+Ce−x
  • y3dxdy+2xy2=1 的通解：x=ln|y|+Cy2
