P009与极限为 ∞ 的量

一句话核心

极限为 0 的量叫无穷小，极限为 ∞ 的量叫无穷大。它们都是「极限的语言」：前者把「趋于零」符号化，后者把「趋于无穷」符号化。最关键的两句话——「趋于零」不是「等于零」，且「极限是无穷大」其实属于极限不存在。二者还互为倒数。

无穷小：极限为 0 的量

00:00定义很直白：如果 limf(x)=0，就称 f(x) 是当 x→x0（或 x→∞ 等）时的无穷小。一句话，「无穷小」就是「极限为零的那个量」。

定义 · 无穷小

若在某一变化过程中 limf(x)=0，则称 f(x) 为该过程下的无穷小量（简称无穷小）。

02:48数列也照此办理：若 limn→∞xn=0，就称数列 {xn} 是 n→∞ 时的无穷小。所以无穷小这个概念对函数极限和数列极限同时有效，不必分开记两套。

那常数 0 算不算无穷小？04:58

算。这个追问在课上是老师自己提出来的：「常数零是不是无穷小啊？」——不管 x 怎么变，0 的极限永远是 0，符合定义。所以 0 是唯一一个可以作为无穷小的常数。它旁边的 0.0001、0.000001 都不行，因为它们的极限是它们自己，不是 0。

这句话的价值在于把边界钉死了：「无穷小」里能当常数的只有一个 0，其余全是随过程变化的变量。所以前面那条「无穷小是变量、不是很小的数」，唯一的例外就是 0。

两个必须立刻纠正的误解 01:50

误解一：负的无穷大是无穷小。有同学想「负的一亿、负的一万亿，多小啊」，于是把 −∞ 当成无穷小。错。无穷小指的是趋于零（贴着 0），而 −∞ 是往负方向飞，离 0 越来越远。0 在中间，「负无穷」和「无穷小」是八竿子打不着的两件事。

误解二：把很小的常数当成无穷小。0.0001 确实小，但它是一个固定的常数，不是「无限趋于零」。无穷小必须是一个会动的过程——x 越变它越靠近 0，而不是永远停在某个小数值上。

为什么必须写出变化过程 00:38

同一个函数，换一个变化过程，可能就从无穷小变成不是了。比如 x2：当 x→0 时 x2→0，所以它是 x→0 时的无穷小；但当 x→1 时 x2→1，它不再是无穷小。所以写「无穷小」时，「谁趋于什么」必须标明，否则这句话没有意义。

例02:48判断下列哪些是无穷小：① x2（x→0）；② 1x（x→∞）；③ x2（x→1）。

逐条看变化过程
  • ① x→0 时 x2→0：limx→0x2=0，是无穷小。
  • ② x→∞ 时 1x→0：limx→∞1x=0，是无穷小。
  • ③ x→1 时 x2→1≠0：不是无穷小。

同一式子 x2，只因变化过程不同，结论就不同——这正是上一条「必须写变化过程」的理由。

一个把极限拆开的定理

定理 · 极限 = 常数 + 无穷小

limf(x)=A 的充要条件是：存在无穷小 α（与 f 同一变化过程），使得

f(x)=A+α(x)

04:58这句话把「f(x) 以 A 为极限」翻译成大白话：f(x) 无限靠近 A，所以二者之差就是一个无穷小 α。A 是主体，α 是那一点点误差。这一定理实际计算用得不多，但它给了「极限」一个更灵活的表达——后面讨论带误差的近似时会用到这种写法。

必要性一眼看出

若 limf=A，令 α=f−A，则 limα=limf−A=0，即 α 是无穷小，移向即得 f=A+α。充分性同理：f=A+α 且 limα=0，则 limf=A+0=A。这条定理其实就是极限定义换了件衣服。

无穷大：极限为 ∞ 的量

07:14和无穷小对称地，极限为 ∞ 的量叫无穷大（无穷大量）。例如 limx→01x=∞：x 从两侧逼近 0 时，函数值一头向上、一头向下无限延伸。

课本的严格定义，以及老师对它的态度 08:20

课本把「量大」这件事也用 ε 语言写死了：若对任意给定的 M>0，都存在 δ>0，使得当 0<|x−x0|<δ 时恒有 |f(x)|>M，就称 f(x) 是 x→x0 时的无穷大。把 ε 换成 M、把「小于」换成「大于」，就是这份定义与普通极限定义的全部差别——它讲的还是「任意给定的门槛，过程靠后以后全能跨过去」，只不过门槛是下限而不是上限。

对这份定义，老师的态度很直接：「这个严格的定义我们在做题的时候是不用的。」他的讲法是把无穷大当成一个「意思到了就行」的记法：分母趋于零、分子是非零常数，那就写 ∞。所以这一页的重点不在定义的严格性，而在下面那句容易被忽略的话。

最重要的一句话 08:20

口语说「它的极限是个无穷大」，但严格说，「极限是无穷大」属于「极限不存在」的范畴。极限存在专指极限是一个有限常数；∞（包括 +∞、−∞）都不在这个范围内。所以凡看到「极限是无穷大」，脑子里要立刻翻译成「它发散，且发散的方式是无限增大」。

09:27按方向分：x→0+ 时 1x→+∞（从右侧逼近，图像向上无限延伸）；x→0− 时 1x→−∞（向下）。统称无穷大。

例10:41说明 limx→11x−1=∞。

核心一句话：分母趋于零

x→1 时，x−1→0（趋于零，不是等于零）。分子是常数 1。一个固定非零数除以一个无限变小、无限靠近 0 的量，结果就被放大到无限大。比如 x−1=0.0001，则 1x−1=10000；x−1 再小十倍，结果就大十倍——没有上限，所以极限是 ∞。

这正是「趋于零 ≠ 等于零」的又一现场：正因为 x−1 永远到不了 0，除法才有意义且能发散到无穷；要是真等于 0，除法本身就不合法了。

互为倒数的关系

定理 · 无穷大与无穷小互为倒数

在同一变化过程中：

  • 若 f(x) 是无穷大，则 1f(x) 是无穷小；
  • 若 f(x) 是无穷小且 f(x)≠0，则 1f(x) 是无穷大。

11:27直觉：无穷大是「超级大」（比如一亿、一亿亿），取倒数就成「超级小」（0.00000001），无限靠近 0；无穷小是「无限靠近 0 但永不等于 0」，取倒数就「超级大」。二者正好反过来。

为什么第二条要加「f(x)≠0」 13:43

倒数的分母当然不能为 0。但无穷小可以在某些点上恰好等于 0（例如 x2 在 x=0 处就等于 0）——如果那些点被算进倒数，分母就成 0，没意义。所以定理要求「f(x)≠0」把零点排除。这里又一次体现「趋于零和等于零是两码事」：无穷小是无限靠近零但永远不等于零，所以只要避开个别零点，倒数就合法且为无穷大。

运算规律：哪些是「结论」，哪些「没有结论」

15:48无穷大量和无穷小量之间做加减乘除，远没有「极限四则运算」那么规矩。先把结论列成表——哪些是板上钉钉，哪些老师特意强调「没有结论」。

运算无穷大的结论无穷小的结论
+∞+∞+∞（确定）α+β、α−β 仍是无穷小（确定）
−∞−∞−∞（确定）
∞⋅∞同号得 +∞、异号得 −∞（确定）α⋅β 仍是无穷小（确定）
∞−∞无结论（不一定为 0）——
∞/∞无结论（谁更快不知道）α/β 无结论（引出下节比较）
视频原话（大意）

无穷大减无穷大是不是应该是零啊？不是！它指的是超级超级大。你爸很有钱，他爸也挺有钱，那俩人的钱就应该是一样多吗？当然不是。无穷大除无穷大等于多少？没有结论——你爸很有钱他爸也很有钱，他俩的钱拿过来除，谁更大谁更快，不知道。

为什么 ∞−∞ 不是 0 17:11

「相减得零」只在两个数相等时才成立。两个无穷大只是「都很大」，并不相等，谁比谁更大、大多少，完全不确定。比如 (x+1)−x 当 x→∞ 时两个都是无穷大，差是 1；而 x2−x 差是无穷大；(x+1x)−x 差是 0。同是 ∞−∞，结果可以是常数、可以是无穷、可以是零——所以没有统一结论。

为什么 α/β 无结论，却很重要 20:52

两个无穷小相除，结果可能趋于 0、趋于非零常数、趋于 ∞，全看谁趋于零更快。这个结论的缺失，恰恰引出下一节要专门讲的无穷小的比较——比的就是「谁趋于零更快」，比完之后才有等价无穷小替换这一大杀器。所以这里的「无结论」不是终点，而是下节课的起点。

无穷小的三条性质，以及一个不能丢的字

19:20上表里的运算结论是零散列的，课本把它们收成三条可以直接引用的性质。三条都用得很多，值得单独记：

性质 · 无穷小的运算（同一变化过程）
  • 有限个无穷小之和仍是无穷小；
  • 有限个无穷小之积仍是无穷小；
  • 有界函数与无穷小之积仍是无穷小（推论：常数乘无穷小仍是无穷小）。
第三条为什么成立，第三条又为什么最有用

前两条很直白：都往 0 跑，加起来、乘起来自然还往 0 跑。第三条才是有份量的。设 |g(x)|≤M，α(x) 是无穷小。那么

|g(x)α(x)|≤M|α(x)|→0

有界给它扣了个「天花板」M，而 α 本身要多么小就有多么小，M 乘上去无非是又小 M 倍，还是趋于 0。这条性质的用处在于：你不必知道那个有界函数的具体样子，只要知道它有界就行。最经典的例子是 sinx：它永远被 1 压着，所以

limx→∞sinxx=0,limx→0xsin1x=0

第一个是「有界乘以无穷小」；第二个更要留意——x→0 时 sin1x 反复震荡、根本没有极限，但它有界，乘上无穷小 x 之后整体还是无穷小。这条性质救的正是这种「局部没极限、但有界」的场合。

「有限个」三个字丢不得

把「有限个」偷偷换成「无穷多个」，结论立刻崩掉。反例：把 1n 重复加 n 次（即取 n 个 1n 相加）。当 n→∞ 时，每一个 1n 都是无穷小，可是它们的和

1n+1n+⋯+1n=n⋅1n=1

恒等于 1，一点也没有趋于 0。所以无穷多个无穷小之和，不一定是无穷小。错误出在哪里？——项数本身也在随 n 增大，每个小量虽然越来越小，但「越来越多」，两个趋势互相抵消，结果就说不准了。这也解释了性质里为什么必须写「有限个」：一旦允许无穷多，「有多少项」就成了一个新的、必须单独讨论的量。

对比着看就更清楚：项数固定成 100 项、每项都是无穷小，那么和确实是无穷小——这正是「有限个」三个字保住的结论。20:52老师提醒这一页的运算结论「做题的时候是能用到的」，但他特意把无穷小那几条留了个尾巴，因为「后边还有单独的内容再来介绍」——那个单独的内容就是下一节的无穷小比较。

无界 ≠ 无穷大

19:20学了无穷大，很多人顺手把「无界」当成它的同义词——毕竟两个词听着都是「没有边界」。但它们是两个不同的概念，差别在「一致性」上：

概念要求通俗说法
无穷大 过程充分靠后以后，所有的值都超过任意给定的正数 M 「一路上都在变大，回不了头」——这是最强的「大」
无界 存在某些点的取值可以超过任意给定的正数 M，中间是否掉回来不管 「时不时会很大」——只要求「够得着」，不要求「一直大」
反例：f(x)=xsinx 在 x→∞ 时无界，但不是无穷大

先说它无界。取序列 xn=2nπ+π2，此时 sinxn=1，于是

f(xn)=xn→+∞

只要 n 取得够大，f 就能超过任意给定的 M，所以它无界。

再说它不是无穷大。取另一序列 xn=2nπ，此时 sinxn=0，于是

f(xn)=0

无论 x 走得多远，函数值都会周期性地回到 0。无穷大要求「充分靠后以后所有值都大于 M」，可这里永远有取到 0 的点，于是永远不满足。所以 f(x)=xsinx 不是无穷大。

判据一句话：无穷大 ⇒ 无界，但无界 ⇏ 无穷大。
