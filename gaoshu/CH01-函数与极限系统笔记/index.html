CH01函数与极限：从函数到连续的系统梳理

一句话核心

这一章只做一件事：把“函数的变化趋势”变成可以计算、可以证明、可以判断的语言。先有函数，才有极限；先有极限，才有连续；先有连续，才有闭区间上的四个存在性定理。

引言：这一章到底在研究什么

高等数学与中学数学最大的区别，不是公式变多了，而是研究对象从“静止的数”变成了“变化的量”。函数描述一个量怎样随另一个量变化；极限描述这个变化最终趋向哪里；连续描述这个变化过程中有没有突然断开。把这三件事连起来，就是第一章的主线。

可以把整章压缩成四个问题：

  1. 函数是什么？它把“一个输入对应一个输出”这件事写成可计算的对象。
  2. 函数的趋势怎么描述？当自变量越来越接近某个值，函数值是否越来越接近某个数？这就是极限。
  3. 极限能推出什么？唯一、有界、保号、运算法则、存在准则，都是为了回答“这个极限能不能算、为什么存在”。
  4. 极限和函数值什么时候能对上？当它们对得上，函数就连续；连续再加上“闭区间”，就得到四个存在性定理。
函数 描述变化→ 极限 描述趋势→ 连续 把趋势钉在函数值上→ 闭区间定理 从局部走向整体

为什么要按这个顺序？因为每一步都要用到上一步的对象。没有函数，就没有“谁的趋势”；没有极限，就说不清“连续”里的“无限接近”；没有连续，闭区间上的最值、零点、介值就无从谈起。下一章的导数，也是用一个极限来定义的——所以这一章不是孤立的预备知识，而是整门课的语言基础。

1. 从映射到函数：先把“关系”说清楚

1.1 为什么先讲映射

函数不是凭空冒出来的，它首先是一种“对应关系”。在数学里，比函数更宽的概念叫映射。映射允许两个集合里装任何东西：人可以对应学号，矩阵可以对应矩阵，点可以对应点。函数只是把两个集合都收紧成“数集”。先讲映射，是为了把“一个输入只能有一个输出”这条铁律单独说清楚，不被定义域、值域这些细节分散注意力。

定义 · 映射

设 X、Y 是两个非空集合。如果存在一个法则 f，使得对 X 中的每一个元素 x，按照这个法则，在 Y 中都有唯一的一个元素 y 与它对应，那么就称 f 是从 X 到 Y 的映射，记作

f:X→Y

并把 y 叫作 x 的象，x 叫作 y 的原象。

这个定义只有三个零件：两个非空集合、一个法则、两条要求（“每一个”与“唯一”）。其中“唯一”是最容易被忽略的：一个 x 不能同时对应两个 y。至于“不同的 x 能不能对应同一个 y”，映射不管——这正是后面“单射”要单独定义的原因。

第一个必须记住的坑：Y 不是值域

映射只要求“每个 x 有象”，从没要求“Y 里的每个元素都被用到”。所以值域通常只是 Y 的一部分：

Rf={f(x)∣x∈X}⊆Y

定义域用的是 X 的全部，值域只是 Y 的一部分。这个不对称，正是“满射”这个名字的来源。

1.2 满射、单射、一一映射：三个容易混的词

看一个映射，可以分别问两个问题：Y 被铺满了吗？和有没有两个输入撞到同一个输出？前一个问题对应满射，后一个问题对应单射。

定义 · 满射 / 单射 / 一一映射

满射：若 Rf=Y，即 Y 中每个元素都被用到，则称 f 是满射。

单射：若对 X 中任意两个不同的元素 x1≠x2，都有 f(x1)≠f(x2)，则称 f 是单射。

一一映射：既单又满，也叫双射。

映射值域是否撞车直观记忆
f(x)=x2,f:R→R[0,+∞)2 与 −2 都到 4不满（Y 有剩）、不单（撞车）
圆上的点投影到 x 轴[−1,1](0.5,±0.87) 投到同一点满、不单
f(x)=sinx,[−π2,π2]→[−1,1][−1,1]不撞车既满又单，是一一映射

这张表说明：满射和单射是两个互相独立的问题。一个映射可以满而不单，也可以单而不满；只有两者同时成立，才能“倒过来”仍然是一个合法的映射。这就引出了逆映射。

1.3 逆映射与复合映射：倒过来、接起来

“倒过来”不是把箭头简单反过来就行了。若 f 不是单射，两个不同的 x 都可能对应同一个 y，那么从 y 倒推时就不知道该回哪一个 x。所以逆映射的门票是单射。

定义 · 逆映射

设 f:X→Y 是单射。则对每一个 y∈Rf，都存在唯一的 x∈X 使 f(x)=y。于是可以定义一个新的映射

f−1:Rf→X

称它为 f 的逆映射。注意它的定义域是 Rf（原映射的值域），值域是 X（原映射的定义域），刚好交换过来。

“接起来”也有门槛：里层函数吐出来的东西，外层函数必须全都认得。记 g 的值域为 Rg、f 的定义域为 Df，则复合 f(g(x)) 有意义的前提是

Rg⊆Df
第二个坑：判断复合不能只看表达式

“写得出表达式”和“是一个合法映射”是两码事。例如 g(x)=2x2、f(u)=1−u，代进去能写成 1−2x2，但当 |x|>22 时根号里为负，g 吐出来的值 f 接不住。复合映射要求 X 中的每一个元素都能走完两步，所以必须检查 Rg⊆Df，而且方向不能反。

2. 函数：把“关系”变成可计算的对象

2.1 函数的定义与两要素

把映射的两个集合都换成数集，就得到函数。它是整章出现频率最高的对象：后面所有的极限、连续、导数，都是在函数身上做文章。

定义 · 函数

设数集 D⊆R。如果 f 是从 D 到 R 的一个映射，就称 f 是函数，记作

y=f(x),x∈D

其中 x 叫自变量，y 叫因变量，D 叫定义域（记作 Df），Rf={f(x)∣x∈D} 叫值域。

课本有时写“三要素”：定义域、对应法则、值域。但本质上是两要素：定义域 Df 与对应法则 f。因为只要这两者定了，值域就被唯一确定，多写一个只是重复。判断两个函数是否相同，也只看定义域与对应法则是否都相同。

四个入门例子能把“定义域、值域、分段、图像”一次练熟：

  • y=2：式子里没有 x，所以 x 可以随便取，定义域是 (−∞,+∞)；函数值永远是 2，值域是集合 {2}。注意值域要写成集合，不能只说“值域是 2”。
  • y=|x|：定义域是 (−∞,+∞)，值域是 [0,+∞)。它的图像是把负半轴翻上去。
  • 符号函数 sgn(x)：x>0 取 1，x=0 取 0，x<0 取 −1。定义域是 R，值域是 {−1,0,1}。
  • 取整函数 [x]：不超过 x 的最大整数。定义域是 R，值域是全体整数。它的图像是阶梯，每个台阶左端实心、右端空心。

为什么要在第一章就提符号函数和取整函数？因为它们是最好的“反例仓库”：符号函数在 0 处跳跃，取整函数在每个整数处跳跃，后面讲间断点和左右极限时都会用到；取整函数还会出现在 ε–N 证明的取整步骤里。

2.2 四把尺子：有界、单调、奇偶、周期

这四条性质不是四段需要背的文字，而是描述函数图像的四种几何特征。共同点是：每一条都必须先指定范围。脱离范围谈“有界”“单调”，就像脱离温度谈“冷热”，没有意义。

有界性：图像能不能被两条水平线框住

直观上，有界就是存在一对水平线 y=M 与 y=−M，让整段图像都夹在中间。精确地说：

定义 · 上界 / 下界 / 有界

设 X⊆D。若存在 K1 使对一切 x∈X 有 f(x)≤K1，则 K1 是 f 在 X 上的一个上界；若存在 K2 使 f(x)≥K2，则 K2 是一个下界。

若存在 M>0 使对一切 x∈X 有 |f(x)|≤M，则 f 在 X 上有界；否则无界。

有界等价于“既有上界又有下界”。证明只有一句话：若 |f(x)|≤M，则 −M≤f(x)≤M；反过来，若有上界 M1、下界 M2，取 M=max{M1,|M2|}，就能把两边合成 |f(x)|≤M。上界、下界、M 都不唯一：sinx 满足 |sinx|≤1，也满足 |sinx|≤2。

同一个函数，换个区间有界性就变了

f(x)=1x 在 (0,1) 上有下界（图像在 x 轴上方），但没有上界——你画再高的线，靠近 0 时函数值都能突破，所以它在 (0,1) 上无界。换到 (1,2) 上，函数值落在 (12,1) 之间，既有上界又有下界，于是有界。这就是“必须先指定范围”的铁证。

单调性：区间不能省

设 I⊆D 是一个区间。若对 I 上任意 x1<x2 都有 f(x1)<f(x2)，叫单调增；都有 f(x1)>f(x2)，叫单调减。y=x2 在整个实数上不单调，但在 (−∞,0] 上单调减、在 [0,+∞) 上单调增。说“x2 是单调函数”是不准确的，必须带上区间。

奇偶性：先看定义域是否对称

对一切 x∈D，若 f(−x)=f(x) 则 f 为偶函数，图像关于 y 轴对称；若 f(−x)=−f(x) 则为奇函数，图像关于原点对称。这里有一个前置条件：定义域必须关于原点对称。x2 在 [−1,2] 上既不是奇函数也不是偶函数，因为定义域不对称，−x 可能根本不在定义域里。

还有一个常用的构造：任一在对称定义域上的函数，都可以拆成“偶函数 + 奇函数”：

f(x)=f(x)+f(−x)2+f(x)−f(−x)2

前一半是偶函数，后一半是奇函数。这个式子说明奇偶性不是函数的“标签”，而是一种可以分解的结构。

周期性：周期不一定有最小正周期

若存在 T>0，使对一切 x∈D 都有 f(x+T)=f(x)，则 T 是一个周期。sinx、cosx 的周期是 2π，tanx、cotx 的周期是 π。但“周期函数”不保证有最小正周期：狄利克雷函数（有理数取 1、无理数取 0）以任意正有理数为周期，而有理数可以任意小，所以它没有最小正周期。这是周期性里最反常识的例子。

性质直观含义关键条件典型反例
有界图像被上下两条水平线框住先指定区间 X1x 在 (0,1) 无界，在 (1,2) 有界
单调图像一直上升或一直下降先指定区间x2 在整个 R 上不单调
奇偶关于 y 轴或原点对称定义域关于原点对称x2 在 [−1,2] 上非奇非偶
周期图像按固定长度重复周期不唯一狄利克雷函数无最小正周期

2.3 反函数：什么时候可以倒过来

函数把 x 送到 y。反函数想反过来，把 y 送回 x。但“送回去”必须是唯一的，所以原函数必须单射。这就是上一节映射里的结论，只不过现在两个集合都是数集。

定义 · 反函数

若 f:D→Rf 是单射，则对每个 y∈Rf，存在唯一的 x∈D 使 f(x)=y。由此定义

f−1:Rf→D,x=f−1(y)

称 f−1 为 f 的反函数。它的定义域是原函数的值域，值域是原函数的定义域。

几何上，反函数与原函数的图像关于直线 y=x 对称。因为点 (a,b) 在原函数上，等价于点 (b,a) 在反函数上，而 (a,b) 与 (b,a) 正是关于 y=x 的对称点。判断一个函数有没有反函数，也可以用“横线法则”：任意一条水平线与图像至多一个交点。

例：y=2x−3。由 y=2x−3 解出 x=y+32，交换字母得 y=x+32。定义域和值域都是 R。这不是“把 x 和 y 换个位置”那么简单，背后是“单射保证倒推唯一”。

2.4 复合函数：什么时候可以接起来

复合函数是把一个函数的输出接到另一个函数的输入上。合法性条件仍然是 Rg⊆Df。这里最容易犯的错，是只检查“表达式写不写得出来”，不检查“定义域接不接得上”。

例：y=u，u=tanx。要使复合有意义，必须 tanx≥0，即 x∈[kπ,kπ+π2)（k∈Z）。如果只看表达式 y=tanx，似乎没问题；但定义域已经被 tanx≥0 砍掉了许多。

反例：g(x)=2x2，f(u)=1−u。代进去得到 1−2x2，但当 |x|>22 时根号内为负，g 的输出落到了 f 的定义域外面。所以这两个函数不能在整个 R 上复合，只能在 |x|≤22 上复合。

2.5 函数的四则运算与一个构造题

两个函数可以做和、差、积、商。前三种的定义域取交集；商还要额外要求分母不为零。这些运算看起来简单，但后面极限的四则运算法则，本质上就是把这些运算搬到“极限”上。

一个常考的构造题：证明任一在对称定义域上的函数都能拆成偶函数与奇函数之和。上面的拆分式已经给出答案。它的价值不在于计算，而在于说明“奇偶性”是一种结构，而不是所有函数非黑即白的标签。

3. 初等函数：搭乐高的零件

3.1 六类基本初等函数

初等函数是本章的“工具箱”。后面判断连续性、求极限、做导数，绝大多数对象都是初等函数。它们由六类基本初等函数经过有限次四则运算与复合得到：常函数、幂函数、指数函数、对数函数、三角函数、反三角函数。

3.2 课程补充：cot、sec、csc

高中对 cotx、secx、cscx 讲得少，但大学里经常出现。它们都只是“换个写法”：

cotx=cosxsinx=1tanx,secx=1cosx,cscx=1sinx

定义域只看分母：tanx、secx 的分母是 cosx，所以要挖掉 x=π2+kπ；cotx、cscx 的分母是 sinx，所以要挖掉 x=kπ。cotx 的周期是 π，特殊值：cot30∘=3，cot45∘=1，cot60∘=33。

3.3 反三角函数：主值区间为什么不能随便改

三角函数是周期函数，整个定义域上不单射，所以不能直接反。办法是“砍一段”：在每个周期里选一段单调区间，让函数在这段上既单调又走满原来的值域。这段区间叫主值区间。

反函数定义域值域（主值区间）单调性 / 奇偶性
arcsinx[−1,1][−π2,π2]增，奇函数
arccosx[−1,1][0,π]减，非奇非偶
arctanxR(−π2,π2)增，奇函数
arccotxR(0,π)减，非奇非偶

主值区间不能随便改。比如 sin5π6=12，但 arcsin12 不能写成 5π6，因为 5π6 不在 [−π2,π2] 里。正确的值是 π6。特殊值要能反推：arcsin12=π6，arccos12=π3，arctan1=π4，arccot1=π4。遇到 arcsin13 这种非特殊角，保持原样即可，不要硬凑。

3.4 分段函数与初等函数的边界

“初等函数”的判据不是“看起来是不是分段”，而是“能不能用一个解析式统一表示”。|x| 看起来分段，但 |x|=x2，是一个式子，所以它是初等函数。取整函数 [x] 由无穷多段拼成，无法用一个解析式统一表示，所以它不是初等函数；符号函数 sgn(x) 同理。

分段函数一般不是初等函数，但 |x| 是例外

判据只有一条：能不能“一个式子”写完。能，就是初等函数；必须分段列且无法统一，一般就不是。注意“一般”两个字：|x| 这样的分段函数仍然是初等函数。

为什么要在意这个归类？因为后面有一个重要结论：初等函数在其定义域内连续。如果知道一个函数是初等函数，求极限时往往可以直接代入；而分段函数在分界点必须单独检查左右极限，不能直接套这个结论。

4. 为什么需要极限：从“趋势”到一句可检验的话

有了函数，下一步自然要问：当自变量变化时，函数值会怎样？很多问题不能只看某一个点，而要看“越来越接近”的过程。比如

an=1n:1,12,13,14,…

直觉上它“越来越接近 0”。但“越来越接近”这句话不能直接拿来证明或计算：接近多少算接近？前几项离得远要不要紧？如果一个数列一会儿靠近 0、一会儿又跳回 1，它算不算“越来越接近 0”？

极限的任务，就是把“越来越接近”翻译成一句可以逐字检查的话。做法不是规定一个固定的“很近”，而是让质疑者先报一个任意小的容许误差 ε，我们再去证明：从某一项开始，后面所有项都落在这个误差范围内。

核心思想 · 用有限管住无限

“从某一项开始，后面所有项都满足”这句话，等价于“不满足的项只有有限个”。极限定义真正抓住的，就是这种“带外只剩有限项、带内有无穷多项”的不对称。

图上取 ε=0.35，在 A=0 上下画一条误差带。前几项站在带外，但从某一项起，后面的点全部进入带内，再也出不去。ε 取得越小，带子越窄，需要往右挪的“起点”就越远；但无论 ε 多小，这个起点总是存在的。

为什么先讲数列，再讲函数？因为数列的自变量是 n=1,2,3,…，只有“往后走”一个方向，最单纯。把这件事说清楚之后，再把“第 N 项之后”换成“x0 旁边多大一个邻域”，就是函数极限。

5. 数列极限：ε–N 定义

5.1 定义与五个零件

定义 · 数列的极限

设 {xn} 是一个数列，A 是一个常数。如果对任意给定的正数 ε>0，总存在正整数 N，使得当 n>N 时，都有

|xn−A|<ε

则称 A 是数列 {xn} 的极限，也称数列收敛于 A，记作

limn→∞xn=A或xn→A(n→∞)

如果这样的常数 A 不存在，就说数列发散。

这个定义里有五个零件，逐个看：

  1. 任给 ε>0：误差是别人报的，多小都要接住。不是“存在一个很小的 ε”，而是“对任何 ε 都能做到”。
  2. 存在 N：N 是我们找的，而且只需要找到一个。它通常依赖于 ε，ε 越小，N 一般越大。
  3. 当 n>N：只要求第 N 项之后，前面的有限项不管。这正是“有限管住无限”的落点。
  4. |xn−A|<ε：xn 落在 A 的 ε 邻域 (A−ε,A+ε) 内，而且是两侧对称的。
  5. A 是常数：极限必须是一个有限的数，不能是 n 的函数，也不能是 ∞。

5.2 关于 N 的两个细节

N 不唯一。定义只要求“存在一个”，没要求“唯一”。用 ε=0.01 算出的 N 够用，把它换成 100N 当然更够用。所以考试时不必纠结自己的 N 和答案不一样；不一样很正常，尤其是用了放缩之后——放缩牺牲精确度，换来的是算式干净。

N 只能往大取，不能往小取。如果从第 N 项开始所有项都在带内，那么从第 N+1 项、第 N+5 项开始当然也在；但往前推到第 N−3 项就未必，因为 N 前面可能正好有落在带外的项。做题时宁可把 N 取大一点、式子糙一点，也不要为了“精确”取小。

5.3 用定义证明极限：四步模板

方法 · 数列极限证明四步
  1. 猜 A：看通项随 n 增大的趋势，先猜出极限值。
  2. 草稿倒推：从 |xn−A|<ε 出发，反解出 n 需要大于什么。
  3. 取 N：把临界的那个量取整加一，保证 N 是正整数。
  4. 卷面正写：任给 ε>0，取上述 N，当 n>N 时推导 |xn−A|<ε。

例 1：证明 limn→∞1n=0。

草稿：要 |1n−0|=1n<ε，只需 n>1ε。所以取 N=[1ε]+1（[⋅] 为取整）。

正写：任给 ε>0，取 N=[1ε]+1。当 n>N 时，n>1ε，于是

|1n−0|=1n<ε

故 limn→∞1n=0。这个模板要练到不用想就能写。

例 2：证明 limn→∞n+(−1)n−1n=1。

先看趋势：分子是 n 加一个有界项，除以 n 后趋于 1。计算

|n+(−1)n−1n−1|=|(−1)n−1n|=1n

又回到例 1。任给 ε>0，取 N=[1ε]+1，当 n>N 时上式小于 ε，故极限为 1。这里的关键是：绝对值把 (−1)n−1 的符号吃掉了，问题立刻简化。

例 3：证明 limn→∞(−1)n(n+1)2=0。

直接估计绝对值：

|(−1)n(n+1)2|=1(n+1)2<1n2

而 1n2→0。要严格写，可以任给 ε>0，取 N=[1ε]+1，当 n>N 时 1n2<ε。也可用夹逼准则：0≤1(n+1)2≤1n2，两头都趋于 0。这类题的关键是“先放大成好算的上界”，不必死抠原式。

例 4：设 0<|q|<1，证明 limn→∞qn−1=0（q=0 时显然成立）。

要 |q|n−1<ε。两边取对数，注意 |q|<1 时 ln|q|<0，除以负数要变号：

(n−1)ln|q|<lnε⟹n>1+lnεln|q|

这里有一个细节：如果 ε≥1，lnε≥0，上面的符号讨论会乱。可以合法地写“不妨设 0<ε<1”——因为 ε 很大时带子很宽，反而更容易满足；我们只需要对付“ε 很小”的困难情形。取

N=[1+lnεln|q|]+1

当 n>N 时，|q|n−1<ε，故极限为 0。这道题的两个坑是：忘记“不妨设 ε<1”，以及除以 ln|q| 时忘记变号。

5.4 什么情况下不能直接套定义

定义证明适合“已知极限、要严格验证”的题。考试里更常见的是计算题，那就轮到后面的运算法则、存在准则和等价无穷小。定义的作用有两个：一是把“收敛”这个概念钉死，二是给性质定理提供证明工具。不要把它当成唯一解法。

6. 收敛数列的四条性质：收敛能“送”给我们什么

如果已经知道一个数列收敛，但不想每次都用定义，能不能直接推出一些结论？这就是性质定理的作用。它们都不需要算出极限值，只需要知道“极限存在”。

6.1 唯一性：极限只能有一个

定理 · 极限的唯一性

若数列 {xn} 收敛，则它的极限唯一。

证明用反证法。假设同时有 limxn=A 与 limxn=B，且 A<B。取

ε=B−A2

这个数正好是 A、B 距离的一半。由 xn→A，存在 N1，当 n>N1 时 xn<A+ε=A+B2；由 xn→B，存在 N2，当 n>N2 时 xn>B−ε=A+B2。取 N=max(N1,N2)，当 n>N 时，同一个 xn 既小于中点又大于中点，矛盾。

证明的关键不是“取 ε”，而是“取一个刚好让两条误差带分开的 ε”。ε 取大了，两条带重叠，什么也证不出来；取小了，还要补一句“缝里的项哪条都不满足”。B−A2 刚好让两条带在中点相接，最省事。

6.2 有界性：收敛一定有界，有界不一定收敛

定理 · 收敛数列必有界

若数列 {xn} 收敛，则它一定有界。

证明思路：取 ε=1，存在 N，当 n>N 时 |xn−A|<1，于是 |xn|<|A|+1。前面的 N 项（x1,…,xN）是有限个数，取它们的绝对值最大值 M1。再令 M=max{M1,|A|+1}，则对一切 n 都有 |xn|≤M。

这个证明体现了“有限项好办，无限项用极限控制”的典型思路。逆否命题同样好用：无界一定发散。例如 n、n2 都无界，所以发散。

最容易被记反的一点：有界推不出收敛

xn=(−1)n+1 有界（|xn|=1），但它在 1 与 −1 之间跳，不收敛。所以“有界”只是收敛的必要条件，不是充分条件。三句话要连起来记：收敛 ⇒ 有界；无界 ⇒ 发散；有界 ⇒ 收敛。

6.3 保号性：极限的正负会传给尾部

定理 · 保号性

若 limxn=A>0，则存在正整数 N，当 n>N 时 xn>0。若 A<0，则存在 N，当 n>N 时 xn<0。

推论：若从某项起恒有 xn≥0，且极限 A 存在，则 A≥0；若从某项起 xn≤0，则 A≤0。

证明只需取 ε=A2（A>0）。当 n>N 时，xn>A−A2=A2>0。几何上，极限点离 0 有一段正距离，取足够窄的邻域，整个邻域都在 x 轴上方，尾部的项自然都为正。

严格正推不出严格正

从某项起 xn>0，只能推出 A≥0，不能推出 A>0。反例：1n>0 恒成立，但极限是 0。保号性保的是“方向”，不是“距离”；极限可以正好压在 0 上。

6.4 子列：从原数列里抽一部分

从数列 {xn} 中抽取无限多项，并保持这些项原来的先后顺序，得到的新数列叫子列。注意两条：必须抽无限多项；顺序不能乱。

母列与子列的五条关系
  1. 母列收敛于 A，则任意子列也收敛于 A。
  2. 某一个子列发散，则母列一定发散。
  3. 两条子列都收敛但极限不同，则母列发散。
  4. 发散数列也可以有收敛的子列。
  5. limxn=A 的充要条件是：奇数项子列与偶数项子列都收敛，且都收敛于 A。

这些关系最重要的用途是判发散。例：证明 xn=(−1)n+1 发散。抽奇数项得 1,1,1,…→1，抽偶数项得 −1,−1,−1,…→−1。两条子列极限不同，由第 3 条，母列发散。

但要注意第 4 条：发散数列也可以有收敛的子列。所以“找到一条收敛的子列”不能证明母列收敛，只能说明这一条子列乖。这与下一节“函数极限与数列极限的桥”是同一个逻辑陷阱。

7. 函数极限：把“第 N 项之后”换成“邻域”

7.1 为什么函数极限更复杂

数列极限只让 n 往大了走，方向单一。函数极限让 x 逼近 x0，可以从左边来，也可以从右边来；而且 x 永远不等于 x0，x0 处有没有定义都不影响极限。这两件事——两侧与去心——是函数极限的新内容。

先备两个概念：x0 的 δ 邻域是 (x0−δ,x0+δ)；去心邻域是 (x0−δ,x0)∪(x0,x0+δ)，也就是把中心点 x0 抠掉。函数极限只关心去心邻域。

7.2 ε–δ 定义与几何读法

定义 · 函数极限 limx→x0f(x)=A

设函数 f(x) 在 x0 的某去心邻域内有定义。若对任意 ε>0，总存在 δ>0，使得当

0<|x−x0|<δ

时，都有

|f(x)−A|<ε

则称当 x→x0 时 f(x) 的极限为 A，记作 limx→x0f(x)=A。

几何上，这个定义是一个“横带—竖带”的游戏：你在 A 上下画一条高 2ε 的横带，我必须在 x0 左右找一条宽 2δ 的竖带，使得竖带里的曲线段（去掉中心点）整段都落在横带内。顺序不能反：先有 ε，后有 δ；δ 是“找”出来的，通常依赖于 ε。

五个零件与数列极限一一对应：ε 对应误差，δ 对应“多远算近”，0<|x−x0|<δ 对应“x 在 x0 附近且不等于 x0”，|f(x)−A|<ε 对应“函数值在 A 附近”，A 是有限常数。把数列的“第 N 项之后”换成“x0 的去心邻域”，逻辑完全一样。

例 1：证明 limx→1(2x−1)=1。

要 |(2x−1)−1|=2|x−1|<ε，只需 |x−1|<ε2。取 δ=ε2。任给 ε>0，当 0<|x−1|<δ 时，|f(x)−1|<ε，故极限为 1。

例 2：证明 limx→1x2−1x−1=2。

在去心邻域内 x≠1，可以约分：x2−1x−1=x+1。于是 |f(x)−2|=|x−1|。取 δ=ε，当 0<|x−1|<δ 时 |f(x)−2|<ε。这里“约分合法”的根据正是“x≠1”，不是“x=1 时也成立”。

7.3 左极限、右极限与充要条件

从左边逼近记作 x→x0−，从右边逼近记作 x→x0+。注意那个“−”“+”是方向标记，不是 −1 次方，也不是加一减一。左极限的定义只是把 0<|x−x0|<δ 换成 x0−δ<x<x0；右极限换成 x0<x<x0+δ。

定理 · 左右极限充要条件

limx→x0f(x) 存在，当且仅当左极限与右极限都存在且相等：

limx→x0f(x)=A⟺limx→x0−f(x)=limx→x0+f(x)=A

例：设

f(x)={x−1,x<00,x=0x+1,x>0

在 x=0 处，左极限 limx→0−(x−1)=−1，右极限 limx→0+(x+1)=1。两者不等，所以 limx→0f(x) 不存在。注意 f(0)=0 在这里完全不影响结论——极限只看去心邻域。

7.4 x→∞ 的极限与水平渐近线

x→∞ 表示 |x| 无限增大，包含 x→+∞ 与 x→−∞。定义把 δ 换成 X：

定义 · limx→∞f(x)=A

对任意 ε>0，总存在 X>0，使得当 |x|>X 时，都有 |f(x)−A|<ε。则称 x→∞ 时 f(x) 的极限为 A。

若 limx→∞f(x)=b（或 x→−∞ 时），则直线 y=b 是曲线 y=f(x) 的水平渐近线。例如 limx→∞1x=0，所以 y=0（即 x 轴）是 1x 的水平渐近线。写法上要说“直线 y=0”，不能只说“0 是渐近线”。

8. 函数极限的局部性质与数列桥

8.1 为什么每条性质都带“局部”

函数极限只约束 x0 附近，不约束整个定义域。所以能推出的性质也都是“局部的”：局部有界、局部保号。理解这一点，就不会把“局部有界”误当成“整个函数有界”。

定理 · 函数极限的三条局部性质

唯一性：若极限存在，则唯一。

局部有界性：若 limx→x0f(x)=A 存在，则存在 M>0 与 δ>0，使得当 0<|x−x0|<δ 时，|f(x)|≤M。

局部保号性：若 limx→x0f(x)=A>0，则存在 δ>0，使得当 0<|x−x0|<δ 时，f(x)>0；若 A<0，则在该去心邻域内 f(x)<0。

局部有界的证明与数列有界性同构：取 ε=1，存在 δ，邻域内 |f(x)|<|A|+1。局部保号取 ε=A2，邻域内 f(x)>A−A2=A2>0。这里还有一个常用的加强版：A>0 时，邻域内不仅有 f(x)>0，还有 f(x)>A2。证明不等式时经常用到。

去掉“极限存在”这个前提，性质立刻崩

limx→01x 不存在，f 在 0 附近无界；分段函数在 0 处左右极限不同，极限不存在，也就谈不上“局部保号”。性质的前提不是装饰，是承重墙。

8.2 函数极限与数列极限的桥

定理 · 函数极限 ⇒ 数列极限

若 limx→x0f(x)=A 存在，且 {xn} 是 f 定义域内满足 xn→x0、xn≠x0 的数列，则

limn→∞f(xn)=A

这个定理把“连续逼近”化成了“离散抽样”：函数极限存在，那么无论沿哪条数列逼近 x0，函数值都必须趋于同一个 A。它最常用的地方是证明极限不存在：只要找到两条数列，函数值趋于不同的数，就能下结论。

经典反例：f(x)=sin1x，x→0。取 xn=1nπ，f(xn)=sin(nπ)=0→0；取 yn=12nπ+π2，f(yn)=1→1。两条数列给出的极限不同，所以 limx→0sin1x 不存在。

反过来不成立

不能因为“找到一条数列 xn→x0 使 f(xn) 收敛”，就断定函数极限存在。这就像“班里挑出几个同学都是女生”，不能推出“全班都是女生”。正向定理只能用来证存在（沿任意数列同极限），反向使用只能用来证不存在（找两条数列给不同极限）。

9. 无穷小与无穷大：极限语言的两种极端

9.1 无穷小：趋于零的变量，不是很小的数

定义 · 无穷小

若在某一变化过程中 limf(x)=0，则称 f(x) 为该过程下的无穷小量，简称无穷小。数列也照此办理：若 limn→∞xn=0，就称 {xn} 是 n→∞ 时的无穷小。

无穷小必须说明“在哪个过程中”。x2 在 x→0 时是无穷小，在 x→1 时不是；1x 在 x→∞ 时是无穷小，在 x→0 时不是。它不是“一个很小的常数”，而是一个正在趋于零的变量。0.0001 很小，但它固定不动，不是无穷小；−∞ 更不是无穷小，它离 0 越来越远。

定理 · 极限 = 常数 + 无穷小

limf(x)=A 的充要条件是：存在同一变化过程下的无穷小 α，使得

f(x)=A+α(x)

这个定理把“极限”拆成了“常数 + 误差”。它很好用：要证极限为 A，只要证 f(x)−A 是无穷小。后面的等价无穷小、泰勒公式，本质上都是在研究这个“误差”有多大、是什么阶。

9.2 无穷大：极限不存在的一种方式

定义 · 无穷大

若在某一变化过程中 |f(x)| 无限增大，则称 f(x) 为该过程下的无穷大，记作 limf(x)=∞。类似地可以定义 +∞ 与 −∞。

“极限是无穷大”其实属于极限不存在

严格地说，极限存在专指极限是一个有限常数。∞ 不是数，所以“极限为 ∞”只是描述发散的方式：它发散了，而且是无界地增大。看到“极限是无穷大”，脑子里要自动翻译成“它发散，且发散的方式是无限增大”。

定理 · 无穷大与无穷小互为倒数

在同一变化过程中：若 f(x) 是无穷大，则 1f(x) 是无穷小；若 f(x) 是无穷小且 f(x)≠0，则 1f(x) 是无穷大。

倒数关系要求 f(x)≠0。无穷小可以取到 0（如常数 0），但常数 0 的倒数没有意义；所以定理里要加这个条件。

9.3 无穷小的运算：哪些有结论，哪些没有

性质 · 无穷小的运算

在同一变化过程中：有限个无穷小之和仍是无穷小；有限个无穷小之积仍是无穷小；有界函数与无穷小之积仍是无穷小（推论：常数乘无穷小仍是无穷小）。

“有限个”三个字不能丢。把 1n 重复加 n 次：

1n+1n+⋯+1nn 个=1

每一项都是无穷小，但项数本身也在随 n 增大，和恒等于 1，不再是无穷小。无穷多个无穷小之和，结果不确定，必须具体分析。

另一个常见结论是“有界 × 无穷小 = 无穷小”。例如 limx→0xsin1x=0：sin1x 有界，x 是无穷小。limx→∞sinxx=0 同理。

9.4 无界不等于无穷大

无穷大要求“充分靠后以后，所有值都大于任意给定的 M”；无界只要求“总能找到一个点超过 M”。后者可以反复回到 0。经典反例：

f(x)=xsinx,x→∞

取 xn=2nπ+π2，f(xn)=xn→+∞，所以它无界；取 yn=2nπ，f(yn)=0，所以它又反复回到 0，不是无穷大。

10. 极限运算法则：什么时候能把极限拆开

定义能证明极限，却不能快速算出极限。如果每道题都回到 ε–N 或 ε–δ，效率太低。于是需要一套“把已知极限组合成新极限”的规则。但规则不是无条件可用的，最关键的一条是：拆分之前，先确认每一部分的极限都存在。

10.1 四则运算法则：先存在，后拆分

定理 · 极限的四则运算

若 limf(x)=A、limg(x)=B 都存在，则

lim[f(x)±g(x)]=A±B
lim[f(x)g(x)]=AB
limf(x)g(x)=AB(B≠0,g(x)≠0)

数列极限也有完全相同的四则运算法则。

这个定理的读法是“极限可以分配进去”，但分配的对象必须是已经存在的极限。如果拆开之后发现某一部分的极限不存在，不是定理错了，而是你根本不该拆。典型反例：

limx→0(1x−1x)=0

整个式子恒等于 0，极限当然是 0；但如果你拆成 lim1x−lim1x，两个极限都不存在，就成了 ∞−∞，没有意义。这说明“先拆再算”不是万能动作，必须先检查前提。

例 1：limx→1(2x−1)=2⋅1−1=1。这是直接代入，因为 2x−1 是初等函数，在 x=1 处连续。

例 2：limx→3x−3x2−9。直接代入得 00，不能直接算。约分：

x−3x2−9=x−3(x−3)(x+3)=1x+3(x≠3)

于是极限为 13+3=16。约分合法的根据是“x→3 时 x≠3”，不是“x=3 时也成立”。这正是极限与函数值分离的体现。

10.2 x→∞ 的多项式商：抓大头

当分子、分母都是多项式，且 x→∞ 时，低次项在最高次项面前可以忽略。把分子分母同除以分母的最高次幂，就能看出结果只取决于“谁的最高次更高”。

结论 · 抓大头

设分子最高次为 m、分母最高次为 n，最高次项系数分别为 a0、b0（都不为零），则

limx→∞a0xm+⋯b0xn+⋯={a0b0,m=n0,m<n∞,m>n

更准确地说，m>n 时极限为 ±∞，符号由 a0b0 的符号决定；说“趋于无穷”时，重点是无界，不是某个固定的正方向。

记忆方法：同次看系数比；分母次数高，分母增长更快，整体趋于 0；分子次数高，分子增长更快，整体无界。这个结论只适用于 x→∞ 的多项式商。如果 x→ 常数，直接代入或约分，不能套“同次系数比”。

例 3：

limx→∞3x3+4x2+27x3+5x2−3x=37

分子分母都是三次，取最高次项系数比。低次项在 x→∞ 时都趋于 0，不影响结果。

10.3 有界 × 无穷小：又一条常用结论

由上一节的“有界函数乘无穷小仍是无穷小”，立刻得到

limx→∞sinxx=0,limx→0xsin1x=0

这两个极限都不能用四则运算拆，因为 sinx、sin1x 在相应过程中没有极限。但“有界 × 无穷小”直接给出答案。看到“震荡但有界”乘上“趋于零”的因子，优先想这条。

11. 极限存在准则与两个重要极限

有些极限用四则运算和抓大头都算不出来，甚至一时看不出它到底存不存在。这时需要“存在性”的工具：先证明极限一定存在，再想办法求值。两条准则负责“存在”，两个重要极限负责“等于几”。

11.1 夹逼准则：被两头夹住，只能跟着走

准则 · 夹逼准则

若在某个过程中（或对充分大的 n）有

xn≤yn≤zn

且两头的极限相同：limxn=limzn=A，则中间的极限也存在，且 limyn=A。函数极限有完全类似的版本。

夹逼准则的关键不是“夹住”，而是“两头要收敛到同一个值”。如果一头趋于 1、另一头趋于 5，中间的项就不知道该跟谁走，结论不成立。使用时通常要做两件事：找到合适的上下界；证明上下界的极限相等。

11.2 第一重要极限：sin x / x → 1

定理 · 第一重要极限
limx→0sinxx=1

更一般地，只要 □→0 且 □≠0，就有 lim□→0sin□□=1。

这个极限的几何来源是面积夹逼。在单位圆中，设圆心角为 x（0<x<π2），比较三个图形的面积：

12sinx<12x<12tanx

约去 12，再同除以 sinx，得到

1<xsinx<1cosx

取倒数（正数取倒数要变号）：

cosx<sinxx<1

当 x→0+ 时 cosx→1，两头都趋于 1，由夹逼准则得 sinxx→1。x→0− 时利用 sinxx 是偶函数，同理。这就是第一重要极限的完整思路。

它的用法不是只会算 sinxx，而是“凑形状”：只要分子是 sin 的某个整体，分母是同一个整体，且整体趋于 0，极限就是 1。

例 1：limx→0tanxx=limx→0sinxx⋅1cosx=1⋅1=1。

例 2：limx→01−cosxx2。用 1−cosx=2sin2x2：

1−cosxx2=2sin2x2x2=12(sinx2x2)2→12

例 3：limx→0arcsinxx。令 t=arcsinx，则 x=sint，t→0，原式变为 tsint→1。这就是“换元把不认识的整体变成认识的整体”。

sin x / x 只在整体趋于 0 时等于 1

limx→∞sinxx=0，不是 1。因为此时 sinx 有界，1x 是无穷小，用“有界 × 无穷小”得到 0。看到 sin□□，第一件事是确认 □→0；不是，就换工具。

11.3 单调有界准则与第二重要极限

准则 · 单调有界准则

单调递增且有上界的数列必有极限；单调递减且有下界的数列必有极限。它只保证极限存在，不直接给出极限值。

第二重要极限就是这条准则的产物。考虑数列

an=(1+1n)n

它可以证明单调递增，并且有上界 3（把二项式展开后逐项放大，得到一列等比级数的和小于 3）。由单调有界准则，an 收敛。这个极限值被定义为 e：

e=limn→∞(1+1n)n≈2.71828

把数列换成连续变量，三种写法都等于 e：

limn→∞(1+1n)n=limx→∞(1+1x)x=limx→0(1+x)1/x=e

它的形状模板是：底数是 1 加一个趋于 0 的整体 □，指数是 1□。口诀：底数里是啥，指数就凑它的倒数。底数里是加号还是减号都无所谓，关键是“1 + 无穷小”。

例 4：limx→∞(1−1x)x。把 −1x 记作 □，则指数要凑 −x：

(1−1x)x=[(1+□)1/□]−1→e−1

例 5：limn→∞(1−3n)5n。底数里的整体是 −3n，它的倒数是 −n3；指数 5n 要拆成 −n3⋅(−15)，所以极限为 e−15。

“1 的无穷次方”不是 1

底数趋于 1、指数趋于无穷，直觉容易觉得“1 的任何次方都是 1”。但底数不是恒等于 1，而是“比 1 多一点”或“比 1 少一点”，这个“一点”被无穷次方放大，结果可以是 e、e−1、e2 等。判断是不是这种型，先看底数是否趋于 1、指数是否趋于无穷；是，才考虑凑第二重要极限。

12. 无穷小的比较与等价替换

00 型极限的核心问题不是“都是零”，而是“谁趋于零更快”。x2 比 x 趋于零快，1−cosx 比 x 趋于零快，sinx 与 x 几乎一样快。把这些“速度”量化，就能把复杂的极限化成简单的比。

12.1 五个阶的定义

设 α,β 是同一变化过程中的无穷小，且 α≠0。看比值 βα：

比值名称记号直观
βα→0β 是比 α 高阶的无穷小β=o(α)β 趋于零更快
βα→∞β 是比 α 低阶的无穷小—β 趋于零更慢
βα→C≠0同阶无穷小—速度相当，差一个倍数
βα→1等价无穷小α∼β速度几乎一样
βαk→C≠0β 是 α 的 k 阶无穷小—用 αk 去比

例子：x→0 时，x2=o(x)（高阶）；x 是 x2 的低阶；sinx 与 x 同阶且等价；1−cosx 是 x 的二阶无穷小，因为 1−cosxx2→12。

定理 · 等价的另一种写法

β∼α 的充要条件是

β=α+o(α)

也就是说，β 与 α 只差一个“比 α 高阶的无穷小”。

o(α) 不是一个零

o(α) 表示“比 α 高阶的无穷小”，它本身是一个变量，不是 0。说 β=α+o(α)，意思是“主部是 α，剩下的误差比 α 小一个量级”，不是“β=α”。这也是等价替换不能乱用的根源：误差虽然小，但在加减法中可能被放大。

以下全部在 x→0 时成立：

带负号的版本不用另背：判断“谁减谁”，符号自然出来。cosx≤1，所以 1−cosx≥0；ex−1 在 x>0 时为正，1−ex 为负。记住主部，符号由大小关系决定。

12.3 替换定理与铁律

定理 · 等价无穷小替换

设在同一变化过程中 α∼α'、β∼β'，且 limβ'α' 存在，则

limβα=limβ'α'

定理只保证“商的分子、分母整体替换”合法。也就是说，α、β 各自必须是一个完整的因子。加减项不是因子，替换之后各自的误差不会被约掉，可能改变结果。

铁律：乘除能换，加减不能换

反例：limx→0tanx−sinxx3。如果直接把 tanx 换成 x、sinx 换成 x，分子变成 0，得到 0——这是错的。正确做法是先提公因式：

tanx−sinx=tanx(1−cosx)∼x⋅x22=x32

所以原极限为 12，不是 0。错误的原因是：tanx 与 sinx 各自替换后留下的高阶误差，在相减时被放大了。

例 1：limx→0tan2xsin5x。分子 ∼2x，分母 ∼5x，所以极限为 25。

例 2：limx→01+x23−1cosx−1。分子用 (1+u)α−1∼αu，其中 u=x2、α=13，所以分子 ∼x23；分母 cosx−1∼−x22。极限为

13−12=−23

例 3：limx→0xsinxx2=1。这里 xsinx 是乘积，可以把 sinx 换成 x，得到 x2x2=1。

12.4 动手前问自己三句

方法 · 等价替换前的三问
  1. 前提对吗？所有等价公式都要求“整体趋于 0”。x→1 时的 sin(1+x) 不能换成 1+x。
  2. 位置对吗？它是不是一个乘除因子？加减项不许换。
  3. 整体换了吗？公式里的 x 是一个“位置”，可以换成 x2、5x、x−1 等整块，不能只换其中一部分。

13. 连续：把极限落到函数值上

极限只描述“趋势”：x 靠近 x0 时，f(x) 靠近 A。但 A 不一定等于 f(x0)。连续要做的，就是把这两件事钉在一起：趋势的终点，正好是函数在该点的值。

13.1 直观：一笔画，不提笔

画连续函数的图像时，笔不离纸，一笔画到底；不连续的地方，必须提笔跳过去。这个直觉很好用，但它不是定义：什么叫“不提笔”？数学上要把它翻译成“自变量的微小变化，只引起函数值的微小变化”。

定义 · 函数在 x0 处连续

设函数 f(x) 在 x0 的某邻域内有定义。若

limx→x0f(x)=f(x0)

则称 f(x) 在 x0 处连续。

这个定义可以拆成三句话，三句都满足才连续：

  1. 在 x0 处有定义：f(x0) 存在。
  2. 极限存在：limx→x0f(x) 存在。
  3. 极限等于函数值：limx→x0f(x)=f(x0)。

注意第一句用的是“邻域”，不是“去心邻域”。极限只要求去心邻域有定义，连续还要求中心点本身有定义——因为要比较极限与 f(x0)。

13.2 左连续、右连续与充要条件

若 limx→x0−f(x)=f(x0)，称 f 在 x0 左连续；若 limx→x0+f(x)=f(x0)，称右连续。由左右极限的充要条件立刻得到：

定理 · 连续 ⇔ 左右都连续

f 在 x0 处连续，当且仅当它既左连续又右连续。

例 1：设

f(x)={x+1,x≤0x−1,x>0

在 x=0 处，左极限为 1，右极限为 −1，两者不等，所以不连续。具体说，它左连续（左极限等于 f(0)=1），但不右连续。

例 2：f(x)=|x| 在 x=0 处连续。左极限为 0，右极限为 0，f(0)=0，三者相等。注意它在 x=0 处不可导（有尖角），但连续——连续只要求“接上”，不要求“光滑”。

13.3 在区间上连续

若 f 在开区间 (a,b) 内每一点都连续，称它在 (a,b) 内连续。若还满足在左端点 a 右连续、在右端点 b 左连续，称它在闭区间 [a,b] 上连续。端点只有一侧有定义，所以只检查那一侧，这也是“左端点是右连续、右端点是左连续”这句话的来源。

常见连续函数：有理函数（分母不为 0）、x（x≥0）、sinx、cosx 等。更一般地，初等函数在其定义域内连续。这条结论后面会反复使用：求初等函数的极限，往往可以直接代入。

只验一侧就下结论，是最常见的错

分段函数在分界点必须分左右极限算。左极限等于函数值，只能说明左连续；还要看右极限。两者都等于 f(x0)，才连续。

14. 间断点：连续三要素坏在哪一条

间断点就是“连续三要素至少坏了一条”的点。判断类型时，不要一上来背四个名字，而是按“左右极限是否存在”逐层问下去。

定义 · 间断点

设 f(x) 在 x0 的某去心邻域内有定义。如果 f(x) 在 x0 处不连续，就称 x0 为 f(x) 的间断点。

14.1 分类：先看左右极限是否存在

类型左右极限与函数值的关系代表
第一类 · 可去都存在且相等不等于 f(x0)，或 f(x0) 无定义x2−1x−1 在 x=1
第一类 · 跳跃都存在但不相等—分段函数在分界点左右不同
第二类 · 无穷至少一侧为 ∞—1x 在 x=0
第二类 · 震荡至少一侧震荡不存在—sin1x 在 x=0

记忆口诀：一可跳，二无荡。第一类包括可去、跳跃；第二类包括无穷、震荡。判断顺序不能反：

  1. 左右极限是否都存在？——这是总开关，分第一类 / 第二类。
  2. 都存在时，是否相等？——相等为可去，不等为跳跃。
  3. 最后才看极限是否等于 f(x0)——决定这一点连不连续。

14.2 四个代表函数

  • 可去：f(x)=x2−1x−1，x=1。去心邻域内 f(x)=x+1，极限为 2，但 f(1) 无定义。补上 f(1)=2 就连续。
  • 跳跃：分段函数在分界点左右极限不同，例如左极限 −1、右极限 1。函数值取哪一个都无法同时等于两侧极限，所以无法通过补定义救回来。
  • 无穷：1x 在 x=0，右侧 +∞、左侧 −∞。注意“趋于无穷”属于极限不存在，所以归第二类。
  • 震荡：sin1x 在 x=0，振幅有界但频率无限增大，极限不存在。它不是无穷间断点，因为函数值没有“冲出去”。

14.3 只有可去间断点能被“抹掉”

结论 · 可去间断点的补定义

若 x0 是 f 的可去间断点，即 limx→x0f(x)=A 存在，那么只要重新规定 f(x0)=A，f 就在 x0 处连续。四个类型中，只有可去间断点具有这个性质。

例：求 f(x)=(x+1)(x−1)(x−2)(x−1) 的间断点并判类。

分母为零的点是 x=1 与 x=2。在 x=1 的去心邻域内约去 x−1：

f(x)=x+1x−2(x≠1),limx→1f(x)=2−1=−2

极限存在，所以 x=1 是可去间断点。在 x=2 处，约分后分母仍为 0，分子为 3，函数值冲向无穷，所以 x=2 是无穷间断点。

分母为零 ≠ 一定是无穷间断点

同一个分母零点，约分后可能极限存在（可去），也可能极限为无穷。必须逐个算极限，不能一刀切。另一个坑是“有定义就万事大吉”：有定义、极限也存在，但极限不等于函数值，仍然是可去间断点。

15. 连续函数的运算：为什么可以把极限写进去

连续函数的最大好处，是“求极限”和“算函数值”可以交换顺序。这条性质把很多极限题变成了代入题。

15.1 四则、反函数、复合的连续性

定理 · 连续函数的运算

连续函数的和、差、积、商（分母不为 0）仍连续；单调连续函数的反函数在其值域区间上仍连续；若 g 在 x0 处连续、f 在 g(x0) 处连续，则复合函数 f(g(x)) 在 x0 处连续。

复合函数的连续性可以写成一句很实用的话：极限可以写进连续函数里面。若 f 在 u0 处连续，且 limg(x)=u0，则

limx→x0f(g(x))=f(limx→x0g(x))=f(u0)

例如 limx→0esinx=elimx→0sinx=e0=1。这里 eu 是连续函数，所以可以把极限搬到指数上。求 limx→0ln(1+x) 时直接代入得 ln1=0，也是同一个道理。

15.2 初等函数在定义域内连续

定理 · 初等函数的连续性

基本初等函数在其定义域内连续；由基本初等函数经过有限次四则运算与复合得到的初等函数，在其定义域内也连续。

所以遇到 sinx、ex、lnx、arctanx 这些函数，在定义域内求极限可以直接代入。但要注意“定义域内”：tanx 在 x=π2 处没有定义，不能代入；1x 在 x=0 处没有定义，也不能代入。

15.3 四个由连续性得到的极限

用“极限写进连续函数”可以推出一批常用极限。它们在第一重要极限之外，补上了对数、指数、幂函数：

极限结果等价形式（x→0）
limx→0loga(1+x)x1lnaloga(1+x)∼xlna
limx→0ax−1xlnaax−1∼xlna
limx→0(1+x)α−1xα(1+x)α−1∼αx
limx→0e3ln(1+2x)sinxe6先算指数上的极限

第四个极限是“把极限写进连续函数”的典型。先看指数上的部分：

limx→03ln(1+2x)sinx=limx→03⋅2xx=6

因为 eu 在 u=6 处连续，所以

limx→0e3ln(1+2x)sinx=e6

注意这里替换的是指数上的整个分式：ln(1+2x)∼2x、sinx∼x，两者都是乘除因子，所以可以整体替换。不要把 e 和指数拆开，也不要把 e3ln(1+2x) 先算成一个数再处理，那样会绕远路。

纠错与说明：幂指函数的归类

课程笔记里有一句“幂指函数不是初等函数”。这句话需要加限定。按“基本初等函数经过有限次四则运算与复合”的严格定义，u(x)v(x)=ev(x)lnu(x) 在 u(x)>0 时仍是初等函数；说它“不是初等函数”，通常是指它不属于六类基本初等函数，不能直接套基本初等函数的求导公式，而要先化成 evlnu。考试中重要的是会化、会判断定义域，而不是背归类。若原题要求“判断是否为初等函数”，应以教材定义为准，并注意 u>0 的条件。

16. 闭区间上连续函数的性质：四个“一定存在”

前面关于连续的性质都是局部的：在某个点附近连续、在某个点附近有界。闭区间上的连续函数则能给出整体的结论：一定有界、一定取到最值、异号端点之间一定穿过 x 轴、两端函数值之间的每个值一定取得到。这些定理不负责算出具体值，只负责告诉你“一定存在”。

16.1 有界性与最值定理

定理 · 闭区间上连续函数的最值定理

设 f(x) 在闭区间 [a,b] 上连续，则 f(x) 在 [a,b] 上一定有界，并且一定取得最大值与最小值。

“最大值”是指存在 ξ∈[a,b]，使对一切 x∈[a,b] 都有 f(x)≤f(ξ)；“最小值”同理。注意最大值唯一，但取最大值的点可以不唯一：一条曲线可以有两个同样高的最高点。端点函数值也不一定是最大值或最小值。

两个前提缺一不可

开区间上连续，可能有界但没有最值：y=x 在 (−1,1) 上取不到 1 和 −1。闭区间上不连续，即使有界也可能取不到最值：把最高点挖掉，最大值就不存在。所以“闭区间”和“连续”两个条件都不能少。

16.2 零点定理

定理 · 零点定理

设 f(x) 在闭区间 [a,b] 上连续，且 f(a) 与 f(b) 异号（即 f(a)f(b)<0），则在开区间 (a,b) 内至少存在一点 ξ，使得

f(ξ)=0

几何上，一端在 x 轴下方、一端在上方，连续曲线一笔画过去，必然穿过 x 轴。注意零点落在开区间内部：端点异号，端点本身不是零点。定理只保证“至少一个”，不保证唯一；如果要判断个数，还需要单调性或其他信息。

例：证明方程 x3−4x2+1=0 在 (0,1) 内至少有一个根。

令 f(x)=x3−4x2+1。它是多项式，在 [0,1] 上连续。计算端点：

f(0)=1>0,f(1)=1−4+1=−2<0

由零点定理，存在 ξ∈(0,1) 使 f(ξ)=0，即方程在 (0,1) 内至少有一个根。这类题的固定套路是：构造函数 → 说明连续 → 验证端点异号 → 引用定理。

16.3 介值定理

定理 · 介值定理

设 f(x) 在闭区间 [a,b] 上连续，f(a)=A、f(b)=B，且 A≠B。则对 A 与 B 之间的任意一个数 C，在开区间 (a,b) 内至少存在一点 ξ，使得

f(ξ)=C

直观上，连续曲线从高度 A 画到高度 B，中间每一个高度都扫过。零点定理是介值定理取 C=0 的特例：当 A、B 异号时，0 介于它们之间。

推论：闭区间上连续函数的值域恰好是 [m,M]，其中 m、M 分别是最小值与最大值。也就是说，最小值与最大值之间的每一个数都取得到，一个不落。

三个容易混的点

第一，零点定理中的 ξ 在开区间内，不是端点；端点的函数值异号，本身不为零。第二，f(a)、f(b) 是端点函数值，不是最大值、最小值；介值定理里的 A、B 也不是 m、M。第三，零点定理只保证存在，不保证唯一；要证明唯一，需要再说明单调性。

这一部分的主线
  • 四则运算：先存在，后拆分
  • 抓大头：只适用于 x→∞ 的多项式商
  • 夹逼 / 单调有界：先证明存在
  • 两个重要极限：sin□□ 与 1∞
  • 等价替换：乘除能换，加减不能换
  • 连续 → 间断点 → 连续运算 → 闭区间定理

18. 题型与方法：拿到题先问什么

这一节不重复前面的推导，而是把“怎么想”压缩成可执行的流程。做题时先判断题型，再选工具；不要一上来就套公式。

18.1 总流程：先判断，再动手

  1. 是数列还是函数？数列只有 n→∞；函数要看清 x→x0、x→x0± 还是 x→∞。
  2. 能不能直接代入？函数在点处连续、分母不为 0，直接代入。
  3. 代入后是什么型？00、∞∞、1∞、∞−∞、有界 × 无穷小、分段点。
  4. 选工具。约分 / 有理化 / 抓大头 / 第一重要极限 / 第二重要极限 / 等价替换 / 夹逼 / 左右极限。
  5. 检查前提与结果。等价替换是不是因式？四则拆分前两个极限是否存在？结果是否与趋势相符？

18.2 八类必会题型

题型 1 · 用定义证明极限

识别：题目出现“用 ε–N 定义证明”“用 ε–δ 定义证明”，或要求严格验证某个极限。

步骤：猜极限 → 写 |xn−A| 或 |f(x)−A| → 放缩成只含 n 或 |x−x0| 的式子 → 反解 → 取 N 或 δ → 正写。

易错：N 取整加一；N 只能往大取；放缩方向要保证“变大之后仍小于 ε”。

题型 2 · 0/0 型

识别：代入后分子分母都为 0。

优先顺序：因式分解约分 → 有理化 → 等价无穷小 → 第一重要极限。含 sin、tan、ln(1+x)、ex−1 时优先考虑等价替换。

易错：约分后忘记说明 x≠x0；等价替换用在加减项。

题型 3 · ∞/∞ 型

识别：x→∞，分子分母都趋于无穷。

优先顺序：多项式商用抓大头；含根号先除以最高次幂；含 sin、cos 等有界量，考虑“有界 × 无穷小”。

易错：把抓大头用到 x→ 常数；忽略 m>n 时符号由系数比决定。

题型 4 · 1^∞ 型

识别：底数趋于 1，指数趋于无穷。

步骤：把底数写成 1+□（□→0）→ 把指数凑成 1□ → 多出的常数移到 e 的指数上。

易错：底数不是“1 + 无穷小”却硬套；指数配凑时符号出错。

题型 5 · 分段函数在分界点

识别：题目给出分段表达式，问在分界点是否连续、是哪种间断点。

步骤：算左极限 → 算右极限 → 算函数值 → 比较三者 → 按“左右极限是否存在 / 是否相等”分类。

易错：只算一侧；把“有定义”当成“连续”；把分母为零直接判为无穷间断点。

题型 6 · 证明方程有根

识别：证明“至少有一个根”“存在 ξ 使 f(ξ)=0”。

步骤：构造 f(x) → 说明在闭区间上连续 → 验证端点异号 → 引用零点定理。若要证唯一，再加单调性。

易错：忘记说明连续；把零点写在端点上；只证存在却声称唯一。

题型 7 · 证明极限不存在

识别：题目问“是否存在”，或函数在一点附近震荡。

步骤：优先找两条数列（或左右极限），使函数值趋于不同的数；由“函数极限 ⇒ 数列极限”的逆否，或左右极限不相等，得出不存在。

易错：只找到一条收敛的数列就断言存在；忘记说明 xn≠x0。

题型 8 · 夹逼准则

识别：和式、n 项相加、无法直接求极限，但每一项可以被统一放大 / 缩小。

步骤：找上下界 → 证明两端极限相同 → 夹逼。常用放缩：分母统一放大或缩小、项数固定、最大项 / 最小项。

易错：两端极限不同；放缩过松，导致一端极限算不出来。

18.3 三个完整的思考样例

样例 A：求 limx→01−cosxxsinx。

先代入：1−10=0/0，是 0/0 型。分子是 1−cosx，分母是 xsinx。两者都是因子，可以等价替换：1−cosx∼x22，sinx∼x，所以分母 ∼x2。原式 →x2/2x2=12。

检查：x→0 时分子是二阶小量，分母也是二阶小量，结果是非零常数，合理。若把分母的 sinx 忘记换，只换分子，会得到 x2/2xsinx，仍然要再处理 xsinx，多绕一步。

样例 B：求 limx→∞(1+2x)3x。

底数 1+2x→1，指数 3x→∞，是 1∞ 型。把底数里的整体记作 □=2x，它的倒数是 x2。指数 3x=6⋅x2，所以

(1+2x)3x=[(1+□)1/□]6→e6

检查：底数大于 1，指数为正，结果应大于 1；e6>1，合理。

样例 C：求 limn→∞(1n2+1+1n2+2+⋯+1n2+n)。

这是 n 项和，不能直接逐项求极限（项数也在变）。用夹逼：每一项的分母在 n2+1 到 n2+n 之间，所以

nn2+n≤∑k=1n1n2+k≤nn2+1

两端都趋于 1（分子分母同次，系数比 1），由夹逼准则，原极限为 1。这类题的关键是“项数固定为 n，分母统一放大 / 缩小”，不要试图逐项算。

有界是收敛的必要条件，不是充分条件。“有界”只说明跑不出去，不说明会停在一个点。

极限只看去心邻域，连续才看中心点。极限存在与 f(x0) 无关；连续要求极限正好等于 f(x0)。

等价替换的铁律：乘除能换，加减不能换。看到加减，先提公因式、通分或有理化，把它变成乘积再换。

20. 自测：10 道题检查薄弱环节

先合上笔记写，再对照后面的答案。每题都标了对应小节，做错时回到那一节，而不是只看答案。

20.1 题目

  1. 判断 f(x)=1x 在 (0,1) 与 (1,2) 上的有界性，并说明理由。（§2.2）
  2. 用 ε–N 定义证明 limn→∞n+(−1)n−1n=1。（§5.3）
  3. 求 limx→01−cosxxsinx。（§12.3）
  4. 求 limx→∞3x3+4x2+27x3+5x2−3x。（§10.2）
  5. 求 limx→∞(1+2x)3x。（§11.3）
  6. 求 limx→0tanx−sinxx3，并说明为什么不能直接把 tanx、sinx 换成 x。（§12.3）
  7. 判断 f(x)=sin1x 在 x=0 处的间断点类型；再判断 x2−1x−1 在 x=1 处的类型。（§14）
  8. 设 f(x)={x+1,x≤0x−1,x>0，判断它在 x=0 处是否连续、是否左连续、是否右连续。（§13.2）
  9. 证明 x3−4x2+1=0 在 (0,1) 内至少有一个根。（§16.2）
  10. 判断两句话是否正确，并各举一个反例：（1）有界数列一定收敛；（2）若在 x0 的去心邻域内 f(x)>0，则 limx→x0f(x)>0。（§6）

20.2 答案与提示

1. 在 (0,1) 上无界：有下界 1，但没有上界，靠近 0 时函数值任意大。在 (1,2) 上有界：12<f(x)<1。关键：有界性必须和区间绑定。

2. |n+(−1)n−1n−1|=1n。任给 ε>0，取 N=[1ε]+1；当 n>N 时 1n<ε，故极限为 1。

3. 分子 1−cosx∼x22，分母 xsinx∼x2，所以极限为 12。

4. 分子分母同次（三次），取最高次项系数比：37。

5. 令 □=2x，则指数 3x=6⋅x2=6⋅1□，所以原式为 [(1+□)1/□]6→e6。

6. tanx−sinx=tanx(1−cosx)∼x⋅x22=x32，极限为 12。不能直接换，是因为 tanx−sinx 是加减项，两个替换后的高阶误差在相减时被放大。

7. sin1x 在 x=0 是第二类震荡间断点：振幅有界，但极限不存在。x2−1x−1 在 x=1 是第一类可去间断点：约分后极限为 2，补定义 f(1)=2 即可连续。

8. 左极限为 1，右极限为 −1，f(0)=1。所以左连续、不右连续，整体不连续。左右极限都存在但不相等，是跳跃间断点。

9. 令 f(x)=x3−4x2+1，在 [0,1] 上连续；f(0)=1>0，f(1)=−2<0。由零点定理，存在 ξ∈(0,1) 使 f(ξ)=0。

10. （1）错。(−1)n+1 有界但发散。（2）错。f(x)=x2 在 0 的去心邻域内 x2>0，但 limx→0x2=0，并不严格大于 0。

21. 结语：这一章留下的三样东西

学完第一章，真正要带走的不是一堆公式，而是三样东西：

  1. 函数是对象。以后做题，先看定义域、对应法则、基本性质；分段函数要盯分界点。
  2. 极限是工具。它把“趋势”变成可计算的运算；四则、抓大头、重要极限、等价替换、夹逼，都是围绕它建立的工具，每个工具都有前提。
  3. 连续是桥。它把极限和函数值接起来，让“求极限”可以变成“代入”；再往前一步，就是闭区间上的四个存在性定理。
衔接下一章：导数为什么也需要极限

下一章的导数，定义为差商的极限：

f'(x0)=limΔx→0f(x0+Δx)−f(x0)Δx

它不是新的极限类型，而是“函数增量与自变量增量之比”的极限。可导必连续，但连续不一定可导：连续只保证“接上”，可导还要求“光滑”。所以第一章的极限与连续，不是学完就丢的预备知识，而是第二章的地基。

全章记忆入口 · 一张纸复习

一条主线

函数（定义域 + 对应法则）→ 极限（ε–N / ε–δ / ε–X）→ 收敛性质与计算工具 → 连续（极限 = 函数值）→ 闭区间四定理。

两个“先存在”

四则运算先确认两个极限都存在；闭区间定理先确认“闭区间 + 连续”。

三个“不能反”

有界 ⇒ 收敛；连续 ⇒ 可导；函数极限 ⇒ 数列极限，但反过来不成立。

四个“一定存在”

闭区间连续函数：有界、有最大值最小值、异号端点之间有零点、两端函数值之间每个值都取得到。

五个必背公式

limx→0sinxx=1；limx→∞(1+1x)x=e；1−cosx∼x22；ln(1+x)∼x；ex−1∼x。

六个易错点

去心邻域；无穷大属于极限不存在；“有限个”无穷小；无界 ≠ 无穷大；抓大头只适用于 x→∞；等价替换只换因式。
