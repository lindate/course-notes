P149【黑板】函数的幂级数展开：间接展开法三步走

一句话核心

展开是求和的逆运算：给定 f(x)，把它写成幂级数。考试只考间接展开法——背熟八张常用展开式，再用代换 / 逐项求导 / 逐项积分拼装。三件事决定成败：把 (x−x0) 当整体焊死、整体代换后收敛区间跟着变、多式合用取交集。收敛区间是算分的，漏写必扣。

这一页站的位置：求和的反面，也是全书的终点

00:00老师说这部分「理论实在是比较烦」，所以不按课本一条条推证明，直接给结论和常用方法。位置关系很清楚：02:22上一页（【黑板】幂级数求和函数）做的是有了右边的幂级数，求左边的函数（求和函数）；这一节反过来——有了左边的函数，把它写成右边的幂级数（函数的幂级数展开）。前者是「收」，后者是「放」，用的是同一套公式、同一套收敛区间。

为什么要费劲把一个简单函数拆成无穷多项？因为右边全是 xn 的加减乘，是多项式。老师的原话是：在所有的函数里边，多项式函数是最好的函数，它是最好的，它计算是最快的。而 ex、sinx 这些是非线性函数，计算机直接算很费时。03:36他随手举了个近似计算的例子：取 x=0.1，x2 是 0.01、x3 是 0.001，越往后的项小数点的位置越靠后，「做近似的时候啊，后边的这个部分其实你就可以不取了」——这正是工程上用幂级数做快速近似的理由。

八张必须背下来的展开式

下面这张表就是全部家当。每一行都要连同收敛区间一起背，因为区间在考试里是算分的。

函数展开式收敛区间怎么记住它
ex∑n=0∞xnn!(−∞,∞)死记
sinx∑n=0∞(−1)nx2n+1(2n+1)!(−∞,∞)死记，只含奇次项
cosx∑n=0∞(−1)nx2n(2n)!(−∞,∞)对 sinx 的式子逐项求导
11−x∑n=0∞xn(−1,1)等比求和公式反用

ln(1+x)∑n=1∞(−1)n−1xnn(−1,1]对 11+x 逐项积分

04:26这八式里真正需要「背」的只有四张：ex、sinx、11−x、11+x。剩下四张都能从它们推出来——ln(1+x) 是把 11+x 两边同时积分（左边积出 ln(1+x)，右边逐项积出 ∑(−1)n−1xnn）；05:39把 sinx 求导就得到 cosx；把 11+x 里的 x 换成 x2 得到 11+x2；06:34再把 11+x2 积分就得到 arctanx。老师特意点了一句：07:26首先这个第三条跟第四条啊，你是天生就应该会的——11−x 与 11+x 就是上一页那个唯一的求和对象，换个说法而已。

为什么三式覆盖整条实轴，其余五式却只有 (−1,1)

把八式的收敛区间排成一列，立刻分成两档：ex、sinx、cosx 的系数里带阶乘（1n!），衰减极快，按 【黑板】幂级数求收敛半径和收敛域 的判据 ρ=0、R=∞；剩下五式的系数都是有理式（1n、12n+1 之类），ρ=1，所以 R=1。这就是为什么前三式可以放心代任意实数，而后五式必须盯着那个「整体」落在 (−1,1) 里。

再考虑代换就明白 11+x2 为什么仍是 (−1,1)：条件 |x2|&lt;1 与 |x|&lt;1 本来就是同一件事。换成 x→x−22 就不同了，条件变成 |x−22|&lt;1，区间被拉伸平移成 (0,4)。统一口诀：代换进去的是什么，就把那个「什么」塞进 (−1,1)（或对应的区间）里解一次不等式。至于端点能不能捡回来，只看链条最后一步是积分还是求导——停在积分上的（ln(1+x)、arctanx）有机会扩，停在求导上的不会。

为什么积分能「捡回」端点，求导却不行

看 11+x 与 ln(1+x)：前者的收敛区间是 (−1,1)，积分后变成 (−1,1]，右端点 x=1 被捡回来了。原因在通项上——积分让每一项多除一个 n，端点处原本「勉强不收敛」的项被压小了一档，于是收敛。arctanx 更明显：11+x2 只在 (−1,1) 收敛，积分后两个端点都收敛，区间扩成 [−1,1]。

求导则相反：每一项多乘一个 n，原本在端点勉强收敛的会被推出去。所以 cosx 由 sinx 求导得到，收敛区间依旧是 (−∞,∞)（本来就无处可退）；而如果你对 ln(1+x) 求导，右端点 x=1 就会丢掉。记一条暗线：积分可能扩域、求导只会保域或缩域。这条经验能帮你在考场上预判每个公式该写几个括号。

手段一：整体代换——最省事的一招

08:12「间接展开法」这个名字听着吓人，落到实处就是拿已知公式做整体替换。老师举的例子全是最简单的那种：

sinx
把 sinx=∑(−1)nx2n+1(2n+1)! 里的 x 全部换成 x，即得 x−x3/23!+x5/25!−⋯。09:13取值范围要跟着变：原来 x 任意，现在 x 要求 x≥0，所以 x∈[0,∞)。
ex2
把 ex=∑xnn! 里的 x 换成 x2，得 1+x2+x42!+x63!+⋯。x2≥0 不限制 x，所以仍是 (−∞,∞)。
e−x2
把 x 换成 −x2：1−x2+x42!−x63!+⋯。09:13老师原话原来的 X 可以随便取，你现在是一个负的 X 方，X 也可以随便取，所以 X 随便取呗——仍 (−∞,∞)。
代换的头号错误：只换式子，不换区间

写完 ex2 的展开式就收工，区间照抄 (−∞,∞)。这一步恰好没出事，因为换进去的 x2 不影响 x 的取值。但换 sinx 时，如果不动脑子照抄 (−∞,∞) 就错了：x 只在 x≥0 有定义，正确答案是 [0,∞)。每做一次整体代换，都要解一次不等式：新的「整体」落在原公式的收敛区间里，等价于 x 落在什么范围。

手段二与三：逐项求导、逐项积分

当函数不能靠一次代换直接拼出来时，就动用上一页（【黑板】幂级数求和函数）的两条性质。合法性来源完全相同：幂级数在收敛区间内可以逐项求导、逐项积分（幂级数（2）），而且操作前后收敛半径不变——所以只要保证操作在区间内部进行，结果就是同一个函数的展开式。

手段典型用法注意
代换sinx、ex2、e−x2、11+x2收敛区间要按新变量重新解
逐项求导cosx=(sinx)'；∑nxn−1=(∑xn)'可能丢掉端点（区间只会变窄）
逐项积分ln(1+x)=∫0xdt1+t；arctanx=∫0xdt1+t2可能捡回端点；积分常数由 x=0 定
拆项 / 乘开1(2+x)(3−x)、(1−x)ln(1+x)各部分分别展开，最后取交集

例 1：把两个级数乘开、再并成一个

例 110:05把 (1−x)ln(1+x) 展开成 x 的幂级数。

思路：ln(1+x) 有现成公式，乘开即可

先把 ln(1+x) 写出来：ln(1+x)=∑n=1∞(−1)n−1xnn。再用 1−x 乘进去，拆成两块：

(1−x)ln(1+x)=∑n=1∞(−1)n−1xnn−∑n=1∞(−1)n−1xn+1n

11:44老师在这里停了一下：有的同学可能就写不动了，有些同学呢可能整到这一步啊可能就不想动了。题目要的是一个幂级数，所以还得把两个求和号合并。12:54先把第二块的指标平移：令 m=n+1，它变成 ∑m=2∞(−1)m−2xmm−1；再注意到 (−1)m−2=−(−1)m−1，于是两大块的第一项之外部分可以合并：

(1−x)ln(1+x)=x+∑n=2∞(−1)n−1(1n+1n−1)xn

括号里通分：1n+1n−1=2n−1n(n−1)。所以

(1−x)ln(1+x)=x+∑n=2∞(−1)n−12n−1n(n−1)xn

16:01收敛区间：ln(1+x) 的区间是 (−1,1]，乘一个 (1−x) 不改变半径。代两个端点验一遍：x=1 时系数是交错形式、量级 2n，收敛（而且原函数在 x=1 恰好为 0）；x=−1 时交错结构被 xn 抵消，级数变成 −∑2n−1n(n−1)，通项 ∼−2n，发散。所以收敛区间是 (−1,1]。

这一步最容易错

两个求和号各写各的，不合并。题目问的是「展开成幂级数」，标准答案必须是一个 ∑ 加一个常数项。合并时最容易漏掉第一项 x——它是 n=1 那一项单独提出来剩下的，漏了就整整差一项。老师给的做法是「把第一个式子里 n=1 的那一项单独写出来」，再与第二块共享 xn 的因子后通分。

例 2：分母是「常数 + 一次项」

16:42这是考场上重复率最高的一类：分母形如 a+bx。打法固定——提常数，把分母凑成 1−u 或 1+u，再把那个含 x 的整体代进公式。

例 2把 12−x、12+x、13−2x 分别展开成 x 的幂级数。

12−x：提 12，凑 11−u
12−x=12⋅11−x2=12∑n=0∞(x2)n=∑n=0∞xn2n+1

收敛条件 |x2|&lt;1，即 |x|&lt;2，区间 (−2,2)。

12+x：加号对应 11+u，会多一个 (−1)n
12+x=12⋅11+x2=∑n=0∞(−1)n2n+1xn(−2,2)
13−2x：提 13，把 2x3 当整体
13−2x=13⋅11−2x3=∑n=0∞2n3n+1xn(−32,32)
26:32区间忘写会扣分

26:32老师专门叮嘱：写完它的展开式以后啊，好多同学就不弄了。大家一定要注意它的取值范围……你如果考试的时候这个点你忘写了，这个地方应该就会给你扣一分。而且区间不是照抄：原来的 |x|&lt;1 经过整体替换后要解一遍——|x2|&lt;1⇒|x|&lt;2，|2x3|&lt;1⇒|x|&lt;32。

例 319:45把 1(2+x)(3−x) 展开成 x 的幂级数。

思路：先拆项，再各展各的，最后取交集

老师先做了一件必要的事——通分验证拆法：12+x+13−x=(3−x)+(2+x)(2+x)(3−x)=5(2+x)(3−x)，所以

1(2+x)(3−x)=15(12+x+13−x)

两块都用例 2 的套路：12+x=∑(−1)nxn2n+1（|x|&lt;2），13−x=13⋅11−x3=∑xn3n+1（|x|&lt;3）。于是

1(2+x)(3−x)=15∑n=0∞((−1)n2n+1+13n+1)xn

收敛区间取两部分的交集：(−2,2)∩(−3,3)=(−2,2)。

取交集，不是取并集

看到 −3&lt;x&lt;3 就说整体区间是 (−3,3)。两个展开式必须同时成立，式子才成立，所以公共部分说了算：(−2,2)。老师把这条放在最后当总提醒：39:23如果这个题用到了两个展开式或者三个展开式，那么你求出各自 X 的取值范围以后，其实是要求交集的。

展成 (x−x0) 的幂：整体焊死，永不拆开

30:13展成 (x−x0) 的幂，与展成 x 的幂相比，唯一的差别是：(x−x0) 从此是一个整体，不能拆开。老师用了个很生活化的比喻：

老师原话

展成 X 减一的幂级数，他的意思就是它最终出现的都是 X 减一，整体出现……原来你没有男朋友的时候、没有女朋友的时候，那吃饭、上自习、睡觉不都你自己一个人对不对？哎，有了男女朋友以后，那就是一块吃饭、一块上自习，成双入对了。所以 X 减一，它自此以后永远不分开，你就记住这一点。

例 432:42把 lnx 展开成 (x−2) 的幂级数。

思路：唯一的对数公式是 ln(1+u)，就把 x 改造成 1+「整体」

x 与 −2 必须成双成对，所以先把 x 写成 2+(x−2)，再提出 2：

lnx=ln(2+(x−2))=ln2+ln(1+x−22)

32:42令 u=x−22，套 ln(1+u)=∑n=1∞(−1)n−1unn：

lnx=ln2+∑n=1∞(−1)n−1(x−2)nn⋅2n

34:23收敛区间：条件 |x−22|≤1 且 x−22≠−1，解出 −2&lt;x−2≤2，即 x∈(0,4]。36:19注意这里「一是能取到的」——ln(1+u) 的右端点是闭的，所以 x=4 要取；而左端点 u=−1（即 x=0）处级数发散，不取。

不能直接展成 x 的幂

把 lnx 硬按 ln(1+u) 的形式套，令 u=x−1 就开算。题目要求的是 (x−2) 的幂，中心必须是 2；而且 lnx 在 x=0 处根本没定义，也没法以 0 为中心展开。题目指定哪个中心，就以哪个中心重新组织式子——这也是为什么 lnx 要改写成 ln2+ln(1+x−22)，那个 ln2 就是「中心搬移」的代价，它是常数项，不能丢。

例 530:57把 13+(x−1) 展开成 (x−1) 的幂级数。

思路：把 (x−1) 整体当成 11−u 里的那个字母

提常数，把分母凑成 1+「整体」：

13+(x−1)=13⋅11+x−13=13∑n=0∞(−1)n(x−13)n=∑n=0∞(−1)n3n+1(x−1)n

收敛条件 |x−13|&lt;1，即 |x−1|&lt;3，也就是 −2&lt;x&lt;4。老师强调：还是那句话，不要忘记取值范围。原来不是 (−1,1) 吗？你现在不是 X−13 吗？你不是做成了整体吗？整体换进去，区间就跟着换成 (−2,4)。

为什么「(x−x0) 不能拆开」不是一句空话

假设有人图省事，先把 lnx 展成 x 的幂级数、再想办法「平移」到 x=2 附近，结果一定不对：lnx 在 x=0 处的各阶导数虽然存在，但以 0 为中心的泰勒级数在 x 靠近 0 时并不收敛到 lnx（收敛半径只有 1，而 lnx 的奇点在 0）。这就是为什么必须换中心——「展成 (x−x0) 的幂」的本质是把 x0 当成新的原点，所有结构都必须围绕 (x−x0) 重组。

换个角度看，整条操作链是自洽的：u=x−x0 是一次代换，代换的合法性来自幂级数在收敛区间内的绝对收敛（可以逐项重排、可以整体代入）；而代换后「区间跟着变」又保证了每一个 x 都真的落回原公式的收敛区间里。这两件事是同一个逻辑的两面，缺一面结论就不成立。

收尾清单：展开题的六个动作

① 看中心：题目要 x 的幂还是 (x−x0) 的幂？后者立刻令 u=x−x0，全书不再拆开。
② 看形状：能不能提常数凑成 1±u？不能就拆项或乘开。
③ 选手段：代换最省事，求导/积分用于把 cosx、ln(1+x)、arctanx 这类拼出来。
④ 合并：若出现多个求和号，必须并成一个 ∑ 加常数项（例 1）。
⑤ 换区间：整体代换后解一次不等式，把 u 的区间翻成 x 的区间。
⑥ 取交集 + 验端点：多式合用取交集（例 3）；端点用代入法确认（例 4 的 x=4 取、x=0 不取）。
