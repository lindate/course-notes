P093两类曲线积分之间的联系：那条弧上的两条投影

一句话核心

上一页的两类曲线积分各管一摊，这一页把它们焊起来：dx=cosαds、dy=cosβds——第二类积分由此可以全部改写成对弧长的积分。cosα、cosβ 不是随便的角，它们正是这一点的有向切向量的方向余弦。这一页是三页里最短的，却直接决定了 格林公式&积分与路径无关条件 格林公式能不能用对。

先把两类积分摆在一起看

00:00上一讲的两类曲线积分，学的时候是分开学的，所以脑子里它们还是两件不相干的东西。这一讲要做的事只有一件：把 dx 和 dy 用 ds 表示出来，然后代进第二类曲线积分。

先把上一页的结论搬过来对照一下：

第一类（对弧长）第二类（对坐标）
微元 ds：一小段弧长 dx、dy：小段在两个方向上的改变量
符号 恒大于零 可正可负，由方向决定
曲线要不要标方向 不要，A→B 与 B→A 一样 必须标，换向变号

这张表里最值得盯住的是第二行：一个是「永远正」，一个是「可正可负」。它们之间的桥梁就藏在这一行里。

桥梁的第一半：从 ds 出发的勾股定理

01:21回忆 ds 当初是怎么定义的：把曲线切成很多小段，每一段很短，短到可以近似看成一条直线段。既然它是一条直线段，那么它的水平投影 dx 和竖直投影 dy 与它本身构成一个直角三角形，勾股定理给出

ds=dx2+dy2

这条式子我们的同学都很熟悉。但老师在这里停了一下，指出一个很容易被忽略的后果：

02:13平方之后，「正负号」被藏起来了

式子右边是 dx2 和 dy2，平方之后不论 dx 是正是负，dx2 都大于零。所以这条勾股定理只给出长度，完全丢掉了方向的信息。

它的含义是：ds 必须是正的（它就是弧长、就是长度），而 dx、dy 未必。老师原话是希望大家「对它的正负号先有一个浅浅的意识」——这个意识非常重要，因为后面做第二类曲线积分时，dx 的符号就是答案里那个负号的来源。

打个比方：一条从左下到右上的斜线，和一条从右下到左上的斜线，长度完全一样，勾股定理给出的 ds 也一样；但它们的 dx 一个正、一个负。勾股定理能算出「多长」，算不出「朝哪」。

桥梁的另一半：方向余弦

02:50现在反过来问：既然 ds 是斜边，dx 与 dy 是两条直角边，那么能不能把 dx 用 ds 表示？能——只要引入两个角。

04:13设这一小段 ds 的方向与 x 轴正半轴的夹角为 α、与 y 轴正半轴的夹角为 β。在以 ds 为斜边的直角三角形里，dx 是 α 的邻边，所以

cosα=dxds⟹dx=cosαds

同理，把这条斜边与 y 轴方向的夹角记为 β（它与图中的另一个角是内错角，数值相同），则

cosβ=dyds⟹dy=cosβds
05:27钝角的情形：这条公式自己把符号对上了

有同学会担心：α 万一是钝角怎么办？那就正好说明这套写法是对的。

当 α 是钝角时，这个余弦是负的，于是 dx=cosαds<0——和我们前面说的「dx 可正可负」完全吻合。也就是说，dx 的符号不是另外加的规定，它天然地被「余弦的正负」承担了。

这就是为什么这套公式比勾股定理更好用：勾股定理丢掉了方向，而余弦把方向捡了回来。dx=cosαds 是一条「带符号的勾股定理」。

联系公式

06:23把 dx=cosαds、dy=cosβds 代进第二类曲线积分，立刻得到本页的主公式：

∫LP(x,y)dx+Q(x,y)dy=∫L[P(x,y)cosα+Q(x,y)cosβ]ds

右边是关于弧长的积分，所以：第二类曲线积分可以化为第一类；反过来也可以。两类积分从此不再割裂。

一句话读这条公式：把「沿坐标方向的累加」换成「沿弧长的累加」，代价是每一项都要乘上它自己方向的方向余弦。直白地说，dx 只取了 ds 在 x 方向的cosα 那么多，剩下的分量跑到了 dy 里。

cosα、cosβ 到底是什么

07:34公式写出来以后，新问题马上来了：cosα 和 cosβ 是几？

如果 L 是一条直线，那 α、β 是固定的，一眼就能看出。但 L 一般是一条曲线，这时候「L 与 x 轴正半轴的夹角」这句话本身就没有意义了——曲线上不同点的切线朝向不同。

正确的理解是：在每一个点上，取这一点的有向切向量，它与坐标轴正方向的夹角就是 α、β。所以 cosα、cosβ 都是关于点的函数，会随位置变化，必须放进积分号里面。

为什么「方向余弦」这个名字是准确的

把曲线参数化：x=x(t)，y=y(t)。曲线在参数 t 处的切向量是 (x'(t),y'(t))，它的长度（也就是速率）是 x'2(t)+y'2(t)。

把一个向量除以自己的长度，就得到同方向的单位向量。所以这一点的有向单位切向量是

(x'(t)x'2+y'2,y'(t)x'2+y'2)

而「方向余弦」的定义就是单位向量与各坐标轴夹角的余弦，也就是它的各个分量。所以

cosα=x'(t)x'2+y'2,cosβ=y'(t)x'2+y'2

这就把「模模糊糊的角度」变成了「可以直接算的式子」。而且注意：这个定义里用的切向量是有向的——它带着曲线前进的方向，这正是第二类曲线积分讲究方向的原因。

08:52推导时要小心一件事：t 是增大还是减小。设参数从 a 变到 b：

曲线方向参数关系dt 的符号方向余弦
沿 t 增大的方向 a<b dt>0 cosα=x'(t)x'2+y'2（不带负号）
沿 t 减小的方向 a>b dt<0 cosα=−x'(t)x'2+y'2（整体加负号）

13:57第二行的负号是怎么来的？关键在于推导过程中出现了一个 dt 的绝对值：为了把 dt2 开出来，需要写成 |dt|。参数增大时 |dt|=dt，符号不变；参数减小时 |dt|=−dt，于是整个式子在前面多出一个负号。t 是从小到大走还是从大到小走，全从这个负号体现出来。

21:22换成两种常见的函数写法，结果也顺手列在这里（老师建议不用单独记，直接套上面的总公式推）：

若 y=y(x)，x 从 a 到 b 且方向为 x 增大
cosα=11+y'2，cosβ=y'1+y'2
若 x=x(y)，y 从 c 到 d 且方向为 y 增大
cosα=x'1+x'2，cosβ=11+x'2
方向反过来
两个方向余弦同时加负号
空间曲线 x=x(t),y=y(t),z=z(t)
多一个 cosγ=z'(t)x'2+y'2+z'2，三条式子的分母相同

例题

例 122:47把 ∫LPdx+Qdy 化为对弧长的曲线积分，其中 L 是抛物线 y=x2 上沿 x 从 0 到 2 的一段。

思路：先判断这是「参数增大的方向」，然后分别求两个方向余弦

这里取 x 当参数。曲线 y=x2，所以 y'=2x，而 x 对参数（也就是 x 自己）求导是 1。方向是 x 从 0 到 2，即参数增大的方向，所以两个余弦都取正号：

cosα=11+(2x)2=11+4x2,cosβ=2x1+4x2

代进联系公式：

∫LPdx+Qdy=∫L[P(x,x2)+2xQ(x,x2)1+4x2]ds

要点：dx=cosαds 里的 cosα 就是那个 1/1+4x2。注意它与 cosβ 的分母完全相同——因为两条余弦来自同一个单位切向量，分母都是切向量的长度，这一点在任何曲线、任何参数下都成立。

例 225:09对上半圆周 x2+y2=1（从 (−1,0) 到 (1,0)），把 ∫LPdx+Qdy 化为对弧长的曲线积分。要求用两种参数化各做一遍。

思路：同一段曲线，两种参数化的「参数增减方向」恰好相反，负号也恰好相反

方法一：取 y 为 x 的函数。上半圆 y=1−x2，x 从 −1 到 1。这是参数增大的方向，所以不带负号。先求导：

y'=−x1−x2

于是 1+y'2=1+x21−x2=11−x2，分母 1+y'2=11−x2。所以

cosα=1−x2,cosβ=−x1−x2⋅1−x2=−x

注意 cosα=1−x2 正好就是 y，于是

∫LPdx+Qdy=∫L(Py−Qx)ds

方法二：取 θ 为参数。x=cosθ，y=sinθ。32:26这里最容易错的一步是定 θ 的范围：起点 (−1,0) 对应 θ=π，终点 (1,0) 对应 θ=0，所以θ 从 π 变到 0——这是参数减小的方向，整套公式前面要加负号。

先算不带负号的版本：x'=−sinθ，y'=cosθ，x'2+y'2=1，所以 cosα=−sinθ、cosβ=cosθ。加上负号：

cosα=sinθ=y,cosβ=−cosθ=−x

两种方法给出完全相同的结果 (cosα,cosβ)=(y,−x)。

这个「恰好」值得追问一句

为什么同一个点、同一段曲线，用两套完全不同的参数化，方向余弦算出来一模一样？因为方向余弦是几何量，它只取决于这一点上曲线的有向切向量，与你怎么参数化无关。

方法一里 cosα 来自 1−x2，方法二里来自参数减小时的那一个负号与 −sinθ 的抵消——两条完全不同的代数路径，通向同一个几何事实。这就是为什么结果必须是 (y,−x)。

另一方面也要看清：换了方向，两个余弦会同时变号。如果这道题改成从 (1,0) 走到 (−1,0)，答案就变成 (−y,x)。第二类的「换向变号」在化成第一类以后依然留着印记。

例 336:24把 ∫LPdx+Qdy+Rdz 化为对弧长的曲线积分，其中 L 是从 (0,0,0) 到 (1,1,1) 的直线段。

思路：空间情形只是多一条余弦，做法完全一样

取 x=y=z=t，t 从 0 到 1——参数增大的方向，全取正号。三个导数都是 1，分母是 1+1+1=3，所以

cosα=cosβ=cosγ=13

代入联系公式（空间版是 dx=cosαds、dy=cosβds、dz=cosγds）：

∫LPdx+Qdy+Rdz=∫LP+Q+R3ds

要点：直线段的三个方向余弦是常数，可以提到积分号外面去。这也顺便说明：只有直线上的方向余弦才固定，曲线上的一定随点变。

例 444:28把 ∫Ldx+2xdy+3ydz 化为对弧长的曲线积分并求出结果，其中 L:x=t、y=t2、z=t3，t 从 0 到 1。

思路：先把三个方向余弦写出来（分母是同一个根号），再代入

x'=1、y'=2t、z'=3t2，所以切向量长度是

1+4t2+9t4

45:42三个方向余弦的分母都是这个根号：

cosα=11+4t2+9t4,cosβ=2t1+4t2+9t4,cosγ=3t21+4t2+9t4

把 P=1、Q=2x=2t、R=3y=3t2 代进 ∫L(Pcosα+Qcosβ+Rcosγ)ds，分子上出现

1⋅1+2t⋅2t+3t2⋅3t2=1+4t2+9t4

它恰好等于分母的平方！于是整个被积表达式化简成

∫Ldx+2xdy+3ydz=∫L1+4t2+9t4ds

47:49接下来老师点出了一个很实用的观察：「这玩意儿我们不会用这个东西来求，为什么呢？求的话 x,y,z 已经是关于 t 的参数方程了，dx、dy、dz 直接对 t 求微分不就完了吗？」也就是说，真要算数值，不必绕道对弧长：

∫L=∫01[1⋅1+2t⋅2t+3t2⋅3t2]dt=∫01(1+4t2+9t4)dt
=1+43+95=6215
这道题真正要记住的是这两句

第一，化成对弧长是本节的训练目标，但不是计算的首选路径。第二类曲线积分的参数化本身就好算（dx=x'dt 一步到位），除非题目专门要求，不必绕。

第二，∫L1+4t2+9t4ds 这个写法要能读得懂：它说的是「沿这条曲线，把切向量的长度累加起来」。之所以结果里没有根号，是因为这个特定被积函数的方向余弦分子与勾股因子刚好消掉了。

这一页为什么必须放在格林公式前面

49:17这一节的内容很薄，但它承担着一个结构性的任务：它把两类曲线积分统一到同一条公式下，也让第二类曲线积分有了「几何解释」。没这一步，下一讲的格林公式就只能是一堆偏导数的机械运算。

提前看一眼：为什么格林公式偏爱第二类

格林公式说的是：区域上的二重积分 = 边界上走一圈的第二类曲线积分。50:16为什么是第二类，而不是第一类？

因为「走一圈」这件事本身带方向。沿着正向（区域在左手侧）绕一圈，dx、dy 的符号在每个点、每段弧上都不同：上边一段往左走 dx<0，下边一段往右走 dx>0，它们的贡献不会互相抵消，而是精确地加起来等于区域上的某个量。换成第一类就写不出这种「绕行方向」的信息——ds 一律为正，绕行方向的信息全丢了。

而本页的公式恰好告诉我们：这个「方向」被藏在 cosα、cosβ 的正负里。dx=cosαds 是格林公式的入场券。
