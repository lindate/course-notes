P133【黑板】多元函数微分学的几何应用：曲线与曲面的两套向量

一句话核心

这一页把 空间曲线的切线和法平面 与 曲面的切平面和法线 压成一张速查表。曲线的关键量是切向量——逐分量求导就能拿到；曲面的关键量是法向量——隐式 F=0 时取 (Fx,Fy,Fz)，显式 z=f(x,y) 时取 (fx,fy,−1)。这个向量只有两个出口：当方向向量用（点向式，写切线 / 法线），或者当法向量用（点法式，写法平面 / 切平面）。输入形式有四种，名字有四个，真正要算的东西永远只有那一个向量。

先分名字：曲线配切线，曲面配切平面

25:19这一讲真正的难点不在算，而在认名字。老师说得很直白：「空间曲线和曲面的切线、切平面、法线、法平面，这个地方特别容易绕。」他当场拿了一条充电宝的线代表空间曲线，又借同学的脑袋当球面，在球上放一本书——那本书就是切平面。26:31「你拿个西瓜，用一本书放在西瓜某一个点上，这样切过去就叫切平面。」

27:29四个名字定义完就是下面这个样子：曲线上过一点、沿曲线方向的直线叫切线；过切线上那个点、并且与切线垂直的平面叫法平面。曲面上过一点、贴着曲面的那张平面叫切平面；过那一点、并且与切平面垂直的直线叫法线。

项目曲线（1 维）曲面（2 维）
要先算的向量切向量（沿着的方向）法向量（垂直着的方向）
向量怎么来三个分量逐个求导求三个偏导，再拼成向量
它配的第一套方程切线：它当方向向量，写点向式切平面：它当法向量，写点法式
它配的第二套方程法平面：它当法向量，写点法式法线：它当方向向量，写点向式
维数记忆「切」出来的与曲线同维（1 维），「法」出来的补成 2 维「切」出来的与曲面同维（2 维），「法」出来的补成 1 维

表里最值钱的是那两行「反过来的搭配」。切向量当方向向量写出来的是直线（切线），切向量当法向量写出来的是平面（法平面）——同一个向量，落在分母上就是直线，落在系数上就是平面。曲面那一列完全对称：法向量当法向量写切平面，当方向向量写法线。做题时如果式子「看着像」但意思不对，十有八九是把这两个角色换错了。

预备：一元向量值函数的三个要点

00:00第一个工具是一元向量值函数。定义很朴素：如果一个向量的三个分量都由同一个变量 t 决定，例如

⃗r(t)=(f1(t),f2(t),f3(t))

那么 t 一变，三个数跟着变，整个向量就变了——这就叫「一元向量值函数」。02:13「一元」是因为变量只有一个 t，「向量值」是因为函数值是一个向量而不是一个数。老师强调过：这部分不需要背太多定理，理解它「是什么东西」就够了，因为后面真正要用到的只有一个概念——导向量。

04:10它的几何含义最有信息量：把 t 固定成一个值得到一个向量，把起点放在原点，终点就落在空间某个位置上。让 t 连续变化，这个终点就会走出一条空间曲线。所以课本那句「一元向量值函数与空间的一条曲线对应」，说的就是这件事：曲线是终点画出来的轨迹，而向量值函数是「从原点出发指向曲线上一点」的那支箭。

08:35求导（课本叫导向量）只做一件事：三个分量各自求导。对上面的 ⃗r(t) 就是 ⃗r'(t)=(f1',f2',f3')。10:16求完要留意两点：它还是向量，而且里面还带着 t——所以做题时必须先在切点处把 t0 定出来，再把 t0 代进去，才能拿到一个具体的向量。

11:31导向量与切向量：为什么有两个切向量、却只有一个导向量

老师拿一条线讲这一段：过曲线上的一点作切线，这条切线是一条直线，而直线向两端无限延伸。11:31「从这个点朝左边沿着切线引一个向量，是不是也叫切向量？朝右边引一个，是不是也是个切向量？」所以切向量有两个，方向相反。

但导向量只有一个。12:45理由很干脆：t 取定一个值代进去，三个分量就都成了确定的数，这个向量就被算死了，哪来的第二个？那它到底是朝左那个还是朝右那个？课本规定：导向量的方向与 t 增长的方向一致。

15:37两个例子把这件事说透。第一个：⃗r(t)=(t,t,t)。t 增大时三个坐标同比例增大，曲线是从原点朝斜上方长出去的直线——15:37老师说这就像「拿一根拖把棍正正地杵在墙角上」。它的导向量是 (1,1,1)，朝上，与 t 增大的方向一致。

18:20第二个：⃗r(t)=(−t,−t,−t)。这条曲线的形状就是同样的那条直线，但 t 增大时三个坐标越来越小，动点反而朝下走，于是导向量是 (−1,−1,−1)——朝下。

同一个几何图形，参数化方式不同，导向量就可能反向。这说明切向量只关心「方向所在的那条直线」，而导向量额外认了一个朝向，这个朝向完全由参数 t 定出来。

例 120:41设 ⃗r(t)=(t2+1,4t−3,2t2−6t)，求曲线在 t=2 处的单位切向量。

思路：先求导向量，再除以它的模；「单位切向量」与「导向量」是两个东西

第一步，逐分量求导。t2+1 求导得 2t，4t−3 求导得 4，2t2−6t 求导得 4t−6，所以

⃗r'(t)=(2t,4,4t−6)

第二步，代入 t=2。

⃗r'(2)=(4,4,2)

顺手把切点也算出来：⃗r(2)=(5,5,−4)。

第三步，求模。|⃗r'(2)|=16+16+4=36=6。

第四步，单位化。三个分量同除以 6，约分后

±(23,23,13)

22:19老师在这里专门提了一句：「这个求出来的是导向量，你在书上不妨写一下子。」24:13然后他补了一句很关键的话：「其实我们后面用的就是这个切向量——因为不管是曲线还是曲面，切向量都是有用的。」

这一步最容易错：把「单位切向量」当成「导向量」

只写 (4,4,2) 就交卷。题目问的是单位切向量，必须再除以模 6。反过来，如果题目只要「导向量」或「切向量」，模就不必求，写成 (4,4,2) 反而更简洁。

还有一个符号上的问题：既然切向量有两个方向，答案写成 ± 最稳妥。如果题目额外规定了「与 t 增长方向一致」，那就取正号那一支。

曲线（一）：参数方程给出的曲线

29:08设空间曲线由参数方程 x=x(t)、y=y(t)、z=z(t) 给出。上一段的结论直接用：这其实就是向量值函数 ⃗r(t)，而 ⃗r'(t0) 就是切向量。30:31所以切线用点向式写：

x−x0x'(t0)=y−y0y'(t0)=z−z0z'(t0)

31:57法平面过同一个点、法向量取同一个 ⃗r'(t0)，用点法式写：

x'(t0)(x−x0)+y'(t0)(y−y0)+z'(t0)(z−z0)=0

29:08这里有一个容易被忽略的对应关系：直线是「一点加一个方向向量」确定的，平面是「一点加一个法向量」确定的——老师顺口把这句老话重念了一遍：「直线是点和方向向量确定，平面是用点和它的法向量，叫什么式？点法式。」整节的算术就是从这句话开始的。

例 232:39设曲线 x=t、y=t2、z=t3，求它在点 (1,1,1) 处的切线与法平面。

思路：先把参数值定出来，再逐分量求导

第一步，定 t0。三个坐标都是 1，代人参数方程立刻看出 t0=1。

第二步，求切向量。逐分量求导得 (1,2t,3t2)，33:42把 t=1 代进去：

⃗r'(1)=(1,2,3)

第三步，写切线。点是 (1,1,1)，方向向量是 (1,2,3)，直接套点向式：

x−11=y−12=z−13

第四步，写法平面。点不变，切向量改当法向量，套点法式：

1(x−1)+2(y−1)+3(z−1)=0⟹x+2y+3z=6

要点：这道题唯一的新东西是「先找 t0」。找到它，切向量的分量和切点的坐标就都从同一个 t0 出来，两个结果不会打架。

曲线（二）：两种「绕」的输入形式

35:44课本接着给了两种看起来不一样、其实是一回事的曲线给法。第一种：曲线写成 y=y(x)、z=z(x)。36:59这种形式不需要单独记公式——只要想起一句话：把 x 也看成 x 的函数，那它还是参数方程，只不过参数换成了 x 自己。三个分量是 x、y(x)、z(x)，逐个求导就是 1、y'、z'：

⃗r'(x0)=(1,y'(x0),z'(x0))
那个 1 是本节的头号丢分点

36:59「x 看作 x 的函数，x 对 x 求导就是一」——这个 1 不是题目给的，也不是猜的。漏掉它，切向量的第一个分量就没了，切线方程的第一个分母、法平面的第一个系数会一起崩掉。

同理，如果曲线写成 x=x(y)、z=z(y)，切向量就是 (x',1,z')。谁是自变量，谁的位置上就站着一个 1。

37:41第二种给法更绕：曲线不给方程，而是两张曲面相交得到的，写成

{F(x,y,z)=0G(x,y,z)=0

38:26理论部分老师说「咱也不讲了」，直接上例子。他举的就是课本上那道经典题。

例 338:26设曲线由 x2+y2+z2=6 与 x+y+z=0 相交而成，求它在点 (1,−2,1) 处的切线与法平面。

思路：把 y、z 都看成 x 的函数，两个方程各对 x 求一次导

第一步，看清这是什么。上面是球面，下面是平面——39:57这两张面一交，交线是一个落在平面 x+y+z=0 上的圆。

第二步，两边同时对 x 求导。39:57老师在这里停下来敲了黑板：「你一定要注意 y 和 z 都是 x 的函数。我们到目前为止，求导、求偏导大家已经全乱套了——什么时候是求导、什么时候是求偏导？」这一句必须记牢：沿着曲线走的时候，y、z 不是自由的，它们跟着 x 动。

40:52球面方程对 x 求导（y2、z2 都是复合函数，要补 y'、z'）：2x+2yy'+2zz'=0，消去 2 得

x+yy'+zz'=0

平面方程对 x 求导：1+y'+z'=0。两个式子合起来就是一个二元一次方程组：

{yy'+zz'=−xy'+z'=−1

第三步，用克莱姆法则解出 y'、z'。42:13老师说「这不又到了我们熟悉的克莱姆法则吗」，43:01解出来是

y'=z−xy−z,z'=x−yy−z

第四步，代人 (1,−2,1)。y'=1−1−2−1=0，z'=1−(−2)−2−1=3−3=−1。

44:47再加上来自「x 对 x 求导」的那一项，切向量就是

⃗r'=(1,0,−1)

第五步，写切线。点 (1,−2,1)、方向向量 (1,0,−1)。这里出现了分量为 0 的情形，点向式不能照抄（下面单独讲），规范写法是拆成「连等 ＋ 单独等式」：

x−11=z−1−1,y+2=0

第六步，写法平面。法向量取同一个 (1,0,−1)：

1(x−1)+0⋅(y+2)+(−1)(z−1)=0⟹x−z=0

老师说这道题把三个坑一次踩全：切向量第一个分量的 1、「对 x 求导」与「求偏导」的区别、以及分母为 0 时怎么写。

这一步最容易错

把 x2+y2+z2=6 两边对 x 求导时把 y、z 当常数，写成 2x=0。那是求偏导的做法。曲面上随便走的时候 y、z 确实可以不动，但这里是沿着两曲面的交线走，三个坐标是绑在一起的。

曲面：先认可法向量，再写两套方程

46:38曲面的情形结构完全对称，只是主角换了人。47:39假设曲面写成隐式 F(x,y,z)=0，课本直接给出结论：

定理 · 曲面的法向量

曲面 F(x,y,z)=0 在点 P0(x0,y0,z0) 处的法向量是

⃗n=(Fx(P0),Fy(P0),Fz(P0))

其中 Fx、Fy、Fz 是 F 的三个一阶偏导数。

48:20这个向量的算法和切向量一样朴素：把 F 分别对 x、y、z 求偏导，再把点代人。49:22拿到法向量以后，法线用点向式、切平面用点法式：

x−x0Fx=y−y0Fy=z−z0Fz
Fx(x−x0)+Fy(y−y0)+Fz(z−z0)=0

注意这里的 Fx、Fy、Fz 都是在 P0 处取的值。老师说了一句特别实在的话：49:58「为什么法向量是它？一会儿我给你证明，咱放到后边，要不然我们同学就晕掉了。」他先把用法讲完，最后十分钟才回头补证明——这个顺序值得学。

例 451:33求球面 x2+y2+z2=14 在点 (1,2,3) 处的切平面与法线。

思路：先移项凑成右边为 0，再求三个偏导

第一步，写成 F=0 的形式。52:30F(x,y,z)=x2+y2+z2−14。检验点：1+4+9=14 ✓。这一步不能省——52:30「因为右边不是 14 吗？咱先给它挪过去。」

第二步，三个偏导。Fx=2x、Fy=2y、Fz=2z。53:14代入 (1,2,3)：

⃗n=(2,4,6)

第三步，写法线。54:57三个分母有公因子 2，约掉以后用 (1,2,3) 更清爽：

x−11=y−22=z−33

第四步，写切平面。法向量取同一个 (1,2,3)：

1(x−1)+2(y−2)+3(z−3)=0⟹x+2y+3z=14

1:03:49老师说他自己喜欢先写法线，原因很实用：「法线写出来以后，写切平面的系数就直接抄这三个分母，不用再想一遍。」先写切平面再回头写法线，就没有这个便利。

曲面写成 z=f(x,y)：那个 −1 是从哪来的

56:00课本接着给了显函数形式：曲面由 z=f(x,y) 决定。这当然更省事，但必须先把它翻成上一段那种「右边为 0」的样子：

F(x,y,z)=f(x,y)−z=0

57:25现在求三个偏导，关键在于把 x、y、z 看成三个互相独立的变量：

Fx
f(x,y) 对 x 求偏导就是 fx，而 −z 跟 x 无关，导数为 0。所以 Fx=fx。
Fy
同理，Fy=fy。
Fz
f(x,y) 里根本没有 z，导数为 0；只剩 −z 对 z 求导，得 −1。

59:46于是法向量是

⃗n=(fx(x0,y0),fy(x0,y0),−1)
为什么第三个分量永远是 −1，与 f 长什么样无关

换个角度想更直观：沿着 z 轴方向往上走一步，z 增加 1，那么 F=f(x,y)−z 就减少 1。所以 F 沿 z 方向的变化率恒为 −1——59:46老师原话是「对 z 求偏导是最简单的，因为 xy 都看作是常数，z 对 z 求导是个一，所以这个地方就是个负一」。

它是整个法向量里唯一不依赖于 f 的分量。这也解释了一个现象：为什么老师讲到显函数时反复念叨「这个地方一直都是个一」——56:00他指的是后面要讲的方向余弦公式里会把它翻成 +1（整体取反朝上），但⃗n 本身那里是 −1。

如果当初写成 F=z−f(x,y)，法向量就变成 (−fx,−fy,1)，只是整体差一个符号。符号不影响方程：切平面两边同乘 −1 还是同一个平面，法线三个分母同乘 −1 还是同一条直线。真正要命的是切平面与法线用了差一个负号的两个向量——那它们就不再垂直了。

例 51:02:20求旋转抛物面 z=x2+y2−1 在点 (2,1,4) 处的切平面与法线。

思路：z 已经是 x、y 的显函数，直接用 (fx,fy,−1)

第一步，认准 f 并检验点。f(x,y)=x2+y2−1；22+12−1=4 ✓，与题目给的 z=4 一致。

第二步，求偏导并代入。fx=2x、fy=2y；在 (2,1) 处 fx=4、fy=2。所以

⃗n=(4,2,−1)

第三步，写法线。点 (2,1,4)、方向向量取 ⃗n：

x−24=y−12=z−4−1

第四步，写切平面。

4(x−2)+2(y−1)−1⋅(z−4)=0⟹4x+2y−z=6

检验：4⋅2+2⋅1−4=6 ✓，切点确实在平面上。

要点：这道题和例 4 的唯一区别，是法向量的第三个分量从「2z 在 P0 处取值」变成了「固定的 −1」。记住这一处区别，显函数形式的题就再没有新东西了。

1:05:04法向量朝上还是朝下，随你

(4,2,−1) 的第三个分量是负的，说明这支法向量指向下方。1:05:52课本为了让它「与 z 轴正向成锐角」，把它整体取反成 (−fx,−fy,1)，再拿去求方向余弦。对求切平面和法线来说，这两种取法完全等价，只要同一道题里前后一致即可。

特例：向量某个分量为 0 的时候怎么办

这是全节最容易「式子写出来自己都觉得别扭」的地方，单拎出来说清楚。

情形一：切向量的某个分量为 0。例 3 就是这种情况，⃗r'=(1,0,−1)。点向式 x−x0x'=y−y0y'=z−z0z' 是三个分式连等，而分母一旦为零，这个写法就不再有意义。正确的理解是：某个分量为 0，说明沿着这条切线走的时候，对应的那个坐标从头到尾不变，这其实是一条额外的信息，必须单独写出来。

  • 若 y'=0，就写成 x−x0x'=z−z0z' 并且 y=y0（即 y−y0=0）。例 3 的结果 y+2=0 就是这个意思。
  • 若有两个分量为 0（例如 ⃗r'=(0,0,1)），那切线就是一条平行于 z 轴的直线，写成 x=x0、y=y0 即可。

情形二：法向量的某个分量为 0。这时切平面的点法式仍然照写，只是对应项的系数变成 0，这一项直接消失。例如在抛物面 z=x2+y2−1 上取点 (0,1,0)：fx=2x=0、fy=2y=2，所以 ⃗n=(0,2,−1)，切平面是

0⋅(x−0)+2(y−1)−1⋅(z−0)=0⟹2y−z=2

而法线的第一个分母是 0，同样要拆开写：y−12=z−1 且 x=0。

一条通用判据

凡是分母或系数里出现 0，先别急着「约掉」或者「当作没有」。那个 0 是一个方程：切向量分量 =0 意味着某个坐标是常数（切线落在某个坐标平面内）；法向量分量 =0 意味着切平面平行于某条坐标轴。把它写成一个单独的等式，既不会错，也顺手检查了自己的答案是否合理。

补证明：为什么法向量偏偏是 (Fx,Fy,Fz)

1:11:46现在回头补上开头欠下的那笔账。要证的事情是：曲面上过 P0 的一切曲线，它们在 P0 处的切向量都落在同一张平面里，而这张平面就是切平面，垂直于它的那个向量就是 ⃗n=(Fx,Fy,Fz)。

  1. 任取一条曲线。1:09:23曲面上过 P0 有一条曲线，写成参数方程 x=x(t)、y=y(t)、z=z(t)，并且 t=t0 时对应的就是 P0。它的切向量是 ⃗r'(t0)=(x'(t0),y'(t0),z'(t0))。
  2. 曲线在曲面上，所以满足曲面方程。1:12:53把曲线的三个分量代进 F，得到 F(x(t),y(t),z(t))≡0。这是恒等式——曲线上每一个点都满足它。
  3. 两边对 t 求导。1:14:04这里要看清「三条路」：F 先经过 x、y、z 三个中间变量，再经过 t。于是按复合函数求导法则
    Fxx'(t)+Fyy'(t)+Fzz'(t)=0
    右边为 0，因为左边的恒等式恒等于 0。
  4. 把等式读成两个向量的数量积。1:14:57左边这个式子，恰好是「(Fx,Fy,Fz)」与「(x',y',z')」的数量积。两个向量的数量积等于 0，说明它们垂直。
  5. 分清谁固定、谁在变。1:16:40这是整个证明的灵魂。曲面是固定的，所以 Fx、Fy、Fz 作为函数是固定的；点 P0 也是固定的，代入以后这三个值成了确定的数——(Fx,Fy,Fz) 完全固定。而曲线上过 P0 的曲线可以任意取，取一条变一条，⃗r'(t0) 跟着变。
  6. 结论。1:18:47一个固定的向量，与一切变化的切向量都垂直——那么这些切向量只能全都躺在一个平面上，这个平面就是切平面。它的法向量自然就是那个固定的向量 (Fx,Fy,Fz)。
「为什么法向量要这么取」这个问题的答案

1:18:47证明结束后老师说了一句很坦诚的话：「有同学问：老师，法向量你为什么要取这个东西？——因为我们是由这个式子推出来的。我们发现这三个东西组成的向量，和它所有的导向量都是垂直的，所以我们把这个向量拿来做它的法向量。」

这句话把顺序讲清楚了：不是先规定「法向量是谁」，再验证它垂直于切线；而是先有了「垂直于一切切线」这个要求，再从推导里看出这个要求的解就是 (Fx,Fy,Fz)。

把这一段和 方向导数与梯度 对照着看会更爽：在 方向导数与梯度 里，同一条结论是从「梯度垂直于等值面」推出来的——因为 F=C 正是一族等值面，而 gradF=(Fx,Fy,Fz)。两条完全不同的路（一条走几何、一条走方向导数）通向同一个向量，说明它确实是本质的。

易错清单

一 · 切向量的第一个分量 1 忘了写

只要曲线写成 y=y(x)、z=z(x)，或者由两曲面相减消去一个变量得到，切向量一定长成 (1,y',z') 这样。44:47老师在例 3 里专门回头问了这个问题：「这个地方为什么是个 1？——x 看作 x 的函数，x 对 x 求导是一。」判据：切向量有三个分量，任何时候都不该只剩两个。

二 · 「对 x 求导」被做成了「求偏导」

两曲面相交给出的曲线，求导时 y、z 都要补 y'、z'；曲面方程求法向量时，x、y、z 是三个独立变量，互不牵连。区别不在写法，而在「有没有只让一个变量动」：沿着曲线走，三个坐标绑在一起动；在曲面上求偏导，只让一个动。

三 · 显函数形式的 −1 写成 0 或漏掉

z=f(x,y) 时法向量是 (fx,fy,−1)，第三个分量恒为 −1，不是 0，也不是 −fz（这里根本没有 fz 这个东西，f 只是 x、y 的函数）。它来自 F=f(x,y)−z 里的那一项 −z。

四 · 切平面与法线用了差一个负号的法向量

切平面用 (fx,fy,−1)、法线用 (−fx,−fy,1)，两个符号各取一个——这样切平面与法线就不再垂直，必然算错。做法：先把 ⃗n 写在草稿纸最上面，后面两个方程都从同一个 ⃗n 抄。

五 · 分量为 0 时照抄点向式

点向式只在三个分量全不为 0 时能直接写。有分量为 0 时，把那一项拆成单独的等式（例 3 的 y+2=0、上面那个 x=0 都是这个做法）。

六 · 方程右边不为 0 就直接求偏导

用 (Fx,Fy,Fz) 之前，曲面必须先写成 F(x,y,z)=0。x2+y2+z2=14 要写成 x2+y2+z2−14=0。这道题里常数求导为 0，侥幸不影响；但换成 x2+y2=2z 这类题，不移项直接对左边求偏导就会少掉分量。
