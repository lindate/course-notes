一句话核心

画图不是「凭感觉描点」，而是把定义域 / 奇偶周期 / 一二阶导 / 渐近走向逐项算清，再落笔。核心口诀：一阶导管单调与驻点，二阶导管凹凸与拐点；最后把所有信息收进一张表，照表描图。渐近线要分水平、铅垂、斜三种，按「铅垂 → 水平 → 斜」的顺序排查。

六步法：把「画图」变成「查表」

00:01老师开篇就交底：画图这部分不算考试重点，因为「比较麻烦」，但一般步骤必须了解。他把流程总结成六步，本质是让画图从「凭手感」变成「按清单逐项填」：

  1. 定义域：先搞清楚函数在哪有定义。
  2. 奇偶性、周期性：周期性用得少，但奇偶性要查——它直接决定图像是否对称，能少画一半。
  3. 求一阶导、二阶导：一阶导判断单调与找驻点；二阶导判断凹凸与找拐点。
  4. 令导数为零及特殊点：f'(x)=0（驻点）、f''(x)=0（拐点）、原函数为零的点、间断点、f' 与 f'' 不存在的点。
  5. 渐近线：水平渐近线、铅垂（铅直）渐近线；斜渐近线用得少。
  6. 描图：把上面信息收进一张表，照表落笔。

00:45一句话记住分工：一阶导回答「往上还是往下走」，二阶导回答「凹着还是凸着走」。单调性很简单——一阶导大于零单调增、小于零单调减，和高中的讲法一致；真正要小心的是凹凸性与二阶导正负的关系。

二阶导正 = 凹，负 = 凸，为什么

二阶导是「一阶导的变化率」。二阶导为正，说明斜率越走越大——曲线越走越陡，长得像碗口朝上（凹）；二阶导为负，斜率越走越小，长得像拱背（凸）。所以「凹 / 凸」看的不是函数本身的升降，而是升降的快慢在加速还是减速。

渐近线（一）：水平渐近线

05:15水平渐近线定义：如果 x→∞ 时 f(x) 的极限是个常数 A，那么直线 y=A 就是水平渐近线。这里「x→∞」要拆开看，它其实包含三种情形：

情形条件
总体limx→∞f(x)=A
单侧（正无穷）limx→+∞f(x)=A
单侧（负无穷）limx→−∞f(x)=A

只要三种里有一种极限是常数 A，就得到一条水平渐近线 y=A。多数函数左右两端趋于同一个数，只有一条；但两端趋于不同数的函数就会有两三条。

09:18水平渐近线不唯一。最经典的反例是 arctanx：当 x→+∞ 时它逼近 y=π2，当 x→−∞ 时它逼近 y=−π2——一条函数图像可以有两条水平渐近线。做题时思路是：先看 x→∞ 整体极限是不是一个固定数；如果要分正负无穷讨论，就分开讨论。

说「y=0」不要说「x 轴」

12:26老师专门纠正过用语：我们说的是「直线」，应写成 y=0；说「x 轴」不规范，因为坐标轴是规定了原点、正方向、单位长度的数轴，而渐近线只是一条线。考试写 y=0 就够。

渐近线（二）：铅垂渐近线

14:10铅垂（也叫铅直、垂直）渐近线定义：如果 x→a 时 f(x)→∞，那么直线 x=a 就是铅垂渐近线。逼近可以从左边（x→a−）也可以从右边（x→a+），只要有一侧极限是无穷即可。

15:49它最常见的来源就一句话：分母为零。比如 y=1x，当 x→0 时极限是无穷，所以 x=0（即 y 轴）是铅垂渐近线。再比如 lnx，当 x→0+ 时趋于 −∞，x=0 也是它的铅垂渐近线（只从右侧逼近）。

还有斜渐近线（考得少，但公式要会）

除了水平、铅垂两种，还有「斜渐近线」y=kx+b（k≠0）：当 x→∞ 时曲线无限贴近一条斜线。老师明确说「用的比较少」，所以六步法里把它放在可选位置——但求它的公式考试会考，下面单独讲。

查找渐近线建议固定顺序，免得漏或白费功夫：先查铅垂——把使分母为零（或对数真数趋于 0）的 x 拎出来，看单侧或双侧极限是否无穷；再查水平——看 x→±∞ 的极限是否为常数；若水平没有，才考虑斜的。像本节这种多项式，两端奔向无穷但不是贴近某条固定直线，三种渐近线一概没有，这步直接跳过即可。

铅垂渐近线也不唯一

17:34见过 tanx 的图像吗？它在每个 x=π2+kπ 处都窜向无穷，所以有无数条铅垂渐近线。结论和水平渐近线一样：数量没有上限，见到「趋于无穷」就记一条。

渐近线（三）：斜渐近线怎么求

03:15水平渐近线管的是「曲线最终变成一条水平线」，但如果曲线两端是斜着奔向无穷——比如 y=x+1x 向右上方跑——那就既没有水平渐近线，也可能没有铅垂渐近线，得看斜的。判断方法分两步：先求斜率 k，再求截距 b。

斜渐近线的求法

若 y=f(x) 满足

k=limx→∞f(x)x,b=limx→∞(f(x)−kx)

且 k 存在、k≠0、b 也存在，则直线 y=kx+b 就是斜渐近线。两个极限缺一不可。

这两个极限是怎么想出来的

假设曲线真的贴着一条斜线 y=kx+b，那么当 x 很大时两者之差应趋于 0：f(x)−(kx+b)→0。

两边同除以 x：f(x)x−k−bx→0。后两项里 bx→0，于是f(x)x→k——这就是第一个公式，先把斜率「量」出来。

斜率到手后，代回原式就得到 f(x)−kx→b，截距也随之「量」出来了。所以两个公式不是硬背的，而是「假设贴着斜线 → 两边除掉 x」自然挤出来的。顺序也不能颠倒——先有 k，才求得了 b。

把它用在 y=x+1x 上：f(x)x=1+1x2→1，所以 k=1；再算 f(x)−kx=1x→0，所以 b=0。于是斜渐近线是 y=x——图像离原点越远，越贴着这条直线。

渐近线排查的标准顺序

05:15三种渐近线混在一起容易乱，老师给的顺序是一条固定的链：先查铅垂 → 再查水平 → 最后才查斜。理由很实在——铅垂渐近线来自「分母为零」这类明显坏点，一眼能找；水平渐近线只要算一次 x→±∞ 的极限；只有前两条都没有时，才值得动 k、b 两个极限去查斜的。

类型判据方程常见出现场合
铅垂x→a 时 f(x)→∞x=a分母为零、对数真数趋于 0（1x、lnx、tanx）
水平x→∞ 时 f(x)→Ay=A趋于定值的函数（arctanx、e−x）
斜k=limf(x)x≠0 且 b=lim(f(x)−kx) 都存在y=kx+b增长得像一次函数的函数（x+1x、x2x−1）
三条容易踩的线
  • 把水平渐近线和斜渐近线同时算。同一方向（如 x→+∞）上两者二选一：limf(x) 是常数就是水平线；不是常数却又能被一次函数追上，才是斜线。不会同时出现。
  • 只算了 limf(x)x 就下结论。k 存在只是必要条件，还得看 b 是否存在。两个都算完才能写 y=kx+b。
  • 以为曲线不能穿越渐近线。渐近线只管「远处贴近」，中途交叉完全允许（见上图）。

例求 y=x2x−1 的所有渐近线。

思路：按「铅垂 → 水平 → 斜」的顺序逐项排查

第一步，铅垂。分母 x−1=0 得 x=1。当 x→1 时分子趋于 1、分母趋于 0，函数值窜向无穷，所以 x=1 是铅垂渐近线。

第二步，水平。看 x→∞ 时 x2x−1→+∞，不是常数，没有水平渐近线。既然没有水平线，才轮到查斜的。

第三步，斜。先求斜率：f(x)x=xx−1→1，得 k=1。再求截距：

b=limx→∞(x2x−1−x)=limx→∞x2−x(x−1)x−1=limx→∞xx−1=1

所以斜渐近线是 y=x+1。一共两条渐近线：x=1 与 y=x+1。

验算一遍更放心

对 x2x−1 做多项式除法：x2x−1=x+1+1x−1。末尾那个 1x−1→0，所以 x 很大时函数值确实趋于 x+1——斜渐近线一眼可见。能除尽就先做除法，斜渐近线会自己跳出来，这是最快的验算手段。

例20:05用六步法画 y=x3−x2−x+1 的图像。

下面把六步法走一遍。函数 y=x3−x2−x+1。

第一步 定义域：多项式，定义域是 (−∞,+∞)，无特殊限制。

第三步 求导（奇偶周期这里没有）：

f'(x)=3x2−2x−1,f''(x)=6x−2

这里为什么是三个切分点、得到四段？因为驻点有 (−13,1) 两个、拐点候选 13 一个，共三个「符号可能变号」的位置。把它们按从小到大排好，相邻两个之间符号不会再变，于是每一段内的单调、凹凸都恒定，可以放心下结论。通用配方是：切分点个数 = 驻点个数 + 拐点候选个数，列表法照此切段即可。

第四步 特殊点：令 f'(x)=0：

3x2−2x−1=0⟹(3x+1)(x−1)=0⟹x=−13,1

这两个是驻点。令 f''(x)=0 得 x=13，这是拐点候选。

列表：用三个点把数轴切开

23:39用 −13、13、1 三个点把 (−∞,+∞) 切成四段，逐段判一阶导、二阶导符号。考试时建议按下面这张表的六列写全——右侧三列是把两个符号「翻译」成人话，答题分就落在这里：

区间f'(x)f''(x)单调性凹凸结论
(−∞,−13)+−单调增凸增且凸，曲线鼓着上升
(−13,13)−−单调减凸减且凸，鼓着下降
(13,1)−+单调减凹减且凹，兜着下降
(1,+∞)++单调增凹增且凹，兜着上升

27:05符号判断的小技巧：f'(x)=(3x+1)(x−1)，看两个因式正负；二阶导 6x−2 只在 x=13 变号，所以 x>13 全凹、x<13 全凸。

把四段摊开读：「单调增」出现了两次（第一段与第四段），但一个「增且凸」、一个「增且凹」；「单调减」也两次，同样一个凸一个凹。可见一阶导只回答「往上还是往下走」，二阶导才回答「拱着还是兜着走」——两者合起来才能唯一确定每一段曲线的形状。漏掉二阶导，你连这一段该拱起来还是塌下去都不知道，图就画不出来。所以老师反复强调：这张表是整个画图过程的「核心」，所有信息都先集中到表里，再照表落笔。

拐点的判定

二阶导在 x=13 左侧为负（凸）、右侧为正（凹），凹凸性发生翻转，所以 x=13 是真正的拐点。驻点 x=−13 处一阶导由正变负，是局部极大；x=1 处一阶导由负变正，是局部极小。

算关键点，照表描图

32:08把几个关键横坐标代回原函数取函数值。先因式分解更省力：

因式分解这一步不只是为了求零点，更是为了「一眼看出曲线从哪穿过 x 轴」：(x+1)(x−1)2 告诉我们 x=−1 是单根（曲线斜穿过去）、x=1 是二重根（曲线在这里「贴着」x 轴但不穿过，因为 (x−1)2≥0 始终非负）。所以 (1,0) 既是根又是局部极小，图像在该点轻轻「吻」一下 x 轴再弹起——这和表里「x=1 处由减转增」完全吻合。

f(x)=x3−x2−x+1=(x2−1)(x−1)=(x+1)(x−1)2

由此可知 f(−1)=0、f(1)=0；再算：

f(−13)=3227(局部极大),f(13)=1627(拐点),f(0)=1,f(32)=58

照表落笔时，从左到右一段段画：最左段「增且凸」，曲线从左下昂头、向上鼓着往右上爬，到 (−13,3227) 达到局部极大；接着「减且凸」，调头向下、仍向上鼓，过拐点 (13,1627) 后转为「减且凹」——这里凹凸翻面，曲线从「鼓着下」变成「兜着下」；继续下行到局部极小 (1,0)；之后「增且凹」，从 x 轴弹起、兜着向下一路向右上冲。补点 f(32)=58 确认它确实在 (1,0) 上方继续上升。整张图就是把表里四行的「增 / 减 × 凸 / 凹」逐字翻译成笔触。

42:11补点的作用

x=32 这种点没有特殊意义，纯粹是为了「描图时心里有底」——你知道曲线过了 (1,0) 之后是朝上走，再补一个点确认弧度即可。老师说：「x 等于二也行啊，你整个二不也行吗？」他原文用的就是 32。老师还说过一句大实话：「画图还是有点麻烦是吧」——所以这一节不是考试重点，但流程是死的，照六步走就不会乱。

例用六步法讨论 y=x2x−1 的图像（带渐近线的完整流程）。

思路：上一题是多项式（无渐近线），这一题专门把渐近线那一步用上

第一步 定义域。分母 x−1≠0，所以定义域是 x≠1——注意这一点会在图上留下一条铅垂渐近线。

第二步 奇偶周期。把 x 换成 −x 得到 x2−x−1，既不等于原式、也不等于负原式，非奇非偶；也不是周期函数。这两项都查不出信息，跳过。

第三步 求导。用商的求导法则：

f'(x)=2x(x−1)−x2(x−1)2=x2−2x(x−1)2=x(x−2)(x−1)2
f''(x)=(2x−2)(x−1)2−(x2−2x)⋅2(x−1)(x−1)4=2(x−1)3

二阶导化简后这么短，是因为分子里 (x−1) 被约掉了一次——先把 (x−1) 提出来约，比硬展开省力得多。

第四步 特殊点。令 f'(x)=0，因为分母 (x−1)2>0 恒正，只需 x(x−2)=0，得驻点 x=0 与 x=2。令 f''(x)=0——但分子是常数 2，永远不为 0，所以没有拐点候选。另外 x=1 是间断点，必须单独作为切分点写进表里。

第五步 渐近线。先查铅垂：x→1 时函数窜向无穷，故 x=1 是铅垂渐近线。再查水平：x→∞ 时 x2x−1→+∞，不是常数，没有水平渐近线。最后查斜：前面算过 k=1、b=1，所以斜渐近线是 y=x+1。三条里齐了两条。

第六步 列表。切分点用 0、1、2（1 是间断点也要切）把数轴分成四段：

区间f'(x)f''(x)单调性凹凸
(−∞,0)+−单调增凸
(0,1)−−单调减凸
(1,2)−+单调减凹
(2,+∞)++单调增凹

关键点函数值：f(0)=0、f(2)=41=4。所以 x=0 处是局部极大（f' 由正变负，值 0），x=2 处是局部极小（f' 由负变正，值 4）。

落笔。左端沿斜渐近线 y=x+1 贴上来，增且凸地爬上 (0,0) 这个局部极大；随后减且凸，一路向左下冲向 x=1 这条铅垂线；越过 x=1 后从右上重新出现（凹，减）下行到 (2,4)；最后增且凹，向右上重新贴近斜渐近线 y=x+1。

这一步最容易错

把间断点 x=1 漏出切分点。列表的切分点不只是驻点和拐点候选，间断点、导数不存在的点都要一并切。漏掉 x=1，你会在 (0,2) 上一路画成连续的下降，完全看不出曲线在 x=1 两侧是「两支」——而这两支正是铅垂渐近线的两张脸。

记忆入口 · 一眼回忆

一句话

画图 = 一阶导管升降、二阶导管凹凸，再补渐近线，最后照表描。

六步

  1. 定义域
  2. 奇偶 / 周期
  3. 求 f'(x)、f''(x)
  4. 令 f'=0（驻点）、f''=0（拐点）、间断点、导数不存在点
  5. 水平 / 铅垂渐近线
  6. 列表描图

三种渐近线

  • 铅垂：x→a 时 f(x)→∞ ⇒ x=a（常因分母为零，如 tanx 多条）
  • 水平：x→∞ 时 f(x)→A ⇒ y=A（可多条，如 arctanx）
  • 斜：k=limf(x)x≠0、b=lim(f(x)−kx) ⇒ y=kx+b（同一方向上与水平线二选一）
