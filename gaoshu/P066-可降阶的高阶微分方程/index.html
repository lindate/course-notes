P066可降阶的高阶微分方程：缺什么，就换什么

一句话核心

高阶方程一般很难，但有一批「残缺」的高阶方程可以从容降阶。判断的依据只有一条：方程里缺了谁——右边只有 x，就两边直接积分；缺 y、只剩 y(n) 与 y(n−1)，就令 u=y(n−1)；缺 x、右边出现 y 与 y'，就令 p=y' 并把 p 看成 y 的函数。降成一阶之后，前面三节的工具全部照用。

三种「残缺」的高阶方程

二阶、三阶、四阶方程一般都不好惹，但有一批方程可以「降阶」——把高阶的问题一层层剥下去，剥到一阶，就能用前面三节的方法解决。老师说这一部分拿出来的是比较简单的、可以通过降阶的方式化成简单的方程来求的。

能不能降阶，判据非常朴素：看方程里缺了谁。三种情形各缺一样东西，配三种不同的处理手法。先把总表摆出来：

类型方程里缺什么设什么降成什么
一 y(n)=f(x)：右边只有 x，没有 y 的任何影子 不用换元 两边积分，一直积到最后，共积 n 次
二 只出现 y(n)、y(n−1) 与 x，缺 y 及其低阶导数 u=y(n−1) 关于 u 的一阶方程（可分离 / 线性都行）
三 y''=f(y,y')：右边有 y 与 y'，缺 x p=y'，并把 p 看作 y 的函数 关于 p 与 y 的一阶方程（x 不再露面）

这张表就是本页的全部骨架。下面三类逐个讲透，重点放在「为什么后两类要那样设」——这两类的设法学错了，后面就全盘皆输。

类型一：y(n)=f(x)，右边只有 x

先说一个容易看岔的地方：y(n) 的括号里是阶数，不是幂次——y(4) 是「y 的四阶导数」，不是「y 的四次方」。老师特意强调：这个 y 的 n 不是 y 的 n 次方，是 y 的 n 阶导数。

类型一的特征是右边只和 x 有关，不能出现 y。解法没有技巧：两边同时积分，n 阶降成 n−1 阶；再积一次，降到 n−2 阶……一直降到 y 为止。

例 101:47求 y(4)=2x 的通解。

思路：一路积分，边积边把常数收拾整齐

两边第一次积分（2x 的原函数是 x2）：

y'''=x2+C

05:22老师在这里说了一句很实在的话：因为咱也不知道后面事情会变到什么地步，所以咱先加个 C。——每积一次就冒出一个常数，先把它们都写下来，最后再统一整理。

再积一次（x2 的原函数是 x33，C 的原函数是 Cx）：

y''=x33+Cx+C1

第三次（x33 的原函数是 x412，Cx 的原函数是 C2x2）：

y'=x412+C2x2+C1x+C2

第四次积分，得到 y：

y=x560+C6x3+C12x2+C2x+C3

写到这一步已经是对的。但老师又做了一步「好看化」：常数本身是任意的，所以 C6、C12 这样的系数完全可以吸收进常数里。于是整理成

y=x560+C1x3+C2x2+C3x+C4

最后检查一件事：这是四阶方程，通解里必须有四个任意常数——数一数，C1 到 C4，正好四个。老师说：微分方程是几阶的，就得有几个任意的常数。

课上的两个小练习也是这一路，各积到底、把常数编号理顺：

y''=x−sinx⟹y'=x22+cosx+C1⟹y=x36+sinx+C1x+C2
y'''=ex⟹y''=ex+C1⟹y'=ex+C1x+C2⟹y=ex+C12x2+C2x+C3

两道题的收尾动作都是同一件事：把系数并进常数、把编号理顺、数一遍个数。第一道是二阶，末尾两个常数；第二道是三阶，末尾三个常数。ex 反复求原函数还是 ex，是三阶里最舒服的一种。

类型二：缺 y，就令 u=y(n−1)

类型二的方程里只允许出现三种东西：最高的那个 n 阶导数、比它低一阶的 n−1 阶导数、以及 x。除此之外——尤其 y 本身——一个都不能出现。

处理办法顺理成章：既然最碍事的是「最高阶的那一个」，而它又只比另一个导数高一阶，那就把低一阶的那个整体设成一个新字母：

u=y(n−1)⟹u'=y(n)

代进去，方程里就只剩 u'、u 和 x 了——这是一个关于 u 的一阶微分方程。它可能是可分离变量的，可能是一阶线性的，可能是齐次的，看题目而定；不管哪一种，前面都学过。老师说：总而言之把它转换成了一个一阶的微分方程。

这一类的通用提醒

老师反复强调的一句话：解完以后别忘了回代。——u 是我们引进的临时变量，解出 u 只是完成了降阶，接下来还要把 u 换回 y 的导数，继续按类型一的方法一路积下去，直到积出 y 为止。这一步漏掉，答案里就会留下一个来历不明的 u。

例 2求方程 xy(4)−y'''=0 的通解。

思路：最高的两项相差一阶，正好可以整体打包

方程里出现了 y(4) 与 y'''，它们相差一阶，且不含 y——符合类型二。令

u=y''',u'=y(4)

代进去，方程变成 xu'−u=0。

第一步：解这个关于 u 的一阶方程

把 x 与 u 各自归边，它就是个可分离变量方程（可分离变量的微分方程）：

xdudx=u⟹duu=dxx

两边积分：ln|u|=ln|x|+C1。老师在这里用了一个很讨巧的写法：把常数直接写成 ln|C|，这样两个对数就能合并成乘积——咱不是不加 C 吗？咱加 ln|C|。

ln|u|=ln|x|+ln|C|⟹u=Cx
第二步：回代，然后一路积分到底

把 u 换回 y'''，得到 y'''=Cx——这已经是类型一了，两边反复积分即可：

y''=C2x2+C1,y'=C6x3+C1x+C2
y=C24x4+C12x2+C2x+C3

把系数并进常数，写成

y=C1x4+C2x2+C3x+C4

核一下常数个数：原方程是四阶，末尾正好四个任意常数，对上了。

例 3求 y'''=1xy''+2x2 的通解。

思路：还是缺 y，但降阶后是一阶线性方程

方程里只有 y'''、y'' 和 x。令 u=y''，则 u'=y'''，代入得

u'−1xu=2x2

左边 u' 的系数已经是 1，右边只有 x 的表达式——标准的一阶线性方程（一阶线性微分方程）。先把两个系数报出来：

P(x)=−1x,Q(x)=2x2

套通解公式。这里 P 里含 1x，两条指数一正一负：外层 e∫1xdx=elnx=x，里层 e−lnx=1x，于是

u=x(∫2x2⋅1xdx+C)=x(∫2xdx+C)=x(x2+C)
u=x3+Cx
回代并再次积分

把 u 换回 y''：y''=x3+Cx。这又是类型一了，积两次：

y'=x44+C2x2+C1⟹y=x520+C6x3+C1x+C2

整理常数：

y=x520+C1x3+C2x+C3

三阶方程，三个常数——对上了。

这道题的价值在于它把两节内容串起来了：降阶之后遇到的是 一阶线性微分方程 的一阶线性方程，套公式即可。也就是说，类型二本身不提供新方法，它只提供「怎么把阶数降下去」。

类型三：缺 x，就令 p=y' 并把它看成 y 的函数

第三种类型长这样：

y''=f(y,y')

老师说它有一个比较明显的特征：x 没有直接出现。这句话容易让人发懵——方程里明明没有 x，可 y 是 x 的函数啊，怎么会没有 x 呢？关键在于「直接出现」这四个字：y 里面当然藏着 x，但方程把 y 与 y' 当成两个普通的量摆在一起，x 这个字母从头到尾没有露面。

处理手法是把一阶导数设成一个新变量：

p=y'(于是 y''=p')

想法和类型二一样，都是「对二阶不熟、对一阶熟」。但这里有一处天差地别的不同：p 是 y 的函数。

y'' 为什么要写成 pdpdy

设 p=y' 之后，y'' 就是 p 对 x 的导数，也就是 dpdx。麻烦在于：题目里的右边只有 y 和 p，没有 x；如果左边留在 dpdx 这个形式上，方程里就同时出现了 y、p、x 三个量，还是解不动。

出路是把求导的「对象」从 x 换成 y。用链式法则：

dpdx=dpdy⋅dydx

而 dydx=p，所以

y''=dpdx=pdpdy

代进原方程，y''=f(y,y') 变成 pdpdy=f(y,p)——这是一个只含 p、y、dpdy 的方程，x 彻底消失了，它就是一个关于「以 y 为自变量、以 p 为函数」的一阶微分方程。

24:16老师的「灵魂拷问」：两边积分，到底对谁积

假设我们已经把 p 解出来了，写成 dydx=φ(y)。很自然的冲动是「两边同时对 x 积分」：左边积成 y，右边呢？右边是关于 y 的表达式，对 x 积分是积不出来的——除非你把 y 关于 x 的表达式代进去，可那个表达式正是我们要求的东西。那你带什么呀？你要能代还忙活啥呀？

右边对 y 积分当然能积，但左边是对 x 积的，两边积分变量不一致，这个等式没有意义。

正确的出路是先把 dy 与 dx 分开：

dydx=φ(y)⟹1φ(y)dy=dx

这一步做完，两边就可以同时积分了——左边是对 y 积（y 在左、dy 也在左），右边是对 x 积。这正是「可分离变量」的老动作（可分离变量的微分方程）。所以类型三的最后一段，其实又回到了最熟悉的地方。

例 4求方程 yy''=2(y')2 的通解。

思路：方程里有 y、有 y'、也有 y''，独独没有 x——类型三

令 p=y'，并把 p 看成 y 的函数，则 y''=pdpdy。代进去：

y⋅pdpdy=2p2

两边同时约掉一个 p（p≠0 的情形），方程立刻瘦下来：

ydpdy=2p
第一步：分离变量、解出 p 与 y 的关系

30:03这已经是可分离变量了：dpp=2dyy。两边积分：

ln|p|=2ln|y|+ln|C1|

这里老师又把常数写成了 ln|C1|，好处是右边可以合并成 ln|C1y2|，两边取指数得

p=C1y2

他说这一步判断得很准：因为它是二阶方程，最终是不是两个常数？你一个 C 肯定搞不定。所以从一开始就用带下标的 C1。

第二步：回代 p=y'，再分离一次

把 p 换回 dydx：

dydx=C1y2⟹dyy2=C1dx

两边积分：左边是 −1y，右边是 C1x，于是

−1y=C1x+C2⟹y=−1C1x+C2

这就得到了通解。核一下：二阶方程，通解里两个任意常数，正好。

32:48别忘了那个被约掉的解

约掉 p 的时候，我们等于默认了 p≠0。那么 p=0 呢？p=y'=0 意味着 y 是常数；代回原方程 yy''=2(y')2，左边 =y⋅0=0，右边 =0，成立——所以 y≡0 也是方程的一个解，它被我们的除法赶出去了。

老师说这是微分方程里非常普遍的现象：你会频繁地把某一项放到分母上，只要放到分母，你就把它等于零这种情况给排除掉了。他补了一句安慰：这个问题不算大，但求完之后回看一眼有没有漏解，是很好的习惯。y=0 求导还是零，代进方程是个恒等式。

三类放在一起：易混点在哪

三种类型的手法是「缺什么补什么」，最容易混的是后两类的「设什么」——它们都要引进一个新字母，但那个新字母的身份完全不同：

对比项类型二（缺 y）类型三（缺 x）
方程长相只有 y(n)、y(n−1) 与 xy''=f(y,y')，x 不露面
设什么u=y(n−1)p=y'
新变量是谁的函数u 仍然是 x 的函数p 要看成 y 的函数（这是关键区别）
导数怎么换y(n)=u'，直接对 x 求导y''=pdpdy，用链式法则换掉自变量
降成什么关于 u 的一阶方程关于 p 与 y 的一阶方程
解完之后回代 u，再按类型一积到底回代 p=y'，再分离变量积一次

记住一句话就够了：缺 y 的时候，大家都在「对 x 求导」的世界里，所以照旧；缺 x 的时候，必须换个世界，把自变量临时改成 y。这就是为什么后者的公式里会出现 dpdy 这种长相古怪的东西。

老师对这三类的定位

讲完三类之后，老师说了一句很实用的「考试预报」：第三种和第二种出现的可能性就比较小一些，第一种——两边直接求积分的这种——可能还会出现。

所以复习的优先顺序很清楚：类型一要练到不出错（它只是积分，但常数个数、整理方式容易丢分）；类型二、类型三要能认出类型并写对换元，剩下的计算就是前几节的基本功。
