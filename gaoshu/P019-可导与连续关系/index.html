P019可导与连续的关系

一句话核心

一句话：可导必连续，连续未必可导。「可导」比「连续」多一道关卡——不仅要一笔连得上，曲线还要光滑。所以可导函数一定连续，但连续函数可能因为尖角、垂直切线或无穷振荡而不可导。记住这条方向不能倒着用：不连续就一定不可导，但连续只是入场券，进了场才谈得上求导。

两句话，定下整页

00:00这一节最后的内容是可导与连续的关系，说到底就两句话：

  • 第一句：可导必连续。只要一个函数在某点能求导，它在这个点一定连续。
  • 第二句：连续未必可导。连续是比可导更弱的条件。前面举过的 y=|x| 就是例子——它一笔就画得出来，但在 x=0 处不可导。

第一句是定理（要证），第二句是事实（要靠反例说明）。下面先把各自的「为什么」讲清楚。

直观理解：一笔能画 ≠ 画得顺

00:37老师给的直观说法特别好记：

连续
就是一笔画——从左边连到右边，中间不能断、不能离开纸面。哪怕你画得弯弯曲曲、拐来拐去，只要没抬笔，就是连续。
可导
在「一笔画」之外，还要求曲线光滑——不能有尖角、不能突然拐弯、也不能竖起来。也就是过每一点的切线都得是「正常的」有限斜率。

这样一想，「可导」明显比「连续」多了一道关卡：连续只要求「连得上」，可导还要求「连得顺」。关卡更多，能通过的函数自然更少——所以可导的一定连续，连续的不一定可导。这个直觉是后面证明的灵魂。

两层比喻：入场券与升级

把这两个概念想成两道门槛：连续是入场券，拿着它才允许你在这一点被讨论；可导是升级考，进了场还要再考一次，考的是「切线斜率必须有限且唯一」。所以逻辑单向——有入场券不一定能升级，能升级的人一定先有入场券。

这给出一个极好用的反向判据：讨论可导性时先查连续；连连续都保不住的点，根本不必去算导数，它一定不可导。

两个定义，先摆出来

01:30证明之前，先老老实实把两个定义写清楚。我们最常用的连续定义是

limx→x0f(x)=f(x0)

但讲「可导与连续关系」时，另一个等价写法更顺手——用增量来写：

limΔx→0Δy=0（其中 Δy=f(x0+Δx)−f(x0)）

它的意思是：自变量变化量趋于 0 时，函数值的变化量也必须趋于 0。「输入几乎不动，输出也几乎不动」，这就是连续。

而可导的定义是差商的极限存在：

f'(x0)=limΔx→0ΔyΔx

把两个定义并排摆好，差别一眼可见——唯一的不同就是「除不除 Δx」：

连续（增量写法）可导
看的式子Δy 本身差商 ΔyΔx
极限是什么limΔx→0Δy=0limΔx→0ΔyΔx=f'(x0)（有限）
结果要求趋于 0 即可必须存在且为有限数
几何上曲线在这一点接得上有唯一的有限切线

连续只问「Δy 这个分子跑到哪去了」，可导问的是「分子除以分母之后跑到哪去了」。多除了一个趋于 0 的分母，要求就陡然变严——这正是「连续不一定可导」在式子层面的根源。

02:41证明前的灵魂一问：分子必须趋于 0 吗

既然导数 f'(x0) 是「极限存在」的，那这个分式 ΔyΔx 的极限就必须是个有限数。而分母 Δx 在趋于 0——如果分子 Δy 不趋于 0（比如趋于 1），那整个分式就趋于无穷大，极限就不存在了。所以反过来想：分式极限存在这件事，强行要求分子 Δy 必须也趋于 0。这正是「可导 ⇒ 连续」的命门。

这一步最容易被质疑，课上真的有人举手反问，老师的回答把两个「不一定」的区别讲得很干净——见下面那段原话。

05:13课堂上一段真实的问答（大意）

同学当场反问：老师，我记得你讲过一个东西——无穷小比无穷小，是什么？不一定啊！那你凭什么说分子一定趋于零呢？

老师：它这个逻辑是这样的：无穷小比无穷小，结果怎么样是不一定的；但是这个玩意儿，它说的是极限已经存在了。也就是说，无穷小比无穷小极限是啥不知道，但说了它——极限已经存在，那分子必须是无穷小。

一句话把关键摘出来：「不一定」说的是「结果未知」，而「极限存在」说的是「结果已知且有限」。前提不同，结论自然不同。这也提醒我们：数学里凡是要用某个性质，先回头看它的前提条件有没有满足。

严谨证明：把 Δy 拆开

06:04现在用「极限与无穷小的关系」把导数定义改写。因为

limΔx→0ΔyΔx=f'(x0)

存在且有限，所以可以把差商写成「极限值 + 一个高阶无穷小 α」：

ΔyΔx=f'(x0)+α,其中 limΔx→0α=0

两边同乘 Δx：

Δy=f'(x0)Δx+αΔx

现在对 Δx→0 取极限。第一项 f'(x0)Δx 里 f'(x0) 是常数，乘上趋于 0 的 Δx，极限是 0；第二项 αΔx 是「无穷小乘无穷小」，更是趋于 0。所以

limΔx→0Δy=0+0=0

这正是连续定义的增量写法！于是在 x0 可导 ⇒ 在 x0 连续。证明里没有用任何额外的技巧，就是把「导数存在」翻译成「Δy 能被拆成两项，每项都趋于 0」。

把这个证明取「逆否」，得到一个考试里更常用的结论：不连续 ⇒ 不可导。但反向推不出来：「在某点不可导」什么也说明不了——它可能连续（本页的主角 |x|），也可能连连续都不满足。所以不能因为「f 在这点连续」就答可导，也不能因为「不可导」就断定它不连续。

反例一：y=x3，垂直切线

07:51「连续未必可导」不能只靠一句话，得有真反例。第一个反例是 y=x3=x1/3。它在全体实数上连续（一笔画出），但在 x=0 处不可导。为什么？

先按公式求：

y'=(x1/3)'=13x−2/3=13x23

把 x=0 代进去，分母变成 0，式子无意义——所以 x=0 处导数不存在。但光看公式是「算不出」，更好的做法是回到定义把左右导数各算一遍，让「无穷大」这个模糊说法变成硬结论。在 x=0 处 f(0)=0，差商是

f(0+Δx)−f(0)Δx=Δx3Δx=1(Δx)23

分母 (Δx)2/3 恒为正（平方那一步把符号抹掉了），所以无论从左还是从右逼近，商都趋于 +∞：

f'+(0)=f'−(0)=limΔx→01(Δx)2/3=+∞

两个单侧导数都是 +∞、方向还一致，但都不是有限数，所以 f'(0) 不存在。这里藏着一个容易忽略的细节：判可导时「左右导数相等」还不够，必须先保证它们都是有限数。

08:55为什么斜率是无穷大（用高中知识也能讲）

斜率就是对边比邻边。当切线越来越接近竖直，邻边（水平方向的那一段）就越来越短、趋于 0。一个固定的对边除以一个趋于 0 的邻边，结果就趋于无穷大。老师原话：「你这个线充分垂直，邻边不就趋于零了吗？那不就无穷大嘛。」

10:33紧接着有个极易混淆的点：这条切线存在吗？存在——它就是 x=0 这条直线，方程就是 x=0。那导数存在吗？不存在。因为「切线存在」只要求有一条直线贴着曲线，而「可导」要求的是这条切线的斜率是一个有限数。无穷大不是有限数，所以切线存在 ≠ 导数存在。这是「连续不可导」的第一类情形：垂直切线。

反例二：y=|x|，尖角

00:00第二个反例就是开头提到的 y=|x|。它连续（V 形一笔画出），但在 x=0 处有个尖角——左边往上走、右边也往上走，中间拐了一下，左右两边的斜率对不上，于是导数不存在。下面这道例题把这件事讲透。

例00:00证明：y=|x| 在 x=0 处连续，但不可导。

思路：连续用增量定义，不可导用左右导数

第一步，证连续。f(0)=0，而 x=0 处的增量是 Δy=|Δx|−0=|Δx|，当 Δx→0 时 |Δx|→0，即 limΔx→0Δy=0，所以连续。

第二步，证不可导。|x| 在 0 处没有现成的求导公式，只能改用左右导数。左导数让 Δx→0−，此时 |Δx|=−Δx：

f'−(0)=limΔx→0−|Δx|−0Δx=limΔx→0−−ΔxΔx=−1

右导数让 Δx→0+，此时 |Δx|=Δx：

f'+(0)=limΔx→0+|Δx|Δx=limΔx→0+ΔxΔx=1

左导数是 −1、右导数是 +1，两者不相等。而可导的充要条件是左右导数都存在且相等，所以 f'(0) 不存在。

这一步最容易错

把 |x| 在 0 处直接写成「导数是 1 或 −1」。错在忽略「要从哪边逼近」。0 左边斜率是 −1、右边是 +1，正是这 两边对不上 才导致不可导。结论不是「导数是某个值」，而是「导数压根不存在」。

方法：分界点处怎样判可导

00:00前面两个反例都发生在「函数由两段拼起来」的分界点上（|x| 由 −x 与 x 拼成，x3 在 0 处公式失效）。这类点上的导数不能套求导公式，只能回到定义、分左右两边各算一次——这就是考试里那个固定的答题模板。

  1. 第一步：先看连续：算 limx→x0−f(x)、limx→x0+f(x) 和 f(x0)，三者相等才连续。不连续就不必往下做了，一定不可导（可导必连续，逆否即「不连续必不可导」）。
  2. 第二步：算左导数：把 Δx<0 时的 f(x0+Δx) 换成左边那一支的表达式，算 limΔx→0−f(x0+Δx)−f(x0)Δx。
  3. 第三步：算右导数：同理换右边那一支，算 limΔx→0+f(x0+Δx)−f(x0)Δx。
  4. 第四步：下结论：左右导数都存在且相等 ⇒ 可导，且 f'(x0) 就等于这个公共值；只要有一个不存在、或两个不相等 ⇒ 不可导。

回到 y=|x|：第一步连续通过了（分子 |Δx|→0），第二步得左导数 −1、第三步得右导数 +1，第四步发现「都存在但不相等」，于是卡在最后一步。这个「连续过关、最后一步失败」的剧本，正是绝大多数连续不可导函数的样子。

例用四步模板讨论 f(x)={x2sin1x,x≠00,x=0 在 x=0 处的可导性。

思路：这是一道把「连续 + 左右导数」全套走完的标准题

第一步，看连续。对 x≠0，|f(x)−f(0)|=|x2sin1x|≤x2，令 x→0 由夹逼得 f(x)→0=f(0)，故在 0 处连续，可以继续往下做。

第二步，直接写差商。因为 f(0)=0，差商自动是

f(0+Δx)−f(0)Δx=(Δx)2sin1ΔxΔx=Δxsin1Δx

第三步，求极限。这里不必分左右，因为两侧是同一个表达式。由

|Δxsin1Δx|≤|Δx|→0

夹逼得极限为 0。

第四步，下结论。差商极限存在且为 0，所以 f'(0)=0，函数在 0 处可导。

这一步最容易错

把它和 |x| 混为一谈，套「分界点必须分左右算」的模板。分不分左右，取决于差商表达式在两侧是否相同：|x| 的两侧是 −1 和 +1，必须分；这里两侧都是 Δxsin1Δx，一次算完即可。判断依据始终是「左右两支表达式是不是同一个」，而不是「这个点是不是分界点」。

为什么分界点常常要左右分开算

导数是局部概念，只看「从这一点往哪个方向走时函数怎么变」。在分界点左侧 f 用一条表达式，右侧用另一条，两条可能一个是 x、一个是 −x，也可能一个趋于有限数、一个趋于无穷。所以要问「f 在这一点怎么变」，只能分方向分别问，再要求两个答案一致。这正是「左右导数都存在且相等」这个充要条件的由来——它不是额外规定，而是「导数唯一」在分界点上的自然要求。

反例三：y=xsin1x，振荡到「没有切线」

前面两个反例，曲线在分界点附近至少是「安静」的——要么拐个尖角，要么竖起来。第三类反例更隐蔽：曲线在分界点附近来回振荡，摆动的幅度确实趋于 0，但摆动的次数是无穷多次，以至于连割线的极限都不存在。这类函数长这样：

f(x)={xsin1x,x≠00,x=0

注意 x=0 处式子本身没定义（sin10 无意义），我们补定义 f(0)=0，这是研究这类函数的常规动作。先看图。

先证连续。因为 |sin1x|≤1，所以对任何 x≠0 都有

|f(x)−f(0)|=|xsin1x|≤|x|

令 x→0，右边趋于 0，夹逼得 f(x)→0=f(0)，故在 0 处连续。

再证不可导。老规矩，写出差商：

f(0+Δx)−f(0)Δx=Δxsin1ΔxΔx=sin1Δx

这个式子的值根本不收敛：取 Δx=2(4n+1)π（n 充分大）时它恒等于 1；取 Δx=2(4n+3)π 时它恒等于 −1。两组 Δx 都趋于 0，差商却分别趋于 1 和 −1，所以极限不存在。左导数、右导数同样不存在（它们各自也在摆），于是 f 在 0 处连续但不可导。

只差一个 x，命运完全不同

把函数改一个字：g(x)=x2sin1x(x≠0)，同样补定义 g(0)=0。差商变成 g(0+Δx)−g(0)Δx=Δxsin1Δx——依然振荡，但前面多了个因子 Δx，被夹逼逼到了 0：|Δxsin1Δx|≤|Δx|→0。于是 g'(0)=0，g 在 0 处居然可导。

以为「振荡就不可导」。振荡是否致命，要看振幅有没有被压到 0 之外：f 的差商振幅恒为 1，压不下去；g 的振幅 →0，极限就存在。判断这类题只要老实写出差商、再用夹逼看一眼，就不会错。

三类反例，一张表收拢

到这里，「连续但不可导」的三类典型情形都齐了。它们的共同点是都在分界点被左右导数卡住，区别在于「卡」的方式：

类型例子左导数右导数卡在哪
尖角y=|x| 在 x=0−1+1两个都存在，但不相等
垂直切线y=x3 在 x=0+∞+∞极限不是有限数
振荡y=xsin1x 在 x=0不存在不存在差商在 −1 与 1 之间无限次摆动

顺带一个常被忽略的细节：垂直切线那一行的左、右导数都是 +∞，方向一致，但不是有限数，照样算「不存在」。所以口诀要背完整：左右导数都存在（有限）、且相等，三者缺一不可。

为什么「连续」推不出「可导」

11:08把三类反例放一起看就彻底明白了：连续只要求「不脱节」，一笔能画完就行，完全不关心你画得顺不顺；可导额外要求「光滑」，切线斜率必须有限且唯一。y=|x| 拐了个尖角，y=x3 竖了起来，xsin1x 摆个不停——三者都缺了「光滑」这一关，所以都连续但不可导。连续是必要非充分条件。

范围提醒：以上结论是针对一元函数的。老师特意点明「注意这是一元函数，因为明年要讲多元函数，那边的结论比这复杂」。

边界补充：连续但处处不可导

还有一个方向值得想一想：「连续但不可导」的点，能不能多到铺满整条数轴？能。反例是魏尔斯特拉斯函数 W(x)=∑n=0∞ancos(bnπx)（0<a<1，b 取合适的正奇数）。它每个项都在「加频率」，越往后振荡越快，于是 W(x) 在每一点都连续（级数被 ∑an 一致控制），却在每一点都不可导——图像处处是毛刺，找不到哪怕一小段光滑的弧。

它的意义是给「连续 ⇒ 可导」的幻想彻底盖棺：连续但不可导不只是「个别的坏点」，可以坏到处处都坏。考试不会让你算它，知道「存在这样一条曲线」就够了。

再往上还有一层：可导 ≠ 导数连续

把「光滑」的等级往上排，是一个阶梯：连续 ⊂ 可导 ⊂ 导数连续，每一层都是下一层的必要条件。本页只需要记住最下面两级的分界在哪里。

记忆入口 · 一眼回忆

一句话

可导必连续，连续未必可导。可导 = 连续 + 光滑；连续只要求一笔画，不要求光滑。

证明枢纽

导数极限存在 ⇒ 差商 ΔyΔx 有限 ⇒ 分子 Δy 必须趋于 0 ⇒ 连续。核心一步是「分子必须趋于 0」。

三类反例（必记）

  • 尖角：y=|x| 在 0 处，f'−=−1≠f'+=+1（都存在但不等）。
  • 垂直切线：y=x3 在 0 处，f'±=+∞（非有限数）。切线存在 ≠ 导数存在。
  • 振荡：y=xsin1x 在 0 处，差商 =sin1Δx 在 ±1 间无限摆动；补成 x2sin1x 就可导。

判分界点的四步

先看连续（不连续直接毙）→ 算左导数 → 算右导数 → 都有限且相等才可导。

两个坑

  • 「无穷小比无穷小不一定」≠「这里分子不趋于 0」——前提「极限已存在」逼着分子必须是无穷小。
  • 斜率无穷大不算有导数：导数必须是有限实数。
前置知识
  • 导数的定义 导数的定义（差商极限、左右导数）
  • 连续 连续（增量定义与极限定义）
  • 极限与无穷小的关系（把极限拆成「常数+高阶无穷小」）
接下来
  • 求导公式 求导公式（既然可导必连续，下一步就是怎么算导数）
  • 导数几何含义 导数的几何含义（切线斜率、垂直切线为何斜率无穷大）
容易混
  • 「切线存在」与「导数存在」不同：垂直切线存在但导数不存在。
  • 连续是可导的必要非充分条件，方向不能反。
  • 「振荡」本身不致命，幅度压不下去才致命：xsin1x 不可导，x2sin1x 可导。
  • 本页结论仅对一元函数成立；多元情形更复杂。
