P067二阶常系数齐次线性微分方程：特征方程与三种根

一句话核心

这一族方程的全部秘密可以用一句话说完：拿 y=erx 去试。因为 erx 求导后形式不变、又永远不等于零，代进去之后剩下的只能是一个关于 r 的二次方程——特征方程。特征方程的三个根的情形，对应三种通解；本页把「为什么这样设」「为什么重根要多乘一个 x」「共轭复根为什么会冒出 cos 与 sin」都讲清楚。

把标题四个词逐字拆开

这节课的标题很长——「二阶常系数齐次线性微分方程」，老师原话是这个标题特别长哈。但它的好处是：四个词每个都限定了一件事，拆开之后形式就没有含糊的地方了。

这类方程的样子是

y''+py'+qy=0(p,q 是常数)
二阶
方程里必须有 y''。y' 与 y 可以有、也可以没有（比如 y''+4y'=0 里就没有 y），但二阶导数不能缺。
常系数
y''、y'、y 前面的系数必须是常数。标准写法里 y'' 的系数取 1、y' 的系数记作 p、y 的系数记作 q。系数里不能出现 x——xy'' 或 sinx⋅y' 都不行。
线性
y''、y'、y 三者之间只能是线性关系：各自一次方、不相乘。所以 y''y'（两个导数相乘）不行，y2（平方）也不行。但系数可以是任何常数，比如 2y''+12y'−3y 就是合法的线性表达式。
齐次
等号右边是 0。右边换成非零的 f(x)，就叫非齐次。

02:07这里有一个容易被问住的地方：既然系数可以随便取，为什么标准形式里 y'' 前面的系数一定写成 1？老师的回答很干脆：那你两边除以二不就完了嘛。——系数不是 1 的时候，两边同除，把最高阶导数的系数化成 1，就得到标准形式。

按右边是否为零分成两种之后，老师说得很明确：右边等于零的这一种（齐次）是实打实的、期末考试或者考研的一个比较主要的考点。理由也很实在：二阶方程一旦出难了就不好做，所以命题时会往简单处出，而「常系数 + 齐次」正是最简单又最能考出方法的那一类。

定理：两个解就能拼出通解

定理 · 齐次方程通解的结构

设 y1、y2 都是方程 y''+py'+qy=0 的解，并且

y1y2≠常数

则

y=C1y1+C2y2

就是该方程的通解（C1、C2 为任意常数）。

这个定理的价值在于：它把「解二阶方程」这件大事，换成了「找出两个不成比例的解」这件小事。一旦找到两个，把它们线性组合起来就是通解，不用再做别的。

定理的证明：代入 + 分组合并

证明要证两件事：C1y1+C2y2 确实是解，以及它带两个任意常数。

先求导（C1、C2 是常数，直接穿过去）：

y'=C1y1'+C2y2',y''=C1y1''+C2y2''

把 y''、y'、y 一并代进方程左边：

C1y1''+C2y2''+p(C1y1'+C2y2')+q(C1y1+C2y2)

按 C1、C2 重新分组：

C1(y1''+py1'+qy1)+C2(y2''+py2'+qy2)

而题目说了 y1、y2 都是解，所以两个括号各自等于零，于是整个左边等于零，方程成立。

这里能分组的理由只有一个：方程是线性的、系数是常数。正因为 p、q 不随 x 变、也不会被 C1 之外的因子影响，我们才敢把 C1 整块提到括号外面。这也是「线性」这两个字在本题里的具体用处。

为什么两个解不能成比例

定理里那条附加条件——y1y2 不能是常数——看着像技术细节，其实是整个结构能不能成立的关键。老师用「反着试一试」的方式讲：假设 y1y2=K（常数），那么 y1=Ky2，代进通解：

y=C1⋅Ky2+C2y2=(C1K+C2)y2

式子看着挺正常，但括号里那一整块只是一个任意常数：C1K 与 C2 各自任意，加起来仍然任意。也就是说，y 的表达里只剩下一个任意常数了。

而二阶方程的通解必须有两个任意常数。所以这样拼出来的不是通解，最多是通解的一部分。老师说这个场面很有意思：老师我还免费赠送了一个 K——两个常数我给你三个。行不行啊？不行。多出来的那个 K 不是自由度，它只是把两个常数里的一部分信息重新写了一遍。

线性相关
两个函数之比等于常数（一个是另一个的常数倍）。例如 ex 与 2ex：比值恒为 12。老师提醒：这里的「线性相关」与线性代数里的定义略有不同，本课按「比值是否为常数」来判定。
线性无关
比值不是常数。例如 sinx 与 cosx（比值是 tanx，随 x 变）；ex 与 xex（比值是 1x）。

所以定理的条件可以记成一句话：要找的两个解必须线性无关。这也是下面三种情形里，第二种情形会「不完美」的原因——重根时 er1x 与 er2x 是同一个函数，比值恒为 1，必须另想办法造出第二个解。

特征方程从哪冒出来的

现在任务很明确了：给方程 y''+py'+qy=0 找出两个线性无关的解。直接猜是猜不出来的，老师给了一个思路：先看方程有什么特点。

方程里只出现三样东西：y''、y'、y；它们的系数是常数；三项加起来要求等于零。这让人想到一个问题：什么样的函数，求导之后还是自己（至多差一个系数）？

为什么偏偏挑 erx 来试

老师说，求导公式里有一个非常特殊的：ex 求导还是它本身。换成带系数的形式 y=erx：

y=erx⟹y'=rerx,y''=r2erx

三次求导的结果形式完全一样，只是前面多了 r 的幂。这正是我们想要的：三项相加时，erx 可以整体提出来，剩下的只是一堆 r 的多项式。

对比一下别的函数：若取 y=x2，则 y'=2x、y''=2——三样东西的形式完全不同，根本提不出公因子，方程会变成 2+2px+qx2=0，那是关于 x 的恒等式，不可能对整个区间成立。erx 的「求导不变形」是它能通过试探的唯一理由。

把 y=erx 代进去试试：

r2erx+prerx+qerx=0⟹erx(r2+pr+q)=0

到这一步，第二个关键性质登场：erx 永远不等于零（指数函数恒正，图像一路往上走）。所以要让乘积等于零，只能是括号里那一项等于零：

r2+pr+q=0

这就是特征方程。老师说：说白了就是你只要把 r 求出来，它的两个解就解出来了。于是整个问题被压成了「解一个一元二次方程」。

特征方程的写法：一个「翻译表」

从微分方程写特征方程，动作机械到老师用「半分钟就能教会你」来形容：

微分方程里的换成
y''r2
y'r
y1

课上当场演示了两道：y''+2y'+y=0 的特征方程是 r2+2r+1=0；y''+4y'=0 因为没有 y，所以翻译出来就没有常数项，是 r2+4r=0。

情况一：两个不等的实根

这是最舒服的一种。判别式 Δ=p2−4q>0，特征方程给出两个不同的实数根 r1≠r2。两个解就是 er1x 与 er2x，它们的比值 e(r1−r2)x 显然不是常数，符合定理要求，直接组合：

y=C1er1x+C2er2x

课上的例子是 r2+r−2=0。因式分解得 (r+2)(r−1)=0，所以 r1=−2、r2=1，通解就是

y=C1e−2x+C2ex

老师说这一类是我们同学最喜欢见到的——「最完美的，就是没有任何好解释的，搞定」。它的确不需要任何额外手续：根解出来，直接照公式摆上。

情况二：重根——第二个解要多乘一个 x

判别式 Δ=0 时，特征方程只有一个（二重的）实根 r1=r2=r。这时候麻烦来了：按公式照抄会得到 y=C1erx+C2erx，也就是 (C1+C2)erx——只剩一个任意常数，而且两个解比值恒等于 1。两条要求同时违反，这一路走不通。

出路是：既然 erx 已经有了，那就给第二个解「动个手脚」，让它是 erx 乘上一个函数。老师原话：他俩相比不能是个常数，那看来它相比是不是得和 x 有点关系啊？于是设

y2=u(x)y1=u(x)er1x

把这个形式的 y2 代回方程，看看 u(x) 该长什么样。先把导数算出来：

y2'=(u'+r1u)er1x,y2''=(u''+2r1u'+r12u)er1x

代入 y''+py'+qy=0，两边把 er1x 约掉（它不为零，可以放心约）：

u''+(2r1+p)u'+(r12+pr1+q)u=0
26:44这个式子看起来复杂，其实有两项自动消失

第三项消失了，因为 r12+pr1+q=0——r1 是特征方程的根，这个式子就是特征方程本身。

第二项也消失了，因为重根时两根相等。由韦达定理，两根之和 r1+r2=−p；这里 r1=r2，所以 2r1=−p，即 2r1+p=0。

两个系数都是零，方程一下子瘦成了

u''=0

老师说这一步「看起来挺复杂，但是你把这两件事想起来，它就没有了」——消掉的两项分别来自「r1 是根」和「r1 是重根」，把这两个条件各用一次，方程就只剩 u''=0。

33:20接下来要解 u''=0。这很容易，但要小心一个细节：u 是常数行不行？不行——我们设 y2=u(x)y1 的初衷就是让 y2y1=u(x) 不是常数。所以要取满足 u''=0 的非常数解。u''=0 的通解是 u=C1x+C2，取最简单的一个：

u=x⟹y2=xer1x

于是重根情形的通解是

y=(C1+C2x)erx

课上的例子是 r2−2r+1=0，即 (r−1)2=0，得 r1=r2=1，通解 y=(C1+C2x)ex。

老师说这段证明可以跳过，但结论要记住

这个呢其实我们还给了大家一个比较严格的证明过程，其实你如果不看这个证明过程、光记答案的话，也没有什么大问题。

不过老师特意强调，重根这一段的推导在三种情形里是唯一需要「造解」的。记住「重根要乘一个 x」很容易，但知道那个 x 是从 u''=0 里解出来的，就不会在别的地方乱乘 x。

情况三：共轭复根

判别式 Δ=p2−4q<0 时，特征方程的一元二次求根公式会开出一个负数，于是两根是一对共轭复数。直接写求根公式：

r=−p±p2−4q2=−p±−(4q−p2)2=−p±i4q−p22

把它写成 α±βi 的形式，得到两个系数：

α=−p2,β=4q−p22

老师特别提醒了 β 的取法：这个 β 的地方是不包含它那个正负号的部分。也就是说 β 一律取正数——正负号已经由 ± 承担了，不要重复带进去。

α、β 不用背，用求根公式现推

老师说他见过同学硬记 α、β 的公式，这个完全没必要：解一元二次方程的时候，x=−b±b2−4ac2a 是不是每个同学都能写出来？写出来之后，把根式里那个负数提出一个 i，得到的表达式天然就是 α±βi 的形状：实部就是 α，虚部那个系数就是 β。

举个数：若特征方程是 r2+2r+5=0，则 Δ=4−20=−16<0，r=−2±4i2=−1±2i，所以 α=−1、β=2。

从复根到 cos 与 sin

如果只是把 α±βi 代进 erx，得到的解是 e(α+βi)x 与 e(α−βi)x——它们都带虚数单位。但实际问题的解应当是实值函数，所以要把这两个复值解重新组合成一对实值解。做法是用欧拉公式把复指数拆成三角形式：

e(α±βi)x=eαx(cosβx±isinβx)

把这两个式子相加、相减再各除以 2 与 2i，就得到两个纯实值的东西：

y1=eαxcosβx,y2=eαxsinβx

它们仍然都是方程的解（复值解取实部与虚部，得到的仍是解——这一步与「C1y1+C2y2 是解」用的是同一套线性叠加的道理）。而它们的比值 y1y2=cotβx 不是常数，y=x 之外第二个线性无关的解有了，于是通解是

y=eαx(C1cosβx+C2sinβx)

40:01课上让同学们点头认可的一点正是这个比值：因为 cos 跟 sin 它俩相比，一般来说不可能是一个固定的常数。至于「eαxcosβx 为什么确实满足方程」，老师没有展开验算：这个就是一个重复性的工作——把 y1 的两阶导数代进 y''+py'+qy，按 α、β 与 p、q 的关系（p=−2α、q=α2+β2）合并同类项，两边正好抵消。

三种情形，一张表带走

判别式 Δ=p2−4q特征根两个线性无关的解通解
Δ>0 两个不等实根 r1≠r2 er1x，er2x y=C1er1x+C2er2x
Δ=0 二重根 r1=r2=r erx，xerx y=(C1+C2x)erx
Δ<0 共轭复根 α±βi eαxcosβx，eαxsinβx y=eαx(C1cosβx+C2sinβx)

这张表就是整节课要交的答卷。老师的说法是：前面那套证明你都可以不看，只要能从特征方程解出根、再照三种情形把公式摆上，题就能做。不过把推导听一遍的好处很直接：知道重根为什么要乘 x、知道复根里的 cos、sin 是怎么来的，遇到题目变形（比如系数不是 1、或者缺 y' 项）就不会慌。

例求下列方程的通解：(1) y''−3y'+2y=0；(2) y''+4y'+4y=0；(3) y''−2y'+5y=0。

思路：三道题的流程完全一样——写特征方程 → 解根 → 判断情形 → 摆通解

(1) 特征方程为 r2−3r+2=0，因式分解得 (r−1)(r−2)=0，两个不等的实根 r1=1、r2=2，属于情况一：

y=C1ex+C2e2x

(2) 特征方程为 r2+4r+4=0，即 (r+2)2=0，只有一个二重根 r=−2，属于情况二，第二个解要乘一个 x：

y=(C1+C2x)e−2x

(3) 特征方程为 r2−2r+5=0，判别式 Δ=4−20=−16<0，用求根公式得 r=2±4i2=1±2i，所以 α=1、β=2（实部与虚部各取出来），属于情况三：

y=ex(C1cos2x+C2sin2x)
三道题各自的一个坑

(2) 漏掉那个 x。重根时若写成 (C1+C2)e−2x，通解里只剩一个任意常数，不满足要求。

(3) 忘记 β 要从根里读出来。β=2 来自虚部 2i 的系数，它在通解里是 cos2x、sin2x 里面的那个 2——漏了它，答案就成了一对普通的常数。
