P141【黑板】第一型曲线积分：一代二换三定限

一句话核心

第一型曲线积分（对弧长）的全部动作只有三步：把曲线参数化、把 x、y 代进去、把 ds 换成 x'2+y'2dt。它不讲方向，所以换元以后定限永远是「小在下、大在上」。黑板课真正要练的只有两件事：什么时候可以把曲线方程直接朝里带，以及一条曲线分成几段时怎么各段算完再相加。

这一讲只做一件事：把「弯的」换成一个参数

00:00前面已经攒了一重、二重、三重积分，现在又来了一种新的，叫对弧长的曲线积分，也叫第一型曲线积分。老师给的引子很朴素：一条曲线，每个点上的线密度不一样，密度是 μ(x,y)，问这根曲线有多重。注意这里的「区域」不再是平面上一块面，而是一条线本身——这正是它和二重积分彻底分家的地方。

01:25做法是老一套。在曲线上插一些点，把它切成很多小弧段，任意取其中一小段，在这一小段上取一点 (ξi,ηi)，用它在这一点的密度 μ(ξi,ηi) 去代表整小段的密度。于是这一小段的质量就近似是 μ(ξi,ηi)Δsi，其中 Δsi 是这段弧长。05:17全部加起来再让 λ→0（λ 是这些小弧段里最长的那一段），就得到精确质量。这套「切、取、乘、和、取极限」的动作，和二重积分一模一样，只是把面积元素 Δσ 换成了弧长元素 Δs。

05:17定义 · 第一型曲线积分

设 L 是平面上一条光滑曲线弧，f(x,y) 在 L 上有界。把 L 任意分成 n 小段，第 i 段的弧长记作 Δsi，在它上面任取一点 (ξi,ηi)，作和式 ∑i=1nf(ξi,ηi)Δsi。当所有小弧段的最大长度 λ→0 时，若这个和式的极限存在，就称它是 f(x,y) 在 L 上对弧长的曲线积分，记作

∫Lf(x,y)ds=limλ→0∑i=1nf(ξi,ηi)Δsi

空间曲线上的情形完全平行：被积函数换成 f(x,y,z)，曲线记作 Γ，得到 ∫Γf(x,y,z)ds。

这个定义不必会算——老师讲得很直白，极限求和谁也算不出来。它唯一的作用是交代清楚这个符号在说什么：∫ 还是一个积分号（一重的），被积函数就是题目给的那个二元函数，ds 表示「沿弧长」。11:50真正决定你能不能做出题目的，是下面那条计算公式。

性质里只有两条真正上过场

09:58性质给了一串，但做题目能做到的只有前两条，第三条（不等式性质）基本不用，可以先放着。

线性性
∫L[αf+βg]ds=α∫Lfds+β∫Lgds。系数可以往外提——这条和在定积分里学的一模一样。
可加性
若 L 由 L1、L2 两段拼成，则 ∫L=∫L1+∫L2。09:58老师的说法很实在：既然求质量是求两根棍的质量，那就一根一根求完再加。

第二条比它看上去更重要。凡是一条曲线由几段不同的曲线拼起来（直线加圆弧、折线绕一圈），一律先拆成几段，每段单独处理，最后相加。这正是黑板课上最常见的题型之一。

16:31为什么可加性是「分段」而不是「分方向」

拆段的时候只关心「这是不是两段不同的曲线」，不关心你是从 A 走到 B 还是从 B 走到 A。因为第一型曲线积分压根不讲方向：16:31它量的是一根铁链子的质量，不管你是从这头量还是从那头量，链子都是同一根链子，质量当然是同一个数。

18:32老师还打了个更贴身的比方：上山和下山消耗的能量可不一样，那件事就要讲方向了。所以「讲不讲方向」不是规定，而是由你要算的那个物理量本身决定的。凡是算「长度、质量、质心、转动惯量」这类与走向无关的量，统统是第一型。

核心公式：一代、二换、三定限

设曲线 L 由参数方程给出

x=x(t),y=y(t)(α≤t≤β)

并且 x'(t)、y'(t) 连续。11:50那么整条曲线上的积分就变成对 t 的一个普通定积分。三步走，一步都不能少：

  1. 一代。把被积函数里的 x、y 全部换成 t 的表达式：f(x,y)→f(x(t),y(t))。这一步没有任何技术含量，就是「给什么代什么」。
  2. 二换。把 ds 换成 x'2(t)+y'2(t)dt。这是唯一需要动脑筋的一步，下面单独说清楚为什么。
  3. 三定限。19:36换成对 t 的定积分以后，上下限取 α 到 β，而且必须小的在下、大的在上。
∫Lf(x,y)ds=∫αβf(x(t),y(t))x'2(t)+y'2(t)dt(α<β)
14:11ds 为什么长成 x'2+y'2dt

取很小很小的一段弧，小到可以把它看成一条直线段。既然是直线段，它和它在两个坐标方向上的投影 dx、dy 就构成一个直角三角形，勾股定理立刻给出

ds2=dx2+dy2

再把 x、y 都看成 t 的函数求微分：dx=x'(t)dt，dy=y'(t)dt。两条式子各自平方后代入，dt2 可以提出来，开方就得到 ds=x'2+y'2dt。

这里藏着一个细节：严格写应该是 x'2+y'2|dt|——因为开方开出来的必须是正数，而 ds 是长度。之所以规定「α 必须小于 β」，就是为了保证 dt>0，从而把绝对值直接脱掉。这条规定不是讲究，它是这条公式能成立的前提。

黑板课第一坑：曲线上的方程可以「朝里带」

40:10先看一道很有意思的题：在 L 上求 ∫L(x+y)ds，其中 L 是直线 x+y=2 上从 (2,0) 到 (0,2) 的那一段弧。有人一看就想：这也能做？其实一步就完了——43:15因为这条曲线上的每一个点都满足 x+y=2，所以被积函数 x+y 在这条曲线上恒等于 2：

∫L(x+y)ds=∫L2ds=2∫Lds=2×(弧长)

而 ∫Lds 就是弧长本身——43:15被积函数是 1 的时候，沿曲线把 1 累加起来，得到的当然是长度。这段直线的长度是 22+22=22，所以答案是 42。整个过程连参数化都省了。

42:09同一个动作，换到二重积分上就是错的

有同学马上会问：那二重积分是不是也能这么带？比如 ∬D(x2+y2)dσ，D 是圆盘 x2+y2≤4，能不能把 x2+y2=4 带进去变成 ∬D4dσ？绝对不行。

原因是两个积分的积分范围根本不是一类东西。42:09第一型曲线积分的范围是一条曲线，你要累加的每一个点都落在这条曲线上，所以曲线方程对每个点都成立，代进去是恒等变形。而二重积分的范围是一整块面，x2+y2=4 只是这块面的边界，内部那无数个点的 x2+y2 都小于 4，把它们统统改成 4 就把积分算错了。

一句话记法：「沿线的积分，可以用线的方程；盖面的积分，不能用面的边界方程。」判断标准只有一条——你要累加的那些点，是不是全都满足这个方程。

例题

例 119:36计算 ∫Lxds，其中 L 是半径为 1 的圆在第一象限的那一段弧。

思路：先把曲线参数化，再一代二换三定限

这段弧是 x2+y2=1 的一部分。最省事的参数方程是高中就熟悉的那一组（注意这里不是极坐标）：

x=cosθ,y=sinθ

一代：被积函数只有 x，代进去就是 cosθ。二换：x'=−sinθ，y'=cosθ，所以

x'2+y'2=sin2θ+cos2θ=1

根号整个消失了，ds=dθ。三定限：这段弧对应 θ 从 0 到 π2，小的在下：

∫Lxds=∫0π2cosθdθ=sinπ2−sin0=1
这一段的定限是最容易翻车的地方

错误写法：θ 从 π2 到 0。有人想「我是从 y 轴那边走到 x 轴那边的，所以角度从 90 度变到 0 度」。但第一型曲线积分不讲方向，而且上一段已经说清楚：写成 dt 的前提是 dt>0。真按 π2 到 0 去积，会算出 −1——一个弧长积分不可能是负数，负号一出现就说明定限反了。

顺带一提：如果这道题没有限制在第一象限，而是整个圆，那么 θ 从 0 到 2π，结果照样是 0——因为被积函数 cosθ 在一整圈上正负抵消了。这跟方向无关，纯粹是函数的对称性。

例 240:10计算 ∫L(x+y)ds，其中 L 是直线 x+y=2 上从 (2,0) 到 (0,2) 的一段。

思路：先看看被积函数在曲线上是不是常数——是常数就别硬算

这条曲线上的点全部满足 x+y=2，所以被积函数在 L 上恒等于 2。由线性性和 ∫Lds 就是弧长：

∫L(x+y)ds=2∫Lds=2⋅22=42

换成参数化硬做当然也能做出同样的结果（取 x=t、y=2−t，t 从 0 到 2，此时 ds=2dt，被积函数是 2，积分 ∫0222dt=42），但那完全是白费力气。

要点：做题前先扫一眼被积函数能不能用曲线方程简化。43:15「曲线上的方程可以朝里带」是这一讲最值钱的一句话，也是它和第二型曲线积分之间少有的「好消息」——第二型同样可以带，但下面那种 ds 的根号它没有了。

例 346:59计算 ∮Lex2+y2ds，其中 L 由 O(0,0)→A(2,0)→B(2,2)→O 三段组成，AB 在圆 x2+y2=4 上，BO 在直线 y=x 上。

思路：曲线是拼出来的，先拆成三段，每段单独参数化，最后相加

这是那种「一条曲线由直线加圆弧拼起来」的典型题。由可加性，

∮L=∫OA+∫AB+∫BO

第一段 OA：在 x 轴上，y=0，x 从 0 到 2。于是 x2+0=x（x≥0，不用加绝对值），且 ds=dx：

∫OA=∫02exdx=e2−1

第二段 AB：这一段落在圆 x2+y2=4 上，所以 x2+y2=2，被积函数变成常数 e2。剩下的事只有一件——求弧长。这段弧从一个象限点走到半个象限点，占整圆的八分之一，弧长是 18⋅2π⋅2=π2，于是

∫AB=e2⋅π2

第三段 BO：在直线 y=x 上，x 从 0 到 2。此时 x2+y2=2x2，2x2=2x，且 ds=1+1dx=2dx：

∫BO=∫02e2x2dx=e2−1

三段相加，得到

∮Lex2+y2ds=2(e2−1)+π2e2

要点：第三段写成「BO」还是「OB」毫无区别——第一型不讲方向。真正要小心的是每段的参数范围：OA 上 x 从 0 到 2，BO 上 x 从 0 到 2，都必须从小的写到大的。

例 456:08计算 ∫Ly2ds，其中 L 是摆线的一拱：x=a(t−sint)，y=a(1−cost)，0≤t≤2π。

思路：曲线已经是参数方程，直接一代二换，难点全在三角函数化简上

一代：y2=a2(1−cost)2。二换：先算两条导数 x'=a(1−cost)、y'=asint，于是

x'2+y'2=a(1−cost)2+sin2t=a2−2cost

这里用两倍角公式 (1−cost)=2sin2t2，把根号里的 2−2cost 写成 2sint2。关键点在于当 0≤t≤2π 时 t2 落在 [0,π] 内，sint2 恒非负，所以开方不用带负号——这又是一次「定限取小到大」在替我们干活。于是

y2ds=a2(1−cost)2⋅2asint2dt=8a3sin5t2dt

（这里把 (1−cost)2 换成了 (2sin2t2)2=4sin4t2。）令 u=t2，

∫02π8a3sin5t2dt=16a3∫0πsin5udu=25615a3

要点：∫0πsin5udu=1615 这条常见的定积分结果（奇次幂的正弦在 [0,π] 上的积分）值得记一下，否则光在这里做三角代换就要花掉大半时间。摆线这道题的价值在于：它把「一代二换」做熟，同时把两倍角公式和开方去绝对值两个老知识点都串起来了。

两种常见变形与空间曲线

24:42课本上还列了两种参数化的「特例」，其实都不必单独记——它们只是总公式的自然结果：

若 y=y(x)，x 从 x0 到 X
干脆把 x 自己当参数：这时 x'=1，于是 ds=1+y'2dx，积分变成 ∫x0Xf(x,y(x))1+y'2dx。这正好就是求平面曲线弧长的那个根号，18:32说明 ∫Lds 就是弧长这一点是自洽的。
若 x=x(y)，y 从 y0 到 Y
把 y 当参数：y'=1，ds=x'2+1dy，其余照搬。
29:00一个「建模型」的例子：圆弧对 x 轴的转动惯量

有一段半径为 R 的圆弧，关于 y 轴对称，圆心角为 ±α，线密度恒为 1。取一小段 ds，它的质量就是 ds，而它到 x 轴的距离是 |y|，所以这一小段对 x 轴的转动惯量是 y2ds——转动惯量的定义是「距离的平方乘以质量」。于是

I=∫Ly2ds=R3∫−ααsin2θdθ=R3(α−sinαcosα)

这道题比别的题多了一步：先把物理量写成积分，再算积分。弧长元素、距离平方这两个东西被「组装」成一个新的被积函数 y2，这是应用型题目和纯计算题的唯一区别。

34:00空间曲线只是多一个变量、多一个根号：若 Γ 由 x=x(t)、y=y(t)、z=z(t)（α≤t≤β）给出，则

∫Γf(x,y,z)ds=∫αβf(x(t),y(t),z(t))x'2+y'2+z'2dt

拿课本上的螺旋线验一下手：Γ 是 x=acost、y=asint、z=kt，0≤t≤2π，计算 ∫Γ(x2+y2+z2)ds。三条导数分别是 −asint、acost、k，根号里 sin2t+cos2t=1，所以 ds=a2+k2dt——这一次根号是个常数，可以提到积分号外面。被积函数代进去是 a2+k2t2，于是

∫Γ=a2+k2∫02π(a2+k2t2)dt=a2+k2(2πa2+8π33k2)

二维和三维的公式形状完全一样，只是根号里的平方项多了一项。所以空间曲线不需要另学一个新公式，把二维那条抄过来加一项即可。

记忆入口 · 一眼回忆

一句话

第一型曲线积分 = 「沿一条曲线把函数值按弧长累加」。它不讲方向，做法是一代二换三定限。

核心公式

∫Lfds=∫αβf(x(t),y(t))x'2+y'2dt(α<β)

一条链

切小弧 取点乘密度→ 求和取极限 得到 ∫Lfds→ 参数化 一代二换三定限→ 算出 一个数

要背的

  • ds=x'2+y'2dt；空间情形多一项 x'2+y'2+z'2dt。
  • 定限一律小的在下——不是习惯，是因为要把开方出来的 |dt| 直接写成 dt。
  • 曲线上的方程可以代入；∫Lds 就是弧长；系数可以提出来（线性性）。
  • 曲线由几段拼成时，拆段分别算，最后相加（可加性）。

两个坑

  • 把 θ 按走向写成从大到小。结果会出现负号，而弧长积分不可能为负——负号就是定限反了的信号。
  • 把二重积分的区域方程也往里带。圆盘内部不满足 x2+y2=4，带了就把整块面积分算错。
