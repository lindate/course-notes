一句话核心

这一页把换元法的三件「额外红利」讲完：奇偶函数在对称区间上的定积分（奇函数为 0、偶函数是半区间的两倍）、两个区间反转恒等式（sin 与 cos 互换、带 x 的积分化成不带 x 的）、以及周期函数一个周期内积分与起点无关。老师说：拿到定积分题，只要积分区间关于原点对称，第一反应就该是奇偶性——它的应用排在第一位。

一、本页要继续用换元做的三件事

00:00上一页把「换元必换限」这条规矩立住了。这一页不再讲新的换元技巧，而是用换元这把刀去砍三类有固定套路的题目：对称区间上的奇偶函数、sin 与 cos 互换的恒等式、周期函数。它们的共同特点是——结论可以直接背下来用，证明却都要靠换元。

老师的排序很明确：这一页的第一个结论是龙头，第二个是它的应用，第三、第四个属于「会考但不常考」。所以我们按这个轻重来安排篇幅。

二、奇偶函数在对称区间上的定积分

结论（老师说可以当定理用）

设 f(x) 在对称区间 [−a,a] 上连续，则

∫−aaf(x)dx={0,f是奇函数2∫0af(x)dx,f是偶函数

00:00老师对这条结论的重视程度非常高：「大家考的所有考试这两个结论一定会用到」，而且「做定积分的题目，这个定理的应用是排在第一位的」。理由很简单——它能把一整道计算题直接变成 0，或者至少把计算量砍掉一半。

03:12证明：把负半轴那段「搬」到正半轴去

结论看着像「显然」，但要靠换元才能说清。第一步是把整个积分按原点切开：

∫−aaf(x)dx=∫−a0f(x)dx+∫0af(x)dx

现在专门处理第一块 ∫−a0f(x)dx。对它换元，令 x=−t，则 dx=−dt；换限：x=−a 时 t=a，x=0 时 t=0，所以 t 从 a 到 0。代入得

∫−a0f(x)dx=∫a0f(−t)(−dt)

那个 dt 前面的负号，正好可以用「交换上下限」换掉：∫a0(⋯)(−dt)=∫0a(⋯)dt。于是

∫−a0f(x)dx=∫0af(−t)dt

04:26最后一步很关键：定积分的值只与被积函数和积分限有关，与积分变量用什么字母无关。所以可以把 t 改回写成 x：

∫−a0f(x)dx=∫0af(−x)dx

现在结论一目了然。若 f 是奇函数，f(−x)=−f(x)，右边变成 −∫0af(x)dx，与第二块相加正好抵消，得 0。若 f 是偶函数，f(−x)=f(x)，右边与第二块完全相同，相加就是两倍。证毕。

02:06使用前提只有一条，但必须每次都核对

积分区间必须关于原点对称。也就是形如 [−a,a] 的区间。老师举了个反面例子：

∫−ππ/2sinxdx能不能直接写0?不能

sinx 确实是奇函数，但区间 [−π,π2] 左长右短，根本不关于原点对称，所以结论用不上。这道题的实际值是 ∫−ππ/2sinxdx=[−cosx]−ππ/2=0−1=−1，不是 0。

检验动作：拿到题先看两个端点是不是互为相反数。是，才能动这个结论；不是，就必须老老实实算。

例 105:52求 ∫−11xcosxdx 与 ∫−ππx2dx。

思路：先判奇偶，再判区间

第一题：区间 [−1,1] 关于原点对称 ✓。被积函数 xcosx 里，x 是奇函数、cosx 是偶函数，奇 × 偶 = 奇。所以

∫−11xcosxdx=0

结果直接是 0，「就不用做了」——老师笑着说「所有同学都喜欢结果等于零」。

06:51第二题：区间 [−π,π] 也关于原点对称 ✓，而 x2 是偶函数，所以

∫−ππx2dx=2∫0πx2dx=2[x33]0π=2π33
偶函数这一半的好处，没有你想的那么大

08:00老师讲得很实在：偶函数化成 2∫0af 之后，积分还是得算，只是把上限从 −a 换成了 0，代进去的时候数字小一点、好算一点，所以「计算量能减小一些，但没有你想象中的那么好」。真正让人省心的是奇函数那一半——它直接把整道题变成 0。所以判奇偶时，先盼着它是奇函数。

05:52为什么这个结论要排在第一位

它解决的不只是「少算一点」的问题，而是改变了你看题的顺序。老师说得很清楚：「大家看的题目，只要积分的上下限是关于原点对称的 −1 到 1，马上就想这两个结论，一般来说都是能用的。」

这句话背后是一套判断流程：看区间 → 看奇偶 → 再决定要不要动手算。很多看起来很长很吓人的被积函数（比如 x3cosx1+x4 这一类），只要它是奇函数、区间又对称，答案就是 0，一个积分都不用做。反过来说，如果不先判奇偶就埋头去算，很可能算了半天才发现「原来是零」。

三、两个「区间反转」恒等式

09:15接下来的两条结论思路相通：用一个把区间「翻过来」的换元，把陌生的积分变成已经会做的东西。

恒等式一：sin 与 cos 可以互换

设 f 连续，则

∫0π/2f(sinx)dx=∫0π/2f(cosx)dx

09:15证明的换元是 x=π2−t。此时 dx=−dt，且 x 从 0 到 π2 时 t 从 π2 到 0。代入后那个负号与「交换上下限」抵消，而 sin(π2−t)=cost，于是左边化成 ∫0π/2f(cost)dt，再把 t 改写成 x 即可。

这个换元的动机很明显：题目里出现 sin 和 cos 这对搭档，又都配着 0 到 π2 这个区间，那就用诱导公式把它们对调。至于它的几何意义，老师说「不是很好理解」：f 是随便给的抽象函数，所以这里只能靠换元去体会——两边的被积函数虽然一个含 sin、一个含 cos，但它们的取值经过 f 之后分布是一样的。

恒等式二：带 x 的积分可以「去掉」x

设 f 连续，则

∫0πxf(sinx)dx=π2∫0πf(sinx)dx

13:17证明用换元 x=π−t。此时 dx=−dt，x 从 0 到 π 对应 t 从 π 到 0，且 sin(π−t)=sint。代入并整理负号后得到

∫0πxf(sinx)dx=π∫0πf(sint)dt−∫0πtf(sint)dt
17:23「要求的式子又出现了」——这是本页最值得学的一招

上一步收拾完，会发现等式右边第二项 ∫0πtf(sint)dt 与左边的 ∫0πxf(sinx)dx 长得一模一样（把字母 t 换回 x 就行）。也就是说，我们要求的那个量在推导过程中又冒出来了。

很多同学到这一步会慌：「怎么绕回来了？」老师的办法是把它当成未知数搬到一边。设 I=∫0πxf(sinx)dx，那么上面的等式就是

I=π∫0πf(sinx)dx−I⟹2I=π∫0πf(sinx)dx

两边除以 2，就是恒等式二。老师给的判据很有意思：「要求的这个东西又出现了，你心里头不用怕——但是如果它前面的系数是个正的、而且正好是正一，那你就的确应该怕了，因为那就证明你做错了。」系数是 2 就能解出 I；系数如果是 1，等式就退化成「I=I」这种没用的恒等式，说明换元选错了。

例 218:06求 ∫0πxsinx1+cos2xdx。

思路：先确认它是「x 乘以某个 sinx 的函数」的形状，再用恒等式二

19:19第一步是把它凑成恒等式二要求的样子。恒等式二里的 f(sinx) 必须只含 sinx。这里的分母是 1+cos2x，看起来含 cos，但用平方关系一换就清楚了：

1+cos2x=1+(1−sin2x)=2−sin2x

它确实只是 sinx 的函数。于是可以套用恒等式二（取 f(sinx)=sinx2−sin2x）：

∫0πxsinx1+cos2xdx=π2∫0πsinx1+cos2xdx

那个碍事的 x 就这么被「抹掉」了。剩下的积分用凑微分：sinxdx=−d(cosx)，令 u=cosx：

∫0πsinxdx1+cos2x=∫−11du1+u2=[arctanu]−11=π4+π4=π2

注意这一小步又用上了本页第二节的结论：11+u2 是偶函数、区间 [−1,1] 对称，所以它其实等于 2∫01du1+u2=2⋅π4。三种工具在一道题里接力。

∫0πxsinx1+cos2xdx=π2⋅π2=π24
两个不要踩的地方

一、化简 sinxdx 时忘了负号。d(cosx)=−sinxdx，所以 sinxdx=−d(cosx)。换限之后上下限从 0,π 变成 1,−1，负号与「交换上下限」抵消，才写成 ∫−11。跳过这一步、只管符号结果，很容易多一个负号。

二、把 1+cos2x 当成「cos 的函数」就放弃恒等式二。只要用 cos2x=1−sin2x 化一次，它就变成 sinx 的函数了。恒等式二的条件是「f 只含 sinx」，不是「式子里不许出现 cos」。

四、周期函数的定积分

21:17结论

设 f 连续且以 T 为周期（T>0），则对任意实数 a：

∫aa+Tf(x)dx=∫0Tf(x)dx

27:03更一般地，对正整数 n：

∫aa+nTf(x)dx=n∫0Tf(x)dx

第一条的白话版是：「一个完整周期内的定积分，跟你从哪儿开始数没有关系」。老师说这就跟 sin 一样——sin 的周期是 2π，你从 0 开始取一个周期，和从图像上随便哪个点 a 开始取一个周期，积出来的值是一样的。

这个结论的实用价值恰恰在「随便」二字上：既然起点的位置不影响结果，那我们当然把起点取成 0——从 0 开始算，端点数字最简单，代上下限的时候不容易出错。

23:39证明：把起点 a 当成变量去求导

这条结论的证法很特别，值得单独学一下。老师先把「起点 a 决定的那个积分」看成一个关于 a 的函数：

G(a)=∫aa+Tf(x)dx

这一步有点反常——我们平常把 a,b,c 都当常数，这里却把 a 当作自变量。对 a 求导，用的是上下限都是 a 的函数的求导公式：

G'(a)=f(a+T)⋅1−f(a)⋅1=f(a+T)−f(a)

而 f 以 T 为周期，所以 f(a+T)=f(a)，两项相减得

G'(a)=0

导数恒为零，说明 G(a) 是一个常数——也就是说，无论起点 a 取什么，这个积分值都一样。既然是常数，那就取最方便的 a=0：

G(a)≡G(0)=∫0Tf(x)dx

这正是要证的结论。第二条（∫aa+nT=n∫0T）就是把区间拆成 n 个长度 T 的小段，每一段用第一条即可。

例 329:44求 ∫0nπ1+sin2xdx（n 为正整数）。

思路：周期性拆出 n 个相同的小段，再把被积函数化简

29:44第一件事是找周期。sin2x 的周期是 π（因为 sin 的周期是 2π，把 x 换成 2x 后周期除以 2）。所以 [0,nπ] 正好是 n 个完整的周期，可以用第二条结论：

∫0nπ1+sin2xdx=n∫0π1+sin2xdx

30:53第二件事是化简根号。用平方关系与二倍角公式，把 1 拆开：

1+sin2x=sin2x+cos2x+2sinxcosx=(sinx+cosx)2

所以 1+sin2x=|sinx+cosx|——绝对值必须留着，因为 [0,π] 上 sinx+cosx 有正有负。为了看清它的符号，把它化成一个三角函数（提 2 出来）：

sinx+cosx=2sin(x+π4)⟹1+sin2x=2|sin(x+π4)|

31:50第三件事是平移换元：令 t=x+π4，则 dx=dt，x 从 0 到 π 对应 t 从 π4 到 5π4：

∫0π1+sin2xdx=2∫π/45π/4|sint|dt

而 |sint| 的周期是 π，区间 [π4,5π4] 长度正好是 π，是个完整周期。再用一次周期性，把起点搬回 0（这一段 |sint|=sint≥0，绝对值可以直接去掉）：

=2∫0πsintdt=2[−cost]0π=2(1+1)=22
∫0nπ1+sin2xdx=22n
三个扣分点

一、把 (sinx+cosx)2 直接写成 sinx+cosx。开偶次方必须先取绝对值，再做符号讨论。这里正是靠后面的「一个完整周期 + 起点搬回 0」才把绝对值安全地去掉。

二、|sint| 的周期当成 2π。|sint| 的周期是 π——加绝对值以后，原来在 x 轴下方的那一半被翻上来，周期就减半了。

三、忘了最外面那个 n。周期性拆出来的 n 个相同小段是乘法关系，别漏乘。

34:54老师对周期性这一节的评价

要求很实在：「周期函数这部分，期末考试用到的可能性少一点」，一是因为结论不太好理解，二是因为定积分能考的东西本来就多，再塞一条周期性有点勉强。考研的时候会用得到。他还留了个保底建议：「这个结论你记不住，那到时候你就用换元呗，按照正常的换元过程做不就行了。」

五、分段函数与抽象函数：先换元，再分段

例 434:54设 f(x)={11+cosx,x<0xe−x2,x≥0，求 ∫14f(x−2)dx。

思路：先把 x−2 换成 t，把抽象函数「翻译」成 f(t)，再按分段点拆开

35:37老师说这是「比较重要的一个题型」，它有两个卡点。

卡点一：被积函数里是 f(x−2)，不是 f(t)。分段表达式是按「自变量小于零还是大于等于零」给的，所以必须先把它变成标准形式。令

t=x−2,dt=dx

换限：x=1 时 t=−1；x=4 时 t=2。所以 t 从 −1 到 2，积分变成 ∫−12f(t)dt。

卡点二：被积函数是分段的，必须按分段点切开。分段点是 t=0，所以

∫−12f(t)dt=∫−10dt1+cost+∫02te−t2dt

左边的积分用半角公式：1+cost=2cos2t2，所以被积函数是 12sec2t2。而 sec2 的原函数是 tan（这是不定积分里被反复强调的一对），于是

∫−10dt1+cost=[tant2]−10=0−tan(−12)=tan12

右边的积分用凑微分：tdt=−12d(e−t2) 的等价写法是 tdt=−12d(−t2)，直接算得

∫02te−t2dt=[−12e−t2]02=−12e−4+12

两块相加：

∫14f(x−2)dx=tan12+12−12e−4

其中 tan12 是一个没法再化简的数，写成这样就是最终答案。

两个最容易错的地方

一、不换元就直接往分段式里代。被积函数写的是 f(x−2)，而分段表达式描述的是 f(⋅) 在自变量与 0 的大小关系下的取值。不先把 x−2 换成 t，就无从判断「该用哪一段」。老师强调：「你必须给它转换成 f(t)，才能用它的分段函数给它朝里带。」

二、换完元忘了换限，或者忘了把 x 从 1,4 换成 −1,2。如果限还留着 1 和 4，而分段点在 t=0，你就完全不知道该从哪里切。

记忆入口 · 一眼回忆

一条链

看区间 是否关于原点对称→ 看奇偶 奇为 0、偶为两倍→ 再想 sin/cos 互换、周期平移→ 实在不行 老老实实换元

要背的

  • 奇偶：∫−aaf=0（f 奇）；∫−aaf=2∫0af（f 偶）。前提：区间关于原点对称。
  • ∫0π/2f(sinx)dx=∫0π/2f(cosx)dx（换元 x=π2−t）。
  • ∫0πxf(sinx)dx=π2∫0πf(sinx)dx（换元 x=π−t）。
  • ∫aa+Tf=∫0Tf，∫aa+nTf=n∫0Tf（T 是周期）。
  • |sint| 的周期是 π，不是 2π。

三个技巧要点

  1. 「要求的式子又出现了」不用怕：设成 I 移项解出来。系数是 2 就能解；系数是 1 说明换元选错了。
  2. 把抽象函数先换成 f(t)：∫14f(x−2)dx 必须先令 t=x−2、换成 ∫−12f(t)dt，才能按分段点拆。
  3. 开偶次方先取绝对值，再找变号点分段：1+sin2x=2|sin(x+π4)|。

两个坑

  • 区间不对称就不能用奇偶：∫−ππ/2sinxdx=−1≠0。
  • 分段函数一定要按分段点切开，不能整体套一个公式。
