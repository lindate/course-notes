一、知识速查：变上限积分函数

00:55定积分 ∫abf(x)dx 里，a、b 和被积函数一旦定下来，它就是一个确定的数，是几就是几。现在我们只动一个地方：把右端点 b 换成一根可以左右拖动的指针 x。指针往右挪，阴影部分的面积就大一点；往左挪，面积就小一点——面积随着 x 变，那它就是一个函数。这个函数叫变上限积分函数（有的书叫积分上限函数，名字不同、意思一样）：

Φ(x)=∫axf(t)dt

02:47记号上必须换一个字母。上限已经是 x，积分号里的变量就要写成 t。这个 t 是积分内部的哑变量：它从 a 跑到 x，积完就消失了，Φ 的值与它毫无关系——把它换成 u、s、□ 结果完全一样。而 x 是外部变量，它决定积分的长度，是留在结果里的那一个。有的书偷懒写成 ∫axf(x)dx，不算错，但两个 x 的含义完全不同，做题时一律把内部变量改写成 t。

02:47「内部变量」到底是句什么话

把它想成一台机器：你把 x 送进去，机器内部拿 t 当"工人"，t 从 a 干到 x 就把活干完了，交出来的成品（一个面积值）和工人的名字没有关系。这也解释了另一件事——为什么 ∫abf(x)dx=∫abf(t)dt。定积分只认「区间 + 被积函数」，不认变量用什么字母，因为变量在积分内部只是跑腿的。老师课上反复念这一句，是因为后面第五套公式里，正是这条"与字母无关"让上下限能自然对接上。

05:25主定理（本页的发动机）

设 f 在 [a,b] 上连续，则 Φ(x)=∫axf(t)dt 在 [a,b] 上可导，并且

Φ'(x)=f(x)

证明只说一句话：按导数定义写出差商 Φ(x+Δx)−Φ(x)Δx；用区间可加性把分子化成 ∫xx+Δxf(t)dt；用积分中值定理把它写成 f(ξ)⋅Δx（ξ 夹在 x 与 x+Δx 之间）；除以 Δx 后令 Δx→0，这时 ξ→x，再由 f 的连续性把 f(ξ) 换成 f(x)，极限就是 f(x)。

  1. 导数定义：把"变化率"写成差商再取极限：
    Φ'(x)=limΔx→0Φ(x+Δx)−Φ(x)Δx
    这一步只是把题目翻译成可算的形式。
  2. 区间可加性：把 ∫ax+Δx 拆成 ∫ax+∫xx+Δx，前一块与 Φ(x) 相消（也可以理解成先交换上下限再"接起来"）。于是分子只剩 ∫xx+Δxf(t)dt。
  3. 积分中值定理：这条定理的直观是「弯弯曲曲的面积 = 一个长方形的面积」，长是底 b−a、高取某个函数值 f(ξ)。套到这里就是 ∫xx+Δxf(t)dt=f(ξ)Δx，ξ 在 x 与 x+Δx 之间。
  4. 取极限：Δx 上下约掉，式子变成 limΔx→0f(ξ)。Δx→0 时 ξ 被夹得越来越贴近 x，由连续性得极限为 f(x)。
04:47为什么偏偏要卡「连续」这条线

容易混的是两个不同的条件。要让定积分存在（可积），条件松得多：只要 f 有界、且只有有限个间断点就够了，老师在新授课里强调过"可积的要求比较松"。可本定理要的是可导并给出 Φ'=f，就必须要求连续——原因全在最后一步：必须把 f(ξ) 换成 f(x)，而这一步没有连续性过不去。所以「连续」不是老师故意为难，它是证明链条上不可替换的一环。一旦区间内出现间断点，这条求导公式就得小心（见第五节的误用反例，也可回看 无界函数的反常积分）。

端点处怎么办
12:53在开区间 (a,b) 内用的是普通导数；在左端点 x=a，Δx 只能向右取，得到的是右导数；在右端点 x=b 只能向左取，得到左导数。结论照样成立：Φ'+(a)=f(a)、Φ'−(b)=f(b)。定理在两端只是退化为单侧导数，不影响结论。
证明里的"顺带收获"
15:20因为「可导必连续」，证出 Φ 可导的同时就顺带证了它连续，所以课本不单独证连续。由此得到推论：连续函数一定有原函数，∫axf(t)dt 就是它的一个原函数。注意这个推论的分量——它保证了原函数"存在"，哪怕我们写不出初等表达式（比如 e−t2）。

二、题型套路一：变上限求导的五套公式

17:24新授课重点讲了第一套，但考试会把上限、下限甚至上下限统统换成 x 的函数。与其记五条，不如记一句口诀：上限代入乘以上限的导数，减去下限代入乘以下限的导数。下面五条都是它的特例：

情形求导结果记法
上限是 x，被积函数只含 tΦ'(x)=f(x)直接把 x 代进去
下限是 x−f(x)先交换上下限，多个负号
上限是 φ(x)f(φ(x))φ'(x)链式法则，两步走
下限是 φ(x)−f(φ(x))φ'(x)负号 + 链式法则
上下限都是 x 的函数f(h)h'−f(g)g'上代入乘上导，减下代入乘下导

例 118:43求下列导数：（1）(∫1xxcostdt)'；（2）(∫x5sintdt)'；（3）(∫xx2costdt)'。

思路：先判断是"哪一套"，再动手

（1）这是全章最容易栽的一题。18:43定理说"上限是 x，把 x 代进去"，可它有一个前提：被积函数只能含积分变量 t。本题被积函数是 xcost，那个 x 与 t 无关，是可以提出积分号的常数，所以先外提：

ddx∫1xxcostdt=ddx(x∫1xcostdt)

现在括号里是两个 x 的函数的乘积，用乘积求导：

=1⋅∫1xcostdt+x⋅cosx

（2）下限是 x，22:26交换上下限会多一个负号，再把 x 代进去：结果是 −sinx。

（3）上下限都是 x 的函数，套最后一条。上限 h(x)=x2 求导得 2x，下限 g(x)=x 求导得 1：

=cos(x2)⋅2x−cosx⋅1=2xcos(x2)−cosx
这一步最容易错

第（1）题直接把 x 代进 xcost，得到 xcosx。错在把「外部变量」当成了「被积变量」。同样是代 x，第（2）(3) 题被积函数只含 t，代进去没问题；第（1）题被积函数里混进了外部变量，必须先把它提出去，于是多出一项"x 不动、积分那块求导"和一项"积分不动、x 求导"。凡被积函数含外部变量，一律先外提再求导。

三、题型套路二：含变上限积分的极限题

32:29这是考试里出现频率极高的一类：极限的分子或分母上挂着一个变上限积分。识别方法是——先代入看型：上限下限一代，积分变成 ∫aa=0，于是通常是 00 型，直接用洛必达把积分号消掉。

例 232:29求 limx→0∫cosx1e−t2dtx2。

思路：判定 00 → 洛必达消积分号 → 等价无穷小收尾

先看型：分母 x2→0；分子下限 cosx→1，上限也是 1，所以分子趋于 ∫11=0。确认是 00 型，可以洛必达。分母求导得 2x；分子是「下限是 cosx」这一套，求导时先交换上下限出负号，再乘以下限的导数：

ddx∫cosx1e−t2dt=−e−cos2x⋅(−sinx)=e−cos2xsinx

于是原式变成

limx→0e−cos2xsinx2x

把它拆成两块相乘：limx→0e−cos2x=e−1（连续，直接代），而 limx→0sinxx=1（等价无穷小 sinx∼x，也是第一重要极限）。所以

limx→0∫cosx1e−t2dtx2=12e
33:40为什么这类题"一步都不能省"

有人会问：能不能先把分子那个积分算出来再代入？不能——e−t2 没有初等原函数，你根本积不出来。洛必达的妙处正在于：在求导的那一瞬间把积分号消掉，只留下被积函数在端点的值，于是不可积的东西反而变成了可算的代数式。这就是这类题"看着吓人、动手很轻"的原因。

再把套路压实成三步：①代入定类型（大多是 00）；②洛必达（变上限求导，注意下限型要出负号）；③收拾剩下的式子（等价无穷小、重要极限、直接代入）。三步里最常翻车的是第②步的符号，其次是第③步忘了把 sinx 换成 x 之后还要处理 12 这个系数。

四、知识速查：牛顿-莱布尼兹公式

39:46求定积分的主工具。设 F 是 f 在 [a,b] 上的一个原函数（且 f 在 [a,b] 上连续），则

∫abf(x)dx=F(b)−F(a)

书写上，手写习惯写成竖线形式，书上印成中括号，两种都对。代入次序永远是先上限、后下限，谁减谁差别极大；另外定积分算出来是一个数，不用再加积分常数 C。

34:21它为什么成立：证明只串两根线

设 Φ(x)=∫axf(t)dt。由主定理已知 Φ'(x)=f(x)，而 F 也是 f 的原函数，两个原函数之间只差一个常数：Φ(x)=F(x)+C。

  • 令 x=a：左边 Φ(a)=∫aaf=0，右边 F(a)+C，所以 C=−F(a)。
  • 令 x=b：Φ(b)=F(b)−F(a)；而 Φ(b) 按定义就是 ∫abf。

于是 ∫abf=F(b)−F(a)。整个证明只用了「变上限积分是原函数」这一句话——所以新授课 变上限积分函数 那一页绝不是孤立的，它正是牛顿-莱布尼兹公式的垫脚石。也正因为这个公式把"切割求和取极限"的定积分与"求原函数"的不定积分接了起来，它才被叫做微积分基本公式：在此之前，这两件事看上去毫无关系。

39:46为什么定积分不写 +C

不定积分求的是"一族"原函数，彼此相差常数，所以必须写 +C 才完整；而定积分算的是两个具体数值之差 F(b)−F(a)，那个常数在相减时刚好抵消掉了。既然加不加都不影响结果，约定俗成就省掉。考场上写了 +C 虽然不改数值，却暴露你对"定积分是数、不定积分是族"还没分清——建议养成不写的习惯。

例 341:00计算 ∫−13dx1+x2。

思路：认出 arctan，代限后用一个奇函数性质化简

11+x2 的原函数是 arctanx，所以

∫−13dx1+x2=[arctanx]−13=arctan3−arctan(−1)

arctan 是奇函数，所以 arctan(−1)=−arctan1=−π4。再代入 arctan3=π3（对应 tanπ3=3），得

π3−(−π4)=π3+π4=7π12

易错点是最后这一步：减去一个负数等于加上它的相反数，很多人写成 π3−π4=π12，白白丢掉一半的分。

例 443:30计算 ∫0πsinxdx，并说明它的几何意义。

思路：原函数是 −cosx，直接代限
∫0πsinxdx=[−cosx]0π=(−cosπ)−(−cos0)=1+1=2

几何上，这是正弦曲线在 [0,π] 上与 x 轴围成的曲边梯形面积。有意思的是：π 不是整数、"山包"的形状也不规整，最后围出的面积却恰好是整数 2——44:33老师课上还专门感慨了这个"巧合"。

顺带记一条书写规范：[F(x)]ab 中的方括号只表示"代限后再相减"，不要和括号混淆；先把原函数完整写出来，再一次性代两个端点，比"先代一个再代一个"更不容易出错。

五、使用条件的红线：两个反例

41:47红线：区间内必须处处"正常"

牛顿-莱布尼兹公式要求 f 在整个闭区间 [a,b] 上连续。一旦区间内部藏着间断点、尤其是无界点，公式会给出荒谬的结果。看这个反例：

若对 ∫−111x2dx 盲目套公式，得 [−1x]−11=(−1)−(−(−1))=−2。但被积函数在 x=0 处无界、且恒为正——面积不可能为负，更不可能有限。真相是它发散到 +∞。正确做法是当作瑕积分（见 无界函数的反常积分）在 0 处拆成两段分别取极限。

口诀一句话：公式用错位置，比不会用还可怕。

48:40为什么"拆成两段"就能得到正确答案

内部瑕点的处理原则是：在瑕点处把区间切开，每段各自取极限，两段都收敛才算整体收敛。对 ∫−11x−2dx，切在 0 得 ∫−10+∫01，右段 =[−1x]0+1=−1−(−∞)=+∞，左段同理为 +∞，两段都发散，整体发散——这与"不拆得 −2"形成鲜明对照。反过来，∫−11|x|−2/3dx 拆开后每段都等于 3，加起来是有限的 6。同样是"无界"，一个发散一个收敛，区别只在无界的"速度"。48:40这也正好接上下一节的比较判别法。

例 549:34设 f(x) 在 [0,+∞) 上连续，且 f(x)>0。证明 F(x)=∫0xtf(t)dt∫0xf(t)dt 在 (0,+∞) 上单调增加。

思路：先看变量——上下都是 x 的函数，商的形式，直接求导

拿到题目先观察变量：分子分母的上限都是 x，积分里的 t 都是内部哑变量，所以 F 是 x 的函数。这是一个"商求导"，按商的求导法则（分母平方、分子导乘分母减分子乘分母导）：

F'(x)=xf(x)∫0xf(t)dt−f(x)∫0xtf(t)dt(∫0xf(t)dt)2

分子两项都有公因子 f(x)（它是外部量，可以提出去），提出后剩

F'(x)=f(x)[x∫0xf(t)dt−∫0xtf(t)dt](∫0xf(t)dt)2=f(x)∫0x(x−t)f(t)dt(∫0xf(t)dt)2

最后一步的动机是：把外部的 x 塞进积分号变成常数倍——因为 x 与 t 无关，所以 x∫0xf(t)dt=∫0xxf(t)dt，两个积分合并成 ∫0x(x−t)f(t)dt。

现在判断符号：分母是平方，恒正；f(x)>0；当 x>0 时 t 在 0 到 x 之间跑，所以 x−t≥0、f(t)>0，被积函数非负且不恒为零，故 ∫0x(x−t)f(t)dt>0。三块相乘为正，

F'(x)>0⇒F(x)在(0,+∞)上单调增加
这一步最容易错

把 x 当成积分变量，直接对被积函数求导。积分号里的 t 才是积分变量，x 是外部量。判断 (x−t) 的符号时也正是靠这一区分：x 一旦确定就看作固定的常数，t 从 0 变到 x，所以 t<x、x−t>0。同一个题目里"谁是变量、谁是常数"必须时刻分清，这就是内部变量与外部变量的现实意义。

六、易错清单

  • 被积函数含外部变量（例 1 第（1）问）：必须先外提再乘积求导，直接"把 x 代进去"是错得最多的一条。
  • 下限是 x：记得先交换上下限、多一个负号，结果是 −f(x) 而不是 f(x)。
  • 上下限都是函数：两端都要乘各自的导数因子，写成"上代入乘上导，减下代入乘下导"三步，别漏第二步的负号。
  • 把变上限积分当定积分：前者是函数（上限在动），后者是数（上下限固定），一个是求导问题、一个是代值问题。
  • 含变上限的极限不先判型：先代入看是不是 00，再决定洛必达；乱用会算出不存在的极限。
  • 牛顿-莱布尼兹的连续条件：遇到分母为零、区间内有间断点，先警觉——它可能是反常积分（无穷限的反常积分 无界函数的反常积分），不能直接代限。
  • 代限次序与符号：永远 F(b)−F(a)；arctan(−1)=−π4 这种"减去负数"最容易写成减正数。
记忆入口 · 一眼回忆

一条链

变上限 Φ=∫axf→ 主定理 Φ'=f→ 推论 连续函数有原函数→ 求定积分 牛顿-莱布尼兹

要背的

  • 一句口诀：上限代入乘上导，减下限代入乘下导。五套公式全是它的特例。
  • ∫abf=F(b)−F(a)：先上后下，不写 C。
  • 连续函数必有原函数，而 ∫axf(t)dt 就是其中之一。

两个坑

  • 被积函数含外部变量 x → 先外提再乘积求导（例 1 第（1）问）。
  • 区间内有无界点就不能直接套牛顿-莱布尼兹：∫−11x−2dx 代限得 −2 是错的，真相发散；对照 ∫−11|x|−2/3dx 收敛于 6。

三个动作

  1. 见变上限 → 先问"哪一套公式"，再问"被积函数里有没有外部变量"。
  2. 见 lim∫⋯xk → 先定 00，再洛必达消积分号。
  3. 见求定积分 → 先扫一眼区间内有没有间断点或无界点。
