这页的定位：工具箱，不是概念页

00:00老师开头就说得很直白：这部分大家就得死记了，因为绝大部分求导公式我们已经推导完了，所以这里进行一个总结。也就是说，这一页不是要你再推一遍，而是把前面散落在各处的结论钉在一张表里，方便以后随时抽出来用。

它分两半：一半是「法则」（告诉你一个复杂的导数该怎么拆），一半是「公式」（拆完之后每一小块的结果是多少）。做题时两步配合——先用法则把大式子拆成小块，再用公式把每块换成结果。

什么时候会用到这页

后面隐函数求导、对数求导、参数方程求导、洛必达、泰勒……没有一页离得开这套公式。它们就是高数里的加减乘除。你现在不熟，后面每道题都会卡。所以这一页的目标不是「看懂」，是「条件反射」。

第一块：四则运算求导法则

06:08这四条老师说是「比较熟，稍微过一遍」的。但越熟越容易在乘积、商的细节上翻车，所以先把它们一字排开。

法则写法一句话提醒
和差 (u±v)'=u'±v' 先求导再加减，直接拆
常数提出 (Cu)'=Cu' 常数原样挂着，别求导成 0 再乘
乘积 (uv)'=u'v+uv' 两项，前导后不导 + 前不导后导
商 (uv)'=u'v−uv'v2 分母是 v2，分子是「导乘不导 − 不导乘导」
为什么乘积是「两项相加」而不是「各自求导再相乘」

这是新手最容易犯的糊涂：(uv)' 不等于 u'v'。原因在乘积的增长来自两方面——一边变、另一边不变，或者反过来。比如面积 =长×宽，长单独变一点、宽单独变一点，两种变化量都要算，所以出现两项 u'v 与 uv'。只有当成一个整体去看才会漏掉另一半。

商的公式可以用乘积法则自己推出来：(uv)'=(u⋅v−1)'=u'v−1+u(−1)v−2v'，通分后就是上表那一项。所以记住乘积法则，商法则当场能造；但考试时商分母 v2 的平方别漏。

商的公式最容易写错的两处

一、分子顺序写反。是「上导下不导 − 上不导下导」，即 u'v−uv'。写成 uv'−u'v 结果差一个负号，整题报废。

二、分母忘平方。u'v−uv'v，漏了右上角那个 2，是极普遍的错误。养成习惯：一写除法，先补 v2。

第二块：基本初等函数求导公式（全表）

01:00老师把公式分成几「组」来讲，每一组都点了一句记忆口诀。下面按他讲课的顺序贴出来，并在每组后附上口诀。

三角六组

正号三家（高中也熟）
(sinx)'=cosx(tanx)'=sec2x(secx)'=secxtanx
负号三家
(cosx)'=−sinx(cotx)'=−csc2x(cscx)'=−cscxcotx

01:00老师特别提醒：secx、cscx 高中没怎么学，但在大学里天天用，求导、求积分都在用。所以别因为它们眼生就跳过——secx=1cosx，cscx=1sinx，记住这两个定义，符号自然跟着来。

反三角四组

正号
(arcsinx)'=11−x2(arctanx)'=11+x2
负号（都带「余」）
(arccosx)'=−11−x2(arccotx)'=−11+x2

02:19老师故意把反三角四组单独提上来，就是为了点破这个规律：这五个是正号、这五个是负号，有规律——正弦、正切、正割、反正弦、反正切，正正正正正；余弦、余切、余割、反余弦、反余切，带『余』的就都有负号。所以反三角那两组负号，看名字就能现写，不必硬背。

指数、对数四组

指数
(ax)'=axlna(a>0,a≠1)(ex)'=ex
对数
(logax)'=1xlna(lnx)'=1x

04:03ax 与 logax 都要求 a>0 且 a≠1，这是底数能当底数的前提。lnx 是 a=e 的特例，所以 (lnx)'=1xlne=1x。老师强调这四组很常用很常用。注意 ex 是唯一求导不变的函数，这条在后面高阶导数里会反复用到。

老师现场加的彩蛋：(ln(−x))'=1x

05:10书上没有这条，老师自己推了一遍当作小彩蛋：

(ln(−x))'=1−x⋅(−x)'=1−x⋅(−1)=1x

05:10老师啊你这个公式书上没有啊，咱做成一个小彩蛋。后边这个东西我们还会再用到它。它说明：无论 x>0 还是 x<0，ln|x| 的导数都是 1x。后面讲积分时这个彩蛋会回来。先记住结论：ln|x| 导数是 1x。

为什么是 1x 而不是别的

关键在于复合函数求导：外层 ln(□) 导数是 1□，内层 □=−x 导数是 −1，两个相乘正好把负号抵消。这正好提前演练了下一节要讲的复合函数求导——彩蛋虽小，却是个合格的预热。

第三块：反函数求导法则

07:13反函数求导在考试里「着实用得不是特别多」，但老师建议记成一句人话：

dydx=1dxdy

也就是y 对 x 的导数，等于 x 对 y 的导数的倒数。比如已知 (ex)'=ex，那么它的反函数 lnx 就有 (lnx)'=1ey=1x。老师原话：我觉得这个还稍微有点人话的味道，还能理解——y 对 x 的导是 x 对 y 的导的倒数。

为什么是倒数而不是负的

从几何上看，反函数就是把图像沿直线 y=x 翻折。翻折不改变「切线斜率是正是负」，只把它变成自己的倒数（因为横纵坐标互换）。所以反函数导数 = 原函数导数的倒数，而不是相反数。这一点要和「商的公式」区分开，它们长得不像、也毫不相干。

第四块：复合函数求导（洋葱法则）

07:57老师明确说：反函数求导其实用得不多，真正做题用最多的是复合函数求导——我讲的『洋葱法则』非常好用。复合函数求导的法则是

ddxf(g(x))=f'(g(x))⋅g'(x)

「洋葱法则」是它的操作化说法：从最外层往里一层层剥，每一层求导后乘起来。比如 sin(nx)：最外层是 sin，导数是 cos；里面是 nx，导数是 n；合起来是 ncos(nx)。

例题：综合练手 y=sin(nx)⋅sinnx

例08:51已知 y=sin(nx)⋅sinnx，求 y'。

思路：先乘积法则，再洋葱法则

两部分都用 x 表达、中间是相乘，所以先用乘积法则：把 sin(nx) 看成第一块、sinnx 看成第二块，分别「前导后不导 + 前不导后导」。

第一块对 sin(nx) 求导（洋葱：外层 sin，内层 nx）：

(sin(nx))'=cos(nx)⋅n=ncos(nx)

第二块对 sinnx 求导（洋葱：外层「某东西的 n 次方」，内层 sinx）：

(sinnx)'=nsinn−1x⋅cosx

代入乘积法则，并把两项里都出现的 sinn−1x 提出来：

y'=ncos(nx)sinnx+sin(nx)⋅nsinn−1xcosx
y'=nsinn−1x(cos(nx)sinx+sin(nx)cosx)

括号里是和角公式 sinAcosB+cosAsinB=sin(A+B)，这里 A=nx,B=x：

y'=nsinn−1x⋅sin((n+1)x)
这一步最容易错

把 sinnx 的导写成 nsinn−1x 就停了。忘了对内层 sinx 再求一次导（乘 cosx）。幂函数的链式法则和三角求导是叠着的，两层都要走完。老师课上也特别把「次数朝外提、次数减一、再乘里层 cosx」念了两遍。

为什么出题模式「以复合函数求导为主」

11:54老师收尾时说：出题的模式大部分是以复合函数求导为主的，当然还有对数求导、参数方程求导、隐函数求导。根本原因是——真实函数几乎都是复合出来的（sin(nx)、ln(1+x2)、(1+x)10……）。所以洋葱法则是这一页、乃至整章的第一基本功：它不会单独考，但每一道题都藏着它。
