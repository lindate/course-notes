P101幂级数（一）：收敛半径与收敛域

一句话核心

幂级数把常数项级数升级成函数项级数——通项里多了 x。阿贝尔定理告诉我们：它的收敛域一定以原点为中心对称成一个区间，内部绝对收敛、端点必须单独判。求收敛半径用比值法 R=lim|an+1an|；但缺项时不能直接套公式，要直接比值判别或换元。

先把来路理清：从常数项到函数项

00:47在前面两章我们讲的级数，通项都只与 n 有关：比如 1n、1n2 这种正项级数，或者 (−1)n−11n 这种交错级数。它们的敛散性是固定的——发散的就是发散的，收敛的就是收敛的，跟 x 没关系。这是"常数项级数"的世界：你给一个级数，它要么收敛要么发散，结论唯一。

03:21今天不一样了。看一个例子：∑n=1∞n!xn。它的通项里既与 n 有关，也与 x 有关。这类通项是一个带 x 的函数、再对 n 求和的级数，就叫函数项级数。关键差别在于：你每取定一个 x 的值，它就退化成一个常数项级数；而 x 取不同的值时，它可能一会儿收敛、一会儿发散。换句话说，函数项级数的敛散性不是固定的，而是依赖于 x 的取值。这正是本章要研究的核心现象。

05:19为什么它"只与 x 有关"

函数项级数 ∑un(x) 是「先对 n 求和、再取极限」：S(x)=limN→∞∑n=1Nun(x)。求和与极限都只针对下标 n 进行，x 只是被带进去的一个参数，所以最终算出来的和函数 S(x) 里不再出现 n，只依赖那个被指定的 x。这就是"函数项级数求和后只剩 x"的含义。也正因如此，我们才要问：对哪些 x 它收敛、对哪些 x 它发散？

收敛点、发散点、收敛域

09:01既然同一个级数对不同 x 命运不同，就自然要问：哪些 x 让它收敛？这就引出两个定义。老师还顺便玩了个谐音梗——"收敛点"听着像"收敛点"，但这是严肃的定义，不是段子。

收敛点
若把 x=x0 代进去，级数 ∑un(x0) 收敛，则称 x0 为收敛点。
收敛域
把所有收敛点收集起来组成的集合，就叫收敛域。我们考试里基本只求它和收敛点。
发散点 / 发散域
代进去发散的点叫发散点；考试一般不单独考，所以不展开。

10:54一句话记：收敛域 = 让这个级数收敛的全体 x 的集合。它可能是区间、可能是全体实数、也可能只有孤零零一个点。后面我们会看到，幂级数的收敛域结构异常规整，规整到可以用一个半径完全描述。

幂级数：函数项级数的"正规军"

12:11函数项级数五花八门，比如 ∑sin(nx) 也带 x，但它不是幂函数。我们主要研究的、也是考试重点的，是下面两种标准形式：

定义 · 幂级数

称下面两类为幂级数（它们通项是 x 或 x−x0 的幂）：

（一）∑n=0∞an(x−x0)n　——称为(x−x0) 的幂级数；

（二）∑n=0∞anxn　——称为x 的幂级数。

其中 an 只与 n 有关，叫系数；x 是变量。本页主要看第二种（第一种只要令 t=x−x0 就归约成第二种）。

14:52幂级数 ⊂ 函数项级数，不是全部

∑sin(nx) 也是函数项级数，但它通项是 sin，不是 (x−x0)n 这种幂函数，所以它不是幂级数。我们研究幂级数，是因为它的收敛性异常规整（下面阿贝尔定理会讲），而且函数还能展开成它（见 函数的幂级数展开）。简单说，幂级数是函数项级数里"最好算、最有用"的一支，所以本章的全部篇幅都给它。

核心问题：收敛域为什么关于原点对称

15:42要回答"在哪收敛、在哪发散"，阿贝尔定理是背后的总根源。我们先把任意项级数的判别法搬过来：对 ∑un(x)，看后一项比前一项的绝对值的极限 L；若 L<1 收敛，L>1 发散。把这个思想用在幂级数 ∑anxn 上，就能推出下面这个决定全局的定理。

阿贝尔定理（Abel）

对幂级数 ∑anxn：

（1）若它在 x=x0≠0 处收敛，则对一切满足 |x|<|x0| 的 x，级数绝对收敛；

（2）若它在 x=x0 处发散，则对一切满足 |x|>|x0| 的 x，级数发散。

18:02它为什么能推出"收敛区间关于原点对称"

设所有使级数收敛的 |x| 的上确界为 R。由阿贝尔定理（1）：只要在 |x|<R 的某点收敛，它内部所有更靠近原点的点都绝对收敛——所以 (−R,R) 内部整段绝对收敛。由（2）：只要在 |x|>R 的某点发散，它外部所有更远的点都发散——所以 |x|>R 整段发散。于是收敛点集一定是以原点为中心、半径为 R 的对称区间（端点 x=±R 收敛与否要单独看）。这就是"收敛区间关于原点对称"的来历，不是凭空规定的。

18:02收敛域对称，但端点可以"一收一散"

阿贝尔定理只保证内部以原点对称地绝对收敛、外部对称地发散，但它不保证两个端点同生共死。端点 x=R 与 x=−R 是否收敛要分别代回去判断，结果可能一边收敛、一边发散（如例 1 的 (−1,1]），也可能两边同收或同散。所以"关于原点对 称"指的是那个开区间 (−R,R) 对称，收敛域整体未必左右对称。这一点在画图和理解时务必分清，别把"收敛区间对称"误说成"收敛域对称"。

收敛半径怎么求：比值法

19:26对标准形式 ∑anxn，把 x 的部分先放一边，只看系数，定义

ρ=limn→∞|an+1an|

然后收敛半径 R 由 ρ 决定，分三种情况：

情况ρ收敛半径 R含义
一般0&lt;ρ&lt;∞R=1ρ区间 (−R,R) 内绝对收敛
系数为零衰减极快ρ=0R=∞x 随便取都收敛
系数暴涨ρ=∞R=0只有 x=0 收敛
18:02比值法从哪来：就是任意项级数的比值判别

这个 ρ 公式不是凭空来的。把 ∑anxn 当成任意项级数，套用比值判别法：看 lim|un+1/un|=lim|an+1xn+1/(anxn)|=|x|⋅ρ。当 |x|ρ&lt;1 时绝对收敛，|x|ρ&gt;1 时发散。于是 |x|&lt;1/ρ 收敛、|x|&gt;1/ρ 发散，半径自然就是 R=1/ρ。所以幂级数的比值法，本质就是把上一章任意项级数的 L 判别法搬过来、把 x 提出来。这也解释了为什么缺项时（系数夹零）不能直接套——那时"相邻项系数"并不是真正的 an+1/an。

21:41ρ=0 为什么对应 R=∞

由阿贝尔定理，|x|⋅ρ&lt;1 才收敛。若 ρ=0，则任何 x 都满足 |x|⋅0=0&lt;1，所以 x 任取都收敛，自然地 R=∞。注意这里的 0 是真的零（x 乘上真零等于真零，不是未定式），不像洛必达里的 0⋅∞。

22:50反过来若 ρ=∞：只要 x≠0，|x|⋅∞=∞¬&lt;1，只有 x=0 时 0⋅∞ 仍按"真零"处理等于 0&lt;1 才收敛，所以 R=0。

收敛区间与收敛域：差在端点

29:26有了 R，立刻得到收敛区间 (−R,R)——它是永远开的。但两个端点 x=±R 收敛还是发散，必须代回去单独判断，不能想当然。端点组合出四种可能的收敛域：

(−R,R)
两个端点都发散。
(−R,R]
左端点发散、右端点收敛。
[−R,R)
左端点收敛、右端点发散。
[−R,R]
两个端点都收敛。

例 1：普通情形，R=1

例 134:07求 ∑n=1∞(−1)n−1xnn 的收敛域。

思路：标准型，直接套比值法

这是 ∑anxn 标准型（系数 an=(−1)n−11n）。只取系数比：

ρ=limn→∞|an+1an|=limn→∞nn+1=1

所以 R=1ρ=1，收敛区间是 (−1,1)。下面代端点：

当 x=1：∑(−1)n−11n 是交错级数，1n 递减趋于 0，由莱布尼茨定理收敛。

当 x=−1：∑(−1)n−1(−1)nn=∑−1n，是调和级数乘 −1，发散。

因此收敛域是 (−1,1]。

这步最容易错

把 x=−1 也算成收敛。代 x=−1 时，交错的符号 (−1)n−1 和代入的 (−1)n 会叠加成 (−1)2n−1=−1，级数变成 −∑1n，是调和级数，发散。端点必须老老实实代进去，不能靠"看着像交错"就下结论。

例 2 与例 3：两个极端情形

例 238:28求 ∑n=0∞xnn! 的收敛域。

解
ρ=limn→∞|1/(n+1)!1/n!|=limn→∞1n+1=0

ρ=0，所以 R=∞，收敛域是 (−∞,∞)，x 任取。这也和 ex 的展开式（见 函数的幂级数展开）一致：ex=∑xnn! 处处收敛。

例 340:11求 ∑n=0∞n!xn 的收敛域。

解
ρ=limn→∞|(n+1)!n!|=limn→∞(n+1)=∞

ρ=∞，所以 R=0，只有 x=0 收敛，收敛域就是单点集 {0}。

41:30老师的比方：谁更"猛"

为什么例 2 处处收敛、例 3 只有原点收敛？把 x 当常数（比如取 10），例 2 的分母是 n!，阶乘比任何指数函数都"猛"，分子 10n 再大也被压下去，必收敛；例 3 反过来，分子是 n!，分母只是 10n，阶乘"猛"过指数，项反而爆炸，除非 x=0 让项直接变 0。收敛半径的本质，就是问"xn 与系数谁增长得更快"。系数衰减快于任何指数（如阶乘倒数）→ R=∞；系数增长快于任何指数（如阶乘）→ R=0；介于其间 → R 为有限正数。

哪些才算"标准型"

14:52老师特别强调：∑anxn 只是最标准的样子，但 ∑anxn+1、∑anxn−1 同样属于标准型——因为它们仍是对 x 的连续整数次幂、系数 an 一一对应，套公式时只取 an 的比值即可。真正"非标准"的只有两类：只含偶次项（如 x2n，系数里夹零）和含 (x−x0)n。前者靠换元 t=x2，后者靠换元 t=x−x0，都能化回标准型再套公式。

46:45为什么缺项会引发"系数错位"

标准型公式 ρ=lim|an+1an| 的底层假设是：相邻两项的次数恰好相差 1。一旦只留偶次项，第 n 项是 x2n、第 n+1 项是 x2n+2，中间 x2n+1 的系数是 0。这时如果机械地拿"第 n+1 个系数"去比"第 n 个系数"，比的其实是 x2n+2 的系数与 x2n 的系数，跳过了中间的零——比值里隐含的一个 |x|2 因子被你无视了，结果自然失真。举个直观反例：例 4 若不管缺项直接套，相邻系数比是 (2n+2)!((n+1)!)2/(2n)!(n!)2=4，你会错误地得到 R=14；但真正收敛半径是 12——差了一倍，正是那个被你无视的 |x|2 在作怪。所以缺项不能"裸套"公式，必须让比值的次数差回到 1：要么令 t=x2 把 2n 压平，要么干脆带着 x 一起比，后者等价但更不容易漏。换个角度想：缺项级数本质上就是"标准型套了一层换元"，你把它换回去，一切回到标准型的轨道，公式就又能用了。这也解释了老师反复强调的"系数里有没有零"这条判断标准——它比死记"偶数次项"更本质，因为只留奇数次项（如 x2n−1）是同样的毛病，处理方式也完全相同。

大坑：缺项时不能直接套公式

46:45前面的比值法只针对标准型 ∑anxn（奇次、偶次项都齐全）。如果级数只含偶次项（如 x2n）或只含奇次项（如 x2n−1），那"系数"里夹着一堆 0，直接套 ρ=lim|an+1/an| 会出错，因为比的不是相邻真正非零的系数。

例 4（缺项）46:45求 ∑n=0∞(2n)!(n!)2x2n 的收敛半径与收敛域。

思路一：直接比值（带着 x 比）

不分离系数，直接对相邻项做比值判别：

limn→∞|un+1un|=limn→∞(2n+2)(2n+1)(n+1)2⋅|x|2=4|x|2

令 4|x|2&lt;1 得 |x|&lt;12，所以 R=12，收敛区间是 (−12,12)。端点 x=±12 代入后项为 (2n)!(n!)214n，其量级约 1πn（不趋于 0 足够快，∑1n 发散），故端点发散，收敛域为 (−12,12)。

思路二：换元 t=x2

令 t=x2，级数变成 ∑(2n)!(n!)2tn，这是 t 的标准型，可套公式：

ρ=limn→∞(2n+2)(2n+1)(n+1)2=4,Rt=14

即 |t|&lt;14，代回 t=x2 得 x2&lt;14，同样 |x|&lt;12。

换元后务必换回 x

算完 Rt=14 就当 R=14 收工。你求的是 t=x2 的收敛半径，而题目要的是 x 的。必须代回：|t|&lt;14⟺x2&lt;14⟺|x|&lt;12，所以 R=12。忘掉这一步是这类题最经典的失分点。

46:45小结这个"缺项坑"：判断标准是"系数里有没有 0"。只要某次幂的系数恒为零（隔项出现），直接的 ρ=lim|an+1/an| 比的就是错位的系数，结果失真。最稳妥的记忆是：看见 x2n、x2n−1 这类，先令 t=x2（或 t=x），变回 t 的标准型再算，算完千万别忘了换回 x。

(x−x0)n 型：换元归约

例 557:17求 ∑n=1∞(x−1)n2nn 的收敛域。

思路：令 t=x−1，变回标准型

这是 ∑an(x−x0)n 型（x0=1）。令 t=x−1，级数化为 ∑tn2nn，对 t 套公式：

ρ=limn→∞|2nn2n+1(n+1)|=12,R=2

于是 t∈(−2,2)，即 x−1∈(−2,2)，得 x∈(−1,3)。代端点：

t=2：∑2n2nn=∑1n，发散；t=−2：∑(−1)nn，收敛。

所以 t 的收敛域是 (−2,2]，x 的收敛域是 (−1,3]。

58:39四类题型一句话总结

① ∑anxn（标准型）→ 直接公式法；② 只含偶次项 ∑anx2n → 令 t=x2 再公式法，或带着 x 直接比；③ 只含奇次项 ∑anx2n−1 → 同理令 t=x2 或换元 t=x；④ ∑an(x−x0)n → 令 t=x−x0。后三种的口诀是：缺项或带 x0 的，先换元成 t 的标准型，算完再换回 x。

34:07端点判定为什么"代回去"而不是套公式

比值法求出的 R 只管内部，端点 x=±R 处的级数不再是"带 x 的幂级数"而是一个普通常数项级数，比值判别此时失去意义——|x|=R 恰好是边界，比值极限等于 1，判别法失效。所以端点必须老老实实代回，当作常数项级数单独判断：用莱布尼茨判别、调和级数、p 级数等已知结论。这一步没有任何公式可代，纯靠"代值 + 认级数类型"，也是考试最爱抠的细节，务必练熟代回的套路而不是想当然。
