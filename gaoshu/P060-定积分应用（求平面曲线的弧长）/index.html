P060平面曲线的弧长：以直代曲，量任意一条曲线

一句话核心

「平面曲线的弧长」这六个字里，除了那个「的」，每个字都有讲究。真正要做的事只有一件：把曲线剁成无数小段，每一段用一根直线顶替，再用勾股定理把这一小段的长度写出来。于是三种公式——参数方程、直角坐标、极坐标——其实只有同一个来源，区别只在「参数是谁」。

先问一句：一条随便画的曲线，它有多长

「平面曲线的弧长」这六个字，除了中间那个「的」是个虚词，其余六个字都有讲究。

  • 平面——说的是在纸上画的一条曲线。有平面曲线就一定有空间曲线（三维的），那是对应章节的内容。
  • 曲线——不是直线段拼出来的折线，而是真的带弯的、表达式随便给的那一类。
  • 弧长——曲线的长度。

「弧长」这个词以前是见过的，但见过的都是极特殊的情形：圆的周长是 2πR；三角形的周长是 a+b+c；长方形是 2(a+b)；正方形是 4a。它们都有现成公式，因为它们太规则了。站在考场上的问题是：如果给你一条曲里拐弯、只给一个方程的曲线，它有多长？

这件事之所以能做成，靠的是一件我们早就熟练的手艺——先切碎，再求和，最后取极限。定积分求面积是这么干的，求体积是这么干的，求弧长还是这么干。

为什么「碎」了以后就能算

关键在一条朴素的经验：一条足够短的曲线，看起来就是一条直线段。

你拿一根稍微弯的钢丝，截出很短的一小段，那一小段几乎是直的——用尺子量它和量它的两个端点之间的直线，读数几乎一样。曲线本身没法用尺子量，直线段可以；所以把曲线剁碎，就把「量曲线」换成了「量一大堆小直线」，这是唯一可行的一条路。

老师在课上把它说得更直白：这一小片是个圆弧，并不是一个线段，但因为它取得比较小，我们可以近似地看成是一个线段。这就是后面所有公式的唯一一块地基。

微元法：把曲线剁成小片，弧当成弦

设曲线从 A 到 B，我们在上面依次取许多个分点，把它切成 n 小段。取其中典型的一小段，记它的两个端点分别是 M、N。

现在做两件事：

  1. 把弧拉直。把 M 到 N 这一段弧，近似看成线段 MN。
  2. 把直线段用坐标差表示出来。过 M、N 分别作水平线和竖直线，交出一个直角三角形：横着的直角边是 Δx（横坐标的改变量），竖着的直角边是 Δy（纵坐标的改变量），斜边就是线段 MN。

斜边是两条直角边的斜边，那就直接上勾股定理：

Δs≈(Δx)2+(Δy)2

把「近似」升级成「微元」，也就是让分点无限密、每一小段都趋于无穷小时，Δx、Δy 就变成了微分 dx、dy，于是得到这一节的全部来源：

ds=dx2+dy2

这一行必须记死。后面三种形式的公式，全都是它的不同写法；推导的时候也只需要从它出发。

「以直代曲」到底合不合法

上面那句「取小了就近似是线段」，听着像自我安慰。把它说严一点：设一小段弧长为 Δs，两端点之间的弦长为 (Δx)2+(Δy)2，那么当 Δx→0 时，弦长与弧长之比趋于 1，两者之差是比 Δx 更高阶的无穷小。

这句话的后果很重要：每一段的误差都只占该段长度的一个趋于零的比例，所以把 n 段加起来、再让 n→∞，总误差也趋于零，和的极限就等于真正的弧长。于是「ds=dx2+dy2」不是近似式，而是一个等式——右边是左边的一阶主部。

一句话对照：Δs≈(Δx)2+(Δy)2 是近似（用于理解），ds=dx2+dy2 是精确（用于计算）。

第一种形式：参数方程——最基本的那一个

设曲线由参数方程给出

x=x(t),y=y(t),α≤t≤β

并且 x(t)、y(t) 在 [α,β] 上都有一阶连续导数。

看到 x、y 都挂在 t 上，有些同学会以为这是「立体图」。老师特意纠正：它仍然是一条平面曲线——x 是横坐标、y 是纵坐标，只不过这两个坐标被第三个量 t 统一调度。t 不是坐标轴上的任何一根轴，它只是「走到哪儿了」的计时器。

把 dx、dy 换成对 t 的微分：dx=x'(t)dt，dy=y'(t)dt。两式一起塞进 ds 的表达式：

ds=[x'(t)]2dt2+[y'(t)]2dt2=x'2+y'2dt

中间那一步「把 dt2 提出根号」，是两个括号里都含同一个因子 dt2 的缘故（A2dt2+B2dt2=(A2+B2)dt2），提出来之后开方就是 dt。

于是弧长是这一堆微元的总和。横坐标的范围从 x=a 到 x=b 已经用不上了，因为一切都换成了 t 的语言，所以积分变量就是 t，上下限换成 t 的取值范围 α、β：

S=∫αβx'(t)2+y'(t)2dt

这条公式就是这一讲的母公式。老师原话：这个参数方程囊括了我们后面要讲的极坐标还有直角坐标。所以后面两条不必单独背——需要的时候从这条推，一两行就出来了。

08:31老师的一段自白

公式太多，我有时候记其实也记不了那么多。你想，一个老师既讲高数又讲线性代数又讲概率，还想数学分析、还想高等代数……其实啥也不行。所以我好多公式其实记得不是特别准，怎么办呢？我就用这种自己推的、自己理解的方式来帮助大家去记。

这段话是这一讲的学习方法：母公式要背死，其余两条可以现推。宁可花二十秒推一遍，也不要背三条互相长得像的公式然后在考场上认错。

第二种形式：直角坐标——让 x 自己当参数

直角坐标就是最常见的样子：y=f(x)，x 在 [a,b] 上。老师半开玩笑地说，「突然写得这么正式，有些同学还觉得有点不可理解，什么叫直角坐标」——就是 y=x2、y=13x3 这种，你从学函数那天起就在画的图。

要套参数方程那条公式，就得把直角坐标硬"翻译"成参数方程。怎么翻译？把 x 自己派去当参数：

x=x,y=f(x),a≤x≤b

这样一来，第一个参数方程的导数就是 x 对 x 求导，等于 1（平方之后还是 1）；第二个参数方程的导数就是 f'(x)。代进母公式：

S=∫ab1+y'2dx(y=f(x),a≤x≤b)

老师明确说不建议把这条当成新公式去记：你也不要死记，你就用刚才参数方程的公式去推。因为「取 t=x」这个动作是零成本的——x 对 x 求导等于 1，这谁都知道。

这一条和「曲率」形似，别认错

后面的曲率公式里也会出现 1+y'2，但那是它的分母部分，外面还挂着 y''。弧长是把 1+y'2 整个积起来，曲率是把它当分母去除 y''——两个公式长得像，用处完全不同，别在考场上串行。

第三种形式：极坐标——变量换成 θ

极坐标下的曲线写作 ρ=ρ(θ)，其中 θ 从 α 变到 β，并且 ρ(θ) 在 [α,β] 上有一阶连续导数。要求的还是这段曲线的长度。

思路和上面完全一样：想办法把它变成参数方程。极坐标与直角坐标的转换关系是每个人都该记住的两行：

x=ρcosθ,y=ρsinθ

这里有一处极容易被误会的地方。有人说：「你这儿不是还有个 ρ 吗？怎么能说是 θ 的参数方程？」——注意，ρ 本身就是 θ 的函数，把它代进去以后，表达式里就只剩下 θ 了：

x=ρ(θ)cosθ,y=ρ(θ)sinθ

到这里它已经完全是一条关于 θ 的参数方程，可以放心套母公式。

  1. 两个坐标分别求导。x 是「ρ 与 cosθ 相乘」，按乘积求导法则：
    x'=ρ'cosθ−ρsinθ,y'=ρ'sinθ+ρcosθ
  2. 各自平方，再相加。平方之后一共出现四类项：ρ'2cos2θ、ρ'2sin2θ、ρ2sin2θ、ρ2cos2θ，还有两组交叉项 2ρρ'sinθcosθ 与 −2ρρ'sinθcosθ。
  3. 消。两组交叉项一个正一个负，正好抵消；剩下的四类里，ρ'2 的两项用 cos2θ+sin2θ=1 合成 ρ'2，ρ2 的两项合成 ρ2。
  4. 开方。x'2+y'2=ρ2+ρ'2。

所以极坐标下的弧长微元是

ds=ρ2+ρ'2dθ,S=∫αβρ2+ρ'2dθ
为什么交叉项一定要消掉

这不是巧合，而是极坐标的「正交性」在替你干活。ρ 变化的方向是沿着射线往外走，θ 变化的方向是垂直于射线拐弯，这两个方向互相垂直，所以 dρ 与 ρdθ 是另一组互相垂直的直角边，它们的平方和就是 ds2：

ds2=(dρ)2+(ρdθ)2

两边同除 dθ2，立刻得到 ρ2+ρ'2。这就是把这个公式记牢的最省力的办法：在极坐标里，「往外走」贡献 dρ，「绕圈走」贡献 ρdθ，两者垂直、平方相加。后面算面积时会有类似的一句：dS=12ρ2dθ。

三道例题，把三种形式各走一遍

例 1求摆线 x=a(t−sint)、y=a(1−cost) 的一拱（0≤t≤2π）的长度，其中 a>0。

思路：这是标准参数方程，直接套母公式

摆线在讲参数方程求导时已经见过：它是圆在直线上滚动时，圆周上一个定点划出的轨迹。t 从 0 走到 2π，正好画出一个「拱」。因为给的就是参数方程，不必翻译，直接代：

S=∫02πx'(t)2+y'(t)2dt
第一步：求导

x=a(t−sint) 对 t 求导，得 x'=a(1−cost)；y=a(1−cost) 对 t 求导，得 y'=asint。

第二步：平方相加，化简根号里的东西
x'2+y'2=a2(1−cost)2+a2sin2t

把第一项的平方展开：a2(1−2cost+cos2t)；再加上 a2sin2t。注意 cos2t+sin2t=1，两项合并成一个 a2，于是根号里剩下

x'2+y'2=a2(2−2cost)=2a2(1−cost)
第三步：用倍角公式把根号拆开

由 1−cost=2sin2t2，得 2a2(1−cost)=4a2sin2t2，开方出来是 2a|sint2|。所以

S=∫02π2a|sint2|dt
第四步：去绝对值，积分

因为 t 从 0 到 2π，所以 t2 从 0 到 π，而 sin 在这个区间上始终非负，绝对值可以放心去掉。凑一个微分：

S=4a∫02πsint2dt2=4a[−2cost2]02π=[−8acost2]02π

上限代入：−8acosπ=8a；下限代入：−8acos0=−8a。相减得

S=8a−(−8a)=8a
这一步最容易丢分

开方之后直接写 sint2，把绝对值扔掉。sin2u=|sinu|，这一步是恒等式，sinu 本身可能是负的。这里能去掉绝对值是因为有「t2 落在 [0,π]」这个条件撑腰，不是因为它可以随便去。

换成另一条摆线、积分区间改成 [0,4π]，t2 就会跑到 [0,2π]，其中一半的 sin 是负的，去掉绝对值就会把正负面积抵消掉，答案直接变成 0。凡是开方得到含 sin、cos 的式子，先问一句「在这个区间上它是正的吗」。

例 2证明：正弦线 y=asinx（0≤x≤2π）的弧长，等于椭圆 x=cost、y=1+a2sint（0≤t≤2π）的周长。

思路：两边各自算，看会不会算成同一个式子

这道题老师评价为「挺巧妙」。巧妙在哪儿？它逼你把两种形式都用一遍：前面那条是直角坐标，后面那条是参数方程。

第一条：正弦线的弧长

y=asinx 是直角坐标，套 S=∫ab1+y'2dx。这里 y'=acosx：

S1=∫02π1+a2cos2xdx

这个积分积不出来（它的原函数不是初等函数）。老师原话说得很干脆：这个式子不是特别好积，你先搁在这儿，先不用着急把它积出来。先放着。

第二条：椭圆的周长

椭圆给的是参数方程，x'=−sint，y'=1+a2cost。注意 y 这一项的系数是 1+a2，求导后平方正好等于 1+a2，把根号消掉：

S2=∫02πsin2t+(1+a2)cos2tdt
把两条摆在一起比

把 S2 的根号里也用一次 sin2t+cos2t=1：sin2t+cos2t+a2cos2t=1+a2cos2t。于是

S2=∫02π1+a2cos2tdt

现在两个式子长得一模一样，唯一的差别是积分变量一个叫 x、一个叫 t。但这根本不构成差别——

∫abf(x)dx=∫abf(t)dt

定积分只与积分区间和被积函数有关，与积分变量用什么字母毫无关系。搬一下家、换个名字，值不变。所以 S1=S2，命题得证。

这道题真正在考什么

它考的不是积分技巧，而是「定积分的值与积分变量记号无关」这条性质。看不出这一点的人会一直盯着那个积不出来的积分发愁；看出来的人只用一行「换个字母，值不变」就结束了。

顺带提醒：正因为第一条弧长的积分积不出来，才必须靠第二条「间接」证明相等。这也说明弧长公式给出的定积分不保证都能算出初等结果——椭圆周长就是历史上著名的算不出来的例子。

例 3求心形线 ρ=a(1+cosθ)（a>0）的全长。

思路：先弄清楚这条曲线怎么长出来的，再套极坐标公式

老师开场先开了个玩笑：这条曲线「特别适合表白用」。玩笑之后是很实在的一步——求弧长之前先画图。画极坐标曲线的通用动作是：让 θ 一点点增大，每走一步就沿那个方向量出长度 ρ，然后连起来。

第一步：描点
  • θ=0：cos0=1，所以 ρ=a(1+1)=2a——这是最远的一点，落在 x 轴正方向上。
  • θ=π6：ρ=a(1+32)，比 2a 小了一些。
  • θ=π2：cosπ2=0，ρ=a。
  • θ 继续增大到 π：cosπ=−1，ρ=a(1−1)=0——曲线回到原点，而且是以一个尖点收进去的。
  • θ 从 π 走到 2π：cosθ 从 −1 慢慢回到 1，ρ 从 0 慢慢长回 2a，于是对着下半平面再画一遍。

所以这条曲线是左右完全对称的、带一个尖点的封闭曲线，因为形状像一个心，得名心形线。

第二步：用对称性把积分砍一半

28:56全长当然是 θ 从 0 到 2π 积一遍。但上半支（0≤θ≤π）和下半支（π≤θ≤2π）形状一模一样，长度的贡献也一模一样，所以可以只算上半支再乘 2：

S=2∫0πρ2+ρ'2dθ
第三步：算 ρ2+ρ'2

ρ=a(1+cosθ)，ρ'=−asinθ。所以

ρ2+ρ'2=a2(1+cosθ)2+a2sin2θ=a2(1+2cosθ+cos2θ+sin2θ)

括号里 cos2θ+sin2θ=1，再和前面的 1 合成 2：

ρ2+ρ'2=a2(2+2cosθ)=2a2(1+cosθ)
第四步：拆根号、积分

再用一次倍角公式 1+cosθ=2cos2θ2，根号里就是 4a2cos2θ2，开方得 2a|cosθ2|。因为 θ∈[0,π] 时 θ2∈[0,π2]，cos 非负，绝对值可以直接去掉：

S=2∫0π2acosθ2dθ=4a[2sinθ2]0π

上限代入：4a⋅2sinπ2=8a；下限代入：4a⋅2sin0=0。所以

S=8a
两个坑

一、把全长写成 ∫0π。那是一半。心形线是封闭曲线，上下两支都要算；忘了乘 2，答案就少一半（写成 4a）。

二、ρ' 漏掉负号或者把它当成常数。ρ=a(1+cosθ) 里那个 a 是系数，ρ' 只对 θ 求导，得 −asinθ。写漏了负号，平方以后看不出来（负号的平方还是正），但如果不平方就代进去，结果会错得很离谱。

读一遍结果：心形线 ρ=a(1+cosθ) 的全长是 8a，摆线一拱的长度也是 8a。两条形状完全不同的曲线，弧长公式算出来是同一个数——这不是巧合，两者之间有可微分的几何联系，但对我们来说，更重要的是两遍计算都只做了同一件事：化简 ds，然后积分。

  • 摆线一拱 =8a；心形线 ρ=a(1+cosθ) 全长 =8a。
  • 极坐标公式的本质：「往外走」贡献 dρ，「绕圈走」贡献 ρdθ，两者垂直、平方相加。
  • 定积分的值只与积分区间和被积函数有关，与积分变量用什么字母无关。

三个坑

  1. 开方后忘绝对值。sin2u=|sinu|，能不能去掉绝对值，要看 u 的取值范围撑不撑腰。
  2. 只算一半。心形线这样的封闭曲线要乘 2（或从 0 积到 2π），写成 ∫0π 答案就少一半。
  3. 把 dx、dy 当成「随便的小量」。它们是微分，代换时 dx=x'dt 这一步不能省。
