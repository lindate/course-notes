P020求导公式

一句话核心

本节把「能直接拿来用」的求导公式一次讲清：先是最常用的四则运算求导（加减、乘积、商、常数提出），再由此推出三角函数的导数。乘积法则是「交叉相加」，商法则是「分母平方、分子交叉相减」——谁减谁、减号方向是最容易翻车的地方。文末把16 条基本初等函数求导公式汇成一张总表，并给出「负号跟着『余』走」的统一记忆法。

第一组公式卡：四则运算求导法则

00:00这一组是做题时用得最多的公式。先提醒一句：下面式子里的 u,v 写的虽然是字母，但它们都不是常数，而是函数——因为习惯就这么写，简单。四则运算一共四种，前两个你永远错不了，后两个才是重灾区。

法则公式适用条件记忆口诀
加减 (u±v)'=u'±v' 无额外条件 先加（减）后求 = 先求再加减
乘积 (uv)'=u'v+uv' u,v 都可导 交叉相加：谁求导谁不动
商 (u/v)'=u'v−uv'v2 v≠0 且可导 分母平方、分子交叉相减
常数因子 (Cu)'=Cu' C 是常数 常数直接朝外提
乘积法则 · 本课最容易错的一个

00:47很多同学看到相乘，想都不想就「先求导再相乘」——这是严重错误。相乘求导是交叉相加：

(uv)'=u'v+uv'

用老师原话验证：求 xsinx，按法则是「x 求导、sinx 不动，加上 x 不动、sinx 求导」：

(xsinx)'=(x)'sinx+x(sinx)'=sinx+xcosx
商法则 · 减号方向是生死线

01:52相除求导比相乘还难记，因为分子里是个减号：

(uv)'=u'v−uv'v2

老师特别强调：「它先是分母的平方，分子是『前导后不导 减 后导前不导』」。谁减谁区别老大了——记反了符号就全反。口诀：分母平方，上导乘下，减下导乘上。

03:59常数因子为什么能直接提出去

(Cu)'=Cu' 看起来理所当然，但它成立的前提是 C 真是常数。课本后面补的这条公式，比如求 (2sinx)'，把 2 提出去得 2cosx。它和乘积法则其实是一回事：把 C 看成「永远不变的函数」，那 C'=0，乘积法则 (Cu)'=C'u+u'C=0+u'C=Cu' 立刻退化成它。所以常数提出去 = 乘积法则在「其中一个因子恒定不变」时的特例。

证明：只证一个，其余不用看

04:39老师明确说：四则运算这四条的证明都不用看，书上其他证明做题也基本用不到。不过他还是当场证了最简单的加减法，让我们看看「用定义怎么证」的套路：

  1. 把 u(x)+v(x) 整体当成一个函数，写出它在 x 处导数的定义：
    (u(x)+v(x))'=limΔx→0[u(x+Δx)+v(x+Δx)]−[u(x)+v(x)]Δx
  2. 把分子重新分组：含 u 的变化量归一堆、含 v 的变化量归一堆。
  3. 拆成两个极限：
    limΔx→0u(x+Δx)−u(x)Δx+limΔx→0v(x+Δx)−v(x)Δx=u'(x)+v'(x)

06:50推广到三个函数也照猫画虎：相加就分别求导；三个相乘则是「每个轮流求导、其余两个不动，再加起来」：

(uvw)'=u'vw+uv'w+uvw'

例06:50设 y=xexsinx（三个因子相乘），求 y'。

思路：三个因子，展开成三项

把 x、ex、sinx 依次看作 u,v,w。三个相乘的规则是每一项只让一个因子求导、另外两个原样不动，三项相加：

y'=(x)'exsinx+x(ex)'sinx+xex(sinx)'

逐项算：(x)'=1，(ex)'=ex，(sinx)'=cosx，代进去得

y'=exsinx+xexsinx+xexcosx

把公因子 ex 提出来整理：

y'=ex[(1+x)sinx+xcosx]
三项，不是两项

按乘积法则只写两项。(uv)' 是两项，而 (uvw)' 是三项——几个因子就几项。漏一项是这类题最典型的丢分点。记法像「击鼓传花」：求导的记号依次落到每个因子头上，轮到谁就只有谁变，其余两个一动不动。

08:01还有一个巧妙视角：商也能写成乘积——uv=u⋅1v。于是用乘积法则再配合「1v 看成复合函数」也能推出商法则。这里会提前碰到一点点复合函数（下节课才正式讲），但思路是通的：乘积法则是更底层的工具，商法则可由它推出。

第二组公式卡：基本初等函数求导（前面已学，本课用到）

四则运算要「套」在具体函数上，所以这些最基础的求导结果也必须熟。幂、指、对三类是前面已经学过的，这里整理成卡，并标注适用条件：

类型公式适用条件
幂函数(xa)'=axa−1按 xa 的定义域（如 a=1/3 时全体实数）
指数(ex)'=ex,(ax)'=axlnaa>0,a≠1
对数(lnx)'=1xx>0
对数（推广）(ln|x|)'=1xx≠0
三角（已知）(sinx)'=cosx,(cosx)'=−sinx全体实数
为什么对数要写成 ln|x|，绝对值有什么用

23:17课本和后续积分里出现的常常是 (ln|x|)'=1x 而不是 (lnx)'=1x，这个绝对值不是摆设：

  • lnx 只在 x>0 有定义，所以 (lnx)'=1x 也只在 x>0 成立。
  • 但 1x 在 x<0 也有定义。为了让导数公式在负的那一半也说得通，看 x<0 时：令 w=−x>0，则 ln|x|=ln(−x)，用复合求导
    ddxln(−x)=1−x⋅(−1)=1x
  • 于是 x>0 时 ln|x|=lnx 导数 1x；x<0 时 ln|x|=ln(−x) 导数也是 1x。合起来就是 (ln|x|)'=1x，对一切 x≠0 成立。

绝对值的意义一句话总结：它把公式的定义域从 x>0 扩到了 x≠0，和 1x 的定义域对齐。所以积分 ∫1xdx=ln|x|+C 才在正负两侧都正确——没有绝对值就会在 x<0 出错。

第三组公式卡：三角函数的导数（本课由商法则推出）

19:44sinx,cosx 的导数前面已经知道。其余四个三角函数都能写成 sin/cos 的商，用商法则当场推出来，所以必须会推、更要会记。

例 212:53设 f(x)=x3+4cosx−sinπ2，求 f'(x) 与 f'(π/2)。

思路：先符号求导，再代入数值；绝不要先代入

用加减法则，每一项分别求导：

f'(x)=(x3)'+(4cosx)'−(sinπ2)'=3x2−4sinx−0=3x2−4sinx

注意 sinπ2=1 是常数，常数求导为 0。要的是 f'(x) 这个表达式，不是先把 x 换成数。

现在代 x=π2：

f'(π2)=3(π2)2−4sinπ2=3π24−4
15:21大聪明错误：先代入再求导

有同学想：先算 f(π/2)，再对结果求导，省事。把 x=π/2 代进去得到的是一个具体的数（常数），常数的导数当然是 0。于是他写下 f'(π/2)=0。

错在哪？f'(π/2) 的意思是「先得到导数函数 f'(x)，再把 x=π/2 代进去」，不是「先把 x=π/2 代入函数得到常数，再求导」。后者求的是常数的导数，恒为 0，那所有这种题答案都该是 0——显然荒谬。口诀：先求导，再代值；千万别先代值再求导。

例 3：乘积法则练手

例 316:58设 y=ex(sinx+cosx)，求 y'。

思路：把整个括号当成一个因子，用乘积法则

这是「ex ×（一个和）」的形式，按 (uv)'=u'v+uv'：

y'=(ex)'(sinx+cosx)+ex(sinx+cosx)'

其中 (ex)'=ex，而 (sinx+cosx)'=cosx−sinx。代入：

y'=ex(sinx+cosx)+ex(cosx−sinx)

把 ex 提出来，sinx 与 −sinx 抵消，剩下

y'=ex(2cosx)=2excosx

关键观察：(sinx+cosx) 内部是相加，求导时各自求、再相加；乘积法则是作用在「ex 与这个整体」之间。一层一层不要乱。

例 4、例 5：用商法则推出三角导数

19:44这两道既是例题，也是把三角求导公式「推导一遍」——以后直接当结论用。

例 4：求 (tanx)'。把 tanx=sinxcosx 用商法则：

(tanx)'=(sinx)'cosx−sinx(cosx)'cos2x=cosxcosx−sinx(−sinx)cos2x=cos2x+sin2xcos2x=1cos2x

即

(tanx)'=sec2x

顺手把 cotx 也推一遍（套路一样，注意分子的减号方向）：

(cotx)'=(cosx)'sinx−cosx(sinx)'sin2x=−sin2x−cos2xsin2x=−1sin2x=−csc2x

最后一步用了 sin2x+cos2x=1，分子凑成 −1，外面落下一个负号——这就是 (cotx)'=−csc2x 的来源。它和 (tanx)'=sec2x 恰成一对：一个带正号，一个带负号。

21:30例 5：求 (secx)'。secx=1cosx，仍是商法则（分子是 1）：

(secx)'=(1)'cosx−1⋅(cosx)'cos2x=0−(−sinx)cos2x=sinxcos2x=sinxcosx⋅1cosx

即

(secx)'=secxtanx

再补 cscx=1sinx，仍是商法则（分子为 1）：

(cscx)'=(1)'sinx−1⋅(sinx)'sin2x=0−cosxsin2x=−cosxsinx⋅1sinx

即 (cscx)'=−cscxcotx（同样带负号）。

19:44视频原话（大意）

cos 分之一是个啥？是 sec，想起来了没有？sin 分之一就是 csc。sec 跟 csc 我们在高数里用得很多——包括 cot，我都不知道你们高中竟然没有学过 cot，真的。

老师特意叮嘱：别因为「高中没学过」就把 secx、cscx、cotx 跳过。这三个在高数里（尤其是后面的积分）出现得非常频繁，它们的导数必须像 sinx、cosx 一样熟练。

推导线索 · (arcsinx)' 是怎么来的

设 y=arcsinx，则 siny=x，其中 y∈[−π2,π2]。两边对 x 求导（左边把 y 看成 x 的函数，用链式法则）：

cosy⋅y'=1⟹y'=1cosy

再由 sin2y+cos2y=1 得 cosy=±1−x2。关键就在这个正负号：当 y∈(−π2,π2) 时 cosy>0，必须取正号。于是

(arcsinx)'=11−x2

arccosx 完全同理：令 y=arccosx，则 cosy=x，求导得 −siny⋅y'=1，即 y'=−1siny；而 y∈(0,π) 时 siny>0，故 siny=1−x2，于是 (arccosx)'=−11−x2——和 arcsin 只差一个负号。

最容易记混的几对，和「负号」的统一解释

总表里最容易翻车的，是四对「长得几乎一样、只差一个负号或一个函数名」的公式。先并排看清差别，再给一个一次性记住所有负号的理由。

容易混的一对两条公式差在哪
arcsin 与 arccos 11−x2　与　−11−x2 只差一个负号；根号内是 1−x2（不是 x2−1）
arctan 与 arccot 11+x2　与　−11+x2 只差一个负号；分母是 1+x2，且没有根号
tan 与 cot sec2x　与　−csc2x 负号 + 函数名换成它的「余」兄弟
sec 与 csc secxtanx　与　−cscxcotx 负号 + 函数名整体换成「余」兄弟
「余」字辈为什么统统带负号

回头看上面四对：带负号的永远是「余」字辈——余弦 cos、余切 cot、余割 csc、反余弦 arccos、反余切 arccot；不带负号的是 sin,tan,sec,arcsin,arctan。这绝不是巧合。

「余」对应的英文前缀是 co-，本义是 complementary（余角）。每个余函数都能写成原函数「反着来」的样子：

cosx=sin(π2−x),cotx=tan(π2−x),cscx=sec(π2−x)

右边是复合函数，内层 π2−x 的导数是 −1，用链式法则时必然多出一个 −1。反三角那边同理，全是「常数减一个不带负号的函数」：

arccosx=π2−arcsinx,arccotx=π2−arctanx

求导时那个常数求导为 0，剩下的正好是被减函数的导数取反。所以口诀只有六个字：负号跟着「余」走。把 sin,tan,sec,arcsin,arctan 五条正的记牢，其余全靠「加负号」补齐——一次搞定，不会再记反。

23:17记忆策略

六个三角导数里，tanx 与 secx 前面是正号，cotx 与 cscx 前面是负号——成对记。sinx→cosx（正）、cosx→−sinx（负）是底座。上面那张十六行总表就是这个套路的完整版，现在先分组成卡记牢即可。

记忆入口 · 一眼回忆

四则运算（最常用）

  • (u±v)'=u'±v'
  • (uv)'=u'v+uv'（交叉相加，别写成先求再乘）
  • (u/v)'=(u'v−uv')/v2（分母平方，分子交叉相减）
  • (Cu)'=Cu'（C 是常数，直接提）
  • (uvw)'=u'vw+uv'w+uvw'（三个因子就三项）

三角求导（成对记正负）

  • (sinx)'=cosx，(cosx)'=−sinx
  • (tanx)'=sec2x(正)，(cotx)'=−csc2x(负)
  • (secx)'=secxtanx(正)，(cscx)'=−cscxcotx(负)

十六条的来路（一张网）

  • 由定义：C'、xμ、ax、ex、logax、lnx、sinx、cosx
  • 由商法则：tan、cot、sec、csc
  • 由反函数求导：arcsin、arccos、arctan、arccot（下一节）

一条万能口诀

负号跟着「余」走：cos,cot,csc,arccos,arccot 全带负号；sin,tan,sec,arcsin,arctan 全不带。

对数别忘了绝对值

(lnx)'=1x(x>0)；更完整地写成 (ln|x|)'=1x(x≠0)，绝对值把定义域扩到正负两侧，和积分 ∫1xdx=ln|x|+C 对齐。

三个坑

  • 乘积别写成「先求导再相乘」；商法则减号方向记反整题错。
  • 先求导再代值，绝不能先代值再求导（那会得到常数、导数恒为 0）。
  • 三个因子相乘是三项，不是两项。
