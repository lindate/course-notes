P061微分方程的基本概念：未知的是一个函数，不是一个数

一句话核心

从小学到现在，解方程都是「求一个数」；从这一讲起，要求的变成一条函数。定义只有一句话——含有未知函数的导数或微分的方程。真正要弄透的只有三件事：阶（看最高阶导数求了几次，别把「平方」当「阶」）、通解（任意常数个数恰好等于阶数）、特解（初始条件把常数定死）。

以前解方程求一个数，现在求一条函数

这一章叫「微分方程」，第一件事当然是回答「什么叫微分方程」。定义给得很短：

定义 · 微分方程

含有未知函数的导数或者微分的方程，叫做微分方程。

把定义拆成三个关键词：未知函数（我们习惯写成 y，它是待解的东西）、导数（y'、y'' 之类）、微分（dy、dx）。只要方程里出现这三样里的任意一样，它就是微分方程。

01:21老师当场举了两个例子。第一个是

y'+y+x=0

里面有未知函数 y，也有它的导数 y'，所以是微分方程。第二个是

xdy=ydx

这个式子里没有出现「y'」这个记号，但 dx、dy 都是微分，照样是微分方程。

为什么「微分方程」这四个字是全新的东西

你从小学到高中解过的方程，长这样：2x+3=7，求 x；x2−5x+6=0，求 x。这些方程里出现的都是数，答案是一个数或者几个数。

而 y'+y+x=0 里出现的是 y'，也就是 dydx——它是「y 变化得多快」的度量。要给这个方程找出 y，你交付的不是一个数，而是一整条函数，甚至是一整个函数族。这就是为什么它叫「微分」方程：方程里跑进了微分，答案是函数。

换句话说：以前是「找一个数」，现在是「找一条曲线」。这就是本章所有麻烦的来源，也是它所有意思的来源。

先弄清一件事：dydx 可以拆开

这一条看起来像语文题，其实是本页唯一的技术准备。

讲导数的时候，老师特意强调过：dydx 里的 dy 和 dx 不能分开来理解，它是一个一体的符号，整体表示「y 对 x 求导」。那时候这样说是为了防你把它当成「dy 除以 dx」去做四则运算。

但讲微分的时候，y 的微分写成 dy=f'(x)dx，这个式子本来就是把 dx 乘过来得到的。同一个 dydx，在微分这个视角下就变成了「两个微分各占一边」。

到了参数方程求导，还有第三种说法：设 x、y 都是 t 的参数方程，那么

dydx=dy/dtdx/dt

这里那两个「dt」就像分子分母同时除以一个数一样被约掉了。

所以在微分方程这一章，请接受这个事实：dy 和 dx 既可以看作一个整体，也可以在做题的过程中把它们分开、挪位置、乘过来。后面整章都要这么干。

立刻用它做一道最简单的题。设 y'=x，也就是

dydx=x

把 dx 乘过去：dy=xdx。两边同时求不定积分：左边 ∫dy=y，右边 ∫xdx=12x2，再加上常数：

y=12x2+C

注意这个 C 是凭空冒出来的——它来自「不定积分要加任意常数」这条规矩。这个 C 在后面的每一页都会出现，而且会变成最让人头疼的角色。

方程里能出现什么？常微分和偏微分

有同学不放心，一路追问：含一阶导数的可以，那含二阶、三阶导数的呢？含 x 的呢？含 sinx 的呢？含 y 甚至含 y 的函数的呢？老师的答案是连着六个「能」：

方程里出现的东西算不算微分方程说明
y'、y''、y'''……算高阶导数当然可以，这就是它的「阶」的来源
x、x3、ex算x 是自变量，随便怎么出现都行
sinx、lnx算x 的函数都可以摆在方程里
y、y2、ey、siny算y 是未知函数，含 y 的函数当然也可以
dx、dy算含微分同样算，例如 xdy=ydx

再往下分一类，看未知函数是几元的：

  • 常微分方程——未知函数是一元函数。也就是 y 只和 x 有关，y=y(x)。这类方程我们这门课要一路解下去。
  • 偏微分方程——未知函数是多元函数。比如 z 既和 x 有关也和 y 有关，方程里就会出现偏导数。老师举的例子是 yz'x−xz'y=0，里面既有对 x 的偏导，也有对 y 的偏导。

这部分老师明确说了：大家不用担心，你能把这个常微分方程、这种一元函数的整明白了就不错了。偏微分方程这门课不解，顶多在判断题或选择题里出现一个名字，知道有这个分类就行。

阶：看的是「求了几次导」，不是「几次方」

定义 · 微分方程的阶

微分方程中出现的未知函数的导数的最高阶数，叫做这个微分方程的阶。

老师顺手做了个词源上的对照：线性代数里说「三阶行列式、四阶行列式」，英文是 order three、order four，这个 order 就是「阶」；微分方程的阶也是 order。

按字面理解很简单：出现 y'（或者 dydx）就是一阶；出现 y''（或者 d2ydx2）就是二阶；出现 y''' 就是三阶。但老师立刻加了一句：这个地方没有你想的那么简单。

他连问了六七种情形，每一种都有同学答错。把它们摆成一张表最快：

方程里出现的式子它是一阶还是二阶？为什么
y都不是（零阶）没有导数
y2不是二阶y 根本没求导。它是「y 的二次」，不是「二阶」——次数 ≠ 阶数
y'一阶求了一次导
(y')2 或 y'y还是一阶平方、相乘只是「怎么组合」，最高只求了一次导
y''二阶求了两次导
(y'')2 或 y''y'还是二阶最高求了两次导，平方与相乘不改变阶
y''y'二阶看着像能约掉，但 y'' 与 y' 是两个不同的函数，约不了
y''+ey二阶ey 里的 y 没求导，与阶数无关，根本不用管它
为什么「阶」必须盯着导数，而不是盯着次数

因为阶这个数字不为难你，它是为「答案里有几个未知常数」服务的。

想一下你解方程要做的动作：解一次方程，本质上就是「求一次不定积分」。做一次不定积分，就冒出来一个任意常数 C。所以——

  • 一阶方程，解的过程中要积一次分，答案里有 1 个任意常数；
  • 二阶方程，要积两次分，答案里有 2 个任意常数；
  • n 阶方程，要积 n 次分，答案里有 n 个任意常数。

而「要积几次分」完全由「最高阶导数是几阶」决定：方程里最高出现的是 y''，就得把求导这件事倒推两次，也就是积两次分。跟 y 有没有平方、跟 ey 一点关系都没有——因为 y 本身不是靠积分求出来的，y'' 才是。

所以「阶」是一根指针，它指向「通解里该有几个常数」。记住这个动机，表里那七行就不需要死记了。

线性还是非线性：x 一律当常数

这是一个在微分方程里才出现的用法，和线性代数里的「线性」不完全一样，极易混淆。老师先花了一大段时间复习线代那一侧的用法，再作对比。

线代里的线性：只有「系数乘变量再相加」这一种形式

线性代数里讲得比较简单：2x1+3x2−x3 是关于 x1,x2,x3 的一个线性表达式；2x+3y 也是。标准形式是

k1x1+k2x2+⋯+knxn

也就是变量前面乘上系数，然后相加（相减也行，让系数变负就成），只有这一种形式叫线性。据此判断：

  • x1x2 不是线性——变量相乘了。
  • sinx⋅cosy 不是线性——出来了三角函数。
  • x2+2x 不是线性——有平方。
  • 2x+3y−16z 是线性。
  • y=3x−6 是线性——它本来就是一条直线。
  • ex 不是线性。

微分方程里的线性：只看 y 和它的各阶导数

定义 · 线性微分方程

把方程里出现的 y、y'、y''、y'''……只看它们之间是不是线性关系。是，就叫线性微分方程；不是，就叫非线性微分方程。

判断时有一条特别的规定：x 一律看作常数。任何只含 x 的表达式（x、x3、ex、sinx……）都只是「系数」，不影响线性与否。

20:46老师讲这一步时把理由说得非常清楚：我们这里指的是 y、y'、y''……与 y 的导数成线性关系，这里边没有说 x 的事。所以在微分方程判断线性关系的时候，x 看作是个常数。

方程线性？判断依据
y''+y'+y=0线性y''、y'、y 都只出现一次方，且是相加
12y'+6y=0线性同上，系数是 12 和 6，不改变性质
y'y=0非线性y' 与 y 相乘了，这是二次项
y'+2y=1非线性y 跑到了指数上，2y 不是 y 的一次式
xy'+2=0线性x 只是 y' 的系数，当作常数；y' 与常数相加，线性
y'+exy+x3=0线性ex 和 x3 都不含未知函数，统统当常数
最容易判错的三处

一、看到 ex 或者 x3 就判非线性。错。它们里面没有未知函数，只是系数。要警惕的是 ey 或 2y 或 xy 这种——未知函数进了指数。

二、看到 xy' 就判非线性。错。x 当常数，xy' 就相当于「常数乘 y'」，正是线性表达式允许的样子。

三、把线性代数的判据直接搬过来。线代里 xy 是非线性，这里 xy' 却是线性——区别不在「有没有相乘」，而在相乘的双方是谁：只含 x 的东西一律当系数，未知函数之间相乘才叫非线性。

解、通解、特解、初始条件

接下来四个词，是这一讲的落脚点。

解
把一个函数代入微分方程，如果方程恒成立，这个函数就叫方程的一个解。验证为主，概念上没什么可琢磨的。
通解
首先它得是解；其次，这个解里含任意常数，而且任意常数的个数恰好等于微分方程的阶数。两个条件都满足，才叫通解。
初始条件
题目额外给出的「在某个特殊点处的值」，比如 x=0 时 y=1、x=1 时 y'=2。这类条件统称初始条件。
特解
把初始条件代入通解、把里面的任意常数都解出具体数值之后得到的那个解，就叫特解。特解里不含任何任意常数。

先用两个最简单的例子把「通解」的含义落地。

  1. 一阶：y'=ex。谁求导等于 ex？ex 求导还是 ex。但别忘了不定积分要加常数，所以
    y=ex+C
    这是一阶方程，通解里正好有 1 个任意常数 C。
  2. 二阶：y''=ex。两边同时求一次不定积分，得到 y'=ex+C1；再求一次不定积分，得到
    y=ex+C1x+C2
    注意第二项：∫C1dx=C1x，这里的 x 是从「对 1 求原函数」来的；而末尾那个 C2 是第二次积分新添的常数。这是二阶方程，通解里正好有 2 个任意常数。
「几个任意常数」和「几个初始条件」是一回事

上面两个例子已经把规律摆出来了：n 阶方程要积 n 次分，每次积分贡献一个任意常数，所以通解里恰好有 n 个任意常数。

反过来想这件事更有用：通解里有 n 个待定的常数，所以需要 n 个条件才能把它们全部定下来。而一阶导数 y' 在 x0 处的值本身就是一个条件（它管着常数 C1），y 在 x0 处的值又是一个条件（它管着 C2）。这就是为什么——

  • 一阶方程只需要一个初始条件（比如 y(0)=1）；
  • 二阶方程需要两个初始条件（比如 y(0)=1 且 y'(0)=2）；
  • n 阶方程需要 n 个初始条件。

考试里给错个数的初始条件，方程就定不出唯一解——这不是巧合，是被「常数个数 = 阶数」这条规矩掐死的。

把 y=ex+C1x+C2 的常数定下来做一遍。题目给两组条件：x=0 时 y=1，x=1 时 y=2。

  1. 代第一组。x=0 时 e0=1、C1x=0，所以 1=1+C2，得 C2=0。
  2. 代第二组。x=1 时 y=e+C1⋅1+0=2，得 C1=2−e。
  3. 回代。把 C1、C2 的具体值写回通解，得到
    y=ex+(2−e)x
    这就是特解——里面已经没有任意常数了。

30:27老师的总结是：把初始条件代入通解以后，把那个任意的常数都给他解出来了，这时候就得到了一个特解。另外他特别提醒了条件给法：题目会「特别明确」地写清「x 等于几时 y 等于几」，你只管照着代。

例题：验证一个解，再定出特解

例27:53已知 y=C1x+C2x2。（1）验证它是 y''−2xy'+2x2y=0 的解，并说明是通解还是特解；（2）若再给 y(1)=0、y'(1)=1，求特解。

思路：验证解的动作只有一个——求导、代入、看是不是恒等于零

这类题没有技巧，就是把 y、y'、y'' 全算出来，代进方程左端，看它能不
能化简成 0。

第一步：先求两阶导数

y=C1x+C2x2 对 x 求导（C1、C2 都是常数，求导时按系数处理）：

y'=C1+2C2x

再求一次：C1 是常数，求导得 0；2C2x 求导得 2C2。所以

y''=2C2
第二步：代入方程左端
y''−2xy'+2x2y=2C2−2x(C1+2C2x)+2x2(C1x+C2x2)

逐项展开：第二项是 −2C1x−4C2；第三项里 2x2⋅C1x=2C1x，2x2⋅C2x2=2C2。三类项排在一起：

(2C2−4C2+2C2)+(−2C1x+2C1x)=0+0=0

恒等于零，所以它确实是解。

第三步：判断是通解还是特解

看两件事：方程是几阶的？y'' 出现了，是二阶。解里有几个任意常数？C1、C2，两个。个数正好对上，所以它是通解。

这里最容易含糊的一步

只要「含 C1、C2」就说是通解。表述不严谨。通解的定义里有两个条件：是解 且 任意常数的个数等于阶数。严格做题时应该把两个数字都写出来——「方程是二阶的，解中含两个任意常数，二者一致，故为通解」。

另外，两个常数必须真的「独立」：C1x 与 C2x2 是两个不同的函数，把常数写在一起也拼不出对方，所以它们确实是两个独立的任意常数。如果解写成 Cx+Cx，那实际只有 1 个常数，就不是二阶方程的通解了。

第四步：用初始条件定常数

把 y(1)=0 代入 y=C1x+C2x2：C1+C2=0。

把 y'(1)=1 代入 y'=C1+2C2x：C1+2C2=1。

两式相减，C1 消掉，得 C2=1；再回代得 C1=−1。于是

y=−x+x2(即 y=x2−x)

验一下：x=1 时 y=1−1=0 ✓；y'=2x−1，x=1 时 y'=1 ✓。这就是满足两个初始条件的特解。

要点：这道题把四个概念一次串起来——先验证「是解」，再数常数个数对上级数得「通解」，最后用两个初始条件换到「特解」。整套流程是本章所有解方程题目的收尾动作。

记忆入口 · 一眼回忆

一句话

微分方程 = 含有未知函数的导数或微分的方程。以前求一个数，现在求一条函数。

四个关键词

阶
未知函数的导数的最高阶数。看「求了几次导」，不看几次方——y2 不是二阶，y'2 是一阶
线性
y,y',y'' 之间只许一次相加；x、ex、x3 全当常数；y'y、2y 是非线性
通解
是解，且任意常数个数 = 阶数（两个条件都要满足）
特解
把初始条件代入通解、常数全解出来之后的解，不含任意常数

一条链

阶数 n 看最高阶导数→ 积 n 次分 得 n 个常数→ 通解 含 n 个任意常数→ n 个初始条件 定死常数→ 特解

要背的

  • y'=ex 的通解是 y=ex+C（1 个常数）；y''=ex 的通解是 y=ex+C1x+C2（2 个常数）。
  • dydx 在微分方程里可以拆开：把 dx 乘过去是合法动作。
  • 常微分方程（一元）vs 偏微分方程（多元、含偏导数）——考试多半只考一个名字。

三个坑

  1. 把次数当阶数。y2 是「y 的二次」，不是「二阶」；这个坑老师连问了六遍。
  2. 判线性时把 x 也算进去。xy'+2=0 是线性的，因为 x 只是系数。
  3. 初始条件个数给错。二阶方程必须两个条件，只给一个定不出特解。
