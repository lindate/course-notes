P049定积分的换元法（上）

一句话核心

定积分的换元法和不定积分很像，但多了一条自己的规矩：变量换成 t 以后，积分限也必须跟着换成 t 的范围——口诀是换元必换限。换来换去之后还有一件好事：定积分算完直接就得数，不用回代。这一页把「限怎么对应」和「为什么不用回代」两件事讲透。

一、定积分为何也离不开换元

00:00上一页我们有了牛顿–莱布尼兹公式：求定积分＝求原函数 + 代上下限。可「求原函数」这件事本身就不轻松——很多被积函数必须靠换元才能积出来。于是问题来了：换元这套办法能不能搬到定积分里？答案是能，但搬过来以后要多一条规矩。

老师开头就说得很实在：定积分的换元法与不定积分的第一换元、第二换元有类似的地方，但它也有一些比较独特的点。这一页的重点就是把这些「独特之处」分辨清楚——哪一步能照搬，哪一步必须多做一个动作。

二、定理：换了元，就必须换限

定积分的换元公式

设 f(x) 在 [a,b] 上连续，函数 x=φ(t) 满足：

  1. φ(α)=a，φ(β)=b；
  2. φ(t) 在 α 与 β 之间（或 β 与 α 之间）具有连续的导数，且其值域不超过 [a,b]。

则

∫abf(x)dx=∫αβf(φ(t))φ'(t)dt

00:52把公式拆开读，它其实只做了两件事。第一，把被积函数里的 x 全部换成 φ(t)——这一步和不定积分完全一样。第二，把 dx 换成 φ'(t)dt——因为 dx 里那个「求微分」的动作作用在 φ(t) 上，结果就是 φ'(t)dt。

02:23但公式里还有第三处变化，也是全页最容易漏的一处：积分限从 a,b 变成了 α,β。老师把它总结成一句口诀——换元必换限，并在课上反复强调：「换了元，结果上下线也不换，这是不对的。」

为什么非换不可——从「积分限是什么」说起

很多同学把换限看作「做题的一步手续」，所以总觉得它是个可有可无的仪式。要打消这个念头，只需问一句：积分限到底在说什么？

答案是：积分限是「积分变量」的取值范围。∫abf(x)dx 里的 a,b 描述的是 x 从哪儿走到哪儿；一旦变量换成了 t，这个「从 a 到 b」就失去了意义——t 根本不会走到 a 和 b 去，它走的是 α 到 β。硬把 a,b 留在那里，等于让 t 去取一组它压根不属于的端点值，算出来的数自然不是原来的积分。

换个比方：把「从北京到上海的距离」改成用「经度」来度量，那么端点就不能再写「北京、上海」，得改写成两地的经度。变量换了，描述这个变量范围的数就得跟着换——这就是换限的全部道理。

02:23一个必须养成的动作

写完换元式，直接往下算，忘了改上下限。流程上应该这样做：一旦写下 x=φ(t)，立刻在旁边算两个数——t 取什么值时 x=a，t 取什么值时 x=b。这两个数就是新的下限和上限。先算限、再动笔积分，顺序错了就容易漏。

三、上下限怎么对应：两种记法，一个坑

对应关系本身很直白：x 取 a 时 t 取 α，x 取 b 时 t 取 β；下限对下限、上限对上限。可一旦 φ 是递减的，对应出来的两个数就会「小的在后、大的在前」，这时候写区间就麻烦了。

06:29老师用两个例子把这件事讲透了。

换元原来的限t 的对应值写成积分限顺序
x=−t x 从 1 到 2 t 从 −1 到 −2 ∫−2−1 反过来了
x=t2 x 从 1 到 2 t 从 2 到 4 ∫24 不变

09:55第一行为什么要写成 ∫−2−1 而不是 ∫−1−2？因为数学上写区间要「小的在前、大的在后」，所以 −2 是下限、−1 是上限。老师讲到这里特意模仿了同学的困惑：「老师你不就从 −1 到 −2 吗，那你写呗——这就不对了。」

35:39老师推荐的一种写法

书上都写「当 x=0 时 t=1，当 x=4 时 t=3」，两头的数字挤在一起，读起来费劲。老师更喜欢写成

x从0到4,t从1到3

他说这种写法「绝对不会搞错」，因为谁是下限、谁是上限一眼就能对上。他同时承认这种写法在数学上并不是严格的映射记号，但考试写它绝不会被扣分，因为它清楚表达了定积分的上下限。同学们可以任选一种，但一定要把自己的写法固定下来。

38:14最容易犯的直觉错误

默认「下限一定小、上限一定大」，于是把 −2 和 −1 顺手调个位置。定积分的上下限本来就不要求谁大谁小——这一点在讲定积分性质时就说过：交换上下限，积分值变号。所以 ∫−1−2 和 ∫−2−1 是两个互为相反数的积分，写反了结果差一个负号。

老师举的例子更极端：若换元是 x=−t2，x 从 −1 到 1 时 t 从 12 走到 −12。此时下限就是 12，上限是 −12——下限比上限大，这是完全正常的。

四、定理的第二条条件：为什么会有「或」

03:38定理的第二条读起来别扭：「φ(t) 在 α 到 β 或 β 到 α 上具有连续导数」。很多同学会问：为什么要整两个方向？

那个「或」字到底在说什么

06:01它其实在照顾两种相反的换元。看上面那两个例子：

  • 当 x=t2 时，x 从 1 到 2 对应 t 从 2 到 4，α=2<β=4，t 的活动区间是 [2,4]——顺着走，所以条件是「α 到 β」。
  • 当 x=−t 时，x 从 1 到 2 对应 t 从 −1 到 −2，本来想说 t∈[−1,−2]，但这个区间写不出来（小的得在前），实际活动区间是 [−2,−1]——从 β 到 α。所以条件得补上这个方向。

至于「值域不超过 [a,b]」这一条，老师说理解起来没什么难度：既然 x=φ(t) 把 t 映成 x，而 x 本来就在 [a,b] 里取值，那么 φ 能取到的所有值自然也落在 [a,b] 里——换句话说，φ 的值域就是原来 x 的范围。要求 φ' 连续，是为了保证换元之后的被积函数仍是「正常的」连续函数，牛顿–莱布尼兹公式还能继续用。

为什么不理解这条也不影响做题？因为它只影响我们在什么情况下「可以用」这个公式，而实际遇到的题目里，x=φ(t) 基本都是光滑的初等函数，条件自动满足。真正需要动手判断的只有一件事——把 t 的范围算准。

五、例题

例 111:09求 ∫0aa2−x2dx（a>0）。

思路：先用几何含义看清答案，再用三角代换走一遍正规流程

11:53老师的原话是：「如果这个题真让你做，你千万不要傻傻地跟书上一个做法……谁傻乎乎地真用换元去做呀。」他的意思是：先看图形。

令 y=a2−x2，两边平方得 x2+y2=a2——这是一个半径为 a 的圆，而 y=a2−x2 取的是上半圆。积分区间 x 从 0 到 a，正好是上半圆的右半边。于是这块面积是四分之一个圆：

∫0aa2−x2dx=14πa2=πa24

两步就出答案，一分钱力气都不费。

13:23现在按正规流程走一遍，看看换元是怎么做的。目的是把根号消掉，所以令 x=asint。先做两件准备工作：

  • 微分：dx=acostdt。
  • 换限：x=0 时要 sint=0，取 t=0；x=a 时要 sint=1，取 t=π2。所以 t 从 0 到 π2。

代入：a2−x2=a2−a2sin2t=acos2t=a|cost|。因为 t∈[0,π2]，cost≥0，所以绝对值可以直接去掉，等于 acost。于是

∫0aa2−x2dx=∫0π/2acost⋅acostdt=a2∫0π/2cos2tdt

17:38用二倍角公式 cos2t=1+cos2t2：

=a2[t2+sin2t4]0π/2=a2(π4+0)−0=πa24

与几何做法完全一致。

这一步最容易错

开根号时忘了取绝对值。cos2t 严格等于 |cost|，不是 cost。这道题侥幸对了，是因为 t∈[0,π2] 上 cost 非负；如果 t 的范围让 cost 变号，不讨论符号就要出错。凡是开偶次方，先问一句「里面的量在这段区间上是什么符号」。

忘记 t 的范围不是唯一的。14:37老师特意指出：要 sint 从 0 走到 1，t 可以取 [0,π2]，也可以取 [2π,5π2]——都能实现。但既然都行，当然取最简单的那个。不过「可以挑」不等于「可以乱挑」：t 的范围是由 x 的范围和 x=φ(t) 这个函数共同确定的，只是在这个约束下可能有多种选法。

例 219:43求 ∫0π/2cos5xsinxdx。

思路：这是第一换元（凑微分），可以完全不做换限

20:33最省事的做法是直接凑微分：sinxdx=−d(cosx)，而 cosx 正好是整体的幂底。所以

∫0π/2cos5xsinxdx=−[cos6x6]0π/2=−06+16=16

代上下限：cosπ2=0 给出 0，cos0=1 给出 16，相减即 16。注意这里并没有换限——因为我们只是「把 sinxdx 凑成了一个微分」，变量仍然叫 x，上下限自然不用动。

22:05书上用的是换元写法。既然要让 cosx 变成新的积分变量，就设 t=cosx，那么 dt=−sinxdx，即 sinxdx=−dt。换限：x=0 时 t=cos0=1；x=π2 时 t=cosπ2=0。所以 t从 1 到 0。于是

∫0π/2cos5xsinxdx=∫10t5(−dt)=∫01t5dt=[t66]01=16

中间那个负号与「交换上下限产生的负号」正好抵消，所以最后写成了干净的 ∫01t5dt。两种做法答案一致。

这种题真正的坑：换限时忘了「1 在前、0 在后」

初学时最容易把 ∫10 顺手写成 ∫01、又把那个负号也省掉，结果凭空多一个负号或者少一个。安全做法是老老实实写 ∫10t5(−dt)，再让两个负号自己抵消，一步都不要跳。

24:28书上那一步为什么「有歧义」——d(cosx) 的积分变量到底是谁

很多书会这样写：

∫0π/2cos5xsinxdx=∫0π/2cos5xd(cosx)

看着挺顺，可老师指出这一步「多多少少是有点歧义的」。原因在于那个 ∫0π/2 上的 0 和 π2——它们是谁的范围？

  • 如果积分变量是 x，那么范围是 0 到 π2，没问题。
  • 如果积分变量是 cosx（毕竟它被微分了、看起来像新变量），那么 x=0 对应 cosx=1，x=π2 对应 cosx=0，范围应该是从 1 到 0。

写成同一串数字，读者根本分不清指的是哪一个。老师说得直白：「这个 d(cosx) 里的积分变量到底是 x 还是 cosx，你能说清楚吗？」

严格的写法只有一种：既然要换变量，就把新变量命名为 t，写成 t=cosx，把限一起换成 ∫10t5(−dt)。这样每一步的角色都是清楚的。

那为什么我们还常常直接写 ∫0π/2cos5xd(cosx) 就往下算？因为这是第一换元（凑微分）：凑微分并没有真正引入新变量，那个「整体」最终还是 x 的函数，积分限仍然是 x 的范围，所以算完可以直接代 0 和 π2。老师最后给的实用建议是：理解这层歧义，但做题时不必因此改写成换元——把 cosx 当作一个整体直接求原函数就行。

例 328:20求 ∫011−x2⋅2xdx。

思路：也走凑微分。看到 2x 就想到它和 x2 只差一个符号

把「除符号外与 x2 有关」的部分凑进微分里：2xdx=d(x2)=−d(1−x2)，前面补一个负号：

∫011−x2⋅2xdx=−∫011−x2d(1−x2)

现在 1−x2 作为一个整体，指数是 12，求原函数就「加一次、配系数」：

=−[23(1−x2)3/2]01=−23(0−1)=23

29:44同例 2 一样，这里上下限没有换——0 和 1 始终是 x 的范围。老师再三强调的正是这一点：「这个 0 到 1 其实是 x 的取值范围，它不是 1−x2 的取值范围。」凑微分的方便之处就在这里：你可以完全不做换限这件事，代价是必须把「整体」认清楚。

例 430:29求 ∫0πsin3x−sin5xdx。

思路：先提公因式化简根号，再处理开出来的绝对值

30:29根号里两项都含 sin 的幂次，先提一个 sin3x 出来：

sin3x−sin5x=sin3x(1−sin2x)=sin3xcos2x

于是

sin3x−sin5x=|sin3/2xcosx|=sin3/2x|cosx|

其中 sin3/2x 在 [0,π] 上非负，绝对值可以省；但 |cosx| 必须留着——因为在 [0,π] 上 cosx 有正有负：[0,π2] 上为正，[π2,π] 上为负。

32:43去绝对值的唯一办法是分段：

∫0π=∫0π/2sin3/2xcosxdx−∫π/2πsin3/2xcosxdx

两段都用凑微分：cosxdx=d(sinx)，被积函数变成 sin3/2xd(sinx)，原函数是 25sin5/2x。所以

=[25sin5/2x]0π/2−[25sin5/2x]π/2π=25−(0−25)=45
33:21老师点名的「低级错误」

看到两个积分长得一模一样就相减得 0。老师原话是「这俩是不是一样的呀，那减号一减是不是就是零啊——不对啊」。两段积分的被积函数确实一样，但它们的积分区间不同，值也不同：一段是 25，另一段是 −25，相减得 45，不是 0。

这个错误之所以常见，是因为中间那个减号是「去绝对值」带出来的，容易被当成「同样的东西相消」。看到减号先问一句：两边减的是同一个积分吗？区间一样吗？

例 535:39求 ∫04x+22x+1dx。

思路：这是第二换元的典型——重点在「把准备工作写全」

35:39老师称它是「一个非常典型的换元的定积分题目」。目的还是消根号，所以令

t=2x+1⟹x=t2−12

36:54准备工作有三项，必须都写出来（考试都算分）：

  1. 求 dx。由 x=12(t2−1) 得 dx=12⋅2tdt=tdt。这一步最容易漏——漏了 dx 后面就没法接了。
  2. 换限。x=0 时 t=1=1；x=4 时 t=9=3。所以 t 从 1 到 3。
  3. 把被积函数用 t 表示。两根号相消：12x+1=1t；又 x+2=t2−12+2。合起来
    x+22x+1dx=(t2−12+2)1t⋅tdt=t22+32
    注意那个 t 被除掉了，根号彻底消失，这才是第二换元的目的。

剩下就是普通的牛顿–莱布尼兹公式：

∫13(t22+32)dt=[t36+3t2]13=(276+92)−(16+32)=223
三个扣分点

一、换限写在草稿纸上、答题纸上不写。老师说这些准备流程「在答题纸上是要写的，考试的时候都算分」，尤其 dx 等于什么。

二、换完限又把 t 代回成 x。这是定积分换元与不定积分最大的区别，下一节专门说。

三、算出 t36+3t2 后代错限。用老师推荐的「x 从 0 到 4，t 从 1 到 3」写法，就不会把 1 和 3 弄反。

六、定积分换元与不定积分换元的分水岭：不用回代

42:45为什么定积分换完元可以「不管」t 了

不定积分的第二换元法里，最后一步是「回代」——求出关于 t 的原函数之后，必须把 t 换回成 x 的表达式，因为不定积分的答案必须写成 x 的函数，而且还要补一个 +C。这一步又长又容易错，很多同学都在这儿翻车。

定积分为什么免了这一步？因为定积分要的是一个数，不是一个函数。一旦我们把积分限也换成了 t 的范围，整个问题就彻底搬到了 t 的世界里：被积函数是 t 的，积分限是 t 的，算出来当然就是那个数，不会因为「用哪个字母写」而改变。既然已经换限了，就没有必要再回代。

换句话说，换限和回代是二选一的两条路：

  • 换限：算 ∫αβ(⋯)dt，直接得数，不用回代。
  • 若不换限：就得先把原函数用 x 表示（也就是回代），再代原来的 a,b——这等于绕远路，还多一次出错机会。

所以「换元必换限」不只是个规矩，它其实是在替你省掉回代这一步。这也是为什么老师把它当成全课最重要的一句话。

记忆入口 · 一眼回忆

一条链

选换元 x=φ(t) 目的是消根号/凑整体→ 算 dx dx=φ'(t)dt→ 换限 a→α，b→β→ 算 t 的定积分 不回代

要背的

  • 公式：∫abf(x)dx=∫αβf(φ)φ'dt（φ 是 t 的函数，dx=φ'dt）。
  • 口诀：换元必换限。限是「积分变量的取值范围」，变量换了，范围就换了。
  • 对应关系：下限对下限、上限对上限。下限不一定小于上限。
  • 定积分换元不回代；不定积分换元必须回代（还要加 C）。
  • 三角代换的常用限：x=asint 配 t∈[0,π2]；消 a2−x2 就是 ∫0a=πa24。

两条路线

第一换元（凑微分）
把某块表达式凑进微分号。限通常不用换，因为没有真正引入新变量。例如把 2xdx 凑成 −d(1−x2)，上下限始终是 x 的那一组。
第二换元（引入新变量）
如 t=2x+1、x=asint。限必须换，而且要写全「dx、t 的范围、被积函数的替换」三件事。

两个坑

  • 开偶次方先问符号。cos2t=|cost|；sin3x−sin5x=sin3/2x|cosx|，符号变号处必须分段。别把两段相同形式的积分当成相减得 0。
  • 别凭直觉换上下限的位置。x=−t 时 x 从 1→2 对应 t 从 −1→−2，写成积分限是 ∫−2−1。
