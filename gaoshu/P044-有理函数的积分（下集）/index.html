P044有理函数的积分（下）：待定系数法与总流程

一句话核心

有理函数的积分只有一条流水线：假分式先做多项式除法 → 分母因式分解 → 设部分分式 → 逐项积分。第三步是待定系数法的主场，设的「形状」由分母因式的类型决定，而系数可以用比较系数或代入特值两套手法定出来。

总流程：有理函数积分只有一条路

00:11这一集接着上一集收尾。老师开场先用一道很简单的题找手感：分母已经是平方差 (x+5)(x−3)，那就顺着这个分解往下走，直接按老办法拆开积分。题目本身不需要新工具，但它提前把本集的主线亮了出来——分母能不能分解、能分解成什么样子，决定了后面走哪条路。

把这一章用过的手法收拢起来，有理函数的积分从来不是「见一道想一道」，而是一条固定的流水线：

看真假 分子次数 ≥ 分母次数？ → 假分式 多项式除法削出整式 → 分母分解 拆成一次 / 二次不可约 → 部分分式 设字母拆成简单块 → 逐项积分 落成 ln / arctan / 幂

流水线上每一步都有它存在的理由，不只是「习惯动作」：

先比次数
真分式才可能被拆成「分母的因子各自做分母」的那几块。次数不对，怎么设都还原不回去。
再分解分母
部分分式设成什么形状，完全由分母的因式类型决定。分母没分解，就没有可参照的形状。
逐项积分收尾
每一块都落到三种基本积分上：u'u 出对数、1u2+1 出反正切、−u−2 出分式。
06:46为什么假分式不能直接设部分分式

拿一个最小的例子试一下：x2+1x2−1。如果不管次数，硬设 Ax−1+Bx+1，通分后分子是 (A+B)x+(B−A)，它的最高次项只有一次；而原式分子是二次的 x2+1。一次式无论怎么取 A,B，都不可能恒等于一个二次多项式——不是系数解不出来，而是这个恒等式根本不成立。

正确的处理是先做除法：x2+1=(x2−1)+2，所以 x2+1x2−1=1+2x2−1，后面那块才是真分式，才有资格拆。这就是老师那句「假分式先给它处理成真分式」的全部含义：不是流程讲究，是数学上不做这一步就无解。

待定系数法：设什么，怎么定

06:46进入本集的正题时，老师强调了一个前提：「分母已经因式分解完了，分子是一个一次表达式」，这种题最适合用待定系数法。它比凑微法直接，因为不用猜——按规矩把字母摆上去，剩下的只是解方程。

设的「形状」是死规矩，与因式类型一一对应（上一集已经列过，这里是本集反复要用的对照表）：

分母含的因式拆出来的块分子设成
(x−a)（一次）Ax−a常数 A
(x−a)k（一次的重根）A1x−a+⋯+Ak(x−a)k每块都是常数
x2+px+q（二次不可约）Bx+Cx2+px+q一次式 Bx+C

18:47第二行最容易漏项：(x−1)2 不是只写 C(x−1)2 一项，而要写出 Bx−1+C(x−1)2 两项。老师课上专门停下来对比这两种分母：同样是二次的分母，(x−1)2 和 x2+1 的做法完全不一样——前者的分子一律设常数，只是要多设几项；后者的分子要设一次式。

18:47为什么同样「二次」，两种分母的设法不同

关键不在「几次」，而在这个因式能不能再分解。(x−1)2 还能拆成两个一次因式，所以它的项会被拆成一整套「一次幂 + 二次幂」；而 x2+1 在实数范围里拆不动了，只能整体作为一类。

更实用的解释是：分子设到「比该因式低一次」为止。分母因式是一次，分子就设常数（零次）；分母因式是二次，分子就设一次式。(x−1)2 的每一块分母分别是 (x−1)1、(x−1)2，所以两块都设常数；x2+1 是一整块二次，分子就必须带 x。设少了，通分以后系数对不上；设多了，字母之间会互相抵消、解不唯一。

11:31至于「为什么敢猜它能拆成这个样子」，老师说得实在：其实这部分是有理论支持的，它是有一个定理的，只是课程涉及的题目难度到不了需要证明分解存在性的程度。所以我们把规矩记死、把题目做顺即可。

定系数的两套手法

设好形状之后，把两边同乘原分母，就得到一个关于 x 的恒等式——分母约掉了，只剩下分子之间的等式。这个恒等式对所有 x 成立，于是有两条路可以走。

预备把 1(x+1)(x−1)2 拆开，两套手法各走一遍。

第一步 · 设形状

分母有一个一次因式 (x+1)，和一个一次因式的平方 (x−1)2，所以设成三块、分子全为常数：

1(x+1)(x−1)2=Ax+1+Bx−1+C(x−1)2

两边乘 (x+1)(x−1)2，得到恒等式

1=A(x−1)2+B(x+1)(x−1)+C(x+1)
手法一 · 代入特值（快，但有条件）

既然是恒等式，代任何 x 都对。挑「让别的项归零」的值最省事：

  • 令 x=1：前两块都变成 0，只剩 1=2C，得 C=12。
  • 令 x=−1：只剩 1=4A，得 A=14。
  • 还差 B。前两个根已经用完了，随手代一个好算的值，比如 x=0：右边是 A−B+C，于是 14−B+12=1，解出 B=−14。
手法二 · 比较系数（慢，但万能）

把右边展开、按 x 的幂整理：

A(x2−2x+1)+B(x2−1)+C(x+1)=(A+B)x2+(C−2A)x+(A−B+C)

左边是常数 1，也就是 0⋅x2+0⋅x+1。比较三档系数：

A+B=0,C−2A=0,A−B+C=1

由前两式得 B=−A、C=2A，代入第三式：A+A+2A=4A=1，于是

A=14,B=−14,C=12

两种手法结果一致——这不是巧合，恒等式的系数本来就被唯一确定。

两套手法怎么选

分母因式互不相同时（比如 (x−2)(x−3)），代入特值几乎一击必中：每个根都让其他项消失。但一旦出现平方因式，可用的「根」只有一个，凑不出全部字母——像上面必须再补一个随便的 x=0。所以：代入特值适合手快，比较系数是永远有效的底牌。

另一个常犯的错误是忘了「代入特值等价于比较系数」的前提：两边必须是同一个恒等式，也就是必须先乘掉分母、约掉公因式。直接拿带分母的式子代值，会得到 0=0 这类废话。

例一：一次因式乘二次不可约因式

11:31这是课上第一个正式例题，也是本集最典型的结构：分母里一个是一次因式，一个是在实数范围里拆不动的二次因式。老师点名提醒：二次那一块的分子必须是一次式 Bx+C。

例 111:31求 ∫1(1+2x)(x2+1)dx。

思路：一次因式配常数分子，二次不可约配一次分子

按形状设两块：

1(1+2x)(x2+1)=A1+2x+Bx+Cx2+1

两边乘掉分母，只留下分子之间的恒等式：

1=A(x2+1)+(Bx+C)(1+2x)

右边展开并按 x 的幂整理：

Ax2+A+Bx+2Bx2+C+2Cx=(A+2B)x2+(B+2C)x+(A+C)

左边是常数 1，所以三档系数分别是 0、0、1：

A+2B=0,B+2C=0,A+C=1

由前两式得 A=−2B、B=−2C，所以 A=4C；代入第三式 4C+C=1，得

C=15,B=−25,A=45

于是原积分拆成两块，分别处理。第一块是标准对数型：

∫4/51+2xdx=45⋅12ln|1+2x|=25ln|1+2x|

第二块的分子是一次式，把它拆成「一次项 + 常数」两部分，一次项凑分母的导数、常数项出反正切：

∫−25x+15x2+1dx=−15ln(x2+1)+15arctanx

合起来：

∫1(1+2x)(x2+1)dx=25ln|1+2x|−15ln(x2+1)+15arctanx+C
绝对值去留要看清楚

x2+1 恒为正，所以 ln(x2+1) 里的绝对值可以直接去掉；但 1+2x 在 x<−12 时是负的，它的绝对值必须留着。这正是上一集讲的「u2+1 型不要绝对值、一次型要绝对值」的复用。

另一个高频错误是二次因式只设常数分子 Cx2+1。那样通分后分子是 A(x2+1)+C(1+2x)=(A)x2+2Cx+(A+C)，x 的系数只有 2C 一个自由度，而 x2 系数又只能靠 A——方程没有解。加上 Bx 这一档，三个字母才配得上三档系数。

例二：分母含一次项的平方

18:47第二个例题的分母是 (x+1)(x−1)2：有一个一次因式，还有一个「一次项的平方」。老师把它作为独立一类来讲——它和 x2+1 那种二次不可约因式处理方式不一样。

例 225:57求 ∫1(x+1)(x−1)2dx。

思路：平方因式拆两项，分子都是常数

设

1(x+1)(x−1)2=Ax+1+Bx−1+C(x−1)2

通分后只留分子：

1=A(x−1)2+B(x+1)(x−1)+C(x+1)

展开：

(A+B)x2+(C−2A)x+(A−B+C)

比较系数得

A+B=0,C−2A=0,A−B+C=1

由第一式 B=−A，由第二式 C=2A，代入第三式得 4A=1：

A=14,B=−14,C=12

三项各自求原函数：前两项是对数，第三项是幂函数。

∫1/4x+1dx−∫1/4x−1dx+∫1/2(x−1)2dx

最后一块注意 ∫(x−1)−2dx=−(x−1)−1，符号来自负指数：

∫1(x+1)(x−1)2dx=14ln|x+1|−14ln|x−1|−12(x−1)+C
25:57课上那句「这个题是课本上的题」

同一个结构在课本里换了样子出现：分母写成 (x+1)(x2−1)，分解以后仍然是 (x+1)2(x−1) 之类的完全平方式，拆三项、比较系数，套路一模一样。所以要认清的不是某一道题，而是「分母里有几重根，就拆几项」这条规矩。

27:39到这里，老师给本节的难度画了一条线：一个一次因式加一个二次因式（或平方因式），就是同学们要面对的最复杂结构。这部分的题目还可以更复杂一点哈，但是我们同学做的题呢就是大概到这个类型就算挺麻烦的了。

根式换元：换元之后又回到本页

29:03接下来几道题的被积函数里带着根号，部分分式用不上，因为根号底下不是「多项式之商」。办法是第二换元积分法里的根式换元：把整个根号令成 t，根号消失，x 与 dx 都用 t 表示出来，题目就退化成有理函数积分——又回到本页的流水线。

例 332:31求 ∫11+x+23dx。

思路：把立方根整块设成 t，dx 提前算好

令 t=x+23，两边立方得 x=t3−2，于是

dx=3t2dt

代进去，分母的 1+x+23 就是 1+t，根号不见了：

∫11+x+23dx=∫3t21+tdt

被积函数是假分式（分子二次、分母一次），按流程先做除法：t2=(t−1)(t+1)+1，即

t21+t=t−1+11+t

逐项积分：

∫3(t−1+11+t)dt=3(t22−t+ln|1+t|)+C

33:25到这里还没完——题目变量是 x，必须回代：

∫11+x+23dx=32(x+2)2/3−3(x+2)1/3+3ln|1+x+23|+C
回代与绝对值

课上老师特意停下来提醒：还是那个问题你得给他回代。换元算完直接交 t 的答案等于没做完。另外这里的根是三次根（奇次），1+t 的符号不受保证，所以 ln 里的绝对值要留着；如果换元的是偶次根（如 x−1，根号本身非负），t≥0，1+t>0，绝对值才可以省。

38:41两个不同次根号同时出现，指数取什么

课上最后一道题里同时出现了 x=x1/2 和 x3=x1/3。要让两个根号同时消失，换元 x=tm 里的 m 必须同时被 2 和 3 整除——取最小公倍数 6。令 x=t6，则 x=t3、x3=t2，而 dx=6t5dt；若分母正好是这两个根号相乘 t5，整块就塌成一个常数：

∫1xx3dx=∫6t5t3⋅t2dt=∫6dt=6x6+C

所以规律是：换元指数 = 各根指数的公倍数，取最小的那个。取大了也能做，只是白添计算。

45:49根式换元 ≠ 三角换元

换元法这一路有两支。本页的根式换元负责「代数根号」：x−1、x+23 这类，换完就变成有理函数。而三角换元（a2−x2 令 x=asint 那一套）靠三角函数恒等式消根号，是另一支，不能也令成一个 t 硬做。看见根号先分类：能化成有理函数的走根式换元，属于三角换元三型的才动三角。

记忆入口 · 一眼回忆

一条链

看真假 分子次数 ≥ 分母就先除 → 分母分解 一次 / 一次平方 / 二次不可约 → 设形状 分子次数 = 该因式次数 − 1 → 定系数 代特值 / 比较系数

要背的 · 定系数两套手法

  • 代入特值：用分母的根让别的项归零，顺手、最快；但平方因式只供一个根，剩下的字母要补一个普通值。
  • 比较系数：展开后让 x2、x、常数项三档系数分别相等；万能，永远能用。
  • 两者结果必然一致，互相可以当验算。

要背的 · 两道结果

  • ∫1(1+2x)(x2+1)dx=25ln|1+2x|−15ln(x2+1)+15arctanx+C
  • ∫1(x+1)(x−1)2dx=14ln|x+1|−14ln|x−1|−12(x−1)+C

两个坑

  • 二次不可约因式的分子是一次式，只设常数会解不出方程；(x−a)k 要拆成 k 项。
  • 换元之后必须回代成 x；ln 的绝对值去留看内部符号（u2+1 去、一次式留）。
