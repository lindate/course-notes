P062可分离变量的微分方程：分家、积分、回头看

一句话核心

这是微分方程里最简单的一类，也是后面所有方法的底子。套路只有一句话——把 x 和 dx 挪到一边，把 y 和 dy 挪到另一边，两边同时积分。但有一个必须养成的习惯：分离时除以过谁，就要回头问一句「那个东西等于零算不算解」——漏掉常数解，是这一节最真实的失分点。

标准形式：x 归一边，y 归另一边

可分离变量的微分方程，是解方程时最先遇到、也是最简单的一类。各本教材在开头部分的写法不太一样，但最后都能化成同一个样子：

M(x)dx=N(y)dy

式子的要点只有一条：等号左边只出现 x（连同 dx），等号右边只出现 y（连同 dy）。这里说的「x」和「y」是包含 dx、dy 在内的——左边那一整块是关于 x 的表达式，右边那一整块是关于 y 的表达式。

一旦分家成功，剩下的动作就一步：两边同时求不定积分。

∫M(x)dx=∫N(y)dy
为什么可以「两边同时积分」

因为 dydx 里的 dy 与 dx 在微分方程里是可以分开的（微分方程的基本概念 已经讲过这件事）。当你把 dx 乘到右边、把 y 的因子除到左边时，你得到的等式两边各是一个「关于单个变量的微分」。等式两边同时取不定积分，等号仍然成立——这就是整套方法的全部合法性。

积分完，左边出来一个只含 x 的函数，右边出来一个只含 y 的函数，中间用常数联系。这时候得到的往往不是一个「y=⋯」的显式表达式，而是一个把 x、y 混在一起的关系式——这也算解，而且常常是唯一能写出来的形式。

常数加在哪一边都行，但只能加一次

两边各求一次不定积分，严格说每边都会冒出一个任意常数：左边是 C1，右边是 C2。把 C1 挪到右边，得到 C2−C1——两个任意常数的差还是一个任意常数，所以干脆只写一个 C。这就是老师说的：你就在一边加常数就行了。

反过来，如果你在左边加了 C、右边也加了 C，然后说「这不就约掉了吗」——那是错的：左右两边的任意常数并不相等，不能相消。

怎么判断它是不是可分离变量

老师给了一条很好用的做题顺序：在做题的时候，你所有的微分方程第一步先考虑它是不是可分离变量的，这是最简单的一种模式。换句话说，遇到方程先别急着找类型，先试试能不能把家分开——分得开，就是最省事的一条路。

有些方程一眼就能分。比如 dydx=x2y3，虽然表面上 x 和 y 搅和在一个分式里，但两边一挪就开了：

y3dy=x2dx

左边全是 y，右边全是 x，分家完成。

也有些方程要绕一个弯。老师在课上举过一个「略微复杂一点」的样子：分子分母里都有 x 加几、y 加几的因子，看上去乱成一团。但只要把 y 的因子整块挪到左边、x 的因子整块挪到右边，仍然能干净地分开。

05:18那判据到底是什么？老师总结了两条特征：

  1. 式子里的运算只能是「相乘」或「相除」。也就是说，x 和 y 只许在乘除的位置上碰面。
  2. 在加减法的位置里，不许出现 x 与 y 混在一起。比如 x+3、y2+6 这种——括号内部虽然出现了变量，但括号里只有一种变量，那没问题；如果是 x+y 这种，x 与 y 在加法里黏上了，就分不开。

老师把这条总结成一句原话：x 跟 y 啊，它在加减法里头不掺和；在相乘跟相除，x、y 可以掺和。这就是判断可分离变量最实用的尺子。

做这类题会遇到的三个苦恼

可分离变量本身不难——无非是把不定积分搬过来做一遍。但老师提醒：在微分方程这部分，大家会碰到三个「巨大的苦恼」，它们不来自方法，来自答案怎么写。

苦恼具体是什么怎么办
① 绝对值 ∫1xdx=ln|x|+C，这个绝对值在微分方程里特别麻烦——什么时候能去掉、什么时候不能去，全看题目的条件。 不能凭习惯一律去掉。要去掉必须有理由（比如某个量恒正），最后往往统一收进常数里。
② 常数 C 同一个解，你写成 eC、写成 12C、写成 −3C，形式都不一样，但都是对的。老师原话：大家做的答案都可能不一样。 认准「它只是一个任意常数」，随手的系数一律并进 C，全篇统一写一个 C 或 C1。
③ 解的形式 很多时候 y 解不出来。比如得到 ex+y=y+12x+C，想写成 y=f(x) 非常麻烦，有的根本写不出。 写不成显式就保留隐式 F(x,y)=C。老师的态度很明确：写到这里就可以了。

例 1：从最简单的一条走完整流程

例 1解方程 1xdx=1ydy。

思路：已经分好家了，直接两边积分

这个方程连「挪位置」都不用做，x 在一边、y 在另一边，两边同时求不定积分：

ln|x|=ln|y|+C

左边是 1x 的原函数 ln|x|；右边是 1y 的原函数 ln|y|。注意那个绝对值——这里不能顺手去掉，因为 x、y 都可能取负值，题目没给任何理由保证它们为正。

第一步：把两个对数并到一起

把 ln|y| 挪到左边，式子变成 ln|x|−ln|y|=C，也就是

ln|xy|=C

两个对数相减等于相除。这一步不只是为了好看：把两个 ln 合并成一个，才能一次性取指数把它们都消掉。

第二步：两边取指数，把 ln 和绝对值一起处理掉

两边同时取 e 的幂：|xy|=eC。绝对值去不掉，只能在去绝对值时补一个正负号：

xy=±eC⟹y=±eCx

到这里，题目给了你一个「±eC」。它就是一个任意常数——C 随便取，正负号也随便取，合起来还是覆盖所有非零常数。所以直接把它记成一个 C：

y=Cx

一条过原点的直线族。验一下：y=Cx 有 y'=C；代回原方程，左边 1x，右边 1Cx⋅C=1x ✓。

这道例题真正想告诉你什么

它什么都没算错，但你已经连做了三个「不优雅」的动作：留着绝对值、去绝对值补正负号、把 ±eC 收成 C。这三步就是「三个苦恼」里前两个的真身。老师说这道题就是拿来让大家先体会一下的——后面每一步都会变本加厉。

心机 boy 的写法：把常数写成 ln|C|

既然每次都要走「合并对数 → 取指数 → 看正负号 → 收成常数」这一串，能不能一步到位？老师给的捷径是这样的。

刚才那一步走到 ln|x|=ln|y|+C 时，别把 C 原样留着，而是把它写成 ln|C|——本身只是一个记号上的改换，但后面会省掉一大串动作：

ln|x|=ln|y|+ln|C|=ln|Cy|

两边同时去掉 ln、去掉绝对值、补上正负号——这三件事一次做完，直接得到 y=Cx。不用先减、再取指数、再讨论符号。

凭什么能拿 ln|C| 去顶替任意常数 C

关键看取值范围对不对得上。C 是任意常数，可以取任何非零实数；而 ln|C| 当 C 跑遍所有非零实数时，取值是整个实数轴——ln|1|=0，|C| 越小它越负、越接近 0 时趋向 −∞，|C| 越大它越正、趋向 +∞。所以「ln|C| 能表示的数」和「非零的 C」是一模一样的集合。

老师把这个小动作叫做「心机 boy」：这个地方加常数 C 的时候，他故意不加常数 C，故意的整一个 ln，还得加个绝对值。看着像是在给自己加活，其实是为了让下一步的化简一步到位。

但要注意一个边界：ln|C| 表示不出 0。也就是说，用这个写法你会暂时放过 C=0 这条解（比如上例里的 y≡0）。做题时心里要留个底：凡是写法上「表示不出某个值」的步骤，都要回头检查一下那个值是不是也是一个解。这正是下面例 2 要讲的事。

例 2：一道必须回头检查的题

例 2解微分方程 x(y+1)dx+(x+1)ydy=0。

思路：先判断能不能分离，再挪位置

有同学一看「有相加的，这不行」——判断错了。要看的不是有没有加法，而是 x 和 y 有没有在同一个加减式里掺和。这里第一项是 x(y+1)，括号里只有 y；第二项是 (x+1)y，括号里只有 x。两种变量已经在乘法的位置上分开了，所以它是可分离变量的。

第一步：把 x 归一边、y 归另一边

把第二项挪到等号右边，再把两个 y 因子和两个 x 因子分别除过去：

x(y+1)dx=−(x+1)ydy⟹xx+1dx=−yy+1dy
第二步：分式拆项（否则积不出来）

xx+1 没法直接积分，用最常用的那一招——分子上凑出分母：x=(x+1)−1，于是

xx+1=1−1x+1

右边同理：yy+1=1−1y+1。

第三步：两边积分
∫(1−1x+1)dx=∫(−1+1y+1)dy
x−ln|x+1|=−y+ln|y+1|+C
第四步：整理成好看的隐式解

把含对数的两项挪到一边、其余挪到另一边，再把两个对数的负号提出来变加号、合并成乘积：

x+y−ln|(x+1)(y+1)|=C

到这里就不要再往下解了。老师讲得很清楚：这个结果写到这里就可以了，因为这里有 y、这里也有 y，你整理也整理不出来 y 的一个显示表达式。这就是「三个苦恼」里的第三个——隐式解也是解。

21:18这道题最容易全盘丢掉的两分

回头看刚才的动作：第二步里，我们把等式两边除以了 (x+1)(y+1)。除法天然带着一条隐含前提——除数不能等于零。也就是说，整个推导过程默认了 x≠−1 且 y≠−1。

那 x=−1 和 y=−1 这两种情形呢？直接代回原方程检验：

  • x≡−1（一条竖直线）：因为是常数，dx=0，第一项 x(y+1)dx 整个为零；又因为 x+1=0，第二项 (x+1)ydy 也为零。方程变成 0+0=0，成立。
  • y≡−1（一条水平线）：同理，dy=0 且 y+1=0，两项都是零，方程也成立。

所以 x=−1 和 y=−1 都是原方程的解，而且它们不包含在上面那个通解里（通解里只要出现 ln|(x+1)(y+1)|，就要求 x+1、y+1 非零；代进 x=−1 还会出现 ln0，根本没有意义）。

正确的收尾：在通解后面补一句——「此外，x=−1 与 y=−1 也是方程的解（分离时被除掉的两个常数解）」。

最常见的失分方式：算完 ln 那一步就交卷，把这两条平平无奇的直线忘得干干净净。这就是老师说的有些同学不是特别在意这个事情——但它确实是真实存在的解。

练习：练一遍常数怎么收

例 3解方程 y'+3x2y=0。

思路：先写成 dydx 的样子，再分离
dydx=−3x2y⟹1ydy=−3x2dx

两边同时积分：1y 的原函数是 ln|y|；右边 −3x2 的原函数是 −x3（因为 x3 求导得 3x2，负号保留）：

ln|y|=−x3+C1

两边取指数、去绝对值补正负号：y=±eC1e−x3，把 ±eC1 收成一个常数：

y=Ce−x3

一个提醒：分离时除以了 y，所以要问一句「y≡0 是不是解」。代回原方程：0+3x2⋅0=0 ✓，它是解。而 y=Ce−x3 中取 C=0 恰好就是 y=0——这次没丢，因为常数 C 写成了没有绝对值的任意常数，允许取零。对比一下例 2：那里丢掉的两条解之所以回不来，是因为它们压根不是「某个 C 值」，而是横的、竖的整条直线。

老师提醒这一步时说的原话是：因为我们其实并不太清楚后边这个 C 它的走向，所以这个地方你到底是写 C 还是 C1 呢？其实我们并不清楚，那你就先写个 C，有需要的话我们后期再改。不要在这一步上纠结，先把常数记成 C，最后统一收拾。

例 4解方程 xdy+2ydx=0，并求满足 x=2 时 y=1 的特解。

思路：先分离，再代初始条件定常数

把 2ydx 挪到右边：xdy=−2ydx。两边分别除以 x 和 y：

1ydy=−2xdx

两边积分，右边那个 −2 是常数，直接搬到对数前面当系数：

ln|y|=−2ln|x|+ln|C|

这里就用上了「心机 boy」的写法——把常数记成 ln|C|，好让两边都是对数。把 −2ln|x| 写成 ln|x|−2 再挪到左边，两项合并：

ln|y|+ln|x2|=ln|C|⟹ln|yx2|=ln|C|⟹yx2=C

这个形式比 y=Cx2 更好——先记住这句话，下一步会解释。

代初始条件

x=2、y=1 代进去：1⋅22=C，所以 C=4。特解是

yx2=4
27:25为什么不要写成 y=4x2

老师在这里专门停了一下，说写成 y=4x2「其实这样还不太合适」。理由不是不好看，而是它偷偷扔掉了一条解。

看原方程在 x=0 处的情形：x=0 意味着 dx=0，于是 xdy 这项为零，2ydx 这项也为零，方程变成 0=0——整条 y 轴（x=0）都是方程的解。

如果你把答案写成 y=4x2，分母上就摆着一个 x：只要 x=0，这个表达式就没有意义，那条竖直线被你在写法上直接排除了。而写成 yx2=4，虽然 x=0 也不满足（左边是 0、右边是 4），但至少形式上是「关于 x、y 的一个等式」，不会给人一种「x 不能取 0」的错觉。

老师给出的处理办法很干脆：我们就直接写成这一步就行了，就是 yx2=4 就可以了。通解（或特解）尽量保留隐式形式，尤其不要在分母上留下变量——这是微分方程里的一条经验。

要点：这道题一次串起了本页的两条主线——分离、积分、代初始条件，以及回头检查写法和漏解。

记忆入口 · 一眼回忆

一句话

可分离变量 = x 归一边、y 归另一边，两边同时积分。做完必须回头看：除过谁，谁就可能是一支漏掉的解。

标准形式与解法

M(x)dx=N(y)dy⟹∫M(x)dx=∫N(y)dy

一条链

判断 变量只在乘除里见面→ 分离 挪位置、做除法→ 积分 常数加一边→ 简化 ln 合并、常数收成 C→ 查漏 除过的因子 = 0

要背的

  • 判断特征：x 与 y 在相乘、相除里可以掺和；在相加减里不行（x+3、y2+6 这种「括号内只有一种变量」的不算掺和）。
  • 常数只加一边：左边加 C1、右边加 C2，差还是任意常数，不要写两个再「约掉」。
  • ln|C| 技巧：想省掉「合并对数 → 取指数 → 讨论正负号」，就把常数写成 ln|C|；但它表示不出 0，要单独查 C=0 的情形。
  • 解不出 y 就写隐式，尽量别把变量放到分母上——那会遮掉 x=0 那一类的解。

三个坑

  1. 漏常数解。x(y+1)dx+(x+1)ydy=0 除以 (x+1)(y+1) 后，必须补上 x=−1 和 y=−1。
  2. ln 的绝对值随手去掉。没有理由就不能去；有理由（比如某量恒正）才能去，而且要去得说得出理由。
  3. 答案写成 y=Cx2 这种带分母的形状。形式上是「解出来了」，实际上遮掉了 x=0 这条解。
