P024高阶导数：把导数再求一次、再求一次

一句话核心

高阶导数没有新概念——它就是把一阶导数当成新函数，再求一次导。难点全在记号和找规律：二阶导 y'' 既是加速度也是凹凸，而 sinx、ex 的 n 阶导有漂亮的通式，莱布尼茨公式则是乘积高阶导的「杨辉三角」。

概念：高阶导数就是把导数再求一次

00:00老师开场就说：高阶导数从概念上挺好理解——你原来不是求一次吗，你多求两次不就是高阶的吗？就这么简单。它没有任何新定义，本质就是：

  1. 先求一阶导 y'。y' 本身还是 x 的一个函数（比如 y=x2 时 y'=2x，2x 仍是函数）。
  2. 把 y' 当成新函数，再对 x 求一次导。得到 y''，即「导数的导数」。
  3. 想求几阶就继续。y'' 再求导得 y'''，依次类推。

所以「高阶」二字只描述动作重复了多少次，不引入任何新数学对象。

记号：这一页最该先搞清楚的

01:11记号是老师反复叮嘱的部分，因为长得像的符号意思差很远。两套记法等价：

阶数撇记法分式记法读法
一阶y'dydxy 对 x 求一次导
二阶y''d2ydx2y 对 x 求两次导
三阶y'''d3ydx3y 对 x 求三次导
n 阶y(n)dnydxny 对 x 求 n 次导

02:02老师特别点了两个「位置」陷阱：

  • 平方在「中间」还是「后边」。d2ydx2 的平方一个在分子 d 上、一个在分母 dx 上，表示「对 x 求两次导」；而 (dydx)2 是「一阶导整体平方」，二者完全是两回事。
  • y(n) 与 yn 天壤之别。y(n) 的 n 加了小括号，表示「求 n 阶导」；yn 没有括号，表示「y 的 n 次方」。老师原话：从四阶导开始我们不再写撇，写个 4 加个小括号表示 y 的四阶导；如果是 y4 就是 y 的四次方。
为什么分式记法把平方写在上下两处

d2ydx2 的来历是：一阶导记成 dydx，再对它求一次导，写作 ddx(dydx)。把外层那个 ddx 与里层合并，分子叠出 d(dy)=d2y，分母叠出 (dx)2=dx2，于是得到 d2ydx2。所以上下两个平方分别来自两次「对 x 求导」，不是把什么数平方了。老师也承认这写法「不如 y'' 好理解」，但书上都这么印，得认。

二阶导的两层意义：物理与几何

05:52二阶导 y'' 之所以重要，是因为它同时承担物理意义和几何意义——这是老师讲 S=sinωt 那道例题时自然带出来的。

物理意义：加速度

若 S(t) 是位移（位置随时间变化），则

S'=速度,S''=加速度

以课上例题 S=sinωt（ω 是常数）为例，里层 t 求导别忘：

S'=ωcosωt,S''=−ω2sinωt=−ω2S

结果 S''=−ω2S 是说：加速度与位移大小成正比、方向相反。这正是弹簧振子、单摆这类简谐运动的标志——位移越大、拉回越猛。所以二阶导在物理里就是「速度变化快慢」即加速度。

几何意义：凹凸

在纯数学里，f''(x) 的符号决定曲线的弯曲方向：

f''(x)几何语言直观
>0凹（向上凹 / 凹向上）切线在曲线下方，像碗
<0凸（向下凹 / 凸向上）切线在曲线上方，像帽
=0 且变号拐点凹凸切换处

这条几何意义在后面画函数图形时会成为主力（见 函数图形的绘制）。它和物理意义的区别只是视角：物理里自变量是时间、二阶导是加速度；几何里自变量是横坐标、二阶导是弯曲方向。同一个 y''，换坐标系就换了一层解释。

小例题：练手二阶导

例 109:12若 y=ax+b（a,b 常数），求 y''。

解

y'=a（常数 b 求导为 0），y''=(a)'=0。

一条直线，一阶导是常数斜率，再求导自然是 0。这是「二阶导为 0」的最简例子，也呼应了上面「f''=0 不弯曲（是直线）」。

例 210:08若 S=sinωt（ω 是常数，t 是变量），求 S''。

解：里层函数求导别忘

外层 sin，内层 ωt。一阶导：

S'=cos(ωt)⋅(ωt)'=ωcosωt

二阶导时，ω 是常数只管挂着，外层 cos、内层还是要再对 t 求导：

S''=−sin(ωt)⋅(ωt)'=−ω2sinωt
最常漏的一步

写成 S''=−ωsinωt。第二次复合时又忘了对里层 ωt 求导（乘 ω）。每剥一层洋葱都要把当层的内层导数乘上，两次相乘得 ω2。

通式一：ex 与 ax 的 n 阶导

12:13ex 是求导的「钉子户」——求多少次还是自己：

(ex)(n)=ex

对 ax，因为 (ax)'=axlna，每求一次就多一个 lna 因子，所以

(ax)(n)=ax(lna)n

当 a=e 时 (lne)n=1，就退化回 ex。这条通式「没有任何技巧，你求多少次不都是它吗」。

通式二：sinx 的 n 阶导

12:13这是必须记住的两大递推公式之一。老师用诱导公式一步步推：

  1. 一阶导。(sinx)'=cosx。把 cosx 写成 sin(x+π2)（诱导公式）。
  2. 二阶导。对 sin(x+π2) 再求导，外层 sin、内层加 π2（常数，导数为 1），得 sin(x+2⋅π2)。
  3. 三阶导。同理再加一个 π2，即 sin(x+3⋅π2)。
  4. 归纳。每求一阶，相位就多 π2。
(sinx)(n)=sin(x+nπ2)

老师强调：这个公式大家需要记住，做题的时候可以直接用。同理（直接给结论）：

(cosx)(n)=cos(x+nπ2)

15:19这两条把 sin、cos 的高阶导彻底「封死」：只关心 n 除以 4 的余数，就知道落在 ±sinx 还是 ±cosx 上。

为什么用「加 π/2」而不是直接记符号

死记 sin→cos→−sin→−cos→sin 容易在中间错位；用 sin(x+nπ/2) 一个式子全包，等于把「转了 n 个直角」写进相位里。算第 7 阶导？直接代 n=7：sin(x+7π/2)=sin(x+3π/2)=−cosx。一张公式顶一整圈循环。

通式四：ln(1+x) 的 n 阶导（现推）

17:13这条老师明确说记不住，现推就行。规律就在逐阶求导里：

y'=11+x,y''=−1(1+x)2,y'''=2(1+x)3,y(4)=−6(1+x)4

观察三件事：符号正负交替（(−1)n−1）；分母是 (1+x) 的 n 次方；分子是 (n−1)!。合并得

(ln(1+x))(n)=(−1)n−1(n−1)!(1+x)n
现推的捷径

考试若卡住，就从 y'=11+x 开始连求两三次，符号、分母指数、分子阶乘的规律立刻现形。老师提醒里层 1+x 还要再求导（乘 1），不过它正好是 1，所以「乘了等于没乘」——但意识不能丢，遇到 ln(2+x) 时这个 1 会变成 2。

和差的 n 阶导：直接分开

25:20若 u,v 都有 n 阶导数，则

(u±v)(n)=u(n)±v(n)

因为求导是线性运算，加减直接带进去，和求一阶时一模一样。这条很简单，老师没多费时间。

乘积的 n 阶导：莱布尼茨公式

27:04乘积的高阶导不像和差那样能直接分开，要用莱布尼茨公式。它长这样：

(uv)(n)=∑k=0n(nk)u(k)v(n−k)

展开写出来（老师特意先写「没写完」的版本，再补零阶导）：

(uv)(n)=(n0)u(n)v+(n1)u(n−1)v'+(n2)u(n−2)v''+⋯+(nn)uv(n)

39:02关键点：u 和 v 都从「零阶导」开始算。零阶导不是 0，而是函数本身——u(0)=u、v(0)=v。老师特意停下来问：v 的零阶导等于啥？v 啊，它没求导那就是它本身。

为什么它和二项式「一毛钱关系没有」却长得一样

33:44老师原话：上面的二项式定理和今儿讲的求导一毛钱关系没有，但式子几乎一样。相似是表面：二项式来自「每次从 a 或 b 里二选一」，莱布尼茨来自「乘积求导时每次从 u 或 v 里选一个求导」，两种「二选一」恰好都数出组合数 (nk)。所以结构同、来源异——别因为像就混为一谈。

莱布尼茨最易错：漏掉零阶导那两项

展开 (uv)(n) 时，第一项 u(n)v(0) 和最后一项 u(0)v(n) 都合法（零阶导=自身）。新手常只写中间带导的项，把首尾丢掉，结果少两截。

例题：y=x2e2x 求 y(20)

例41:41设 y=x2e2x，求 y(20)。

思路：让哪边当 u 有讲究

41:41老师的关键心思：选 u=x2、v=e2x，而不是反过来。原因马上见——x2 求三阶导就归零，而 e2x 求多少次都还在。

先各自摸清底：

  • u=x2：u'=2x，u''=2，u(k)=0(k≥3)。
  • v=e2x：v(k)=2ke2x（每求一次多一个因子 2）。

套莱布尼茨公式，但 u 从三阶起全为 0，所以只会留下 k=0,1,2 三项：

y(20)=(200)uv(20)+(201)u'v(19)+(202)u''v(18)

代入各自结果：

y(20)=x2⋅220e2x+20⋅(2x)⋅219e2x+20⋅192⋅2⋅218e2x

把公共因子 218e2x 提出来：

y(20)=218e2x(4x2+80x+380)=220e2x(x2+20x+95)
这一步最容易错

把 u、v 选反了。若选 u=e2x、v=x2，则 u 永远不为零、v 三阶归零，展开后 u 带 0,1,2 阶导——式子一样能算，但 e2x 那堆 2k 会落在「不归零」的那一侧，项数没减少，计算更繁。老师特意把颜色都配成和公式一致，就是暗示选 u 的原则：让它能早点归零。

莱布尼茨公式要背吗

40:23老师明确：这个公式不要记，做题的时候大家就到这一步就行——即展开到「k=0,1,2 那几项」，因为一阶导部分做题时已经有了，不必死背整条公式。能用通式直接代的是 sinx、ex、cosx 这几类；ln(1+x) 记不住就现推。所以本页真正要「背」的只有三个通式加记号规则。

记忆入口 · 一眼回忆

一句话

高阶导 = 反复求导；n 阶导的记号与通式是重点，莱布尼茨公式只展开、不背整条。

记号红线

  • d2ydx2（求两次）≠(dydx)2（先求导再平方）
  • y(n)（求 n 次）≠yn（n 次方）；四阶起写括号

三个必背通式

(ex)(n)
ex
(sinx)(n)
sin(x+nπ2)
(cosx)(n)
cos(x+nπ2)

(ln(1+x))(n)=(−1)n−1(n−1)!(1+x)n（记不住现推）；(u±v)(n)=u(n)±v(n)。

两层意义

  • 物理：S''= 加速度（如 S''=−ω2S 简谐运动）
  • 几何：f''>0 凹向上、f''<0 凸向上

两个坑

  • 复合函数里层导数漏乘（例 S'' 要 ω2 不是 ω）
  • 莱布尼茨漏首尾零阶导项；选 u 不让它归零导致项数爆炸
