P110【黑板】求体积

一句话核心

本页是第 12 章（定积分的应用）的复习精讲课，也是定积分应用里最容易考、最容易错的一块。所有立体体积题只有三条路：圆盘／圆环法（横截面是圆，对截面面积积分）、壳法（竖着切一条，绕 y 轴转成薄筒再剪开铺平）、平行截面法（截面是什么形状都行，只知道面积 A(x)）。选哪条路不看题目长短，只看两件事——转轴是谁、要不要反解。新授课细节见 求旋转体的体积 壳法求旋转体的体积 求体积非旋转体的体积。

一、知识速查：三条路，一张对比表

00:00老师说求体积「是考试的时候经常会考到的」，所以先把地图摊开。所有立体体积题，归根到底只有三种情形：

立体长什么样用什么方法核心公式什么时候用它
曲线绕 x 轴转出来的旋转体 圆盘法 / 圆环法 V=π∫abf2(x)dx 转轴是 x 轴，一眼套用，没有理由换别的
曲线绕 y 轴转出来的，且反解方便 圆盘法 / 圆环法 V=π∫cdφ2(y)dy 能顺利把 y=f(x) 反解成 x=φ(y)
曲线绕 y 轴转出来的，且反解麻烦 壳法 V=2π∫abxf(x)dx 不想反解、也反解不出来时（例 4、例 5）
根本不是旋转体 平行截面法 V=∫abA(x)dx 截面不是圆（三角形、长方形……），但面积能算

09:27老师说得很干脆：「所有题目都是用这四个公式来解的。」而后面两种（两条曲线夹出来的旋转体）尤其常考。所以这一页要做的事不是记新公式，而是把「拿到一道题，怎么判断该用哪一条」练成条件反射。

为什么「对横截面面积积分」就是体积

这句话听起来像定义，其实有很实在的道理。在 x 处垂直于 x 轴切一刀，再在 x+dx 处切一刀，得到一片薄片。03:56老师说：切得非常细的时候，这一片的两个底面几乎一样大，所以它差不多就是一个圆柱（更准确地说，是一个「柱体」）。

柱体的体积就是「底面积 × 高」，底面积是 A(x)、高是 dx，所以一片的体积是 A(x)dx。把 x 从 a 走到 b 一片片累加，就是 ∫abA(x)dx。

这里的「差不多」要较真：两侧底面面积的差是 dx 量级的高阶小量，几百上千片累加起来仍然趋于零。所以这不是「差不多所以对」，而是「误差是高阶的，求和之后自动消失」——这句话是老师每次讲微元法都要重申的。

还有一个很好用的视角：面积是二维的量，被积分一次就「升」成了三维的体积，等于维数加了一级。这个说法在讲平行截面法时会再用一次，那时它就不再是修辞，而是公式的全部内容。

二、圆盘法与圆环法：绕 x 轴、绕 y 轴

00:47设曲线 y=f(x) 在 [a,b] 上，把它绕 x 轴转一周。垂直于 x 轴切一刀，刀口是一个圆。这个圆的半径是多少？从 x 轴往上量到曲线，正好是 f(x)。所以截面积是 πf2(x)：

V=π∫abf2(x)dx(绕 x 轴，半径是 y)

05:25绕 y 轴的情形只要把两个角色互换：曲线写成 x=φ(y)、y 从 c 走到 d，垂直于 y 轴切一刀得到的是水平的圆盘，半径要横着量，也就是 φ(y)：

V=π∫cdφ2(y)dy(绕 y 轴，半径是 x)
05:25公式可以背，半径必须画

这是这一节最要紧的一句话。老师说他自己「都很容易混」，所以每做一道题都要在草稿纸上把半径那条线段画出来。理由很朴素：题目稍微一变，半径就换人。

  • 绕 x 轴转：转轴是水平的，点到转轴的距离要竖着量，所以半径是 y。
  • 绕 y 轴转：转轴是竖直的，点到转轴的距离要横着量，所以半径是 x。

一句话：半径是「点到转轴的垂直距离」，转轴是谁，量的方向就垂直于谁。它跟题目里函数写成什么形式没关系——写成 y=f(x) 还是 x=φ(y) 只是包装，转轴才决定一切。

为什么要反复强调？因为同学最常犯的错不是积分算错，而是把 y 当半径、把 x 当积分变量，然后一路错到底。这种错最后才发现，代价极大。

07:31第三种、第四种情形是「两条曲线夹着一块区域」再转。这时刀口不再是实心圆，而是圆环——大圆挖掉小圆。面积是「π 大半径平方 − π 小半径平方」，所以公式里是平方相减：

V=π∫ab[f2(x)−g2(x)]dx(绕 x 轴，外半径 f、内半径 g)
为什么是 f2−g2，而不是 (f−g)2

这条和极坐标求面积时的那条完全同类，但更容易记错。想清楚「两条半径从哪里量起」就明白了：外半径和内半径都是从同一根转轴量起的两个距离。外半径量到 f(x)，内半径量到 g(x)，于是圆环面积是 πf2−πg2。

如果写成 (f−g)2，展开是 f2−2fg+g2，多出来一个交叉项 −2fg，几何上对应的是完全不同的另一块形状。「先各自平方、再相减」和「先相减、再平方」是两件不同的事，在求面积、求体积、二重积分里都会反复出现。

07:31顺带说一句：两条曲线夹着转的时候，那个「中间被留下的小洞」正好就是内半径转出来的立体。这也是后面例 5 里「大圆柱减中间小芯」那套做法的来由。

三、壳法：绕 y 轴的第二条路

24:46老师先坦白了这个方法的来头：它在中文教材里很少见，他是从《普林斯顿微积分读本》里看来的，名字叫「壳法」（也有人叫柱壳法），念成 qiào 还是 ké 他都拿不准——但这不重要，重要的是它确实另辟蹊径。

它要解决的问题很具体：绕 y 轴旋转。用圆盘法也能做，但每次都要多做一步「把 y=f(x) 反解成 x=φ(y)」。25:36壳法的价值就是把这一步彻底省掉。做法是把刀转 90∘：不横着切，改竖着切。

  1. 取一条细条。25:36在 x 处取一条宽为 dx、高为 f(x) 的竖条，它离 y 轴的距离就是 x。
  2. 让它绕 y 轴转一圈。这条竖条扫出来的是一层非常薄的圆筒——像一个抽掉了上下底、筒壁极薄的易拉罐。这就是「壳」字的来历。
  3. 拿刀把它剪开、铺平。26:30老师形容这一步「超出你的想象力」：沿圆筒的一条母线剪一刀，再压平，它就变成一个长方体。
  4. 量出长方体的三个尺寸。30:30长是圆筒展开后的长度，也就是周长 2πx；高是原来的 f(x)；厚是 dx。三者相乘就是这一层壳的体积。
  5. 累加。让 x 从 a 走到 b，把这些薄壳一层层套起来。
V=2π∫abxf(x)dx(绕 y 轴，壳法)
为什么剪开铺平之后就是一个长方体

关键还是那个「薄」字。圆筒的厚度是 dx，而它的周长是 2πx，两者差着好几个数量级。所以剪开铺平的时候，圆周的弯曲完全可以忽略：一张薄纸卷成筒再展开，展开后就是一张平的长方形——这是每个人小时候都做过的事。

严格地说，展开后那两块不是一个完美的长方形，会有极微小的褶皱误差；但它是比 dx 高阶的量，几百上千层累加起来仍然趋于零。这就是微元法允许「先近似、后累加」的底气。

28:55老师说这个方法「挺好看、也挺好理解」——确实如此，因为它把一个不规则的立体直接拆成了一个个长方形方块，比圆盘法更直观。

还有一处必须说清楚：公式里的 x 到底是什么？它一会儿看着像「横坐标」，一会儿又像「半径」。正确的读法是——它就是这一层壳到转轴的距离，也就是半径。因为这一节的转轴恰好是 y 轴（直线 x=0），而「某点到 y 轴的距离」恰好等于它的横坐标，两件事才碰巧重合。所以 2πx 就是圆周长公式 2πR 里的那个 R。

四、圆盘法 vs 壳法：到底用哪一个

既然两种方法结果永远一样，为什么还要准备两套工具？41:23答案全在「反解」这两个字上。这也是本页最值得记住的一张表——它把「什么时候用哪个」变成查表题，而不是每次从头想。

比较项圆盘法 / 圆环法壳法（柱壳法）
刀怎么下垂直于转轴平行于转轴
切出的一片是圆盘 / 圆环薄圆筒（一层壳）
算的是圆的面积 πR2长方体体积 长×宽×高
绕 y 轴时的积分变量yx
绕 y 轴时的积分限y 从 c 到 dx 从 a 到 b
绕 y 轴时的公式π∫cdφ2(y)dy2π∫abxf(x)dx
要不要反解 y=f(x)要，而且可能反解不出来不要
被积函数的复杂度半径要平方，常出现高次项一次乘法，通常更简单
什么时候吃亏反解失败或反解结果很难看区域上下边界「换人」，必须分段
一句话把立体横着切成薄片把立体拆成一层层筒

把这张表压成一条判据，就是本页最实用的一句话：

选择判据（背这一条就够）
  1. 绕 x 轴转 → 一律用圆盘／圆环法。切出来的本来就是圆盘，半径是 y，公式一路顺到底，没有任何理由换别的。
  2. 绕 y 轴转 → 先看 y=f(x) 好不好反解。好反解（y=x−1、y=3x 这类），两种都行，挑算起来短的；反解不出来，或者反解结果很丑，直接上壳法。
  3. 两条曲线夹着的区域，壳法要把「高」写成差。设 f 在上、g 在下，每一层壳的高都是 f(x)−g(x)：
    V=2π∫abx[f(x)−g(x)]dx

还有一条隐藏前提：壳法要求从 a 到 b 一路只用同一个 f。一旦曲线交叉、上下关系换人，就必须在交点处切开分段——这条规矩和求面积时完全一样（见 【黑板】元素法和求平面图形的面积）。

反解到底能难到什么程度

说「反解不出来」不是夸张。像 y=x3+x+1 这样的函数，它单调、确实有反函数，但那个反函数不是初等表达式，根本写不出来。硬用圆盘法就走进死胡同了。

反过来看壳法：每一层薄壳的半径就是 x 本身，它正现成摆在积分变量里，一个反解都不需要。这就是老师说「不想反解时就用它」的底气。

另外还有一个和分段无关的理由也会逼你换方法：被积函数积不出来。有些按圆盘法写出来的积分（比如带 1x 的、带根号的复合）根本没有初等原函数，换成壳法之后反而变得很好积。到了二重积分那一章，这种情况会更常见。

五、平行截面法：截面不是圆怎么办

42:43老师用一个很接地气的例子开场：有一个土豆，求它的体积。43:14为什么不说西瓜？因为西瓜比较圆，可以看成旋转体，用圆盘法就做了；而土豆坑坑洼洼，谁也不是谁的旋转，只能老老实实当成一个「不太规则的立体」。

这类立体的正式名字叫平行截面面积已知的立体，说白了就是「比较普通的立体」。它有一个很好的性质：在每一个 x 处，用垂直于 x 轴的平面切一刀，切出来的那块面积是可以算出来的（或者题目直接给你）。把这个面积记作 A(x)，那么

V=∫abA(x)dx

44:12老师说，第一步先把「柱体」和「圆柱体」这两个词分清楚：

  • 圆柱体：两个底面都必须是圆。
  • 柱体：宽松得多。老师给的说法很形象——你平面里的一个图，甭管是三角形、圆形、椭圆形还是一个非规则的形状，把它垂直向上提一下子，就叫柱体。

所以土豆切出来的那片东西，底面可能是歪歪扭扭的一坨，但它仍然是个柱体。只要是柱体，体积就永远是底面积 × 高，与底面形状无关。顺便说一句：旋转体里的薄片，恰恰是「柱体」最特殊的一个例子——底面恰好是圆。所以前两节的公式其实是这一节公式的特例。

六、六道例题

例 110:17一条直线过点 (h,r)，它与 x 轴、x=h 围成一个直角三角形，这个三角形绕 x 轴旋转一周，求所得立体的体积。

思路：先看看它是什么东西，再决定用不用公式

10:17老师笑着说这道题「不是特别典型」——因为一个直角三角形绕直角边转一圈，得到的就是圆锥，体积直接写 13πR2H 就行。但为了照顾课本的情绪，还是用圆盘法走一遍。

直线过原点（它从 (0,0) 出发经过 (h,r)），斜率是 rh，所以 y=RHx（把 r、h 写成 R、H）。转轴是 x 轴，半径是 y，x 从 0 到 H：

V=π∫0H(RHx)2dx=πR2H2∫0Hx2dx=πR2H2⋅H33
V=13πR2H

结果和圆锥体积公式一模一样。老师说：「当然咱们不会傻傻地用这个公式去做，因为它就是圆锥。」这道题的价值在于确认「圆盘法给出的结果与已知公式一致」——它是一次免费的自检。

这里容易漏的

把 RHx 当成半径直接积，忘了平方。公式里要的是 y2，所以是 (RHx)2，x2 那句不能省。另外 R2H2 是常数，积分时提到外面，别让它跟着 x 一起被积。

例 212:44椭圆 x2a2+y2b2=1 分别绕 x 轴、绕 y 轴旋转一周，求两个旋转体的体积。

绕 x 轴：用对称性把积分砍一半

12:44椭圆左右对称，所以只算右半边再乘 2。右半边 x 从 0 到 a，半径是 y。关键是先把 y2 从椭圆方程里解出来，不用真的开根号：

y2=b2(1−x2a2)

这一步是本页最省力的一招——公式里要的正好是 y2，而椭圆方程给的正好也是 y2，所以完全不必求根号。于是

Vx=2π∫0ab2(1−x2a2)dx=2πb2[x−x33a2]0a=2πb2⋅2a3
Vx=43πab2
绕 y 轴：同一个套路，字母对调

14:47上下对称，所以只算上半再乘 2。这次 y 从 0 到 b，半径是 x，仍然先把 x2 解出来：x2=a2(1−y2b2)。

Vy=2π∫0ba2(1−y2b2)dy=2πa2⋅2b3=43πa2b
16:12两个结果摆在一起看，能看出三件事
  • a 与 b 的位置刚好对调。一个是 ab2，一个是 a2b——所以椭圆绕两条轴转出来的立体，体积一般不相等，不能想当然。老师说很多人觉得「转完不都像个橄榄球吗」，其实体积不一样。
  • 当 a=b=R 时两者相同：都变成 43πR3，正好是球的体积——因为此时椭圆退化成圆，绕哪条轴转都一样。这是又一个免费的自检。
  • 积分变量叫什么字母完全无所谓。老师说：我们定积分你用变量的什么符号是不是没有区别啊。所以 Vy 里出现 dy 不必心慌，规律和 dx 一模一样。

例 317:44摆线 x=a(t−sint)、y=a(1−cost)（0≤t≤2π）的一拱绕 x 轴旋转一周，求所得旋转体的体积。

思路：列式很顺，难点全在换元与换限

17:44摆线的画面是「一个圆在地上滚，轮子边上定点划出来的轨迹」。t 从 0 走到 2π 正好画出一拱。绕 x 轴，半径是 y，x 的范围是 0 到 2πa：

V=π∫02πay2dx
第一步：x、y 全换成 t 的表达式

被积函数是 y 的表达式、微分却是 dx，两者互不相干，必须做变量替换。y=a(1−cost)，而 dx=x'(t)dt=a(1−cost)dt。于是三个 (1−cost) 乘在一起：

V=π∫02πa2(1−cost)2⋅a(1−cost)dt=πa3∫02π(1−cost)3dt
本页最重要的一个坑：上下限要跟着换

换了变量却还写着 ∫02πa。老师原话说得很直接：你以为还是原来这个上下限，其实不是，上下限现在 t 是从 0 到 2π 的。

规则：积分变量从 x 换成 t，积分限就必须从「x 的范围」换成「t 的范围」。原来 x 从 0 到 2πa 对应 t 从 0 到 2π，所以写成 ∫02π。老师还补了一句：大家做定积分的题目，换元的时候最常见的错误就是上下限你老是忘换。

第二步：把 (1−cost)3 展开，逐项积

这个立方没有省事的办法，只能硬展开：(1−cost)3=1−3cost+3cos2t−cos3t。好在有两条规律能省掉一半工作：

  • ∫02π1dt=2π（就是区间长度）；
  • ∫02πcostdt=0 与 ∫02πcos3tdt=0——整周期上积分为零，两项直接划掉；
  • ∫02πcos2tdt=π（用降幂公式 cos2t=1+cos2t2，其中 cos2t 那一项又整周期积掉）。

所以括号里的积分是 2π−0+3π−0=5π，于是

V=5π2a3

要点：参数方程求体积，列式、换元、换限三步一步都不能少，最容易漏的是第三步。

例 431:53设 y=2x，取 x 从 1 到 2 这一段，把曲线、x 轴与 x=1、x=2 围成的区域绕 y 轴旋转一周，用壳法求体积。

思路：壳法的训练题——完全不碰反解

31:53老师说：「咱也别整难了」，就用这题把壳法公式跑通一遍。公式里需要的东西全都在手上：半径是 x、高是 f(x)=2x、积分限就是 x 的范围 1 到 2，一个反解都不需要。

V=2π∫12x⋅2xdx=4π∫12x2dx=4π[x33]12

上限代入 83，下限代入 13，相减得 73，所以

V=4π⋅73=283π≈29.32

对比一下工作量：如果改用圆盘法，得先反解出 x=y2，再把 y 的范围定成 [2,4]，还要判断外半径是 2（区域的右边界 x=2 一直不变）、内半径是 y2，最后算 π∫24[4−y24]dy。同一道题，壳法少了一个环节，被积函数也简单得多。

例 533:06摆线的一拱（0≤t≤2π）绕 y 轴旋转一周，求体积。用壳法，并和课本的「大减小」做法对比。

思路：书上分两块，壳法一个式子

33:06前面的例 3 已经把摆线绕 x 轴算完了；同一道题改成绕 y 轴，33:06老师说「是非常的麻烦」。课本的做法是分成两片：右边那一大片转出的立体，减去中间那个「芯」。听起来清楚，做起来要写两个圆环积分：

V=π∫02ax12(y)dy−π∫02ax22(y)dy

麻烦的地方不只是两个积分，而是换限。36:08老师说这一段的上下限「比较难理解」：y 从 0 到 2a 时，左半支对应的 t 是从 0 到 π，而右半支对应的 t 却是从 2π 到 π——上限比下限小，是倒着走的。这一点极其容易写错。最终两个积分的结果相减，得到 6π3a3。

壳法：一个式子直接到底

33:53用壳法就不必拆片了。把 x、y 都换成 t 的表达式，dx=a(1−cost)dt，t 从 0 到 2π：

V=2π∫02πx(t)y(t)x'(t)dt=2πa3∫02π(t−sint)(1−cost)2dt

这个积分确实要动一番手（把 (1−cost)2 展开，再逐项凑），但它是一个式子、一条积分限，没有「两块相减」和「倒着走的限」两个陷阱。算出来：

V=6π3a3

与课本的做法完全一致。41:23老师说：如果咱用咱补充的这个翘法来做，这一个式子就能搞定。这就是两套工具同时准备的意义——同样是正确的路，一条路上的坑比另一条少。

顺手记两个数字

摆线一拱：绕 x 轴转是 5π2a3，绕 y 轴转是 6π3a3。两个数长得像但不同，别记混——记的时候连「绕哪条轴」一起记，别只记系数。

例 646:34有一个底面半径为 R 的圆柱体，通过底面圆的圆心斜着切一刀，刀面与底面所成的角是 α。求切下来的那一块的体积。

先把背景搞清楚：它不是旋转体

46:34老师的办法很实在：你就比方说拿着你这个水杯，拿一个刀子这样斜着切，不过切的时候必须得经过这个水杯的这个圆的圆心。53:35后来他又补了一句更好记的——拿一根火腿肠，用刀斜着切下去。

因为刀必须过圆心，它在底面上留下的痕迹是一条直径，把底面圆分成两个半圆，所以切下来那一块的底面是一个半圆。这个立体的形状，老师说像扫地用的簸箕——一头高一头低，底面是圆的、上面被斜着削平。

53:35关键判断：这个立体的体积就不是个旋转体了，因为旋转体你一旋转得出来是圆，它没有圆啊。所以前面两节的办法在这里全用不上，只能用平行截面法。

建系，量出横截面

48:12取底面圆心为原点，底面所在平面为水平面。x 轴沿着那条底面直径，y 轴在底面上垂直于 x 轴（也就是「往里的深度」方向）。底面半圆是 x2+y2≤R2 且 y≥0。

49:01垂直于 x 轴切一刀，截面是直角三角形：一条直角边是 y=R2−x2（沿 y 方向从直径量到圆弧），另一条是竖直向上的 ytanα（在深度 y 处，切面比底面高出的部分正好是一个直角三角形的对边）。于是

A(x)=12⋅y⋅ytanα=12(R2−x2)tanα

50:02这里有个很常见的心理障碍：同学一看见 tanα 就发怵。老师说：我们同学一看三角形三角函数你就害怕，其实不用管它。因为 α 是题目给定的固定切角，tanα 就是一个常数，随时可以提到积分号外面。

用对称性把积分砍一半

x 从 −R 到 R。区间关于原点对称，被积函数 R2−x2 是偶函数，所以可以「从 0 积到 R 再乘 2」：

V=12tanα∫−RR(R2−x2)dx=12tanα⋅2∫0R(R2−x2)dx

注意那个 12 和 2 正好抵消了。这不是巧合，是老师故意先提常数、再用对称性给大家看的——先提常数再上对称性，能省掉一半代入计算。剩下的就是多项式积分：

V=tanα[R2x−x33]0R=tanα(R3−R33)
V=23R3tanα
这一题最容易错的两处

一、忘了三角形面积里的 12。它和 tanα 一样，是本题丢分最集中的地方。虽然这里被对称性的两倍抵消了，但你要清楚它本来就在那儿。

二、把 tanα 当成变量。它是常数，能提出来、也能和别的常数合并。担心「提出来会不会影响对称性」是多余的——提出来之后被积函数只剩 R2−x2，反而更容易看出是偶函数。

这道题还有一个漂亮的收尾：如果把刀的角度固定、让 α→0，体积趋于 0（刀几乎是水平贴着底面）；让 α→π2（刀竖直），tanα→∞——这说明「垂直切」这件事本身没有意义，因为那已经不是「斜切一刀」了。54:59检查极端情形，是判断一个公式有没有写错的常用手段。

七、易错清单

  • 半径认错。绕 y 轴却按 y 算半径，一路错到底。破解办法只有一个：每次先在草图上把半径那条线段画出来。
  • 圆环面积写成 (f−g)2π。应该是 πf2−πg2，两条半径各自平方再相减。
  • 公式里是 y2，却把 y=x2 直接代进去。要先平方两次：y2=(x2)2=x4（例 2 里则要先把 y2 从椭圆方程解出来）。
  • 换了元不换限。例 3 里 ∫02πa 写成 ∫02π 只在一念之间，但答案会差一整个 a 的量级。
  • 绕 y 轴时忘了反解。圆盘法要求内半径写成 x=φ(y)，直接拿 y=f(x) 去积，被积函数里会同时出现 x 和 y，根本积不下去。反解不出来就别硬撑，换壳法（例 4）。
  • 壳法里把 2πx 写成 πx2。那是圆面积，不是圆周长。壳法用周长，所以系数是 2π、指数是 1。
  • 壳法遇到曲线交叉却忘了分段。壳法要求从 a 到 b 一路只用同一个 f；一旦上下边界换人，必须在交点处切开。
  • 把「柱体」当成「圆柱体」。平行截面法里底面可以是任意形状，体积永远是底面积 × 高。
  • 被 tanα 吓住、忘了 12。α 是给定的固定角，tanα 是常数，可随时提出。
  • 把「面积」与「定积分」混为一谈。∫abf 带符号；而用圆盘法算出来的体积永远是正的（见 【黑板】定积分的定义与性质）。
记忆入口 · 一眼回忆

一句话

求体积 = 把立体切成无数薄片，每片是一个柱体，底面积乘厚度 dx 再累加。截面是圆就用 πR2，是别的形状就用 A(x)。

一条链

看转轴 定半径是 x 还是 y→ 看边界 一条曲线是圆、两条是圆环→ 定变量与上下限 绕谁就对谁积分→ 半径平方再积 得体积

要背的公式

  • 绕 x 轴（圆盘）：V=π∫abf2(x)dx，半径是 y。
  • 绕 x 轴（圆环）：V=π∫ab[f2−g2]dx，外减内。
  • 绕 y 轴（圆盘）：V=π∫cdφ2(y)dy，半径是 x，要反解。
  • 绕 y 轴（壳法）：V=2π∫abxf(x)dx，不用反解。
  • 平行截面：V=∫abA(x)dx，底面积 × 厚度再累加。

要背的结果

  • 圆锥 13πR2H；椭圆绕 x 轴 43πab2，绕 y 轴 43πa2b（a=b 时退化成球 43πR3）。
  • 摆线一拱：绕 x 轴 5π2a3，绕 y 轴（壳法）6π3a3。
  • 圆柱过底面圆心斜切：23R3tanα；底面半径为 R、高为 H 的正劈锥体：12πR2H。
  • ∫02πcos2tdt=π、∫02πcostdt=0——整周期上奇次项直接划掉。

三个坑

  1. 半径认错。绕 y 轴按 y 算半径，是全章最贵的错。动笔前先把半径画出来。
  2. 换元不换限。参数方程题里积分限必须跟着变量一起换。
  3. 该换方法时硬撑。绕 y 轴反解不出来，那就是壳法在喊你；截面不是圆，那就是平行截面法在喊你。
