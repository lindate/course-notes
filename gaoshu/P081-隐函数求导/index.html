P081隐函数求导：直接法、公式法，与同一个 F 的两副面孔

一句话核心

由一个方程确定的隐函数，导数可以用一条公式直接算出来：dydx=−FxFy，三元情形是 ∂z∂x=−FxFz。公式好记（一个负号 + 交叉对应），但这一节真正的难点是理解它怎么来的：直接法里 y 是 x 的函数，公式法里 F 是 x,y 的两个独立变量——同一个 F，两副面孔。

一元隐函数：老朋友，直接用求导法

00:01一个方程确定隐函数，课本分成一元和多元两块。一元这块其实上学期学过：y 是 x 的隐函数，意思是存在一个由 F(x,y)=0 决定的对应关系，但 y 的显式表达式写不出来。比如 ey+x2y=6，你说 y 等于什么？说不出来。

对这种情况，直接求导法是首选：两边同时对 x 求导，心里时刻记住一句话——y 是 x 的函数。这个「心里的印象」是全部关键，忘了它就会把 y 当常数。

例 102:07设 ey+x2y=6 确定 y=y(x)，求 dydx。

思路：两边同时对 x 求导，凡是遇到 y 就多补一个 y′

左边逐项看：ey 是复合函数，外层求导还是 ey，而 y 是 x 的函数，所以还得乘 y'；x2y 是乘积，求导得 2xy+x2y'；右边常数 6 求导是 0。

eyy'+2xy+x2y'=0

把含 y' 的项留在左边、其余移到右边，再把 y' 提出来：

(ey+x2)y'=−2xy⇒y'=−2xyey+x2

老师用这道题两次说明同一件事：直接法一点都不难，难的是别忘了 y 是 x 的函数。注意 ey 那一项——因为它带复合结构，所以求导之后要「多乘一个 y'」；而 x2y 里的 y 是普通因子，也要补一个 y'。两处都补上了，才算做对。

公式法：dydx=−FxFy

03:20隐函数存在定理 · 一元情形

设 F(x,y) 在点 P(x0,y0) 的某邻域内具有连续偏导数，F(x0,y0)=0，且 Fy(x0,y0)≠0，则方程 F(x,y)=0 在该点附近确定一个可导的隐函数 y=y(x)，并且

dydx=−FxFy

其中 Fx、Fy 表示把 F 看作 x,y 的二元函数分别对 x、对 y 求偏导（此时 x 与 y 相互独立）。

那串条件里，唯一值得留意的是 Fy≠0——因为它出现在分母上。老师的原话大意是：这些条件我们计算的时候从来不看，它就是给分母那句话做背书的。使用时只有一个动作：先把方程整理成右边等于 0 的形状，把左边整块记为 F(x,y)，然后套公式。

直接求导法公式法
F 的身份 F(x,y(x))：y 是 x 的函数 F(x,y)：x、y 是两个相互独立的变量
动作 两边同时对 x 求导，遇到 y 补一个 y'，再把 y' 解出来 分别求出 Fx、Fy，代入 −FxFy
优点 思路自然，不需要额外记公式；求二阶时更顺手 求一阶时快，一步到位，不容易算错复合结构
代价 项数多、要在脑子里持续记住 y 是函数 必须先把常数挪到左边；求二阶时反而麻烦
适用 二阶及以上的导数 只要一阶导数时
11:14公式是怎么来的：两边同时对 x 求导

课本对这个公式给的是「简单推导」（老师特意说明：这不是证明——真正证明隐函数存在且可导是个很繁琐的过程，课本没做）。推导只有两步。

第一步，认路。把 F 看成 x 与 y 的函数，而 y 又是 x 的函数，所以 F 到 x 有两条路：一条是 F→x，一条是 F→y→x。按 多元复合函数求导 的链式法则，两边同时对 x 求导得

Fx⋅1+Fy⋅dydx=0

（第一项里那个 1 就是 dxdx，也就是「直接到 x 那条边」的系数。）

第二步，解出来。把第二项移到右边：Fydydx=−Fx，两边同除 Fy（这就是要求 Fy≠0 的原因）

dydx=−FxFy

推导只有两步，但它把一件事说透了：公式法里的 Fx、Fy 是「x 与 y 相互独立」时求出来的偏导；而直接法开头的「两边同时对 x 求导」里，y 却是 x 的函数。同一个 F，两种身份——这是本节所有困惑的总源头。

两个高频踩坑点

一、右边有常数，没有先挪到左边。ey+x2y=6 里的 6 必须先写成 −6 才能记为 F。有意思的是：忘了挪，结果其实一样——因为 6 是常数，对 x 求偏导、对 y 求偏导都得 0，Fx、Fy 都不受影响。但老师提醒了一句：这个细节可能会给你扣一分。规范写法是先把右边化归为零。

二、把 Fx 当成「y 也是 x 的函数」去求。公式法里 F 是 x,y 的二元函数，求 Fx 时 y 当常数；求 Fy 时 x 当常数。这一条与直接法是反着的，混淆了就全错。

06:42用 F 的两副面孔验算同一道题

拿例 1 的 ey+x2y−6=0 试试公式法。记 F=ey+x2y−6。

求 Fx（y 当常数）：ey 是常数，导数为 0；x2y 对 x 求导得 2xy；−6 得 0。所以 Fx=2xy。

求 Fy（x 当常数）：这里最容易犯「y' 病」——看到 ey 就想乘 y'。不行，因为现在 y 只是一个自变量，ey 对 y 求导就是 ey，不需要再补任何东西；x2y 对 y 求导得 x2。所以 Fy=ey+x2。

dydx=−2xyey+x2

与直接法得到的答案分毫不差。一句话对照：直接法里「遇到 y 要补 y'」，公式法里「遇到 y 就把它当普通自变量」。这两句话是同一个人在两副面孔下说的。

例题：一阶用公式法，二阶用直接法

例 213:53设 x2+y2−1=0，求 dydx 与 d2ydx2。

思路：一阶套公式最省事；二阶别再想公式，直接用求导法

一阶。记 F=x2+y2−1，则 Fx=2x（y 当常数）、Fy=2y（x 当常数）。套公式：

dydx=−2x2y=−xy

二阶。16:07老师在这里停了一下，专门讲了一段心态：课本上确实有求二阶的公式，但那个式子很难记，「你能记多少公式你自己没数吗」——他的建议是二阶就别用公式了，直接把一阶的结果再对 x 求一次导。注意此刻 y 又变回 x 的函数了，所以 (−xy) 要按商的求导法则处理：

d2ydx2=−1⋅y−x⋅y'y2

分子里的 y' 有现成表达式，代进去：

d2ydx2=−y−x(−xy)y2=−y+x2yy2=−x2+y2y3

再回头用原方程 x2+y2=1：

d2ydx2=−1y3
这道题最值得记住的其实是「方法切换」

老师把这一点说得很明白：第一步和第二步用的不是同一种思路。第一步用公式法（F 是 x,y 的独立变量二元函数），第二步必须切回直接法（y 是 x 的函数）。要是硬把公式法也用在第二步，就得处理 ∂∂x(−FxFy) 这种嵌套偏导，反而更绕。

二元隐函数：F(x,y,z)=0

17:54由方程 F(x,y,z)=0 确定的隐函数，通常是「z 是 x,y 的函数」。这时 x、y 是自变量，z 是被确定的因变量，所以要写的是两个偏导。公式长得跟一元完全平行：

隐函数存在定理 · 二元情形

若 F(x,y,z) 在点 P 的某邻域内有连续偏导数，F(P)=0，且 Fz(P)≠0，则方程 F(x,y,z)=0 在该点附近确定唯一的 z=z(x,y)，且

∂z∂x=−FxFz,∂z∂y=−FyFz

记忆点和一元一样，就两条：第一，一定有负号；第二，交叉对应——对 x 求的那个偏导，分母上是 Fz；对 y 求的，分母上还是 Fz。换句话说，分母永远是「因变量那个字母」的偏导，因为它是被解出来的那一个。20:31还要再强调一次：Fx、Fy、Fz 是把 F 看成 x,y,z 三个相互独立的变量时求出来的偏导，求谁的时候另外两个都当常数。

例 3设 x2+yz+z2=0，求 ∂z∂x 与 ∂z∂y。

思路：先备好三个偏导，再套两个公式

先算分母。Fz 在两个公式里都要用，所以优先算它、算完直接用两次：

Fz=∂∂z(x2+yz+z2)=y+2z

（x2 与 z 无关得 0；yz 对 z 求导得 y；z2 得 2z。）

再算两个分子。

Fx=2x,Fy=z

（求 Fx 时 y,z 都是常数，只有 x2 活着；求 Fy 时只有 yz 里的 y 活着，得 z。）

∂z∂x=−2xy+2z,∂z∂y=−zy+2z

老师提了一个省事的技巧：两道小题的分母是同一个 Fz，所以分母算一次、抄两次；但反过来也有风险——如果第一次算错了，第二次会跟着错。所以「抄分母」的前提是你对第一步有把握。

换成直接法验一遍。22:31两边同时对 x 求偏导（y 当常数，而 z 是 x,y 的函数）：

2x+yzx+2zzx=0⇒(y+2z)zx=−2x⇒zx=−2xy+2z

完全一致。两边同时对 y 求偏导同理可得 zy=−zy+2z。

直接法里唯一需要留心的地方

对 x 求偏导时，yz 这一项里的 y 是常数、z 却是 x 的函数，所以它是「常数乘函数」，求导得 yzx；z2 是复合的，求导得 2zzx。这两个 zx 都要写出来，它们最后被提出来，才解得方程。

再练一道：一阶用公式，二阶用直接法

例 4设 x2y2z2−4z=0，求 ∂z∂x。

思路：记 F 为左边，先求分母 F_z，再求分子 F_x

记 F=x2y2z2−4z。

Fx=2xy2z2,Fz=2x2y2z−4

（求 Fx 时整块 y2z2 当系数；求 Fz 时 x2y2 当系数，z2 得 2z，−4z 得 −4。）于是

∂z∂x=−2xy2z22x2y2z−4=−xy2z2x2y2z−2

把分母里的负号收进去，还可以写成更清爽的形状：

∂z∂x=xy2z22−x2y2z

二阶怎么求？照例不用公式。把上面这个结果对 x 再求一次偏导，此时 z 又是 x,y 的函数（它含有 z，z 又含 x），所以要用商的求导法则，并且把已经算出来的 ∂z∂x 代进去。老师在这一步只说了一句话：「这一步的脑子得转一转了」——因为函数形式变了，身份也跟着变了。

方程组的情形：退回去用克莱姆法则

30:57这一节的最后，课本把「一个方程」升级成「方程组」。老师的态度很坦诚：30:18这部分一打开课本「除了表示震惊以外就是表示看不懂」——满篇的定理和公式，而且结论根本记不住，做题时只能现推。但只要复习一个线性代数的知识点就够用了。

工具：克莱姆法则（先复习一下）

对方程组

{a11x1+a12x2=b1a21x1+a22x2=b2

当系数行列式 D=|a11a12a21a22|≠0 时，解可以直接写成分式：x1=D1D、x2=D2D，其中 D1 是把 D 的第一列换成右端的 (b1b2)，D2 是把第二列换掉。

例 533:10设方程组 {xu−yv=0yu+xv=1 确定 u=u(x,y)、v=v(x,y)，求 ∂u∂x、∂v∂x。

思路：先认清谁是变量、谁是函数；两边对 x 求偏导，再解一个二元一次方程组

第一步，理清关系。这里有 x,y,u,v 四个变量。其中 x、y 是自变量，u、v 都是 x,y 的隐函数——这是整道题的前提，忘了它后面全乱。

第二步，两边同时对 x 求偏导。此时要记住三件事：y 当常数；u 是 x,y 的函数；v 也是。逐项处理，右端常数求导得 0：

{u+xux−yvx=0yux+v+xvx=0

第三步，把未知量（ux、vx）挪到一边，其余移到右边，凑成标准的线性方程组：

{xux−yvx=−uyux+xvx=−v

第四步，克莱姆法则。36:24系数行列式是 D=x2+y2，把右端项分别替换第一列、第二列，得到

ux=1x2+y2|−u−y−vx|=−xu−yvx2+y2
vx=1x2+y2|x−uy−v|=−xv+yux2+y2

看懂这一步的诀窍是把它翻译回线性代数：我们要解的是一个以 ux、vx 为未知量的二元一次方程组，右端的「常数项」里含 u、v，但那不影响克莱姆法则的用法。

对 y 求偏导的情形完全类似：x 当常数，方程组变成 {xuy−yvy=vyuy+xvy=−u，同样用克莱姆法则解出来即可。

视频原话（大意）

你说这数学课都成什么了……上节课还是 fu、fv，这一节课就成了这些。不知道的还以为是法语课呢。

玩笑归玩笑，老师紧跟着给了很实在的建议：方程组的隐函数求导，不要去背定理的结论——那些公式长得实在记不住，「做题的话还就只能现推」。把上面这个例子的四个步骤（理关系 → 两边求偏导 → 整理成线性方程组 → 克莱姆法则）走熟，比背公式可靠得多。

记忆入口 · 一眼回忆

两个公式

一元 F(x,y)=0
dydx=−FxFy（分母是因变量那个字母的偏导）
二元 F(x,y,z)=0
∂z∂x=−FxFz，∂z∂y=−FyFz

记忆两点

  • 一定有负号（来自移项，不是规定）。
  • 交叉对应：求谁的偏导，分子就是谁；分母永远跟着因变量走。

用之前的三步准备

  1. 把方程整理成右边等于 0（常数忘挪结果不错，但可能扣分）。
  2. 把左边整块记为 F。
  3. 算偏导时把 F 看成所有字母相互独立的多元函数。

两副面孔（最重要）

直接法 y 是 x 的函数，遇 y 补 y'⇋ 公式法 F 是多元函数，另一字母当常数

一阶用公式法，二阶用直接法。切换方法就是切换 F 的身份。

两个坑

  • 公式法里算 Fy 时，不要给 ey 补一个 y'（此刻 y 是自变量）。
  • 二阶别再套公式；把一阶结果当成「y 是 x 的函数」再求一次导。
