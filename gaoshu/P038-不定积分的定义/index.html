P038不定积分的定义 · 求导的逆运算

一句话核心

不定积分就是求导反过来：已知导函数 f(x)，找回「谁求导得到它」的原函数。关键结论有两条——连续函数一定有原函数；原函数的全体之间只差一个常数，所以不定积分永远写成 F(x)+C，那个 C 一个都不能丢。积分表与求导表互为逆运算。

它是求导「反过来」

00:00求导我们会：比如 (sinx)'=cosx。不定积分干的是反方向——谁求导得到 cosx？那当然是 sinx。但老师先泼了盆冷水：正过来容易，反过来不一定容易。

视频原话（大意）

昨天晚上你吃的是西红柿，今天早上上厕所偏红——但你早上那个偏红，昨晚不一定吃的是西红柿，可能吃的是火龙果。反过来不一定容易求。

这个（有点重口味的）比喻说的是：由「结果」反推「原因」这步，往往比正向计算难得多。后面你会看到，求不定积分的绝大多数技巧，都是在跟「怎么反过来」较劲。但本章先把这个「逆过程」本身定义清楚。

原函数：定义与存在定理

定义 · 原函数

设 F(x)、f(x) 在区间 I 上有定义，如果对 I 上任意 x 都有

F'(x)=f(x)

则称 F(x) 是 f(x) 在 I 上的一个原函数。这里 F 要求可导（否则「求导得到 f」无从谈起）。

03:23叫「一个」原函数，是因为一旦 F 是，F+C 也是——常数求导为零，白送一个 cosx。所以一个函数如果有一个原函数，它就有无穷多个。

为什么要求原函数「可导」

定义写的是 F'(x)=f(x)，左边是个导数，那 F 必须能求导才有意义。所以「可导」不是附加条件，而是定义本身埋好的要求。这也解释了存在定理为什么只保证「存在可导函数 F」——我们找的原函数得扛得住求导这一下，否则 F'=f 这句话根本立不住。

原函数存在定理

若 f(x) 在区间 I 上连续，则必存在可导函数 F(x) 使 F'(x)=f(x)。即：连续函数一定有原函数。

05:23老师特别提醒：这条结论是充分非充要。一方面，「连续」这个条件其实相当强——它保证了原函数存在，但原函数存在并不要求 f 连续；某些不连续的函数（比如有可去间断但特殊处理过的）照样能找到原函数。另一方面，正因为条件强，我们平时遇到连续函数就可以「放心地」断言原函数存在，不必再证。课本原话「连续一定存在原函数」记住即可，不必把它当成「只有连续才有原函数」。

「连续」是充分但非必要

05:23老师强调：这条是充分非充要。连续一定保证有原函数；但「有原函数」推不出「连续」——某些不连续的函数也可能存在原函数。连续是个相当强的条件，只是它足以让我们放心：遇到连续函数，原函数一定找得到。

两个说明：为什么差一个常数

08:52书上给了两点补充说明，第二点尤其重要。

说明一：F(x)+C 求导仍是 f(x)，所以只需找出一个原函数，全体就都有了。

说明二：若 F 与 Φ 都是 f 的原函数（即 F'=Φ'=f），构造 G=F−Φ，则

G'=(F−Φ)'=F'−Φ'=f−f=0

由第三章结论「导数恒为零的函数必为常数」，得 G=C，即

F(x)−Φ(x)=C⟹两个原函数只差一个常数
这句话是「必须加 C」的根

正因为所有原函数彼此只差常数，所以「f 的全体原函数」就可以统一写成「某一个原函数 +C」。这不是书写习惯，而是定理的直接推论：漏掉 C，你就只写出了无穷多个原函数里的「一个」，不是「全体」。

不定积分：原函数的全体

定义 · 不定积分

f(x) 的全体原函数称为 f(x) 的不定积分，记作

∫f(x)dx=F(x)+C

其中 ∫ 是积分号（拉长的 S，来自 sum），∫ 与 dx 之间的 f(x) 叫被积函数，x 叫积分变量。

13:23老师特别提醒：积分变量不一定总是 x。就像求导不总对 x 求（复合函数、下册偏导），积分也「对谁积分」要分清。写符号时 dx 这个尾巴不能省，它告诉你积分变量是 x。

例 117:01求 x2 的一个原函数（即 ∫x2dx）。

思路：求导是「少一次」，求原函数就「加一次」

求导时 xn 变成 nxn−1（次数少 1）；反过来，求原函数次数要加 1。要让结果求导后是 x2，原函数应是 x3；但 (x3)'=3x2，多出一个 3，配系数 13 消掉：

∫x2dx=13x3+C

例 219:06求 ∫1xdx。

思路：分正负两段，再合并

已知 (lnx)'=1x（要求 x>0）。老师在前面补充过：(ln(−x))'=1x（此时 x<0，因为 −x>0）。两段的原函数分别是 lnx 与 ln(−x)，统一写成带绝对值的形式：

∫1xdx=ln|x|+C
最容易错

漏掉绝对值，写成 lnx+C。只有在 x>0 时才成立；题目若没限定范围，必须写 ln|x| 才能覆盖负数部分。这是同学初学最爱踩的坑。

例 323:36曲线过点 (1,2)，且任意点处切线斜率等于该点横坐标的 2 倍，求曲线方程。

思路：斜率就是导数，反求原函数再代入定点

切线斜率 = y'，所以 y'=2x。由求导公式 (x2)'=2x，得 y=x2+C。代入点 (1,2)：

2=12+C⟹C=1

故曲线方程为 y=x2+1。

这题的「找曲线」本质是「积分 + 代入定点定 C」：先由 y'=2x 积出 y=x2+C，再用过点条件把 C 钉死。任何「已知导数和一点、求原函数」的应用题都是这个套路——积分给一族曲线，定点从中取唯一一条。

「全体原函数」长什么样

27:05y=x2+C 这一族，就是把一条抛物线沿 y 轴上下平移得到的一组曲线。给不同的 C 就得到不同的「兄弟曲线」，它们形状完全一样，只是高低不同。这就是「不定积分 = 一族曲线」的几何含义。

积分与求导：互逆，但积分必加 C

29:08不定积分和求导是「抵消」的关系。老师用个俗话概括：求原函数是「求爹」，求倒是「求儿子」——求完儿子再求爹回去，或先求爹再求儿子回去，都回到自己。用公式写更准：

公式读法
ddx∫f(x)dx=f(x)不定积分求导，回到被积函数
d(∫f(x)dx)=f(x)dx对不定积分取微分
∫F'(x)dx=F(x)+C先求导再积分回去，加 C
∫dF(x)=F(x)+C对微分求积分，加 C
为什么「积分后一定加 C」

前两条（积分后求导 / 微分）消去得干干净净，不加 C 也成立，因为求导会把常数吃掉。但后两条是「先求导再积分」——积分那一步要把被吃掉的常数补回来，所以凡是出现积分号、最后落定的结果，必须带 +C。老师原话：做不定积分的题，「最终一定要加上这个 C」。

举个最直白的例子对照前两条：问「x2 求导后的原函数是谁」，就是问「谁求导得到 x2」——那不就是 x2+C 吗（求导后常数消失，正好是 x2）。所以 ∫(x2)'dx=x2+C：先求导再积分，被吃掉的常数由 +C 补回。这正是第三条公式的活标本。老师还特意点出：别被符号绕晕，「求积分」和「求导」可以看作互相抵消——但只要最终落点是个积分，尾巴上的 C 就必须留下，这是积分和求导唯一的「不对称」。

考试里这一条是铁律：凡是不定积分的填空题、计算题，最后没写 +C 一律按错处理。哪怕你积分过程全对，漏 C 也拿不到满分。把「加 C」变成写完积分后的肌肉记忆，比背表更重要。

为什么积分表「对着」求导表记最高效

不定积分是求导的逆，所以积分表本质上是「把求导表每一条倒过来念」。你脑子里只要有求导表，积分表就不是新负担，而是它的镜像。唯一要额外记的「不一致」就是上面三处（绝对值、负号、分母 lna），把它们圈出来重点防错，剩下的大可依赖互逆关系推出来，不必死背。

直接用表做题：

  1. ∫x−3dx：加一次得 x−2，配系数 −12（因为求导会冒出 −2）：
    ∫x−3dx=−12x2+C
  2. ∫xdx：x=x1/2，加一次得 x3/2，配 23：
    ∫xdx=23x3/2+C
  3. ∫x2xdx：x2x=x5/2，加一次得 x7/2，配 27：
    ∫x2xdx=27x7/2+C
  4. ∫1xx3dx：1x⋅x1/3=x−4/3，加一次得 x−1/3，配 −3：
    ∫1xx3dx=−3x−1/3+C
老师的验算习惯

47:21简单积分算完，他都会顺手求导回去验证：比如 (23x3/2)'=x1/2=x，能回去就说明没错。这个习惯请照单全收——不定积分是少数「答案正确性可以秒验」的题型，不验白不验。

记忆入口 · 一眼回忆

一句话

不定积分 = 求导的逆；连续必有原函数；全体原函数 = F(x)+C，C 不能丢。

核心公式

  • F'=f ⇒ F 是 f 的一个原函数
  • ∫f(x)dx=F(x)+C，C 是积分常数
  • 互逆：ddx∫f=F 反推 ∫F'dx=F+C

两个坑

  • ∫1xdx=ln|x|+C，绝对值别漏
  • 凡有积分号、最终结果必带 +C

记忆诀窍

求原函数 = 次数加一、配分母 (μ+1)；算完求导回去验。
