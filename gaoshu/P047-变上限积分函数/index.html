P047变上限积分函数

一句话核心

定积分本是「上下限固定」时的一个常数；一旦让上限动起来，它就变成 x 的函数 Φ(x)=∫axf(t)dt。在 f 连续的条件下，Φ'(x)=f(x)——这条结论不仅给出了一套求导公式，更证明了「连续函数必有原函数」。

从「常数」到「函数」

00:00我们前面所有定积分，上下限 a,b 都是给定死的，被积函数也固定，于是算出来的就是一个确定的数。老师先抛一个问题：对一个定积分求导，等于几？

00:00老师先点明本节课有两大内容：一是变上限积分函数的求导，二是牛顿–莱布尼茨公式。二者是「积分学基本定理」的两面——前者告诉你「积分怎么求导」，后者告诉你「求导的逆运算怎么算定积分」。今天聚焦前者，它是后者的直接铺垫。

02:21答案几乎是条件反射：等于 0。因为上下限和被积函数都固定时，定积分就是一个常数，常数求导当然是零。这一步是想让你先确认「定积分 = 常数」这个身份。

03:49现在把右端点从固定的 b 改成可以滑动的 x。也就是说，上限不再是死的，而是个变量。这时阴影部分的面积会跟着 x 的移动而变化——x 往右挪，面积变大；x 往左挪，面积变小。既然面积随 x 变，它就成了 x 的函数。这就是变上限积分函数。

定义 · 变上限积分函数

设 f 在 [a,b] 上可积，对任意 x∈[a,b]，令

Φ(x)=∫axf(t)dt

则称 Φ(x) 为变上限积分函数（积分上限函数）。它衡量的是：从固定起点 a 到活动上限 x 之间，曲线下的带符号面积。

00:00名字在不同教材里不一样

这个概念各版本教材的叫法不统一：有的叫变上限积分函数，有的叫变现积分函数，习题和考试里还常写成积分上限函数。三个名字指的是同一个东西——下限是常数、上限是变量的那种积分。看到别的说法不用犹豫，认出「上限在动」就够了。

05:49积出来到底是 x 的函数还是 t 的函数

老师在这里特意追问：这个积分里既有 x（上限）又有 t（积分变量），最后到底是谁的函数？答案是只和 x 有关，和 t 一毛钱关系都没有。原因是：积分变量 t 只在「积分号内部」活动，积分一做完，t 就被「求和消掉」了，剩下的是一个只由上限 x 决定的数值。好比 ∫abf(x)dx 是个常数、和里面的 x 无关一样——这里的 t 也是同样的命运。所以 Φ 是 x 的函数。

05:49从几何上看，Φ'(x)=f(x) 说的是一句大白话：「面积对上限的变化率，等于上限那一点的曲线高度」。上限多挪一点点 Δx，新增的面积近似是 f(x)⋅Δx，除以 Δx 就是 f(x)。这和我们用导数定义推出的结论完全吻合，也给了 Φ'(x)=f(x) 一个无需计算的直观理解——它本质上是「面积随端点滑动的瞬时速度」。

08:42为什么积分变量偏偏写成 t 而不是 x

这里有个极易踩的坑：如果写成 ∫axf(x)dx，外面上限是 x，里面被积函数也是 x，两个 x 指的是完全不同的东西——一个是要滑动的上限，一个是正在被求和的「哑变量」。这种重名会让人脑子打架、也容易在求导时搞错。解决办法是把积分变量换个字母，写成 t：上限的 x 和积分变量的 t 立刻分清。本质上 ∫axf(x)dx 和 ∫axf(t)dt 是同一个东西，但后者不会引发歧义。约定俗成：上限用 x，积分变量用 t。

05:22老师原话：先分开，熟了再合并也无妨

关于「上限 x、积分变量 t」这条规矩，老师的说法很实在：我们刚刚开始学的时候，上限这个 X 和积分变量这里边这个 T，我们一般给它整成两个不同的符号，图的只是防止搞混；但其实我们学了一阵以后，这里的变量和这里的变量，有的时候我们都给他写成 X，这个也没有什么大问题。所以规矩不是死的：能不能写同一个字母，取决于你脑子里是否分得清「谁在动、谁是哑的」。初学阶段一律分开写，永远是最安全的做法。

主定理：Φ'(x)=f(x) 及其证明

10:36这是整页的灵魂。若 f 在 [a,b] 上连续，则变上限积分函数 Φ(x) 在 [a,b] 上可导，且

Φ'(x)=ddx∫axf(t)dt=f(x)

读起来朴素：对变上限积分求导，把上限 x 直接代进被积函数即可。但「朴素」背后有一个完整的证明，老师讲得很细——它同时用到了上一页的两条性质。

定理 · 变上限积分求导

设 f∈C[a,b]，则 Φ(x)=∫axf(t)dt 在 [a,b] 上可导，且 Φ'(x)=f(x)。

12:31证明分四步，骨架是「导数定义 + 区间可加性 + 积分中值定理」：

  1. 写出导数定义。给 x 一个增量 Δx（仍落在 [a,b] 内），函数增量
    ΔΦ=Φ(x+Δx)−Φ(x)=∫ax+Δxf(t)dt−∫axf(t)dt
  2. 用区间可加性合并。下限都是 a，把第一项拆成 ∫ax+∫xx+Δx，与前一项抵消，得
    ΔΦ=∫xx+Δxf(t)dt
    这就把「大区间」缩减成「长度为 Δx 的小区间」。
  3. 用积分中值定理。在 [x,x+Δx] 上，f 连续，故存在 ξ 介于 x 与 x+Δx 之间，使
    ∫xx+Δxf(t)dt=f(ξ)Δx
    于是 ΔΦ=f(ξ)Δx。
  4. 回到导数定义取极限。
    Φ'(x)=limΔx→0ΔΦΔx=limΔx→0f(ξ)
    当 Δx→0 时，夹在 x 与 x+Δx 间的 ξ 被「挤」向 x；由 f 连续，f(ξ)→f(x)。故 Φ'(x)=f(x)。证毕。
证明里每一步的「为什么」

第二步的抵消，靠的是上一页的区间可加性——它让两段同起点的积分能拼能拆。第三步的 f(ξ) 出场，靠的是积分中值定理，而它要求 f 连续。所以定理开头那句「f 连续」不是客套，它是整个证明能走通的前提：没有连续，就找不到那个 ξ，也就推不出极限等于 f(x)。第四步最后一步「ξ→x」，同样依赖连续性保证极限能取进去。

把证明再读一遍，你会发现它极为「经济」：只用了两条上一页的性质（区间可加性、积分中值定理），就把「积分」和「导数」这对看似无关的操作焊在了一起。这也是为什么老师把这段证明讲得很细——它不仅是结论，更是「用已知性质推导新结论」的范本。今后遇到涉及变上限积分的极限、不等式，第一反应就应该是「先求导，再谈别的」。

28:32端点处的处理：当 x=a 时，只能从右侧逼近（右导数）；当 x=b 时，只能从左侧逼近（左导数）。结论同样成立，只是导数分别指单侧导数。所以定理在闭区间 [a,b] 上整体成立。

推论 · 连续函数必有原函数

30:37既然 Φ'(x)=f(x)，那么 Φ(x)=∫axf(t)dt 就是 f(x) 在 [a,b] 上的一个原函数。这正是原函数存在定理：只要 f 连续，它的原函数一定存在——而且我们直接把它造出来了，就是变上限积分。

这条推论为什么了不起

在讲不定积分时，「存在原函数」几乎是默认可用的。但这里给出了存在性的硬证明：不需要你会求积分，只要 f 连续，把上限设成变量、写出变上限积分，那个式子天生就是原函数。它彻底解决了「什么样的函数一定有原函数」这个问题——答案是「连续即可」。后面牛顿–莱布尼茨公式能成立，也正依赖这个存在性。

06:36为什么说它是「搭在微分与积分之间的桥」

回头看看这一页到底干了什么：左边是积分，本质是一个和式的极限；右边是导数，本质是一个变化率。这两样东西本来属于两个不同的世界，求积分要切、要取点、要求极限，求导数要作差商、要取极限，彼此毫不相干。而 Φ'(x)=f(x) 这条等式，第一次把两个操作焊在了同一个函数身上——对变上限积分求导，结果把积分「还原」回了被积函数。

所以积分上限函数不是一节孤立的知识，它是搭在微分与积分之间的一座桥。也正因为有了这座桥，下一节才有资格通行：牛顿–莱布尼茨公式的证明，全部家当就只有两条——「Φ 是 f 的原函数」和「两个原函数只差常数」。没有这页的 Φ'(x)=f(x)，下一节的公式根本证不出来。这页内容看着短，却是整章的地基。

五个求导公式

35:57主定理只给了一个基本款（上限是 x）。实战里上限、下限、甚至上下限都可能是 x 的函数，共有五种情形。书上讲了第一种，其余四种由「交换上下限变号 + 链式法则」推出。

20:24为什么要补出后面四个

老师特意交待了一句：书上讲完公式一就收笔了，但「这个内容远远没有结束」。如果只会公式一，考试里绝大多数变上限积分求导题都做不出来——因为题目里的上限、下限常常是 x 的函数，而不是 x 本身。后面四个公式都是课上现场补的，它们不是新定理，只是「交换上下限变号」和「链式法则」两条旧工具的组合。所以这部分的正确学法不是背五条，而是认出题目属于哪一种情形，然后两步走。

公式一 · 上限是 x
ddx∫axf(t)dt=f(x)（把上限代进去）
公式二 · 下限是 x
ddx∫xbf(t)dt=−f(x)（交换上下限多一个负号）
公式三 · 上限是 u(x)
ddx∫au(x)f(t)dt=f(u(x))u'(x)（链式法则）
公式四 · 下限是 v(x)
ddx∫v(x)bf(t)dt=−f(v(x))v'(x)
公式五 · 上下限都是函数
上限代入乘上限导数，减去「下限代入乘下限导数」：f(u(x))u'(x)−f(v(x))v'(x)

例 135:57求 ddx∫1xsintdt 与 ddx∫0x(cost+t2−2)dt。

思路：直接套公式一

上限是 x，把 x 代进被积函数里的积分变量位置即可：

ddx∫1xsintdt=sinx
ddx∫0x(cost+t2−2)dt=cosx+x2−2

没有任何技术含量——这就是公式一的标准用法。

例 2 · 易错38:21求 ddx∫0xx2sintdt。

思路：先把 x2 外提，再求导

39:08很多同学会照葫芦画瓢把 x 代进去，得到 x2sinx——这是错的。错在哪儿？被积函数里的 x2 不是积分变量 t 的函数，它相对于 t 是常数！既然是对 t 积分，x2 可以堂堂正正地提到积分号外：

∫0xx2sintdt=x2∫0xsintdt

现在左边是「x 的函数 × x 的函数」，求导要用乘积法则：

ddx(x2∫0xsintdt)=(x2)'∫0xsintdt+x2ddx∫0xsintdt

第一项 (x2)'=2x，第二项积分求导得 sinx，所以

ddx∫0xx2sintdt=2x(1−cosx)+x2sinx

对比「错误答案」x2sinx，少了前面那块 2x(1−cosx)——这正是忘把 x2 外提、漏掉乘积求导的代价。

判断口诀

下笔前先看被积函数里有没有「积分变量以外的字母」。有（如这里的 x2），先外提再求导；没有，直接套公式一把代。这个反转题是考试高频坑。

例 346:54求 ddx∫1x2+2x(sint+et)dt。

思路：公式三，两步法

上限是 x 的函数 u(x)=x2+2x。第一步，把上限整体代进被积函数：

sin(x2+2x)+ex2+2x

第二步，乘上上限对 x 的导数 u'(x)=2x+2：

ddx∫1x2+2x(sint+et)dt=(sin(x2+2x)+ex2+2x)(2x+2)

「先代上限、再乘上限导数」——这就是链式法则在变上限积分上的化身。

思路：上限代入求导 − 下限代入求导

上限 u(x)=ex，下限 v(x)=x2。分别代入被积函数再乘各自导数：

=e4x+2e2x−2x7−4x3

记住「上限带进去乘上限导数，减去下限带进去乘下限导数」，前四个公式全被它包揽，不必单独硬背。

33:40公式三（上限是函数）还有一个「无坑预警」的课堂练习，以及公式四（下限是函数）单独要多留一个心眼——它的坑在于负号会来两个。下面两题各练一种。

例 533:40求 ddx∫0sinxcostdt。

思路：公式三，两步走，没有坑

上限是 x 的函数 u(x)=sinx。第一步，把上限整体代进被积函数（被积函数是 cost，把其中的 t 换成 sinx），得到 cos(sinx)；第二步，乘上上限的导数 (sinx)'=cosx：

ddx∫0sinxcostdt=cos(sinx)⋅cosx

老师对这道题的评价是「无坑预警」——它不设陷阱，只是把步骤熟一遍。真正要练成条件反射的是这一条：看到上限不是光秃秃的 x，立刻想到「先代上限、再乘上限导数」，而不是顺手把 x 塞进去。

例 636:11求 ddx∫e−x5(sint+t2)dt。

思路：公式四，先补一个负号，再乘下限的导数

下限是 x 的函数 v(x)=e−x，上限是常数 5。按公式四：第一步补一个负号（来自交换上下限），把下限代进被积函数；第二步乘上下限的导数。

ddx∫e−x5(sint+t2)dt=−(sine−x+e−2x)⋅(e−x)'

其中 (e−x)'=−e−x，它与前面那个从「交换上下限」来的负号相乘得正：

ddx∫e−x5(sint+t2)dt=e−x(sine−x+e−2x)
这一步最容易错

只记住「下限要加负号」，于是把答案写成 −e−x(sine−x+e−2x)。漏掉的是下限本身求导还会带一个 −1。判断符号最稳的办法是不看公式、回到意义：被积函数 sint+t2 在 [0,5] 上非负，而 x 增大时 e−x 减小，积分区间被拉长，扫过的面积在增加，所以导数必须是正的——一旦算出负号，立刻就知道错了。

1:05:42为什么第五个公式能统一前四个

令上限 u(x)=x、下限 v(x)=a（常数），就退化成公式一（因为常数的导数是 0，下限项消失）；令上限为常数、下限为 x，就退化成公式二；上限或下限之一是常数、另一是函数，则是公式三、四。所以只要记牢公式五，前面四种都是它的特例。考试时直接写第五个，最稳妥。
