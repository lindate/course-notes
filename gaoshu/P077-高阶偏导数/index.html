P077高阶偏导数：再求一次，以及那个「连续」的条件

一句话核心

二阶偏导数就是把一阶偏导数再求一次，算起来没有新东西。这一节真正值钱的只有一条定理：二阶混合偏导数在连续的条件下与求导次序无关。考试就考「连续」这两个字——条件一旦去掉，相等的结论立刻垮掉。

把「求一次」变成「求两次」

03:52一阶偏导算完之后，它本身还是 x,y 的函数，所以当然可以接着对它求偏导。老师说这个概念的定位很清楚：「高阶偏导数这个概念是比较好理解的——你对 x 求完一次以后，你对 x 再求一次，这个就叫二阶偏导数。」

按「先对谁、后对谁」分类，一共得到四个二阶偏导数：

记号下标记号求导顺序读法提示
∂2z∂x2 zxx 先 x，再 x 对 x 连求两次，不是混合偏导
∂2z∂y∂x zxy 先 x，再 y 分母从右往左读顺序
∂2z∂x∂y zyx 先 y，再 x 下标从左往右读顺序
∂2z∂y2 zyy 先 y，再 y 对 y 连求两次

05:09其中中间那两个叫二阶混合偏导数。老师专门划了一条界线：「对 x 求一次再对 x 求一次，这个不叫混合偏导数；对 x 求一次再对 y 求一次，或者对 y 求一次再对 x 求一次，才叫混合偏导数。」

符号是这个知识点最容易踩的地方

05:09老师自己都承认：「这部分的符号是特别的乱。」乱在两套记号的方向正好相反：

  • 用 ∂ 写的时候，∂2z∂y∂x 里的求导顺序要从右往左看：右边是 ∂x 就先对 x 求，左边是 ∂y 就后对 y 求。理由是它本来就是一个「求两次」的复合写法：先算 ∂z∂x，再对 y 求。
  • 用下标写的时候 zxy 要从左往右看：先 x 后 y，和 fxy=(fx)y 完全一致。

所以 ∂2z∂y∂x 和 zxy 指的是同一个东西，不是相反的东西。写卷子时建议只用一种记号并写全，混着写最容易出错。

为什么「求两次」这件事值得单独拿出来讲

因为四个二阶偏导里面，真正有信息量的是那两个混合的：zxy 和 zyx。它们代表两条完全不同的路径——一条先顺着 x 走再拐向 y，一条先顺着 y 走再拐向 x。

07:50后面的例题会显示这两条路算出来的结果一模一样。而这显然不像是「碰巧」——它必然对应着某个条件。09:08把这个条件找出来，就是本节的核心定理。所以这一节的结构是：先算 → 发现巧合 → 追问条件 → 给定理 → 去条件找反例。

先算一遍：两个混合偏导碰巧相同

例 106:38设 z=x3y2−3xy3−xy+1，求四个二阶偏导数。

思路：先老老实实求出一阶偏导，再各求一次

第一步，求一阶偏导。对 x 求的时候 y 是常数：

∂z∂x=3x2y2−3y3−y

逐项核对：x3y2 里 y2 是系数，x3 求导得 3x2；−3xy3 里 −3y3 是系数，x 求导得 1；−xy 里 −y 是系数。对 y 求的时候 x 是常数：

∂z∂y=2x3y−9xy2−x

第二步，各自再求一次。先看只对同一个变量连求两次的两个：

∂2z∂x2=6xy2,∂2z∂y2=2x3−18xy

再看两个混合的。先 x 后 y：把 ∂z∂x=3x2y2−3y3−y 再对 y 求偏导（此时 x 是常数）：

∂2z∂y∂x=6x2y−9y2−1

先 y 后 x：把 ∂z∂y=2x3y−9xy2−x 再对 x 求偏导（此时 y 是常数）：

∂2z∂x∂y=6x2y−9y2−1

07:50两个结果完全相同。老师写到这里自己都顿了一下：「大家会发现一个问题——这俩数是一样的，这俩数是相同的。」

而且这个相同不是这一题的巧合：09:08「我们同学做计算题的话，对 x 求再对 y 求、先对 y 求再对 x 求，这两个结果一定是一样的。」

定理：相等的条件是「连续」

09:08定理 · 混合偏导数与求导次序无关

如果函数 z=f(x,y) 的两个二阶混合偏导数 ∂2z∂y∂x 与 ∂2z∂x∂y 在某区域内连续，则在该区域内二者恒相等：

∂2z∂y∂x=∂2z∂x∂y

也就是说：二阶混合偏导数在连续的条件下，与求导的先后次序无关。

09:08定理陈述很平常，但老师把考法说得非常具体——他是这样提醒的：09:08「你在课本上把连续这俩字儿勾出来。他在考试的时候就考这俩字。我给你仔细说说：若二阶混合偏导数在某点存在则必相等，对不对？」他停了一下：「你看大家都没留神——二阶混合偏导数在某点若存在则一定相等，对不对？不对。它必须连续才相等。这『连续』俩字就是考试的时候要考的地方。」

为什么「存在」不够，非要「连续」

回看那张路线图：zxy 和 zyx 是从 z 出发的两条不同路径。两条不同的路能保证走到同一个终点，这在数学里从来不是免费的——它需要一点「光滑性」来兜底。

连续恰好提供了这种光滑性：它保证 f 在这点附近没有剧烈的、方向相关的跳跃，于是「先走 x 还是先走 y」的差别会在取极限的过程中被抹平。而仅仅「存在」是逐点的、局部的、彼此独立的信息，它管不到两条路径之间的协调。10:42所以定理的写法偏偏不是「若存在」，而是「若连续」——这一个词的差别，正是命题成立与否的分水岭。

把「连续」去掉会怎样：一个不等的反例

10:42既然条件是必需的，就应该有一个反例来证明「少了它真的不行」。下面这个函数是课本里的经典构造，它专治「以为存在就够了」：

例 2设 f(x,y)=xy(x2−y2)x2+y2（x2+y2≠0），f(0,0)=0。验证 ∂2z∂y∂x 与 ∂2z∂x∂y 在原点不相等。

思路：两个混合偏导都要回到定义算，因为它俩在原点只能靠极限刻画

第一步，先算沿坐标轴方向的一阶偏导。取 y≠0，按定义把 y 固定、让 x 从 0 出发变动：

f(h,y)−f(0,y)h=y(h2−y2)h2+y2

右边把 h→0 代进去：分子 y(0−y2)=−y3，分母 y2，所以极限是 −y。即

fx(0,y)=limh→0f(h,y)−f(0,y)h=−y(y≠0)

而 fx(0,0)=0。第二步，把它再对 y 在 y=0 处求导：

fxy(0,0)=limk→0fx(0,k)−fx(0,0)k=limk→0−k−0k=−1

第三步，换另一条路。取 x≠0，先固定 x、让 y 从 0 变动：

f(x,h)−f(x,0)h=x(x2−h2)x2+h2

同样的道理，这个极限是 x，即 fy(x,0)=x。再对 x 在 x=0 处求导：

fyx(0,0)=limk→0fy(k,0)−fy(0,0)k=limk→0k−0k=1

于是

fxy(0,0)=−1≠1=fyx(0,0)

同一个函数、同一个点、只换了求导顺序，结果从 −1 变成 1。这就说明：定理里的「连续」不是客套话，去掉它结论立刻失效。

这个反例为什么不违反定理

因为它恰好不满足定理的前提：f 的两个二阶混合偏导数在原点处不连续（在原点它们甚至要另算，且与在附近取极限的值对不上）。定理是「连续 ⇒ 相等」，它从没说「存在 ⇒ 相等」——反例只是把这个缺口暴露出来而已。

再练几道：把「当常数」用到不同场合

例 311:43设 z=lnx2+y2，求 ∂2z∂x2。

思路：动手之前先化简，把根号吃掉

对数里带根号，先用对数性质把根号搬到前面：

z=lnx2+y2=12ln(x2+y2)

先求一阶。对 x 求偏导时 y 是常数，外层求导得 1x2+y2，再乘内层 x2 的导数 2x：

∂z∂x=12⋅2xx2+y2=xx2+y2

再求二阶。这是一个商，用商法则：分子求导乘分母、减去分子乘分母求导：

∂2z∂x2=1⋅(x2+y2)−x⋅2x(x2+y2)2=y2−x2(x2+y2)2

13:05同样的做法对 y 来一遍会得到 x2−y2(x2+y2)2——分子正好差一个负号，这不是巧合，而是函数关于 x,y 完全对称的必然结果。老师对这道题的评语是「正常求就行，也没什么特别的」。

例 415:06设 z=(1+xy)y，求 ∂z∂x 与 ∂z∂y。

思路：底数和指数都含变量，这是幂指函数，先改成 e 的形式

对 x 求偏导很简单：y 是常数，底 1+xy 的指数 y 也是常数，所以这只是一个幂函数，但内层还得乘一个链式因子（1+xy 对 x 求导得 y）：

∂z∂x=y(1+xy)y−1⋅y=y2(1+xy)y−1

对 y 求偏导就不能这么干了——指数和底数里都有 y，这时候必须把它写成一个真正的指数函数：

z=(1+xy)y=eyln(1+xy)

现在外层是 e□，求导还是 e□，只需要再乘上里面的导数。里面是乘积 yln(1+xy)，用乘积法则：

∂z∂y=(1+xy)y[ln(1+xy)+y⋅x1+xy]

其中 ln(1+xy) 对 y 求导得 x1+xy（内层 xy 对 y 求导得到 x）。先把幂指函数化成 e 的形式再求导，是处理这类函数的固定套路。

例 516:25设 u=xy/z（x>0），求 ∂u∂x、∂u∂y、∂u∂z。

思路：三元函数和二元函数一个道理——对谁求偏导，另外两个全当常数
  • 对 x 求：y,z 是常数，y/z 就是一个常数指数，把 xy/z 看成幂函数：
∂u∂x=yzxyz−1
  • 对 y 求：x,z 是常数，xy/z 是指数函数，底数 a=x，指数是 y/z，所以先出 lnx，再乘指数对 y 的导数 1z：
∂u∂y=xyzlnx⋅1z=lnxzxyz
  • 对 z 求：x,y 是常数，还是指数函数，但这个指数是 yz，对 z 求导要用商（或写成 yz−1）得 −yz2：
∂u∂z=xyzlnx⋅(−yz2)=−ylnxz2xyz

18:08老师对三元函数的评价是：「二元函数和三元函数求偏导这个过程，大家稍微适应一下——对 x 求偏导的时候 y、z 都看作常数。就稍微适应一下就好，这个计算的难度来说不是很难。」

三元函数最容易犯的错

只把「另一个」变量当常数。二元时确实只有另一个，但到了三元，剩下的两个变量都要当常数。例如对 x 求 ∂u∂x 时，y 和 z 都得钉死——于是 yz 整体是一个常数，直接用幂函数法则即可。

必背的例题结果

  • z=x3y2−3xy3−xy+1：zxy=zyx=6x2y−9y2−1。
  • z=lnx2+y2：zxx=y2−x2(x2+y2)2，符号与 zyy 相反。

  • u=xy/z：ux=yzxyz−1，uy=lnxzxyz，uz=−ylnxz2xyz。

两个坑

  • ∂2z∂y∂x 与 zxy 是同一个：一个从右往左读、一个从左往右读。
  • 三元函数求偏导，另外两个变量都要当常数，不是一个。
