P127【黑板】高阶偏导数

一句话核心

二阶偏导数就是把一阶偏导再求一次，计算上没有新东西。这一页真正值钱的只有一条定理：二阶混合偏导数在连续的条件下与求导次序无关。考试就考「连续」这两个字——条件一旦换成「存在」，相等的结论立刻垮掉。

把「求一次」变成「求两次」

00:00一阶偏导算完之后，它本身仍然是 x,y 的函数，所以当然还能接着求偏导。老师对这个概念的定位很干脆：「高阶偏导数这个概念是比较好理解的——你对 x 求完一次以后，对 x 再求一次，这个就叫二阶偏导数。」

按「先对谁、后对谁」分类，一共四个二阶偏导数：

记号下标记号求导顺序读法提示
∂2z∂x2 zxx 先 x，再 x 对 x 连求两次，不是混合偏导
∂2z∂y∂x zxy 先 x，再 y 分母从右往左读顺序
∂2z∂x∂y zyx 先 y，再 x 下标从左往右读顺序
∂2z∂y2 zyy 先 y，再 y 对 y 连求两次

03:42中间那两个叫二阶混合偏导数。老师专门划了条线：「对 x 求一次再对 x 求一次，这个不叫混合偏导；对 x 求一次再对 y 求一次，或者对 y 求一次再对 x 求一次，这才叫混合偏导。」

符号是这一节最容易踩的坑

01:37老师自己都说「这部分的符号是特别的乱」。乱在两套记号的方向正好相反：

  • 用 ∂ 写时，∂2z∂y∂x 的求导顺序要从右往左看：右边是 ∂x 就先对 x 求，左边是 ∂y 就后对 y 求。理由是它本来就是「求两次」的复合写法——先算 ∂z∂x，再对 y 求。
  • 用下标写时，zxy 要从左往右看：先 x 后 y，和 (zx)y 完全一致。

所以 ∂2z∂y∂x 和 zxy 是同一个东西，不是相反的东西。写卷子时建议只用一种记号并写全，混着写最容易出错。

为什么「求两次」值得单独拿出来讲

因为四个二阶偏导里，真正有信息量的是那两个混合的：zxy 与 zyx。它们代表两条完全不同的路径——一条先顺着 x 走再拐向 y，一条先顺着 y 走再拐向 x。

06:15下面的例题会显示这两条路算出的结果一模一样。这显然不像「碰巧」，它必然对应某个条件。把这个条件找出来，就是本节的核心定理。所以这一节的结构是：先算 → 发现巧合 → 追问条件 → 给定理 → 去条件找反例。

先算一遍：两个混合偏导确实相同

例 105:09设 z=x3y2−3xy3−xy+1，求四个二阶偏导数。

思路：先老老实实求出一阶偏导，再各求一次

第一步，求一阶偏导。对 x 求时 y 是常数：x3y2 里 y2 是系数，x3 求导得 3x2；−3xy3 里 −3y3 是系数，x 求导得 1；−xy 里 −y 是系数。于是

∂z∂x=3x2y2−3y3−y

对 y 求时 x 是常数，同理得

∂z∂y=2x3y−9xy2−x

第二步，各自再求一次。先看「连求两次同一个变量」的两个：

∂2z∂x2=6xy2,∂2z∂y2=2x3−18xy

再看两个混合的。先 x 后 y：把 ∂z∂x=3x2y2−3y3−y 再对 y 求偏导（这时 x 是常数）：

∂2z∂y∂x=6x2y−9y2−1

先 y 后 x：把 ∂z∂y=2x3y−9xy2−x 再对 x 求偏导（这时 y 是常数）：

∂2z∂x∂y=6x2y−9y2−1

06:15两个结果完全相同。老师写到这里自己都顿了一下：「大家会发现一个问题——这俩数是一样的，这俩数是相同的。」

而且这不是这一题的巧合。07:15「我们同学做计算题的话，先对 x 再对 y、先对 y 再对 x，这两个结果一定是一样的。」

定理：相等的条件是「连续」

07:15定理 · 混合偏导数与求导次序无关

如果函数 z=f(x,y) 的两个二阶混合偏导数 ∂2z∂y∂x 与 ∂2z∂x∂y 在某区域内连续，则在该区域内二者恒相等：

∂2z∂y∂x=∂2z∂x∂y

也就是说：二阶混合偏导数在连续的条件下，与求导的先后次序无关。

08:07定理说得平平常常，但老师把考法讲得非常具体：「你在课本上把连续这俩字勾出来，考试就考这俩字。」他当场演示了一遍出题人的套路：「若二阶混合偏导数在某点存在则必相等，对不对？」停了一下又说：「你看大家都没留神——不对。它必须连续才相等。这『连续』俩字就是考试要考的地方。」

为什么「存在」不够，非要「连续」

回看那张路线图：zxy 与 zyx 是从 z 出发的两条不同路径。两条不同的路能走到同一个终点，在数学里从来不是免费的——它需要一点「光滑性」兜底。

连续恰好提供了这种光滑性：它保证 f 在这一点附近没有剧烈的、方向相关的跳跃，于是「先走 x 还是先走 y」的差别会在取极限时被抹平。而「存在」是逐点的、局部的、彼此独立的信息，它管不到两条路径之间的协调。一个词的差别，就是命题成立与否的分水岭。

例 2设 f(x,y)=xy(x2−y2)x2+y2（x2+y2≠0），f(0,0)=0。验证两个混合偏导在原点不相等。

思路：在原点只能回到定义，用「先固定一个变量」的办法算

第一步，算 y≠0 处的 fx(0,y)。按定义固定 y、让 x 从 0 出发变动：

f(h,y)−f(0,y)h=y(h2−y2)h2+y2

让 h→0：分子趋于 y(0−y2)=−y3，分母趋于 y2，所以极限是 −y。即 fx(0,y)=−y（y≠0），另有 fx(0,0)=0。

第二步，再对 y 在 y=0 处求导：

fxy(0,0)=limk→0fx(0,k)−fx(0,0)k=limk→0−k−0k=−1

第三步，换一条路。固定 x≠0、让 y 从 0 出发变动，同样的算法得到 fy(x,0)=x；再对 x 在 x=0 处求导：

fyx(0,0)=limk→0fy(k,0)−fy(0,0)k=limk→0k−0k=1

于是

∂2f∂y∂x(0,0)=−1≠1=∂2f∂x∂y(0,0)

同一个函数、同一个点，只换了求导顺序，结果从 −1 变成 1。这就说明定理里的「连续」不是客套话，去掉它结论立刻失效。

这个反例为什么不违反定理

因为它恰好不满足定理的前提：两个二阶混合偏导在原点处不连续。定理说的是「连续 ⇒ 相等」，从没说「存在 ⇒ 相等」——反例只是把这个缺口暴露出来而已。

易错清单与几道计算

  • 记号方向记反。∂2z∂y∂x 从右往左读、zxy 从左往右读，两者指同一个东西。
  • 忘了用已经求出的 fx。求 zxy 时应该在 ∂z∂x 的基础上下手，而不是从头再对原函数求一遍——那样容易算错项、也容易漏项。
  • 把定理条件写成「存在」。这是本节唯一的送分/送命题，写成「若存在则相等」直接判错。
  • 求二阶时把「常数」放跑了。09:48求二阶偏导的规则和求一阶完全一样：对 x 求就把 y 看作常数，对 y 求就把 x 看作常数。

例 312:48设 z=(1+xy)y，求 ∂z∂x 与 ∂z∂y。

思路：先判断它是幂函数还是幂指函数

对 x 求偏导：y 是常数，底 1+xy 的指数 y 也是常数，所以它只是一个幂函数；但内层 1+xy 对 x 求导得 y，链式因子要带上：

∂z∂x=y(1+xy)y−1⋅y=y2(1+xy)y−1

13:58对 y 求偏导就不能这么干了——底数和指数里都有 y，这是幂指函数，必须先用 e 把它改写成纯指数函数：

z=(1+xy)y=eyln(1+xy)

现在外层是 e□，求导还是 e□，只需再乘里面那个乘积 yln(1+xy) 对 y 的导数（用乘积法则，ln(1+xy) 对 y 求导得 x1+xy）：

∂z∂y=(1+xy)y[ln(1+xy)+xy1+xy]

老师对这一类题的评价是：「幂指函数取 eln，这不是常见的处理方法吗？这不就是一元函数求导吗？」

例 418:08设 f(x,y)=x+(y−1)arcsinxy，求 fx(1,1) 与 fxx(1,1)。

思路：先代入能当常数的那个变量，把一整个因子压成零

硬做会很麻烦：arcsinx/y 求导要连用链式法则。但对 x 求偏导时，y 是常数、可以先代 y=1。代进去之后 (y−1)=0，第二项整个消失：

f(x,1)=x+0=x

于是它退化成一元函数 x，求导两次都极简单：

fx(1,1)=(x)'|x=1=1,fxx(1,1)=0

19:19老师示范这一步时特别强调：「是对 x 求偏导的时候 y=1 可以代入」——代入的正是定义要求固定的那个变量，所以合法。他还补了一句判断口诀：「这种题偶尔考试的时候也会出，因为真求偏导太麻烦，先代入是允许的。」

这一步最容易错

把 x=1 也一并代进去，再对 x 求导。那就成了一元函数里「先代入再求导」的老错误——自变量被钉死，导数必然是 0，而正确答案是 1。能提前代入的只有「要当常数的那个变量」：求对 x 的偏导可以代 y，不能代 x；求对 y 的偏导反过来。

例 514:59设 u=xy/z（x>0），求 ∂u∂x、∂u∂y、∂u∂z。

思路：三元与二元一个道理——对谁求偏导，另外两个全当常数
  • 对 x：y,z 是常数，y/z 是常数指数，xy/z 是幂函数：
∂u∂x=yzxyz−1
  • 对 y：x,z 是常数，xy/z 是指数函数，指数对 y 求导得 1z：
∂u∂y=xyzlnx⋅1z=lnxzxyz
  • 对 z：还是指数函数，但指数 yz 对 z 求导是 −yz2：
∂u∂z=xyzlnx⋅(−yz2)=−ylnxz2xyz

16:02老师写完之后的小结很实在：整理的原则是「尽量避免歧义」——题目里相乘的地方要把 lnx 之类的因子放到后面写清楚，别让人误读成指数的一部分。

zxx
先 x 后 x，不是混合偏导
zxy

zyx
先 y 后 x
zyy

定理（本节唯一考点）

二阶混合偏导数在连续的条件下与求导次序无关。

考试就考「连续」两个字：写成「若存在则相等」是错的。

要背的例题结果

  • z=x3y2−3xy3−xy+1：zxy=zyx=6x2y−9y2−1。
  • z=(1+xy)y：对 x 是幂函数得 y2(1+xy)y−1；对 y 要先化成 eyln(1+xy)。
  • u=xy/z：ux=yzxyz−1，uy=lnxzxyz，uz=−ylnxz2xyz。
  • 反例 f=xy(x2−y2)x2+y2：原点处两个混合偏导是 −1 与 1。

两个坑

  • ∂2z∂y∂x 与 zxy 是同一个：一个从右往左读、一个从左往右读。
  • 求二阶时必须建立在已求出的一阶偏导之上，别回头对原函数重求一遍。
