P109【黑板】极坐标下图形面积

一句话核心

本页是第 12 章（定积分的应用）的复习精讲课。极坐标求面积只有一条公式——「小扇形面积 12ρ2dθ，把 θ 从头扫到尾」。公式一眼就会，全部难点都压在同一个动作上：从原点引一条射线转一圈，看它什么时候扫进阴影、什么时候扫出阴影，这进出的两个角度就是 α 与 β。积分限一旦定错，后面算得再漂亮也全废。新授课细节见 定积分应用（求面积-极坐标）。

一、知识速查：两个字母，一条转换公式

00:00老师先用一个很生活的场景说清极坐标：在直角坐标里，你告诉别人「顺着 x 轴正方向走一米，再顺着 y 轴正方向走两米」，他就找到你了。所以要找一个人，你得带一把直尺、一个指南针——直尺量远近，指南针定方向。极坐标就是把这个思路换一个顺序：先定方向，再量远近。

θ（极角）
01:11从 x 轴正半轴出发，沿逆时针转过的角度。转满一圈又回到原处，所以严格定义里 θ∈[0,2π)——也就是 2π 这个角取不到。但老师说做题时不必这么严，θ 完全可以取负值。
ρ（极径）
02:12这个点离原点有多远，所以 ρ≥0。04:06老师说得很实在：我们国内的教材一律取 ρ≥0，国外教材里有 ρ<0 的写法，那其实是往反方向走，我们不需要。

04:42热身用的是几个最简单的点：(1,0) 就是 θ=0、ρ=1；(0,1) 是 θ=π2、ρ=1；(−1,0) 是 θ=π、ρ=1。注意第三个：直角坐标里的 −1 消失了，它「藏」进了角度里——这正是极坐标的特点：位置靠角度和距离两个量合成，不必再用负号表达。

07:12同一个点的两套坐标之间，靠一个直角三角形联系。斜边是 ρ，两条直角边分别是 x 和 y，于是对边比斜边、邻边比斜边：

x=ρcosθ,y=ρsinθ,ρ2=x2+y2,tanθ=yx

这四个式子必须条件反射。前两个负责「极坐标换成直角坐标」，后两个负责「直角坐标换成极坐标」。老师说这就够了，不用记更多。

08:53区域的极坐标写法：为什么先写角度、后写距离

直角坐标里描述一块区域，习惯是「x 从几到几，y 从几到几」。极坐标里顺序要反过来：先问「这个区域占多大角度」，再问「在这个角度上，点能走到多远」。

拿四分之一个圆面（半径 1、第一象限）做例子。08:53角度部分：射线从 x 正半轴开始转，转到 y 正半轴就停，所以 0≤θ≤π2。距离部分：在任意一条射线上，最近的点就在原点，ρ=0；最远的点踩在圆周上，ρ=1。所以 0≤ρ≤1。10:26再看一个圆环（内半径 1、外半径 2）：射线要转满一整圈，0≤θ≤2π；距离则从 1 到 2。

「角度管方向、距离管远近」这句话在描述区域时特别顺手——因为很多曲线的边界天然就是「ρ 从某个值到某个值」。

二、知识速查：面积公式 S=12∫αβρ2(θ)dθ

12:13推导还是那套熟办法：切细、近似、累加。设曲线由 ρ=ρ(θ) 给出，θ 从 α 转到 β。在角度上取一小段，让 θ 变到 θ+dθ，看两条挨得极近的射线夹出来的那一小片。

  1. 看清这一小片是什么形状。12:13两条边都是 ρ（因为片足够窄，ρ 的变化可以忽略），夹角是 dθ——它就是一个小扇形。严格说它并不规则（外缘是弯曲的曲线而不是圆弧），但片一窄，这点差别就是高阶小量。
  2. 算这个小扇形的面积。15:02整圆面积是 πρ2，对应圆心角 2π；现在圆心角只有 dθ，占了整圆的 dθ2π，所以
    dS=πρ2⋅dθ2π=12ρ2dθ
  3. 累加。16:43把 θ 从 α 一路走到 β，把这些小扇形加起来就是总面积。
S=12∫αβρ2(θ)dθ

16:43老师特意强调了他不喜欢死背公式，喜欢现场推一遍：「你想，我为什么非要背它？推一遍多踏实。」这个推法只要三行，而且顺手把三处易错点一起记住了：被积的是 ρ2、前面有个 12、积分变量是 θ。

三、本页唯一的难点：积分限怎么定

17:31极坐标求面积没有「X 型还是 Y 型」要选，只有一件事必须想清楚：θ 从哪个角转到哪个角。老师给的判据只有一句：

定限判据：让射线扫一遍

想象从原点射出一条射线，像雷达一样转起来。射线「扫进」阴影的那个角度是 α，「扫出」阴影的那个角度是 β。

  • 阴影绕原点整整一圈 → α=0、β=2π。
  • 阴影被两条射线夹住 → 直接抄这两条射线的角度。
  • 阴影只占一个小扇区 → α、β 就是扇区两条边的角度。

一个立刻能用的自检：β−α 绝不能超过 2π。超过了一定是定限错了。

17:31为什么这一条最难？因为在直角坐标里，积分限往往能从题目给的方程里「读」出来（x 从 0 到 1，白纸黑字写着）；而极坐标里那个角度范围常常要靠画图才知道。这就是为什么老师说「求面积、求体积，第一件事永远是画图」。

接着要处理一个更隐蔽的问题：有些曲线只在某个角度范围内才存在。比如 ρ=2acosθ，当 cosθ<0 时算出来的 ρ 是负的——按我们教材 ρ≥0 的约定，这一段不算数，所以 θ 必须限制在 [−π2,π2]。反过来，心形线 ρ=a(1+cosθ) 在整个 [0,2π] 上 ρ 都非负（最小也只是 0），所以它一路走到底、不需要分段。

曲线极坐标方程θ 的范围为什么是这个范围
心形线ρ=a(1+cosθ)0→2π全程 ρ≥0，一圈闭合
圆（过原点，圆心在 x 轴）ρ=2acosθ−π2→π2cosθ≥0 才有 ρ≥0
圆（过原点，圆心在 y 轴）ρ=2asinθ0→πsinθ≥0 才有 ρ≥0
双纽线（两叶）ρ2=a2cos2θ−π4→π4 与 3π4→5π4需 cos2θ≥0，两段各画一叶
阿基米德螺线ρ=aθ0→2π转一圈就停（题目给定）

这张表要看的不是「背下角度」，而是最后那一列的理由。五个范围里，有一个是题目指定的（螺线），其余四个全都是「ρ 必须非负」逼出来的。把这句理由记住，以后遇到陌生曲线也能自己算区间。

四、画极坐标草图的技巧：先描几个特殊角

17:31同学最常见的抱怨是「这图我画不出来」。老师的办法很朴素，也很有效：别想着一次画准，先挑几个特殊角，把点一个个描出来，再用光滑曲线连起来。

  1. 挑角。通常取 0、π6（或 π4）、π2、2π3、π——这些角上的 cos、sin 值都很好算。
  2. 算 ρ。把每个角代进 ρ(θ)，得到「沿这条射线要走多远」。
  3. 描点。从原点沿那条射线量出对应长度，点一个点。
  4. 连线并用对称性省事。21:48很多曲线关于极轴对称、或关于 x 轴对称，描一半就够，另一半照镜子。

18:46螺线那一题就是这么做的。ρ=aθ 里 a>0，所以角度一大、距离就大：θ=π2 时 ρ=aπ2；θ=π 时 ρ=aπ，是前一个的两倍；19:57θ=2π 时 ρ=2aπ，是第一个的四倍。「角度翻倍、距离也翻倍」——这就是一次函数在极坐标里的样子，一条由内向外甩出去的螺旋线。

五、三道例题

例 117:31设阿基米德螺线 ρ=aθ（a>0），求它从 θ=0 到 θ=2π 这一段与极轴围成的阴影面积。

思路：先画图确认形状，再定限，最后代公式

老师说这道题「其实挺简单，就是这个图大家刚开始可能不太好理解」。所以第一步不是积分，是描点看形状。18:46取 θ=π4 会得到 ρ=aπ4——一个「零点儿几」的数；19:57取 θ=2π 得到 ρ=2aπ≈6.28a。角度越大、距离越大，所以曲线是从原点一路往外甩的螺旋线。

题目已经把 θ 的范围给死了（0 到 2π），所以 α=0、β=2π，不需要再讨论。

代入公式

ρ(θ)=aθ，先平方：ρ2=a2θ2。这里的 a 是题目给的正常数，积分时提到外面去：

S=12∫02πa2θ2dθ=a22[θ33]02π=a26⋅8π3

上限代入 (2π)3=8π3，下限代入是 0。所以

S=43a2π3
这一步最容易丢分

把 ρ=aθ 直接写进被积函数，忘了平方。写成 12∫02πaθdθ 会得到 aπ2，比正确答案小了一大截，而且小得很「合理」，不容易自己发现。扇形面积正比于半径的平方，这个平方是公式的灵魂。

把 a 当成变量。a 是常数，∫a2θ2dθ 里 a2 直接提出来，不影响计算。

例 221:48求心形线 ρ=a(1+cosθ)（a>0）所围图形的面积。

思路：用对称性，把「一圈」砍成「半圈乘 2」

21:48老师先描了三个点：θ=0 时 cos0=1，ρ=2a（最远）；θ=π2 时 cosπ2=0，ρ=a；θ=π 时 cosπ=−1，ρ=0（回到原点）。距离一路变小直到归零，然后 θ 从 π 走到 2π 时再对称地长回来。

所以这条曲线的上半支（0≤θ≤π）与下半支（π≤θ≤2π）形状完全相同，面积也相同。与其从 0 积到 2π，不如只算上半支再乘 2：

S=2⋅12∫0πa2(1+cosθ)2dθ=a2∫0π(1+cosθ)2dθ

那个「2⋅12」正好抵消——24:58老师说这一步「二跟二分之一消掉」，是个常见的小便宜。

把平方拆开，逐项积

(1+cosθ)2=1+2cosθ+cos2θ，三项分开处理，每一项都有省事的办法：

  • ∫0π1dθ=π（就是区间长度）；
  • ∫0π2cosθdθ=2[sinθ]0π=0（sinπ=sin0=0）；
  • ∫0πcos2θdθ 不能直接积，先用降幂公式 cos2θ=1+cos2θ2，得 π2+[sin2θ4]0π=π2。

三项相加：π+0+π2=3π2。于是

S=a2⋅3π2=32πa2

25:53老师在这里说了一句关于 cos2θ 的话：遇到它就得降幂，然后 cos2θ 那一项在整周期上又会积掉——这个套路在极坐标题里出现得极频繁，值得单独记一笔。

如果老老实实从 0 积到 2π 会怎样

也能算对，只是多做一遍同样的活：∫02π(1+cosθ)2dθ=2π+0+π=3π，再乘 a22 得 32πa2，与上面一致。对称性不是必需的，但它能省掉一半代入。不过要小心：只有在上下两半真的完全对称时才能这么省，曲线不对称就不能乱乘 2。

例 3求圆 ρ=2acosθ（a>0）所围图形的面积。这道题专门考「积分限怎么定」。

思路：先用「ρ 必须非负」把角度范围筛出来

这道题照搬螺线、心形线的做法就会翻车——因为 ρ=2acosθ 在 cosθ<0 时是负的。按我们教材 ρ≥0 的约定，那些角度上根本没有点，所以角度范围必须由「cosθ≥0」定出来：

cosθ≥0⇒θ∈[−π2,π2]

这就是 α=−π2、β=π2 的来历。注意这里出现了一个负的积分下限，这是极坐标题里很正常的现象，不用害怕。

代入公式

ρ2=(2acosθ)2=4a2cos2θ，所以

S=12∫−π/2π/24a2cos2θdθ=2a2∫−π/2π/2cos2θdθ

还是用降幂公式。cos2θ=1+cos2θ2，其中 cos2θ 在长度为一个周期的区间上积分为 0，剩下 12⋅π=π2：

∫−π/2π/2cos2θdθ=π2
S=2a2⋅π2=πa2
结果对不对？一眼就能自检

ρ=2acosθ 两边同乘 ρ：ρ2=2aρcosθ，再用转换公式把 ρ2=x2+y2、ρcosθ=x 代进去，得到 x2+y2=2ax，配方就是 (x−a)2+y2=a2——它是一条圆心在 (a,0)、半径为 a 的圆，面积当然是 πa2。

这个「把极坐标方程翻译回直角坐标」的动作，是极坐标题最好用的免费验算。算完形状和面积，回头看一眼对不对，比重新积一遍快得多。

这道题的两个坑

一、角度范围照抄成 0→2π。那样等于把整条曲线走了两遍（θ 转过 π2 之后 ρ 变成负值，其实是在反方向又描了一遍同一段弧），算出来会正好是正确答案的 2 倍。

二、看到下限是 −π2 就以为错了，硬改成 π2。极坐标里角度可以从负值起算（x 轴下方就是负角），题目没说不许。

六、易错清单

  • 被积函数忘了平方。公式里是 ρ2 而不是 ρ。例 1 里写漏平方会得到 aπ2，答案小一大截。
  • 丢了前面的 12。它来自「小扇形面积占整圆的 dθ2π」，是公式的组成部分。
  • 积分限凭感觉写。β−α>2π 一定错；曲线在某段上 ρ<0 时那一段不算数，要用「ρ≥0」筛出真正的区间（例 3）。
  • 该乘 2 时忘了乘，不该乘时乱乘。心形线上下对称，可以算一半乘 2；曲线不对称就只能老老实实积一圈。
  • 角度制、弧度制混用。扇形面积公式建立在弧度制上，题目给度数要先乘 π180。
  • 两条曲线夹住的阴影用「相减再平方」。极坐标里是平方相减：ρ外2−ρ内2（见 定积分应用（求面积-极坐标）），不是 (ρ外−ρ内)2。
记忆入口 · 一眼回忆

一句话

极坐标求面积 = 把阴影切成无数小扇形，每片 12ρ2dθ，再把 θ 从头扫到尾。

一条链

画图 先描几个特殊角→ 定限 射线扫进扫出得 α、β→ 写 ρ(θ) 再平方→ 乘 ½ 积分 得面积

公式

S=12∫αβρ2(θ)dθ

要背的

  • 被积的是 ρ2，前面有 12，积分变量是 θ——三处错一处整题废。
  • 转换公式：x=ρcosθ、y=ρsinθ、ρ2=x2+y2、tanθ=yx。
  • 角度范围靠「ρ≥0」筛：ρ=2acosθ 只能取 [−π2,π2]；心形线全程非负，所以走满 0→2π。
  • 常见结果：心形线 32πa2、圆 ρ=2acosθ 得 πa2、螺线 ρ=aθ 从 0 到 2π 得 43a2π3、双纽线一叶 a22。
  • ∫cos2θdθ 一律用降幂公式 cos2θ=1+cos2θ2，cos2θ 那项在整周期上直接积掉。

两个坑

  1. 积分限当题目会给。除了螺线那种明说范围的，其余都要自己从「ρ≥0」和图形上算出来。
  2. 忘了平方或忘了 12。这两个错误算出来的答案都很「像样」，很难自己察觉——所以列完式子先低头核对一眼公式。
