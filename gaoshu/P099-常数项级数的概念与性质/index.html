P099常数项级数的概念与性质：无穷项相加，归结为部分和数列的极限

一句话核心

无穷级数说白了就是「把一列数 u1+u2+⋯ 一直加下去」。本章的核心思想是：级数敛散性 = 它的部分和数列 Sn 有没有极限。两个基准级数必须刻进骨头里：几何级数 ∑aqn（|q|<1 收敛）与调和级数 ∑1n（发散）。

从数列到级数

00:01高中我们学过等差数列、等比数列，那里研究的是「一列数」本身。级数研究的是另一件事：把这一列数一直加下去。高中见的是有限和；这里把它推向无穷，问题就完全变了——有限和永远存在，无穷和却可能「加不出一个固定数」。

定义 · 常数项无穷级数

给定数列 u1,u2,u3,…，把它的各项依次相加得到的表达式

∑n=1∞un=u1+u2+u3+⋯+un+⋯

称为（常数项）无穷级数，un 叫一般项（通项）。每一项都是常数；若项里带 x 就不是常数项级数，那是后面的幂级数。

为什么要先取前 n 项的和

03:51「无穷项相加」没法直接算，但「前 n 项相加」是可以算的。记

Sn=u1+u2+⋯+un

Sn 叫部分和，它本身又是一个数列 {Sn}。于是「无穷相加」这件事，被我们翻译成了「看数列 {Sn} 当 n→∞ 时有没有极限」。本章全部问题，归根结底都是部分和数列的极限问题。

收敛与发散：只看部分和数列

定义 · 收敛 / 发散

若部分和数列 {Sn} 有极限 limn→∞Sn=S（S 为有限常数），则称级数收敛，S 叫级数的和，记作 ∑n=1∞un=S。

若 {Sn} 没有（有限）极限，则称级数发散。

一个必须纠正的说法

老师特意强调：当极限是「无穷大」时，属于极限不存在的情况，不能说「极限是无穷大」。1+1+1+⋯ 趋于无穷，它是发散，不是「收敛到无穷」。

为什么研究「部分和」而不是「通项」

通项 un 只告诉你「第 n 项多大」，却回答不了「无穷项加起来会不会爆炸」。真正承载「无穷和」命运的是 Sn=u1+⋯+un 这个累加过程：它要么被某条水平线封顶（收敛），要么一路涨穿天花板（发散）。所以判断敛散，第一动作永远是写下 Sn、看它的极限，而不是盯着 un 发呆。本章后面所有判别法，本质上都是在绕开「直接求 Sn 的极限」这件难事。

基准级数一：几何级数（等比级数）

06:28例 1：

a+aq+aq2+⋯+aqn+⋯=∑n=0∞aqn

当 q≠1 时，高中就给过部分和公式：

Sn=a1−qn1−q
08:13四种情形，结论要刻进骨头
  • |q|<1：qn→0，故 limSn=a1−q，级数收敛，和为 a1−q。
  • |q|>1：qn→∞，Sn 无有限极限，发散。
  • q=1：级数变成 a+a+a+⋯，Sn=na→∞，发散。
  • q=−1：级数变成 a−a+a−a+⋯；n 偶时 Sn=0，n 奇时 Sn=a，奇偶子列极限不同，发散。

只有 |q|<1 这一种情况收敛，且和一定是 a1−q。这条结论后面会反复当「标尺」用。

几何级数之所以是「标尺」，是因为它收敛得干脆利落：只要公比绝对值小于 1，不管前面乘多大一个常数 a，无穷和都被锁死在 a1−q 这个值上。后面学比较判别法、比值判别法时，我们反复拿陌生级数去和「收敛的等比」或「发散的调和」比快慢，几何级数就是那个「收敛标杆」的代表。

例 212:03判断 ∑n=1∞n=1+2+3+⋯ 的敛散性。

解：直接看部分和

Sn=1+2+⋯+n=n(n+1)2，当 n→∞ 时 Sn→+∞，没有有限极限，所以发散。这也是一个提醒：项越加越大的级数，不用犹豫，必发散。

推广：通项不趋于 0，必发散

收敛的必要条件是 un→0，它有个更常用的「逆否版本」：只要 un 不趋于 0（含极限不存在），级数一定发散。所以看见通项极限不存在（如 (−1)n−1nn+1，奇偶子列分别趋于 1 与 −1），或通项明显不趋于 0（如 un=1、un=n），连判别法都别上，直接判发散——这是整章最快的「一票否决」。

同时记住：limun=0 只是门票，不是合格证。下面调和级数就会演示：通项乖乖趋于 0，级数照样发散。两者千万别混。

例 312:55判断 ∑n=1∞1n(n+1) 的敛散性。

解：拆项相消（小学就学的「裂项」）

因为 1n(n+1)=1n−1n+1，所以

Sn=(1−12)+(12−13)+⋯+(1n−1n+1)=1−1n+1

limn→∞Sn=1，故级数收敛，和为 1。这个级数以后在「比较判别法的极限形式」里会出现——它和 1n2 是同阶无穷小。

裂项相消的通用套路

例 3 的「拆开正负抵消」不是巧合，而是一类题型：un=1n(n+k) 总能写成 1k(1n−1n+k)，求和时中间项全消，只剩首尾，极限立刻出来。见到分母是两个因式相乘、且差一个常数 k 的，先想裂项，往往比任何判别法都快。这一招和下一页的「比较/极限形式」不冲突：裂项是直接求和，比较法是绕开求和——能直接求和就别绕路。

级数的性质

性质一 · 线性

若 ∑un=S，则 ∑kun=kS（k 常数）。若 ∑un=S,∑vn=T，则 ∑(un±vn)=S±T。

性质二 · 加括号保收敛（但反过来不成立）

收敛的级数任意加括号后仍收敛且和不变。道理是：加括号后的部分和数列，是原 {Sn} 的一个子列，而收敛数列的任一子列都收敛到同一极限。

一个危险的逆命题

「加括号后收敛 ⇒ 原级数收敛」是错的。反例：1−1+1−1+⋯ 是发散的（奇偶子列分别趋于 1 和 0）；但加括号成 (1−1)+(1−1)+⋯ 后每项都是 0，整体收敛到 0。反过来有一条是成立的：若加括号后发散，则原级数必发散。

性质三 · 敛散性与有限项无关

去掉、增加或改动有限项，不改变级数的敛散性。但注意：若原级数收敛，改动有限项后和可能改变（去掉前 4 项就少了那 4 项的和）。所以「敛散性不变、和不变」是错的，只有前者一定成立。

直觉上，增删有限项相当于在部分和数列 {Sn} 里改掉前有限项的值，而极限是否存在、等于多少，只取决于 n 充分大之后的行为，前面那几项撼动不了它。因此有限项只是「换了个起点」，不影响最终的封顶与否。

性质四（必要条件）· 收敛 ⇒ 通项趋于 0

若 ∑n=1∞un 收敛，则 limn→∞un=0。

证明：un=Sn−Sn−1，两边取极限得 limun=limSn−limSn−1=S−S=0。

两个容易漏的推论（考试常考）

① 一个发散 + 一个收敛 = 发散。用反证法：若 ∑(un+vn) 与 ∑vn 都收敛，则由线性性质 ∑un=∑(un+vn)−∑vn 也应收敛，与「un 发散」矛盾，故必发散。

② 两个发散的 ± 不确定。例如 1+1+1+⋯ 与 (−1)+(−1)+(−1)+⋯ 都发散，相减得 2+2+2+⋯ 仍发散；但 1−1+1−1+⋯ 与 0+0+0+⋯ 不能这样随便套结论。

③ 必要条件要会反着看例子。若 un=(−1)n−1nn+1，奇偶子列分别趋于 1 与 −1，极限不存在（更不趋于 0），由性质四的逆否立即判发散。看见通项本身不趋于 0，别再犹豫。

19:17这条性质怎么反过来用

原命题成立，但逆否命题最有用：若 un→0，则级数一定发散。所以做题时第一反应应当是看通项趋不趋于 0——不趋于 0 立即判发散，连后面的判别法都不用上。

但千万记住：un→0 只是必要条件，不是充分条件。通项趋于 0，级数照样可能发散。下面这个反例是整章最重要的「反面教材」。

基准级数二：调和级数（发散）

39:09调和级数

∑n=1∞1n=1+12+13+14+⋯

通项 1n→0，但它发散。下面这个证明是标准的，必须会：

证明 · 调和级数发散

考虑 S2n−Sn（第 n+1 项到第 2n 项之和）：

S2n−Sn=1n+1+1n+2+⋯+12n

这 n 项里每一项都 ≥12n（因为分母最大是 2n），于是

S2n−Sn>n⋅12n=12

若级数收敛，则 S2n→S 且 Sn→S，二者之差应趋于 0；但上式表明差恒大于 12，矛盾。故调和级数发散。

「调和」二字与速度

「调和」这个名字来自音乐里的调和律，和数学推导无关，不用纠结。老师真正想让大家记住的是一句话：1n 趋于 0 太慢，慢到无穷项累加仍然会发散。后面判断级数时，「它趋于 0 够不够快」是最核心的直觉——而调和级数就是这条直觉的底线标尺。

老师打了个很形象的比方：有人晚上去跑步，跑了半圈很辛苦，一称只减了 0.001；回头赶紧犒劳自己，吃了两个鸡腿、四个馒头——失去的那点热量，远跟不上吃进来的。1n 就像这种「减得太慢」的进程：每一项都在变小、都在「努力趋于 0」，可因为慢得离谱，无穷多项加起来的总量还是一路膨胀、压不住。所以「趋于 0」只是门票，真正的生死线是你趋于 0 的速度。

42:55两个基准级数为什么是「标尺」

几何级数 ∑aqn（|q|<1 收敛）和调和级数 ∑1n（发散）是后面所有判别法的比对基准：见到一个陌生级数，往往就是拿它去和「收敛的等比」或「发散的调和」比快慢。把这两个的敛散性、和、证明都钉死，下一页的判别法才有抓手。

记忆入口 · 一眼回忆

一句话

级数敛散 = 部分和数列 Sn 有无有限极限。收敛的必要条件是 un→0，但不充分——调和级数是反例。

两个基准级数

  • 几何级数 ∑aqn：|q|<1 收敛，和 a/(1−q)；q=±1 或 |q|>1 发散。
  • 调和级数 ∑1/n：通项 →0 但发散（证：S2n−Sn>1/2）。

四条性质

  • 线性：收敛级数可乘常数、可逐项加减。
  • 加括号保收敛；但加括号收敛 ⇏ 原级数收敛。
  • 增删有限项不改敛散性（和可能变）。
  • 收敛 ⇒ un→0；其逆否：不趋于 0 ⇒ 发散。

两个坑

  • 「极限是无穷大」= 不存在 = 发散，别嘴上说是「收敛到无穷」。
  • un→0 只是必要不充分——看见趋于 0 千万别直接判收敛。
