P145【黑板】正项级数的敛散性：四件武器，和一张「谁猛谁不猛」的阶梯

一句话核心

黑板课的第二站，正项级数（un≥0）的判敛工具箱。比较判别法听着好用，实际上「放还是缩、跟谁比」两个难题让我们做题时最后一个才考虑它；真正上场的是比较判别法的极限形式（配「抓大头」与「等价无穷小替换」两把钥匙）、比值和根值。而全课的灵魂是一句话：级数敛散取决于通项趋于 0 的速度——谁猛谁不猛，谁在分母上谁就赢。

先给正项级数一颗定心丸

00:00正项级数的定义只有一句：每一项 un≥0。老师特意点了一下：等于 0 也算正项级数，因为我们做的题里几乎不会出现 un=0 的情形，所以图省事，直接说「每一项都是正的」也不会错。

为什么先看它？因为 un≥0 让部分和 Sn=u1+⋯+un 每加一次都不减小：

S1≤S2≤S3≤⋯

于是「单调有界数列必有极限」这条老工具立刻能用：

02:53定理 · 正项级数收敛的充要条件

正项级数 ∑un 收敛 ⟺ 它的部分和数列 {Sn} 有上界。

什么是「有界」——老师不许用定义回答

02:53老师追问：「什么叫有界？」然后自己给了一个不许用定义的答案：能找一个东西把它框住，就叫有界。单调增的 Sn 要么被框在某个点下面、无限靠近它（这就是有极限），要么一路朝右走穿过一切框（这就是无界）。只有这两种结局，没有第三种。

04:57但这条定理存在感很低，老师讲得毫不客气：「我们其实从来不用的——因为证明一个有界，你会证吗？你好像不会。」它真正的价值是给我们一句世界观：正项级数的部分和要么封顶（收敛），要么冲破天花板（发散）。所以正项级数的问题不是「会不会震荡」，而是「上界在哪」。下面所有判别法，都是在绕开「直接求 Sn 极限」这件事。

武器一：比较判别法（讲义里的第一个，做题时的最后一个）

05:41定理 · 比较判别法

设 ∑un、∑vn 都是正项级数，且 un≤vn。则

  • 若 ∑vn 收敛，则 ∑un 也收敛；
  • 若 ∑un 发散，则 ∑vn 也发散。
05:41瘦子 / 胖子记忆法（老师原话）

把收敛的级数想成瘦子，发散的想成胖子，四句话立刻出来：

  • 比瘦子还瘦（un≤vn，vn 收敛）→ 也是瘦子 → 收敛。
  • 比胖子还胖（un≥vn，vn 发散）→ 也是胖子 → 发散。
  • 比瘦子胖（un≥vn，vn 收敛）→ 不知道。
  • 比胖子瘦（un≤vn，vn 发散）→ 不知道。

老师用班里同学打比方：「有个男生 80 斤，我比他还瘦，75 斤，那我肯定也是瘦子。」反过来，「我 81 斤，比 80 斤的瘦子胖——那我算瘦算胖？不知道」；「那个 280 斤是胖子，我 270 斤，比胖子瘦——那我算瘦算胖？也不知道。」只有前两句能下结论，后两句一定判不了，而考试偏偏最爱拿后两句做干扰项。

14:32判断题翻车现场：漏了「正项」两个字

题目：「已知 un≤vn 且 ∑vn 收敛，则 ∑un 收敛。」听起来完全符合「比瘦子还瘦」，但这是错的。

错在哪？比较判别法要求两个级数都是正项。为什么非要正项？14:32老师解释得很干脆：vn 收敛意味着它右边有界；正项又保证 un≥0，左边也有界。左右两头都框住了，un 才被夹在中间出不去。少了「un≥0」这一半，左边那道界就没了。

15:44反例：取 vn=(12)n（收敛），un=−1。显然 un≤vn 成立，可 ∑un=(−1)+(−1)+⋯ 发散。老师提醒：这类判断题、以及「比瘦子胖」「比胖子瘦」两个迷惑选项，都很容易一不小心就选错。

11:36这个方法的两个困难

老师说得很坦率：比较判别法看着好用，实际做题有两个拦路虎。第一，到底该放还是该缩——要下结论，你得决定自己是要「≤ 一个收敛的」还是「≥ 一个发散的」，方向选错了整道题白做；第二，跟谁比——那个「收敛的瘦子」或「发散的胖子」题目不会给你，得自己找。所以结论是：它是我们讲课时的第一个方法，却是做题时最后一个考虑的方法。真正好用的一会儿就来。

基准中的基准：p 级数

17:00比较判别法要「跟谁比」，所以必须先把标尺备好。整个正项级数的第一把标尺就是 p 级数：

定理 · p 级数
∑n=1∞1np(p>0):p>1收敛;p≤1发散

其中 p=1 就是上一节的调和级数 ∑1n，它是这条分界线上的那一点。

20:15老师把一串具体的 p 级数连着写在黑板上，让全班把它们排成一列比大小：

级数对应的 p结论和 1/n 比谁大
∑1n3p=13发散更大
∑1np=12发散更大
∑1np=1发散（调和级数）—— 分界线
∑1n3/2p=32收敛更小
∑1n2p=2收敛更小
∑1n3p=3收敛更小

武器二：比较判别法的极限形式（真正上场的那一个）

28:54老师先吐槽了一句：书上的写法把几种情形捆在一起，「我不是特别喜欢——学数学的喜欢把结论弄得一清二楚」。于是他把书上的定理重写了一遍：

定理 · 比较判别法的极限形式

设 ∑un、∑vn 都是正项级数，limn→∞unvn=L。

  • 0<L<+∞ ⇒ 两个级数同敛散（这是最常用的一条）；
  • L=0 且 ∑vn 收敛 ⇒ ∑un 收敛；
  • L=+∞ 且 ∑vn 发散 ⇒ ∑un 发散。

注意：老师把书上的「L≥0」改成了 L>0，让第一条的 L 是严格非零的正数——这样三句话之间不再粘连，看着就清楚。

31:08用工资的量级来理解三句话

「L 是 10000 倍也算同敛散？这也太离谱了吧。」老师用工资解释：一个月 6000 和一个月 8000，差别大吗？在量级上其实是一回事；可你一个月 6000、你同学一年收入 8 个亿——这才叫差别。判断敛散性比的就是这种量级，不是具体的倍数。所以 0<L<+∞ 意味着两者是同一量级，趋于 0 的速度一样快，敛散性当然一样。

另外两句也是同一套逻辑：L=0 说明 un 差不多是 vn 的「零倍」，比已经收敛的 vn 更快地趋于 0——「比瘦子还瘦，肯定也是瘦子」。L=+∞ 说明 un 是 vn 的「无穷倍」，比已经发散的 vn 还猛，当然更发散。

例 135:56判断 ∑n=1∞1n(n+1) 的敛散性。

先看放缩法为什么让人「傻眼」

这题书上是这么做的：把 n 放大成 n+1，分母变大、整体变小，得到 1n(n+1)>1n+1，而右端是调和级数去掉第一项、发散，「比胖子还胖」⇒ 发散。

可26:31有同学自己换了个方向：把 n+1 缩成 n，得到 1n(n+1)<1n，「比胖子瘦」——什么都判不出来。老师当场点破：「你到底要放还是要缩？没有人知道。」这就是比较判别法的方向难题。

用极限形式一步到位

把它和 1n 比：

limn→∞1/n(n+1)1/n=limn→∞nn2+n=limn→∞11+1n=1

36:56这里用的就是抓大头：分子分母都是 n 的一次量级。极限是非零正数 1，两者同敛散；而 ∑1n 发散，故原级数发散。同一个数、两种做法，第二种一个字都不用纠结。

40:58两把钥匙：抓大头 + 等价无穷小替换

极限形式好用的前提是「vn 找得对」。老师说得很干脆：找 vn 只有两种思想——

  • 抓大头：n 很大时，加不加 1 没有区别。「你有 1 亿块钱的时候，多一块少一块有区别吗？没有。」所以 n+1 直接当成 n，1n2+2 直接当成 1n2。
  • 等价无穷小替换：见到 sin1n、ln(1+1n2)、1−cosπn、tan1n2 这类，先把它们换成主部。

例 21:20:40判断 ∑n=1∞un 的敛散性，其中 un=n+1(1−cosπn)。

思路：一把抓大头 + 一次等价替换，落到 p 级数

先把「大头」抓掉：n→∞ 时 n+1∼n。再用等价无穷小：

1−cosπn∼12(πn)2=π22n2

两件合起来，通项的主部是

n+1(1−cosπn)∼n⋅π22n2=π22n−3/2

1:23:00也就是 p=32 的 p 级数样子。常数 π22 是系数，不影响敛散性（级数性质：常数可以提到求和号外）。因为 p=32>1，原级数收敛。

这一步最容易错

把 n+1 留着不动，直接和 1n2 比。那样算出来是 n+1⋅π22n2，和 1n2 的比值是 n+1→∞，落进 L=+∞ 那一格，反而判不了。老师特意指出：这道题的巧处就在「抓大头」这一步——把 n+1 换成 n，指数 −2+12=−32 才干净地露出来。

45:43一道专门骗人的题

∑n=1∞cos1n。有人一看就想去凑等价无穷小，老师直接说：「我忽悠你的，这么想是不对的。」n→∞ 时 1n→0，所以 cos1n→cos0=1——通项趋于 1，不趋于 0。

由上一节的必要条件（不趋于 0 必发散），这个级数发散。老师借此重申做题的第一动作：「所有的级数，不管正项、任意项还是交错级数，永远都先判断通项是不是趋于零。」这道题如果先去抓大头、凑等价，就彻底上当了。

武器三：比值判别法——自己跟自己比

47:05定理 · 比值判别法（达朗贝尔）

设 ∑un 为正项级数，ρ=limn→∞un+1un。则

  • ρ<1 ⇒ 收敛；
  • ρ>1（含 +∞）⇒ 发散；
  • ρ=1 ⇒ 无法判定。
为什么「自己跟自己比」是第一优先级

老师的比喻非常直白：「你怎么知道自己越来越瘦？每天称一下不就行了——昨天 160 斤，今天 159，明天 158，那肯定在瘦。」比值判别法不用找张三找李四，只跟自己比，所以做题时优先级最高。

ρ<1 意味着后一项大约只有前一项的 ρ 倍：0.5 倍就是「今天 100 斤，明天 50，后天 25」，三天就没了，必收敛。ρ>1 反着来：「今天 10 斤，明天 20，后天 40」，一路胖上去，必发散——老师说「猪胖得也没这么快」。50:05至于 ρ=1，∑1n 和 ∑1n2 的比值极限都是 1，一个发散一个收敛，所以 ρ=1 时比值法彻底失灵：后一项和前一项「差不多」，是可慢慢变大（1.0001 倍）还是慢慢变小（0.99999 倍），看不出来。

例 31:02:21判断 ∑n=1∞n!nn 的敛散性。

思路：先用直觉定方向，再用比值写过程

1:01:26直觉：n! 和 nn 谁猛？n!=n⋅(n−1)⋯2⋅1，每一项都不超过 n；而 nn 是每次都乘 n。所以 nn 更猛，它又在分母上——猜收敛。1:02:21下面用比值把它做实：

un+1un=(n+1)!/(n+1)n+1n!/nn=(n+1)nn(n+1)n+1=nn(n+1)n

整理成熟悉的样子：

nn(n+1)n=(nn+1)n=1(1+1n)n→1e≈0.368<1

1:05:01最后一步用的是第二重要极限。ρ=1e<1，所以级数收敛。

同一条路的另外两个样本

∑(12)n：比值恒为 12<1，收敛。∑3n：比值恒为 3>1，发散——不过这道题其实一眼就能判，因为 3n→∞ 通项不趋于 0，用必要条件更快。∑1n!：比值是 1n+1→0<1，收敛。老师说这三个样本连起来看，就能体会「后一项是前一项的几倍」这个念头有多好用。

武器四：根值判别法——见到 n 次方就开根

1:09:46定理 · 根值判别法（柯西）

设 ∑un 为正项级数，ρ=limn→∞unn。则 ρ<1 收敛，ρ>1 发散，ρ=1 无法判定。

什么时候用它：一个动作就能判断

老师说规律只有一条：通项里出现「某个东西的 n 次方」时用根值。因为 □nn=□，开 n 次根刚好把幂抵消掉；如果写成 n 分之一次方，那个 n 和指数上的 n 一约就没了。典型信号是 (⋯)n 或者 (⋯)n+1、(⋯)n2。

例 41:13:31判断 ∑n=1∞2+(−1)n2n 的敛散性。

思路：先确认它是正项级数，再开 n 次根

(−1)n 不是正也不是负地乱跳，它只有两种取值：n 为偶数时是 +1，为奇数时是 −1。所以分子 2+(−1)n 只可能是 3 或 1——恒为正，这个级数确实是正项级数。

于是开 n 次根：

unn=2+(−1)nn2

1:15:15分子不好直接算，但可以这样想：2+(−1)n 只有 1 和 3 两种取值，是有界的；而 1n→0。由「无穷小乘有界仍是无穷小」，

2+(−1)nn=(2+(−1)n)1/n→e0=1

于是 ρ=12<1，级数收敛。

1:17:00另一条更省事的路：放缩

把 2+(−1)n 统一放大到 3，得 2+(−1)n2n≤32n。右边是常数 3 乘一个收敛的等比级数，收敛；而左边是正项、且「比瘦子还瘦」，所以原级数收敛。这条用的是比较判别法。老师说：「你嫌根值麻烦，这条路也完全可以。」

收尾：拿到一个正项级数，按这个顺序试

1:24:43课的最后，老师把整节课的顺序重排了一遍，并且强调这是他「说了好几遍」的东西：

顺序看什么怎么做
第 1 步通项 un→0 吗不趋于 0 ⇒ 直接判发散（免费的一票否决）
第 2 步有没有「某东西的 n 次方」根值判别法，开 n 次根把幂抵消
第 3 步是不是「自己跟自己比」很方便比值判别法（含 n!、an 的一律先试它）
第 4 步一般形状比较判别法的极限形式 + 抓大头／等价无穷小
第 5 步实在没招了比较判别法（原形），自己放缩

1:27:13老师解释这个顺序的来历：根值之所以排第二，是因为 (⋯)n 这种形状最扎眼，一眼就能认出来；比值排第三，因为它门坎低、不用找别人，但遇到难一点的题常常算到 ρ=1 就死掉——用他的原话，「考试里比较难的题目，你比值是绝对做不出来的，它出的那个 ρ 一定是 1」；极限形式排在后面，却反而是平时使用频率最高的那个（抓大头和等价无穷小两把钥匙）；比较判别法原形垫底，因为放缩方向难定、比较对象难找。

四个高频翻车点

翻车一：非正项级数直接用比较判别法——un 有负项时，「左边那道界」不存在。

翻车二：ρ=1 时比值／根值失效，还硬往下写。∑1n 与 ∑1n2 都是 ρ=1，一个发散一个收敛。

翻车三：上来就抓大头、凑等价，忘了先看通项。∑cos1n 的通项趋于 1，直接判发散，抓大头抓不出收敛。

翻车四：算 p 级数的 p 时把系数也算进去。π22n−3/2 的 p 是 32，前面的系数只管大小、不管敛散。

记忆入口 · 一眼回忆

一条链

第一步 un→0？不趋于 0 直接发散→ 根值 见 n 次方→ 比值 见 n!、an→ 极限形式 抓大头 + 等价

三件武器 & 结论

  • 比较（极限形式）：un/vn→L。L 非零正数 ⇒ 同敛散；L=0 且 v 收敛 ⇒ u 收敛；L=∞ 且 v 发散 ⇒ u 发散。
  • 比值 ρ=limun+1un：ρ<1 收敛，ρ>1 发散，ρ=1 无效。
  • 根值 ρ=limunn：同判据；见 n 次方优先。
  • 比较原形：比瘦子还瘦 ⇒ 收敛；比胖子还胖 ⇒ 发散。另两句判不了。

两把标尺

  • p 级数 ∑1np：p>1 收敛，p≤1 发散（p=1 就是调和级数）。
