P140【黑板】多重积分的应用

一句话核心

这一节没有新思想。老师说「没有什么特别难的技巧，就是你照着公式朝里搬就行」——三个应用（曲面面积、质心、转动惯量）用的是同一套动作：把区域切成小块，让「小块 × 某个与位置有关的量」跟着累加。真正需要刹一脚的只有两处：曲面面积里那个 1+zx2+zy2 是怎么冒出来的（法向量与 z 轴的夹角 γ）；以及球面面积那道例题——被积函数在边界上无界，不能把 r=a 直接代进去。

一、三个应用，一套动作

00:00老师把这一节的性质说得很直白：重积分的应用这部分没有什么特别难的技巧，就是你照着公式朝里搬就行。所以它和前面几讲不一样——三重积分要练「怎么定范围」，这里要练的是「认得出该用哪条公式」。

本节讲三件事：曲面的面积、质心、转动惯量。它们看着不搭界，其实是同一套动作的三个变种：

应用切成什么小块小块乘什么再累加结果
曲面面积 曲面（弯的） 投影面积 dσ 乘「斜的放大率」1+zx2+zy2 曲面面积 S
质心 薄片（平面） 小块质量 μdσ 乘它的坐标 质心坐标 ¯x、¯y
转动惯量 薄片或立体 小块质量乘它到轴距离的平方 转动惯量 I

三行的骨架完全一样：先切小块，再想「这一小块贡献多少」，最后求和取极限。区别只在「乘什么」。难点不在算，而在认得出公式里每一项的来历——认出来了，题就退化成代公式。

二、曲面面积：那个 γ 与那个根号

02:09空间里有一块弯弯曲曲的曲面（「就像我拿的这块抹布」），求它的面积。假设它能写成 z=f(x,y)。

办法还是近似：把曲面切成很多小块，每块都小到「直径趋于零」。任取一块，面积记 ΔA；再把它投影到 xOy 面上，投影面积记 Δσ。老师叮嘱：你自己看书的时候，一定要知道哪一块是 ΔA、哪一块是 Δσ。这两个符号一混，后面全乱。

04:32取法向量时要取与 z 轴正半轴夹角为锐角的那个——朝下的也垂直于曲面，但我们要朝上的这一个。记夹角为 γ。

05:47为什么 Δσ 与 ΔA 之比恰好是 cosγ

老师把这一小块面沿竖直方向挪下去，让它和底下的投影面接触。因为做的是投影，「曲面上那个点」与「投影面上对应点」之间的连线垂直于投影面。

再把立体「稍微转一下」从侧面看：上面是 ΔA、下面是 Δσ，中间是空的。这时会看到一个很舒服的事实——法向量与 z 轴成 γ 角，两个面之间也成 γ 角（两对边分别互相垂直）。在小三角形里 Δσ 是邻边、ΔA 是斜边，比值就是 cosγ——这不是近似，而是两个面夹角的精确关系。

07:05课本第 98 页给了那个方向余弦（法向量取的是向上的那一个）：

cosγ=11+fx2+fy2

代回 Δσ=ΔAcosγ，两边一倒：

dA=1+fx2+fy2dσ

累加（求二重积分）就是整个曲面的面积：

S=∬D1+zx2+zy2dσ

D 是曲面在 xOy 面上的投影区域。结构一眼能懂：先把曲面「摊平」到投影面上，再按每一点的斜率把面积放大回去。曲面越陡（偏导越大），根号越大。自检：曲面是平的（zx=zy=0）时根号变成 1，面积正好等于投影面积。

例 1 球面面积

例 109:16求半径 a 的球面的面积。

思路：先算上半球再乘 2，最后处理一个无界积分

09:16老师说「为了求的方便，就光求上半球，求完以后直接两倍」。上半球 z=a2−x2−y2，投影区域 D 是半径 a 的圆。

先求两个偏导。根号求导要小心，链式法则会带出分母：

∂z∂x=−xa2−x2−y2,∂z∂y=−ya2−x2−y2

平方相加再通分：1+x2+y2a2−x2−y2=a2a2−x2−y2，开方后根号是 aa2−x2−y2。于是

S=2∬Daa2−x2−y2dσ

投影是圆，换极坐标（别忘了那个 r）：

S=2∫02πdθ∫0aaa2−r2rdr
17:26这里必须刹一脚

内层那个一元积分看着很顺：凑微分得 −aa2−r2，把 0 和 a 代进去就完了。但老师说，这个地方「其实就有问题了」。上限 r→a 时 a2−r2→0，被积函数无界——严格说这是一个无界函数的二重积分，直接做是不对的，这也是为什么老师的推导和课本不一样。

19:08正确姿势是把积分的圆缩一点：先取一个半径 B（比 a 略小）的圆，此时函数处处有界、积分才有意义；算完再让 B 从左边逼近 a（老师强调「应该是 A 负」，从左边逼近才不会把端点包进去）。

∬x2+y2≤B2aa2−x2−y2dσ=2πa(a−a2−B2)

19:08令 B→a−，根号那项趋于 0，括号里剩下 a，这一块就趋于 2πa2。别忘了上半球外面还挂着一个 2：

S=2⋅2πa2=4πa2

21:07老师说这个结果还挺有意思的：圆盘面积 πa2，同样半径的球面面积 4πa2——「做一个足球的面，需要那个圆的面积的四倍」。这不是特技：只要被积函数在边界上趋于无穷，都得先换成 B、算完再取极限。

三、质心：按密度加权的平均位置

22:08第二个应用是求质心（重心）。一块平面薄片，密度不必均匀，在点 (x,y) 处密度是 μ(x,y)，问质心在哪。公式是「先加权求和，再除以总质量」：

¯x=∬Dxμ(x,y)dσ∬Dμ(x,y)dσ,¯y=∬Dyμ(x,y)dσ∬Dμ(x,y)dσ
为什么这叫「加权平均」

每小块的质量是 μdσ、位置近似是 (x,y)。分子的 ∬xμdσ 就是「每个小质量乘上它的位置，再全部加起来」，分母 ∬μdσ 是总质量。用总质量再除一遍，就把「按质量加权的和」还原成平均位置。

一维版本高中就见过：两质点的质心是 m1x1+m2x2m1+m2。重积分只是把两个质点换成了无穷多小块。

24:11最常见的简化是薄片均匀——μ 是常数，提到积分号外，分子分母各有一个、直接约掉：

¯x=1A∬Dxdσ,¯y=1A∬Dydσ

A=∬Ddσ 就是薄片的面积。所以均匀薄片的质心与密度大小无关，只与形状有关，这也是它常被叫作形心的原因。

例 2 阴影部分的质心

例 225:08一块均匀薄片是两个圆围出的阴影：大圆 x2+(y−2)2≤4 挖掉小圆 x2+(y−1)2≤1。求它的质心。

思路：先用对称性判掉一个坐标，就只剩一个积分

25:08老师说「首先看 x 坐标，因为它是个对称的，所以 x 坐标一定是零」——两个圆心都在 y 轴上，阴影关于 y 轴对称，所以 ¯x=0，只要求 ¯y。

面积好办：大圆 π⋅22=4π，小圆 π⋅12=π，阴影面积 A=3π。

阴影从第一象限铺到第二象限，θ 从 0 到 π。射线从原点发出，先穿进小圆、再穿出大圆，两条边界都是偏心圆：x2+y2=4y 给出 r=4sinθ，x2+y2=2y 给出 r=2sinθ。于是

∬Dydσ=∫0πdθ∫2sinθ4sinθ(rsinθ)rdr=563∫0πsin4θdθ

内层积完是 563sin4θ；再用 ∫0πsin4θdθ=3π8，分子是 7π。除以面积：

¯y=7π3π=73

检查一下合不合理：29:31阴影在 y 轴上只由 y=2 铺到 y=4，质心一定要落在这段里。73 比 2 大、比 3 小——答案落在阴影的高度范围内，是这次计算没错的最直接证据。

22:08三维有界闭区域完全一样，把面积元换成体积元即可：

¯x=∭ΩxρdV∭ΩρdV

另外两个坐标同理。

四、转动惯量：为什么距离要平方

30:51第三个应用是转动惯量，原始公式是：

I=MR2

质量 M、到轴距离 R 的质点，转动惯量就是它。现在推广到一整块薄片：32:52取一小块，到 x 轴的距离是 |y|、质量近似是 μdσ，把每小块的「质量 × 距离平方」加起来——

Ix=∬Dy2μ(x,y)dσ,Iy=∬Dx2μ(x,y)dσ
32:52距离为什么必须平方，而且为什么绕 x 轴时用 y2

「平方」是原始公式带的，不是临时加的——它衡量的是「转起来有多费劲」：离轴越远的小块，费劲程度按距离的平方涨，所以远处的质量比近处的「更重」。

至于为什么绕 x 轴时用 y2：到 x 轴的距离是 |y|（竖着量），平方后 |y|2=y2，绝对值自动消失。绕 y 轴同理，距离换成 |x|、平方后是 x2。口诀：绕谁转，就用「另一个」坐标的平方。

例 3 半圆薄片绕直径

例 335:46一块半径为 a 的均匀半圆薄片（密度为常数 μ），求它绕直径所在的边（也就是 x 轴）的转动惯量。

思路：套 Ix 的公式，剩下的还是极坐标

35:46题里说了「均匀」，所以 μ 是常数，直接提到积分号外。绕的是直径那条边（x 轴），用 Ix=∬y2μdσ；半圆在 x 轴上方，θ 从 0 到 π、r 从 0 到 a：

Ix=μ∫0πdθ∫0a(rsinθ)2rdr=μ∫0πsin2θdθ⋅∫0ar3dr

这里可以「加小点点」：两个积分的上下限全是常数，各自算完再相乘。∫0πsin2θdθ=π2、∫0ar3dr=a44，相乘得

Ix=πμa48
这一步最容易漏的

忘了面积元素里那个 r。被积函数是 y2=(rsinθ)2，再乘 dσ 里的 r，合起来是 r3sin2θ——指数从 2 变成 3，就是因为多乘了一个 r，这正是 【黑板】二重积分{极坐标} 反复强调的那一条。少一个 r，结果会差一个 a 的量级。

30:51空间有界闭区域同理，只是把「小块」换成体积元、「距离」换成三维距离。绕 z 轴时距离是 x2+y2，平方后根号消失：

Iz=∭Ω(x2+y2)ρdV,Ix=∭Ω(y2+z2)ρdV

记公式只抓一件事：绕哪条轴，就把缺的那两个坐标平方相加——绕 z 轴缺 z，所以是 x2+y2；绕 y 轴则是 x2+z2。

五、易错清单

  • dA 与 dσ 搞混。前者在曲面上、后者在投影面上，之比是 cosγ≤1。
  • 曲面面积漏掉根号。1+zx2+zy2 要「先平方、再相加、再加一、最后开方」。
  • 无界积分硬代端点。例 1 里 r=a 处函数无界，必须先取比 a 略小的 B，算完再取极限。
  • 转动惯量漏 r、距离只写一次。y2 还要再乘上面积元里的 r（例 3）；距离是平方，绕 x 轴用 y2、绕 z 轴用 x2+y2。
