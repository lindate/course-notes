P100常数项级数的敛散性判断：拿到一个级数，先试哪一步

一句话核心

这页是判别法大全。正项级数用比较（含极限形式）、比值（达朗贝尔）、根值（柯西），基准是 p 级数 ∑1/np（p>1 收敛）；交错级数用莱布尼茨；任意项级数先看绝对值（绝对收敛 ⇒ 收敛），绝对值发散再看是否交错（条件收敛）。最有价值的一张表是判别法选用决策表。

先给正项级数一颗「定心丸」

00:00正项级数指每一项 un≥0。它的部分和 Sn 因为每次加非负数，是单调不减的：S1≤S2≤S3≤⋯。于是有：

定理 1 · 正项级数收敛的充要条件

正项级数 ∑un 收敛 ⟺ 它的部分和数列 {Sn} 有上界。

理论很强，实战很少直接用

单调有界必收敛是铁律，但「证明一个有上界」在考试里几乎没人让你硬证。它更大的价值是告诉我们：正项级数的项累加上去，要么封顶（收敛），要么冲破天花板（发散），没有第三种可能。实战靠下面几件更顺手的武器。

武器一：比较判别法（含极限形式）

定理 2 · 比较判别法

设 un,vn≥0 且 un≤vn。则

  • 若 ∑vn 收敛，则 ∑un 也收敛；
  • 若 ∑un 发散，则 ∑vn 也发散。
07:48瘦子 / 胖子记忆法（老师原话）

把「收敛的级数」想成瘦子，「发散的级数」想成胖子：

  • 比瘦子还瘦（你比收敛的更小）→ 你也是瘦子 → 收敛。
  • 比胖子还胖（你比发散的更大）→ 你也是胖子 → 发散。
  • 比胖子瘦（你 ≤ 发散的）→ 不一定（你可能仍胖）。
  • 比瘦子胖（你 ≥ 收敛的）→ 不一定（你可能仍瘦）。

只有前两句能下结论，后两句无法判定。考试最爱用后两句做干扰项。

老师还拿宿舍的胖哥们打趣：他们宿舍有个胖子，大二说 180 斤，大四还嘴硬说 210 斤——「比胖子还胖，那当然也是胖子」。反过来「比瘦子胖」可不一定：90 斤比 80 斤的瘦子胖，可 90 斤自己还是瘦子。把「收敛=瘦、发散=胖」这层比喻记住，四句话就永远不会背反，也不会掉进「比发散的更小就判发散」的陷阱。

定理 2′ · 比较判别法（极限形式）

设 un,vn>0，limn→∞unvn=L。

  • 若 0<L<+∞，则两级数同敛散；
  • 若 L=0 且 ∑vn 收敛，则 ∑un 收敛；
  • 若 L=+∞ 且 ∑vn 发散，则 ∑un 发散。
19:05极限形式的本质是等价无穷小替换

当 un/vn→L（0<L<∞）时，un 与 vn 是同阶/等价无穷小，趋于 0 的速度一样，所以敛散性一样。做题时这一步等价于：把 un 换成和它等价的、更熟悉的项（如 1/np），再去判断。这比直接放缩省事得多，是实战首选。

补充一句：极限形式比直接放缩好用，正因为它不用真的去放缩——只要找到「同阶/等价」的 vn，极限存在就能下结论，省掉了「到底放大还是缩小」的纠结，也避开了比较法本身（非极限形式）在考试中极少使用的现实。所以极限形式几乎是正项级数的首选武器：能套等价无穷小就先套，省时且不易错。

例 100:00判断 ∑n=1∞1n(n+1) 的敛散性。

思路：放大成「调和级数去掉首项」来比

因为 n(n+1)<(n+1)2，所以 n(n+1)<n+1，从而

1n(n+1)>1n+1

右端 ∑1n+1 是调和级数去掉第一项，发散。这里 un 比一个发散的 vn 还大（「比胖子还胖」），由比较判别法原级数发散。

例 231:26判断 ∑n=1∞sin1n 的敛散性。

思路：用等价无穷小，套到调和级数上

当 n→∞ 时 1n→0，于是 sin1n∼1n，即

limn→∞sin(1/n)1/n=1

比值趋于正常数 1，二者同敛散；而 ∑1n 是调和级数，发散，故 ∑sin1n 也发散。

同类题一眼做

∑ln(1+1n) 同样用 ln(1+x)∼x：ln(1+1/n)∼1/n，故发散。凡是「三角函数/对数里套 1/n」的，先想等价无穷小替换。

武器二、三：比值与根值（自己跟自己比）

定理 3 · 比值判别法（达朗贝尔 d'Alembert）

设 ∑un 为正项级数，ρ=limn→∞un+1un。则

  • ρ<1 ⇒ 收敛；
  • ρ>1（含 +∞）⇒ 发散；
  • ρ=1 ⇒ 无法判定。

关键提醒：ρ=1 时比值法完全失效——∑1/n 与 ∑1/n2 的比值极限都是 1，但前者发散、后者收敛，结论相反。所以一旦算出 ρ=1，要立刻换比较或 p 级数，别在比值上死磕。

36:40为什么「自己跟自己比」这么方便

比较判别法要「找别人比」，比值判别法只跟自己比：看后一项大约是前一项的几倍。若 ρ=0.5，相当于「后一项是前一项的一半」，通项以等比速度塌向 0，当然收敛；若 ρ=2，「后一项是前一项两倍」，越加越胖，必发散。老师用减肥打比方：每天是昨天的 0.5 倍，迟早没了；每天是昨天的 2 倍，谁扛得住。

定理 4 · 根值判别法（柯西 Cauchy）

设 ∑un 为正项级数，ρ=limn→∞unn。则

  • ρ<1 ⇒ 收敛；
  • ρ>1（含 +∞）⇒ 发散；
  • ρ=1 ⇒ 无法判定。
根值的最佳时机

45:46当 un 本身就是「某个 n 次方」时（比如 (1/2)n、(n/(2n+1))n），开 n 次根刚好把幂消掉，闭眼用根值。比值对这种幂指函数也行，但根值更直。

例 3用比值判别法判断 ∑n=1∞n!10n 与 ∑n=1∞(13)n 的敛散性。

解：前者比值→∞，后者比值=1/3

对 ∑n!/10n：

un+1un=(n+1)!/10n+1n!/10n=n+110→+∞>1

故发散。对 ∑(1/3)n：

un+1un=(1/3)n+1(1/3)n=13<1

故收敛。凡含 n!、含 an 的，几乎一律先试比值。

例 455:26判断 ∑n=1∞(n2n+1)n 的敛散性。

解：见到 n 次方，直接开 n 次根

因为通项本身就是 n 次方，根值最顺手：

unn=n2n+1→12<1

故级数收敛。这里若硬用比值，会出现 (n+1)n 这种麻烦幂指式，不如根值干净。

基准中的基准：p 级数

定理 5 · p 级数
∑n=1∞1np(p>0)

p>1 收敛；p≤1 发散（其中 p=1 就是调和级数）。

1:07:51死记不如对照理解
  • p=2：∑1/n2 趋于 0 很快 → 收敛。
  • p=1：∑1/n 调和级数 → 发散（上一页已证）。
  • p=1/2：∑1/n，因为 1/n>1/n 且 1/n 发散，比胖子还胖 → 发散。

所以 p 级数就是一把「标尺」：一个新级数的通项若和 1/np 同阶，看 p 是否大于 1 即可。

这张阶梯的实战用法是「对号入座」：拿到一个正项级数，先估计它的通项趋于 0 大概在什么速度档。若是 n!、an 这种「飞快」档，直接比值/根值；若是 1/np 这种，看 p 是否大于 1；若是卡在「慢于 1/n」的（n 倒数、对数倒数），基本判发散。老师甚至用 Excel 算过 n 很大时各项谁大谁小，结论就是：记熟这张表的相对快慢，期末大部分题一眼可判。

为什么「谁快谁慢」是整章的灵魂

回到根本：级数敛散，取决于通项趋于 0 的速度够不够快。所有判别法，本质上都是把陌生级数的「速度」拿去和已知基准（1/np、等比 qn）比：比较/极限形式直接比速度阶；比值/根值比的是「相邻两项的倍数关系」，倍数小于 1 就是等比速度、够快；莱布尼茨则要求交错项的绝对值递减到 0。所以「对速度阶梯的哪一格」是贯穿本页的统一线索——拿到题先估速度，比死记公式更有效。

一个实用的口头禅：遇到 n!、an 想「飞快→比值根值」；遇到 1/np 想「看 p 过没过 1」；遇到对数、三角、反三角里套 1/n 想「等价无穷小替换」；通项明显不趋于 0 想「直接发散」。四句话覆盖绝大多数考题。

交错级数：莱布尼茨判别法

1:24:59交错级数指正负号严格交替的级数，形如 ∑(−1)n−1un（un>0）：

定理 6 · 莱布尼茨（Leibniz）判别法

若交错级数 ∑(−1)n−1un 满足：① un 单调不增（un≥un+1）；② limn→∞un=0，则该级数收敛。

两条为什么「扫一眼就行」

老师强调：用莱布尼茨时，递减和趋于 0 这两条一般不用严格证明。比如 ∑(−1)n−11n，1/n 随 n 增大明显减小、且趋于 0，眼睛一扫就够，不扣步骤分。但注意：莱布尼茨只适用于「正负严格交替」的交错级数，任意项级数不能直接套。

莱布尼茨只「判收敛」，不「求和」

要分清：莱布尼茨判别法只告诉你交错级数收敛，并不给出它的和，也不保证绝对收敛。很多题正是考这一层——用莱布尼茨证了收敛，还得再取绝对值看是「绝对收敛」还是「条件收敛」。另外，若递减条件不成立（比如 un 不是单调的），莱布尼茨不能直接用，要改走绝对值或其他路子。把它当作「交错级数专用的收敛门票」，而不是万能钥匙。

任意项级数：绝对收敛与条件收敛

1:28:50任意项级数指各项正负任意（不要求交替）。处理它的总方针是：先取绝对值，把它变成正项级数。

定义 · 绝对收敛 / 条件收敛
  • 若 ∑|un| 收敛，则称 ∑un 绝对收敛。
  • 若 ∑un 收敛，但 ∑|un| 发散，则称 ∑un 条件收敛。
定理 7 · 绝对收敛 ⇒ 收敛

若 ∑un 绝对收敛，则它一定收敛。直觉：取了绝对值（全变正）都收敛，原级数正负还能互相抵消一些，自然更收敛。

为什么「叫绝对收敛」不等于「已经知道收敛」

老师打了个比方：叫你「超级美女」不代表你真的是美女——「绝对收敛」这个名字里虽然有「收敛」二字，但它定义的是「取绝对值后收敛」这件事。只是由定理 7 可知，一旦绝对收敛，原级数必收敛。判断顺序上，先看绝对值最划算，因为正项级数的武器（比值/根值/比较）最多。

例 51:40:05判别 ∑n=1∞sin(nα)n2 与 ∑n=1∞(−1)n−11n 的敛散性类型。

解：前者绝对收敛，后者条件收敛

① 对 ∑sin(nα)n2：因为 |sin(nα)|≤1，所以 |sin(nα)n2|≤1n2；而 ∑1/n2 是 p=2 的 p 级数，收敛。由比较判别法 ∑|un| 收敛，故原级数绝对收敛（从而收敛）。

② 对 ∑(−1)n−11n：取绝对值就是调和级数 ∑1/n，发散；但原级数是交错级数，且 1/n 递减趋于 0，由莱布尼茨收敛。绝对值发散、本身收敛 ⇒ 条件收敛。

例 61:48:20判断 ∑n=1∞(−1)n(12)n(1+1n)n2 的敛散性。

解：先对绝对值用根值，再回头看通项

令 an=(12)n(1+1n)n2。开 n 次根：

ann=12(1+1n)n→e2≈1.359>1

根值大于 1 ⇒ ∑an 发散（绝对值不收敛）。而且 ann→e/2>1 说明 an 不趋于 0，于是原级数通项 (−1)nan 也不趋于 0。

由收敛的必要条件（上一页性质四），通项不趋于 0 ⇒ 原级数发散。这道题的教训：绝对值发散时别急着用莱布尼茨，先看通项趋不趋于 0，这里直接判发散。

例 6 的通用教训：绝对值发散 ≠ 原级数发散

任意项级数一旦取绝对值发散，别急着下结论：原级数可能条件收敛（如 (−1)n−1/n），也可能通项根本不趋于 0 而直接发散（如例 6）。判别顺序上永远先查「un→0 吗」，再谈绝对/条件。这个先后顺序，是整页决策表的第 0 步与第 5 步之间的关键连接。

例 7判断 ∑n=1∞ln(1+1n2) 的敛散性。

解：等价无穷小替换到 p 级数

当 n→∞ 时 1n2→0，由 ln(1+x)∼x 得 ln(1+1/n2)∼1n2。取 vn=1/n2，则

limn→∞ln(1+1/n2)1/n2=1

比值趋于正常数，二者同敛散；而 ∑1/n2 是 p=2 的 p 级数，收敛，故原级数也收敛。这道题训练的正是「看见对数里套 1/nk，先想 ln(1+x)∼x」。

例 8判断 ∑n=1∞n+1(1−cosπn) 的敛散性。

解：两次等价替换，落到 p=3/2

当 n→∞ 时 πn→0，由 1−cosx∼x22 得 1−cosπn∼π22n2。于是通项

n+1(1−cosπn)∼n⋅π22n2=π22n−3/2

这相当于 p=32>1 的 p 级数，故原级数收敛。本题要点：先化简等价量，再判断「趋于 0 的速度」落在阶梯的哪一格，不要被 n+1 和余弦吓住。

化简等价量是正项级数最稳的打法

例 7、例 8 透露出一种通吃思路：先对通项做等价无穷小替换，把它化简成 1/np 的样子，再读 p。对数 ln(1+x)∼x、三角 1−cosx∼x2/2、反三角 arcsinx∼x 都是常客。只要替换后的主部是 n−p 且 p>1，基本收敛；p≤1 基本发散。这比硬放缩干净，也比比值/根值在「非幂非阶乘」时更直。把它和「速度阶梯」一起记，正项级数就几乎没盲区。

判别法选用决策表

第几步先看什么怎么判定结论
第 0 步 通项 un→0 吗？ 若不趋于 0（含极限不存在） 发散（必要性，免费用）
第 1 步 是否正项级数 是 → 进第 2 步；否 → 先取绝对值变正项 —
第 2 步 含 n! 或 an 比值判别法（自己跟自己比） ρ<1 收敛 / ρ>1 发散
第 3 步 通项是 n 次方 根值判别法（开 n 次根消幂） ρ<1 收敛 / ρ>1 发散
第 4 步 一般正项 比较（极限形式）+ 等价无穷小，对到 p 级数 p>1 收敛 / p≤1 发散
第 5 步 正负交替 莱布尼茨（递减且→0） 收敛（再看绝对值定绝对/条件）

这张表是整页的「总纲」。它的逻辑链是：先免费用必要条件（不趋于 0 直接发配发散）；再靠绝对值把任意项变正项（正项武器最多）；按通项形状选武器（阶乘/指数→比值，n 次方→根值，一般→比较+等价无穷小对到 p 级数）；最后才处理交错（莱布尼茨定条件收敛）。按这个顺序走，基本不会在「该用哪个法」上卡壳——绝大多数同学丢分，不是不会算，而是乱试一通、在 ρ=1 上死磕、或把任意项硬套莱布尼茨。把这张表截图存手机，考前看一遍比刷十道题更划算。

决策表的「隐藏顺序」

表里的第 0 步（不→0 直接发散）和第 5 步（交错用莱布尼茨）常常被忽略，却最值钱：前者是「免费的一票否决」，能省掉后面所有计算；后者是「任意项走完绝对值仍发散」时的最后退路。很多同学习惯一上来就比值/根值，结果在 ρ=1 上空耗——记住，先看通项、再看绝对值，比值根值只是中间武器，不是第一步。

四个高频翻车点

翻车一：在非正项情形直接套比较判别法——必须各项非负才能比大小。

翻车二：ρ=1 时比值/根值失效，要换方法（如 1/n 与 1/n2 都是 ρ=1，敛散却相反）。

翻车三：绝对值发散就以为原级数发散——交错级数可能条件收敛。

翻车四：莱布尼茨只认严格交替的交错级数，任意项不能硬套。

记忆入口 · 一眼回忆

一句话

正项用比较/比值/根值对到 p 级数；交错用莱布尼茨；任意项先绝对值。拿到级数先问：un→0 吗？

四大判别法

  • 比较（极限形式 = 等价无穷小）：un∼vn 同敛散。
  • 比值 ρ=limun+1/un：ρ<1 收敛，ρ>1 发散，ρ=1 不定。
  • 根值 ρ=limunn：同判据；见到 n 次方优先。
  • 莱布尼茨：交错 + 递减 + →0 ⇒ 收敛。

基准与结论

  • p 级数 ∑1/np：p>1 收敛，p≤1 发散。
  • 绝对收敛 ⇒ 收敛；绝对值发散 + 交错收敛 = 条件收敛。

四个坑

  • 非正项不能直接比大小。
  • ρ=1 时比值/根值无效。
  • 绝对值发散 ≠ 原级数发散（可能条件收敛）。
  • 莱布尼茨只管严格交替。
前置知识
  • 常数项级数的概念与性质 级数定义、部分和、收敛、调和级数发散、必要条件 un→0
  • 极限运算法则 极限运算（等价无穷小替换）
  • 方向角 方向余弦 数量积 向量积 方向余弦（此处无关，仅占位）
接下来
  • 幂级数（项里带 x 的级数、收敛半径）
  • 傅里叶级数
容易混
  • 比值与根值：ρ=1 都失效，别硬判
  • 绝对收敛（取绝对值收敛）vs 条件收敛（本身收敛、绝对值发散）
  • 比较判别法要求正项，缺这个前提会出反例
