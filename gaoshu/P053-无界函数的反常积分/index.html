P053无界函数的反常积分：找出瑕点，在瑕点处取极限

一句话核心

上一讲拆掉了「区间有限」，这一讲拆掉「函数连续」。积分号长得和普通定积分一模一样，问题却藏在函数爆掉的那一点（叫瑕点）上。补救手法仍是取极限——在瑕点旁边退开一点点，逼过去。真正会要命的是瑕点落在区间内部：这时必须把积分拆成两段，否则你会得到一个有限的、看起来还挺像样的错误答案。

一个「看着很正常」的积分

00:00这一讲的内容名字特别多：无界函数的反常积分、无界函数的广义积分、瑕积分。最后一个名字最形象——它是从「瑕点」来的，也就是函数爆掉的那一点。注意是「瑕」（玉上的斑点）不是「瞎」，因为它对应的确实是函数上的一个缺陷点。

00:56上一讲的毛病一眼就能认出来：积分的上下限里写着 ∞ 或 −∞，那是无穷限。这一讲的毛病难看多了，先看两个例子。

引例 1∫01dxx 有什么问题？

上下限 0 和 1 都是规矩的数，区间 [0,1] 也是规规矩矩的有限闭区间——第一个前提完全满足。问题出在第二个前提上：f(x)=1x 在 x=0 处没有定义（分母为零），而且当 x→0+ 时它趋于 +∞。

所以这个函数在 x=0 附近是无界的。牛顿–莱布尼兹公式要求 f 在 [a,b] 上连续，这一条不成立，于是普通公式不能直接用。它就是一个瑕积分。

引例 203:16∫−11dxx 如果硬套公式，会得到什么？

错在哪

1x 的原函数是 ln|x|，于是（错的）做法是

[ln|x|]−11=ln1−ln1=0−0=0(这是错的)

答案是 0 吗？不是。原因很清楚：1x 在 x=0 处没有定义，而 x=0 恰好夹在 −1 和 1 中间。整个区间上函数并不连续，牛顿–莱布尼兹公式的前提根本没满足。

要点：算出来的 0 是「函数在 −1 和 1 两处的值恰好相等」造成的假象，它完全掩盖了 x→0 时函数爆掉这件事。

01:58把这两个例子放在一起，就得到了这一讲的要害：瑕积分和普通定积分在书面上长得几乎一样，但前者可能给出一个漂亮的错答案。无穷限的反常积分不会骗你（看见 ∞ 就警觉了），瑕积分会。

什么叫瑕点

定义 · 瑕点

设函数 f 在点 c 的某个去心邻域内有定义，但在 c 的任何邻域内都无界，则称 c 为 f 的瑕点（奇点）。

换句话说：只要往 c 靠得足够近，|f| 要多大有多大。最常见的三种来源是：分母在某点为 0（如 1x 在 x=0）、ln 的自变量趋于 0+（如 lnx 在 x=0）、tan 在 π2 处。

瑕点出现在哪里，处理方式就不同。这三种情形必须分清楚，因为它们的写法、甚至「要不要拆」都不一样。

三种情形的定义

定义 · 瑕点在左端点（第一类）

设 f 在 (a,b] 上连续，a 是瑕点（即 f 在 a 附近无界）。取 t∈(a,b)，若极限 limt→a+∫tbf(x)dx 存在，则称瑕积分 ∫abf(x)dx 收敛，并规定该极限为它的值；否则称发散。

∫abf(x)dx=limt→a+∫tbf(x)dx
定义 · 瑕点在右端点（第二类）

设 f 在 [a,b) 上连续，b 是瑕点。取 t∈(a,b)，若 limt→b−∫atf(x)dx 存在，则称瑕积分 ∫abf(x)dx 收敛，其值等于该极限；否则称发散。

∫abf(x)dx=limt→b−∫atf(x)dx
定义 · 瑕点在区间内部（第三类）

设 c∈(a,b) 是唯一的瑕点，f 在 [a,c) 与 (c,b] 上分别连续。规定

∫abf(x)dx=∫acf(x)dx+∫cbf(x)dx

并且：右边两个瑕积分都收敛时，才说左边的积分收敛，其值等于两者之和；只要有一个发散，左边就判发散。（若区间内有多个瑕点，就在每个瑕点处都切开。）

为什么内部的瑕点非拆不可

这不是「更严谨一点」的要求，而是不拆就会算错。回到引例 2：∫−11dxx，硬套公式得 0；按定义拆开，两段分别是

∫−10dxx=limt→0−[ln|x|]−1t=−∞,∫01dxx=limt→0+[ln|x|]t1=+∞

两段都发散，所以整体发散。真正的答案不是 0，而是「不存在」。错解之所以得到 0，是因为 [ln|x|]−11 这个写法跨过了瑕点——它相当于把 +∞ 和 −∞ 用一个减号凑成一个有限数，这在定义里是被明确禁止的。

再举一个更刺眼的例子：∫−11dxx2。原函数是 −1x，跨过瑕点直接代：[−1x]−11=(−1)−(1)=−2。得出了一个负数面积——这本身就荒唐，因为 1x2>0，面积不可能为负。拆开一算，两段各自是 +∞，整体发散。

把两件事放在一起看就懂了：内部瑕点让「原函数」在区间上出现了一个断点，而牛顿–莱布尼兹公式假设原函数是连续的。硬套等于假装那个断点不存在，于是断点两边的无穷恰好抵消，错误就被藏进了一个有限的数里。这就是为什么老师说第三类「隐蔽性最强」。

怎么算：还是广义牛顿–莱布尼兹公式

和上一讲一样，取极限的过程不必每次都写出来。把原函数 F 求出来，在瑕点处「朝里带」——那个「带」的真实含义就是一次极限：

瑕点位置形式写法「带」的真实含义
左端点 A [F(x)]AB B 处真代入；A 处是 limx→A+F(x)
右端点 B [F(x)]AB A 处真代入；B 处是 limx→B−F(x)
内部 c 不能这样写 必须先拆成 ∫Ac+∫cB，再按上面两种分别处理
「一会儿右边一会左边」怎么记

很多人在这里绕晕：什么时候是从右边逼近、什么时候从左边？老师给的答案是——别死记，想一下就清楚：

左端点 A 是瑕点
区间是 [A,B]，而我必须在区间里面取点。A 已经是左端了，往区间里走只有一个方向——向右。所以 t→A+。
右端点 B 是瑕点
同理，B 是右端，往区间里走只能向左。所以 t→B−。

一句话：逼近方向永远指向区间的内部。如果一时想不起来，画一条线段标出区间，比死背口诀可靠得多（老师说得很直白：脑子不好使，手还好使吧——动笔画一下就知道了）。

有时候「直接代入」居然没事

这一小段是老师专门总结的实用经验。同样是瑕积分，有的题直接代入就能出结果，有的必须老老实实取极限——区别在哪里？先看三个例子。

  1. ∫01dxx：原函数 ln|x|。x→0+ 时 lnx→−∞，代不进去，极限不存在 → 发散。
  2. ∫01dxx：原函数 2x。上限代入得 2，下限 x→0+ 时 2x→0——极限存在 → 收敛，值等于 2。这就是「直接带也没事」的典型：虽然 x=0 是瑕点，但极限算出来是个正常的数。
  3. ∫01dxx3：原函数 −12x2。x→0+ 时分母趋于 0，整体 → +∞ → 发散。
什么情况下「直接代入」是安全的

把这三个例子排在一起，规律立刻浮出来：关键不在被积函数，而在原函数。

  • 2x 在 x→0+ 时趋于 0，是有界的（可以连续延拓到 0）；
  • lnx、−12x2 在 x→0+ 时无界，所以必须取极限，而极限是无穷大，判发散。

所以经验是：原函数在瑕点附近有界，直接代入不会有问题；原函数在瑕点附近无界，就必须把极限展开来看。

而且这个「有没有问题」往往自己会暴露：当你发现某个端点代入时分母是 0、带不进去，那就说明该取极限了。老师把它总结成一句很实用的话——做到那一步自然会发现带不动，这时候就想起瑕积分的定义，回头补一个极限。

这也是为什么老师强调：瑕积分在两端点是瑕点的情形，「不一定出错误」；而出错误几乎都发生在内部瑕点——因为内部瑕点在纸上完全不留痕迹，你不会「带不动」，你会带得飞快。

两个必背的结论

例 1证明：∫abdx(x−a)q 在 0<q<1 时收敛，在 q≥1 时发散。

思路：先认瑕点，再单独处理 q=1

x→a+ 时分母趋于 0，所以 a 是瑕点，且是左端点瑕点。和上一讲的 ∫a+∞x−pdx 一样，q=1 要单独拿出来。

情形一：q=1
∫abdxx−a=[ln(x−a)]ab=ln(b−a)−limx→a+ln(x−a)

当 x→a+ 时 x−a→0+，ln(x−a)→−∞，前面又有减号，整体 →+∞，极限不存在 → 发散。（这里 x>a，绝对值可以不加。）

情形二：q≠1

配系数：(x−a)1−q 求导得 (1−q)(x−a)−q，所以要配 11−q：

∫abdx(x−a)q=[(x−a)1−q1−q]ab
  • 0<q<1：1−q>0，x→a+ 时 (x−a)1−q→0，极限存在，值为 (b−a)1−q1−q → 收敛。
  • q>1：1−q<0，(x−a)1−q=1(x−a)q−1→+∞，（配上 11−q<0 后）成为无穷大 → 发散。

合起来就是

∫abdx(x−a)q收敛⟺0<q<1;发散⟺q≥1

例 2讨论 ∫01dxxp 的敛散性。

思路：结构与例 1 相同，只是把 (x−a) 换成了 x

x=0 是瑕点（也是左端点）。同样先处理 p=1：∫01dxx=[lnx]01，x→0+ 时 lnx→−∞，发散。

p≠1 时，原函数是 x1−p1−p，在 x→0+ 处看指数 1−p 的符号：

  • p>1：1−p<0，x1−p1−p=1(1−p)xp−1→∞ → 发散；
  • 0<p<1：1−p>0，x1−p→0，极限存在，值为 11−p → 收敛；
  • p≤0：函数 x−p 在 [0,1] 上其实没有瑕点（有界），本来就是普通定积分，当然收敛。

于是结论是

∫01dxxp收敛⟺p<1;发散⟺p≥1
和上一讲的方向正好相反

上一讲的 ∫1+∞dxxp 是 p>1 收敛；这一讲的 ∫01dxxp 是 p<1 收敛。两个不等式方向相反，这是两条结论里最容易记混的地方。

不要靠背方向。正确的记忆方式是看「谁在捣乱」：

  • 区间是 [1,+∞) 时，捣乱的是右端的尾巴。尾巴要够瘦才好，p 越大越瘦，所以 p>1 收敛。
  • 区间是 (0,1] 时，捣乱的是左端的尖峰。尖峰要够薄才好，p 越大尖峰越高，所以反而要 p<1。

例 320:29计算 ∫0AdxA2−x2（A>0）。

思路：先找瑕点，再推原函数

不明真相的人会把它当成普通定积分——上下限 0 和 A 都是正常的数。但先检查一下：x→A− 时 A2−x2→0+，分母趋于 0，被积函数 →+∞。所以 A 是瑕点，而且是右端点瑕点；x=0 处一切正常。

原函数不在基本积分表里（属于要现推的二级公式）。推法是提一个 A 出来凑成整体：

∫0AdxA2−x2=∫0AdxA1−(xA)2=∫0Ad(xA)1−(xA)2

把 xA 看成一个整体，这正是 arcsin 的原型，于是

[arcsinxA]0A=arcsin1−arcsin0=π2−0=π2

严格的写法应该是 limx→A−arcsinxA=π2——这是一次取极限，不是代入。好在极限存在且等于 π2，所以瑕积分收敛，值为 π2。

要点：这题虽然带瑕点，但原函数 arcsinxA 在 x→A− 时趋于有限值，属于「取极限也没事」的那一类，所以答案是一个正常的数。另外记住这类题的第一个动作永远是：先找瑕点，再动手算。

例 423:21判断 ∫−11dxx2 的敛散性（并对比错误做法）。

思路：先问一句「瑕点在哪」

1x2 在 x=0 处没有定义，x=0 又是区间内部点——内部瑕点，必须先拆：

∫−11dxx2=∫−10dxx2+∫01dxx2

1x2 是偶函数，两段结构一样，算一段即可。以 ∫−10dxx2 为例，原函数是 −1x：

∫−10dxx2=[−1x]−10=limx→0−(−1x)−(−1−1)

x→0− 时 x 是负的小量，−1x→+∞，而 −1 那一项是常数，所以整段 →+∞，发散。

按定义，只要有一段发散，整体就发散，所以 ∫−11dxx2 发散（另一段不用再验）。

错误做法长什么样

错解：直接跨过 0 代入原函数：[−1x]−11=(−1)−(1)=−2，于是回答「收敛，值为 −2」。

为什么荒唐：1x2 在 [−1,1] 上恒为正，面积绝不可能是负数，更不可能是一个有限的数。这个 −2 是「跨过瑕点」硬凑出来的假答案。

对的说法：「x=0 是内部瑕点，拆开后两段都发散，所以整体发散。」

例 547:27计算 ∫0+∞dxx(1+x)3/2。

思路：先识别「坏在哪」，再换元

这个积分要留意两处：

  • 下限 x→0+ 时 1x→+∞，所以 x=0 是瑕点；
  • 上限是 +∞，所以它同时是无穷限的反常积分。

两种毛病叠在一起，说明这一题不「选一种」，而是两件事都得管。做法是换元把它变干净：令 x=t，即 x=t2，则 dx=2tdt，并且 x 从 0+ 到 +∞ 对应 t 从 0+ 到 +∞。代入：

∫0+∞2tdtt(1+t2)32=2∫0+∞dt(1+t2)32

（分子分母里的 t 正好约掉，这是设 t=x 而不是设别的的原因。）看到 1+t2，这是明确的三角替换信号：令 t=tanu。当 t 从 0 到 +∞ 时，u 从 0 到 π2；而 dt=sec2udu，(1+t2)32=sec3u。

2∫0π2sec2usec3udu=2∫0π2cosudu=2[sinu]0π2=2
这一步有个藏起来的绝对值

(1+t2)32 其实等于 (1+t2)3=|sec3u|。严格地说，A2=|A|，不能直接写成 sec3u。

这里能去掉绝对值，是因为 u∈[0,π2)，cosu>0，所以 secu>0。老师课上特意「故意忽悠」了一下再点破——能去绝对值是这一题的一个隐含前提，写题时要说明理由。

要点：换元之后，t=0 处不再有瑕点吗？仍然有——1(1+t2)3/2 在 t=0 附近有界，但这一题原本的瑕点已经被 t 约掉了。最终结果 2 是有限的，所以这个「又瑕又无穷限」的积分收敛。

两类反常积分对照表

这一章的两类反常积分，本质上是同一个人用同一种手法修了两个不同的毛病。把它们并排放，区别与共性一次看清。

对比项① 无穷限的反常积分（P052）② 无界函数的反常积分（本讲）
被破坏的前提 区间有限 函数连续
问题出在哪 端点跑到了 ±∞ 区间内某点（瑕点）处函数无界
怎么补救 用有限的 t 替换 ∞，再 t→∞ 从瑕点旁边退开一点到 t，再 t→ 瑕点
定义式 limt→+∞∫atfdx limt→a+∫tbfdx（a 为瑕点）
两头都坏 拆成两段，两段都收敛才算收敛 同样拆成两段，两段都收敛才算收敛
典型结论 ∫1+∞dxxp：p>1 收敛 ∫01dxxp：p<1 收敛
容易漏的地方 写成「=+∞」当作收敛 看不出瑕点，尤其瑕点在内部时
共同点 都靠取一次极限来修补；算的时候都能用广义牛顿–莱布尼兹公式的形式先求原函数再「朝里带」
为什么两类问题会「长得像」

因为它们的修复动作是同一个动作：把出问题的那一小段从积分区间里挖掉，剩下的部分是一个规矩的普通定积分，最后再让挖掉的窟窿缩到零，取极限。

  • 无穷限：要挖掉的是无穷远的尾巴，所以用 t 当临时上限；
  • 瑕积分：要挖掉的是瑕点周围的一个小区间，所以用 t 当临时端点。

这也解释了两者的收敛判据为什么总是一对幂函数结论：它们关心的其实是同一件事——被挖掉的那一小块，面积到底有限还是无限。

∫abf=limt→b−∫atf，从左边逼近
内部 c
∫ab=∫ac+∫cb，必须拆；两段都收敛才算收敛

必背结论（注意方向与上一讲相反）

  • ∫abdx(x−a)q：0<q<1 收敛；q≥1 发散
  • ∫01dxxp：p<1 收敛；p≥1 发散
  • 对照上一讲：∫1+∞dxxp 是 p>1 收敛。右端看尾巴、左端看尖峰，方向自然相反。

三个坑

  1. 内部瑕点不拆，几乎必错。∫−11dxx 硬算得 0、∫−11dxx2 硬算得 −2，两个都是假答案。
  2. 「无界」不等于「发散」。∫01dxx=2 收敛——判断要看原函数在瑕点附近是否有界。
  3. 左右方向指向区间内部。左端点从右逼近，右端点从左逼近；想不清就画线段。

动手前问自己三句

  1. 函数在 [a,b] 上处处有定义吗？没有定义的那点就是瑕点，它在哪个位置？
  2. 瑕点在内部吗？在，就先拆成两个积分，再各自动手。
  3. 这个端点我「带得动」吗？带不动（分母为零、ln0）就说明该取极限，而且是无穷大 → 发散。
