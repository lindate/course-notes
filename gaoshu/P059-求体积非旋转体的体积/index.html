P059非旋转体的体积：平行截面法

一句话核心

前面两节的立体都是「转出来」的，横截面永远是圆。这一节把限制去掉——只要每个位置的横截面面积 A(x) 知道，体积就是 ∫abA(x)dx。道理只有一句：把立体切成薄片，每片近似是一个柱体，底面积乘厚度再累加。经典例子是「圆柱过底面圆心斜切一刀」切出来的那块楔形，用两种切法都必须算出 23R3tanα。

00:01老师一开口就举了个很接地气的例子：有一个土豆，求它的体积。

00:58为什么不说西瓜？因为西瓜比较圆，可以看成旋转体，用上一节的圆盘法就做了；而土豆坑坑洼洼，谁也不是谁的旋转，只能老老实实把它当成一个「不太规则的立体」。这类立体的正式名字叫平行截面面积已知的立体，说白了就是「比较普通的立体」。

00:58一般思想：截面积积起来就是体积

设有一个立体，夹在 x=a 与 x=b 两个平面之间。在 x 从 a 变到 b 的过程中，用垂直于 x 轴的平面去截它，得到的横截面面积是已知的，记作 A(x)。求这个立体的体积。

01:50老师给了两种理解，和上一节旋转体的两种理解完全平行：

理解一：对横截面面积积分

把每一处的截面面积 A(x) 从 a 累加到 b：

V=∫abA(x)dx

老师说这里有一种「维数增加」的效果——面积本来是二维的量，被积分之后就成了三维的体积。这句话不是修辞，它正是公式的几何含义。

02:35理解二：微元法切薄片

在 x 处切一刀，再在 x+dx 处切一刀，切出一薄片。因为片很薄，可以把它近似看作一个柱体：底面面积 A(x)，高是 dx。

柱体的体积是「底面积 × 高」，所以一片的体积是 A(x)dx。把它们从 a 累加到 b，就回到上面那个公式。

03:27「柱体」不等于「圆柱体」

为什么要抠这个字眼

老师说，薄片「可以看作一个柱体」，但请特别注意——是柱体，不是圆柱体。这两个词的差别很大：

  • 圆柱体：两个底面都必须是圆。
  • 柱体：宽松得多。老师给的说法很形象——你平面里的一个图，甭管是三角形、圆形、椭圆形还是一个非规则的形状，把它垂直向上提一下子，就叫柱体。

所以土豆切出来的那片东西，底面可能是歪歪扭扭的一坨，但它仍然是个柱体。只要是柱体，体积就永远是底面积 × 高，与底面的形状无关。

顺便说一句：旋转体里的薄片，恰恰是「柱体」的一个最特殊的例子——底面恰好是圆。所以前两节的公式其实是这一节公式的特例。

04:14例题：圆柱过底面圆心斜切一刀

例04:14有一个底面半径为 R 的圆柱体，通过底面圆的圆心斜着切一刀，刀面与底面所成的角是 α。求切下来的那一块的体积。

把一个抽象题目变成手里的东西

05:10老师说这道题最要紧的是先把背景搞清楚。他的办法很实在：你就比方说拿着你这个水杯，拿一个刀子这样斜着切，不过切的时候必须得经过这个水杯的这个圆的圆心。他后来又补了一句更好记的——拿一根火腿肠，用刀斜着切下去。

由于刀必须经过圆心，它在底面上留下的痕迹就是一条直径，把底面圆分成两个半圆。所以切下来那一块的底面是一个半圆。

这个立体的形状，老师给了一个比喻，非常好记：和我们扫地用的簸箕差不多——一头高一头低，底面是圆的、上面被斜着削平。

先确认一件事：它不是旋转体

老师说得很清楚：这个立体的体积就不是个旋转体了，因为旋转体你一旋转得出来是圆，它没有圆啊。所以前面两节的办法在这里用不上，只能用平行截面法。这就是本页公式存在的意义。

建系

取底面圆心为原点，底面所在平面为水平面：x 轴沿着那条底面直径，y 轴在底面上垂直于 x 轴（也就是「往里的深度」方向）。那么底面半圆是 x2+y2≤R2 且 y≥0，而斜切面在这个区域内的高度是 z=ytanα。

07:06为什么高度是 ytanα？因为在这个深度 y 处，切面比底面高出 ytanα——这是一个直角三角形里的对边比邻边，y 是邻边、高是对边、夹角是 α。

07:56顺带说一句：老师说 tanα 完全不用怕。α 是题目给定的固定切角，所以 tanα 就是一个常数，积分的时候直接提到外面去。老师原话是：我们同学一看三角形三角函数你就害怕，尤其在积分的时候，其实不用管它。

06:28思路一：垂直于 x 轴切，截面是直角三角形

  1. 确定积分变量与区间。沿 x 切，x 从 −R 到 R。
  2. 看清截面的形状。07:06截面的两条直角边：一条沿着 y 方向从直径量到圆弧，长度是 y=R2−x2；另一条竖直向上，长度是 ytanα。因为 y 在直径处为 0，所以这个截面是一个直角三角形（顶点在直径上，斜边在圆柱壁上）。
  3. 写出面积。「底乘以高除以二」：
    A(x)=12⋅y⋅ytanα=12y2tanα=12(R2−x2)tanα
    这里用了 y2=R2−x2（圆的方程 x2+y2=R2）。
  4. 积分。07:56tanα 是常数，先提到外面：
    V=12tanα∫−RR(R2−x2)dx
09:49为什么这里能用「两倍」这一招

看积分区间 [−R,R]：它关于原点对称。再看被积函数 R2−x2：把 −x 代进去结果不变，所以它是偶函数。

两个条件同时满足，就可以用那条老结论——对称区间上偶函数的积分等于「从 0 积到 R，再乘两倍」：

V=12tanα⋅2∫0R(R2−x2)dx=tanα∫0R(R2−x2)dx

注意那个 12 和 2 正好抵消了，这不是巧合，是老师故意提出来给同学看的——先把常数提到外面、再用对称性，能省掉一半的代入计算。

剩下的就是一个多项式积分：

V=tanα[R2x−x33]0R=tanα(R3−R33)
V=23R3tanα

11:39思路二：垂直于 y 轴切，截面是长方形

换一个方向切，y 从 0 走到 R。老师说这一遍主要是为了验证——顺便也纠正一个非常常见的错觉。

这里最多人答错的一句话

老师问同学：「垂直于 y 轴切出来的横截面是什么图形？」很多人答梯形。他当场否掉了：不是啊！你不要看这个，你看你的水杯啊，你垂直这样切，它和这个边缘交的都是垂线，它怎么能是梯形呢？

13:07他又补了一遍火腿肠版本的说法：你回去拿一个火腿肠，拿个小刀这样切，它的横截面就是个长方形，非常清楚。

错在哪里。错在把「圆柱侧面是弯的」当成了「切出来的边是弯的」。实际上圆柱的母线是直的、竖直的，沿着 y 方向垂直切下去，切口与圆柱面的交线就是两条竖直直线，所以截面是长方形。

  1. 量长方形的两条边。14:18长：在深度 y 处，x 从 −R2−y2 一直伸到 +R2−y2，所以长是两倍，即 2x（这里 x=R2−y2，取正的那一半，就是老师说的「咱取正的就行」）。宽：竖直方向的高度是 ytanα。
  2. 写面积。
    A(y)=2x⋅ytanα=2ytanαR2−y2
  3. 积分。y 从 0 到 R：
    V=2tanα∫0RyR2−y2dy
  4. 凑微分。16:05这个积分要动一下手：把 ydy 凑成 −12d(R2−y2)，让根号里的整块变成一个整体 u=R2−y2：
    ∫0RyR2−y2dy=12∫0R2udu=13R3
  5. 代回去。
    V=2tanα⋅13R3=23R3tanα

17:28两种切法得到完全一样的结果。这不是巧合——它们算的是同一个立体，只是把刀换了个方向。能做两道、对得上答案，本身就是最好的自我验算方式。

为什么两种截面的形状差这么远，结果却一样

因为体积不关心你「怎么切」。切法只决定了用哪个变量做积分变量、用哪个式子当 A，但无论怎么切，被加起来的都是同一个立体的同一堆材料。

这背后其实就是我们早就熟悉的一件事：定积分的值只由被积对象决定，不由你选的分割方式决定。求面积时 X 型与 Y 型得到同一个答案，求旋转体时圆盘法与壳法得到同一个答案，这里两种切法又得到同一个答案——全都是同一个道理。

顺带说一句：老师说这一部分的题目不好出——出难了同学做不出来，出简单了又和旋转体没区别。所以考试里真考的，基本就是这道「圆柱斜切」以及它的几个变体。

整页的两个坑

坑一：把截面形状想错了

垂直于 y 轴切得到的是长方形，不是梯形。判断依据很简单：圆柱的母线是直线，垂着切下去，切口的两条竖直边都是直的。拿个水杯或火腿肠实际比划一下，比在脑子里推理可靠得多。

坑二：被 tanα 吓住

α 是题目给定的固定角度，所以 tanα 是一个常数，可以随时提到积分号外面，也可以和别的常数合并。不要因为是「三角函数」就把它当变量处理。

另外别忘了 12：三角形面积里的 12 和 sin、cos 一样，是最容易被漏掉的东西。思路一里它被对称性的「两倍」抵消掉了，所以更要留意它本来就在那儿。

记忆入口 · 一眼回忆

一句话

平行截面法 = 把立体切成薄片，每片近似是柱体，底面积 A(x) 乘厚度 dx，再累加。

公式

V=∫abA(x)dx

一条链

确认不是旋转体 截面不是圆→ 选切法 垂直于 x 还是垂直于 y→ 写出 A 三角形底乘高除以二 / 长方形长乘宽→ 积分 得体积

要背的

  • V=∫abA(x)dx。底面积 × 厚度再累加，一句话就是它的全部。
  • 柱体 ≠ 圆柱体：柱体的底面可以是任意平面图形，体积永远是底面积 × 高。
  • 旋转体的薄片是柱体的特例（底面恰好是圆），所以前两节的公式是本页公式的特殊情形。
  • 楔形例题：垂直 x 轴切得直角三角形（面积 12y2tanα），垂直 y 轴切得长方形（面积 2xytanα）。
  • 两种切法的答案都是 23R3tanα，可以互相验算。

两个坑

  1. 把长方形看成了梯形。圆柱母线是直的，垂直切出来一定是长方形。
  2. 忘了 tanα 是常数、忘了三角形面积里的 12。这两处是本题丢分最集中的地方。
