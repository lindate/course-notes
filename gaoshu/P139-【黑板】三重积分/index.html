P139【黑板】三重积分

一句话核心

三重积分只有两个动作：把 Ω 的上下限写出来，和挑一种切法。这一页是黑板精讲，正课的定义一个字不重复（老师说「看完定义你会发现跟二重积分差不太多，对做题实打实没有作用」），只讲三件事：投影法该怎么「照」、截面法该怎么「切」、球面坐标该怎么「扫」。最需要练成条件反射的是——看到立体先判断截面会不会随 z 变：不变，截面法最舒服；会变，就得把截面半径老老实实写成 z 的函数（z 而不是 z）。

一、三重积分是什么：一句话讲完

00:00这节课的开场很反常。老师说三重积分的定义「我不想讲了」，理由是「你看完这个定义会发现和一重积分、二重积分其实差不太多，对咱实打实的做题没有什么作用」。

01:11他改讲一个更划算的东西——把三种积分打通，办法是把图「压扁」：

  • 定积分：脑海里那张画面是二维的，但定积分本身是一维——压扁后只剩 x 轴上一段线段，段上每个点对应 f(x)。
  • 二重积分：压扁后剩平面区域 D，区域上每个点对应 f(x,y)。
  • 三重积分：不用再压。它的积分区域「就是一个实心的立体」，每个点 (x,y,z) 对应 f(x,y,z)。
06:08「老师，你讲二重积分的时候不是说求体积吗？」

这是当场就有同学问出来的疑惑，也是本节最容易懵的地方：二重积分的几何意义是「曲顶柱体的体积」，那三重积分的积分区域怎么又是一个立体？两个图长得太像。

老师的回答很干脆：「我们这里不是求体积，我哪说求体积了？三重积分的积分区域就是一个立体的区域，是个实心的图——我没让你求体积。」

区别在于谁在「带函数值」：二重积分里立体是被积函数「造」出来的，三重积分里立体本身就是积分的落脚点。被积函数呢？06:46「那就看具体的题目咯」——一般没有实际意义；唯一有意义的情形是它代表密度，此时积分结果就是不均匀立体的质量。

08:12体积元素 dV 写成什么，取决于怎么切。按垂直于三条坐标轴的方向切，小块是小长方体，三条边长是 dx、dy、dz，所以 dV=dxdydz。老师把三个微元排了队：「dx 是长度的微元，dσ 是面积的微元，dV 是体积的微元」——升一维就多一个微分。

二、投影法（先一后二）：拿手电朝上照

10:05老师把方法的思想讲得很具象，因为「你如果死记的话是记不住的」：

10:05老师的原话

假设你是个人，你站在这个投影之上，你拿着手电筒朝上去照一下。然后你是个小人儿，从这个投影那个地方走，走的过程中你不停地拿着手电朝上照——照的过程中你看一看，上面的函数是 z=z2(x,y)，下面的函数是 z=z1(x,y)。

完整动作是：把立体朝某个坐标面（最常用 xOy 面）投影得到 Dxy，在 Dxy 上任站一个位置朝上照，光柱穿进去碰到的面是下表面、穿出去碰到的面是上表面，这两个函数就是 dz 的下限与上限。

∭Ωf(x,y,z)dV=∬Dxy[∫z1(x,y)z2(x,y)f(x,y,z)dz]dxdy
12:38为什么叫「先一后二」，老师又为什么不爱叫它

写成累次积分以后，内层是一个一元积分（对 z），外层是一个二重积分，所以有的书叫它「先一后二」。老师说他记不牢这个名字，并且明确表示不欣赏：「一会儿还有个先二后一，先一后二先二后一你根本就搞不清楚。」

他建议记「投影法」——「投影」两个字直接告诉你动作是什么。同理另一个叫「截面法」，因为它的动作是切片。

由此得一条方法论：先把方法想成一个动作，再回头记它的名字与积分顺序，顺序就不用背。

例 219:05计算 ∭ΩxdV，其中 Ω 由平面 x+2y+z=1 与三个坐标面围成。

思路：投影是三角形，难点只在「把投影的边写对」

先算截距：x 轴上 1、y 轴上 12、z 轴上 1。上表面是斜面 z=1−x−2y，下表面是 z=0，于是

∭ΩxdV=∬Dxyx(1−x−2y)dxdy
22:09投影里那条斜线，为什么能「一秒写出来」

老师先问全班：「这条直线是个啥？你能不能一秒钟说出来？」——说不出来。但他一秒钟能，因为这条斜线正是斜面与 xOy 面的交线：把 z=0 代进斜面方程即得 x+2y+0=1。

所以他直接写 x+2y=1，即 y=1−x2。「我一秒钟能说出来，你 get 到我的点了没有？」

这条技巧在整个重积分部分通用：投影区域的边界就是曲面与投影面的交线，用联立消元得到，别靠看图猜。

积分限是 x 从 0 到 1、y 从 0 到 1−x2：

∭ΩxdV=∫01dx∫0(1−x)/2x(1−x−2y)dy=∫01x(1−x)24dx=148

三、截面法（先二后一）：像切鸡蛋一样

24:32老师说截面法这个名字「比较有意义」，因为动作就是切；书上画了一个蛋，「画的其实还挺有道理的」。做法：设立体夹在平面 z=c1 与 z=c2 之间，用平面 z=z0 去截它，截出来的平面图形记作 Dz，则

∭Ωf(x,y,z)dV=∫c1c2dz∬Dzf(x,y,z)dxdy

25:44有一个必须留意的地方：截面 Dz 一般与 z 有关。「为什么要写成 Dz 呢？因为这个 z 朝上不停地取，你会看到它的截面会因为 z 的变化而发生变化。」26:52另外，截面不一定非得水平切——「也可以是 x 从几到几、y 从几到几做截面」，朝哪切取决于哪个方向切出来的截面最好算。

例 330:41用截面法计算 ∭ΩxdV，其中 Ω 由 x+y+z=1 与三个坐标面围成。

思路：套路不变，但这次截面会变——全部难度都在这儿

30:41老师提醒「这个题用截面法有相当的风险」：从下往上切，截面一直在变。z 从 0 到 1。

31:51这里最容易看错的一步

同学很容易顺手把截面的两个端点标成 (1,0) 和 (0,1)。老师说：「这两个地方能是一吗？得加件衣服呗，就这一个错误就是致命的。」

正确做法：z 已经取定，把它当成常数代进平面方程，剩下的关系就是 x+y=1−z。所以截面三角形的两个腰长都是 1−z，于是 x 从 0 到 1−z、y 从 0 到 1−z−x：

∭ΩxdV=∫01dz∫01−zdx∫01−z−xxdy=∫01(1−z)36dz=124

结果对不对？最快的自检是把同一道题改用投影法再做一遍（投影是 x+y≤1、光柱从 z=0 照到斜面 z=1−x−y），照样得到 124。两法给出同一个数，说明截面的边界写对了。自检的正确姿势是「同一道题、两种方法，比答案」，而不是拿两道不同的题互相对照。

要点：34:14更省事的检查是代入端点——把 z=0 代进去该得到完整的 x+y≤1，把 z=1 代进去该缩成一点；两头对得上，中间就错不了。

例 437:10计算 ∭Ωz2dV，其中 Ω 是椭球 x2a2+y2b2+z2c2≤1。

思路：截面是椭圆，先算椭圆面积，再对 z 积

z 从 −c 扫到 c。取定一个 z，截面是椭圆；因为 z 是固定值，z2c2 就是常数，挪到右边：

x2a2+y2b2=1−z2c2

41:19把右边这堆常数除到分母上、再「把平方朝外提」变成根号，就得到标准椭圆方程，半轴是 a1−z2c2 与 b1−z2c2。用椭圆面积公式 πAB（老师说是高中就记过的）：

S(z)=∬Dzdxdy=πab(1−z2c2)

43:45又因为 z2 对 x、y 求积分时「这个 z 可是个常数」，可以提到内层积分号外面，于是三重积分降成一次一元积分：

∭Ωz2dV=∫−ccz2S(z)dz=πab∫−cc(z2−z4c2)dz=πab(2c33−2c35)
∭Ωz2dV=415πabc3

要点：只要能写出截面面积 S(z)，三重积分立刻降成一元积分。半轴带根号不要紧——算面积时两个根号相乘，正好抵消成 (1−z2c2)。

四、两种方法怎么选

比较项投影法（先一后二）截面法（先二后一）
动作把立体压到坐标面上，从投影里发竖直光柱沿某个轴切片，每一片自己是一个平面区域
积分顺序∬[∫dz]dxdy：内一元、外二重∫dz∬dxdy：内二重、外一元
上下限怎么定光柱的穿入面、穿出面（下表面、上表面）立体在扫描方向上的最底、最顶
何时首选投影是圆、三角形等规则图形，且上下表面容易写截面形状规则、面积随 z 变化的规律简单
最容易错投影边界写错（它其实是交线，代 z=0 就能得到）忘了截面与 z 有关，把 1−z 写成 1

47:23老师的取向很清楚：优先投影法，它「一般来说相对简单一些」；截面法遇到会变的截面「有相当的风险」。但也别把话说死——椭球和旋转抛物面用截面法明显更省事。方法不是规定，是选择。

五、柱面坐标：其实就是极坐标

44:58课本在两种方法之后还插了一节「柱面坐标」。老师直接说：「这个柱坐标，我一般不把它当成一个单独的方法去讲。你在用投影法或者截面法做题的时候，如果它有合适的极坐标，那它就是极坐标——柱坐标就是极坐标，不用单独去记。」

它确实只是把 xOy 面上的极坐标搬到三维：x=rcosθ、y=rsinθ、z=z 不变，于是 dV=rdrdθdz——那个 r 和极坐标里的 r 是同一个东西。

例 546:05计算 ∭ΩzdV，其中 Ω 由旋转抛物面 z=x2+y2 与平面 z=4 围成。

投影法：投影是圆，剩下的交给极坐标

抛物面与 z=4 相交于 x2+y2=4，投影是半径 2 的圆；下面碰到抛物面、上面碰到平面：

∭ΩzdV=∬Dxy12(16−(x2+y2)2)dxdy=12∫02πdθ∫02(16−r4)rdr

（投影是圆 → 换极坐标，别忘了多一个 r。）算下去得

∭ΩzdV=π[8r2−r66]02=π(32−323)=643π
截面法：同一道题，换成切片

53:00z 从 0 到 4。取定一个 z，截面是圆盘 x2+y2≤z，半径是 z。被积函数 z 对 x、y 是常数，提出去：

∭ΩzdV=∫04zdz∬Dzdxdy=∫04z⋅πzdz=643π
53:57这道题唯一会错的地方

关键是「截面圆盘的面积」。很多同学会顺手写成 4π（把 z=4 时的半径当成所有截面的半径）——老师说：你只要对截面法稍微有一丁点的概念，你就不会把它误以为是二。

正确做法：由 x2+y2=z 得截面半径是 z，面积是 π(z)2=πz，不是 4π、也不是 πz2。自检很直接：把 z=4 代进去应是 4π（半径 2 的圆），把 z→0 代进去应趋于 0；两头都对得上就错不了。

六、球面坐标：三个参数与那个 ρ2sinφ

59:48球面坐标「是完全不一样的一个东西」，值得单独学。空间里的点改用三个参数描述：

ρ（老师也写成 R）
点到原点的距离，ρ≥0。它是极坐标里 r 的升维版。
φ
由原点指向该点的射线与 z 轴正半轴的夹角，0≤φ≤π。1:01:32老师用胳膊比划：「z 轴的正半轴就是我这只手」——φ=0 指正上方，90 度是水平，到脚跟那边就到底了。
θ
把点投影到 xOy 面，由 x 轴正半轴转到这条投影射线的角度，0≤θ≤2π。它和极坐标里的 θ 完全是同一个角。

1:04:08换算关系建议现场推一遍，比死背可靠：ρ 是斜边、φ 的邻边正好是 z，所以 z=ρcosφ；水平分量等于 ρsinφ，再往 x、y 上投即可。

x=ρsinφcosθ,y=ρsinφsinθ,z=ρcosφ

顺手还得两个常用的二级结论：x2+y2=ρ2sin2φ、x2+y2+z2=ρ2。体积元素则是

∭ΩfdV=∭Ω'f(ρsinφcosθ,ρsinφsinθ,ρcosφ)ρ2sinφdρdφdθ

1:18:15关于那个 ρ2sinφ，老师说「是需要证的，但是咱就不证了」——原理和极坐标那个 r 同源：把小块看成长方体，三条边是 dρ、ρdφ、ρsinφdθ，相乘即得。第三条边带 sinφ，因为沿 θ 方向走的是纬圈，而纬圈半径是 ρsinφ 而不是 ρ。

1:10:35为什么定范围的顺序是 θ、φ、ρ，而且不能乱

老师把这一步编成一个动作：想象自己坐在原点上，是个小机器人。

  1. 先平扫 θ。「从 x 轴的正方向开始转」——「为了把立体里边的每一个点都扫一遍」；整个半球体是 0 到 2π。
  2. 再上下扫 φ。「φ=0 朝下走」，一直走到「转不动了」为止；半球体是 0 到 π2（「这不是个半球体吗」）。
  3. 最后伸手量 ρ。「在转的过程中，这个点的距离从零开始，最远距离是几？」半球体就是 0 到 1。

1:11:35老师形容这个过程是「边转边给你扇扇子」——先绕圈、再抬头低头、最后伸手。顺序固定：θ 定了 φ 才能定，两者都定了 ρ 的上限才有意义。

例 61:07:50计算 ∭Ω(x2+y2+z2)dV，其中 Ω 是上半球体 x2+y2+z2≤1、z≥0。

思路：练一遍「小机器人」的三步扫描

范围：θ 从 0 到 2π（平扫一圈），φ 从 0 到 π2（扫到赤道就停，下面空的），ρ 从 0 到 1。被积函数用二级结论 (x2+y2+z2)=ρ2，体积元素是 ρ2sinφ：

∭Ω(x2+y2+z2)dV=∫02πdθ∫0π/2sinφdφ∫01ρ4dρ=2π⋅1⋅15
∭Ω(x2+y2+z2)dV=25π

要点：能「各自算再相乘」的前提是三个积分限都是常数（在球面坐标里区域是个「长方体」），且被积函数能拆成三个单变量因子的乘积。1:15:02漏掉 ρ2sinφ 是本节最常见的失分点——老师自己也说「有时候是故意的，有这次是真的忘了」。

例 71:14:15计算 ∭Ω(x2+y2+z2)3/2dV，其中 Ω 由球面 x2+y2+z2=1 与圆锥面 z2=3(x2+y2) 围成（取锥面上方那块）。

思路：φ 的上限要自己算出来，这是本题唯一的新东西

θ 照旧 0 到 2π。φ 的上界由锥面给出：z=3x2+y2 说明 tanφ=13，所以 φ 从 0 到 π6。1:19:25老师是「站在原点上」量出来的：「转到这儿就转不动了，底下是空的。」

被积函数 (x2+y2+z2)3/2=(ρ2)3/2=ρ3，再乘体积元素里的 ρ2sinφ，合起来是 ρ5sinφ：

∭Ω(x2+y2+z2)3/2dV=2π(1−32)⋅16=π6(2−3)

要点：「球体被圆锥截」是球面坐标最典型的信号。锥面在球面坐标里就是「φ 等于常数」：z=kx2+y2 对应 φ=arctan1k，这个角不必靠图猜。

例 81:26:45（课本例题）球面过原点、半径为 a，用半顶角为 α 的圆锥面去截它，求锥面内那一块立体的体积。

思路：本节唯一的难点——ρ 的上限随 φ 变

1:24:21老师特意提醒别把图画错：「你不要以为他这个球心是在原点，不是，他的球心是在上面。」球心在 z 轴上、球面过原点，沿 z 方向的直径是 2a。

θ 仍是 0 到 2π；φ 从 0 到 α。难在 ρ：1:26:45看一个过 z 轴的截面，球过原点、直径 2a，取任意一条与 z 轴成 φ 角的射线，「直径所对的圆周角是直角」，它与球面的交点到原点的距离就是 2acosφ（φ 角的邻边）：

ρ∈[0,2acosφ]
V=∫02πdθ∫0αsinφdφ∫02acosφρ2dρ=2π∫0α8a3cos3φ3sinφdφ

1:28:29注意φ 在这里不能提前算——内层 ρ 的上限带着 φ：「φ 你能提前先求吗？不能，因为后头有 φ。」积分得

V=43πa3(1−cos4α)

要点：验证一次极端情形——当 α→π2 时 cosα→0，公式给出 43πa3，正好是半径 a 的整个球的体积。「ρ 上限带 φ 时，φ 的积分必须放到最后」，这是本节最后一条硬规矩。

记忆入口 · 一眼回忆

一句话

三重积分只有两步：写上下限、挑切法。切法一变，微元就跟着变。

四个微元

  • 直角坐标：dV=dxdydz
  • 柱面坐标：dV=rdrdθdz（就是极坐标那个 r）
  • 球面坐标：dV=ρ2sinφdρdφdθ
  • 平面极坐标：dσ=rdrdθ（对照用，见 【黑板】二重积分{极坐标}）

两套切法

  • 投影法：投影 → 手电朝上照 → 下表面、上表面就是 dz 的上下限 → 剩下的是二重积分（投影是圆就换极坐标）。
  • 截面法：定 z 的范围 → 取一个 z 看截面 Dz（一般与 z 有关）→ 先算截面上的二重积分 → 再对 z 积。
  • 球面坐标：小机器人先平扫 θ、再上下扫 φ、最后伸手量 ρ；上限随 φ 变时，φ 不能提前积掉。

选型判据（背这一条）

看截面 会不会随 z 变→ 不变 截面法最舒服→ 会变 投影法优先→ 球或锥 直接上球面坐标

四个坑

  1. 截面半径当成常数。x2+y2≤z 的半径是 z，不是 z、也不是 2。
  2. 忘了截面与 z 有关。三棱锥的截面是 x+y≤1−z，「得加件衣服」。
  3. 漏掉 ρ2sinφ。那个 sinφ 来自纬圈半径 ρsinφ。
  4. ρ 上限含 φ 时提前把 φ 积掉。例 8 里 2acosφ 一旦代入，φ 必须留到最后。
