P083空间曲线的切线和法平面：切向量是唯一的钥匙

一句话核心

空间曲线在一点处的切线方向，就是曲线在该点的切向量 ⃗r'(t0)；过这一点并且与切线垂直的平面叫法平面，它的法向量取的还是同一个切向量。于是整节真正需要算的只有一件事：先把切向量求出来，剩下的全是往点向式、点法式里代数。

先把名字分清：曲线配「切线 + 法平面」

00:00这一节和下一节的标题长得几乎一样，只有两个字之差，所以第一件事不是算题，而是把名字对齐。老师说得很实在：这里到底是切线还是切平面、是法线还是法平面，大家得注意区分一下。

给的是一根绳子——或者说一条空间的曲线。在曲线上挑一个点，沿着这条绳子的方向画一条直线，这条直线就叫曲线的切线。这个比喻把要害抓住了：切线的方向是一维的，只要曲线上这一点处「朝哪个方向走」，切线就定死了。

00:50接着定义另一个对象：过这一点、并且与切线垂直的平面，叫这条曲线的法平面。老师讲这段话时嘴快说成了「和切线平行的平面叫法平面」，马上改口：「我刚才说平行还是垂直啊？我说错了，就是过这个点与它的切线垂直的平面。」这个口误值得单拎出来——法平面与切线是垂直关系，不是平行关系，说反了整道题就全错。

为什么「法」这个字总带「垂直」的意思

「法」的老家是「法线」：垂直于曲线的直线。到了空间里，垂直于一条曲线的对象不止一种，于是「法」被用来指那类垂直于切方向的东西：曲线的法平面、曲面的法线，都是这个意思。

更省事的记法是数维数。曲线的维数是 1，切线也是 1 维；曲面是 2 维，切平面也是 2 维——「切」出来的对象与原来的对象同维，所以曲线配切线、曲面配切平面。而「法」出来的对象永远是补足到 3 维的那一个：曲线缺 2 维，所以配一张法平面；曲面缺 1 维，所以配一条法线。名称全都不必死记，数一下维数就出来了。

切向量：整节唯一需要算的东西

02:07设空间曲线由参数方程给出：x=x(t)、y=y(t)、z=z(t)。在 一元向量值函数及其导数 里我们做过一件事——把这三个分量捆成一个向量值函数

⃗r(t)=(x(t),y(t),z(t))

并且证明了它的导数 ⃗r'(t0) 就是曲线在点 P0 处的切向量。所以切向量根本不用另想办法求，就是逐分量求导：

⃗r'(t0)=(x'(t0),y'(t0),z'(t0))

其中 (x0,y0,z0)=⃗r(t0) 是切点。整节的「计算量」到此为止：三个一元函数求导，再代人。剩下的全是写方程的格式工作。

「切线方向就是切向量方向」到底在说什么

要小心，这里有两层意思，混在一起最容易出岔子。

第一层是几何。切向量落在切线上，方向与切线一致。这不是巧合：切线本来就是割线的极限，而割线方向正是 Δ⃗r=⃗r(t0+Δt)−⃗r(t0) 的方向，除以正数 Δt 不改变方向。让 Δt→0，割线转成切线，方向就交给 ⃗r'(t0)。所以「曲线在一点的切方向」这个捉摸不定的东西，被一个可以计算的对象替代了。

02:07第二层是角色。同一个切向量要演两个身份。求切线时它是方向向量，求法平面时它是法向量。为什么可以一物两用？因为「法平面与切线垂直」这句话里的「垂直」，是用切线整条直线的方向去定义的；方向向量决定了切线，所以它自然也就垂直于整张法平面。

两个方程，一正一反

04:15把切向量拿到手之后，两个方程都是直接把公式写出来即可。切线是一条直线、已知过点 (x0,y0,z0)、方向向量是 (x',y',z')，所以用点向式：

x−x0x'(t0)=y−y0y'(t0)=z−z0z'(t0)

法平面是一张平面、已知过同一个点、法向量也是 (x',y',z')，所以用点法式：

x'(t0)(x−x0)+y'(t0)(y−y0)+z'(t0)(z−z0)=0

例 1：参数式曲线，最标准的题型

例 105:27设曲线 x=t、y=t2、z=t3，求它在点 (1,1,1) 处的切线与法平面。

思路：先把切点对应的参数值 t0 定出来，再逐分量求导

第一步，找 t0。本题的三个坐标都是 1，代人参数方程立刻看出 t0=1。这一步不能跳：切向量的公式里要在 t0 处取值，切点的坐标也要用 t0 算。

第二步，求切向量。三个分量各自求导：x 关于 t 是 1，y 是 2t，z 是 3t2。所以

⃗r'(t)=(1,2t,3t2)

把 t=1 代进去（06:59老师特别强调「111 朝里代，其实不是用 111，而是 t 等于 1 朝里代」）：

⃗r'(1)=(1,2,3)

第三步，写切线。点是 (1,1,1)，方向向量是 (1,2,3)，直接套点向式：

x−11=y−12=z−13

第四步，写法平面。点不变，切向量改当法向量，套点法式：

1⋅(x−1)+2⋅(y−1)+3⋅(z−1)=0

展开整理：x−1+2y−2+3z−3=0，即

x+2y+3z=6

要点：两道题问的是同一个切向量，只是把它摆到了两个不同的位置上。前三个分量求导不会出错，真正容易翻车的是后面这种——把方向向量和法向量的位置搞反，写出来的式子照样「像」，但意思完全不同。

07:59老师原话 神奇的是我们课本竟然和我写的一样……这个 x−1 前面没有一呀，这个小括号咱其实一般是不加的，加得有点多余。

他在说的是课本把 1⋅(x−1) 写成了 1(x−1)，中间的乘号与系数 1 都可以省，小括号也就跟着多余了。写成 x−1+2(y−1)+3(z−1)=0 是所有人的习惯。

特殊情形：曲线写成 y=y(x)、z=z(x)

08:43课本接着讨论了一种特殊情形：如果曲线的 y 与 z 都是 x 的函数，也就是曲线写成

y=y(x),z=z(x)

那么它其实还是参数式，只不过参数换成了 x 自己。既然 x 是参数，三个分量就是 x、y(x)、z(x)，逐分量求导得1、y'(x)、z'(x)：

⃗r'(x0)=(1,y'(x0),z'(x0))

于是切线方程是

x−x01=y−y0y'(x0)=z−z0z'(x0)

法平面则是

1⋅(x−x0)+y'(x0)(y−y0)+z'(x0)(z−z0)=0

老师给的建议很明确：这一页 PPT 上的这两个公式没有必要记，用前面那个一般形式现场推一遍就行，而推的关键只有一句话——把 x 看成参数，x 对 x 求导等于 1。

那个 1 是本节的头号丢分点

「切向量是 (1,y',z')」里的第一个分量 1，不是题目给的，也不是猜的，它来自 x 关于 x 求导。16:52讲例 2 时老师停下来专门问了一句：「这个 1 从哪来的？——1 是从这儿来的，xyz 都看作是 x 的函数，x 对 x 求导是个 1。」

漏掉它，切向量就少了第一个分量，切线方程的分母、法平面的第一个系数会一起崩掉。同样地，当曲线写成 x=x(y)、z=z(y) 时，切向量是 (x',1,z')——谁是自变量，谁的位置上就是 1。

例 2：两个曲面相交给出的曲线

10:10课本上一段一般性的理论，老师说自己看着都「痛不欲生」，于是直接跳到例子。他要处理的是一种新的给法：曲线不是直接用参数方程给出来的，而是用两张曲面相交给出来的：

{F(x,y,z)=0G(x,y,z)=0

例 211:02设曲线由 x2+y2+z2=6 与 x+y+z=0 相交而成，求它在点 (1,−2,1) 处的切线与法平面。

思路：把 y、z 都看成 x 的函数，方程两边对 x 求导，解出 y' 与 z'

11:02先看清楚这两张曲面是什么：上面那个是球面，下面那个是平面。老师当场拿了个球、又拿了个平面比划：「这个球用一个平面这么一切，它其实就是个圆。」所以这条交线是一个平面圆——它完全落在 x+y+z=0 这张平面里，圆心在原点。

第一步，确认点在曲线上。代进去：12+(−2)2+12=1+4+1=6 ✓；1−2+1=0 ✓。这个检验必须做，代错点后面全错。

第二步，把 y、z 看成 x 的函数，两边对 x 求导。12:07这里有一个必须说清的细节：是对 x 求导，不是求偏导。因为在这条曲线上 y 与 z 都只跟着 x 变，整体上只有一个自变量。

球面方程对 x 求导（y、z 是复合函数）：2x+2y⋅y'+2z⋅z'=0。约掉 2：

x+yy'+zz'=0

平面方程对 x 求导：1+y'+z'=0，也就是

y'+z'=−1

第三步，解方程组。两式合起来是y'、z' 的二元一次方程组：

{yy'+zz'=−xy'+z'=−1

15:43系数行列式是 |yz11|=y−z。用克莱姆法则把两个未知数解出来：

y'=z−xy−z,z'=x−yy−z

第四步，代人 (1,−2,1)。

y'=1−1−2−1=0,z'=1−(−2)−2−1=3−3=−1

16:52再加上来自 x 对 x 求导的那一项，切向量就是

⃗r'=(1,0,−1)

第五步，写切线。点 (1,−2,1)，方向向量 (1,0,−1)。分母上出现了 0，点向式不能照抄：分量为 0 意味着「这个方向上的改变量恒为零」，也就是 y 保持不变。规范的写法是把这一项单独摘出来：

x−11=z−1−1,y+2=0

第六步，写法平面。法向量取同一个 (1,0,−1)：

1⋅(x−1)+0⋅(y+2)+(−1)⋅(z−1)=0

17:40整理得 x−1−z+1=0，即

x−z=0

要点：这一道题把三个易错点全踩了一遍——切向量第一个分量的那个 1、分母为 0 的写法、还有前面「对 x 求导」与「求偏导」的区别。老师说得很轻松：「这就是前面那一堆理论讲的东西，你看我这个例子就得。」

这一步最容易错

把 x2+y2+z2=6 两边对 x 求导时，把 y、z 当成常数，写成 2x=0。那是求偏导的做法。这里 y、z 都随 x 变，必须按复合函数求导补上 y' 与 z'。判据很简单：题目问的是「沿着这条曲线」，曲线上 y、z 就不是自由的。

易错清单

一 · 切线、法平面位置搞反

切向量当方向向量写出的是切线（点向式，三项连等）；当法向量写出的是法平面（点法式，三项相加等于 0）。记不清就回看上面那张图：连等式是直线，和式是平面。

二 · 漏掉切向量里的 1

只要曲线写成 y=y(x)、z=z(x)（或由两曲面相减消去一个变量得到）的形式，切向量一定是 (1,y',z') 这种带 1 的样子。这个 1 来自「x 对 x 求导」，不是任何题目条件。判据：切向量有三个分量，任何时候都不该只剩两个。

三 · 分母为 0 时照抄点向式

点向式 x−x0x'=y−y0y'=z−z0z' 只在三个分量全不为 0 时可以直接写。某个分量为 0 时，把对应的那一个改成单独的等式：例如 y'=0 就写成 x−x0x'=z−z0z' 且 y=y0。例 2 里 y'=0，结果就是 y+2=0——直线落在平面 y=−2 内。

四 · 把「对 x 求导」写成「求偏导」

由两曲面相交给出的曲线，y 与 z 都随 x 变，所以求导时要把 y'、z' 补上。这两者的区别不在于写法，而在于「有没有只让一个变量动」。沿着曲线走的时候，三个坐标是绑在一起动的。
