P132【黑板】隐函数求导：公式法、直接法与同一个 F 的两副面孔

一句话核心

由一个方程确定的隐函数，导数可以用一条公式直接算：dydx=−FxFy，三元情形是 ∂z∂x=−FxFz、∂z∂y=−FyFz。公式好记（一个负号 + 交叉对应），但这一节真正的难点是理解它怎么来的：直接法里 y 是 x 的函数，公式法里 F 是 x,y 的两个独立变量——同一个 F，两副面孔。

一元隐函数：老朋友与新公式

00:00这一节按课本的顺序分三块：一元隐函数、二元隐函数、隐函数方程组。一元那块其实不陌生——上学期就讲过。老师随手举的例子是 xy+ey=sinx：x 与 y 之间确实存在函数关系，但「这个 y 你提不出来」，所以叫隐函数。

对这种情况，老办法是直接求导法：两边同时对 x 求导，心里时刻记住一句话——y 是 x 的函数。这个「心里的印象」是全部关键，01:28老师特意强调：「这一点大家一定要记住，因为这一点和我们一会要讲的这一节的方法，是不是相矛盾的？」

例 1设 xy+ey=sinx 确定 y=y(x)，用两种方法求 dydx。

方法一：直接求导法（两边同时对 x 求导）

逐项看左边：xy 是乘积，x 求导得 1，所以得 y+xy'；ey 是复合函数，外层求导还是 ey，而 y 是 x 的函数，所以还要补一个 y'。右边 sinx 求导得 cosx：

y+xy'+eyy'=cosx

把含 y' 的项留在左边，其余移到右边，再把 y' 提出来：

(x+ey)y'=cosx−y
y'=cosx−yx+ey

注意 ey 那一项——它带复合结构，所以求导之后要「多乘一个 y'」。这是直接法里唯一容易漏的地方。

06:24方法二：公式法

先把方程整理成右边等于零的形状，把左边整块记作 F(x,y)：

F(x,y)=xy+ey−sinx=0

这里是最关键的心态转变：04:43计算 F 的偏导时，要把 F 看成 x 与 y 两个相互独立的变量的函数——求 Fx 时 y 当常数，求 Fy 时 x 当常数：

Fx=y−cosx,Fy=x+ey

（求 Fx：xy 里 y 是系数得 y；ey 是常数得 0；−sinx 得 −cosx。求 Fy：xy 得 x；ey 得 ey。）套公式

dydx=−FxFy=−y−cosxx+ey=cosx−yx+ey

与直接法得到的答案分毫不差。

03:22隐函数存在定理 · 一元情形

设 F(x,y) 在点 P(x0,y0) 的某邻域内具有连续偏导数，F(x0,y0)=0，且 Fy(x0,y0)≠0，则方程 F(x,y)=0 在该点附近确定一个可导的隐函数 y=y(x)，并且

dydx=−FxFy

其中 Fx、Fy 是把 F 看作 x,y 的二元函数、并且认为 x 与 y 相互独立时求出的偏导。

定理前面的条件里，唯一值得留意的是 Fy≠0——因为它出现在分母上。老师的态度很干脆：这部分「都是计算题」，所以那些细节他不准备讲很多。使用时只有三个动作：把方程整理成右边为零；把左边整块记为 F；算偏导时把 F 看成字母之间互不相关的多元函数。

公式是怎么来的：两边同时对 x 求导

08:28老师先声明这不是严格的证明——「这个他的证明过程其实是挺复杂的，我们也不想严格地去证了」——但给了一个很好用的简单推导。

第一步，认路。把 F 看成 x 与 y 的函数，而 y 又是 x 的函数，所以 F 到 x 有两条路：一条是 F→x，一条是 F→y→x。按 【黑板】多元复合函数求导（1） 的链式法则，两边同时对 x 求导得

Fx⋅1+Fy⋅dydx=0

其中那个 1 就是 dxdx，也就是「直接到 x 那条边」的系数。

第二步，解出来。把第二项移到右边：Fydydx=−Fx，两边同除 Fy（这就是要求 Fy≠0 的原因），立刻得到公式。

最要紧的是这一步的观感：推导要从「两边同时对 x 求导」出发，说明公式法处理的对象本来是「y 是 x 的函数」；可一旦用上公式，Fx、Fy 又必须按「x 与 y 相互独立」来算。同一个 F，两种身份——这是本节所有困惑的总源头。

一阶用公式，二阶用直接法

例 211:07设 x2+y2−1=0，求 dydx 与 d2ydx2。

思路：一阶套公式最省事；二阶别再想公式，直接对一阶的结果再求一次导

一阶。记 F=x2+y2−1，则 Fx=2x（y 当常数）、Fy=2y（x 当常数）。套公式：

dydx=−2x2y=−xy

二阶。10:34老师在这里停了一下，专门讲了一段心态：课本上确实给了一个求二阶的公式，但「这个书上的公式你看一看，这玩意谁能记得住啊？」他的建议是——二阶就别用公式了，把一阶的结果再对 x 求一次导。

注意此刻 y 又变回 x 的函数了，所以 (−xy) 要按商的求导法则处理：

d2ydx2=−1⋅y−x⋅y'y2

分子里的 y' 有现成的表达式，代进去：

d2ydx2=−y−x(−xy)y2=−y+x2yy2=−x2+y2y3

再回头用原方程 x2+y2=1：

d2ydx2=−1y3
这道题真正要记的是「方法切换」

第一步和第二步用的不是同一种思路：第一步是公式法（F 是 x,y 的独立变量二元函数），第二步必须切回直接法（y 是 x 的函数）。要是硬把公式法也用在第二步，就得处理 ∂∂x(−FxFy) 这种嵌套偏导，反而更绕。老师的结论是：「这个二阶导，千万不要记。」

二元隐函数：F(x,y,z)=0

14:56由方程 F(x,y,z)=0 确定的隐函数，通常是「z 是 x,y 的函数」。这时 x、y 是自变量，z 是被确定的因变量，所以要写两个偏导。公式与一元完全平行：

隐函数存在定理 · 二元情形

若 F(x,y,z) 在点 P 的某邻域内有连续偏导数，F(P)=0，且 Fz(P)≠0，则方程 F(x,y,z)=0 在该点附近确定唯一的 z=z(x,y)，且

∂z∂x=−FxFz,∂z∂y=−FyFz

记忆点和一元一样就两条：第一，一定有负号；第二，交叉对应——对 x 求的那个偏导，分子是 Fx；对 y 求的，分子是 Fy；而分母永远是 Fz，因为 z 是被解出来的那一个。17:40还要再强调一次：Fx、Fy、Fz 是把 F 看成 x,y,z 三个相互独立的变量时求出的偏导，求谁的时候另外两个都当常数。

16:20二元公式的推导，以及老师那句「划线别画多了」

推导方式和一元一模一样，只是树多一个孩子。把 F 看成 x,y,z 的函数，而 z 又是 x,y 的函数，那么 F 到 x 有两条路：一条直接到 x，一条绕经 z。两边同时对 x 求偏导：

Fx⋅1+Fz⋅∂z∂x=0

移项、同除 Fz，就得到 ∂z∂x=−FxFz。

老师画这张树时专门提醒了一句：「注意划线别画多了。」因为 x 与 y 之间没有函数关系，所以在树上x 和 y 之间不许连线；只有 z 才同时连着 x、y。这与 【黑板】多元复合函数求导（1） 的规矩完全一致——和谁有关就连谁，无关的绝不连。多连一条线，公式里就会冒出一个本不存在的项。

例 318:30设 x2+y2+z2−4z=0 确定 z=z(x,y)，求 ∂z∂x 与 ∂z∂y。

思路：先算分母 F_z（两个公式共用），再算两个分子

先算分母。Fz 在两个公式里都要用，优先算、算完用两次：

Fz=∂∂z(x2+y2+z2−4z)=2z−4

（x2、y2 与 z 无关得 0；z2 得 2z；−4z 得 −4。）

再算两个分子。Fx=2x（y,z 都当常数），Fy=2y。于是

∂z∂x=−2x2z−4=x2−z,∂z∂y=y2−z

换成直接法验一遍。19:33两边同时对 x 求偏导，此时 y 是常数，而 z 是 x,y 的函数：

2x+2zzx−4zx=0⇒(2z−4)zx=−2x⇒zx=x2−z

完全一致。

再对 y 走一遍直接法。23:01这次 x 是常数：x2 求导得 0，y2 得 2y，z2 得 2zzy，−4z 得 −4zy：

2y+2zzy−4zy=0⇒zy=y2−z

与公式法一致。老师对这两种方法的态度是「都可以」，选哪个只看熟练程度。

直接法里唯一需要留心的地方

对 x 求偏导时，y 是常数，但 z 是 x 的函数，所以 z2 是复合的，求导得 2zzx；−4z 也是复合的，得 −4zx。这两个 zx 都要写出来，它们最后被提出来，才能解出方程。漏掉 −4z 的那个 zx，分母就变成 2z，答案整块错掉。

直接求导法公式法
F 的身份 F(x,y(x))：y 是 x 的函数 F(x,y)：x、y 是两个相互独立的变量
动作 两边同时对 x 求导，遇到 y（或 z）就补一个导数，再把它解出来 分别求出 Fx、Fy（或 Fz），代入 −FxFy
优点 思路自然，不需要额外记公式；求二阶时更顺手 求一阶时快，一步到位，不容易漏掉复合结构
代价 项数多，要在脑子里持续记住谁是函数 必须先把常数挪到左边；求二阶时反而更麻烦
适用 二阶及以上的导数 只要求一阶导数时

方程组确定的隐函数：两边求偏导 + 克莱姆法则

23:53这一节最后是方程组。老师先给了一句实话：课本上这部分理论「我觉得大家可以不看了」——满篇的公式，「这是个人就记不住啊，对吧？也没有必要记」。他干脆把范围缩到最小：「我一共给大家讲两个例子，你只要把这两个例子理解就行。」

第一个例子是三个变量、两个方程。这里 x 是自变量，y 和 z 都随 x 变化，但它们各自的表达式解不出来，所以只能写成 y=y(x)、z=z(x)。25:44由于 y 与 x 有关、z 也与 x 有关，它们对 x 都是求导，不是求偏导——这一点必须先在脑子里定下来。

例 4设方程组 {x+2y+3z=1x2+y2+z2=2 确定 y=y(x)、z=z(x)，求 dydx 与 dzdx。

思路：两边同时对 x 求导，整理成关于 y′、z′ 的二元一次方程组，再用克莱姆法则

第一步，两边同时对 x 求导。第一式：x 求导得 1，2y 得 2y'，3z 得 3z'，右端常数得 0。第二式：x2 得 2x，y2、z2 都是复合的，分别得 2yy'、2zz'，约掉公因子 2 之后写成：

{1+2y'+3z'=0x+yy'+zz'=0

第二步，把未知量挪到一边。把含 y'、z' 的项留在左边，常数项移到右边：

{2y'+3z'=−1yy'+zz'=−x

第三步，克莱姆法则。28:17现在这是一个以 y'、z' 为未知量的二元一次方程组，系数行列式是

D=|23yz|=2z−3y

把右端的 (−1−x) 分别替换第 1 列、第 2 列，得到 D1=−z+3x、D2=y−2x，于是

y'=3x−z2z−3y,z'=y−2x2z−3y

条件是 2z−3y≠0——就是分母不为零那句老话。

这一步看不懂就把它翻译回线性代数

我们要求的是 y'、z' 这两个数。它们满足的是一个非齐次线性方程组，只不过「系数」是含 y,z 的式子、「常数项」含 x。这并不影响 【补充】克莱姆法则 克莱姆法则的用法：把系数原样排成 D，把右边那一整块当成常数项去替换对应的列即可。

32:24第二个例子是四个变量、两个方程，老师坦言「这一部分是挺难的」。他从头强调了一次最要紧的判断：「你先看一看他最终求的那个东西——他是 u 对 x、v 对 x、u 对 y、v 对 y，这样的话你就知道了，是 u,v 对 x,y 求偏导。」

例 533:53设方程组 {xu−yv=0yu+xv=1 确定 u=u(x,y)、v=v(x,y)，求 ∂u∂x、∂v∂x。

思路：先认清谁是自变量、谁是函数；两边对 x 求偏导后，再解一个二元一次方程组

第一步，理清关系。这里有 x,y,u,v 四个变量。其中 x、y 是自变量，u、v 都是 x,y 的隐函数——这是整道题的前提，忘了它后面全乱。

第二步，两边同时对 x 求偏导。此时要记住三件事：y 当常数；u 是 x,y 的函数；v 也是。逐项处理，右端常数求导得 0：

{u+xux−yvx=0yux+v+xvx=0

（第一式里 xu 是乘积，求导得 u+xux；−yv 里 y 是常数、v 是函数，得 −yvx。第二式同理。）

第三步，整理成标准线性方程组。把未知量 ux、vx 挪到一边，其余移到右边：

{xux−yvx=−uyux+xvx=−v

第四步，克莱姆法则。35:52系数行列式是 x2+y2，把右端项分别替换第一列、第二列：

ux=1x2+y2|−u−y−vx|=−xu−yvx2+y2
vx=1x2+y2|x−uy−v|=−xv+yux2+y2

对 y 求偏导的情形完全类似：x 当常数，方程组变成 {xuy−yvy=vyuy+xvy=−u，同样用克莱姆法则解出来即可。38:04老师的结束语很实在：「这个题你理解了吗？那这部分就行了。」

本节四个反复被踩的坑

一、右边有常数，没有先挪到左边。公式法要求先写成 F(x,y)=0 的形状。有意思的是：忘了挪，结果其实一样——因为常数对 x、对 y 求偏导都得 0，Fx、Fy 不受影响。但规范写法是先把右边化归为零。

二、算 Fy 时给 ey 补了一个 y'。这是「直接法后遗症」。公式法里 y 只是一个自变量，ey 对 y 求导就是 ey，不需要再补任何东西。直接法里「遇到 y 要补 y'」，公式法里「遇到 y 就把它当普通自变量」——这两句话是同一个人在两副面孔下说的。

三、二阶还想套公式。二阶就转回直接法：把一阶的结果当成「y 是 x 的函数」再求一次导，该用商法则就用商法则。

四、方程组情形去背定理结论。那些公式长得实在记不住，「做题的话还就只能现推」。走熟四步流程比背公式可靠得多。

记忆两点

  • 一定有负号（来自移项，不是规定）。
  • 交叉对应：求谁的偏导，分子就是谁；分母永远跟着因变量走。

用之前的三步准备

  1. 把方程整理成右边等于 0（常数忘挪结果不错，但可能扣分）。
  2. 把左边整块记为 F。
  3. 算偏导时把 F 看成所有字母相互独立的多元函数。

两副面孔（最重要）

直接法 y 是 x 的函数，遇 y 补 y'⇋ 公式法 F 是多元函数，另一字母当常数

  2. 两边同时对同一个自变量求导。
  3. 整理成关于待求偏导的线性方程组。
  4. 克莱姆法则（【补充】克莱姆法则）。
