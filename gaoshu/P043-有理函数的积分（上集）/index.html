P043有理函数的积分（上）

一句话核心

有理函数就是多项式除以多项式。假分式（分子次数高）先化真分式，真分式再按分母的四种因式分解情形做部分分式分解。二次因式的分子必须设 Ax+B，不是只设 A。

什么是有理函数

00:00有理函数就是多项式除以多项式的有理分式，例如 x2+5x−1、x3+6x2+1。本节目标就是求这类分式的不定积分。先分两类：

假分式
分子次数 ≥ 分母次数，如 x2+1x2−2x+1、2x4+x2+3x2+1
真分式
分子次数 < 分母次数，如 xx3+6
为什么假分式要先化真分式

01:02真分式才好积。假分式里那块「整式部分」直接逐项积分就行，剩下的真分式才能用部分分式拆解。所以第一步永远是：把假分式变成「整式 + 真分式」。老师直言这部分课本写得差，下面两招才是实战主力。

化真分式：两招

第一招 多项式除法。02:32课本只教这一招，老师却先交了底：我们绝大部分同学是没有学过这个的，实战里大家更爱用下一招「凑」。不过它和小学除法竖式是同一个结构，值得看一遍。

  1. 缺项补 0。分子 2x4+x2+3 缺 x3 项、也缺 x 项，竖式里要先写成 2x4+0x3+x2+0x+3，否则位对不齐，后面全乱。
  2. 最高次相除。2x4÷x2=2x2，商先记下 2x2；乘回去得 2x4+2x2，相减余 −x2。
  3. 把后面的项落下来。接上 0x 和 3，得 −x2+0x+3；再除：−x2÷x2=−1，商补上 −1；乘回去得 −x2−1，相减余 4。
  4. 停手。余数 4 是 0 次，已经低于分母的 2 次，除不动了。商为 2x2−1、余数为 4——正是下面例 1 要用的那个结果。

05:22老师用小学除法作类比：13÷4 商 3 余 1，写成 13=4×3+1。多项式这边一模一样，只是「余数」从一个数换成了一个次数更低的多项式。我们同学现在的水平已经直逼四五年级奥数的水平了——这句调侃背后其实只有一件事：商 + 余数 / 除数。

第二招 按分母凑（老师推荐的主流）。06:25老师原话：这种分式啊，分母你是没有办法去改变它的，我们能改变的其实就是分子。凑的诀窍是从高次往低次削——先用分子最高次项去凑出分母的一个倍数，把这块削掉，再拿剩下的继续往下走。下面这道题就是标准动作：

例 104:03把 2x4+x2+3x2+1 化为真分式并积分。

思路：分子按分母 x2+1 的模样凑

把 2x4 写成 2x2(x2+1) 消掉一截，余下的再凑：

2x4+x2+3=2x2(x2+1)−(x2+1)+4

除以 x2+1：

2x4+x2+3x2+1=2x2−1+4x2+1

于是逐项积分——整式部分直接积，真分式部分套公式：

∫(2x2−1)dx+∫4x2+1dx=23x3−x+4arctanx+C

剩下的 4x2+1 正是本页后半段要主攻的「真分式」，它自己一项就贡献一个 arctan。假分式处理完的收益就在这里：整式部分当场积掉，只留一小块真分式交给后面的技术。

11:45分母是一次式：从最简单的一类练起

11:45真分式怎么积，老师是从分母最简单的情形一层层往上走的。这一整类有一个「母公式」：

∫dxx=ln|x|+C

分母是一次式时，目标永远是把它整个当整体，凑成 duu。下面四道是逐步加难度的练习——老师说这节课需要大量的大家自己来动手，边听边练。

例 211:45求 ∫dx2x−3。

思路：凑出分母的微分 d(2x−3)=2dx

D 里凑一个 2x−3，外面配一个 12 抵消：

∫dx2x−3=12∫d(2x−3)2x−3=12ln|2x−3|+C

要点：D 里可以任意加减常数，也可以乘除非零常数（外面补倒数就行）。分母是一次式，就是把它凑成 duu。

例 313:02求 ∫3x+22x−5dx。

思路：分子分母都一次，分子次数不低 —— 先化真分式

这是假分式。按分母 2x−5 去凑分子：3x=32(2x−5)+152，于是

3x+2=32(2x−5)+152+2=32(2x−5)+192

除以分母，整式与真分式分家：

3x+22x−5=32+19/22x−5

第二块照例 2 的办法凑，逐项积分：

∫3x+22x−5dx=32x+194ln|2x−5|+C

15:42老师还演示了一条技巧版：先把 32 整个提出来，3x+22x−5=32⋅x+23x−52，再把分子补成 (x−52)+196，得 32(1+19/6x−52)，结果完全一样。你想来点技巧也行——两条路都通，赶时间就用凑的，想少写点字就提系数。

例 417:24求 ∫4x2−x+22x+1dx。

思路：分母一次、分子二次 —— 还是按分母凑，只是要凑两刀

分母最高次是 2x，分子的 4x2 是它的 2x 倍，先凑出 2x(2x+1)=4x2+2x：

4x2−x+2=2x(2x+1)−3x+2

剩下的 −3x 是 2x 的 −32 倍，再凑一块 −32(2x+1)=−3x−32：

4x2−x+2=2x(2x+1)−32(2x+1)+72

除以分母就干净了：

4x2−x+22x+1=2x−32+7/22x+1

逐项积分：

∫4x2−x+22x+1dx=x2−32x+74ln|2x+1|+C

要点：这就是「按分母凑」的通用节奏——削一刀再削一刀，直到残余的次数低于分母。因为分母是一次，最后剩下的真分式必然只有一项。

例 519:13求 ∫x2x+1dx 与 ∫x3x−1dx。

思路：在分子上「借一个」出来，凑成可因式分解的样子

第一题：分母是 x+1，就给分子借 +1 再 −1，借出来的 x2−1 正好含因式 x+1：

x2x+1=x2−1+1x+1=(x−1)+1x+1
∫x2x+1dx=12x2−x+ln|x+1|+C

21:07第二题同理，借法换成立方差 x3−1=(x−1)(x2+x+1)：

x3x−1=x3−1+1x−1=x2+x+1+1x−1
∫x3x−1dx=13x3+12x2+x+ln|x−1|+C

要点：分母是 x±1 时，在分子上借一个 1，造出平方差或立方差，比多项式除法快得多。借了要记得还——那个 +1 最后还留在分子上，变成单独一项。

22:32分母是一次式的部分到此结束。老师顺口点了一句重点：例 3、例 4 里那个「整式部分」是直接能积的，真正需要技术的只有后面那个真分式——难度全在真分式里。

22:32分母是二次式：先配成 1+(⋅)2

22:32分母升到二次，母公式就换成了

∫dx1+x2=arctanx+C

一切以它作原型。可卷面上的分母往往写成 3x2+2、x2+4 这种，和 1+x2 长得不像——办法是硬把它配成「1+ 某整体的平方」，提出去、补进来的每一个常数，最后都要在结果里找回来。

例 623:23求 ∫dx3x2+2。

思路：把常数项提到分母外面，让 3x2 变成「整体的平方」

这题的要点不是 x2，而是前面挡着的那个 2。先提一个 2 出来：

∫dx3x2+2=12∫dx1+32x2

现在一半是 1 了，另一半写成平方：32x2=(32x)2。于是分母已符合母公式的模子：

=12∫dx1+(32x)2

整体是 32x，把它凑进 d 里，外面补 23：

=1223arctan(32x)+C=16arctan32x+C

24:35愿意把系数整理一下，写成 66arctan62x+C 也完全一样。老师说得很直白：这个 x 比上根号几，这不很明显它想做成一个整体吗？——看到「常数乘 x」，第一反应就该是「它想当整体」。

外头的系数千万别丢

这一型的失分点几乎全在系数上：提出去的 12、凑进 d 时补的 23，两个都要留下，乘起来才是 16。只写 arctan32x+C 就漏了整条系数。养成习惯：每提一个常数、每补一个常数，都在式子上标一笔，最后统一收拢。

例 725:38求 ∫dxx2+2x+2 与 ∫dx(x+1)2+4。

思路：配方法把一次项收进平方里，再凑母公式

第一题：x2+2x+2=(x+1)2+1，分母刚好是「1+ 一个整体的平方」：

∫dxx2+2x+2=∫d(x+1)(x+1)2+1=arctan(x+1)+C

27:13第二题麻烦一点：分母里那个 4 挡着，必须提出来，提完 (x+1)24 正好写成 (x+12)2：

∫dx(x+1)2+4=14∫dx1+(x+12)2

整体是 x+12，要凑进 d 里就得补一个 2：

=14⋅2arctanx+12+C=12arctanx+12+C

要点：二次分母只有两个动作——先配方把一次项收进括号，再把常数项提出去凑成 1。老师说这类题是「配好了给你的」，练熟之后一眼就能看出该提多少。

例 828:39求 ∫dx(x−1)2。

思路：分母已经是完全平方，当幂函数积，不用 arctan

把 x−1 当整体 u，则 du=dx：

∫(x−1)−2dx=−(x−1)−1+C=−1x−1+C

要点：负指数求原函数是「加一次」：−2+1=−1，所以出来的是 −1 次幂，前面那个负号就来自这里。老师课上专门问了一遍：求原函数是加一次还是减一次？加一次。分母是「整体的平方」时出分式，不是 arctan——这是与例 6、例 7 的分水岭。

真分式的四种情形对照表

28:39真分式能积，靠的是先把分母因式分解，再按因式类型拆。分母因式分解后只有四种因式，对应四种拆法：

情形分母含的因式拆成什么样（待定系数设置）
互异一次因式(x−a)(x−b)⋯Ax−a+Bx−b+⋯（分子设常数）
重一次因式(x−a)kA1x−a+A2(x−a)2+⋯+Ak(x−a)k（分子常数）
不可约二次因式x2+px+q（判别式 <0）Ax+Bx2+px+q（分子设一次 Ax+B）
重二次因式(x2+px+q)kA1x+B1x2+px+q+⋯+Akx+Bk(x2+px+q)k
为什么二次因式分子设 Ax+B、不能只设 A

部分分式的铁律是：每个分式的分子次数 = 该分母因式次数 − 1。一次因式（次数 1）对应分子常数（次数 0）；二次因式（次数 2）对应分子一次 Ax+B（次数 1）。若对二次因式只设常数 Ax2+px+q，它积分只能出 arctan 型，永远得不到 ln 项；而真实分解里还藏着 2x+px2+px+q 这一项，积出来正是 12ln(x2+px+q)——这是「一次项当分子」独有的贡献。只设 A 会漏掉它，分解既不完整、也还原不了原式。更本质地说，二次不可约因式在复数域对应一对共轭复根，合并后分子必为一次，所以必须 Ax+B。

情形一：互异一次因式（两种拆法）

例 929:23分解 1(x−2)(x+1) 并积分。

方法甲：直接凑（宋老师法）

猜 1(x−2)(x+1)=Ax−2+Bx+1，中间若是加号通分后 x 消不掉，故为减号。通分：

A(x+1)−B(x−2)(x−2)(x+1)=(A−B)x+(A+2B)(x−2)(x+1)

要求分子是 1，即 A−B=0、A+2B=1，得 A=B=13。所以

1(x−2)(x+1)=13(1x−2−1x+1)

积分：

∫dx(x−2)(x+1)=13ln|x−2x+1|+C
方法乙：待定系数法（死办法，不动脑）

32:40设 1(x−2)(x+1)=Ax−2+Bx+1，通分后分子 A(x+1)+B(x−2)=1，即 (A+B)x+(A−2B)=1。比较系数：

A+B=0,A−2B=1

相减得 3B=−1，B=−13，A=13——和上面完全一致。考试紧张时用乙法最稳。

41:32凑拆小规律

两项的 x 系数同号（都正或都负）时，中间是减号；两项的 x 系数异号时，中间是加号。这样通分后 x 才消得掉。熟练后用这个规律能秒写，但拿不准就老老实实待定系数法。

例 1035:52举一反三：分解 1(2x+1)(x−2) 与 1(2x+1)(2−3x)。

思路：分母的 x 系数不是 1 了，分子的系数要跟着凑

老师放慢了速度讲这两道，因为分母的系数从 1 变成 2、3 之后，「猜」就不那么直观了。

第一题：两个因式的 x 系数都是正数（2 与 1），按规律中间用减号。但分子不能只写 1 和 1——通分后 2x 与 x 相减还剩 x，消不掉。要让 x 消失，分子的系数得跟分母的 x 系数保持一致：给 x−2 配 1、给 2x+1 配 2，通分分子是 2x+1−2(x−2)=5，是个常数，于是外头补一个 15：

1(2x+1)(x−2)=15(1x−2−22x+1)

第二题：两个 x 系数是 2 与 −3，异号，这次中间用加号。同样让分子系数跟分母看齐：2x+1 上配 2、2−3x 上配 3，通分分子是 2(2−3x)+3(2x+1)=7，于是补一个 17：

1(2x+1)(2−3x)=17(22x+1+32−3x)

积分时注意链式法则会给每个对数各带一个系数：

∫dx(2x+1)(2−3x)=17ln|2x+12−3x|+C

要点：两条可操作的规则合起来就是——分子配的系数 = 分母各自的 x 系数；中间是加还是减，看两个 x 系数同号还是异号。老师说这两条你提前预感一下它通分以后的结果就出来了；要是懒得预感，还有第三题交给待定系数法兜底。

符号反了必错

第二题如果把中间的加号写成减号，通分分子会变成 2(2−3x)−3(2x+1)=1−12x，x 项消不掉，怎么调系数都凑不出常数。「猜」失败的最快信号就是：通分后 x 没消掉。一旦出现这种情况，立刻回头改符号，而不是继续硬凑系数。

情形二：重一次因式

例 1128:39分解 3x−1(x−1)2 并积分。

思路：重根要拆成「一次幂 + 二次幂」两层

设 3x−1(x−1)2=Ax−1+B(x−1)2，通分分子 A(x−1)+B=Ax+(−A+B)=3x−1。比较：

A=3,−A+B=−1⇒B=2

所以 3x−1(x−1)2=3x−1+2(x−1)2，积分：

∫3x−1(x−1)2dx=3ln|x−1|−2x−1+C

情形三：不可约二次因式（分子 Ax+B 出场）

例 1222:32求 ∫x+1x2+1dx。

思路：把分子拆成「一次项 + 常数」，分别喂给 ln 和 arctan

二次因式 x2+1 不可约，分子写成 Ax+B 后拆成两块：

x+1x2+1=xx2+1+1x2+1

第一项凑 d(x2+1)=2xdx 出 ln，第二项直接 arctan：

∫x+1x2+1dx=12ln(x2+1)+arctanx+C

25:38配方法也常用：如 ∫dxx2+2x+2=∫dx(x+1)2+1=arctan(x+1)+C。这就是二次因式分子设 Ax+B 的意义——一次项产 ln，常数产 arctan，缺一不可。

本页最该记住的两条

一、假分式必须先化真分式，否则部分分式无从拆起——这是整节的前提。二、二次因式分子设 Ax+B，只设 A 会漏掉 ln 项、分解失败。老师总结：直接凑是巧劲，待定系数法是笨劲，脑子不想动就用死办法，总比抄不出强。

记忆入口 · 一眼回忆

一句话

有理函数 = 多项式/多项式。假分式先化真分式，真分式按分母四类因式做部分分式分解，每项落 ln 或 arctan。

两个母公式

分母是一次式
凑成 ∫duu=ln|u|+C（u 是分母整体）
分母是二次式
配成 ∫du1+u2=arctanu+C（先配方、再提常数）

四种拆法

互异一次
A/(x−a)+B/(x−b)（常数）
重一次
A1/(x−a)+⋯+Ak/(x−a)k
不可约二次
(Ax+B)/(x2+px+q)（一次！）
重二次
二次因式同样拆 k 项，每项分子都是 Aix+Bi

铁律

  • 分子次数 = 分母因式次数 − 1；二次因式必须 Ax+B，不能只 A；
  • 凑拆：x 系数同号→减号，异号→加号；分子配的系数 = 分母各自的 x 系数；拿不准就待定系数法；
  • 分解失败的最快信号：通分后 x 没消掉——回头改符号，别硬凑系数。

三个坑

  • 忘化真分式就直接拆——前提错；
  • 二次因式只设 A——漏 ln 项，分解不完整；
  • 配方时提出去、补进来的常数丢了（例 6 的 16）；分母是完全平方时误用 arctan。
