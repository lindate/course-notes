P148【黑板】幂级数求和函数：你会求和的和函数只有一个

一句话核心

到现在为止，你真正会求和的级数只有等比级数 ∑n=0∞xn=11−x。所以求和函数的全部工作就是把题目扭成等比：n 在分母就先求导再积分，n 在分子就先积分再求导（或者一步认出它是等比级数的导数）。四步走完还要回头补两件事：端点重新验、结果分母带 x 就单独算 S(0)。

黑板课先把话说死：你只会一个和函数

00:00上一页（【黑板】幂级数求收敛半径和收敛域）我们练的是求收敛半径和收敛域。这一页是它的下半场：把和函数求出来。老师说课本这一节写得「非常隐晦」，「该讲的例题他都没怎么明确地说出来」，所以黑板课直接给全清单。09:32他也点明了这类题的固定结构：正课里每道题都是两步——先求收敛域，再求和函数。既然收敛域在上一页练透了，本页的例题就默认略去半径与端点的重复计算，把注意力全部放在「怎么求和」上；但你自己做题时不能省第一步，最后仍要回到原级数把端点补上。

07:21求和函数只有一条信念，老师反复强调到近乎唠叨：你会求和的和函数，只有等比级数一个。

∑n=0∞xn=11−x(|x|&lt;1)

其余所有级数——不管长得多花哨——都要想办法变成它。所以「求和函数」这四个字，翻译过来就是：找一个合法的操作，把原级数扭成 ∑xn，算出闭式，再做逆操作扭回去。合法操作只有两种：逐项求导、逐项积分。这就是全部。

两条性质：交换求和与求导/积分的许可

00:44第一条性质是和函数连续，进而可积。老师顺口对比了一句：连续的要求比可积高，连续一定可积，所以这条几乎不需要单独记。真正要记的是逐项积分与逐项求导这两条，它们是全页的工具箱。

01:53性质 · 逐项积分

设 S(x)=∑n=0∞anxn 在收敛域上，则可逐项积分：

∫0xS(t)dt=∑n=0∞anxn+1n+1

核心就是一句话：先求和再积分 = 先积分再求和，两个运算的次序可以交换。03:01而且书上还注明了一句关键的话：逐项积分以后的幂级数与原来的级数有相同的收敛半径。

04:05性质 · 逐项求导

设 S(x)=∑n=0∞anxn，则在收敛区间 (−R,R) 内可逐项求导：

S'(x)=∑n=1∞nanxn−1

即先求和再求导 = 先求导再求和。同样地，逐项求导以后收敛半径不变。

老师把这两条性质的核心各压成一句：先求和再求积分等于先求积分再求和，先求和再求导等于先求导再求和，就是它的运算这个顺序啊是可以交换的，并且它的收敛半径是相同的。后面每一道例题，实际上都在用这两句话中的一句。

为什么收敛半径不变，端点却可能变

逐项求导让通项多乘一个 n，逐项积分让通项多除一个 n。在区间内部，|x|&lt;R 的地方|x| 与 R 差距有限，乘除一个 n 不足以改变「收敛还是发散」的定性判断，所以半径纹丝不动。但在端点 |x|=R 处，级数本来就走在临界线上、靠 n 的高次幂或阶乘的衰减勉强收敛，这时乘上或除掉一个 n 就足以让它翻盘。

最典型的例子是例 1：原级数 ∑xnn 在 x=−1 收敛（交错），但求导后得到 ∑xn−1 在 x=−1 是 1−1+1−⋯，发散。所以你每一步求导或积分之后，都不能把中间那一步的收敛域当最终答案，必须回到原级数在端点上重新验一遍。这一条是本页最容易被扣分的地方，没有之一。

四步套路：先定域、再看 n、凑等比、还原补漏

把上面的话整理成流程，就是下面四步。老师上课时省掉了第一步和第四步的一半，但你自己做题必须走全。

第一类：n 在分母，先求导再积分

例 108:21求 ∑n=1∞xnn 的收敛域与和函数。

收敛域先摆着（最后要回来补）

标准型，系数比 nn+1→1，所以 R=1，收敛区间 (−1,1)。端点留到最后判。

思路：分母有 n → 求导消掉它

设 S(x)=∑n=1∞xnn。10:15老师把动机讲得很直白：这个 N 你要把这个分母这个 N 给它搞掉，那这个 N 怎么给它去掉呢？如果 x 的 N 次方求导是不是出来一个 N……出来一个 N 和这个分母的 N 能不能抵消？那不就没了吗？哎，先求导。于是用逐项求导：

S'(x)=∑n=1∞nxn−1n=∑n=1∞xn−1=1+x+x2+⋯=11−x

12:44这正是等比级数（首项 1、公比 x），所以闭式出来了。再做逆操作——从 0 到 x 积分：

S(x)=S(0)+∫0x11−tdt=0+[−ln(1−t)]0x=−ln(1−x)

其中 S(0)=0，因为原级数在 x=0 处每一项都是 0。

13:41还原之后回头判端点

16:08x=1 时原级数变成 ∑1n，调和级数，发散；x=−1 时变成 ∑(−1)nn，交错级数，收敛。所以收敛域是 [−1,1)。

绝对值能不能去，取决于收敛域

积分出来严格写法是 −ln|1−t|。老师说：这个地方其实这个绝对值是可以去的，为什么呢？因为我这个题偷了个懒，X 的取值范围咱没给你求，但这个地方还是得求，咱来试一下。在 x∈[−1,1) 上 1−x&gt;0，绝对值确实可以去掉——但必须先求出收敛域才能去掉。先写 −ln|1−x|，再用收敛域把绝对值摘掉，是更稳的书写顺序。

求导那一步的收敛域不是最终答案

把 S'(x)=11−x 的收敛域 (−1,1) 直接当原级数的收敛域。S' 的级数 ∑xn−1 在 x=−1 是 1−1+1−⋯，发散；而原级数在 x=−1 收敛。两者端点行为不同，最终答案必须由原级数决定：[−1,1)。

例 218:50求 ∑n=0∞xnn+1 的收敛域与和函数。

思路：直接求导消不掉 n+1，先乘 x 凑

收敛半径 R=1。19:57老师指出这道题和例 1 差一点点，但「计算起来巨复杂」：如果直接对 xnn+1 求导，会得到 nxn−1n+1，分子冒出一个 n、分母还留着 n+1，抵消不掉。要抵消，就得让求导后出来的是 n+1，而 xn+1 的导数恰好是 (n+1)xn。于是两边先乘 x：

xS(x)=∑n=0∞xn+1n+1

再求导，指数上的 n+1 正好抵消分母：

(xS(x))'=∑n=0∞xn=11−x

积分还原：xS(x)=∫0xdt1−t=−ln(1−x)（这里用了 xS(x) 在 x=0 处为 0）。于是当 x≠0 时

S(x)=−ln(1−x)x
20:49提了 1x，就必须讨论 x=0

20:49老师的原话：任何时候你把一个东西放在分母上，都要讨论它怎么样等于零的这个问题。原级数在 x=0 时是第一项 001=1（n=0 项约定 00=1），后面全是 0，所以 S(0)=1，而 −ln(1−x)x 在 x=0 分母为零、用不了。所以答案要分两段写：x≠0 时 S(x)=−ln(1−x)x，x=0 时 S(x)=1。

22:34老师自曝的糗事

这个地方啊，各位同学在求和函数的时候，S(0) 到底等于几，有些同学，包括我刚上班给大家讲课的时候，我第一次讲的时候，我老觉得 S(0) 就应该等于零——那零朝里代不是零吗？不是！你看这个零朝里带，S(0) 就等于一。这个地方大家一定要小心：零朝里带的时候啊，它不一定等于几。

23:45诀窍就一句：把级数写开，一项一项看。S(0) 是「所有项在 x=0 处的取值之和」，不是「把 x=0 代进那个闭式」。只要第一项不是 0，S(0) 就不是 0。

端点

x=1 时 ∑1n+1 发散；x=−1 时 ∑(−1)nn+1 交错收敛。收敛域 [−1,1)，与例 1 相同。

30:01这两个例题吃透以后，「第一类」的变式就都能拆解了。老师当场又给了两个：∑n=0∞xn+1n 和 ∑n=2∞xn+1n−1（31:07他先提示「你这里是个 xn+1，想出现 xn−1 怎么办？提出来一个 x2」）。前者把 x 提出来就变回例 1：∑xn+1n=x∑xnn=−xln(1−x)。后者提 x2：∑xn+1n−1=x2∑m=1∞xmm=−x2ln(1−x)（m=n−1）。分母的 n 或 n−1 都在求导下消失，这就是「第一类」的共同特征。

第二类：n 在分子，先积分再求导（或认出导数）

例 334:27求 ∑n=0∞(n+1)xn 的收敛域与和函数。

为什么这次不能求导

35:05老师说得很直接：这次求导啊，就白忙活了。为什么呢？xn 一求导是不是又出来个 n？好嘛，原来你有 n+1，好嘛，求导又出来个 n，那更麻烦了。分子上的 n+1 求导后会变成 n(n+1)，越搞越大。所以这次反过来——先积分。

做法一：先积分再求导
∫0xS(t)dt=∑n=0∞(n+1)xn+1n+1=∑n=0∞xn+1=x1−x

再用变上限积分求导把 S 还原：

S(x)=(x1−x)'=1⋅(1−x)−x⋅(−1)(1−x)2=1(1−x)2
39:58做法二：一行认出它是导数（老师推荐）

注意到 (n+1)xn 本身就是 (xn+1)'，所以可以直接先求和再求导：

S(x)=(∑n=0∞xn+1)'=(x1−x)'=1(1−x)2

41:10老师说这种题不用那么麻烦，一行就能出来。收敛域：|x|&lt;1 内部成立，端点处通项不趋于 0，故收敛域 (−1,1)。

例 4 与例 544:17求 ∑n=1∞nxn 与 ∑n=2∞nxn−2 的和函数。

例 4：提一个 x，化归例 3

把 x 提到外面：∑n=1∞nxn=x∑n=1∞nxn−1。而 ∑n=1∞nxn−1=(∑n=0∞xn)'=(11−x)'=1(1−x)2，所以

∑n=1∞nxn=x(1−x)2(−1,1)
46:02提 x 不用讨论 x=0

46:02老师的两句口诀：朝外边提个 X，你不用讨论它等不等于零；但是你朝外边提个 1X，你就得讨论它等于零还是不等于零。例 4 提的是 x，x=0 时原级数各项为 0、和为 0，代入 x(1−x)2 也得 0，完全一致，不必单独讨论。

例 5：提一个 1x，就躲不掉 x=0

∑n=2∞nxn−2 的指数比例 4 少两次，只能提 1x：

∑n=2∞nxn−2=1x∑n=2∞nxn−1=1x(1(1−x)2−1)

化简：1(1−x)2−1=1−(1−2x+x2)(1−x)2=2x−x2(1−x)2，除以 x 得

∑n=2∞nxn−2=2−x(1−x)2(−1,1)

按口诀，这里提了 1x，本该单独讨论 x=0。但有趣的是：原级数在 x=0 时只剩 n=2 这一项，值恰好是 2；而化简后的式子代 x=0 也得 2−01=2。所以这个「洞」被代数化简自动补上了，可以直接写成统一的一个式子。不过要先按规矩讨论、再说明能合并，不能一开始就跳过。

结果卡里的七个式子其实是同一条链

把结果卡竖着读一遍就会看出来：−ln(1−x) 求导得 11−x，11−x 求导得 1(1−x)2；反过来就是除法与积分。也就是说，左边「第一类」和右边「第二类」的答案并不是七条互不相干的结果，而是同一个等比级数在求导与积分下的一条链——∑xnn、∑xn、∑(n+1)xn 的和函数依次是 −ln(1−x)、11−x、1(1−x)2，每求一次导，答案换一个。

这也解释了为什么两类题的做法看起来相反、却都能成功：第一类是「先求导把分母的 n 消掉，再积分退回来」，第二类是「先积分把分子的 n 收进去，再求导送回去」——它们走的是同一条链的两个方向。所以与其硬背七个公式，不如记住这条链的起点是 11−x：往左走是积分，往右走是求导。考场上忘了某个答案，顺着链推一步就能救回来。

为什么「先积分再求导」等于「先求和再求导」

例 3 的两种做法看起来是两件事，其实是同一条性质的两次使用。做法一是：先逐项积分（性质三），算出原函数 x1−x，再对结果求导还原。做法二是：直接看出 (n+1)xn=(xn+1)'，于是把「逐项求导再求和」交换成「先求和再求导」（性质四的逆用）。两条路的差别只在哪一步先做，数学上是恒等的。

更值得注意的是：做法二的合法性依赖性质四，而性质四只在收敛区间内部成立。所以无论走哪条路，你都得先确认 |x|&lt;1，否则整个操作就没有依据。「先求收敛域」之所以必须是第一步，不只是为了答案完整，而是因为后面每一步求导/积分都要踩在收敛域内部才合法。

题面信号先做什么为什么
n 在分母（xnn、xnn+1）求导，再积分还原求导让分子冒出一个 n，与分母的 n 相消
n 在分子（nxn、(n+1)xn）积分，再求导还原积分把 n 收进原函数（除掉了）
能一眼看出是 (xk)' 的形状直接「先求和再求导」省掉积分还原，一行出结果
指数比标准少一次（xn−2）提 1x 后再照上面的做提了 1x，必须补 S(0)
47:54考场上的书写顺序

① 先算出 R、判两个端点，把收敛域写在最前面；② 设 S(x)=∑⋯ 并声明 x 的取值范围；③ 写出求导或积分的那一步，把「先求和再求导 = 先求导再求和」这类性质用文字点一句，这是采分点；④ 算出等比闭式；⑤ 还原，补常数 S(0)；⑥ 若提过 1x 或结果分母带 x，单列 x=0；⑦ 最后回看端点是否要并入。老师形容这部分内容是「课本上你几乎自己看你啥也看不出来」，所以步骤写全本身就是分数。

记忆入口 · 一眼回忆

一句话

你只会一个和函数：∑xn=11−x。求和的全部工作就是用求导或积分把原级数扭成它，再扭回来。

一条链

求收敛域 半径 + 端点→ 看 n 的位置→ 求导或积分 凑等比→ 还原 补 S(0)→ 重验端点

要背的结果

  • ∑xnn=−ln(1−x)，x∈[−1,1)（分母有 n，先求导）。
  • ∑xnn+1=−ln(1−x)x（x≠0），S(0)=1。
  • ∑(n+1)xn=1(1−x)2（n 在分子，先积分）。
  • ∑nxn=x(1−x)2；∑nxn−2=2−x(1−x)2。

两个开关

n 在分母
先求导消 n，再积分还原（第一类，较麻烦）。
n 在分子
先积分收 n，或认出它是等比级数的导数（第二类，较简单）。

三个坑

  • 以为 S(0)=0。把级数写开一项项看：例 2 的 S(0)=1。
  • 提了 1x 却不讨论 x=0。提 x 不用管，提 1x 必讨论。
  • 把中间步骤的收敛域当最终答案。求导/积分后半径不变，但端点必须回到原级数重新验。
