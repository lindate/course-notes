P115【黑板】二阶线性微分方程

一句话核心

本页是二阶线性方程的理论核心：我们不再去解方程，而是先弄清「解与解之间有什么结构关系」。四条结论一条链——齐次方程解的叠加原理、通解结构 y=C1y1+C2y2（要求 y1,y2 线性无关）、非齐次方程通解 = 齐次通解 + 特解、以及解的叠加原理（两个特解之差是齐次解）。其中「为什么必须线性无关」配一个会退化的反例讲透。新授课见 二阶常系数齐次线性微分方程（理论）。

一、先把名字拆清：二阶、线性、齐次

这节课的标题是「二阶线性微分方程」。老师开场时的态度很明确：后面的名字会越来越多，你都不知道这些名字是怎么来的，所以先把名字本身解释清楚。本页处理的方程长这样：

y''+P(x)y'+Q(x)y=0
二阶
方程里出现了 y''。它把「要求两次不定积分」这件事提前钉死了，所以通解里一定有两个任意常数。
线性
01:13考察的对象是 y''、y'、y 三者之间的关系：各自都是一次方、不相乘、不作分母。老师说得很形象：考察线性这个关系的时候，这个 x 的部分我们是不是把它看作是个常数？所以 P(x)、Q(x) 里怎么折腾 x 都可以，它们只是系数。
齐次
等号右边是 0。右边换成非零的 f(x)，就叫非齐次。注意跟 齐次方程 里那个「齐次方程」同名不同义——那里的齐次说的是「右边只依赖 yx」，这里的齐次说的是「自由项为零」。

另有一个必须分清的对照：本页的 P(x)、Q(x) 是关于 x 的函数，也就是变系数的情形。到了 【黑板】常系数齐次线性微分方程，这两个位置会被要求是常数，那里才有「特征方程」这套具体解法。本页讲的是结构——不论系数是函数还是常数，下面四条结论都成立。

为什么这一页「不解方程」

一般变系数的二阶线性方程是没有初等解法的。那我们为什么还要花一整节课讲它？因为解不出来，不代表说不出解长什么样。

这一页要交付的是结构信息：齐次方程的解全体构成一个什么样的集合？非齐次方程的解跟齐次解差多远？两个非齐次方程的解能不能拼起来？这些问题的答案不依赖方程能不能解出来。

它的价值在下一节立刻兑现：【黑板】常系数齐次线性微分方程 里我们只要找到两个线性无关的解，通解就自动出来了，剩下的工作只是「找」而已。如果不知道结构，找到两个解也不敢说它就是通解。老师说得很直白：这一页也是比较难理解，但它决定了后面所有题目的写法。

二、齐次方程解的结构（一）：叠加原理

第一个结论，老师的说法是「你朝里带不就完了吗」——它几乎没有技术含量，但它是后面全部结论的地基。

定理一 · 齐次方程解的叠加原理

设 y1 与 y2 都是齐次方程 y''+P(x)y'+Q(x)y=0 的解，则对任意常数 C1、C2，

y=C1y1+C2y2

也是该方程的解。这个式子叫 y1、y2 的一个线性组合。

证明：只有「分组」这一个动作

要证 C1y1+C2y2 是解，就把它代进方程左端，看能不能化成 0。求导很省事——相加求导就是分别求导，不像乘积、相除那样还要扯出额外的项：

y'=C1y1'+C2y2',y''=C1y1''+C2y2''

代入左端：

C1y1''+C2y2''+P(C1y1'+C2y2')+Q(C1y1+C2y2)

按 C1、C2 重新分组：

C1(y1''+Py1'+Qy1)+C2(y2''+Py2'+Qy2)

而题目已经说明 y1、y2 都是解，所以两个括号各自等于零，整个左端等于零，结论成立。

这里能分组的理由只有一条：方程是线性的。正因为 y''、y'、y 是一次地摆在一起（不相乘、不套函数），C1、C2 才敢整块提到括号外面。如果方程里出现 y2 或者 y⋅y'，这个证明立刻失效——这也解释了「线性」这两个字到底在管什么。

老师讲这段时的吐槽很实在：把这个 C2 求 X 我都快写晕了，你们是不是都快看晕了对吧？他随即补了一句本页的重点：过程看晕没关系，结论只有一句——线性组合仍然是解。

三、为什么必须线性无关：一个会退化的反例

定理一给的是「组合仍是解」。那组合出来的 C1y1+C2y2 是不是通解？直觉上是的——它带有两个任意常数，而二阶方程正需要两个常数。老师说他写的时候自己就发现了问题：哎呀老师挺好啊，那你得到了通解啊，两个任意常数吗？那俩那不是通解。答案是：不一定。要看清这件事，先要引进一对概念。

定义 · 线性相关与线性无关

设 y1、y2 是两个函数。

  • 若 y1y2 恒等于一个常数（等价地说，y1=ky2），则称它们线性相关。
  • 否则称它们线性无关。

07:22这其实是线性代数里那个定义的特殊情形。完整的定义是「存在不全为零的 k1,…,ks 使得 k1α1+⋯+ksαs=0」，放到两个函数上就化简成上面这一句。本课只用到两个函数的情形，老师说：多个向量咱也不用管，留到你们那个老师给你讲去吧。

判断起来只有一步：算比值，看它是不是常数。老师说这件事一句话你就理解了——

2x 与 x
比值恒为 2，线性相关（它是它的两倍）。
ex 与 sinx
比值 exsinx 里两个都是与 x 有关的函数，不可能恒为常数，所以线性无关。
ex 与 3ex
比值恒为 13，线性相关。
x 与 ex
比值 exx 随 x 变化，线性无关。
反例：线性相关时，通解会「退化」成一个常数

老师编了一个极端的场景来讲这件事的道理。假设某个二阶齐次方程的两个解是 y1=x 与 y2=2x（它们显然是相关的）。按定理一的写法，C1x+C2⋅2x 是解，于是通解似乎就是

y=C1x+2C2x

式子看着挺正常，两个常数 C1、C2 都在。但把 x 提出来：

y=(C1+2C2)x=Cx

括号里那一整块只是一个任意常数。原因是：C1 与 C2 各自任意，它们线性组合出来的 C1+2C2 仍然可以取到任何实数。所以这个「解」里其实只剩一个自由参数，而二阶方程的通解必须有两个。它不是通解。

老师的总结很传神：老师我还免费赠送了一个 K——两个常数我给你三个，行不行啊？不行。多出来的那个系数不是新的自由度，它只是把原有信息重新写了一遍。

这条反例的教训是：常数「个数」不等于常数「自由度」。看一个解是不是通解，不能只数 C 的个数，还要看这些常数能不能真正独立地变化——这正是「线性无关」要保证的事。

四、齐次方程解的结构（二）：通解怎么拼

加上「线性无关」这个条件之后，通解就稳了。

定理二 · 齐次方程通解的结构

设 y1、y2 是齐次方程 y''+P(x)y'+Q(x)y=0 的两个线性无关的解，则

y=C1y1+C2y2(C1,C2为任意常数)

是该方程的通解。

这个定理的价值在于它把「解二阶方程」这件大事，换成了「找出两个不成比例的解」这件小事。一旦找到两个，线性组合一下就是通解，不用再做别的。老师课上举的两组例子都是「不用算，代入就能验」的：

  • 方程 y''+y=0：y1=cosx、y2=sinx 都是它的解（求两次导就变号），而 cosxsinx=cotx 不是常数，所以线性无关。于是 y=C1cosx+C2sinx 是通解。这个结论要背下来，它是后面复根情形的基础。
  • 方程 (x−1)y''−xy'+y=0：y1=x、y2=ex 都是它的解，而 exx 不是常数，所以线性无关。于是 y=C1x+C2ex 是通解。

第二组里 y1=x 为什么是解，值得当场验一遍，因为它展示了一个通用动作：把候选函数求导到方程需要的阶数，再一起代进左端看是否恒为零。y=x 时 y'=1、y''=0，代入左端得 (x−1)⋅0−x⋅1+x=−x+x=0 ✓。y=ex 时三阶导数都是 ex，左端变成 (x−1)ex−xex+ex=ex(x−1−x+1)=0 ✓。

例 110:32判断下列各组函数是否线性无关，并说明理由。

思路：只做一件事——算比值，看它是不是常数

这是本页唯一「有统一套路」的题型。不要试图「看长相」判断，直接算比值。

  1. f1=ex，f2=3ex。比值 ex3ex=13 恒为常数，所以线性相关。
  2. f1=x，f2=2x。比值恒为 12，线性相关。
  3. f1=x，f2=ex。比值 xex 随 x 变化（x=0 时是 0，x=1 时是 1e），线性无关。
  4. f1=cosx，f2=sinx。比值是 cotx，随 x 变化，线性无关。
  5. f1=1，f2=x。比值是 1x（x≠0 时），不是常数，线性无关。这一组常被忽略：常数函数也是函数，它可以参与判断。
这一步最容易出的错

只看「是不是同一个函数」。第 1 组 ex 与 3ex 是两个不同的表达式，但它们线性相关；第 4 组 cosx 与 sinx 长得很像（都是三角函数、都有界、都以 2π 为周期），却线性无关。判据只有「比值是不是常数」，别的直觉都不可靠。

还有一处细节：说「比值」的时候要小心分母为零的点。严格地讲判据是「存在常数 k 使 y1=ky2 恒成立」，用比值只是它的通俗说法。做题时按比值算、把特殊点绕开即可，不必在答案里展开讨论。

例 2已知 y1=ex、y2=e2x 是方程 y''−3y'+2y=0 的两个解。判断 3y1−5y2 是不是它的解；并写出通解。

思路：第一问用定理一（叠加原理），第二问用定理二（通解结构）

第一问。3y1−5y2=3y1+(−5)y2，它是 y1 与 y2 的一个线性组合，其中两个系数分别是 3 与 −5——都是常数。由定理一，它是方程的解，根本不需要代入验算。

第二问。先核对方程确实以它们为解。y1=ex：y1'=y1''=ex，代入左端 ex−3ex+2ex=0 ✓。y2=e2x：y2'=2e2x、y2''=4e2x，代入 4e2x−6e2x+2e2x=0 ✓。

再判断是否线性无关：y1y2=exe2x=e−x，它随 x 变化，不是常数，所以线性无关。由定理二，通解是

y=C1ex+C2e2x

要点：两道小题各考一条定理，一步计算都不用做。这就是本页的价值——把「验证」升级成「判断」。

顺带交代一件事

这里 ex 与 e2x 是怎么找到的？本页不回答，那是 【黑板】常系数齐次线性微分方程 的任务（把 y=erx 拿去试，得到特征方程 r2−3r+2=0，两根正是 1 与 2）。本页负责「找到两个解之后怎么办」，下一页负责「怎么找」。两页合起来才是一道完整的题。

五、非齐次方程：通解 = 齐次通解 + 特解

把方程右边的 0 换成一个非零的 f(x)，方程就变成非齐次的。它对应的那个「右边为 0」的方程，习惯上叫它的对应齐次方程。老师给的结论是一句非常好记的话：

定理三 · 非齐次方程通解的结构

设 y∗ 是非齐次方程 y''+P(x)y'+Q(x)y=f(x) 的一个特解，Y 是它的对应齐次方程的通解，则

y=Y+y∗

就是该非齐次方程的通解。

为什么「通解 + 特解」能凑出全部解

证明要交代两件事，老师的原话是：要证明它是通解，我们得证明两个事。

第一件：它确实是解。把 Y+y∗ 代进左端。相加求导就是分别求导，所以左端可以拆成两块：一块是「Y 代进去的结果」，一块是「y∗ 代进去的结果」。19:20而 Y 是齐次通解，它那部分恒为 0；y∗ 是非齐次特解，它那部分等于 f(x)。两块相加恰好是 f(x)，成立。

第二件：它含有两个任意常数。Y 是二阶齐次方程的通解，里面有两个任意常数；y∗ 是特解，特解里没有任何任意常数——它的常数早就被初始条件定死了。所以 Y+y∗ 里正好两个任意常数，而方程是二阶的，两个常数正合适。

老师对第二件事的表述非常口语化：特解是通解把初始条件带进去、把它的常数都去掉了，所以 y∗ 是没有任意常数的。这句话概括了「特解」的本质：它是通解被条件钉死之后的一个具体函数。

还有一个理解角度值得记住：非齐次方程的解集，相当于把齐次方程的那一族解整体平移了一个 y∗。平移不改形状，只改位置，所以「齐次解有几个自由度，非齐次解就有几个自由度」。

21:59课上的例子把这条定理用了一遍：方程 y''+y=x2 是非齐次的。它有一个特解 y∗=x2−2（验算：y∗''=2，代进左端得 2+x2−2=x2 ✓）。它的对应齐次方程 y''+y=0 的通解是 Y=C1cosx+C2sinx。于是原方程的通解是

y=x2−2+C1cosx+C2sinx

注意这里两个任意常数都出在齐次那一半，特解那一半一个都没有——这与定理三的证明完全对应。

六、解的叠加原理，以及一个必会的推论

定理四 · 解的叠加原理

设有两个方程，它们的左端完全相同，只有右端不同：

y''+P(x)y'+Q(x)y=f1(x),y''+P(x)y'+Q(x)y=f2(x)

若 y1∗ 是第一个方程的特解，y2∗ 是第二个方程的特解，则

y1∗+y2∗

是方程 y''+P(x)y'+Q(x)y=f1(x)+f2(x) 的特解。

25:21这道定理连证明都省事。老师说：你看课本怎么证明？这不是把它直接带进去，不就等于 f1 加 f2 嘛。把 y1∗+y2∗ 代进左端，拆成两块，分别等于 f1 与 f2，相加就是 f1+f2。这就完了。

推论 · 两个特解之差是齐次解

设 y1∗ 与 y2∗ 都是同一个非齐次方程 y''+P(x)y'+Q(x)y=f(x) 的特解，则

y1∗−y2∗

是它的对应齐次方程 y''+P(x)y'+Q(x)y=0 的解。

怎么来的：把 y2∗ 乘上 −1。因为方程左端是线性的，−y2∗ 代进去正好等于 −f(x)，所以 −y2∗ 是右端为 −f(x) 的那个方程的特解。现在两个方程的左端相同、右端分别是 f 与 −f，由定理四，y1∗+(−y2∗) 就是右端为 f+(−f)=0 的方程的解——也就是齐次解。

这个推论有什么用

它给了一个不用求解就能「造齐次解」的办法。只要手里有两个非齐次方程的特解，一减就得到一个齐次解。在 常系数非齐次线性微分方程（观察法） 那一节（观察法求特解）里，如果题目给的函数恰好不是特解、而是两个特解的差，用这条推论就能立刻识别。

它还提供了另一种理解定理三的方式：非齐次方程任意两个解之差都落在齐次解空间里，换句话说，非齐次方程的解在模掉「齐次解」这个方向之后还剩唯一一个东西——那个东西就是特解。所以「通解 = 一个特解 + 齐次通解」不是拼凑，而是唯一可能的形状。

七、本页的易错点

一 · 把「线性组合是解」当成「线性组合是通解」

定理一只保证是解，不保证是通解。通解还要求两个解线性无关（定理二）。做题时看到「C1y1+C2y2」不要反射性地写「通解」，先算一下 y1y2 是不是常数。

二 · 只数常数个数，不看是不是独立

反例里 C1x+2C2x=(C1+2C2)x 明明写着两个 C，实际只有一个自由度。判断通解要看「独立常数有几个」，不是「字母 C 出现了几次」。

三 · 把非齐次的特解当齐次解用

特解只满足非齐次方程，代进齐次方程左端不会等于 0。定理三里 y∗ 和 Y 的角色不能互换：Y 必须是齐次通解（带两个任意常数），y∗ 必须是不带任意常数的特解。

四 · 忘了两边系数必须完全一样才能用叠加原理

定理四要求两个方程的左端完全相同（P(x)、Q(x) 一字不差），只有右端不同。如果左端不一样，把两个解相加没有任何保证。

五 · 把两个「齐次」搞混

本页的「齐次」指右端为零（y''+P(x)y'+Q(x)y=0）；齐次方程 里的「齐次方程」指右端只依赖 yx。同名不同义。看到「齐次」两个字，先看方程长什么样再下判断。

记忆入口 · 一眼回忆

一句话

本页不解方程，只交付解的结构：齐次解线性组合仍是解；两个线性无关的解拼出通解；非齐次通解 = 齐次通解 + 一个特解；两个特解之差是齐次解。

线性组合 仍是解→ 加线性无关 才成通解→ 非齐次 通解 = 齐次通解 + 特解→ 特解相减 回到齐次

要背的

  • 判据只有一句：y1y2 是常数 ⟹ 线性相关；不是常数 ⟹ 线性无关。
  • y''+y=0 的线性无关解是 cosx 与 sinx，通解 C1cosx+C2sinx。
  • 退化的反例：x 与 2x 线性相关，组合 C1x+2C2x=Cx 只剩一个常数。
  • y''+y=x2 有特解 x2−2，通解 y=x2−2+C1cosx+C2sinx。

三个坑

  1. 把「是解」当成「是通解」。还要过线性无关这一关。
  2. 只数 C 的个数。要看独立自由度有几个。
  3. 用叠加原理时左端不一致。定理四要求两个方程左端完全相同。
