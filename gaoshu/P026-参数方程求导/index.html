P026参数方程求导：借一个中间变量 t 把曲线求导

一句话核心

当曲线用 x=φ(t),y=ψ(t) 给出时，y 仍是 x 的函数，只是隔了一层参数 t。核心公式一句话：dydx=dy/dtdx/dt——分子分母同除以 dt 即得。二阶导不必硬记公式，把一阶导再「比上 dt 比上 dt」重做一遍即可。

概念：参数方程确定的函数还是函数

00:00老师先点明标题的严谨之处：由参数方程所确定的函数的导数——这句话其实描述得特别严谨。原本 y=f(x) 是 y 直接关于 x 的函数；现在 x,y 都用同一个参数 t 表示：

x=φ(t),y=ψ(t)

意义是：把 t 消掉（用 x 表示 t 再代进 y），y 最终只和 x 有关——所以它描述的依然是一条 x,y 平面上的曲线，依然是 y 关于 x 的函数。只是中间借了 t 这个「桥」。

把「y 被藏起来」的三种方式摆在一起，就能看出本页的位置：

形式长什么样怎么求 dydx在哪一节
显函数y=f(x)，y 已单独解出来直接求导求导公式
隐函数F(x,y)=0，y 混在式子里两边对 x 求导，把 y 看成 x 的函数，再解出 y'隐函数求导对数求导
参数方程x=φ(t),y=ψ(t)，y 连 x 都没出现两式各自对 t 求导，再相除：ψ'(t)φ'(t)本页

三种形式只是「y 被藏起来的深度」不同：显函数摊开给你看，隐函数藏在方程里，参数方程则要绕道 t。但最后要算的那个东西始终是同一个——曲线在某一点的切线斜率 dydx。

一阶导数：书上推导 vs 宋老师简便法

书上的严格推导（看一眼即可）

02:14书上的路数：

  1. 把链条看成复合。y 是 t 的函数，t 又是 x 的函数（由 x=φ(t) 有反函数），所以 y 是 x 的复合函数，用链式法则 dydx=dydt⋅dtdx。
  2. 反函数求导把 dtdx 换成 1dx/dt。于是 dydx=dydt⋅1dx/dt=dy/dtdx/dt。

老师评价：书上这个方法肯定比较麻烦……很多书上的方法如果按书来弄就太麻烦了。所以看个来龙去脉就行。

宋老师简便法（主用）

05:52把 dydx 想成「分数」，分子分母同时除以 dt：

dydx=dydtdxdt=dy/dtdx/dt

老师原话：把 dydx 看作 dy 比上 dt、dx 比上 dt——这不就是这个函数对 t 求导、那个函数对 t 求导吗？这不就完了吗！也就是说：x,y 都是 t 的函数，分别求它们对 t 的导数，再相除。

为什么「同除以 dt」这种讲法成立

08:21这里涉及到 dydx 符号的两副面孔：前面说它是「一个整体、表示 y 对 x 求导」；到了微分那一节你会学到 dy=f'(x)dx，于是 dydx=f'(x) 本来就是把 dx 移到右边得到的——在这个视角下它确实可以被「拆开」看。老师把同一符号讲了三遍（整体 / 可分 / 可分），就是为了帮你记住公式。这里先记住结论：简便法完全可靠。

书上那套推导，偷偷用了什么前提 01:04

「y 是 t 的函数、t 又是 x 的函数」这句话不是白说的：它要求 x=φ(t) 存在反函数 t=φ−1(x)，也就是在所考虑的区间上 φ 得单调——等价于 φ'(t)≠0（或至少不变号）。否则同一个 x 可能对应好几个 t，y 就不是 x 的单值函数，「y 对 x 求导」这件事本身都立不住。宋老师的简便法把这一步藏进了符号里，用的时候不用想，但前提依旧在背后兜着。

那 φ'(t)=0 的地方公式还能用吗？要分三种情况看：

在 t0 处的取值切线长什么样公式怎么用
φ'(t0)≠0（常规）斜率有限，倾斜直线直接用 dydx=ψ'(t0)φ'(t0)
φ'(t0)=0，但 ψ'(t0)≠0竖直，斜率不存在换个方向用：dxdy=φ'(t0)ψ'(t0)=0，仍然有结论
φ'(t0)=ψ'(t0)=0可能是尖点，方向都不确定两个公式全失效，只能单独判断（摆线的 t=2nπ 就是这种）
第三行那个「尖点」到底长什么样

摆线在 t=2nπ 处：dxdt=a(1−cost)=0，同时 dydt=asint=0——两个导数一起归零，所以两边的公式都走不通。这不是巧合，而是「曲线在那里猛地拐了个死弯」的代数表现：圆上的点落回地面的一瞬间，既没有向右的速度，也没有向上的速度，轨迹只能折一下再走。所以参数方程求导的标准流程里，第一件事永远是先看看 dxdt 会不会为 0。

二阶导数：高频错误是「直接两次相除」

10:29求二阶导时，新手最爱犯一个错：

最高频错误

把 d2ydx2 写成 ψ''(t)φ''(t)。即「一阶导是相除、二阶导也两次相除」。这是错的。二阶导是「一阶导再对 x 求一次导」，而一阶导 dydx 本身是 t 的函数，对它再求导，仍要走一遍「比上 dt 比上 dt」。

12:34正确做法：把一阶导记作一个整体 z(t)=dydx，则

d2ydx2=ddxz(t)=dzdtdxdt=ddt(dydx)dxdt

老师强调：这个公式不要记！因为你记不住，记了也没用。做题时一阶导已经有了，把它对 t 求导、再除以 dxdt 就行，根本不用背这条二阶导公式。

07:54课本上还给了这条公式的「展开版」。把中间那块 ddt(dydx) 单独拎出来看：dydx 本身是两个 t 的函数之商，对它求导就得用商的求导法则——分母平方，分子求导乘分母、再减分子乘分母的导数：

ddt(ψ'(t)φ'(t))=ψ''(t)φ'(t)−ψ'(t)φ''(t)[φ'(t)]2

08:38再除以 dxdt=φ'(t)，分母升成三次方，于是课本上那条「吓人公式」长这样：

d2ydx2=ψ''(t)φ'(t)−ψ'(t)φ''(t)[φ'(t)]3

老师当场就把它否了：老师哇，你这公式是人记的吗？这啥呀这是！所以处理方式和前面那条一样——不背，能现推就够了。

09:30视频原话（大意）

按照宋老师的惯例，这个公式不要记。第一你记不住，记不住那你就别学了，你记它干嘛？

那我不记的话我不会做题啊？没事——做题的时候你做到「把一阶导对 t 求导、再除以 dxdt」这一步就行，因为一阶导那部分你在做题时已经求出来了。它已经有了，你该怎么做怎么做，跟公式有什么关系？

为什么不能「两次相除」

一阶导 dydx 是 t 的函数，不是 x 的函数。求 d2ydx2=ddx(dydx) 时，外层是「对 x 求导」、里层是「关于 t 的函数」，又是一层复合——所以必须再经过一次「÷dt」来落地。直接拿 ψ''、φ'' 相除，等于跳过了这一层复合，自然不对。简记：每往高一阶，就多一次「比上 dt」。

把两阶摆在一起对照，差别就只剩「多除一次」：

对照项一阶导 dydx二阶导 d2ydx2
手上已有什么y=ψ(t)、x=φ(t) 两个式子一阶导 dydx（已经是 t 的函数）
要做的事x,y 各自对 t 求导，再相除把 dydx 对 t 求导，再除以 dxdt
一句话公式dy/dtdx/dtddt(dy/dx)dx/dt
比上一阶多了什么—多一次「除以 dxdt」
典型错法忘了分别对 t 求导写成 ψ''(t)φ''(t)
21:46视频原话（大意）

我们在做计算题的时候，普通的计算题就是这样的：y 对 x 求一阶导，你就把它看作「比上 dt、比上 dt」；求二阶导啊，也是看作「比上 dt、比上 dt」。就这么两步。

例 116:55椭圆 x=acost,y=bsint，求 t=π4 时的切线方程。

思路：先求点，再用参数方程求导得斜率

代入 t=π4 得切点：

x0=acosπ4=22a,y0=bsinπ4=22b

分别求对 t 的导数：

dxdt=−asint,dydt=bcost

相除得斜率：

dydx=bcost−asint=−bacott

代 t=π4（cotπ4=1）：

dydx|t=π/4=−ba

切线方程 y−y0=dydx(x−x0)：

y−22b=−ba(x−22a)

14:16两边同乘 a，把分母清掉：ay−22ab=−bx+22ab，把右边的项搬到左边，两个 22ab 正好合成一个 2ab，得

bx+ay−2ab=0

与老师写出的「bx+ay−2ab=0」一致。老师对这题的评价就一句：这个题主要还是求导呗。切线方程、法线方程这类题，难点全在「把斜率求出来」这一步上。

例 223:36摆线 x=a(t−sint),y=a(1−cost)，求 d2ydx2。

思路：先一阶导，再「比上 dt 比上 dt」

对 t 求导：

dxdt=a(1−cost),dydt=asint

16:53一阶导就是相除，a 与 a 直接约掉：

dydx=asinta(1−cost)=sint1−cost

17:47再用半角公式把这个分式收拾干净：sint=2sint2cost2，1−cost=2sin2t2，代入后约掉一个 2sint2，就只剩一个余切：

sint1−cost=2sint2cost22sin2t2=cost2sint2=cott2

二阶导：把一阶导对 t 求导，再除以 dxdt。

ddt(cott2)=−12csc2t2
d2ydx2=−12csc2t2a(1−cost)

35:20化简：用 1−cost=2sin2t2，于是 csc2t2=1sin2(t/2)，分母 a(1−cost)=2asin2t2：

d2ydx2=−12⋅1sin2(t/2)2asin2t2=−14asin4t2=−1a(1−cost)2
d2ydx2=−1a(1−cost)2(t≠2nπ,n=0,±1,±2,…)
这一步最容易错

直接写 d2ydx2=ψ''(t)φ''(t)。老师当场演示：若硬套那个「两次相除」的假公式，会比正确算法更麻烦、还会算错。正确路径永远是「一阶导对 t 求导，再除以 dxdt」。

为什么答案要挖掉 t=2nπ

回头看一阶导 dydx=asinta(1−cost) 的分母：t=2nπ 时 1−cost=0，也就是 dxdt=0。几何上这正对应摆线的一个尖点——圆上的点落回地面那一刻，曲线「只往上走、不往右走」，切线是竖直的，斜率根本不存在。既然 dydx 在这些点没定义，二阶导自然也要一并排除。这就是答案后面那个 (t≠2nπ,n=0,±1,±2,…) 的来历。凡是用 dydx=ψ'(t)φ'(t)，先看一眼 φ'(t) 会不会等于 0。

拿答案验两个点

公式对不对，代两个好算的 t 试一下就知道了。t=π 时 cott2=cotπ2=0——那是摆线的拱顶，切线确实是水平的，对上了。t→0+ 时 cott2→+∞——尖点处切线竖直、斜率无穷大，也对上了，这正印证了前面「t=2nπ 要挖掉」的理由。再验一条对称性：把 t 和 2π−t 分别代入，得到 cott2 与 cot(π−t2)=−cott2，两者正好差一个负号——摆线一拱的左右两半关于 t=π 对称，斜率互为相反数，图上看得出来。

15:19视频原话（大意）

这个摆线啊，我也没什么合适的道具了——弄一个圆，让它在 x 轴上开始滚。注意不是滑，是滚。圆上你整一个点，然后开始滚，这个点的轨迹就是摆线。你拿个硬币在一条线上滚，滚出来的就是它。

结果要不要换回 x

35:46老师收尾点破一个纠结：普通函数 y 对 x 求完导只和 x 有关；但参数方程求出来的表达式是关于 t 的——老师我要不要再换成 x？答案是不用。既然 x,y 本来就是用 t 表示的，导数写成 t 的函数完全合法，题目要哪一点就代哪个 t 进去。强行消去 t 反而把式子搞复杂。

例 1 就是现成的证据：要 t=π4 处的切线，直接把 t=π4 代进 dydx=−bacott 就拿到斜率了，根本不用先去反解「哪个 t 对应哪个 x」。真要换成 x，还得从 x=acost 里解出 t=arccosxa 再代回去——多绕一大圈，式子还更难用。

记忆入口 · 一眼回忆

一句话

参数方程：借 t 表 x,y。一阶导 = 各自对 t 求导再相除；二阶导把一阶导再「比上 dt 比上 dt」，公式不用背。

两个公式

一阶导
dydx=dy/dtdx/dt=ψ'(t)φ'(t)
二阶导
d2ydx2=ddt(dy/dx)dx/dt（别写成 ψ''φ''）

两个必记例题形态

  • 椭圆 x=acost,y=bsint：dydx=−bacott
  • 摆线 x=a(t−sint),y=a(1−cost)：dydx=cott2，d2ydx2=−1a(1−cost)2

三个坑

  • 二阶导直接「两次相除」=ψ''/φ''（高频错误，错）
  • 忘了 dx/dt 可能为 0（切线垂直处，公式失效）
  • 非要把结果换回 x（不必，代 t 即可）
