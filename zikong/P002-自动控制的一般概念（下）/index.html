一、本节坐标：四个角色与三种方式

上节（自动控制的一般概念（上））的定义是：自动控制就是在没有人直接参与的情况下，利用控制装置使被控对象的被控量按给定量的规律运行。这句话里有四个角色——控制装置、被控对象、被控量、给定量，本节从头到尾都在给它们"分配座位"。实现方式有三种：开环、闭环、复合。

前置补课 · 三个词先锁死
被控对象
要它干活的那台设备（名词，如加热炉、记录笔）。
被控量
描述设备状态、你真正想控制的那个物理量（如炉温、笔位移）。
给定量
希望被控量按什么规律变化的命令信号，常是另一个物理量（如电压）。

二、例1 · 炉温系统：先看开环为什么不灵

2.1 炉子是怎么工作的

煤气从管道经阀门进混合器，与空气混合后送进炉膛点燃，热量经对流、辐射传给工件，达到热传递的动态平衡，炉温稳定在某个值。炉子把工件保温在 1000 ℃ 做渗碳——碳的扩散对温度极敏感，差几十度渗层就差一截，所以要的是稳定维持，不是"能不能加热"。

2.2 最省事的开环办法

理想条件下，阀门开度一定 → 煤气流量一定 → 放热一定 → 炉温一定。于是可以反过来做：测出各开度对应的稳定温度，在阀门刻度盘上直接标温度。要 1000 ℃ 就把阀门拧到刻着"1000"的角度，人就可以走了。定义里的"没有人直接参与"已经满足，所以它确实是自动控制，只是精度不高。

为什么不精确？因为现实系统有干扰：

  1. 煤气压力不稳。用气高峰管网压力降下来，阀门开度没变、实际流量却变小，放热减少，炉温往下掉。
  2. 环境温度在变。冬夏散热效率不同，夏天炉温偏高、冬天偏低。
考研补充 · 用方框图语言说"开环"

开环的本质：控制装置只管发命令，不管命令有没有被执行到位；信号单向流动，构不成回路。判断开环还是闭环，别看它有没有自动化设备，只问两句：有没有把被控量测回输入端？方框图上有没有形成闭合回路？这两条后面会变成判断闭环的实操标准。

2.3 换成人来干，再换成装置

要更高精度，先看人怎么做：炉上装温度计随时看（眼睛），偏离 1000 ℃ 就判断偏高还是偏低、差多少（大脑），再开大或关小阀门（手）。整个过程人必须在线、始终不停地调——干扰随时发生，而人是唯一的纠偏机制，人一走纠偏就停。这反过来提示了自动化：只要把"人"这个纠偏功能用装置固化下来，人就可以离场。

自动控制就是用装置去代替人的这些功能，三块对应三种能力：

前置补课 · 热电偶凭什么能"当眼睛"

两种不同金属接成回路，两端存在温差就产生热电势。两个性质让它适合当眼睛：输出是电压（只有电压才能拿去比较），且与温度近似线性（知道电压就知道温度，且等比例）。缺点是信号很弱（毫伏级），所以现场必须配放大器。

这个电压记为 ut——表面是电压，实际反映炉温。另一路用给定电位器输出 ug，电刷停在标定位置（对应 1000 ℃），这个位置就成了期望温度的化身。

为什么这里的电压可以"代表"温度

这是全课最关键的一次思维跳跃：温度不能直接相减，但与温度一一对应的电压可以。于是"温度差多少"被翻译成"ug−ut 等于多少"。从此物理系统的运行规律变成信号之间的关系——这正是自动控制原理能用数学处理物理系统的原因，也是为什么后面只管电压、位移这些信号，不再回头算热传导。

2.4 平衡、扰动、再平衡：闭环到底怎么工作

视频核心 · 闭环工作的三段

① 平衡态。炉温恰为 1000 ℃，ut=ug，偏差 Δu=0；放大器输出为零，电动机不转，阀门停在原处——而原处刚好能把温度维持在 1000 ℃。

② 扰动发生。工人打开炉门检查，冷空气进去，温度掉下来；热电偶感受到的电势减小，ut 跟着变小，而 ug 标定不变。

③ 自动纠正。此时 ug−ut≠0，偏差被放大后加在电动机上，电动机经齿轮减速器带动阀门（温度偏低，往开大方向转），流量增大、温度回升；直到 ut 与 ug 在新的基础上再次相等、偏差归零，电动机停转，进入新平衡。

为什么这就叫"闭环"

老师给的理由很朴素：阀门不是"调好就停在那儿不动"——温度一变化，阀门位置还会被重新调节，而调节依据正是温度本身。信号从给定出发、经过一长串装置到达被控对象，再从被控对象回到出发点，首尾相接成环，这就是"闭环"这个名字的全部含义。反过来看开环方案：阀门一旦拧到"1000"，它的位置就和温度再也没有关系了。

三、极性接反：从闭环到事故

假设温度高了、本该把关小阀门，结果接线弄错、转向反了变成开大：温度因此更高，更高之后又开得更大——偏差不被消除，反被放大。

极性接反的连锁后果
  • 电动机、减速器、阀门之间开始"较劲"（互相顶牛）。
  • 电动机较弱：被卡死 → 发热 → 绕组烧毁。
  • 电动机强、阀门结实：齿轮的齿全部被打掉，之后原地空转。
  • 齿轮也强、阀门不结实：阀门被拧裂，煤气泄漏遇明火 → 安全事故。
考研补充 · 这段事故是后面三章的伏笔

极性接反在数学上就是正反馈：偏差被逐级放大、输出单调发散。后面三块内容都在回答"怎么事先判断这种危险"：第 3 章劳斯判据（不解微分方程判断特征根有没有落在右半平面）、第 4 章根轨迹（参数变化时闭环极点往哪跑）、第 5 章奈奎斯特判据与稳定裕度（离失稳还有多远）。这是"稳定性"这条主线的起点。

知识拓展 · 正反馈不总是坏事

正反馈会让偏差发散，用在控制回路里是事故；但在电子线路里，它被有意用来做振荡器——要的就是"自己越振越大"直到饱和。所以"正反馈"本身是中性的，判断好坏只看你要的是"稳住"还是"振起来"。

四、本节第一个硬技能：由工作原理图画方框图

12:23讲清工作原理后就要把系统的模型建立起来，路径是固定的：

工作原理图 看得见的装置→ 方框图 装置 + 信号→ 数学模型 微分方程 / 传递函数→ 分析·校正 稳 / 准 / 快

由工作原理图画方框图是本节的两个必考点之一，也是典型大题的第一步。判分点：对象 / 被控量 / 给定量找准，各方框与信号线对应正确，比较点的极性符号标对，反馈从被控量引出。

4.1 三问法 + 从后往前推

动笔前先答三句话；画法则是两头先定：被控对象摆最右、给定量摆最左，再从被控量倒着追问"谁在直接影响它"。

问答画什么
谁直接影响炉温？阀门——开度决定煤气流量 q方框「阀门」
谁管着阀门？齿轮减速器——从动轮与阀门连在一起方框「减速器」
谁管着减速器？电动机——输出轴连着减速器主动轮方框「电动机」
谁管着电动机？放大器——输出电压加在电动机上方框「放大器」
谁管着放大器？ug 与反馈电压 ut 的比较比较点 ⊗，输出偏差 Δu
反馈电压 ut 从哪来？热电偶感受炉温，输出电势经放大从炉温引线经方框回比较点
为什么是"从后往前"而不是从前往后

因为控制的目的地是被控量。从目的地倒推原因，每一步答案几乎唯一（工程上一个量通常只有一个主要直接来源）；从给定往前推则每个岔口都要猜"送给谁"，容易走偏。先定两端，再补中间——这个思路在整门课反复出现，分析稳态误差、画根轨迹都用"从结果反推原因"。

4.2 方框图的五大要素

老师把方框图里的图形归结为五类，这是画图、读图时必须认得的"字母表"：

最容易错的地方：方框与信号线混淆

划线之前先问一句：这个环节是"一个装置"，还是"一个量"？是装置就画方框，是量就画带箭头的线。例如"放大器"是装置（方框），"偏差电压 Δu"是量（线）。把放大器画成线、或把炉温画成方框，都是必扣分的硬伤。另外比较点的正负号必须标，否则阅卷时无法判断你是否意识到这是负反馈。

五、例2 · 函数记录仪：一个双回路的系统

函数记录仪是实验室常用仪器：输入端口接被测电压，希望把电压随时间的变化规律记录在纸上。核心是一个电桥，由两个形状、材料、特性完全相同的电位器构成。

前置补课 · 电桥为什么能测位移

两个相同电位器接成桥式，本质是一个分压比可调的电路：电刷在基准位、输出为 0；电刷偏移时，输出与偏移量成正比的电压，且偏移方向不同、电压极性相反。所以电桥是"位移 → 电压"转换器，与热电偶（"温度 → 电压"）角色完全相同，都是"眼睛"。内部电路本章不考，只需记住它输入输出成线性。

关键机械安排：记录笔和电刷绑在同一根绳子上，由绳轮机构拖动，两者总是同步移动；绳轮机构又把减速器的旋转变成绳子的平移。

  1. 平衡。输入为零，电刷在基准位，电桥输出 up=0，放大器输入为零，电动机不转，笔停在原位。
  2. 输入电压出现。笔和电刷还来不及动，电桥输出仍为零，放大器输入端的电压差等于输入电压，放大后加在电动机上，电动机转动。
  3. 笔被拖动。减速器经绳轮机构把转动变平移，绳子带着笔和电刷一起移到新位置。
  4. 电刷一动，反馈就来了。电桥输出不再是零，且极性与输入电压相反，两者相减、偏差随之减小。
  5. 停在新位置。直到电桥输出与输入电压大小相等、方向相抵消，偏差为零，电动机停转，笔停在确定位置。
  6. 连续记录。输入不断变化，笔就不断跟踪；另一方向用电机匀速拉纸（相当于时间轴），纸上就画出一条曲线。
为什么非要把电刷和笔绑在一起

因为反馈信号必须来自被控量的真实位置：这里被控对象是记录笔、被控量是笔位移，电桥感受的是电刷位移，只有两者联动，电桥测的才真正是"笔现在在哪儿"。若两者独立，反馈的就是与现实无关的量，闭环立刻失效——这与"极性接反"同类：反馈通道送回的信息，必须忠实对应被控量。

5.1 为什么要再加一个小回路

这里的"电动机"其实是一个电动测速机组：一根细长圆柱分两半，一半是电动机，一半是测速机（相当于发电机），两者同轴。电动机一转，测速机绕组切割磁力线产生发电效应，把与转速成正比的电压送回放大器前端，于是系统多了一个内回路。理由：希望笔能把电压的变化规律"记得比较准"，即要求动态响应灵敏——输入有微小变化时笔能迅速跟上，所以用测速反馈改善动态特性。

前置补课 · 测速发电机是什么

测速发电机是一只能"反向使用"的电机：给它转速，它还你一个与转速成正比的电压，是"转速 → 电压"的传感器。只反馈位置时，系统只知道已经偏了多少，不知道偏得多快，动作慢半拍、容易冲过头再折回（振荡）；加速度反馈后能提前减速、稳住——这就是阻尼的来源。只需记住：它测转速、作用是改善动态性能；数学解释在第 3、5 章补上。

六、开环与闭环：老师为什么只讲闭环

对比项开环控制闭环控制
信号流向单向，构不成回路存在反馈信号流动，构成闭回路
控制精度依赖元件本身精度，干扰无法自纠，不高靠偏差驱动，可达相当高
结构复杂度简单省事装置多、结构复杂、成本更高
是否需测被控量不需要必须（否则形不成偏差）
稳定性问题不存在失稳问题存在——极性或参数不当会发散

老师说得很直白：以后讲系统的工作原理，都是针对闭环系统而言的，因为开环系统没有太多东西要说，比较简单；而闭环系统有很多东西要展开去说。

为什么后面整门课几乎只研究闭环

开环的性能在设计阶段就被元件定死了，没有可调节的余地；闭环引入反馈后，多出三个可分析也可设计的维度：稳定性（会不会发散，第 3、4、5 章）、准确性（稳态误差）、快速性（动态性能）。这三个词就是本课程对性能的基本要求，且只在闭环上才有意义。

七、负反馈控制原理 —— 本节头号考点

36:57老师说："所有的闭环系统或者反馈系统，都遵循这样一个基本的工作原理——负反馈原理。"他用三层意思来阐述它。

视频核心 · 负反馈控制原理的三层意思（建议原样背下）
  1. 把输出信号引回到输入端，与输入信号相比较。——这一层讲"反馈"这个动作本身。
  2. 利用所得的偏差信号进行控制。——老师强调：这意味着是负反馈，偏差一出现就成为控制的依据。
  3. 目的是减小偏差、消除偏差。——这一层讲目的，也是判断"这个反馈有没有用对"的标准。

由此总结出闭环系统的两个显著特点，它们是判断是否闭环的实操标准：结构特征——画方框图，一定存在反馈信号流动、构成闭回路；机理特征——一定靠偏差起调节作用，不管什么因素使被控量偏离给定值，偏差一出现闭环就起作用，直到调回给定值才稳定。

两个高频误解
  • 误解一：有反馈就是闭环。反馈也分正负。如果反馈回来的信号使偏差增大，那就是正反馈，系统会发散（正是 2.6 节那场事故）。判断关键是看比较点上的符号，以及反馈信号是"抵消"还是"助长"输入。
  • 误解二：有自动化设备就是闭环。2.2 节的炉子全自动，却是彻头彻尾的开环。决定性因素是有没有把被控量测回来参与决策，而不是设备多不多。
考研补充 · "简述负反馈控制原理"这类题怎么答

采分点就是上面那三层，按序写、一句一层：① 把输出量（被控量）测量、变换后引回输入端；② 与输入量（给定量）比较得偏差；③ 利用偏差产生控制作用，使偏差减小乃至消除，让被控量按给定量规律运行。若问"闭环的特点"，补上"构成闭回路、偏差起调节作用"。

八、控制系统的组成：两大块、六大元件

39:16老师把整个系统分成两块：被控对象——完成一个特定控制任务所必须借助的那个装置（要建立一个温度场，一定要借助一台加热炉，没有它控制目标无从谈起）；控制装置——除被控对象之外所有的东西，因为搞控制特别关注它，所以再细分。

控制装置里的这些元部件，本质上都是在代替人的功能，共六类：

功能元件作用对应人的炉温系统里是
测量元件你要控制什么量，就必须测量什么量眼睛热电偶
比较元件把被控量与给定量比较，形成偏差大脑比较线路
放大元件偏差信号幅值、功率都比较弱，需放大后才能驱动执行机构—放大器
执行机构直接操纵被控对象的被控量胳膊电动机+减速器+阀门
校正装置用来改善系统性能—（本例没有）
给定元件给出给定量，规范被控量运行的规律—给定电位器
视频核心 · 哪些必须有，哪些可以省
  • 测量元件、比较元件、执行机构（眼、脑、胳膊）——这三个是每个控制系统必须有的。
  • 放大元件——原理上，如果偏差信号足够大、能直接推动执行机构，也可以不要；但一般来说控制系统里都需要。
  • 校正装置——控制精度要求不太高的系统可以不要。
  • 给定元件——必须要有；但它不一定属于这个系统本身，可能由外部装置提供（函数记录仪就是这种情形）。

老师还从"输入"的角度把系统上的信号分成两类：给定作用——规定被控量应遵循的运行规律，是有利的；干扰作用——客观存在、不以人的意志为转移（煤气压力波动、外界温度变化、开炉门），使被控量偏离给定规律，是不利的。于是控制系统的任务可概括成一句：想办法消除或抑制干扰对被控量的扰动，使被控量始终按给定量的规律运行。

九、校正方式与复合控制

剩下的一段，老师把"校正元件放在哪儿"先铺开成四种方式，本节只要求认得名词：

方式校正元件放在哪里后续在哪讲
串联校正放在偏差之后、前向通道上（主通道里、被控对象之前）第 3、5 章
反馈校正把输出引回来，经校正装置做局部反馈第 3、5 章
前馈校正（按输入补偿）输入信号进入主反馈回路之前先通过校正装置，再引入闭环第 5 章
前馈校正（按干扰补偿）把可测量的干扰测出来，经校正装置加到系统中，用它去抑制它自己第 5 章
视频核心 · 复合控制的定义

老师给出一句很干脆的结论：开环控制、闭环控制、复合控制这三种方式里，复合控制就是前馈控制加上反馈控制。下次课（控制系统示例与复合控制）他会用一个具体例子来讲它。

十、小结

50:08这节课的内容收拢成两个必须掌握的知识点：

  1. 负反馈控制原理。以后研究的系统都是针对闭环控制系统展开的，而闭环系统依据的核心控制机理就是它：把输出信号引回输入端与输入信号比较，利用所得的偏差去控制被控对象，最终达到减小偏差、消除偏差的目的。
  2. 由工作原理图绘制方框图。这是以后建模过程中首先要完成的第一步；只有建立了数学模型，才能运用课程中讲的分析与校正方法对系统展开研究，需要通过听课和作业掌握到位。

记忆入口 · 一眼回忆

一条链

工作原理图 看得见的装置→ 三问 对象 / 被控量 / 给定量→ 从后往前推 谁在影响它？→ 方框图 方框 + 信号 + 比较点→ 数学模型 微分方程 / 传递函数→ 分析校正 稳 / 准 / 快

负反馈原理 · 三层

  • 引出：输出信号引回输入端，与输入信号比较；
  • 利用：用所得的偏差去控制 —— 这才叫"负"反馈；
  • 目的：减小偏差、消除偏差。

方框图五要素

  • 方框 = 装置；带箭头的线 = 物理量；
  • ⊗ 比较点（只比同性质的量）；实心点 = 引出点（理想，引多少路都不变）；
  • 负号 —— 决定系统收敛还是发散的那一笔。

系统组成

  • 两大块：被控对象 + 控制装置；
  • 六大元件：测量（眼）、比较（脑）、放大、执行（胳膊）、校正、给定；
  • 必备三个：测量、比较、执行；给定量必须有，但给定元件可以在系统外。

两个坑

  • 反馈极性接反 → 正反馈发散：烧电机 / 打齿 / 拧裂阀门 → 事故；
  • 把"有自动化设备"当成闭环 —— 判断只认两件事：有没有测回被控量、有没有构成闭回路。
