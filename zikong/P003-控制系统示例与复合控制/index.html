一、本节课的任务与「方框图」

开场交代本章剩余：控制系统的示例、自动控制系统的分类、对控制系统性能的基本要求、本课程的研究内容。本节 39 分钟只办两件事——把上节两个系统再推一遍，再用两个新系统讲透复合控制；分类与性能要求放到 系统分类与性能要求。

这一章真正的技能是：把一台真实设备的运行过程，翻译成一张只有方框和箭头的图。这张方框图是后续一切数学分析的入口——微分方程、传递函数、稳定性判据都要先有它。每讲一个系统都走同一套动作：先弄清工作原理，再问「什么量跟踪什么量」，然后从被控量倒推出整张图。

1.1 三种控制方式与负反馈

自动控制＝没有人直接参与，用控制装置使被控量按给定量的规律运行。实现方式三种——开环、闭环、复合。其中闭环（负反馈）控制是本课程研究的主体；开环简单但精度不高；复合控制本节举例专门说明。

视频核心 · 负反馈控制原理（一句话版本）

把系统的输出信号引回输入端，和输入信号相比较，达到减小偏差、消除偏差的目的。任何闭环系统遵循的核心机理都是它——老师把「深入理解负反馈控制原理」列为本课程的基本功。

1.2 系统由哪些环节拼成

系统分两块：被控对象与控制装置。搞控制主要关注后者，把它分细：测量 → 比较 → 放大 → 执行，再加给定与校正两类元件。老师用人体作比：测量像眼睛、比较像大脑、执行像胳膊。

校正元件的三种摆法：放进前向通道叫串联校正；把输出局部引回做反馈校正；把干扰或输入提前引入叫前馈校正。前馈＋反馈，就构成复合控制——这正是例 2 要兑现的一句话。

二、复习两个旧例：由工作原理图到方框图

老师没有直接讲新内容，而是把炉温、函数记录仪重新推了一遍：画方框图这个动作必须练成肌肉记忆。口诀只有一句——两头先定，从后往前推。

2.1 炉温控制系统：从被控量倒着问回去

先定两头：被控对象＝加热炉（放最右），被控量＝炉温（从加热炉右边引出），给定量＝给定电位器电压 ur（放最左）。再从被控量追问「谁在直接影响它」：阀门 → 减速器 → 电动机 → 放大器，而放大器的输入是 ur 与热电偶反馈电压 ut 的偏差。

2.2 函数记录仪：双回路的系统

要求「笔的位移跟踪输入电压的变化规律」。同样两头先定：被控对象＝记录笔，被控量＝笔的位移，给定量＝要记录的那个电压 ur。倒推：绳轮机构 ← 减速器 ← 电动机 ← 放大器，放大器输入是 ur 与电桥反馈电压 up 的偏差。

与炉温不同的是多了一个内回路：电动机同轴带着一台测速机，把转速换成电压送回放大器前端。因为要求笔「记得准、跟得快」（动态特性好），才加这一路测速反馈。电桥直接与笔位移相连，构成外回路的位置反馈。

视频核心 · 两个旧例各留下一样「遗产」
  • 炉温系统：给出标准骨架，给定 → 比较 → 放大 → 电机 → 减速 → 执行 → 被控对象 → 反馈回比较。

三、例1 · 火炮方位角控制系统

火炮装在转盘上，转盘由伞形齿轮带动；电动机接在齿轮减速器的主动轴上，另有瞄准器。要求很明确：火炮的方位角跟着瞄准器的方位角走。

工作过程这样闭环：瞄准器给定方位角后，只要火炮方位角与它有偏差，就得到偏差电压；经相敏整流器 → 校正装置 → 功率放大加在电动机上，电动机驱动减速器、拉着火炮向瞄准方向靠拢；直到两角一致、偏差为零，火炮在新位置达到平衡。核心器件是自整角机。

3.1 自整角机：把两个角度「接」成一路电信号

前置补课 · 读懂自整角机之前，先接受三件小事实
  • 绕组通交流电会产生来回交变的磁场，方向与该绕组的绕制方向一致。
  • 三相绕组在空间互差 120°，这就是「三相」的本来含义。
  • 变化的磁场能在别的绕组里感应出电势（电磁感应）——有感应电势，才可能有输出电压。

接受这三件事，下面「角度变电压」的过程就只是把它们串起来。更深的电机学推导不属于本课程。

3.2 角度是怎么变成电压的

  1. 发送机转子通交流电。转子绕组产生方向来回交变的交变磁场。
  2. 三相定子被感应。磁场照到三组定子绕组上，各绕组中感应出交变电流——只有与绕组同向的投影分量起作用，垂直分量不起作用。
  3. 磁场被「搬」到接收机。发送机三相定子经三根线接接收机三相定子，于是发送机里的磁场规律原封不动地出现在接收机里。
  4. 接收机里做一次角度比较。接收机转子与火炮同轴。两方向一致时，搬来的磁场与转子绕组垂直，不产生感应电势，故输出 e=0。
  5. 出现失调角就输出偏差。两方向差一个失调角 θ，磁场多出一个与转子绕组同向的分量，于是 e≠0。
为什么输出正比于 sinθ，而不是别的

两点决定性的观察：① 失调角越大，投影到「同向分量」上的长度越大，输出电压越大；② 这个投影长度正比于失调角的正弦。

e∝sinθ≈θ

（θ 较小时）实际控制中失调角不会很大，此时 sinθ 与 θ 几乎一样，于是可近似认为偏差电压与失调角成正比。这一步「小角度线性化」是自整角机能当作简单比较元件的关键——只有关系线性，后面才能用线性系统的方法分析它。

这里最容易想错的一点

以为「两个角度相等时输出最大」。恰恰相反：对准时磁场与转子绕组垂直，输出为零；偏差越大输出才越大。所以自整角机是工作在零位附近的平衡式测量元件——靠偏离零位产生控制信号。

3.3 画出方框图

三问法先答清楚：被控对象＝火炮，被控量＝火炮方位角，给定量＝瞄准器方位角。

例由火炮方位角控制系统的工作原理图，画出它的方框图。

思路：两头先定，从被控量倒着问回去

把被控对象「火炮」摆最右，给定量「瞄准器方位角」摆最左，中间倒推补齐。

  1. 谁直接影响火炮方位角？减速器——它直接带着火炮转。
  2. 谁控制减速器？电动机——它接在减速器主动轴上。
  3. 谁控制电动机？功率放大器。
  4. 谁控制功率放大器？校正装置——这是一个串联校正装置，放在前向通道上。
  5. 谁控制校正装置？相敏整流器，其输入是自整角机给出的偏差电压。
这一步最容易错的地方

把自整角机画成两个方框（发送机、接收机各一个）当成串联元件。此画法里，自整角机整体扮演一个比较元件——它做的唯一一件事是把「瞄准器角度」与「火炮角度」相减，应画成比较点。老师原话：它「可以当成一个比较元件，完成大脑的功能」。

前置补课 · 相敏整流器是干什么的

自整角机输出交流电压，其相位（正负方向）携带着「火炮偏向哪一边」的信息。相敏整流器把它整流成直流、同时保留偏差方向——是正是负，决定电动机往哪边转。本课程不深究其电路，只需记住它位于比较环节与放大器之间。

3.4 另一种画法与应用

同一系统从不同角度可画成不同的方框图。另一种画法把它拆成发送机与接收机：发送机把瞄准器转角变成电压，接收机把火炮转角也变成电压，两个电压再相减得偏差。这样接收机是测量（敏感）元件，发送机是「角度 → 电压」的变换元件。

知识拓展 · 为什么这套结构能用在「火炮群」上

自整角机之间那几根连线可以拉得很长。火炮可以放在很远的地方，瞄准器单独摆一处，一台瞄准器可同时带一个火炮群对准同一目标开火。这正是「测量元件与控制元件可分离」的工程价值——比较用的「命令」可在几十米外产生。雷达引导高炮、舰炮随动系统里都有它的影子。

四、例2 · 水温调节系统：复合控制正式登场

28:43目标很朴素：让热交换器出口实时输出固定温度（如 60 ℃）的热水，用户用水多少都保持恒定。冷水经阀门进热交换器，高压蒸汽经另一个阀门进热交换管，在管内与冷水换热。出口处装温度控制器测水温，控制器里有一个旋钮设定理想温度（像冰箱的温度调节器）；实测低于 60 ℃ 就开大蒸汽阀门，偏高就关小。

4.1 流量一剧烈变化，温度就压不住

31:48流量比较恒定时控制效果不错；一旦出口流量剧烈变化，出口水温波动就大。老师的生活比喻：居民上班时家里没人、用水少，下班都回来一起开热水阀，流量就发生很大变化。

流量小时，池里的水早已烧到 60 ℃，蒸汽阀门维持在不大不小的开度。用水量骤增后，热水大量流出、冷水补入；而温度计装在出口处，流出的过程中池里的水基本还是 60 ℃，它感受不到这突如其来的流量变化；等整池水变凉才反应过来，此时再开大阀门已经迟了——至少要等半池冷水先流走，新加热的水才过来。

为什么「测量滞后」会毁掉反馈的效果

反馈控制的前提是「先看见偏差，再纠正偏差」。这里的问题恰恰是测量本身慢了半拍：温度计读到的还是「过去的水温」，等它读出偏差，扰动早就作用完了——反馈回路里插入了一段大滞后。

这不是负反馈原理错了，而是这一路反馈对一个特定的干扰反应太慢。所以解决思路不该是「把反馈做得更强」，而是：能不能在扰动刚发生、还没影响到出口温度之前，就把它测出来并提前补偿？这就是前馈的动机。

4.2 加一只流量计：让补偿「提前发生」

问题根源是传感器装在出口处，而它要控制的正是出口水温，位置无法改。但有一件事可以利用——冷水的补充量和出口流量是相同的（流出多少水，就要补充多少冷水）。于是：虽然温度不能及时感受流量变化，但冷水进水管处的流量却能非常敏感地感受到它。

在冷水进水管上加一只流量计：出口流量骤增、温度还没反应时，流量计已经测到，把对应的电压信号送到温度控制器的前端，先把电磁阀开大、加大蒸汽，在流量变大的这段时间里提前把热交换器的温度提上去。等水真正流到出口时，温度虽有波动，但波动已经很小了。

照例先问「什么量按什么规律运行」：让出口水温按旋钮设定的 60 ℃ 变化。于是被控对象＝热交换器，被控量＝出口热水温度，给定量＝旋钮设定温度。倒推：阀门直接影响出口温度，温度控制器管着阀门，其输入是设定温度与温度传感器反馈电压之差，主反馈回路就此闭合。新加的支路上：冷水流量是干扰量，用流量计变换成电信号预先加到控制器前端，这就是按干扰补偿的前馈控制。

为什么前馈能「提前」，反馈却不行

关键在测量的对象不同：反馈测的是被控量（出口水温），扰动要「走完整条通道、影响到出口」才被看见，天生滞后；前馈测的是干扰本身（冷水流量），扰动一出现就被抓到，不必等它把后果做出来。

一句话概括分工：反馈是「事后纠偏」，前馈是「事前预判」。前者通用但慢，后者快但只对「可测量、可预知的干扰」有效——这也是前馈不能单独用、必须和反馈配成复合控制的原因。

五、复合控制：本集头号考点

水温系统里，冷水流量是干扰量；用流量计把它测出、变换后加到控制器前端，就完成按干扰补偿。这个前馈控制与原来的反馈控制一起，构成复合控制。老师强调：「这是一个非常典型的按照干扰来补偿的前馈控制的控制策略。」

视频核心 · 复合控制的定义（建议原样记下）

04:00在开环、闭环、复合三种方式里，复合控制＝前馈控制＋反馈控制，同时保留两条通道：

  • 反馈通道：从被控量测出、送回输入端比较，用偏差去纠正——保证最终精度。
  • 前馈通道：把可测量的干扰（或输入）测出，经补偿装置提前注入系统——加快对扰动的响应。

老师还给了结论：凡是闭环系统，核心机理都是负反馈；复合控制是在负反馈基础上再外加一路前馈补偿。

5.1 前馈与反馈，一次说清

对比项反馈控制前馈控制
测量对象被控量（如出口水温）干扰量（如冷水流量）
动作时机偏差出现之后 —— 事后纠偏干扰出现之时 —— 事前预判
是否构成回路是，构成闭合回路否，是单向的开环补偿通道
优点通用，能对付一切引起偏差的因素响应快，扰动尚未显形就补偿
局限对滞后大的环节反应慢只对「可测量」的干扰有效，单独用不保证精度

前馈按其信号来源又分两种：按输入补偿——前馈信号取自输入 r，先经校正装置再进主回路；按干扰补偿——把可测量的干扰 n 测出来反向注入。本节水温系统是典型的按干扰补偿。

为什么前馈不能单独使用

前馈是开环的：它测的是干扰，不是被控量。它只能对「事先知道规律、又能测到的那个干扰」做补偿；如果补偿量算得不准，或者出现别的没测的干扰，前馈自己发现不了、也纠正不了——因为它根本没有把被控量送回来比较。

反过来，反馈虽慢，但它盯着被控量本身，任何原因造成的偏差它都管。所以两者必须组合：反馈负责「最后一定要准」，前馈负责「尽量不要慢」。这就是复合控制同时保留两条通道的根本理由。

考研补充 · 关于复合控制，答题要抓住三个点
  1. 定义要准确：复合控制＝前馈控制＋反馈控制，而非「两种反馈相加」。
  2. 分清前馈的两种补偿方向：按输入补偿（信号取自输入）、按干扰补偿（信号取自可测干扰）。水温系统属后者。
  3. 能在方框图上指认：前馈通道一定不构成回路，且信号来自「干扰」或「输入」。判断一个系统是不是复合控制，就看它是否同时存在一条反馈回路和一条前馈补偿通道。

复合控制的定量设计（按不变性原理求补偿装置）属于第 5 章，本页只需把结构认全、把定义背准。

知识拓展 · 前馈—反馈在工程里的常见身影

「按干扰补偿」在工业控制里非常普遍：锅炉汽包水位用蒸汽流量做前馈、汽轮机用负荷指令做前馈、精馏塔用进料流量做前馈……共同点是：总有一个「又大又快」的可测干扰需要被提前抵消。凡遇到「某个扰动量能测、又来得猛」的场合，工程师往往就在反馈回路之外再挂一条前馈。你学到的不只是一个水温系统，而是一类反复出现的控制套路。

六、小结与衔接

两个新系统各留一个记忆抓手：火炮系统记自整角机——「角度比较器」，对准时输出为零、失调时输出正比于 sinθ；水温系统记流量计——它把「又快又猛」的冷水流量干扰提前量出来，在出口温度还没变凉之前就动手。合起来正好回答：一个只会「事后纠偏」的反馈系统，如何靠一路前馈获得「提前量」。

一条链

工作原理图 装置→ 三问 对象 / 被控量 / 给定量→ 从后往前 谁在影响它→ 方框图 方框 + 信号 + 比较点→ 复合控制 反馈 + 前馈

两个系统

  • 火炮方位角系统：被控对象＝火炮，被控量＝火炮方位角，给定量＝瞄准器方位角；核心器件自整角机，画成比较元件；输出 e∝sinθ，小角度近似 ∝θ。
  • 水温调节系统：被控对象＝热交换器，被控量＝出口水温，给定量＝旋钮设定温度；温度控制器测出口水温（反馈），流量计测冷水流量（前馈）。

要背的

  • 复合控制＝前馈控制＋反馈控制，本集头号考点。
  • 前馈按来源分两种：按输入补偿、按干扰补偿；水温系统属后者。
  • 前馈通道不构成回路（开环补偿），反馈通道构成回路。
  • 画图口诀：两头先定，从后往前推。

两个坑

  • 把自整角机画成两个串联方框 —— 当比较元件用时它应是一个比较点。
  • 以为「两角相等时自整角机输出最大」—— 恰恰相反，对准时输出为零，靠偏离零位工作。
