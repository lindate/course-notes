一、方程列出来了，"解"它这一步怎么办

上一节（控制系统的数学模型（下））把输入、输出关系写成微分方程，这就是系统的时域模型。老师说，解一旦拿到手，系统在任意时刻的精确行为就都能用这个解析式表达。可硬解常微分方程（求积分、消元、反复用初值定常数）不太容易，阶数一高人工几乎做不动。

于是把主程序打断，进拉普拉斯变换这个"子程序"。上节已备好定义、常见变换对与几条定理；本页走最后一段——反变换：代数方程好解，但解出的是象函数，得变回时域才是方程的解。

为什么"绕道 s 域再绕回来"反而更省事

因为在 s 域里求导变成乘法。时域里纠缠在一起的"求导、解方程、用初值定常数"，被拆成三步互不干扰的机械动作：① 两端变换得代数方程；② 解出象函数；③ 反变换回时域。我们多花的是搬来搬去的力气，省下的是"解微分方程"这件难事。

数学家给过一条一步到位的反演公式（下式）。老师说它写出来很漂亮很完整，无懈可击，可实际用时这个广义积分一般都不容易算——它更多是理论保证，不是工程工具。

f(t)=12πj∫σ−j∞σ+j∞F(s)estds

工程上的做法是查表：给一个象函数，把它拆成表里已有简单象函数之和，再逐项查回去。这个"拆"，就是部分分式分解，也是全页的主角。

二、前置补课：把"有理分式"这一族名词一次锁死

要拆的对象是一个关于 s 的有理分式。跨考同学先把下面几个名词和符号认全，后面才读得下去。

前置补课 · "部分分式分解"到底在干嘛（先看一个类比）

好比把一张整钱换成零钱：整钱 = 一个复杂的大分式，零钱 = 几个简单小分式。为什么要换？因为"钱包"——上节那张变换表——里只认得零钱，表上只有 1s、1s+a 这类最简单的象函数。

数学上的根据是一条代数定理：任何一个分子次数低于分母次数的有理真分式，一定可以拆成若干个最简分式之和，形如 c(s−p)k。所以部分分式不是要去发明技巧，而是代数保证做得到的事；我们要做的只是把系数 c 求出来。

符号扫盲：s 是上节引入的复变量（可以当自变量的复数），本节所有式子都是它的函数；m、n 分别是分子、分母多项式的次数（最高次幂的指数）。

这里只要会用即可：记住"整钱换零钱"这句话，细节可先跳过，往下读不影响。

前置补课 · 真分式、假分式、极点，各一句话

把象函数写成 F(s)=B(s)A(s)：B(s) 是分子多项式，A(s) 是分母多项式。

真分式
分子次数 m 小于分母次数 n —— 分子比分母"矮"。只有它才能直接拆。
假分式
m≥n。不能直接拆，先用长除法化成一个"多项式 + 真分式"。
极点
令分母 A(s)=0 解出的那些根 p1,p2,…,pn。它们同时也是系统的特征根——课上这两个词指同一批数。

实际物理系统是因果系统（先加激励才有响应），所以 m≤n，象函数必是这两种之一。

04:09老师把可用的三种拆法都列了出来，都能用；但本章统一用留数法，因为它几乎不用列方程，一个极点一次算出一个系数。

方法怎么做什么时候用
试错法在分子上人为加减一项，凑成能约分的形式（如把分子写成 (s+a)−s）。分母只有两三个简单因子、一眼能看穿时最省事。
系数比较法把分解式通分，令两端 s 的同次幂系数相等，解方程组。项数不多时稳当；项一多就烦。
留数法对每个极点单独套公式，一次算出一个系数，互不干扰。本章统一用它；单根 / 复根 / 重根各有公式。

三、一般框架：从微分方程到象函数

写出一个 n 阶线性定常系统的微分方程，并假定初始条件为零（这是本段的简化前提）：

∑i=0naidic(t)dti=∑j=0mbjdjr(t)dtj

其中 c(t) 是输出，r(t) 是输入。物理系统 m≤n，即前面说的因果系统。关键动作是两端同时做拉氏变换，并用上节的微分定理：零初值把一串"初条件尾巴"全部抹掉，c 的 i 阶导数直接变成 aisiC(s)。合并输出项、输入项得代数方程：

(∑i=0naisi)C(s)=(∑j=0mbjsj)R(s)

记 A(s)=∑aisi、B(s)=∑bjsj。原来的微分方程，现在变成"多项式乘象函数 = 多项式乘象函数"——导数不见了，只剩乘法与加法。

为什么"微分定理 + 零初值"这一步是命根子

微分定理说：c(t) 求一次导，相当于在 s 域乘一个 s；i 阶导就乘 si。于是"求导"被整体换成"乘 si"，方程退化成多项式等式。零初值让初值项归零，公式才这么干净；后面 RC 例会故意不设零初值，看它多出什么。

前置补课 · 单位脉冲与单位阶跃，各一句话

单位阶跃 1(t)：t 小于 0 时为 0，t 大于等于 0 时为 1——像"开关一合，信号从这一秒起恒为 1"，象函数 1s。

单位脉冲 δ(t)：只在 t=0 一瞬取值、其余为 0，可以理解成"极短极强的一下敲击"，象函数恰好是常数 1。下面正要用它。

把 C(s) 前面的系数除过去得 C(s)=B(s)A(s)R(s)。老师说输出取决于输入；为把话说定，取输入为单位脉冲 δ(t)，其象函数 R(s)=1：

C(s)=B(s)A(s)⋅1=B(s)A(s)

于是象函数是标准形态：分子 m 阶、分母 n 阶的有理分式。一般系统都长这样，所以只要会反变换"任意有理分式"就够了。

这里已埋下"传递函数"的种子（下一节展开）

B(s)A(s) 只跟系统自身有关，与输入无关；取单位脉冲时它恰好就是 C(s)。它就是下一节（拉氏反变换与传递函数（下））要正式定义的传递函数——即"系统输出象函数 ÷ 输入象函数"。单位脉冲响应，就等于系统传递函数本身。

四、单根情形：留数法

把分母因式分解即得极点。先看最简单的一套：n 个互异单根 p1,…,pn（没有重根）。代数定理保证能拆成：

F(s)=B(s)A(s)=∑i=1ncis−pi

系数 ci 叫对应极点 pi 的留数——它就是让上面这个分解式成立的那个系数。全部 n 个留数求出来，"分解部分分式"就完成了，剩下逐项查表。

ci=lims→pi(s−pi)F(s)

为什么乘 (s−pi) 再取极限就能把系数"抠"出来？看下图。

老师还给了另一个等价公式，形式上更省事——不用写极限符号：

ci=B(pi)A'(pi),A'(s)=dA(s)ds
为什么导数形式和取极限是同一件事

A(s) 在极点 pi 处正好等于零，而 (s−pi) 是它的一个因子。当 s→pi 时，A(s)s−pi 描述的正是"A 在零点附近怎样线性地穿过零"，这个比值就是 A 在 pi 处的导数 A'(pi)。把这份导数搬到分母位置，两条公式就重合了。做题时两种情况随便挑。

例20:06求 F(s)=s+2(s+1)(s+3) 的原函数。

思路：两个互异单根，直接套留数公式，一步一个

分母为零给出 p1=−1、p2=−3，可拆成 c1s+1+c2s+3。

c1=s+2s+3|s=−1=12,c2=s+2s+1|s=−3=−1−2=12

两系数都是 12，查表 1s+a→e−at：

f(t)=12e−t+12e−3t
这一步最容易错

代值时代错地方、或漏掉负号。c2 的分母是 s+1，代入 s=−3 得 −2，分子 −1，两个负号相消才是 +12。每算一个系数都回头验一下最稳。

例求假分式 F(s)=s+2s+1 的原函数。

思路：先看次数——m=n，必须先长除
s+2s+1=(s+1)+1s+1=1+1s+1

表里只有 δ(t) 的象函数是常数 1，所以 f(t)=δ(t)+e−t，比真分式多一个冲激项。

这一步最容易错

想都不想直接对假分式套部分分式。一旦 m≥n，代数定理就不保证能拆成纯真分式形式，强套必漏那个多项式项（也就漏掉冲激项）。

五、模态：系统自己的"语言"

拆出 cis−pi 后查表 1s−pi→epit，于是 f(t)=∑ciepit。老师把每一项的指数函数单独命名：eλt 叫特征根 λ 所对应的模态（力学里同一个词常叫"振型"）。

视频核心 · 模态与单位脉冲响应

模态的要点：系统一旦确定，极点（特征根）就定了，模态也就定了；它跟输入无关、跟初值无关，是系统自带的、描述"这个系统会怎么动"的最基本动作单元。由此得到本页最重要的结论：

单位脉冲响应=各模态的线性组合
为什么"极点"这一个复数，就能决定系统的动态

把极点 pi=α+jβ 拆开看（α 是实部、β 是虚部，j 是虚数单位）：实部 α 管"包络"——α 为负时 eαt 衰减，越负越快，为正则发散；虚部 β 管"振荡"——β 不为零就来回摆动，为零则单调。所以只看极点在复平面上的位置，就能预判这一路模态长什么样。

用四阶系统把"模态叠加"具象化。它的特征根是 −2、−8 与一对共轭复根 −1±j2（共 4 个根），单位脉冲响应可整理成：

c(t)=c1e−2t+c2e−8t+e−t(Acos2t+Bsin2t)

即两条实模态加一条振荡模态，共同拼出响应；其中 −2 一路的系数是 −0.25。老师特别点出 −8 那一项"收敛得比较快"——时间稍长就衰减掉了。

6.1 共轭复根：当单根算，最后整理成正弦余弦

例：F(s)=s+3s2+2s+2。老师说得很实用：共轭复根也可以当成"单根"来算，先老实用留数法求出两个复数留数，最后再整理。

前置补课 · 反变换里的两条"整理工具"
欧拉公式
ejθ=cosθ+jsinθ。它把复指数翻译成正弦余弦，是"复数结果整理成实数波形"的桥。
复位移定理
把象函数里的 s 换成 s+a，反变换就在原结果上再乘 e−at。因为 a 是复数时它来自"在 s 域平移"，所以叫复位移。

两条合起来，本课所有带复根的象函数都能反变换，不必碰反演公式。

老师还给了更"不查表"的做法——配方法：把分母配成完全平方加常数 s2+2s+2=(s+1)2+12，再把分子凑成"(s+1) 部分 + 常数部分"，问题就变成查 xx2+ω2 与 ωx2+ω2 的原像（ω 是振荡的角频率：一秒钟摆动多少弧度），只不过 x=s+1。

6.2 重根：公式怎么来、怎么记

第二种情形：分母含 (s−p1)m，即 p1 是 m 重根，其余为单根。代数定理给出的形式是：属于重根的部分拆成 m 项，分母次数从 m 一路降到 1：

F(s)=∑k=1mck(s−p1)k+∑i=m+1ncis−pi

书上直接给了重根系数的一整套公式：

ck=1(m−k)!lims→p1dm−kdsm−k[(s−p1)mF(s)]

公式看着复杂，但记不住可以自己推：两端同乘 (s−p1)m，右边 cm 那项不再带因子、其余各项至少还留一个。于是

  1. 取 s→p1：带 (s−p1) 的项全归零，只剩 cm。
  2. 两边求一次导：cm 求导为零，一次项变成常数 cm−1，更高次的仍在取极限时归零。
  3. 反复求导取极限：每求一次导，"存活"的项上移一位，系数前依次出现 1,2,6,… 的阶乘，除过来就是 1(m−k)!。
重根反变换为什么会多出 t、t2 这些因子

看反变换这一头：1s−p1→ep1t，而 1(s−p1)2→tep1t，1(s−p1)m→tm−1(m−1)!ep1t。也就是说，重根每多一重，时域里就多乘一个 t。这一串 tk−1ep1t 就是 p1 对应的模态族：同一个模态被"叠"了 m 次，重根公式就是用来算这 m 个叠加项各自权重的。

例34:04求 F(s)=s+2s(s+1)2(s+3) 的原函数。

思路：分母含三种根，各按自己的规矩来

−1 是二重根（m=2），0 与 −3 是单根。分解式按降幂排重根项：

F(s)=c1s+1+c2(s+1)2+c3s+c4s+3

① 二重根最高次 c2（取极限即可）：

c2=s+2s(s+3)|s=−1=−12

② 二重根一次项 c1（先对 s+2s(s+3) 求一次导再代 s=−1）：

c1=dds[s+2s(s+3)]|s=−1=−34

③ 两个单根按留数公式：c3=s+2(s+1)2(s+3)|s=0=23，c4=s+2s(s+1)2|s=−3=112。

逐项查表，四对变换一次列出：

1s→1(t),1s+1→e−t,1(s+1)2→te−t,1s+3→e−3t
f(t)=23⋅1(t)−34e−t−12te−t+112e−3t
这一步最容易错

重根项求导时忘了"先乘 (s+1)2 再求导"的顺序，或把 c1,c2 次序弄反。两条口诀：分解式里重根按降幂排（(s+1)2 在前、(s+1) 在后）；最高次取极限即可，每降一次幂多求一次导。算完可取 s=1 代回原式与分解式验算。

七、综合例：RC 电路的解析解

最简单的电路：电源、开关、电阻、电容串成回路。研究对象是电容两端电压 uC，计时起点定在开关闭合瞬间（t=0）。闭合后电源电压就加到这个 RC 回路上，相当于输入一个幅值为 U0 的阶跃信号 ur(t)=U0⋅1(t)，象函数 R(s)=U0s。

前置补课 · 这个电路的物理规律（够用即可）

回路里电源电压 = 电阻压降 + 电容压降，即 ur=uR+uC。电容像一只水桶：流过它的电流 i 等于"水位 uC 上升的速度"乘桶底面积 C，即 i=CduCdt；而电阻压降 uR=iR。两者合起来，得到以 uC 为未知量的方程：

RCduCdt+uC=U0⋅1(t)

这是一条一元一阶线性定常微分方程——正是本课一直在对付的类型。

40:15关键：这次不设零初值——开关闭合瞬间电容上可能已有电压，用微分定理时必须带上初值项。两端变换并整理（把含 UC(s) 的项提到一侧）：

(RCs+1)UC(s)=U0⋅1s+RCuC(0)

把前面的系数除过去，得到电容电压的象函数；为反变换方便，把各项处理成"s 加一个数"的标准形状：

UC(s)=U0/s+RCuC(0)RCs+1=U0s−U0s+1RC+uC(0)s+1RC

逐项查表（1s→1(t)，1s+a→e−at），就得到完整解析解：

uC(t)=U0+[uC(0)−U0]e−t/(RC)

老师顺势把它拆成两种分法，这是本页最该记住的地方：

分法第一分量第二分量说明
按来源分由输入电压驱动由初始条件引起前者叫零状态响应（强迫响应），后者叫零输入响应（自由响应）；满足叠加原理。
按时间分U0（常数项）[uC(0)−U0]e−t/(RC)t→∞ 时指数项趋于零，叫瞬态分量；剩下的 U0 不随时间消失，叫稳态分量。
为什么把响应拆成"零状态 + 零输入"这么重要

因为两部分来源与性质完全不同：零状态（强迫）响应完全由外部输入决定，输入换了它就变；零输入（自由）响应只由系统自身与初始储能决定，与输入无关。分开以后，一可以用叠加原理分别算（考试常考），二能看出：初始条件引起的分量必按系统模态 e−t/(RC) 衰减、最终消失，只留下输入决定的稳态——本题即 uC(∞)=U0，无论从哪出发最终都被充到电源电压。

  • 交叉验证。用控制系统的数学模型（下）的初值、终值定理验算：f(0+)=lims→∞sF(s)，f(∞)=lims→0sF(s)（要求极点都在左半平面）。如本题 uC(∞)=lims→0sUC(s)=U0，与解析解一致。
  • 认模态。见到极点就要能说出模态是"单调衰减"还是"衰减振荡"、衰减多快——这是后面时域分析、稳定性、根轨迹的全部基础。
知识拓展 · 反演公式为什么"漂亮"

反演公式本质是复变函数里的留数定理在线性系统上的应用：沿竖直线（收敛域内）的积分，等于被积函数所有极点处留数之和。展开后得到的恰好就是"按极点拆部分分式、留数作系数"这套结论。所以留数法不是孤立技巧，而是反演公式的"可操作版本"。知道这层联系有助于理解"系数为何叫留数"，考试计算时只用留数法即可。

记忆入口 · 一眼回忆

一条链

起点 微分方程（零初值）→ 拉氏变换 + 微分定理 代数方程→ 解出 C(s)=B(s)A(s)R(s)→ 部分分式 单根 / 复根 / 重根→ 查表反变换 ∑ciepit

要背的

  • 反变换路线：部分分式 + 查表；不直接套反演公式。
  • 单根：ci=lims→pi(s−pi)F(s)=B(pi)A'(pi)，反变换 ciepit。
  • 重根：两端同乘 (s−p1)m，取极限得 cm，逐次求导得 cm−1,…,c1；反变换带 tm−k。
  • 复根：当单根算，整理成 e−at(cosωt,sinωt)。
  • 模态：实单根→单调指数；共轭复根→衰减振荡；越靠左衰减越快。

三个坑

  • 假分式（m≥n）不先长除，漏掉冲激项。
  • 重根分解式漏写降幂项，或求导次序弄反。
  • 微分定理带初始条件时漏掉初值项（RC 例里正是靠它才多出零输入响应）。
